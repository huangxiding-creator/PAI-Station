# 附录 J 开发环境搭建与 AI 协作手册（新人 30 分钟上手）

## J.1 环境搭建（Windows 10/11）
```
1. Python 3.11.9（winget install Python.Python.3.11）
2. git clone https://github.com/huangxiding-creator/PAI-Station && cd PAI-Station
3. python -m venv .venv && .venv\Scripts\activate
4. pip install -r requirements.txt   # 19 依赖见 J.2
5. copy config\pai.example.ini config\pai.ini  # 填智谱 key（免费注册 open.bigmodel.cn）
6. python -m paistation --check       # 配置自检+模型连通测试
7. python -m paistation               # 托盘启动；pytest -q 全绿后开发
```

## J.2 依赖清单（全部主流维护，锁版本发布）
lark-oapi、dingtalk-stream、DrissionPage、watchdog、mss、dxcam（可选）、APScheduler、tenacity、python-docx、pywebview、pystray、paddleocr（或 rapidocr 轻量版）、funasr+torch（SenseVoice，可选重依赖）、jieba、jsonschema、pyinstaller、WinSW（发行随包）。

## J.3 工程规范
- 分支：main 保护+feat/fix 短分支；PR 必须过 CI（lint+单测+隐私断言）；
- 提交：conventional commits（feat/fix/docs/chore）；每次提交附验收锚点编号（如 M1.8）；
- 文档即代码：PROPOSAL_V2 章节与代码模块一一对应，改动代码若影响设计文档必须同步 PR；
- 测试金字塔见 D.1，覆盖率门禁 80%。

## J.4 与 AI 结对开发流程（本项目的生产方式）
用户主导的方向决策 + AI 执行的工程循环：任务卡（验收锚点）→AI 实现→测试自证→code review→合并。此模式已在 We-AIPO 验证（290 commits/78 项优化/11/11 无人值守达标）。规范：AI 产出必须带测试与 audit 覆盖；禁止无验收标准的"顺手重构"。

## J.5 发布流水线
pytest→pyinstaller 打包→签名→WinSW 服务安装脚本→内测通道（20 人）→GitHub Release（附 SHA256）→目录站同步。
