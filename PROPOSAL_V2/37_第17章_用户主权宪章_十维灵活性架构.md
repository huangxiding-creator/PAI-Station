# 第 17 章 用户主权宪章：十维灵活性架构（V3.0）

## 17.0 本章缘起与设计公理

用户指令：**"我想把最大的灵活性给到用户。"** 本章把这句话从愿望翻译成架构。三条设计公理：

1. **一切皆有默认，无一被锁死**（Everything has a default, nothing is locked）：开箱 3 分钟可用（默认值即最佳实践），但每一个默认都可被用户改写——包括本手册通篇论证过的选型本身；
2. **配置即资产**：用户的所有选择（模型路由、感知范围、自主边界、技能定制）随 avatar.pai 导出——换机、迁移、备份时，灵活性一起走；
3. **灵活性不是强迫症**：不把选择负担甩给用户。首启只问 3 个问题（用哪个通道、看哪些目录、自主度多高），其余十维全部后台可调、随用随解锁。

**对标声明**：中国用户心中"灵活性"的金标准是 Quicker / uTools，国际是 Raycast / Obsidian。本章按"可配置项数量、热加载、导出开放度"三个硬指标对标（17.13 FlexBench），目标是**灵活性维度单独超越所有竞品**——这是第 18 章全维超越矩阵的第 11 维。

## 17.2 维度一：模型自由（谁替我思考，我说了算）

四级模型路由，从粗到细逐级覆盖（细者胜出）：

```
全局默认 [llm] → 按消息类型（fast/deep/vision/long 四通道）
→ 按任务域 [domain.周报] model=… → 按技能 [skill.PPT初稿] model=…
```

- **任意端点**：任何 OpenAI 兼容端点 3 行接入（base_url+key+model 名）。预置端点商店（开箱即选）：智谱、DeepSeek、Kimi、硅基流动、阿里百炼、Ollama（本地）、LM Studio（本地）、任意自建（vLLM/llama.cpp）；
- **云地混合**：同一台 PAI 可以"周报用免费云链、合同用本地 Ollama、PPT 用付费旗舰"——第 16 章三级隐私档是本维度的快捷预设（L0/L1/L2 就是三套模型路由模板）；
- **思考开关路由**（V2.2 勘误后的架构红利）：GLM-4.7-Flash 同模型 `thinking` 开/关即得系统 1/系统 2——用户可对每个域单独决定"这块工作要不要深思"；
- **降级链用户可编辑**：默认 4.7-Flash→4.5-Flash→4-Flash-250414，用户可插入自己的端点作末级兜底；
- **预算护栏**：`monthly_token_budget`（默认无限）+ 超限动作（降级/暂停/仅本地）——防付费端点意外烧钱。

## 17.3 维度二：通道自由（在哪说话，我说了算）

- **任意组合**：四通道+桌面通知任意开 N 个；每通道独立凭据文件（C.2），坏一个不拖累其他；
- **分域路由**：`[domain.工作] channel=wecom`、`[domain.生活] channel=wechat`——不同事走不同门；
- **优先级与故障转移**：主通道超时自动落到次通道（消息不丢）；
- **静默时段**：每通道独立 quiet_hours（企微夜间免打扰、桌面通知常开，都行）；
- **通道即插件**：新增通道=一个 Python 文件（实现 send/receive 两个接口）+一个 ini——社区可自扩（B 站私信、Telegram 都有人做的话，装插件即可）。

## 17.4 维度三：感知自由（看什么，我说了算）

- **每源独立开关**：文件监视 / 屏幕截图 / 前台窗口 / 剪贴板 / 音频（M4）/ 日历 / 浏览器历史（M5）——逐个 bool；
- **范围三件套**：目录白名单（watch_dirs）+ 应用黑名单（screen_blacklist 窗口标题正则）+ 时段（工作 9-18 点才看屏幕，下班后失明，都行）；
- **强度分档**：每源 low/med/high（截图 600s/300s/120s；文件深度摘要/仅索引文件名）；
- **临时性失明**：全局快捷键一键"闭眼 30 分钟"（屏幕+剪贴板暂停，文件不暂停）——比整体暂停粒度更细；
- **感知源即插件**：新增感知源同通道插件机制（如"读我的 Git 提交记录"）。

## 17.5 维度四：自主性自由（它敢做多大主，我说了算）

第 15 章责任转移协议 L1-L3 的**用户侧控制面**：

- **全局自主上限**（`[autonomy] max_level=2`）：任何域的奇点判据再硬，也不能越过全局上限——用户握总闸；
- **每任务域独立 L0-L3**：`[domain.周报] autonomy=2`（预审后可发）、`[domain.合同] autonomy=0`（只建议）——风险偏好按域分配；
- **审批模式三选**：事前审批（默认）/ 事后报备 / 抽检 N%（老练用户降摩擦）；
- **外发白名单**：`approved_recipients`——L3 也只能发给名单内的对象；名单外一律回落 L1；
- **金额/频次护栏**：涉及付费 API、批量外发（>10 条/日）的动作单独设限。

## 17.6 维度五：记忆自由（记住什么、忘掉什么，我说了算）

- **记忆浏览器**：分层展示（原文/摘要/索引三层），支持查看、编辑、删除、**锁定**（锁定条目永不参与衰减与重写——重要事实钉死）；
- **分层保留策略**：原文 TTL（默认 30 天）/摘要 TTL（默认 1 年）/索引永久——每层独立可调，极端者可"只留索引不留原文"（最小footprint）；
- **遗忘权一键执行**：按关键词/按时间窗/按来源批量物理删除（含向量库与 FTS5 索引同步清除），删除即出审计日志——GDPR 式权利本地化；
- **画像参与范围**：`[memory] profile_domains`——指定哪些任务域的行为进入画像（工作进、生活不进，都行）；
- **导出**：记忆全量导出 Markdown（人可读）+ JSON（机可读）两种格式。

## 17.7 维度六：技能自由（用什么方法干活，我说了算）

- **纯文本技能**：SKILL.md 是 Markdown，无编译、无签名锁、无运行时校验——用户可改任何技能的任何一行（包括官方种子技）；
- **全生命周期控制**：安装/停用（不卸载，历史引用不坏）/改写（自动 fork 存本地私库，不改原件）/锁定版本（不受市场更新影响）/回滚（git 化版本历史）；
- **三源并存**：市场技 + 本地私库 + 完全离线自蒸馏——不连市场也全功能；
- **降权运行**：不想信任的技能可以 sandbox 最低权限跑（只读临时目录），跑坏了不伤系统。

## 17.8 维度七：数据自由（数据躺在哪、去哪，我说了算）

- **存储位置任意**：`[storage] data_dir` 指向本机任意路径/外置硬盘/NAS 挂载盘/VeraCrypt 加密卷——四库全是 SQLite 单文件，指向即搬家；
- **备份多目标轮转**：本地目录 / 外置盘 / 网盘同步目录 / WebDAV / S3 兼容对象存储——多目标+保留 N 份+备份前后自动校验（checksum）；
- **avatar.pai 开放标准**：资产包=zip（四库+配置+技能+记忆导出），JSON Schema 公开发布——任何第三方工具都能读，**用户资产永远有第二种打开方式**（对订阅制竞品的结构性反制，见 6.5）；
- **一键迁移**：新电脑装 PAI → 导入 avatar.pai → 五分钟内分身复活（含全部灵活性与技能）。

## 17.9 维度八：界面自由（用什么姿势用它，我说了算）

| 形态 | 适合 | 说明 |
|---|---|---|
| 系统托盘 | 普通用户 | 右键菜单：暂停/闭眼/打开面板/退出 |
| IM 即界面 | 极简用户 | **全部管理操作可在企微/飞书对话中完成**（"把周报域调成 L2""今晚别看我屏幕"）——对话式配置是灵活性最高的入口 |
| Web 面板 | 重度用户 | 127.0.0.1 本机回环+token 鉴权，仪表盘/记忆浏览器/技能管理/出境账单（16.6）全在 |
| CLI / headless | 极客与服务器 | `pai --headless` 无 UI 运行，CLI 全命令；跑在家用小主机/NUC 上当常驻分身 |

- 主题（亮/暗/跟随系统）与 i18n（zh-CN 首发，文案全外置 JSON，社区可翻译）。

## 17.10 维度九：调度自由（它多主动，我说了算）

- **主动强度滑块 0-5**：0=纯被动（只应答）/1=每日摘要/2=关键事件提醒（默认）/3=主动初稿/4=主动探索建议/5=激进探索（Ericsson 边缘练习全开）；
- **token 预算联动**：17.2 的月度预算可与强度联动（预算将尽自动降档而非停摆）；
- **时段策略**：工作时段保守（少打扰）/夜间激进（批量学习+蒸馏，恰是限流低峰，16.5.2）；
- **勿扰递进**：全局勿扰 > 通道勿扰 > 域勿扰三级，粒度递细。

## 17.11 维度十：扩展自由（它还能变成什么，我说了算）

- **MCP 一等公民**：任何 MCP server 可挂载为工具（与技能并列参与调度）——直接继承 MCP 生态的全部扩展面；
- **插件 API**：Python 入口点（通道插件/感知插件/导出器三类钩子），社区扩展不需改主程序；
- **本机 REST API**：`127.0.0.1:17861`（默认仅回环+token），全功能 API——**PAI 本身可被用户的其它自动化调用**（Quicker 动作、uTools 插件、Home Assistant、Excel 宏都能驱动分身）——PAI 不做围墙，做用户自动化宇宙里的一个节点；
- **Webhook 出口**：事件订阅（任务完成/奇点过线/审计事件推到用户指定的任何 URL）——被集成能力与集成能力对等。

## 17.12 灵活性的工程保障（不是许愿，是机制）

1. **热加载**：十维配置改完即生效（文件监视+原子替换），不重启、不断任务——热加载失败自动回滚上一个好配置并托盘告警；
2. **配置版本化**：config/ 整目录 git 化（本地仓库），每次变更自动 commit——配置可回滚，误改可救；
3. **冲突检测**：细粒度覆盖粗粒度时显式提示（域级模型覆盖全局时，面板标出"此域已被覆盖"），不静默；
4. **向导与手写双模式**：首启向导管 3 个必答项；其余全部 INI 直改+Web 面板改，两条路等价；
5. **校验兜底**：附录 C.4 校验器对十维新增字段全量校验（非法值中文报错拒绝启动/热加载拒绝替换）。

## 17.13 FlexBench：灵活性基准（自建，随附录 D 验收集发布）

## 17.14 小结

十维灵活性把"最大灵活性给到用户"从口号变成 300+ 配置项、四级模型路由、L0-L3 域级自主、四形态界面、开放资产标准与本机 API 的完整架构。它同时服务三个战略目标：①对用户——数据主权与选择权（对抗订阅制竞品的结构性差异，6.5）；②对生态——插件与 API 让社区扩展不需等官方（第 6 章飞轮的供油系统）；③对自身——配置即遥测（匿名统计"用户最常改什么"反哺默认值进化，默认值本身用采纳率数据迭代——第 15 章复利飞轮在配置层的延伸）。
