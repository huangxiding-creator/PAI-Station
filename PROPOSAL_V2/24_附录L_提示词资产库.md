# 附录 L 提示词资产库（prompts/ 目录规范与首批 12 条全文）

> 提示词=产品资产（E.5）：文件化、版本化、基准回归。此处收录首批 12 条核心提示词全文要点，开发时直接扩充成文件。

| 文件 | 用途 | 核心结构（system 要点） |
|---|---|---|
| summarize_v1.md | 文档摘要（L1→L2） | 角色：档案员。输出 JSON{summary≤200字, entities[], tags[], date_refs[]}。禁评论禁推断，只述事实。 |
| vision_screen_v1.md | 截图结构化 | 输出 JSON{app, window_title, text_summary, action_type, entities[]}；不确定性写 unknown 禁编造。 |
| extract_rules_v3.md | 蒸馏规则抽取（z1） | 输入：diff 修改块×N+任务上下文。规则形式"当<条件>时<动作>"，每条附频次证据；合并同型；输出 SKILL.md 规则段草稿。 |
| jtbd_score_v1.md | 主动动机打分 | 功能/情感/社会各 1-5 分+一句理由；紧迫度由时间窗口计算（代码侧），LLM 只出三分项。 |
| whys_v2.md | 5Whys 根因（z1） | 每层 Why 必须引用日志行号/audit id；最多 5 层；输出根因分类∈{数据,规则,技能,模型,通道}。 |
| profile_bigfive_v1.md | 画像打分（z1） | 每维度 1-5 分+证据链（引用 memory_id）；低于阈值输出"未知"。禁绝对化标签。 |
| quadrant_v1.md | 象限判定 | importance（对长期 JTBD 贡献）/urgency（窗口宽度）各 1-5；输出象限号+理由≤20字。 |
| outline_minto_v1.md | 金字塔大纲 | 先结论句；三层以内；同层 MECE 自检；每节标证据需求（哪些记忆待召回）。 |
| scqa_push_v1.md | 推送文案 | S-C-Q-A 四句式；总长≤80字；附出处与"是否需要我处理"问句。 |
| contract_scan_v2.md | 合同九区扫描 | 逐区输出{条款引用,风险级,修改建议,法律依据}；缺失项单列；长文自动分段。 |
| confirm_double_loop_v1.md | 双环审批卡片 | 变更前后对比+风险+回滚方案，≤120字，附"同意/拒绝"指令说明。 |
| skill_card_v1.md | 市场技能卡片 | name+一句话价值+采纳率+样本数+适用场景三条；禁夸张词（最好/第一）。 |

版本规则：语义化 v{n}；改提示词必跑关联基准（summarize→500 事实集；vision→200 标注集；extract_rules→蒸馏消融）；基准脚本输出对比表入 PR 描述。
