### E.2.1 限流工程五件套（V2.2 增补，全部对应官方《速率限制》建议）

来源：https://docs.bigmodel.cn/cn/api/rate-limit.md （2026-09-06 核实）——并发按账户权益等级分档；1302=账户触发限流；1305=平台过载；低峰期速率更高；通用 API 可申请提额（10 个工作日审核）。

1. **错峰调度**：夜间批量（蒸馏/索引/画像）排 00:00–08:00 低峰（官方明示低峰享更高速率）；
2. **全局队列+并发池**：感知/服务/夜间三路统一排队，杜绝瞬时洪峰；
3. **指数退避+抖动**：1302→退避并降并发；1305→拉大间隔重试（官方建议"避免立即高频重试"）；沿用 `_AdaptivePacer`；
4. **降级链**：文本 4.7-Flash→4.5-Flash→4-Flash-250414；视觉 4.6V-Flash→4V-Flash→本地 PaddleOCR；
5. **提额通道**：重度用户引导控制台申请速率调整或购 Coding Plan Lite——限流压力转化为 Pro 档付费动机（第 7 章闭环）。

## E.3 成本与额度核算（为什么免费可持续）
- 感知摘要：日均 1,440 截图×300 token + 200 文档×2,000 token ≈ 83 万 token/日（fast）；
- 蒸馏/画像：日均 50 万 token（deep，非每日）；
- 合计 ~2,500 万 token/月 < 免费额度（~3,000 万级/月），且重度用户溢出正是 Pro 档需求（7.3 节商业闭环）；
- **风险与对冲**（对应 R1）：适配器三行换端点；Pro 收入可覆盖付费通道（¥19/月 ≈ 智谱 GLM-4-Plus 数百万 token 成本，仍有毛利）。

## E.4 视觉通道专用约定
- 截图先本地预处理：黑名单区域检测→裁剪→缩至 1280 宽（省 token 且去除无关信息）→JPEG q=80；
- prompt 固定 schema：`{"app":"","window_title":"","visible_text_summary":"","action_type":"","entities":[]}`；
- 断网降级：PaddleOCR 本地识别 visible_text，事件降级标记 `vision_offline=true`。
