# 附录 O 贡献者指南与技能作者分成细则（生态契约全文）

## O.1 贡献者四赛道
1. **适配器赛道**：为组件生态新增适配器（19 件清单外的新开源件）。要求：实现 base 接口+验收锚点+README。署名进组件总表。
2. **通道赛道**：继承 Channel 四方法（5.6）。要求：断线重连测试+权限分级+文档。当前需求池：QQ 官方机器人、Telegram、Slack。
3. **技能赛道**：蒸馏真实技能并上架。要求：三联证据包+采纳率标注+隐私分级声明。
4. **安全赛道**：威胁样本（坏技能/逃逸用例）、渗透报告。奖励：安全致谢榜+市场信用分。

## O.2 技能市场契约（作者版）
- **定价权**：作者自主 0-99 元；平台抽成 15%（种子作者首年免佣）；
- **结算**：月度自动打款（微信/支付宝），满 ¥100 起结；
- **退款**：买家 7 天内可退；仲裁依据=技能标注的采纳率与买家实测初稿采纳率偏差（Kano 判据，7.2 节）；恶意退款（下载即退）风控拦截；
- **下架**：投诉成立/scanner 新规则追溯命中/连续两月采纳率 <30% 且差评 >20%——下架不删库（买家已购可继续用）；
- **原创保护**：技能文本相似度检测（SimHash>0.85 判重复）拒绝抢注；举报通道 48h 响应。

## O.3 市场信用分体系
作者信用分 0-100：初始 70；上架过审+2；好评+1；差评-2；退款率 >10% 每月 -5；scanner 追溯违规 -30；安全贡献 +10。低于 50 禁止上新。买家侧同样有信用（恶意退款影响仲裁权重）。

## O.4 法律与合规边界（写在契约里）
- 技能不得包含：破解/外挂/批量营销骚扰/个人信息采集类功能（scanner 关键词+人工双审）；
- 数据授权：技能执行中接触的用户数据归用户，作者对技能运行结果无任何权利主张；
- 免责：技能输出为初稿建议，重大决策（法律/医疗/财务）用户自负审核责任——技能描述页强制展示。

## O.5 社区治理
季度公开治理报告（上/下架数、退款率、申诉处理时效）；治理规则变更走 RFC（社区提案→7 天公示→生效）。**生态契约的可信度就是市场的地基**——契约本身也是产品。
