## I.2 渠道打法与预期（数字可核对）
- Product Hunt：openhuman 路径验证（其获 #1 周榜）；我们主打 China-first 差异点；
- 知乎/V2EX/掘金：技术长文导流（转化率行业均值 3-8% 安装）；
- 即刻/小红书：职场效率人群（周报/公文技能切中公务员与白领痛点）；
- B 站/抖音：3 分钟实机演示（主动服务最直观）；
- GitHub trending：README 对比表+一键安装是转化关键；
- 预期漏斗：首月曝光 50 万 → GitHub 访问 5 万 → 安装 5,000（10%）→ 周活 2,500（50%）。

## I.3 社区运营 SOP
- issue 分诊 SLA：24h 响应；bug/feature/discussion 三标签；
- 贡献者阶梯：装了用→提 issue→交 PR（适配器/技能/通道三赛道）→committer（季度评审）；
- 技能作者社群：种子 100 人微信群，月度采纳率榜单+现金奖；
- 危机预案：安全事件走 F.4 SOP；负面舆情 2h 内技术回应（用 audit 数据说话）。

## I.4 指标看板（每周一晨会读数）
北极星：周活分身产生的工作小时节省数（= Σ采纳成果×人工耗时估计）。
辅助：安装→首周留存（>60%）、技能市场供需比、Pro 转化、NPS（季度）、CAC（渠道分摊）。
反指标（越小越好）：打扰拒绝率、崩溃率、隐私投诉数（目标零）。
