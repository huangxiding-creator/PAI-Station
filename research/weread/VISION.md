# Phase 0 · 愿景：微信读书智库渠道

> Super-Skill V4.1.9 十四阶段产物 · 2026-09-10 · 对应提案第 19 章"四源蒸馏"之**源①电子书**

## 一句话愿景

**任意关键词 → 整本结构化知识 → 专业排版 Word/MD**，一条命令完成；
浏览器只负责一次扫码登录，其余全部走逆向 API——快、稳、可断点续采。

## AI-Native 定位（C2：大胆合法）

| 维度 | 现状（手工） | 愿景（本渠道） |
|------|------------|--------------|
| 获取 | 手动翻页复制，格式丢失 | 关键词搜索→整书 JSON 原料+MD+DOCX |
| 效率 | 一本书数小时 | 一条命令，断点续采，睡觉时跑 |
| 质量 | 无结构 | 章节树/元数据/图片完整保留，直接喂 GLM 挖掘 |
| 复用 | 一次性 | 原料湖 `data/weread/{书名}/`，接 hundun_mine 同款挖掘管线 |

## 三层架构愿景（对齐 RE-Factory 演进范式）

```
L1 登录层（浏览器，仅此一层用浏览器）
   DrissionPage 可见窗口 → 用户扫码 → cookie 提取
   → 双层持久化: data/browser_profile/ + data/weread/_auth/weread_auth.json
   → 自动续期（wr_skey 30 天，HEAD 首页收 Set-Cookie）
L2 提取层（纯 API，逆向工程核心价值）
   搜索 /web/book/search ─┐
   详情 /web/book/info    ├─ 纯 urllib 直连（cookie 认证，无签名）
   目录 chapterInfos     ─┘
   正文 /web/book/chapter/e_0..e_3 / t_0..t_1（签名+混淆，算法已开源还原）
   → weread_sign.py（签名移植）+ 解混淆 + HTML→MD
L3 导出层（专业排版）
   book.json（原料）+ {书名}.md（人读）+ {书名}.docx（专业排版：封面/目录/标题层级/中文字体/图片）
```

## 第一约束：账号安全（宪法 R8 红线）

一切设计以**不被封号**为前提：
- 行为自律而非技术对抗——人类化节奏（随机间隔）、日提取限额、单书冷却
- 只走 web 端合法阅读流量形态（笔记同步类项目封号报告最少；整书批量下载/刷时长是风控靶心，**坚决不做**）
- 异常响应立即熔断停机，宁可中断不可冒险
- 提取范围限于账号**已可阅读**的内容（会员/无限卡在线读权限内），不碰安卓 chapterdownload 下载路线
