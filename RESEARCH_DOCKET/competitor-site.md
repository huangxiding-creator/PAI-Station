# 频道：竞品与对标产品（商业 + 开源）

## 框架级竞品
| 竞品 | Stars | 形态 | 对 PAI-Station 的启示 |
|------|-------|------|----------------------|
| OpenClaw | 388,933 | TypeScript 本地网关 + Web 控制台 | 基线。优势：24+ IM、skills、调度、MIT。短板：面向极客（需自建服务器/VPS 心智）、中国 IM 非一等公民、无本地感知（屏幕/文件/语音）、无中文场景技能、模型默认走付费 API |
| Open Interpreter | 68,243 | 桌面/终端代码执行代理 | 桌面 agent 交互范式可借鉴 |
| Letta/MemGPT | ~20k | 记忆型 agent 运行时 | 分层记忆（core/archival/recall）设计 |
| GoPlus? | - | - | - |

## 感知级竞品
| 竞品 | 定位 | 差距 |
|------|------|------|
| screenpipe | 24/7 屏幕+音频捕获→AI 记忆（YC S26） | 只做感知，无任务执行、无中国 IM、无技能市场 |
| Rewind.ai（商业） | 商业化屏幕记忆 | 闭源、订阅制、无 agent 能力 |
| Microsoft Recall | Windows 原生屏幕记忆 | 仅快照检索，无主动服务 |
| Windrecorder / OpenRecall | 开源 Rewind 替代 | 同 screenpipe，单点能力 |

## 办公套件竞品（用户点名对标）
| 竞品 | 短板（PAI-Station 的 100× 空间） |
|------|------|
| 飞书工作 | 绑定飞书生态；不理解个人全盘上下文；无自我学习能力；企业付费墙 |
| 腾讯 WorkBuddy | 同上，钉钉/企微生态内单点助手 |
| 钉钉 AI 助理 | 通用问答为主，不蒸馏个人技能，不读本地文件 |
| Manus/CUA 类 | 云端沙箱，无本地上下文，按次收费贵 |

## 核心判断
没有任何一个产品同时具备：本地全盘感知 + 中国四通道 IM + 零成本模型 + 个人技能蒸馏 + JTBD 主动服务 + 满意度计费。五者交集是空白市场（详见 GAP_REPORT.md）。
