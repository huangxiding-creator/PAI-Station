# V4 愿景百倍重铸 · 调研计划

## 用户指令（2026-09-13，原话要点）

> 我觉得当前项目的愿景、开发方法框架、商业价值实现、生态构建，都还不是最顶级的。
> 把当前项目当作很初步的想法，通过调研 GitHub 及网络，调研至少 100 个类似项目，
> 提出比当前想法好 100 倍的顶级想法，并提出实现这个想法的思路和方法。

## 定位

- **当前 V3 = 基线**：比腾讯 WorkBuddy 好 100 倍的个人 AI 工作站（24/7 常驻 Windows
  笔记本：感知→任务发现→确认→自主执行→交付→进化；技能资产化 git 仓库+市场）。
  871 tests / coverage 89% / lint 0 / cleanroom 过。
- **本轮目标 = 四维重铸**：愿景格局 / 开发方法论 / 商业价值 / 生态构建，
  每一维都以"世界顶级的做法是什么"为标尺，产出比当前构思好 100 倍的 V4 愿景
  + 可落地实现路线（不是科幻，是可证伪的差量）。

## 硬指标与纪律

1. 新增 ≥100 个真实 URL 项目（8 路 × 目标 20，下限 15/路 → 合计 ≥120）。
2. **C14 不编造**：每个条目必须有可访问的真实 URL；查不到元数据就标 null，不猜。
3. 本项目目录之外只读；只写各自 track 目录。
4. 工具降级链：gh CLI → curl 经代理 7890 访问 api.github.com → WebSearch/WebFetch。
   全部不可用则如实记录"本轮网络降级"，不许用编造凑数。
5. 每路产出：`_all.json`（结构化）+ `DIGEST.md`（人读摘要 + **对百倍升级的信号**一节）。
