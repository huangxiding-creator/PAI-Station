# GAP_REPORT — 四维对照：世界顶级做法 vs 当前 V3

- 生成：2026-09-13 · 证据全部来自八路 DIGEST（条目编号可溯源到各 `_all.json`）
- 差量编号 G1-G22，供 VISION_V4 / PROPOSAL_V4 引用。

## 维度一：愿景（Vision）

### G1 · 意图层与主权层缺失
- **顶级**：个人 agent 的常驻资产（意图/记忆/技能/声誉）应有唯一法定持有层，
  跨 agent 可携带（ai-memory、engrim、Second-Me 15.7k★、Sovereign Reflections）。
  912 个记忆引擎过剩，主权协议空位。
- **V3**：画像五层+语料库是 PAI-Station 私有格式；换 agent 即归零；
  无导入/导出/审计/遗忘协议。
- **差量**：V3 拥有「引擎」，未拥有「主权」。资产是产品的，不是用户的。

### G2 · 认知健康维度不存在
- **顶级**：MIT 脑电认知债务 + MSR 批判性思维迁移 + 12 个月纵向陪伴危害 +
  Enrichment Paradox 相变模型（委托过阈值→能力衰减不可逆）。
  「增强用户」已是顶级实验室共同底线，且已可计算（认知资产负债表、信息贸易顺差）。
- **V3**：KPI 是任务产出与省时；「替用户做得越多越好」与认知债务完全同向。
- **差量**：V3 在科学上站错了边——做得越多可能让用户越弱，且无任何度量。

### G3 · 网络身份与代理交涉缺失
- **顶级**：LLM-X（个人 agent 交易所，agent 替用户谈判）、Project Sid/AgentSociety
  （agent 社会可实验）、Virtuals（agent 雇 agent 的劳务市场）。
  终局环境不是你的电脑，是千万 agent 共存的世界。
- **V3**：单机工具。无对外身份，无代理交涉，agent 间无协议。
- **差量**：V3 是孤岛；V4 需要作为「个人主权网络节点」存在。

### G4 · 遗产模式与可继承性缺失
- **顶级**：Moxie 破产上万儿童告别「朋友」；Dot 被收购即数据死。
  「公司死了 AI 还活着」（本地最小功能集+全量导出）已成设计约束；
  「数字自我可继承」是愿景级差异点。
- **V3**：无任何遗产/导出承诺；项目死亡=用户资产死亡。
- **差量**：缺整个维度。

### G5 · Windows 单机 agent 控制面——空位而非缺失（机会）
- **顶级**：agent 是新 workload，但单机控制面（本机应用 API 网关、审批密码学、
  断点续跑原语、资源账本）无人占位（02 路 10 信号之一；ECC 257k★ 证明
  harness OS 形态有海量需求，但它是跨平台通用层，不是 Windows 本机深耕）。
- **V3**：已有看护器/断点续跑/降级矩阵雏形——距占位只差升维整合。
- **差量**：这是 V3 已有资产离「世界第一个」最近的赛道，未成型。

## 维度二：开发方法论（Methodology）

### G6 · 无宪法层、闸门固定不分级
- **顶级**：spec-kit constitution（所有 spec 先过全局不变式）+ BMAD
  「process sizes itself to work」（小改直通/大改深走）+ Willison 三档判据。
  闸门是**带风险权重的路由器**。
- **V3**：单一提案审批闸，任何变更同等仪式——小改被摩擦、大改不够深。
- **差量**：缺宪法层与分级路由。

### G7 · 上下文无预算管理
- **顶级**：GSD fresh-context 子代理波次（每 executor 干净 200k）、HumanLayer
  回压/forking、Anthropic compaction+结构化笔记。复盘质量受 context rot 支配。
- **V3**：Ralph 复盘无 token 预算表，长会话必然衰减。
- **差量**：每条工作线缺 token 预算与超限策略。

### G8 · 有入口闸、无出口闸
- **顶级**：Taskmaster stop-hook 完成度守卫：evidence over narrative（禁总结式停机）、
  机器可查完成条件、确定性 done token、同会话恢复+目标重锚定。
- **V3**：任务以「汇报完成」收尾，无机器判据终点协议——AI 自称完成即完成。
- **差量**：无人值守的终点必须是机器判据，V3 完全空白。

### G9 · 闸门不随能力曲线调整
- **顶级**：METR 实证 agent 可完成任务时长每 7 个月翻倍——静态流程一年后退化为
  纯摩擦；人审节点应做成随能力指数增长自动调松紧的旋钮。
- **V3**：人审节点写死，无自动后退机制。
- **差量**：缺「闸门松紧=能力函数」机制。

### G10 · 多线交接传摘要不传全轨迹
- **顶级**：Cognition 三原则：共享全轨迹、动作携带隐式决策、优先单线程线性；
  Conductor 以过程时间线为人审对象。线间只传摘要=分布式系统经典坑。
- **V3**：三线复盘以摘要/台账交接。
- **差量**：隐式决策传染未设防。

### G11 · 工具面为人设计，非 agent 专用（ACI 缺失）
- **顶级**：SWE-agent（NeurIPS）证明为 agent 专门设计的带防护精简接口
  （失败即回滚、防误编辑）显著优于复用人类工具；MetaGPT 证明中间工件 schema 化交接。
- **V3**：工具面沿用人类习惯的 CLI/文件接口。
- **差量**：缺 agent 专用工具层（防护型 ACI）。

### G12 · 进化是周级仪式，验证资产未复利
- **顶级**：Learning While Acting（测试期共同演化，进化周期从按周到按任务）+
  MERIT（按行动贡献/成本给记忆计价）+ promptfoo（行为 eval 进 CI）。
  70% 定律：价值全在后 30% 验证资产。
- **V3**：进化复盘周级；金标准 40 条是静态资产，不随任务增长、不对外定价。
- **差量**：进化无代谢；验证资产无复利机制。

## 维度三：商业价值（Business）

### G13 · 定价单位停在订阅/抽成想象
- **顶级**：定价单位决定定价权——Intercom $0.99/resolution 进主流价目表、
  Sierra「Pay for a job well done」、uxtigers 万亿人力服务预算 TAM、
  Klarna 700 全职等价。个人工作站的天然单位是「替你完成的小时数」。
- **V3**：商业设想=市场抽成+未定义的订阅。
- **差量**：无可验证结果的度量，就没有结果定价权（前提回扣 G8/G12）。

### G14 · 无结算轨道
- **顶级**：x402 零协议费、月 75M 笔；「给 MCP 工具按调用收费」是一行中间件；
  Shopify 证明 billing 内建是插件经济规模化前提；钱轮是飞轮缺环。
- **V3**：无任何计量/结算轨道设计（v0.2+ 后置项）。
- **差量**：技能无法直接赚钱→收入即质量信号的回路不存在。

### G15 · 数据路线未定义（卖什么、锁什么）
- **顶级**：正（Vana BYOD 进 LF、Surge 数据货架化）反（23andMe 贱卖、Mercor 4TB
  泄露）对照收敛：原料锁本地、卖加工品（技能/结果），本地优先=商业模式。
- **V3**：语料/画像留在本地是工程巧合，不是商业主张。
- **差量**：缺「锁原料、卖加工品」的显式商业设计。

### G16 · 无治理结构与信任护城河
- **顶级**：Ghost 章程级「不可收购」、Bitwarden $10/年证明个人隐私层可行
  （但其社区信任损耗 715 分长文示警）；open-core 2.0=核心全开+托管付费+治理章程。
- **V3**：无治理章程、无「永不卖用户」承诺、无托管层设计。
- **差量**：隐私型个人产品最强的获客杠杆（可验证的承诺）缺失。

### G17 · 上游挤压下的生态位未选
- **顶级**：Anthropic $65B 年化亲自下场应用层、OpenAI 佣金+广告双引擎——
  技能市场必须选上游不愿做的长尾（本地化/隐私/跨端/中文生态）。
- **V3**：通用技能市场设想，与巨头正面。
- **差量**：生态位未定义。

## 维度四：生态构建（Ecosystem）

### G18 · zip+meta.yaml 分发已过时
- **顶级**：分发协议化杀死 zip——Claude Code 市场协议（git 托管清单+5 种 source+
  版本化缓存+依赖白名单）与 MCP metaregistry（发布一次处处引用）。
- **V3**：zip 交换格式。
- **差量**：发布≠push、更新≠pull、安装≠add——全缺。

### G19 · 升格闸门人工化、声誉靠好评
- **顶级**：机器可验证四层：签名+来源证明（ToolHive/mcpb）→沙箱运行时→
  自动化评测（MCPBench）→策略引擎（OPA）；排名消费**交易衍生数据**
  （付费调用次数、履约记录，ERC-8183 式结算写回声誉）而非下载量。
- **V3**：「用户用出好技能→人工升格入库」。
- **差量**：无签名、无沙箱背书、无 eval 证明、无交易声誉。

### G20 · 发布端有摩擦、淘汰端无数据
- **顶级**：冷启动=协议开放+锚点供给+零审批（Anthropic 只发协议社区市场数周涌现；
  Shopify agent 零审批自助注册）；闸门后置到消费端（安装/付费/评测数据淘汰）。
- **V3**：双层飞轮的升格闸在供给端。
- **差量**：闸门位置放错边。

### G21 · 第四个孤岛标准（应为适配器）
- **顶级**：技能标准被 OS 厂商瓜分（华为鸿蒙智能体框架、Anthropic skills 176k★、
  OpenClaw）；08 路明确：应做「跨标准适配器」而非第四个孤岛标准。
- **V3**：自有技能格式，单向。
- **差量**：无适配器层。

### G22 · 分发形态单一
- **顶级**：agents.md（24.3k★，repo 声明式）、WebMCP（Chrome 149 origin trial，
  网页即工具零安装）、云渠道（AgentCore/魔搭）、IM 侧挂（AstrBot 40.4k★，
  中国分发正解）。
- **V3**：仅本地安装包。
- **差量**：技能非多形态；中国分发第一站（IM 侧挂）未规划。
