## 〇、一句话愿景

> **V3 卖工具（替你干活的工作站）；V4 卖主权——你的意图、记忆、技能、声誉、
> 钱包的唯一法定持有层，我保证你变强（可计算），并替你在 agent 经济里谈判、
> 交易、赚钱。**

三个升维：
1. 从「更好的 WorkBuddy」→ **世界第一个个人主权层产品**（912 个引擎世界里的协议位）
2. 从「替用户做得越多越好」→ **第一个以用户认知健康为 KPI 的常驻 agent**
3. 从「单机工具」→ **agent 经济中的个人主权节点**（本地清算所+代理交涉）

【混沌方法论】**第二曲线**：V3 工作站是第一曲线（工具效率），在它被框架平权
（OpenManus 6 万星证明能力天级复制）吞噬之前，启动第二曲线（主权+验证资产+
网络）——第二曲线的资源恰恰是第一曲线的资产（见 PROPOSAL_V4 复用清单）。
**升维**：竞争维度从「功能/速度」（巨头主场）升到「主权/信任/认知复利」
（无人主场）。

## 一、五支柱（P0-P4）

### P0 · 主权资产层（Sovereign Asset Layer）〔G1/G4〕

**主张**：PAI-Station 拥有的不是第 913 个记忆引擎，而是用户数字资产的法定持有层：
意图队列、记忆库（markdown 为源，含**决策记忆**——含被否决的备选方案）、
技能账本、画像（可导出/审计/证伪/遗忘）、声誉档案。配**遗产模式**：
公司死了 AI 还活着（本地最小功能集+一键全量导出+可继承）。

**证据基**：912 记忆系统目录 vs 主权协议空位（T1）；Moxie/Dot/HuggingChat 尸检
（壳死资产活）；23andMe 反面（锁原料）；Second-Me 15.7k★ 验证叙事需求；
Hidden User Models（影子档案不可审计=反面教材）。

- **10× 判据（可验收）**：用户切换到 Claude Code / OpenClaw / AstrBot 任一 agent，
  资产 100% 可携带、导入即用（V3 现状：0%）；遗忘权经 Temvera 式双时态审计可验证。
- **100× 判据（可证伪）**：主权导入/导出/审计/遗忘协议被 **≥3 个第三方 agent
  原生实现**——从产品变成生态事实标准；届时每个竞品死亡都是获客事件。

【混沌方法论】**第一性原理**：把世界推到极端——所有模型厂/agent 厂死亡后，
用户还剩什么？只剩本地资产与对其的主权；因此唯一必然存活的生意是持有层。
**逆向思维**：912 家做引擎，我做协议。**反脆弱**：遗产模式+可携带性让
「厂商死亡」从风险变成增长事件（每次 Moxie 式惨案都是主权的广告）。

### P1 · 机器控制面（Agent Control Plane on Windows）〔G5/G8/G11〕

**主张**：agent 是新 workload，每个 workload 终将获得自己的控制面——PAI-Station
成为这台 Windows 机器的 agent 控制面：本机应用 API 网关（无头自动化统一入口）、
**审批密码学**（高风险动作生成签名授权日志，AP2 Verifiable Intent 同构）、
**风控式信任**（限额/白名单/异常检测/可回滚，取代一次性权限弹窗）、
断点续跑原语、资源账本（token/时长/钱）、**出口闸**（机器判据 done token，
禁总结式停机）。

**证据基**：Windows 本机应用 API 网关无人占位（02 路）；ECC 257k★ 证明 harness
OS 形态需求量级；Rokid×支付宝看一眼支付=风控范式本土验证；Rabbit 尸检
（不可审计的魔法=信任破产）；Taskmaster 出口闸四件套；SWE-agent ACI。

- **10× 判据**：无人值守连续运行 7 天，全程密码学可审计回放，
  策略强制下不可逆损失为零；每条任务以 done token 收口（CI 可解析）。
- **100× 判据**：控制面被第三方 harness 复用（其他 agent 经 PAI-Station 调度
  本机资源/过审批闸）——从应用变成 Windows agent 层基础设施。

【混沌方法论】**组合创新**：把支付行业的风控（限额/异常检测）、AP2 的
Verifiable Intent（授权防篡改）、支付清算的对账（资源账本）三个跨域成熟件
缝合到「本机 agent 权限」这个新问题——三件各自 20 年成熟度，缝合处无人做。
**第一性原理**：workload（云上）→控制面（Kubernetes）的映射在本机侧缺失，
先占位者得标准。

### P2 · 反退化引擎（Anti-Enfeeblement Engine）〔G2〕

**主张**：第一个以**用户认知健康为 KPI** 的常驻 agent。内建：委托预算
（每类任务的委托度上限）、能力保留集（哪些任务强制保留人类执行/复审）、
认知资产负债表（未验证推理义务的存量，随任务实时记账）、验证成本最小化
（把「验证 AI 产出」的成本压到低于「自己做」的认知门槛之下）、
信息贸易顺差仪表盘。对外承诺：「用我，你变强」——可计算、可验证、可退费。

**变强的三条可验证路径（2026-09-13 用户定义，产品化核心）**：
1. **经验沉淀**：通过用户全面上下文的理解/分析/归纳，把**没有总结的经验、
   没有沉淀的技能**显性化为主权资产（记忆库+决策记忆+技能账本）——
   隐性经验显性化，用户第一次「拥有」自己的方法论。
2. **专家交付**：普通工作者在其任务领域远非最厉害的专家——基于任务匹配
   领域专家级技能，让**每个任务都达到专家级成果质量**（普通人获得
   专家级交付能力）。
3. **前后对比**：每次赋能保留「原成果 vs 赋能后成果」的**对照证据**——
   变强不是口号是 diff；用户看到质量跃升才会接受该技能（采纳的证据链）。

**证据基**：MIT 脑电认知债务+MSR 批判性思维+12 个月纵向陪伴（三重独立证据链）；
Enrichment Paradox 相变模型（委托过阈值→能力衰减不可逆）→ 委托预算的数学依据；
Cognitive Debt 形式理论（可记账）；MSR 结论「核心技能从做迁移到验证」→
验证成本最小化的直接出处。

- **10× 判据**：每个委托任务产出「委托度×能力保留」双记录；用户可查看自己的
  能力曲线与认知负债表；高危委托（相变阈值附近）触发主动降委托建议。
- **100× 判据**：信息贸易顺差为正且经第三方可审计——行业第一份**人机共生
  收支表**；「反成瘾/反退化」从功能变成品类定义（提到「让我变强的 AI」
  即提到 PAI-Station）。

【混沌方法论】**逆向思维**：全行业（含 CharacterAI 纵向证据链的对立面）优化
engagement/替代率，我优化**人的能力保留率**——对手的 KPI 恰是我的反 KPI，
不可被巨头模仿（模仿=否定其商业模式）。**升维**：把「好不好用」升维为
「认知会计」——功能竞争变会计准则竞争。**第一性原理**：个人 AI 的终极价值
是人的复利而非机器的产出——机器产出边际成本趋零（70% 定律），人的能力
不趋零。

### P3 · 主权网络节点（Sovereign Node in Agent Economy）〔G3/G14〕

**主张**：用户的 agent 携带主权身份进入 agent 经济：内建 x402/ACP/MPP 客户端，
技能互相调用按次微结算、向外购数据/算力按量付费、**卖出加工品（技能/结果）
锁死原料（用户数据）**；签名 skill card（作者身份锚定 Web Bot Auth 类标准）；
agent 间代理交涉（LLM-X 方向：日程谈判、经验交换）。工作站=**个人侧清算所**。

**证据基**：x402 月 75.41M 笔/零协议费；UCP 进 Google 全家桶；支付宝 AI Pay
单周 1.2 亿笔（全球最大实证）；ERC-8183 结算写回声誉；Virtuals agent 雇 agent
劳务市场；A2A v1.0 签名 card。

- **10× 判据**：任一技能从发布到收到第一笔微付费 ≤1 天（结算+验收+复购闭环）；
  技能间调用自动计量结算（哪怕金额为零）。
- **100× 判据**：普通用户技能组合的被动收入 ≥ 其订阅费——**商业模式倒转**
  （用户不付钱给平台，平台帮用户赚钱）；声誉从交易衍生（付费次数/履约记录），
  零人工评分。

【混沌方法论】**升维**：从「商店」（抽成层）升维为「清算所」（记账+钱包层）——
x402 零协议费正在降维打击抽成层，抽成是死路，记账/托管/增值是活路。
**组合创新**：x402（微支付）×技能市场（供给）×ERC-8183（声誉写回）×
ACP（购买流程）四件缝合为「个人侧结算栈」。**第二曲线**：V3 市场设想的
「抽成」是第一曲线思维；清算所+被动收入网络是第二曲线。

### P4 · 验证资产复利（Verification Asset Compounding）〔G12/G8/G13〕

**主张**：金标准/evals/记忆自检随**每个任务**自动增长并进 CI：记忆四能力自检
（MemoryAgentBench：准确检索/测试时学习/长程理解/**冲突消解**）+ 结构回归
（StructMemEval）+ 遗忘合规（Temvera）；机器判据出口闸（P1）；**任务级进化**
（任务结束即技能变异候选，下次同类任务即验证——Learning While Acting 代谢制）。
验证资产对外=定价权：**谁定义「done」，谁拥有市场的定价单位**。

**证据基**：70% 定律（价值全在后 30%）；promptfoo（eval 进 CI 被双 O 采用）；
Qodo Cover 反面（测试长出来≠有用，金标准质量才是关键）；Vibe Kanban 日落
（编排壳无护城河）；MERIT（记忆按行动贡献计价）；Intercom/Sierra（结果计费
前提=结果可机器验证——本支柱即那个「可验证」）。

- **10× 判据**：进化周期从周级压到任务级；金标准条目随任务线性增长
  （40 → 500+，每条带 origin 任务溯源）；记忆冲突消解回归全绿。
- **100× 判据**：「替你完成的小时数」由本系统验证资产背书成为对外报价单位——
  验证层成为市场基础设施（其他 agent 用 PAI 判据定义自己的 done）。

【混沌方法论】**第一性原理**：生成边际成本趋零后，经济里唯一稀缺的是
**验证**（信任）——把公司全部押在稀缺侧。**组合创新**：学术评测基准
（2026 论文群）×CI 工程实践×进化环×定价单位，四个域的现有件缝合为
「验证资产流水线」。**耗散结构（代谢观）**：每次任务完成=摄入能量→
排出负熵（金标准/技能/画像增量）——系统复杂度不升反降地变强。
