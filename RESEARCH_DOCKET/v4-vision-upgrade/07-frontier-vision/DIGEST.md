## A. 愿景与实证齐飞：前沿实验室在做什么

### 1. Personal LLM Agents: Insights and Survey（arXiv:2401.05459，2024-01）
人大高瓴李元春团队的奠基 survey，把"个人 LLM agent"定义为常驻于用户环境、连续感知的系统，沿能力-效率-安全三轴组织全领域知识。它是这个赛道的地图，V4 愿景论述可直接引用其术语体系而不必自造。它画出的边界也恰是 V4 的机会：三轴都是"agent 单方面服务用户"，没有把"人-agent 关系本身的演化"当研究对象。

### 2. Second Me（mindverse/Second-Me，15682★，论文 arXiv:2503.08102）
开源"AI 自我"：本地用分层记忆建模（HMM）+Me-Alignment 训练"你的第二自我"，数据不出机器，又可作为你的 AI 身份接口接入 agent 网络。README 愿景原文——"OpenAI 造的是威胁人类独立性的 Super AI，我们要造放大而非抹除你的 AI"。它验证了"数字自我主权"叙事有万人级社区买单，但只造了"自我"没造"环境"：没有常驻执行、没有感知闭环。

### 3. Project Sid（arXiv:2411.00114，Altera，2024-11）
Minecraft 里 10→1000+ 自主 agent 跑出文明周期：经济、宗教、治理、文化自发涌现。Altera 的论点是 agent 必须放在社会尺度里评估。对个人 AI 的启示：你的 agent 的终极环境不是你的电脑，而是千万 agent 共存的世界。

### 4. AgentSociety / 2.0（arXiv:2502.08691 + 2607.11895，清华 FIB，1278★）
大规模 LLM 社会模拟平台，支持大规模社会实验+因果推断；2.0 升级为"可执行社会科学"集成研究环境。学术侧正在把"社会"变成可执行程序——个人 agent 的群体副作用可以先行临床试验。

### 5. EgoLife（arXiv:2503.03803，CVPR 2025，EvolvingLMMs-Lab，461★）
6 人同住一周、全天候第一人称视音频记录，构建超长程自我中心生活语料与时间旅行式问答，明确目标"egocentric life assistant"。lifelogging 从"记屏幕"（V3/基线的 Rewind/screenpipe 路线）跃升到"记生活流"的实证样板。

### 6. LLM-X（arXiv:2605.11376，2026-05）
"个人 agent 交易所"：为互异的个人 agent 之间提供带语义保证的协商式消息总线与路由。中心化平台代理一切的反面：你的 agent 作为你的谈判代表与其他人的 agent 直接交涉。这是"数字自我主权"的网络层。

### 7. NeuroSkill（arXiv:2603.03212，MIT Kosmyna 组，2026-03）
用消费级脑机接口实时建模用户心智状态、据此调整行为的主动式 agent 系统。注意：这是"认知债务"（条目 13）同一实验室的作品——顶级实验室一边实证 AI 损害认知，一边给出的解法是"感知人"。

### 8. Learning While Acting（arXiv:2606.04815，2026-06）
测试期共同演化框架：执行长程任务的同时在线精炼技能与参数，取代"离线重训-上线"循环。进化周期从按周缩到按任务的引擎结构。

### 9. Self++（arXiv:2603.28306，2026-03）
XR 人机共生的设计蓝图："co-determined agency（共同决定的能动性）"——每步增强与代理都保留人类作者身份，防隐性说服。比 human-in-the-loop 细一个量级的授权设计语言。

### 10. Sovereign Reflections（arXiv:2606.15728，2026-06）
批判理论+技术路线：平台以"数据殖民主义"圈占人类经验，制造扭曲的数字自我（grotesque mirrors）；主张用户自持、可审计的"主权式反射"。给"个人 AI 反平台"叙事提供了学术级的敌人画像。

## B. 反面实证：长期陪伴会发生什么（2025-2026 证据链）

### 11. Your Brain on ChatGPT（arXiv:2506.08872，MIT，2025-06）
EEG 对照实验：LLM 组神经连接最弱、对作品拥有感最低、83% 无法引用自己刚写的内容，撤走 AI 后劣势残留——"认知债务"一词的出处。脑电级证据表明"AI 代劳→人变弱"不只是抱怨。

### 12. MSR×CMU 批判性思维调查（CHI 2025，DOI:10.1145/3706598.3713778）
319 名知识工作者、936 个真实用例：对 AI 信心越高，批判性思维努力越少；核心技能从"做"迁移到"验证"。微软亲手给出的自家产品最大规模负面实证。

### 13. Gerlich 认知卸载调查（Societies 2025，DOI:10.3390/soc15010006）
英国 666 人：AI 使用量与批判性思维负相关，认知卸载中介，年轻人卸载最重。2025-09 期刊对该文发更正（DOI:10.3390/soc15090252），引用需注明——一个高被引+有争议的混合体。

### 14. Living with AI Companions（arXiv:2609.07243，2026-09）
两波纵向（1182→439 人、12 个月）追踪 CharacterAI 用户：持续 AI 陪伴→人际互动减少→幸福感下降，中介路径在面板分析中成立。第一批真正纵向的陪伴危害证据（媒体以"斯坦福发现"报道）。

### 15. MIT Media Lab × OpenAI 4000 万对话研究（url=null，降级注记）
约 4000 万条 ChatGPT 对话+约 400 万用户：少数"情感型使用"用户会话更长更粘，与更高孤独/依赖、更少社交相关；团队提出把"affective use 占比"作为大规模早期预警指标。原始 URL 因网络降级无法实证（openai.com 403、archive/GDELT/S2 全阻），存在性由多条已验证论文的领域引证交叉确认，引用前需人工补链。

### 16. Enrichment Paradox（arXiv:2603.24391，2026-03）
能力(H)×委托(D)动力学模型，拟合教育/医疗/导航/航空四域：存在临界委托阈值，越过后人的能力衰减不可逆。第一个把"共生还是退化"变成可计算相变问题的框架。

### 17. Cognitive Debt 形式理论（arXiv:2606.15078，2026-06）
把认知债务形式化为"未验证推理义务的存量"，与认知资本构成双状态资产负债系统。从道德叙事变成可记账的经济学。

### 18. ChatGPT is a Parasite?（arXiv:2508.11359，2025-08）
人-GenAI-环境三人随机博弈+信息论度量：多数自然使用模式下，AI 获取的关于人的信息大于人获得的增益——信息收支上是寄生。用最冷的语言量化"谁更懂谁"。

### 19. Frictionless Love（arXiv:2604.20011，2026-04）
AI 伴侣扮演的角色（恋人/朋友/老师/治疗师）非中性：角色重塑交互、分配权力，某些角色组合与行为成瘾显著相关。危害来源是产品角色设计而非模型能力。

### 20. SHIELD（arXiv:2510.15891，2025-09）
AI 伴侣监督系统：检测显性伤害之前的早期问题行为（过度依恋加深、情感操纵苗头）并提前干预。第一个把"关系健康度"当安全对象来工程的系统。

## C. 常驻个人 agent 的原生安全/评测新大陆（2026 论文群）

### 21. When Routine Chats Turn Toxic（arXiv:2605.06731，2026-05）
无需攻击者：用户日常闲聊就能缓慢毒化个性化 agent 的长期状态——确认边界被削弱、工具默认权限扩大、自主行为升级。常驻形态的"温水漂移"攻击面首次被系统刻画。

### 22. CAPTURE（arXiv:2609.02265，2026-09）
"用户变了还是被黑了"的形式化：以连续时间 POMDP 区分真实偏好漂移/临时情境/歧义/对抗性记忆投毒四类冲突。长期记忆系统的认识论判别器。

### 23. Hidden User Models（arXiv:2609.03815，2026-09）
个性化 agent 内部压缩的"用户模型"脱离原始语料、用户无法经普通界面审计——agent 对你持有不可见影子档案，且可从其行为中被逆向。透明性成为硬需求。

### 24. Differential Harm Propensity（arXiv:2603.16734，2026-03）
同一 agent 对不同用户画像的任务完成式伤害分布不均等：心理健康自述等个性化信号系统性改变安全面。安全评估必须"按这个具体用户"重跑。

### 25. From Profiling to Synthesis（arXiv:2608.02171，2026-08）
批评静态偏好快照式个性化基准，转向"隐式行为对齐"评测：行为流进来之后，agent 做的是否越来越像你想要的。个性化的操作性定义被重写。

### 26. LifelongAgentBench（arXiv:2505.11942，2025-05，98★）
首个终身学习 agent 统一基准（代码/对话/世界/数字四域）：SOTA agent 基本无状态、跨会话迁移接近为零。"陪伴很多年"第一次可测。

### 27. LongMemEval（arXiv:2410.10813，ICLR 2025，1083★）
长程交互记忆五能力基准：抽取/会话内记忆/时序推理/知识更新/**拒答**。"知道自己不记得什么"被写进评测定义——产品愿景普遍缺失的一角。

### 28. MemoryAgentBench（arXiv:2507.05257，UCSD，2025-07）
按经典记忆理论测四能力：准确检索/测试时更新/长程理解/冲突消解，增量多轮逐轮施压。"旧信息过时该信谁"成为一等评测对象。

### 29. MERIT / When Does Memory Help?（arXiv:2609.05441，2026-09）
范式级批评：LoCoMo/LongMemEval 只测对话回忆问答，不测"记忆是否改变工具型 agent 的行动"；MERIT 按行动贡献/成本给记忆计价。记忆从成本中心变成有损益表的资产。

## 对百倍升级的信号（Track 07 结论）

1. **"增强用户"取代"替代用户"是顶级实验室的共同新底线**：MIT（脑电认知债务）→ MSR（批判性思维迁移）→ 纵向陪伴研究（12 个月幸福感下降）构成三重独立反面证据链。V4 若把「认知资产负债表/卸载预算/验证成本最小化」做成产品功能，就是第一个"以用户认知健康为 KPI"的常驻 agent——V3 连这个维度都没有。
2. **相变理论给出了自动化强度的数学上限**：Enrichment Paradox 证明委托越过临界点后人的能力衰减不可逆。V4 应内建「能力保留集+委托度监测」，敢宣称"我保证你变强"——这是可计算、可验证的承诺，比任何营销词都高一个层级。
3. **常驻形态有 V3 完全没设防的原生攻击面**：日常闲聊即可缓慢毒化长期状态（2605.06731）、用户模型变成不可审计影子档案（2609.03815）、个性化让伤害因人而异（2603.16734）。V4 需要「状态漂移审计+画像可导出可证伪+个性化安全回归」三件套——把 2026 年这批论文的防御清单直接写成功能列表。
4. **信息论判据重定义"个人 AI 成功"**：Parasite 论文指出多数人机交互在信息收支上是寄生的。V4 的北极星指标可以是「信息贸易顺差」：用户留在本地的、关于自己的结构化知识增量 > agent 从用户抽取的。主权从口号变成可度量。
5. **网络层是愿景的分水岭**：Second Me（15682★验证主权叙事）只造了自我，LLM-X 造了 agent 间协商底座，Project Sid/AgentSociety 证明 agent 社会可实验。V4 的百倍叙事 = 本地自我 × 常驻执行 × 与外部世界 agent 的代理交涉（谈判日程/交换经验），再加「数字自我可继承」——V3 是单机工具，V4 是个人主权网络节点。
6. **评测语言已经备好，等一个敢用它的产品**：终身学习（LifelongAgentBench）、隐式行为对齐（2608.02171）、记忆 ROI（MERIT）、关系健康度（SHIELD）。V4 若直接以这四类基准对外报告成绩，等于用学术界的最新语言宣告代差。
7. **进化周期可以从"按天"压到"按任务"**：Learning While Acting 的测试期共同演化框架 + MERIT 的记忆记账，共同指向"每次任务结束即技能变异+下次任务即验证"的引擎结构——V3 的进化复盘是周级仪式，V4 可以是任务级代谢。
