## 二、五阶段路线（依赖排序：先主权定位，后网络放大）

### Phase A · 主权层 MVP〔P0〕——「资产法定化」

**复用**：画像五层/语料库/技能 git 仓库/871 tests 底座。
**新建**：
1. 主权格式规范：markdown 为源的记忆库（含**决策记忆**——决策+被否方案+理由），
   schema 化技能账本/画像/声誉档案，全部单文件可读可 diff。
2. 携带协议：export/import/audit/forget 四命令（对标 engram/ai-memory 的
   「跟人走」语义）；遗忘=双时态标记（Temvera 语义，可审计「已忘且何时忘」）。
3. **遗产模式**：一键全量导出+离线最小功能集清单+继承指定。
4. 适配器×3：导出格式直接可被 Claude Code（CLAUDE.md/memory 目录）、
   OpenClaw（skills 结构）、AstrBot（会话侧挂）消费。

**验收（10× 判据）**：三向导出导入实测回放；遗忘权审计报告；
遗产模式在干净房全离线跑通。
【混沌方法论】第一性原理+逆向（详见 VISION_V4 P0）。

### Phase B · 验证资产复利+出口闸〔P4/M3/M2〕——「进化换代谢」

**复用**：金标准 40 条、Ralph 复盘、CI/测试基建。
**新建**：
1. **出口闸四件套**：evidence over narrative、机器可查完成条件、确定性 done
   token（CI 可解析）、同会话恢复+目标重锚定（Taskmaster 移植）。
2. 记忆自检三套进进化环：冲突消解（新事实推翻旧画像）/结构回归/遗忘合规。
3. **任务级进化**：任务结束→技能变异候选（diff 即梯度，agentdescent 语义）→
   下次同类任务即 A/B 验证→KEEP/DISCARD 自动裁决+台账。
4. 金标准自动增长管线：每任务可沉淀条目带 origin 溯源，质量闸防稀释。
5. 上下文预算表+fresh-context 复盘子代理（M2）。

**验收**：进化周期实测压到任务级；金标准 40→200+；记忆冲突回归全绿；
无人值守任务 100% done-token 收口。
【混沌方法论】第一性原理（稀缺侧=验证）+耗散代谢。

### Phase C · 机器控制面〔P1〕——「占 Windows 空位」

**复用**：看护器/断点续跑/降级矩阵/弹窗根治 know-how。
**新建**：
1. **本机应用 API 网关**：Windows 应用无头自动化统一入口（UIA/COM/CLI 三路），
   agent 专用 ACI 工具面（失败即回滚/防误编辑，SWE-agent 律）。
2. **风控式信任**：动作四级（读/写/花钱/不可逆）×限额/白名单/异常检测/可回滚
   （Rokid×支付宝范式），取代一次性弹窗。
3. **审批密码学**：高风险动作生成签名授权日志（AP2 Verifiable Intent 同构），
   全程可审计回放（Rabbit 反面律）。
4. 资源账本：token/时长/钱三维计量（B2 结算轨道的计量底座）。
5. **METR 旋钮**（M4）：人审松紧=任务时程函数，自动指数后退。

**验收**：无人值守连续 7 天、回放可审计、策略强制零不可逆损失；
网关被一个第三方脚本/harness 成功复用（100× 方向首证）。
【混沌方法论】组合创新（支付风控×本机权限）+占位。

### Phase D · 主权网络节点+市场协议〔P3/E1-E5〕——「接入不自造」

**复用**：市场雏形/技能锻造/多账号池的计量经验。
**新建**：
1. x402/ACP 客户端：技能间微结算+外购数据/算力按次付费（免费期也全程计量）。
2. **git-native 市场协议**：发布=push/更新=pull/安装=add+版本缓存+依赖白名单
   （Claude Code 市场协议语义）；签名 skill card+自带 eval 结果升格（E2 四层）。
3. 跨标准适配器：Anthropic skills/OpenClaw/MCP/A2A/agents.md/华为智能体格式
   双向转换（E4）。
4. 中国分发第一站：IM 侧挂接入（AstrBot 语义验证，先支持一个 IM）。

**验收**：技能发布→首笔微付费（测试网/极小额）≤1 天闭环；
Anthropic skills 格式技能可一键导入且 eval 通过；IM 侧挂跑通一条真实任务。
【混沌方法论】升维（商店→清算所）+组合创新（协议栈缝合）+逆向（做适配器）。

### Phase E · 商业化与治理〔B1-B5〕——「章程先行」

**新建**：
1. 治理章程 v1（对外承诺三律：永不卖用户/数据本地/一键带走——Ghost 律），
   open-core 切分（核心开源清单+商业边界）。
2. 定价实验：托管同步/备份/多端订阅（Bitwarden 档）+「替你完成的小时数」
   计量报表（结果计费前置件，不先收钱）。
3. 反退化仪表盘对外版（P2 顺差指标公开方法论——信任获客杠杆）。

**验收**：章程发布且代码库结构与章程一致；托管层最小可用（同步+备份）；
小时数报表经机器判据背书。
【混沌方法论】组合创新（章程×定价×托管）+反脆弱（长尾生态位）。

## 四、规模现实检验（单人开发）

- **不做的**：不自造支付协议/不自造第四技能标准/不做硬件/不做通用编排壳
  （Vibe Kanban 日落律）/不与巨头在同赛道比参数。
- **节奏**：A→B 为第一优先双星（定位+护城河，均可纯本地开发验证）；
  C 为 Windows 深耕独门（已有 know-how 折现）；D/E 在 A-D 验证后推进，
  且 D 的协议接入逐个来（先 x402+Anthropic skills 两个）。
- **预算纪律**：R1-R12 全沿用；免费池继续为默认推理底座；
  外部付费仅 x402 测试网级微额。
