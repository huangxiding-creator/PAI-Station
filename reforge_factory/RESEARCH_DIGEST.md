## 二、瓶颈链分析（阿姆达尔：1000 万字卡在哪）

```
战役编成单(已自动化) → [A 渠道开火] → [弹药汇池] → [去重/质检] → [字数盘点] → 1000万门
                          ▲瓶颈1          ▲瓶颈2        ▲瓶颈3       ▲瓶颈4
```

1. **瓶颈 1（最大）— 渠道开火器缺失**：编成单生成后无自动执行腿，16 渠道靠手动逐个跑（dispatch-mock 仅打印）。战役编成=作战地图，但无部队出动命令系统。
2. **瓶颈 2 — 弹药池未实体化**：无统一存储 schema/无 URL 归一去重/无 source_engine 标记落地。1000 万字门槛无自动计数器——「门槛」还只是 JSON 里的声明。
3. **瓶颈 3 — 质检入库位空缺**：Jev S2 预筛未接弹药管线；弹药等价原则（用户定调）无执行器。
4. **瓶颈 4 — 盘点器缺失**：无维度覆盖/独立信源数/字数账本的自动盘点（B 段任务是纸面任务）。

**结论：重构不是再造骨架（骨架今日已立），而是接四条腿+实体化弹药池。**
