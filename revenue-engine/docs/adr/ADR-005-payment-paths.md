# ADR-005: 收款三态路径（商户号门驱动）

日期：2026-10-14 | 状态：accepted（Phase 0-3 结论后落定具体态）

## 决策
收款实现按商户号门（REQ-003）结论三选一：
1. 有企业商户号 → wechatpay V3 直连（wechatpay-skills 官方件）+ acg-faka
2. 无 → 个人码半自动（收款截图人工确认→transformer 手动触发发货）
3. 补办中 → 暂缓收款，链路先行（推荐/私聊照跑，下单入口挂「即将上线」）

## 理由
微信支付 V3 硬前提=企业商户号+营业执照（个人无法开通）；三态皆有收入链路不断。
