# 商机评分公式与阈值表（T-046 / REQ-014.AC1，唯一阈值来源）

> 消费方：Lead transformer（评分计算）/ 告警腿（≥70）/ 推荐触发腿（≥50）都从本文件读。
> 等价机读结构见文末 JSON 块。修改走调参记录（追加式）。

## 1. 四因子公式

```
score = round( 省份系数 × 行业系数 × 规模系数 × 时间窗系数 × 100 , 0 )   # 封顶 100
```

### 因子档位表

| 因子 | 档位 | 系数 |
|---|---|---|
| **省份** | 苏/浙/粤/京/沪 | 1.2 |
| | 其余省份 | 1.0 |
| | 跨省/不明 | 1.0 |
| **行业** | 水利/水电 | 1.3 |
| | EPC 总包/市政 | 1.25 |
| | 造价/咨询 | 1.1 |
| | 其他工程 | 1.0 |
| **规模**（投资额线索） | ≥10 亿 | 1.3 |
| | 1-10 亿 | 1.15 |
| | <1 亿/不明 | 1.0 |
| **时间窗** | 招标/筹备期（信号词：招标、立项、可研、找合作） | 1.5 |
| | 在建期（信号词：在建、施工中、赶工期） | 1.2 |
| | 前期/不明 | 1.0 |

### 示例

江苏某水库 EPC 项目（10 亿+，招标期）= 1.2 × 1.3 × 1.3 × 1.5 × 100 = **304 → 封顶 100**（顾问级）
安徽某造价咨询求助（不明规模，在建）= 1.0 × 1.1 × 1.0 × 1.2 × 100 = **132 → 封顶 100**？
——注意：四因子连乘极易封顶，故连乘结果 **线性压缩到 40-100 区间**：
`final = 40 + min(raw, 300) / 300 * 60`（raw=132 → 66.4 ≈ 66；raw=304 → 100）。
压缩式保证：普通求助 ~50-65、明确项目信号 ~70+、重大项目 ~85-100，阈值才有区分度。
