# 商机评分公式与阈值表（T-046 / REQ-014.AC1，唯一阈值来源）

> 消费方：Lead transformer（评分计算）/ 告警腿（≥70）/ 推荐触发腿（≥50）都从本文件读。

## 1. 公式（单一公式，两步）

```
raw   = 省份系数 × 行业系数 × 规模系数 × 时间窗系数 × 100        # raw ∈ [100, 304.2]
final = 40 + (min(raw, 300) - 100) / 200 * 60                    # final ∈ [40, 100]
```

### 因子档位表

| 因子 | 档位 | 系数 |
|---|---|---|
| **省份** | 苏/浙/粤/京/沪 | 1.2 |
| | 其余省份/跨省/不明 | 1.0 |
| **行业** | 水利/水电 | 1.3 |
| | EPC 总包/市政 | 1.25 |
| | 造价/咨询 | 1.1 |
| | 其他工程 | 1.0 |
| **规模**（投资额线索） | ≥10 亿 | 1.3 |
| | 1-10 亿 | 1.15 |
| | <1 亿/不明 | 1.0 |
| **时间窗** | 招标/筹备期（信号词：招标、立项、可研、找合作） | 1.5 |
| | 在建期（信号词：在建、施工中、赶工期） | 1.2 |
| | 前期/不明 | 1.0 |

### 示例（值域自洽）

- 安徽造价咨询求助（1.0×1.1×1.0×1.2 → raw 132）→ final **49.6**——低于推荐阈 50，不推荐不告警，仅入账
- 江苏水库 EPC 招标期（1.2×1.3×1.3×1.5 → raw 304.2 → cap 300）→ final **100**——顾问级告警
- 全因子 1.0 的弱信号（raw 100）→ final **40**——低于入账下限 45，噪声门拦截
- 普通求助带一次档位提升（raw 117-150）→ final **45-55** 区间——推荐候选带
