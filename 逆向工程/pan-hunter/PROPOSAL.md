```
panhunter search "水电站EPC施工组织设计"        # 三路源聚合 → 去重归一 → 红绿灯标注 → JSON/表格
```

## 七、法务四原则（防死三原则+V3 新增第四，入宪）

1. **法务隔离**：只做免登录公开分享索引+用户自有通道下载；不碰限速破解/账号池/向下载收费（PanDownload 刑事/常某收费/盘多多民事三案为界）
2. **双解耦**：源插件化（yt-dlp 纪律）×下载器抽象（OpenList 协议+aria2 执行）；单源单盘死可热插拔；pansou fork 入仓+org 化多维护者（AList 卖身+iikira 蒸发双教训）
3. **凭据零托管**：永不代收用户盘 Cookie；登录态功能一律本地自供（速盘偷 BDUSS 史为界）
4. **无公开策展**（盘多多案教训）：缓存仅私有按需、不建公开索引库、不转存再分发；**收割物只进内部调研语料，禁止直接进付费交付物**（付费层只收整编/原创）；quarry 硬编码密钥只作协议情报、禁作生产源
