**login_gated:empty 根因结论（production_bridge 战伤定性修正）**：
T19（1022）判「匿名搜索登录墙」是**渲染面表象误判**——search.html 渲染页内联
`base.limit_search=1` 只驱动客户端 login 弹窗（static `index_new.js` 的
`search_login.init`），底层 newSearchApi 端点本身匿名放行（首窗
`limit_search=0` 全绿吐题录）。真实墙 = **匿名检索用量配额**（用量耗尽后
`code=1 + limit_search≥1 + list=[]`，>1h 未恢复，IP 级、跨会话、跨新词）——
非登录墙，账号态只影响配额额度而非访问权。

## 二、API 规约（复刻件逐一实现）

### 1. 检索面 newSearchApi（题录清单）

```
GET https://max.book118.com/user_center_v1/home/Search/newSearchApi.html?q=<urlencoded>&page=1
头: UA(桌面Chrome) / Referer: …/search.html?q=<词> / X-Requested-With: XMLHttpRequest
```

信封（200，JSON）：
```json
{"code":1,"data":{"check_code":0,"limit_search":0,
  "list":{"total":143,"docs":[{"uname":..,"encode_aid":"6020050214001000",
  "url":"/html/2017/0418/100821230.shtm","title":"..ppt","senddate":..,"litpic":..,
  "highlight":..,"checkdate":..,"vip_type":1,"is_free":0,"filetype":"ppt",
  "filesize":..,"pagenumber":"25","needmoney":"200","hits":..,"es_score":..,
  "es_score_level":..,"pay_num":..,"down_num":..,"doc_score":..}, ×10/页]}},
 "message":""}
```
- `encode_aid`（题录主键，getTxt 用）≠ URL 文档号（.shtm 文件名）——两套编号。
- 翻页：`page=N` 10 条/页；匿名深度实测 page1-3 全绿，page5 吐数但 limit_search=2
  （软限信号），page10+ 空停。复刻件 `MAX_PAGES_DEFAULT=5`。
- 配额耗尽形态：`code=1, data.limit_search>=1, list=[]` → 复刻件抛 `SearchQuota`
  （区分于其他错误；getTxt/browse 不受影响可继续）。
- 抓包线索来源：search.html 内联 `search_index.url.loadmore` 明文（零 JS 逆向成本）。

### 2. 文字层 getTxt（免费预览文字 ≥500 字验收腿）

```
GET https://max.book118.com/user_center_v1/home/Search/getTxt.html?aid=<encode_aid>&detail_id=0&keywords=<词>
```
信封：`{"code":1,"data":{"text":"…999字…","is_collected":0,"label":[],
"recent_download":0,"money":199,"vip_type":1,"is_free":0}}`
- 实测 8 件（is_free=0 全档、needmoney 100-8000、vip_type 0/1/13）均 999-1000 字——
  **配额墙期内仍全绿**（文字层独立配额，或无配额）。
- text = 文档真文（关键词命中段高亮），非摘要——检索面直接兑现 ≥500 字/份。

### 3. 详情面 .shtm → 预览参数（T19 口径平移 + 纯HTTP首跳实证）

```
GET https://max.book118.com/html/<YYYY>/<MMDD>/<docid>.shtm   （无 XHR 头）
```
页内联 `var base` 挖：`pic:{aid:<加密aid|裸id>, actual_page, preview_page,
view_token}` + 顶层 `senddate:'<32hex>'`。**view_token 双形态**：裸 token（旧档）
或 `//view-cache.book118.com/pptView.html?aid=…&view_token=<tok>` 包装（新档）——
统一取内层。T19 曾判「必须 Playwright 过 SafeLine」——本役实证 urllib 直打 200
（SafeLine 对纯 stdlib 指纹放行，同 wenku BFE 打法）。

### 4. 页图清单 openapi getPreview（对接 harvest T19/T23）

```
GET https://openapi.book118.com/getPreview.html?project_id=1&aid=<pic.aid>&t=<senddate>&view_token=<raw@保留>&page=1&callback=jsonpReturn
```
信封（jsonp）：`{"status":200,"data":{"1":"//view-cache…png","2":…},"pages":
{"preview":"3","actual":"7","filetype":"docx"}}` —— **data 本体=页号→图URL**；
6 页/批（page=1,7,13…）；`code:100 系统错误`=pptView html5 形态件（如
5011203143013244）不走图床 API，如实分类 `api_status`。空批抖动实测占多数
（T41 同判），复刻件批内 3 连退避。
- 图 URL 原样透传（`@`/`=` 勿二次编码，fastdfs 形态）；文字层归 OCR 管线
  （harvest_engine T13/T33 在役），本件只出清单。

### 5. 浏览面 doclist（免配额题录源）

```
GET https://max.book118.com/doclist/list-<id>.html[或 -<page>.html]
```
静态 .shtm 直链 33-80 条/页（`title` 属性+行内 `hits N页` 元数据），50 页深。
配额墙期全绿——检索断供时的兜底题录面 + 选品入口（T37 同口径）。
分类图（页内导航提取，31 类）：**562=建筑/施工（EPC 选品主面）**、430=工业/机械/
环境、551=经济/贸易/计划、669=资格/认证考试、813=企业管理 等。

### 附注（1024 补充实测）

- getTxt 的 `keywords` 参数服务端忽略（同 aid 换词返回逐字节同文）→ 文字段
  = 文档开头固定 ~999 字摘录，确定性好，缓存友好。
- `encode_aid` 与 .shtm 文档号是两套编号（题录 encode_aid=6020050214001000 ↔
  url 文档号=100821230）；getTxt 只认 encode_aid，详情/预览只认 .shtm 编号。
