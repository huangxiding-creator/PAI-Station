# CapCut Runtime Preflight

## Speech-to-text and deterministic media

- Probe the active speech-to-text route and report its real output schema.
- Probe `ffmpeg`, `ffprobe`, and every material codec/filter in the active Sandbox before deterministic video work.
- Files are directly available only when attached, retrieved, or inside an authorized Desktop shared folder. Shared-file visibility, Sandbox shell, and host terminal are separate permissions.
- Validate outputs and copy them to the intended shared destination when required.

## Manus video surfaces

- Treat generation and semantic variation as short flattened-output tools with runtime-specific limits.
- Semantic variation is not deterministic trim, crop, subtitle, chroma-key, or long-form editing.
- Manus Video Editor saves Manus scene state for user editing and exports MP4. Checked code does not establish agent timeline control or CapCut draft conversion.

## CapCut Web through My Browser

- Confirm My Browser is ready and authenticated to the intended CapCut account.
- Record client/build, account, region, and visible feature entry point.
- Use a disposable Web project and prove save/reopen plus exact retained objects.
- Treat My Browser as browser control, not Computer Use.

## CapCut Desktop through Computer Use

- Resolve the installed app/version from live installed-app state; do not hard-code a path.
- Confirm the CU helper is ready and the desktop-control lease is free.
- Record account/region/version before using Auto Cut, captions, templates, or other rollout-sensitive features.
- Work on copied media and a new or copied draft. Never mutate reverse-engineered draft files as a production route.
- Observe current controls; documentation is a candidate map until the exact app/OS/account path passes live replay.
- Re-observe every meaningful mutation. Input dispatch is not proof that a caption track, cutout, timeline, or relink exists.
- Use state-based bounded waits and never resubmit a running analysis/export.
- Finish the CU session exactly once after final verification.

## Integration boundary

No Manus-accessible supported CapCut timeline integration was found in the checked code/evidence snapshot. This scoped result is not an exhaustive claim that CapCut can never expose an API.

## Parallelism

Independent transcript, file, route, and media-probe tests may run in parallel on separate assets. My Browser projects should be serialized within one account, and all Desktop CU tests are serial.
