# Captions, Cutout, and Cleanup (Cards 1, 2, and 5)

## Card 1 — Transcript and captions

**Use when:** the user needs transcript text, subtitle files, burned-in captions, or an editable CapCut caption track. Typical cases include Reels/Shorts, interviews, product demos, education, and multilingual creator content.

**Primary channel:** T0 for standalone transcript text; F1 for existing subtitle normalization/translation/conversion/burn-in; W1/C1 when captions must remain editable in the selected CapCut client.

**Escalation trigger:** use W1/C1 for retained caption timing/style, sequence-aware correction, or explicit in-app teaching. Missing timestamps in T0 never permits fabricated cues.

**Hybrid handoff:** T0/F1 prepares and validates subtitle assets; W1/C1 imports or creates editable captions and may export a file for independent cue checks.

**Workflow:** define exact product, glossary/language/style; probe route and feature visibility; approve transcript/five cues; correct names/numbers/line breaks; complete and verify.

**Verification:** sampled accuracy, cue order/timing/encoding where present, coverage, independent subtitle-file opening, and save/reopen proof for editable CapCut captions.

**Failure and recovery:** retain partial output, record absent timing/speakers or feature gate, reconcile cue IDs, and never resubmit running recognition.

**Record as skill:** strong for one client/version/account path after live replay; parameterize source, language, glossary, style, and output.

**CU display:** yes only for C1 editable Desktop captions or a proved Desktop lesson. T0/F1 and W1 are not CU.

## Card 2 — Cutout and background

**Use when:** a clip needs green-screen keying, semantic background replacement, or retained CapCut layers/masks/keyframes. Typical cases include creator overlays, product demos, talking heads, education, and event graphics.

**Primary channel:** F1 for a deterministic chroma key after filter probe; G1 for a short semantic variation within current tool limits; W1/C1 for retained CapCut composition state.

**Escalation trigger:** use W1/C1 for editable layers, masks/keyframes, timeline alignment, long or unsupported variation, or explicit client teaching. Use C1 only when Desktop state is required and the feature is visible for the test account/region/version.

**Hybrid handoff:** native generation may create a background; F1 prepares a keyed intermediate; W1/C1 layers and times assets when retained project state is required.

**Workflow:** classify chroma versus semantic versus irregular foreground; select state; approve representative motion/edge frames; complete; save/reopen if retained; export separately.

**Verification:** duration/audio, edge/spill points across motion frames, layer order, save/reopen editability, and explicit statement that G1 is not a deterministic matte.

**Failure and recovery:** preserve source and intermediate; unavailable Auto Removal or poor edges trigger fallback/review, not stale-coordinate hunting.

**Record as skill:** one feature/client/version path only after live replay.

**CU display:** conditional for C1 retained Desktop cutout/composition state.

## Card 5 — Owned-footage cleanup

**Use when:** an owned/authorized outro, mark, or segment needs trimming, cropping, covering, or timeline-aware cleanup.

**Primary channel:** F1 for fixed tail trim, crop, or deterministic cover; W1/C1 when the target changes over time, needs visual timeline judgment, or must remain editable.

**Escalation trigger:** refuse without ownership/authorization. Use retained CapCut state only when a simple file route would damage approved content or the user needs the edit in the project.

**Hybrid handoff:** F1 identifies/applies safe fixed edits; W1/C1 handles approved timeline/keyframe work; F1 creates mechanical variants from the approved master.

**Verification:** target absent, nearby video/audio preserved, duration/dimensions match chosen method, project state reopens if promised, and source hash remains unchanged.

**Failure and recovery:** present trim/crop/cover choices when ambiguous; stop rather than conceal unrelated content or provenance.

**Record as skill:** fixed transforms remain parameterized; project-specific in-frame cleanup needs live review points.

**CU display:** conditional for C1 timeline judgment, not fixed trimming.
