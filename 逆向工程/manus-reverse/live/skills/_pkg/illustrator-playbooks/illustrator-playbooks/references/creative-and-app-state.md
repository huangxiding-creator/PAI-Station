# Creative and app-state workflows

These cards separate concept generation from retained Illustrator state. No exact Illustrator Desktop procedure is released in this package.

## Card 1: Vector reconstruction

- Ask whether the required product is a raster derivative, standards SVG, Firefly job output, cloud document, or desktop AI master.
- Use Manus-native visual generation only for a concept/reference or supported standalone result.
- Use portable SVG tooling only when the standards contract is sufficient.
- Use official Adobe automation only when its exact runtime and credentials are available.
- Keep desktop trace tuning, expansion, and source-specific path repair blocked until their current build has O1 and save-reopen verification.

Verify dimensions, required holes, path closure if requested, colors, target-size appearance, and the exact retained object state.

## Card 4: Packaging and label handoff

Use file tooling to inventory approved copy, assets, candidate links, license notes, destination, and immutable dieline rules. It may prepare a handoff plan and hash-based inventory. It must not claim live artwork, resolved Links, packaged fonts, printer settings, or Illustrator Package state.

Editable packaging mutation requires a copied document, named immutable geometry, approved copy and barcode state, an authoritative print specification, and an O1-proved app route. External delivery remains a separate approval.

## Card 5: Recolor

- Exact source-to-target mapping is a deterministic specification. Prefer a proved reusable Adobe mechanism when available.
- Visual harmonization is a supervised creative task. Manus may propose palette references, then apply an approved direction only through a separately proved Web or Desktop route.
- Preserve locked legal, logo, spot, gradient, transparency, and print-color semantics in the acceptance contract.

## Card 6: Brand system

Separate concept selection from production. Manus-native visual tools may produce references. Editable lockups, live type, swatches, layers, and delivery-kit state require a verified cloud or desktop client. The user approves identity-defining geometry, type, and color before scaling variants.

## Card 7: Icon or illustration system

Write grid, stroke, corner, palette, naming, layer, export, and intentional-exception rules before editing. Deterministic normalization may use a reviewed file or automation route. Source-specific visual repair and target-size craft remain supervised and client-specific. Approve one pilot before scaling.
