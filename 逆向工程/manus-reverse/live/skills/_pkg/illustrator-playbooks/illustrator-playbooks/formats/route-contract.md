# Route contract

## Required preflight

Record these facts before selecting a mechanism:

1. requested client, if any;
2. source location and granted file reachability;
3. retained state: raster, standards SVG, standalone PDF, cloud document, desktop AI, Variables, Action/script, or package;
4. whether the work is deterministic, visually adaptive, or identity-defining;
5. current tool, account, plan, app, plug-in, and permission availability;
6. destination, collision policy, and immediate approval boundaries.

## Route selection

| Route | Select only when | It does not prove |
|---|---|---|
| Manus-native visual generation | The requested deliverable is a concept/reference or supported standalone output | Editable vector paths, AI layers, type, artboards, or Illustrator state |
| Deterministic file tooling | The portable contract and relevant fixture pass; source is reachable | Illustrator import, save-reopen, Variables binding, link resolution, or Package |
| Official Adobe automation | The exact supported mechanism is configured and invocable now | A Manus connector, generic compatibility, or user authorization for mutation |
| My Browser | Illustrator Web is signed in and the exact feature is visible for this cloud document | Desktop parity, local AI state, or Computer Use |
| Computer Use | Illustrator Desktop and the exact current-build subflow have live evidence and an observable saved postcondition | Cross-OS parity, unobserved recovery, or policy exemption |
| Guidance | A required execution surface is absent, unknown, unsafe, or live-blocked | Completed mutation |

## Escalation rules

- Escalate from raster or portable work only when the required editable state cannot survive there.
- Escalate from file preflight to Adobe automation only after the durable mechanism is detected.
- Escalate to My Browser only for a verified Web feature and cloud state.
- Escalate to Desktop only for a named app-native state and an O1-proved subflow.
- If no route can preserve the promised state, deliver a preflight report, specification, or handoff plan and name the blocked tail.

## File reachability

A mounted or shared local file may be processed through the file bridge without Computer Use. This is not arbitrary host execution. A local script or app invocation needs a separately authorized host runtime; sandbox execution does not imply it.
