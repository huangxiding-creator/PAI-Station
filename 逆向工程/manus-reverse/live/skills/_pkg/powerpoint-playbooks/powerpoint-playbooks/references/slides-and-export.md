# Structure and Export (Cards E1 and F1)

## E1: add, delete, reorder, extract, compare, or merge slides

Route by the canonical object:

- **Manus Slides project**: use the exposed organize operation for add/delete/reorder and the normal editing operation for new content.
- **Retained `.pptx`**: probe the presentation-native imported-deck tooling. Use it only on a copy and only if a fixture proves slide order, relationships, masters, notes, media, and embedded state required by the task.
- **PowerPoint for web deck**: use My Browser when the browser deck is canonical and the required operation is available there.
- **PowerPoint-only residual**: use a verified CU operation when the retained-file route cannot preserve the required state.

Before any retained-deck operation, identify slides by both stable title/content and current position. Work on copies. For a merge, agree which design system should win and whether source formatting must be retained. Verify final count, title order, notes, and master/layout assignments.

Do not infer that CU is mandatory from one library's inability to copy or reorder slides.

Do not route retained-deck comparison to remembered PowerPoint Compare/Merge controls. Microsoft retired that feature from the Microsoft 365 PowerPoint app for Windows beginning with version 2502. Use a presentation-native or file-level comparison report unless a current product/version source and O1 event prove a different supported surface.

## F1: export and derivative output

Choose by source and fidelity:

- **Manus Slides resource**: use its current presentation/export path.
- **Presentation-runtime `.pptx`**: use its exposed export route and reopen the result.
- **Retained `.pptx`, static PDF or images**: use an available verified converter, then inspect the output.
- **PowerPoint for web deck**: use My Browser only for an export surface present in the current account; do not infer a connector conversion action.
- **Exact PowerPoint print state**: use a verified PowerPoint route for handouts, notes pages, or app-specific rendering.
- **Animation-step or motion output**: use a verified app playback/export workflow; static conversion is insufficient.

Microsoft documents desktop video export and Presenter View as product features, but those guides are O2 candidates only. Video export remains platform/version dependent, and Presenter View is a live presentation state rather than an artifact export. Neither guide authorizes autonomous CU without a current operation record.

For every export, compare slide count to page/image count, inspect slides with unusual fonts, SmartArt, charts, transparency, media, or complex layout, and name any substitutions or flattening. Never claim a connector conversion route unless the current connector exposes it.
