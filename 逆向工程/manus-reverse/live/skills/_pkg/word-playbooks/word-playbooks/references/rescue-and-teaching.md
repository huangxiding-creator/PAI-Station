# Recovery, Performance, and Teaching (Cards G1, G2, H1)

## Card G1: Recovery diagnosis

**Primary channel**: forensic file diagnosis on a verified copy; no general recovery capability is promised.

**Escalation trigger**: bounded package salvage cannot produce a valid separate DOCX and an O1 Word recovery procedure exists for the exact corruption/app/OS/version.

**Hybrid handoff**: native ZIP/XML/relationship inventory identifies intact and lost state; an O1-qualified Word route may attempt one copied fixture; extracted content becomes a new file with an itemized loss report.

**Workflow**
1. Hash the original and make a distinct safety copy.
2. Inspect ZIP central directory, content types, XML parsing, relationships, media, and extractable text.
3. State the exact corruption and bounded salvage options.
4. Obtain approval before lossy salvage. Do not invent an Open-and-Repair sequence.
5. Validate and render any recovered copy; never claim full recovery without reconciliation.

**Verification**: original hash unchanged, package checks, intact/lost inventory, recovered output validity, full render, and loss report.

## Card G2: Large-document diagnosis

**Primary channel**: Documents runtime audits and measurement.

**Escalation trigger**: a specific reversible Word setting/action has O1 operation evidence and file-native remediation cannot address the measured cause.

**Hybrid handoff**: audit style counts, images, revisions, fields, sections, package size, and render time; propose one measured change at a time; qualify any app-side tail separately.

**Workflow**
1. Capture file size, page count, media inventory, styles, revisions, fields, sections, and render/open timing where available.
2. Rank likely causes by evidence rather than applying generic cleanup.
3. Preview loss/fidelity consequences of recompression, revision cleanup, splitting, or link changes.
4. Apply one approved change to a copy and remeasure.

**Verification**: before/after size/timing/page count, image fidelity, revision/field integrity, and full render. Diagnosis may finish without a safe automated repair.

## Card H1: In-app lesson

**Primary channel**: Word through Computer Use only for an independently O1-qualified procedure; otherwise evidence-dated guidance.

**Escalation trigger**: the requested procedure has no O1 app/OS/version record, the document is sensitive, or the file is not a safe copy.

**Hybrid handoff**: explain the goal and prepare a synthetic fixture natively; replay only the proved app-only tail; verify the saved result outside Word.

**Workflow contract**
1. Select a closed underlying card and record exact Word/OS/version/locale.
2. Use a synthetic or copied document and semantic actions, never fixture-specific coordinates.
3. Leave the user in control at confirmation points.
4. Save separately, reopen, and verify the outcome structurally.

**Verification**: underlying card assertions pass; recording contains no sensitive content; failure/recovery and unseen-fixture replay are recorded.
