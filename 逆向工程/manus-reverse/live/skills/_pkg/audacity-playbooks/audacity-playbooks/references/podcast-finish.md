# Card 2 — Spoken-Word Podcast Finish

**Use when:** the user has raw or roughly edited spoken-word tracks and wants a coherent master and delivery copy, with an editable Audacity project retained only when needed.

**Primary channel:** F0 owns source protection, track inventory, portable preparation, and independent export checks. Use M1 for exact fixed operations reproduced on the installed build. Use P1 after O1 for cuts, pacing, voice balance, listening, plug-in UI, labels, alignment, or retained project state.

**Escalation trigger:** move to P1 when editorial intent, per-segment listening, track alignment, or future revision requires the real project surface.

**Hybrid handoff:** F0 freezes tracks and the edit/output manifest. M1 may perform observed fixed atoms. P1 handles judgment-heavy edits and saves the named project. F0 verifies outputs and reconciles exceptions.

**Inputs:** source tracks, semantic speaker roles, edit brief or rundown, licensed intro/outro or music, technical delivery requirements, and retained-project requirement.

**Workflow:**

1. Freeze source tracks, rights, semantic roles, and output contract.
2. Inventory track and file properties through available tools.
3. Classify operations as deterministic, reproduced app automation, or listening/editorial judgment.
4. Test a representative segment and compare the result against the edit brief.
5. Obtain approval for pacing, removals, music placement, and voice treatment.
6. Complete work with stable track, segment, and output identities.
7. Verify deliverables independently and record unresolved defects.
8. Save and reopen any promised Audacity project after current-build O1.

**Failure and recovery:** stop on a missing track, ambiguous edit intent, unlicensed asset, clipping, damaged speech, unsupported runtime, or unavailable project state. Resume from stable segment/output identities.

**Record as Skill:** record only a short P1 two-track mainline after O1. Parameterize track roles, edit markers, brief, assets, project, and outputs; never freeze track order, coordinates, or filenames.

**CU display:** eligible after O1 because the app-specific value is retained multi-track state and listening-led editorial judgment. Pure conversion or packaging remains portable.
