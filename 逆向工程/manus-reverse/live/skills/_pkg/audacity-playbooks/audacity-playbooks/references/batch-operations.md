# Supporting Batch Operations

Use these operations only inside an accepted workflow. Batch normalization/export is not a standalone primary card in this package.

## Route choice

- Prefer F0 when a probed portable audio tool can apply and verify the exact fixed transform without requiring Audacity state.
- Use M1 only after the exact Audacity Macro or app automation is reproduced on the installed build.
- Use P1 only for heterogeneous outliers that require listening or retained project state after O1.
- Do not use a repeated CU loop for a deterministic folder operation when a verified batch route preserves the same result.

## Preflight

- Inventory every source and protect originals.
- Define the exact operation, parameters, output format, unique naming, collision policy, and objective verifier.
- Sample normal and outlier files before scale.
- Reject a single fixed chain when the collection is materially heterogeneous or the acceptance rule requires listening.

## Recovery and verification

- Maintain stable input/output identities and a completed/failed/skipped manifest.
- Query outputs before retrying and never overwrite an unknown existing file.
- Verify every output's identity and technical properties; review selected outliers separately.
- Report that the operation remains supporting and conditional when the fixed route has not been reproduced.
