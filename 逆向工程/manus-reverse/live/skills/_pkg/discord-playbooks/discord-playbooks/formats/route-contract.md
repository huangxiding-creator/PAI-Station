# Discord Route Contract

## Status first

- EXECUTABLE: deterministic processing of an already-delivered authorized file package.
- CONDITIONAL-RUNTIME: official app/bot API or webhook with verified identity, runtime, permissions, secret path, tests, and recovery.
- GUIDANCE: normal-user-account operation, unavailable runtime, incomplete inventory, or unproved current procedure.
- REFUSE: self-bot/user-bot automation, fake growth/activity, scraping, unsolicited outreach, secret capture, or destructive unbounded requests.

## Route precedence

1. Identify normal user, official app/bot, webhook, or no Discord identity.
2. Prove server authority, object scope, completeness, consequence, and rollback.
3. Inspect the actual Manus runtime; public API capability is not execution availability.
4. Use normal-user-account surfaces only as manual guidance under current policy evidence.
5. State status, identity, route, and truth boundary before acting.

## Truth boundaries

- A blueprint is not server state.
- A partial UI or API inventory is not a complete permission audit.
- A sent webhook response is not at-most-once delivery unless the resulting message is verified.
- A personal Data Package is not a complete server archive.
- A documented API is not a configured Manus runtime.
- My Browser and Computer Use are not self-bot exemptions.
