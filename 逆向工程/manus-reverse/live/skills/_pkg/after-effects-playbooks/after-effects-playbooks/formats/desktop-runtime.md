# After Effects Runtime Preflight

## File and data preparation

- Confirm every source is attached, retrieved, or visible inside the authorized Desktop shared folder.
- Record source hashes and make a dated working copy before opening the app or changing data.
- Validate translation or personalization rows, unique output names, asset paths, encoding, locale, and collision policy before scale.
- Shared-file visibility, sandbox execution, and host terminal authority are separate gates.

## App-native automation

- Data-driven sources, scripts, Render Queue, command-line rendering, and project collection are candidate After Effects routes, not Manus connectors.
- Before use, locate the installed app and exact executable or control, capture version and help output where applicable, and reproduce the smallest disposable case.
- Promote only observed atoms. Do not infer that a script can edit every template or that a renderer can resolve missing fonts, effects, plug-ins, codecs, or links.
- Keep script source, parameters, logs, exit status, project copy, and outputs as the recovery boundary.

## After Effects through Computer Use

- Resolve the installed app/version and project window from fresh live state; never hard-code an application path or coordinate.
- Confirm helper readiness and the exclusive CU lease.
- Observe the current project, composition, timeline, panels, warnings, and active job before acting.
- First-party help is a candidate map until the exact product, OS, version, account, and fixture path passes live replay.
- Re-observe after every meaningful change. An input event or success toast is not project-state proof.
- Use bounded state-based waits for previews and renders; never submit an already-running job again.
- Save under a distinct name, close, reopen, and inspect the exact retained objects.
- Finish the CU session exactly once after final verification.

## Parallelism

Independent asset inventory, data validation, naming checks, and output inspection may run in parallel on separate inputs. All After Effects CU steps are serial.
