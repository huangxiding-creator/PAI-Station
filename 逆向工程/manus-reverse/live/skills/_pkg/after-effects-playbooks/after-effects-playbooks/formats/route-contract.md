# After Effects Route Contract

## Route precedence

1. Preserve an explicit `.aep`, template, or editable-project request.
2. Name the retained state: F0, A1, P1, or G0.
3. Inspect the authorized files and the current runtime before mutation.
4. Prefer a reproduced structured route when it preserves the same project state.
5. Escalate to P1 only for required visual judgment, app-native object state, plug-in UI, or explicit in-app teaching.
6. State the route and completion truth label before execution.

## Truth labels

| State | Completion label | Must not be called |
|---|---|---|
| F0 | Prepared files, manifest, data, or validated flat output | After Effects project state |
| A1 | Named project or render state created by an observed data, script, render, or collection route | Universal automation beyond the reproduced route |
| P1 | Named After Effects state that survives save and reopen | Complete merely because a preview or render exists |
| G0 | Current bounded guidance and a testable handoff plan | Executed workflow |

## Material questions

- Must the user receive an editable After Effects project, or is a flat output enough?
- Is there an existing licensed project or template, and which parts may change?
- Which compositions, placeholders, expressions, fonts, effects, plug-ins, and links must survive?
- Is the work one version, many data-driven versions, or many languages?
- Which language and visual decisions require qualified review?
- Is a structured data, script, or renderer route currently installed and reproduced?

Ask only when the answer changes the route or acceptance oracle.

## Route-change record

When escalating, record the original route, observed limitation, newly required state, added permissions or risk, and revised verification oracle.
