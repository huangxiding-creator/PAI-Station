# Card 1 — Template Brand Refresh

**Use when:** the user has a licensed After Effects project or template and wants text, logos, images, video, colors, fonts, or timing adapted while retaining an organized editable project. Typical cases include product launches, event openers, annual campaign refreshes, social advertisements, and branded explainers.

**Primary channel:** F0 for protected copying, asset inventory, naming, and preflight. Use A1 for fixed semantic replacements only after a data or script route has been reproduced on the installed build. Use P1 for ambiguous placeholder mapping, crop and scale judgment, typography, timing, transition integrity, effects, plug-ins, or retained project state.

**Escalation trigger:** move to P1 when the template structure cannot be mapped reliably from files or a reproduced script, or when visual and app-native state is part of acceptance.

**Hybrid handoff:** F0 creates the working copy, asset map, change table, and output contract. A1 may apply safe structured replacements. P1 reviews and fixes visual exceptions, then saves the named project copy. File tooling validates collected assets and renders.

**Inputs:** licensed project/template, brand kit, final copy, images/video, audio, reference, target resolution, project-retention requirement, and deadline.

**Workflow:**

1. Confirm license and retained deliverables; hash and copy the source project and assets.
2. Inventory compositions, dependencies, fonts, effects, plug-ins, and unresolved links without claiming app state that has not been observed.
3. Build a semantic change table: target role, replacement, allowed structural change, visual oracle, and output.
4. Select F0, reproduced A1, or current-build P1 and freeze the acceptance truth label.
5. Update one representative scene; verify crop, scale, line breaks, typography, color, timing, and transition behavior.
6. Obtain sample approval before scaling taste-sensitive changes.
7. Complete remaining replacements with stable IDs and an exception manifest.
8. For retained project state, save, close, reopen, and inspect required objects; validate final renders separately.

**Failure and recovery:** stop on missing fonts, effects, plug-ins, linked assets, ambiguous placeholders, or license uncertainty. Keep the source, working copy, change table, and completed-object manifest. Never silently flatten or substitute a missing effect.

**Record as Skill:** record only a current-build P1 mainline after an unseen template replay. Parameterize project, semantic roles, assets, colors, fonts, compositions, and outputs. Do not freeze layer indices, file names, panel layout, or coordinates.

**CU display:** highlight after O1. The visible story is mapping real brand assets into retained project state and visually verifying the result; file inventory and structured replacement are not CU stories.
