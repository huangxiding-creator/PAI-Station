# B站 CC 字幕渠道逆向报告（bilibili-cc-reverse）

**日期**: 2026-10-24 | **出品**: 总包创研院逆向组 | **红线**: SESSDATA 只存 `data/secrets/bilibili/`（gitignored `data/`），永不进仓永不外发；浏览器数据只读不删；数字零造假。

## 0. 一句话结论
字幕 API 本身零门槛（免登录给 cid，`player/v2` 带 SESSDATA 即出字幕列表），**唯一门槛是登录态**；本机 Chrome 155 时代 v20-appbound + 独占锁双墙使文件收割不可行，落地「官方 Web 二维码登录 API 直驱」方案（generate→poll→Set-Cookie 直接拿 SESSDATA，无浏览器、无解密、用户扫一次码）。

## 1. 端点链路（全部实弹验证）
| 步骤 | 端点 | 登录 | 261024 实测 |
|---|---|---|---|
| cid | `GET api.bilibili.com/x/player/pagelist?bvid=..` | 免登录 | BV1qP4y1T7sd → cid=559015716 code:0 |
| 字幕列表 | `GET api.bilibili.com/x/player/v2?bvid=..&cid=..` | **需 SESSDATA** | 匿名(含 finger/spi 引导 buvid3/4) → `subtitles:0`；带 SESSDATA → 见 §4 |
| 字幕正文 | `GET subtitle_url`（aisubtitle.hdslb.com 等，`//`前缀补 https，Referer=bilibili.com） | 弱 | `{body:[{from,to,content}]}` |
| 登录 | `GET passport.bilibili.com/x/passport-login/web/qrcode/generate` → `poll?qrcode_key=..` | - | 状态机在 **`data.code`**: 86101未扫/86090已扫未确认/0已确认；**SESSDATA 在 poll 响应 Set-Cookie 头**（非 cookie_fields） |

## 2. 本机登录态收割侦察（为什么文件路不通）
| 来源 | bilibili | douyin | 判定 |
|---|---|---|---|
| Chrome `Profile 2` | Cookies 独占锁（CreateFileW share-all → err 32，无 WAL，immutable 直读也失败），持锁者=运行中日用 Chrome | 同（不可读） | 文件路死 |
| Chrome `Guest Profile` | 0 cookies | 0 cookies | 无 |
| Edge `Default` | 7 cookies（buvid3/4、b_nut 等**游客态，无 SESSDATA**），全 v20-appbound | 仅 ttwid（v20，无登录） | 无登录态 |
- Chrome **155.0.8059.85** / `Local State → os_crypt` 含 `app_bound_encrypted_key` → cookie 全量 v20；仓内既有解密件（`tools/browser-forensics/decrypt_360_cookies.py`、`逆向工程/IMA下载助手/tools/dpapi_decrypt.py`）只覆盖 v10/v11 DPAPI+AES-GCM 链 → **v20 不硬破**（同抖音签名不硬破令）。
- 360se 按令跳过。

## 3. SESSDATA 获取方案（三路，均合法本机自用）
1. **Web 二维码 API 直驱**（本件采用，`Temp/bili_cc/qr_login2.py` 临时件）：generate → 屏幕弹二维码（qrcode 库渲染 png）+ 企微通知（tools/notify_approval_wecom.py）→ poll 轮询 → 登录态 Set-Cookie 落 `data/secrets/bilibili/SESSDATA.txt` + `cookies.json`。坑位记录：poll 状态码在 `data.code`（外层 code 恒 0，首版误判）；SESSDATA 在 Set-Cookie 头。
2. 手贴：日用浏览器 F12 → Cookie → SESSDATA 值发给会话/存入同路径。
3. 家法同构件：`ope-engine/tools/qr_login.py`（多平台扫码台，bilibili 会话标记即 SESSDATA，vault 加密入库）——OPE 需要创作者态时走它。
- 复刻件读序：`env BILI_SESSDATA` → `data/secrets/bilibili/SESSDATA.txt` → 匿名(如实 subtitles=0)。
