## 一、战果一句话

**搜狗微信搜索 = 四段纯 HTTP GET 链**，零浏览器、零 JS 执行即可完成
「关键词检索 → 临时链接解析 → 公众号文章全文提取」，唯一门票是 **SNUID Cookie**（检索响应自带），
唯一机关是 `/link` 页把真实链接**拆成 11 段 JS 字符串碎片**。

## 二、API 交互规约（四段全链）

### 段 1 — 预热（取基础 Cookie）

```
GET https://weixin.sogou.com/
→ 200
Set-Cookie: ABTEST=0|<epoch>|v1; path=/
Set-Cookie: SUID=<32HEX>; domain=weixin.sogou.com; expires=+20年
```

### 段 2 — 检索（SNUID 落地 + 结果清单）

```
GET https://weixin.sogou.com/weixin?type=2&query=<urlenc>&page=<N>&ie=utf8
    Referer: https://weixin.sogou.com/          # 必带同域 Referer（zh-search-pro 病理沿用）
→ 200 (text/html)
Set-Cookie: SNUID=<32HEX>; domain=.sogou.com    # ★ 过闸门票，本响应直接下发
```

结果页 DOM 契约（每条 `<li id="sogou_vr_11002601_box_N">`）：

| 字段 | 定位 | 备注 |
|---|---|---|
| 标题 | `a[uigs="article_title_N"]` | 内含 `<em><!--red_beg-->…<!--red_end--></em>` 高亮须剥 |
| 临时链 | 同锚 `href` | `/link?url=<密文>&type=2&query=…&token=<HEX>`；`&amp;` 须 unescape |
| 摘要 | `p.txt-info`（`id=…summary_N`） | 同款高亮标记 |
| 公众号名 | `span.all-time-y2` | |
| 发布时间 | `<script>document.write(timeConvert('<epoch秒>'))` | 服务端给 epoch，本地换算日期 |
| 分页 | `page=N` 参数直加 | 每页 10 条 |

**token 结构（F-6）**：`token = 8HEX + SNUID + 6HEX`（`773A55C8`+SNUID+`ADBE96F`）——
检索页把会话 SNUID 织进每条结果的 token，`/link` 端校验 token↔Cookie 一致性。

### 段 3 — 临时链解析（真·风控机关所在）

```
GET https://weixin.sogou.com/link?url=<密文>&type=2&query=…&token=<HEX>
    Cookie: 同一会话（含 SNUID）        # ★ 缺 SNUID = 302 → /antispider/（F-2 实证）
    Referer: 段2的检索页 URL
→ 200 text/html; charset=GBK           # 注意 GBK 解码
```

响应体形态（856B，三个部件）：

```html
<meta content="always" name="referrer">
<script>
  (new Image()).src='/approve?uuid=<uuid>&token=<HEX>&from=inner';  // ① 埋点信标，可忽略
  setTimeout(function () {
    var url = '';
    url += 'https://mp.';      // ② 真实链接碎片 ×11 段
    url += 'weixin.qq.c';
    url += 'om/s?src=3&';
    ...                        // timestamp/ver/signature 逐段拆散
    window.location.replace(url)  // ③ 100ms 后跳转
  },100);
</script>
```

**解法**：正则 `url\s*\+=\s*'([^']*)'` 抓全部碎片直接拼接（无需执行 JS），得
`https://mp.weixin.qq.com/s?src=3&timestamp=<epoch>&ver=1&signature=<sig>` ——
**短时效签名链**（实测分钟级有效，解析后须立即取全文）。

### 段 4 — 全文提取

```
GET https://mp.weixin.qq.com/s?src=…&timestamp=…&ver=…&signature=…
    Referer: 段3的 /link URL
→ 200 (~3.5MB HTML)
```

| 字段 | 提取位 |
|---|---|
| 标题 | `var msg_title = '…'` / `og:title` |
| 公众号 | `og:nickname` / `var nickname = htmlDecode('…')` / `#js_name` |
| 发布时间 | `var createTime = 'YYYY-MM-DD hh:mm'` |
| 正文 HTML | `div#js_content` |
| 正文纯文本 | js_content 剥标签 + unescape |
| 配图 | `data-src="https://mmbiz.qpic.cn/…"`（下载需 Referer=mp.weixin.qq.com 防盗链） |
| __biz | `var biz = "M…=="` |
| 永久链 | **签名变体页 `msg_link=''`，不可直接得**（局限，见五） |

## 三、风控机制解码

1. **TLS 指纹门**：裸 curl 会被识别；`curl_cffi impersonate="chrome"` 即过（zh-search-pro 1004 病理沿用，本次再实证）。
2. **会话门（SNUID）**：`/link` 只校验 Cookie 里有没有与本会话 token 匹配的 SNUID。
   probe2 差分实锤：同一 /link URL，无 SNUID 会话 → 302 antispider；有 SNUID 会话 → 200 碎片页。
   **跳过段 2 直接打段 3 必死**——SNUID 只由检索响应下发。
3. **混淆门（碎片拼接）**：真实链接不落在明文 DOM，只在 JS 运行时拼出——防的就是「拿到 HTML 就能 grep」的爬虫。拼接逻辑无加密无校验，静态重组即可。
4. **时效门**：签名链 timestamp+signature 短时效（分钟级）；SNUID 域级长期（expires +1 年）。
5. **埋点**：`/approve?uuid&token&from=search|inner` 为行为埋点，不参与闸门判定（碎片页里它是 Image 请求，缺席不影响段 3 解析）。

## 四、复刻件

`replica/sogou_weixin_api.py`（curl_cffi，零浏览器）：

```bash
py -3 sogou_weixin_api.py "水利EPC"                    # 检索清单（标题/公众号/日期/摘要/临时链）
py -3 sogou_weixin_api.py "水利EPC" --top 3 --page 1   # 前3条全文
py -3 sogou_weixin_api.py "水利EPC" --top 1 --json     # 程序化消费
```

API：`SogouWeixinAPI(throttle=1.5).search(query, page) / resolve(link_url) /
fetch_article(signed_url) / search_and_fetch(query, top)`；antispider 命中抛 `SogouBlockedError`。

实测（1024 三关键词五会话）：检索 10/10 条全解析，账号+日期+摘要+全文+图床链全字段绿；
《EPC总承包合同拆分架构分析》5440 字、《平南县水利EPC预算评审》844 字（全文完整）。

## 五、边界与坑

- `/link` 页 **GBK** 编码；href 内 `&amp;` 须 unescape；标题/摘要含 `<!--red_beg-->` 高亮注释。
- 签名变体文章页 `msg_link=''`：**永久链（__biz/mid/idx/sn）不可直接提取**，须靠搜狗内文搜
  `site:` 或账号主页旁路（后续增强项）。
- 签名链短时效：resolve 与 fetch 必须同批执行。
- mmbiz.qpic.cn 图片有 Referer 防盗链，下载须带 `Referer: https://mp.weixin.qq.com/`。
- 登录墙：`type=2` 文章检索匿名可用；翻页深、高频会触发 antispider（302 即信号，冷却+换新会话重预热自愈）。

## 附录 A — PentAGI(GLM-4.7-flash, flow14/assistant16) 研判结论

**(a) 风控边界研判**
1. SNUID 生命周期：会话期间有效，会话结束即失效。
2. 两级 token：查询 token 页面加载后一段时间内有效；签名 token/签名 URL 时效较长但未实测出具体值。
3. antispider 触发条件排序：①缺失 SNUID ②Referer 不匹配 ③请求频率过高 ④请求参数异常。

**(b) 复刻件加固清单**
1. Cookie 池 + SUID 定期轮换，防单会话指纹沉淀。
2. 限频（复刻件已内置 1.5s+抖动节流）。
3. antispider 命中自愈：自动换新会话重预热（复刻件 `SogouBlockedError` 已预留该路径）。
4. 可观测：请求频率/参数/SNUID 有效期监控。

**(c) 边缘 case 清单**
登录墙（type=2 匿名可用，深翻页另论）｜折叠长文解析｜视频号内容｜mmbiz.qpic.cn 图片
防盗链（须带 mp Referer，复刻件 images 字段已按此约定）｜翻页深度上限待压测。
