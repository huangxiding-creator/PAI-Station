# IDEA_SEED — 总包智库全网传播引擎（自媒体永动机多账号×多平台分发）

- **来源**：用户令（2026-10-19）+ 易媒助手深度逆向 + OSS 调研（RESEARCH_DOCKET/）
- **歧义评分**：2/10（目标明确：复刻多账号管理+多平台分发两能力；成熟后才接产线；以"总包智库"名义全网发布永动机产出）→ 走自主模式，澄清并入提案批准点
- **用户真实意图揣摩**：
  1. 表层：复刻易媒助手两个能力接入永动机
  2. 深层：让永动机产出的每一份内容（文章/视频）**无人值守地铺满所有已注册自媒体平台**，以统一品牌"总包智库"实现极致传播
  3. 隐含约束：账号安全（已注册账号是资产，不可因自动化被封）；成熟度门槛（"非常成熟、完美运行才可接入"= 需要硬性灰度门）；不提 AI 生成（AI表述禁令铁律，发布内容以"总包智库研究团队"名义）
- **核心 JTBD**：当我完成一份报告/视频时，我要它在 24 小时内以平台原生形态出现在我所有自媒体账号上，无需我或任何人工介入，且我能看到每个平台的传播效果。
- **关键事实底座**（已实测）：
  - 易媒助手架构全解（见 易媒助手逆向分析报告.md）：CEF 会话隔离 + 双引擎分发（直连API/DOM自动化）+ 签名插件层 + 类目映射资产
  - OSS 底座已选型：千帆云递（MIT, 19平台, Playwright, 当日活跃）+ biliup + 公众号官方 API 路线
- **成功判用（初版，提案细化）**：一份报告产出 → N 平台发布凭证齐 + 数据回流雷达 + 零人工
