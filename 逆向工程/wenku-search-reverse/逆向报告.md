## 2. 端点规约（全链四腿, 全部实测）

### 腿1 检索 `POST https://wenku.baidu.com/gsula/sula/syncmrecall`

- Headers: 桌面 Chrome UA（129 系）+ `Content-Type: application/json;charset=utf-8`
  + `Referer: https://wenku.baidu.com/search?word=<enc>` + `Origin: https://wenku.baidu.com`
- Body: `{"requests":[{"sceneID":"PCSearch","params":{"word":词,"pn":页,"noCacheMembershipCard":true}}]}`
- 响应: `data.items.PCSearch.result.items[].data` = 17 字段文档卡
  （docID/title<em>高亮/content摘要/fileType 1doc·2pdf·3ppt·4xls·5txt·7epub·16ebook/
  pageNum/sellType/viewCount/downloadCount/copyable/…）+ `extra.total` 命中总数
- 实测: 免登录零 Cookie（BAIDUID 都不用）; 12 条/页; 裸 urllib 放行, CDP 403（BFE 打分）
- 电子书道: params 追加 `fd:11, fdResource:"11"`（书卡, 本链未用）

### 腿2 元数据 `GET https://wenku.baidu.com/ndview/{docId}.html`（侧门）

- view 页对非浏览器指纹 403 → ndview 别名端点实证 200（~100-125KB）
- 载荷: `var pageData = {...}` 内联 JSON（引号/转义感知花括号配平提取, harvest_engine 同型）
- 消费键: `pageData.title` + `pageData.readerInfo.{page, showPage, tplKey, htmlUrls,
  rtcsRangeInfo, bucketNum, rsign, md5sum, storeId, pageInfo}`
- Headers 加 `Sec-Ch-Ua`/`Sec-Ch-Ua-Platform`/`Upgrade-Insecure-Requests` 全套（同源自洽指纹）

### 腿3 type3 全文 `GET htmlUrls.json[].pageLoadUrl`（BOS 预签直链）

- URL 族: `wkbjcloudbos.bdimg.com/v1/docconvert{NNNN}/wk/{storeKey}/...`（本批 1946;
  type1 图源用 896）——**预签名, 无 Acs-Token, 无 Cookie, Referer=wenku 首页即可**
- 响应: HTTP 206 分片 JSONP → 剥壳 `pageJson.body[]` 中 `t=="word"` 节点的 `c` 串拼接
  = **真文字层**（每页 480~660 字实测; 连标点/数字齐全, 与页面渲染文本同源）
- 附带桶: `htmlUrls.png[]`（底图, md/txt 口径不用）/ `htmlUrls.ttf[]`（wkretype 字体, PDF 重建才用）

### 腿3' type1 全文 `GET https://wkrtcs.bdimg.com/rtcs/getbdjson?...`（接线未实弹）

- 参数: `bucketNum`/`pn`(桶首页)/`rn=3`/`range`(3 项 `_` 连接, encodeURIComponent)/
  `rsign`/`dataType=rtcs`/`isWpNote=false`+`md5sum`（**无键名直拼怪癖**）/callback/`_`
- 载荷: JSONP → `document.xml` = 页对象树（c 字符串节点=文本, img c=BOS 对象名）
- 状态: **EPC 语料 0 遇 type1**（18 doc 扫描全 type3）→ 按 SPEC 接线, 实弹验证留白（如实）

### 墙探针 `GET https://wenku.baidu.com/ndocview/readerinfo?...&rn=50` 无签

实测响应: `{"status":{"code":0,"msg":"need to verify pop-up window!"},"data":{"tri_reason":"ymg","tri_cap":true,"svcp_url":"https://seccaptcha.baidu.com/v1/webapi/verint/svcp.html?..."}}`
—— 与 harvest_engine envelope.py 预言的 tri_cap 陷阱逐字段吻合（code:0 不代表成功）。
补页墙定性完成; 不绕（红线: 不破付费墙）。

## 3. 选品律（免费覆盖优先, 绕开 ACS 补页墙）

实测匿名免费覆盖规律（18 doc 样本）:
- 1 页 doc → showPage=1（**满覆盖**）; 2~4 页 → showPage=2~4（本批 2/2、3/3、4/4 全满覆盖出现）
- ≥5 页 → showPage=1~2（部分覆盖, 如 16 页 doc 只给 2 页文字层）
- BAIDUID 设备 cookie 对 showPage **无增益**（带 cookie 对照 1/4 不变）→ 免费额度=服务端策略位

选品序: syncmrecall items 按 pages 升序 → ndview 判 `showPage>=page`（满覆盖）→ type3
逐页文字层 → ≥120 非空白字门槛（滤封面/水印页）→ 计入全文; 不满覆盖默认不落盘
（`--include-partial` 可开, 台账恒如实记 cover）。
