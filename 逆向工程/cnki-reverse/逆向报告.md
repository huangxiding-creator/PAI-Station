# CNKI 知网检索面逆向报告 — search.cnki.com.cn 老版免登录通道全解

日期: 2026-10-24 | 工作区: E:/AI-Station/逆向工程/cnki-reverse/ | 复刻件: replica/cnki_api.py

## 一、结论速览

**找到了稳定免浏览器免登录的检索/题录/摘要通道, 验收 5/5 独立会话全绿:**

| 腿 | 端点 | 状态 |
|---|---|---|
| 预热 | `GET search.cnki.com.cn/Search/Result?content=<kw>` | 200, 换取 `SID_search` 会话 cookie |
| **检索** | `POST search.cnki.com.cn/search/listresult` | **200 text/html, ~100KB/页, 20条/页** |
| 摘要(期刊) | `GET www.cnki.com.cn/Article/CJFDTOTAL-XXXX.htm` | 200, 【摘要】块 ~128字(免费面) |
| 摘要(报纸) | `GET mall.cnki.net/magazine/article/CCND/XXX.htm` | 200, paragraph 导语块 ~125字 |

1024 战役"四路全死"的根因是**打错了路径层**: 前端 `Page()` 函数调 `/api/search/listresult`
(openresty 403), 但同站还保留着旧函数 `Page0()` 调的 **`/search/listresult`(小写, 无 /api/ 前缀)——
这条腿完全裸奔, 纯 requests 直连即通, 无需 TLS 指纹伪装、无需滑块、无需登录。

## 三、可用 API 规约 (实测, probe3/probe9)

### 1) 预热 (必须, 缺 SID_search 时未验证直 POST 是否存活——复刻件按先预热实现)
```
GET https://search.cnki.com.cn/Search/Result?content=<url-encoded kw>
→ 200 text/html (41KB 壳页), Set-Cookie: SID_search=...
```

### 2) 检索 (核心腿)
```
POST https://search.cnki.com.cn/search/listresult
Content-Type: application/x-www-form-urlencoded
Referer: https://search.cnki.com.cn/Search/Result?content=<kw>
Origin: https://search.cnki.com.cn
X-Requested-With: XMLHttpRequest
Cookie: SID_search=...

Content=国际工程 EPC&Order=2&Page=1
→ 200 text/html (~100KB, 20条/页)
```
- **字段**: `Content`(全文,命中面最宽, EPC 例 total=144901) / `Title`(篇名, total=22085, 高精度)
  / `Author`(作者, 实测通) / 其余前端可见字段(Theme/KeyWd/Originate/Summary/PublishTimeBegin/End)同型
- **Order**: 2=相关度(默认), 1/3=其他排序(实测均 200)
- **Page**: 1 起, 深翻页 Page=10 实测无墙
- 总数/总页解析: `$("#totalcount").html("144901")` + `$("#hidTotalPageCount").val("7246")`
- **禁止带 `/api/` 前缀**: `/api/search/listresult` 与 `/api/fileterresultapi/articlefileter`
  均 openresty 403 (probe2/probe3 各 4 组实证, 与参数多少、GET/POST、Referer 无关)

### 3) 列表项字段映射 (searchArticle.js renderItem + captures/C1 实测)
| 字段 | 来源 | 例 |
|---|---|---|
| title | `<a title="...">` 属性(免高亮污染) | 汇率波动背景下海外EPC项目成本风险协同管控机制研究 |
| authors | `data-key` @ `href=...?author=` 锚 | 杨丽元 |
| journal | `《...》` 或 报纸 `<span title="成都日报">` | 国际商务财会 / 成都日报 |
| year_issue | `<span>2026年20期</span>` 或 `<span>2026-10-23</span>` | 2026年20期 |
| doc_type | 尾部裸 `<span>期刊</span>`; `/CCND/`→报纸 | 期刊/报纸 |
| keywords | info 块 `<a data-key=...>词</a>` | 政府投资/医疗卫生项目群/代建管理/适配性治理 |
| snippet | `<p class="nr">` 列表自带摘要片段 | ~100-200字 |
| detail_url | `//www.cnki.com.cn/Article/CJFDTOTAL-*.htm` 等 | 免费详情页 |

### 4) 详情页摘要 (免费面)
- 期刊/会议: `【摘要】：`块 → ~128 字, **服务端截断**(免费面原样; wap 触屏 404 实证拿不到更长)
- 报纸: `div.paragraph > div` 导语 → ~125 字 + `（共N页)`
- 列表 snippet 与详情摘要长度相当, 批量场景可只用列表腿(1 req/20条)省详情腿
