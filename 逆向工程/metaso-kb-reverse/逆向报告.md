## 1. 登录端点规约 (第一层)

```
POST https://metaso.cn/login
Headers: token: <meta-token>  (GET / 首页 <meta id="meta-token">)
         content-type: application/json; cookie面: tid(uuid4)/_nb_ioWEgULi("")/aliyungf_tc/JSESSIONID
Body:    {"login_by":"account", "account":"<手机号或邮箱>", "pwd":"<RSA密文base64>"}
```
- **RSA**: 前端 chunk 41209 内置 1024-bit 公钥 (PKCS#1 v1.5, JSEncrypt 同构; pycryptodome `PKCS1_v1_5` 实测同构), 公钥全文见复刻件 `RSA_PUB`
- 响应语义: `{code:0}`=成功(会话入 cookie `sid`); `{code:1003}`=账号或密码不正确; 滑块=2704 (不破)
- 手机号注册性判别: `POST /verify?type=login_sms {"phone":"86-<手机号>"}` → `{code:2701,"手机号不存在,请先注册!"}`=未注册(不发短信); 已注册则发短信 (本件**永不代收**)
- 双 UI 实证: 桌面 SingletonLoginDialog (chunk 7060) 与旧弹窗 (chunk 41209) 走同一 `POST /login`; 桌面弹窗提交前有 Cloudflare 人机验证客户端闸 (`/api/cloudflare/verify`), **不附加于 /login 请求本身** — 纯HTTP面无此闸

## 2. 检索 API 规约 (第二层) — 匿名公开面

```
GET https://metaso.cn/api/knowledge/{sid}/search
    ?s=<关键词>&parentId=&pageSize=30&pageIndex=0
Headers: token: <meta-token>; referer: https://metaso.cn/subject-v2/{sid}
Resp: {"errCode":0,"data":{"content":[{"id","fileName","size","pages","parentId",
       "topicId","createTime","updateTime","contentType","originalUrl",...}],
       "totalElements":25538,"totalPages":1277,...}}
```
- **实测**: 关键词 EPC/工程/研报/合同/水利 各 20+ 命中 (EPC 总命中 25538→缩至词面 ~2.5万文件库)
- 坑: 带 `sort=updateTime` 时多词 `s` 被当短语 → 空结果; 无排序语义时省略 sort
- 文件元数据 (匿名可用): `GET /api/file/{fid}/meta` → {id,fileName,contentType,parentId,...}; `GET /api/file/{fid}/pdf/status` → {size}
- owner 专属面: `GET /api/file/{fid}/folder` (目录树, 匿名=404 没有权限); `GET /api/knowledge/{sid}/failed-files`; `GET /api/knowledge/detail/{rootId}`

## 3. 下载 API 规约 (第三层) — owner 面

```
① GET https://metaso.cn/api/file/{fid}/ticket
   → {"errCode":0,"data":"<ticket串>"}     (匿名 → 4401 岛主暂未开放下载权限)
② GET https://files.metaso.cn/api/file/{fid}/stream-download?ticket=<urlencoded>
   → 文件字节流 (浏览器即 <a href> 直下; metaso.cn 同路径亦可)
③ 批量: POST https://files.metaso.cn/api/file/batch-download  {"ids":[fid,...]} → zip blob
④ 预检: GET /api/file/{fid}/check-download-size | POST /api/file/check-download-size {"ids":[...]}
⑤ 预览(阅读面, 订阅墙): GET /api/file/{fid}/preview → 匿名 4402 "完整体验请订阅"
```
- 文件主机 `files.metaso.cn` = 前端 `getPdfHost()` 实证 (tT 函数: metaso.cn 域 → files.metaso.cn)
- 下载链形态 = **签名直链** (ticket 一次性参数), 非分片
- 4401/4402 为 owner 权限语义 (岛主=专题所有者): 本专题 owner 关闭了公开下载/完整阅读 — 用户以 owner 登录后本链即通
