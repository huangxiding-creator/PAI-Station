## 三、功能架构全景（逆向还原）

```
用户（WPS 侧边栏「AI排版」/触发词）
  │

  ├─【严格品类】合同/标书 ──→ ai_typeset(mode=category)      ← 服务端品类默认
  ├─【格式要求】四品类 ────→ ai_typeset(mode=rule, rule_file/rule_string)
  │        │                   rule_mode=model_essay 走范文仿排
  ├─【格式要求】通用 ─────→ strict 直出 oplist（本地 Agent 流，见⑤）
  ├─【试卷】────────────→ exam 格式规范生成（specs/*.json）→ 排版

           + wps.overview() 骨架（B源）→ 双源合并裁决 → formatList{tag: data-id[]}
```

## 七、差异与边界（诚实声明）

1. **结构识别差距**：原厂 A 源是云端引擎（KFormatTags，含 splitHints/编号列表/实体识别），
   复刻件为本地启发式（样式/大纲级别/编号正则/封面-称呼语-落款规则/列表退让）。常见文体实测
   识别正确；极端花体文档可能误判，可用 --mode/--preset 人工纠偏。
2. **模板库未搬运**：原厂公文 16 文种、各校论文模板存于云端（sha256 校验下载）；复刻以国标
   参数等价实现（GB/T 9704 / GB/T 7713），学校专属模板需另行制作 preset。
3. **格式支持**：仅 .docx/.dotx（python-docx 限制）；原厂另支持 .doc/.wps/.wpt（私有引擎）。
4. **未实现件**：范文仿排（rule_mode=model_essay）、试卷自动出规范（exam spec 生成器，规范
   JSON 已归档可后续接）、update/delete TOC 域、多节分节页码（罗马/阿拉伯分段）。
5. **TOC 页码需域刷新**：TOC 为标准域，Word/WPS 打开后 Ctrl+A→F9（或打印预览）刷新页码——
   与原厂行为一致（原厂同样依赖域刷新）。

## 9.1 WI-002 模板容器解密——完整密码学链破城（breakthrough）

**容器格式（全链实证）**：
```
文件 = 12B ASCII 魔数（"225f8didjBaA" / "ACE4ksmg7AJf"）
     + base64 正文 → 解码得 blob
blob = 7B 内层头 + AES-128-CBC 密文（len ≡ 0 mod 16）
密文 = blob[7:]，key = "5FE71BD15A854390"(ASCII 16B)，IV = "96D8FDE5E10A6321"(ASCII 16B)
明文 = [23B 前导] + 标准 zip(docx)   ←（首块 16B 因 IV 释读差异损坏，zip 自 PK\x03\x04 雕出无损）
```
密钥来源：Ghidra 反编译 kwpsaitypeset.dll **FUN_10013020**（0x10013020）——两段 16B 混淆串
`@i}\x18\x11:\x12\x11@N\x04@Tho%` / `o,\x12\x04i\x12}@}\x11%N,h|\x11` 经
`b[i]=((b-0x6c)*0x13) mod 0x7f`（负数补 0x7f）反混淆（手算复验一致）。
