# 排版规范生成指南

本文档指导 Agent 在执行试卷排版前，如何根据用户需求生成自定义的排版规范（format-spec.json）。

有两种排版模式：

1. 按照默认格式规范排版。排版服务将会使用内置的格式规范帮助用户排版，无需指定任何格式规范。
2. 按指定格式规范排版。根据用户的描述，生成排版规范后发起排版服务，服务按照这个规范执行排版。

## 工作流程

用户提出排版需求后按照以下路径决策：

- 如果 诉求中包含格式描述
  - 如果 包含详细的格式信息，比如“正文使用宋体 小四号字”
    - 阅读**格式规范生成说明**章节，按照用户诉求生成规范，最后执行按指定格式规范排版
  - 否则如果 包含宽泛的描述，比如“按照高考试卷标准帮我排版这份试卷”
    - 按照用户的描述寻找规范，于用户对齐后再阅读**格式规范生成说明**章节、生成规范，最后执行按指定格式规范排版
- 否则 无需阅读格式规范说明、不指定排版规范，按默认规范排版。

## 常见问题

### Q: 用户只提出了部分需求，比如“正文使用四号字、宋体”，我应该如何生成规范？

这是很常见的场景，用户基本上只会提出少量要求，你只需要确认文档的科目后，基于**内置格式规范实例**中的案例微调即可，没有提到的不需要修改。

### Q: 我能指定哪些内容的格式，不支持的内容怎么处理？

试卷排版时支持定制的内容要素见[内容要素说明部分](#内容要素说明)，不支持的需要你先记录下来，后续通过其他工具自行实现。

### Q: 元素只需要改字体，需要写完整的 rPr 吗？

不需要。只写要覆盖的属性：

```json
"examTitle": {
  "baseStyle": "titleLarge",
  "rPr": { "rFonts": { "eastAsia": "楷体" } }
}
```

### Q: 元素引用了一个不带 wordStyleName 的样式，格式清理会生效吗？

会。引擎会沿 `baseStyle` 链向上查找 `resetFormat` 或 `wordStyleName`。例如元素引用 `boldSmall`（无 `wordStyleName`，但有 `resetFormat: "auto"`），引擎会找到该声明并执行清理。如果 `boldSmall` 也没有声明，引擎继续查找其 `baseStyle`（如 `base`），只要链上任何一层有 `wordStyleName` 或 `resetFormat`，清理就会生效。

### Q: 在样式上声明 resetFormat 有什么效果？

样式上的 `resetFormat` 会被引用该样式的所有元素自动继承。适合需要统一格式清理策略的场景：

```json
"styles": {
  "boldSmall": {
    "baseStyle": "base",
    "resetFormat": "auto",
    "rPr": { "rFonts": { "eastAsia": "黑体" }, "sz": 21, "b": true }
  }
}
```

此时所有 `baseStyle: "boldSmall"` 的元素无需重复声明 `resetFormat`，引擎会沿样式链找到 `boldSmall` 上的 `"auto"` 并执行链式清理——解析完整继承链上的所有 `pPr`/`rPr` 属性，全部清除后再写入新格式。元素可通过自身的 `resetFormat` 覆盖继承的值。

### Q: baseStyle 可以引用其他元素吗？

不可以。`baseStyle` 只能引用 `styles` 中定义的命名样式，不能引用其他元素。

### Q: 如何为某个特定学校定制规范？

复制对应的 standard 模板，修改差异部分，保存为新的 spec 文件即可。

### Q: option 的 tabs 数值怎么确定？

tabs 的数值表示每个选项起始位置的字符坐标，以`[1.5, 11, 20, 29]`为例：

- 有四个制表位，意味着一行最多放置四个选项
- 每个选项前添加制表符，让选项从对应的字符坐标处开始
- 如果一行放不下4个，会降级，这个由格式化程序内部处理，无需额外关心
- 间隔确定原则参考：一般A4纸张是40个字符，均分后是每个选项10个字符的空间：`[0,10,20,30]`
  - 但如果第一个选项不是从0字符开始，可用空间就少了，这时每个选项分配9个字符：`[2, 11, 20, 29]`

**注意**：如果只使用两列，应该最大化利用空间，tabs的值为`[1.5, 20]`，而不是`[1.5, 11]`，后者会导致右侧有大量空白
