# 不同要素格式关联关系说明

本文档说明 spec 中不同字段之间的关联关系。编写 spec 时需要注意这些关联，以避免格式冲突或意外效果。

## 视觉对齐关联

### option.tabs 首值 ↔ question.title 缩进

#### 目标效果

选择题的题干和选项需要在视觉上左对齐——即题干正文的起始位置与选项的起始位置处于同一垂直线上。以下示意图中 `|` 标记的是内容起始位置（距页面左边缘 1.5 字符）：

```
正确效果（对齐）                    错误效果（未对齐）

  1. 已知函数...                    1. 已知函数...        ← 题干从0.5字符处开始
     |                               |
     |其中a>0...                     |其中a>0...
     |                                |
     |A.选项A  B.选项B               |A.选项A  B.选项B   ← 选项从1.5字符处开始
     |C.选项C  D.选项D               |C.选项C  D.选项D
      ^                               ^
      1.5字符处                       选项与题干不对齐
```

#### 对齐原理

选择题选项的排列方式受 `option.tabs` 控制，如 `[1.5, 11, 20, 29]`。首个值 `1.5` 意味着每个选项段落从 1.5 字符处开始。

题干段落与选项段落共享相同的左边缘，因此 **题干（`question.title`）的缩进必须与 `option.tabs` 首值匹配**。

三个属性配合实现不同段落类型的对齐：

| 段落类型 | 应用的属性 | 作用 |
|---------|-----------|------|
| 首段（含编号） | `tabs=[1.5]` + `hangingChars=150` | 编号后 tab 跳到1.5字符位；续行也保持1.5字符缩进 |
| 非首段 | `leftChars=150` | 整段从1.5字符处开始 |

#### 配置示例

```json
{
  "question": {
    "title": {
      "pPr": {
        "ind": { "leftChars": 150 }
      },
      "firstParagraph": {
        "pPr": {
          "tabs": [1.5],
          "ind": { "hangingChars": 150 }
        }
      }
    }
  }
}
```

属性详解：

- `question.title.firstParagraph.pPr.tabs=[1.5]`: 给首段添加一个1.5字符的制表位。
  - 首段一般会有自动编号，自动编号与内容的间距一般会使用"制表位"，也就是首段内容的第一个字符会从段落内第一个制表位开始。
  - 添加1.5字符的制表位意味着首行会有1.5字符缩进的效果，可以对齐选项段落
- `question.title.firstParagraph.pPr.ind.hangingChars=150`: 题干首段从第2行开始应用1.5字符缩进
  - 自动编号+制表位只控制了第一行的缩进，如果首段有多行，第2行开始是没有缩进的，所以必须通过`hangingChars`设置后续行的缩进，从而实现对齐。
- `question.title.pPr.ind.leftChars=150`：题干所有段落默认设置文本前缩进1.5字符。
  - 在上面的定义中，首段不会使用这个设置，因为首段有单独设置。
  - 当题干段落大于1时，首段之外的段落会应用这个设置，产生1.5字符缩进的效果

#### 数值对应关系

`option.tabs` 首值与各缩进属性之间的数值换算（以 1.5 字符为例）：

| 配置项 | 值 | 含义 |
|--------|-----|------|
| `option.tabs[0]` | `1.5` | 选项从 1.5 字符处开始 |
| `question.title.firstParagraph.pPr.tabs[0]` | `1.5` | 首段制表位 = 1.5 字符位置 |
| `firstParagraph.pPr.ind.hangingChars` | `150` | 1.5 × 100 = 150（OOXML 单位：字符×100） |
| `pPr.ind.leftChars` | `150` | 同上 |

> 规则：`tabs` 的值单位是"字符"，`ind` 的 `*Chars` 值单位是"字符×100"。两者必须表达相同的字符数。


#### subQuestion.title 缩进

`question.title` 影响全文所有一级题目题干的缩进，而二级以及更深层级的题目，题干格式由 `subQuestion.title` 控制。当调整了 `question.title` 中的缩进设置后，必须检查 `subQuestion.title` 中缩进的设置，确保其缩进值不能小于一级题目题干的缩进。

##### 层级关系示意

一级题目和二级题目的编号方式不同，导致缩进配置不同：

- **一级题目**：编号悬挂在缩进区域外（编号在左、正文在右），需要 `tabs` + `hangingChars`
- **二级题目**：编号随段落整体缩进（编号和正文一起右移），只需 `leftChars`

**关键点**：所有缩进都是基于**页面左边缘**的绝对位置。二级题干的续行和选项段落的左边缘与二级题干的**编号左边缘**对齐。

```
页面左边缘
│
│◄─ 1.5字符 ─►
│
│ 1. 一级题干首行内容...             ← 编号"1."在0处，正文从1.5字符处开始
│    一级题干续行内容...             ← hangingChars=150，从1.5字符处开始
│    A.选项A  B.选项B                ← 选项从1.5字符处开始
│    C.选项C  D.选项D
│
│    (1) 二级题干首行内容...         ← 编号"(1)"从1.5字符处开始，正文紧随其后
│    二级题干续行内容...             ← leftChars=150，与编号"(1)"左边缘对齐
│    A.选项A  B.选项B                ← 选项与编号"(1)"左边缘对齐
│    C.选项C  D.选项D
│    ^
│    页面1.5字符处（所有二级内容的起始位置）
```

> 注意：二级续行和选项的左边缘与编号"(1)"的左边缘对齐，而非与编号后的正文对齐。缩进值基于页面左边缘，不是一级题目的缩进位置。

##### 配置示例

在上方例子中，一级题目题干设置了 1.5 字符的缩进，`subQuestion.title` 也必须设置 1.5 字符的缩进：

```json
{
  "subQuestion": {
    "title": {
      "pPr": {
        "ind": { "leftChars": 150 }
      }
    }
  }
}
```

属性详解：

- `subQuestion.title.pPr.ind.leftChars=150`：二级及以后题目题干所有段落默认设置文本前缩进1.5字符
