# Template Search Guide

## 执行工具
**必须**使用 `wps_toolcall_fmt` 工具调用 `search_template` 方法检索模板。工具签名见 `references/tools/wps-toolcall-fmt.md`。

## Core Rule

禁止把用户原话直接当作模板搜索关键词。必须先理解用户意图，再提炼、补全、发散关键词。

**调用搜索前**：确认需求属于「系统模板库」场景（见下文 §When To Search）。若用户要按**附件/范文**  排版，**不得**调用搜索。

## When To Search System Templates

以下场景优先使用模板搜索：

- 用户说“按照某大学模板排版”
- 用户说“用某学校本科/硕士/博士论文模板”
- 用户说“用通知类公文模板”“按批复格式排版”“按函的模板排版”
- 用户只给学校简称、机构简称、模板关键词，但意图明确是排版
- 文档具有学校、机构、品类信息

## Keyword Construction

### 1. Extract Core Entities

优先提炼学校名、机构名、模板类别、文种或学位层次。

示例：

- “按北大的模板排版” -> `北京大学`
- “用武大本科的论文模板” -> `武汉大学`、`本科`
- “按通知类公文模板排版” -> `通知`

注：按学位层次检索，可能会减少出非常多的模板，需要结合主体(校名)进行过滤。

### 2. Expand Common Abbreviations

对简称做全称补全，提升召回率。

示例：

- `北大` -> `北京大学`
- `清华` -> `清华大学`
- `武大` -> `武汉大学`
- `中科大` -> `中国科学技术大学`

若简称存在歧义，可以发散成多个候选词。

示例：

- `交大` -> `上海交通大学`、`西安交通大学`

### 3. Add Related Synonyms When Needed

当用户描述模糊时，可扩展近义表达，但仍要围绕模板意图。

示例：

- “国家机关的公文模板” -> `国务院`、`中央`
- “政府通知模板” -> `政府`、`通知`

### 4. Use Multiple Keywords

搜索支持多个关键词，最多 10 个。必要时可一次传入多个候选词提升召回率。

## Template Kind Mapping

模板搜索时需要推导模板类型：

- 论文、学位论文、本科、硕士、博士、大学、学院、学校等场景 -> `template_kind=5`
- 公文、通知、批复、函、政府、机关等场景 -> `template_kind=4`
- 无法判断时默认按论文模板搜索，即 `template_kind=5`

## How To Search

调用搜索（见 `references/tools/wps-toolcall-fmt.md`），失败重试 1 次。

## Search Result Handling

### Exactly One Result

- 搜索**原始**仅 1 个，或经下方 §Multiple Results 语义预筛选后仅剩 1 个：直接使用该模板
- 把模板 ID 和模板名称带入排版阶段

### Multiple Results

- 多个检索关键字时，出来的结果是每个关键词的并集。需要基于文档上下语义进行过滤，过滤掉无关的干扰选项，仅保留精确匹配的，若预筛选后仅剩1个且**完全匹配**用户需求，按照`$Exactly One Result` 处理。
例如：[武汉大学][本科]-->出来武汉大学及大量本科论文模板-->过滤预期为`武汉大学并且是本科论文`，[通知][公文]-->出来通知和公文主体-->过滤预期为`通知`。
- 超过5个选项，给出语义最接近的5个选项，其他**搜索出的**选项**不**出现，太多选项一大排列出来用户体验不好
- 过滤后有多个候选项，必须暂停并让用户选择(ask_user)模板
- 本轮只做提问，不继续排版

### Zero Results

- 告知用户没有找到匹配模板
- 不要编造模板

## System Template Vs Sample File

- 系统模板适用于用户给出学校、机构、文种、模板关键词的场景
- 范文文件适用于用户明确提供参考文档的场景

## Suggested User-Facing Questions

若需要暂停询问，使用自然语言，不暴露内部术语。可以参考：

- “找到多个匹配的模板，您想用哪一个？给用户模板选项。”
- “暂时没有找到匹配的模板，您可以换个关键词。”
