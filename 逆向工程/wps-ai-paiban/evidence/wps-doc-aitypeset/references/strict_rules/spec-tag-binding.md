# scope → formatList tag 绑定表（strict）

将规范 txt 或用户录入格式要求中的 **scope** 绑定到待排版文档 `formatList` 的 `source.tag`。

## 使用方式

1. 提取 **scope**（冒号前 / 分节标题 / 用户要素名）和 **para_text**（仅规范文件路径：气泡指向段；用户录入可省略）；规范路径下 `[气泡M→段K]` 后整段记为**气泡标注原文**（排除条件列与 §排除规则 全文检索用）
2. 查下表 → `source.tag` 或 toc level（§层级映射）；用户录入仅用 scope 列，规范路径联用 para_text 特征 / 排除条件列
3. `source.tag` 非 `—` 时须 ∈ 当前 `formatList`；无法匹配对照表行 → 不绑定

> - **source.tag**：绑定到的 `formatList` 键；`—` 表示本表无对应 tag  
> - **para_text 特征**（仅规范文件路径）：气泡指向段（para_text）应满足的特征，与 scope 联用消歧

### 层级映射

- **正文区域标题**：按规范出现的层级顺序从高到低映射 `catalog_h1`~`catalog_h4`，**忽略名称中的数字**。
- **目录区域条目**（无 `source.tag`）：映射 **toc level** `1`~`3`（对应目录 1 / 2 / 3）；规范只写「目录项」未分层级时三级共用同一描述；规范只写一级时三级均套用该一级描述；笼统描述（「其余标题」「次级标题」）填补未单独定义的较低层级。

## 排除规则

| 场景 | 处理 |
|------|------|
| 气泡指向段含「目录」但 scope 写「一级标题」 | 不绑 `catalog_h1` |
| 无 `→` 的浮动气泡 | 不绑 tag；进 `spec-txt-to-oplist.md` §直出 oplist（共用） |
| 气泡标注原文以「空N行」「前后分别间隔」开头 | 不绑 tag |
| 气泡标注原文含「上标」且无字体信息 | 不绑 tag |
