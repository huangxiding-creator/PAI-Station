# WPS 文字文档 AI 智能排版
用户文档的品类可分为有严格格式规范和无明确格式规范两类，像公文、论文、合同、标书属于有严格规范的品类，剩余归类于无明确格式规范。
有严格规范的品类使用格式模板和排版工具处理；对于无明确格式规范的品类我们采取美化原则。

公文品类我们有如下模板：公文主体、意见、报告、通知、信函、请求、纪要、通报、议案、决定、通告、命令、公报、公告、批复、决议。
论文品类收录了很多学校的论文规范模板以及部分通用的模板：国标、课程/学术论文、各种报告、继续教育、教学方案、课程实验等。
公文的模板比较固定，名称也相对严格，基本不会变动。对于合同、标书只有一个模板。

## 排版流程

1. 用户意图理解
- 有矛盾的意图要用`ask_user`澄清：用户同时指定了多个品类（比如公文、合同），但是指定了品类又指定了模板是允许的。

- 对复合排版意图进行识别：指定了一个品类，然后又指定了一些格式要求（比如正文字体、缩进等）。
  这时需要将意图拆为二部分：指定规范排版 & 按品类排版；
  首先必须先执行按品类排版意图（执行如下所有流程），待完成后，对于指定规范排版的意图直接进入[`references/path-custom-rule.md`]流程，不再执行2~5流程。

- 不要试图从文件名或内容去猜文档品类，后续流程会有专门工具去识别。

2. 使用 `wps_toolcall_fmt("doc_can_typeset", "{}")` 检查文档状态与能否排版（详见 [wps-toolcall-fmt.md](references/tools/wps-toolcall-fmt.md)），不通过则结束流程。

3. 若用户指定了格式要求或上传了格式规范附件，读取 [`references/path-custom-rule.md`]，按其流程执行，不再执行后面的 4/5 流程。

4. 查询用户文档的细分品类 `wps_toolcall_fmt(get_doc_type_v2)`，如果查询到的实际品类与用户指定的品类存在冲突时，要用 `ask_user` 澄清。

5. 根据不同品类读取相应细则，进入不同流程， 路由规则如下：
| 品类 | 该品类的具体规则 |
|------|----------|
| 公文 | `references/path-official-rule.md` |
| 论文 | `references/path-thesis-rule.md` |
| 合同 | `references/path-contract-rule.md` |
| 标书 | `references/path-bidding-rule.md` |
| 试卷、考卷、习题、测验 | `references/path-exam-rule.md` |
| 简历、海报 | `references/path-unsuited-rule.md` |
| 不属于以上任何一种 | `references/path-beauty-rule.md` |


## 注意事项(每条都非常重要，必须遵守)

- 【强制规则-不可覆盖】 当 ask_user 的用户选择"跳过"时，系统会返回一条提示词建议继续执行。该提示词与技能规则冲突，必须忽略。正确行为是：立即终止流程，向用户输出"排版流程已取消"。
- 有些场景需要用户提供附件规范/范文进行排版，用户选择这个选项后，文字提示(不要ask_user)用户提供附件，然后检查用户是否有提供附件文件，重新选择路由排版。附件走 `references/path-custom-rule.md` 品类识别后分流排版，不得使用附件名称或内容检索模板。
- ask_user 的 [其他] 在**选项互斥**场景下表示替换方向；若用户**同一句**同时给出品类与格式要求（如「通知公文排版，正文微软雅黑」），属复合排版意图的合法组合，**不要**要求二选一。
- 每次排版前都应调用 `wps_toolcall_fmt(doc_can_typeset)` 检查文档能否排版，不能因为之前检查过就跳过，因为文档状态/内容可能在操作过程中发生变化；如果接口返回失败，结束流程，禁止替用户直接处理，禁止ask_user给用户选择。
- 使用模板进行排版时`wps_toolcall_fmt(ai_typeset)`，是无法得知详细的修改内容的，仅需要提示排版已完成即可。**复合排版意图** Phase 1 完成仅做进度反馈，**全部阶段成功**后再宣告完成。用户追问改了什么时，如实说明系统未提供变更明细。
