## 二、关键判例（本役实证，可复用）
1. **官方 agent CLI 常是开源文档仓+闭源二进制**：克隆 docs 仓摸端点面，沙箱是服务端 by-design，改客户端无用。
2. **抓包 vault 即凭据库**：运行中客户端的 Cookie 头里就有 BDUSS/STOKEN——迁移入 gitignored 密钥库后 vault 覆写为指针（明文清、文件留）。
3. **无头签名≠无签名**：本役实测无任何签名头、query rand/rand2 非强制（8+ 端点零签名放行）——先测「不带签名直接打」，别先啃签名算法。
4. **协议代际漂移必须记台账**：pcs 旧族退役/xpan 中代/api 新代并存；写面与读面存活状态可以不同（分享写面「下线」宣后仍活=漂移账 #15）。
5. **诊断矩阵单变量隔离铁律**：变体矩阵若「全参」与「换 UA」同现一个变体，归因必错（本役 CEF-UA 误判，judge 重放 400→200 证伪）。头条结论入 A 级前必须有独立重放。
6. **熔断/风控码表必须与证据源逐字核对**：31319 vs 31329 一字之差=风控保护静默失效（judge HOLDOUT 抓出）；且测试不得把错值钉死。
7. **错误信使可能不是 errno**：部分数据面端点用 error_code（31023/31024 族）报错——解析层两个都要看。
8. **诊断脚本必须落档原始输出**：自我报告链（docstring 转述数字）不可复核=不算 A 级证据。
9. **kill-续传/秒传/删除确认要有结构性测试**：rm 无 --confirm 必须「结构性不可能触网」（护栏在 API 调用之前）。

## 三、闸门体系（每波出口）
- 离线单测（FakeTransport 打桩全链路，含熔断/降级/护栏）
- 活体冒烟（预算硬帽：控制面逐波 40-80 发；写面围栏 /API复刻测试_<日期>/）
- ss-judge 独立质检（跑单测+代码审计+HOLDOUT 探针+活体抽查 ≤4 发）
- 勘误纪律：DISCARD→就地返工→复测→ERRATA 落档（本役两次 DISCARD 均抓到真雷）
