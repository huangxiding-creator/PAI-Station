## 一、API 规约 (三层)

### ① 搜索层 (题录)
```
GET https://search.dangdang.com/?key=<关键词>&act=input&page_index=<N>
```
- HTTP 307 (http→https) → 200 HTML; **声明 charset=GB2312, 实按 gb18030 解**;
- 关键词编码: GBK urlenc 为原生 (UTF-8 亦收, 实测两者同果);
- 分页: `page_index=N`, 60 题录/页, 页间零重叠 (实测);
- 题录抽取 (均在 `<li class="lineN">` 块内):
  | 字段 | 抽取点 |
  |---|---|
  | pid/URL | `product.dangdang.com/<pid>.html` |
  | 书名 | `p.name > a[title]` |
  | 现价/原价/折扣 | `span.search_now_price` / `search_pre_price` / `NN折` |
  | 评论数 | `a.search_comment_num` "N条评论" (无锚=0) |
  | 作者行/作者 | `a[name=itemlist-author]` (title=整行署名) |
  | 出版社 | `a[name=P_cbs][title]` |
  | 出版时间 | 作者区 `/YYYY-MM-DD` |
- **免挑战**: 连续 70+ 请求 (10 关键词 + 50+ 详情) 零 WAF/验证码; 节流 2.5s+抖动。

### ② 详情层 (简介/作者简介/目录框架/出版信息)
```
GET http://product.m.dangdang.com/detail<pid>-0-1.html
```
- **移动端 m 站 = 免挑战真身** (UA 需 mobile; 桌面 UA 也放行); UTF-8; ~20-90KB;
- 结构两段:
  - `<section data-content-name="图书详情">`: 内联描述 blob, 以
    `【内容简介】【作者简介】【目录】【编辑推荐】【媒体评论】【前言】【书摘与插画】`
    分段; **变体标记**: 部分书用短标记 `【内容】【作者】` (已归一);
  - `<section data-content-name="出版信息">` `ul.parms`: 书名/ISBN/作者/出版社/
    出版时间/页数/字数/开本/纸张/包装 (em=字段, i=值);
- 目录在 blob 内 `<br>` 分行, **不跨页** (`-0-2` 与 `-0-1` 同页实测);
- **并非所有书提供**: 集市副本 (11+位 pid) 页面常只有目录甚至全空;
  自营主品 (6-10位 pid) 内容最全 — 复刻件家族制择优。

### ③ 墙定性 (Aliyun WAF「aliyunwaf」变体)
- `product.dangdang.com/<pid>.html` (PC 详情) 与
  `category.dangdang.com/api/suggest` → 200 但返回挑战页:
  `textarea#renderData {"_waf_<hash>":...}` + `meta[aliyun_waf_aa/oo/00/bb]` +
  外部挑战脚本 `/u21pn7x6/r8lw5pzu/psk8uqfi` + 内联混淆 JS + g.alicdn.com
  `antidom.js` 族 — 与 chinca 的 acw_sc__v2 同族不同代 (cookie 名为 `_waf_*`);
- **未破挑战, 也无需破**: 移动端详情面 (product.m.dangdang.com) 无此墙,
  内容等价 (简介/目录/出版信息全量), 复刻件原生绕行; 若日后 m 端加墙,
  chinca 同法 (Node vm 本地执行站点自带 JS) 可解。

### 反爬面
- 当当当面 (SERP+m 详情) 历史较松属实: 70+ 请求/2.5s 节流全程无墙;
- 内置节流 ≥2.5s+抖动, 单线程, 正常 UA (搜索=桌面, 详情=mobile)。
