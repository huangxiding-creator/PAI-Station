# 当当网图书情报逆向 — 授权与边界 (scope)

## 授权链
1. 用户 1024 全渠道 API 化令:「所有调研搜集渠道」尽量 API 化、避免浏览器自动化。
2. 本条当当专项令 (1024): 把 dangdang.com 图书搜索与图书详情(简介/作者简介/目录框架/出版信息)
   逆向为纯 HTTP API 客户端, 服务研报产线书目情报腿
   (搜书→拿目录框架→为报告章节骨架/知识库结构提供参照; EPC 类: 国际工程/FIDIC/电力EPC/工程索赔/出海)。
3. 追加令 (同日): 破解完成后当当作为新渠道接入调研搜集体系
   (channel_matrix 渠道登记 + api_replica_bridge 注册 + legs/dangdang_leg.py 采集腿 + 台账 + C轴验证)。

## 边界 (只窄不宽)
- **只读 GET**: 全部请求限 GET; 不碰购物车/下单/价格库存接口; 不碰任何写接口。
- **免登录公开面**: 只采未登录可见的公开 SERP 与商品详情页; 不破付费内容
  (当当商品页的内容简介/作者简介/目录本就是营销公开面)。
- **不碰账号体系**: 不注册、不登录、不持久化任何 cookie 凭据; 会话 cookie 仅内存态。
- **节流 ≥2s**: 尊重按 IP 频率限制, 复刻件内置节流 (历史较松仍守 2s 铁间距)。
- **浏览器仅侦察**: 若需浏览器侦察, --start-minimized, 用完即清, 不做数据收割通道
  (红线: 浏览器不必要不开)。
- **删除纪律**: 遵守全站铁律, 本工作区零删除; 生产文件改动前 .bak 备份并逐条记录。
- **数字零造假**: 一切命中数/字数以实测为准。

## 交付面
1. `captures/` — 探针原始证据 (HTML/JSON 响应)。
2. `replica/dangdang_api.py` — 纯 HTTP 复刻件 (搜索/详情/目录三层)。
3. `逆向报告.md` — API 规约 + 墙定性 + 验收实录。
4. 渠道接入: channel_matrix.py 登记 + api_replica_bridge 注册 + legs/dangdang_leg.py + 台账行。
