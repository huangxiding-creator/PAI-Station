## 二、端点规约（全部免登录零 Cookie，实测 200）

「首页 JS 动态无直链」的完整答案是: **列表确实是 JS 动态加载，但接口不是藏起来的**。
首页 `<form id="searchForm" onsubmit="return search_submit();">` 引用的
`static.doc88.com/resources/js/search.js?v=2.50`（21343B）是**未混淆的明文 jQuery
脚本，不是 webpack bundle**——`Search.searchDoc()` 的 `$.ajax` 目标明文可读，
一次静态直读即全部出土（REA analyze_web_bundle 级别的重工具在此无必要: 无打包
无混淆无压缩，grep 即可）。

### 2.1 主搜索（选品端点，本战役定名的核心答案）

```
GET https://www.doc88.com/search/post.do?from=1&f=0&h=1&pageRange=0&pageNum=
    &format={空|PDF|DOC|PPT|XLS|TXT}&p={页码}&q={URL编码关键词}&sDate=&eDate=&ct=0
Referer: https://www.doc88.com/tag/   （首页 Referer 实测亦放行）
→ 200 text/html 片段（jQuery $("#result_content").html(msg) 注入用）
```

- 每页 9~10 条（观察值，以逐页实测 count 为准）；
- `#pageResult` 隐藏 span: 「约有12,179,090篇,以下是第1-9篇」= 总数+本页范围
  （**总数跨分片抖动**: 同词两次实测 12,179,090 vs 18,942,210——搜索集群分片
  口径不一，如实保原文不修数）；
- 条目字段（`div.sd-list-con` 块内）: 标题（`a.sd-title` title 属性）、
  p_code（href `p-{code}.html`）、格式（type 图标+sd-intro「格式：」双源）、
  页数、上传时间、浏览数、**intropath**（`div.sd-con[-cover]` 属性，摘要件路径，
  如 `/2017/05/05/6562828517966.xml.gz`；少数条目缺省）；
- 参数族: `f`=排序（0=相关性）、`format`=格式过滤、`p`=页码、`sDate/eDate`=
  时间过滤、`pageRange/pageNum`=页数区间过滤、`ct`=client（0=web）；
  `t=1728894524` 时间戳实测可省。

### 2.2 姊妹端点（同役出土，search.js 明文）

| 端点 | 用途 | 返回 |
|---|---|---|
| `GET /search/suggest.do?q={kw}` | 输入框联想 | JSON `[{"title":…}]` |
| `GET /search/rk.do?q={kw}&ct=0` | 相关词（tag 扩展） | JSON `{"kwSb":"<li>…HTML"}` |
| `GET /doc.php?act=get_intro&p={intropath}` | **免费文字层** | 文档开头真实正文段（HTML/纯文） |
| `/tag/{kw}` `/ltag/` `/ctag/` `/dtag/` | 搜索落地页（各 client 形态） | 页面（内嵌上述 ajax） |

### 2.3 免费文字层定性（任务书要求的如实判定）

- **get_intro 摘要层 = doc88 公开面上唯一的免登录文字层**: `intropath` 是站方
  摘要件（`.xml.gz` 命名，服务端渲染成文字返回），实测单件 163~234 CJK 字
  （文档开头正文段，非元数据）；
- **坑: 摘要件有名无实**——部分条目 intropath 存在但 `get_intro` 回 **200 空
  body 0B**（站方摘要件不存在，accept_s4 实测 3/6 空）→ 如实挂账换下位候选，
  不重试不硬闯；
- **整本预览 = 图片型 SWF（类文库 type2 形态）**: 页体是 ebt 资产 zlib×2 拼回
  SWF，文字住 DefineSprite——**无免登录纯文字整本层**。整本收割归既有段2/3/4
  管线（`adapters/doc88.py` T24/T27/T32: info 配置→ebt 下载→SWF 合成→FFDec
  frame:pdf 双导出抽字，已在役），本战役不碰。
