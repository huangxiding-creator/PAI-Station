> 静态解（services-D2mwzmR1.js axios 层）× 匿名/登录差分探测

## 一、战果一句话

**洞见研报 = 一个无 Cookie 的 JSON API 域 `api.djyanbao.com`**：检索、卡片列表、
详情元数据、**AI 分析（全文摘要+大纲+图表清单+评分）全部匿名可取**，唯登录态
（`Authorization: Bearer <JWT>`，来自 www 页 localStorage 而非 Cookie）只锁
**签名 PDF 直链**一条腿。零浏览器、零 JS 执行即可完成浏览器版收割腿的全部免费面。

## 二、API 交互规约

### 公共头（全部端点）

```
client-ver: v2.0.14
client-type: pc
client-id: <uuid4>            # 首次随机生成即用, 服务端不校验来源
Origin/Referer: https://www.djyanbao.com
Authorization: Bearer <JWT>   # 可选 — 仅段4必需 (前端 axios withCredentials=false, 零 Cookie)
```

JWT：HS256，payload 仅 `{id:<用户uid>, iat:<epoch>}`，**无 exp**（服务端会话型）。

### 段 1 — 关键词检索 → 卡片列表（匿名 200）

```
GET https://api.djyanbao.com/api/report?page=1&limit=10&q=<urlenc>&sort=publish_at&order=DESC&matchPhrase=false
→ 200 {data:{data:[卡片×N], meta:{itemCount}}, code:0, message:"ok"}
```

卡片字段（20 键）：`id/typeId/businessId/labelIds/targetIds/fileSize/pageTotal/title/
authors/orgName/orgIds/publishAt/uploaderName/indexImageUrl/stockName/isHorizontal/
canConvert/hasDownloaded/highlight/score/reportScore`
- `highlight.content[]` = 命中片段（含 `<em>` 高亮须剥）— 列表页摘要即在此
- `reportScore` = AI 评估评分（网页上「AI 评估评分: 76/100」的本体）
- 分页 `page/limit`；`itemCount` 宽词封顶 10000、窄词给实数（实测「工程造价司法鉴定」=699）

### 段 2 — 详情元数据（匿名 200）

```
GET /api/report/{id} → 200 data = 卡片全字段 + fileUrl(裸OSS链,未签名) + aiStatus + cards
```
`aiStatus`: 4=AI 分析已生成（段3有料）；0=未生成（段3返回 `{}`，数据态非故障）。

### 段 3 — AI 分析 = 免费面核心（匿名 200 ★）

```
GET /api/report/{id}/report-ai-analysis?all=true → 200 data{29 键}
```

| 字段 | 内容 |
|---|---|
| `summary` | **全文摘要**（数百字结构化，浏览器版「详情页可读内容」的本体） |
| `reportBrief` / `aiSearchSummary` | 简报 / AI 检索摘要 |
| `outline[]` | 报告大纲（level1/children.level2 树） |
| `figureTableList` | **图表数据**：`{figures:[{id,title}], tables:[{id,title}]}` 清单 |
| `reportScore` / `fieldConfidence` | 评分 + 分域置信度 `{metadata, classification, content}` |
| `title/institution/date/author/reportType/industry/swclass/topicTags/region/…` | 全套元数据 |

### 段 4 — 签名 PDF 直链（匿名 401 / Bearer 200 = VIP 合法下载面）

```
GET /api/report/{id}/download/info?action=view&format=pdf   [需 Bearer]
→ 200 {fileUrl: "https://storage.djyanbao.com/dj-docs/<hash>.pdf?u=<uid>&t=<ms>&token=<hex>",
       validSeconds: 300}
→ GET 签名链（Referer 带 www）→ 真 PDF（实测 2,520,518 B，%PDF-1.7）— 5 分钟时效, 解出即用
```

### 辅助端点（本轮实证在册）

`/api/report/hot/search`(热搜词) · `/api/report-trending?recommended=true`(选题活水) ·
`/api/paid-report?status=online`(付费报告, 独立计价面) · `/api/category/all`(分类树) ·
`/api/organization/{id}`(机构) · `/api/chart/{id}`(图表库) · `/api/auth/login`(POST 密码登录,
合法刷新口) · `/api/auth/wechat/qrcode`(扫码登录) — 完整 60+ 端点清单见
captures/services-D2mwzmR1.js（bundle 内 axios 服务层）。

### 风控与配额（响应头实测）

| 端点族 | x-ratelimit | 窗口 |
|---|---|---|
| `/report` 检索 | 300 | 3600s |

## 三、前端机制解码（为何旧 cookie 路线全败）

1. **API 与页面分域**：www.djyanbao.com（React SPA，V2.1.0 Tailwind 改版）纯静态壳，
   数据全走 api.djyanbao.com。
2. **认证不走 Cookie**：前端 axios 实例 `withCredentials:false`，登录态 =
   `localStorage['token']`（JWT）注入 `Authorization: Bearer`；`localStorage['uuid']` =
   client-id。⇒ 1015「cookie.txt 仅含统计 cookie 无会话 token」的根因：**会话根本不在 cookie 里**，
   在 profile 的 Local Storage（leveldb）里。
3. SPA 路由：详情页 `report/:id`（React Router 新 tab），点卡片 = 纯前端路由，无服务端跳转。
4. `download/info` 的 `action=view|download` 区分在线看/下载，走 VIP 配额
   （bundle 内 QUOTA_EXCEEDED/CONVERT_NO_QUOTA/DOWNLOAD_LIMIT 三态弹窗逻辑）。

## 五、登录态有效期与刷新法

- 当前 token：iat=2026-10-15，**无 exp**，至 10-24（9 天）仍有效；失效表现 =
  `download/info` 401（免费面不受影响）。
- 状态文件：`replica/djyanbao_state.json`（首跑自动从 `captures/profile_localstorage.json`
  导入；.gitignore 已覆盖，密钥不进仓）。
- 刷新法 A（推荐）：persistent-profile 浏览器登录一次 → 导出 localStorage
  `token/uuid`（本次即此法，CDP Runtime.evaluate 一次取齐）。
- 刷新法 B：`POST /api/auth/login {phone,password}`（凭据=01 账号授权/洞见研报密码登录
  账号.txt；复刻件未内置自动登录，防风控连坐，需要时手动一次）。

## 六、剩余墙（如实）

1. **PDF 全文 = VIP 配额面**：走合法签名链（view/download 均计额），未破、不可破、不在范围。
2. `aiStatus=0` 的旧件/新件无 AI 分析（段3 返回空）—— 数据覆盖墙，非权限墙。
3. `itemCount` 宽词封顶 10000（深翻页限流风险自担，300/h 检索配额）。
4. `reportScore` 覆盖率非 100%（部分卡片 None）。
5. 付费研报（`/api/paid-report`，¥19.90 级）是独立 SKU 面，未逆向（不在授权范围）。
