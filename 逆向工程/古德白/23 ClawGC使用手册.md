# **ClawGC 使用帮助**

ClawGC 是一套 AI 短视频生产流水线。你不用把文案、配音、视频、封面和发布拆到一堆工具里来回搬：给它一个想法、一条抖音或小红书作品链接、一段文案，或者一条已经拍好的视频，它可以继续帮你生成文案、包装视频，并准备标题、封面和多平台发布。

```Plain Text
想法/作品链接/现成文案/现成视频 -> 文案生成或提取 -> 视频生成或包装 -> 准备标题封面 -> 多平台发布
```

你可以手动控制每一步，也可以把任务交给自动流水线，让系统连续完成文案、视频和发布。

## **ClawGC 和 AIGC 有什么不一样**

AIGC 解决的是“内容怎么生成”：生成文字、图片、音频或视频。

ClawGC 更强调“内容怎么被操作起来”：把找对标、写文案、生成视频、准备发布、执行发布和结果反馈放进一条流水线。

这里的 Claw 可以理解为“会把流程往下推进的执行能力”。它不是只给你一段 AI 文案或一条 AI 视频，而是帮你把短视频生产这件事从想法推进到发布。

## **1. 从哪里开始**

### **我有想法**

如果你还没有素材，只是有一个想法或需求，可以从“我有想法”开始，直接写出你想做什么。

例如：

```Plain Text
帮我写一条卖窗帘给年轻人的短视频文案，适合发小红书。重点讲租房卧室改造、遮光好、颜值高，语气不要太硬广。
```

系统会先把你的想法扩写成可朗读的短视频口播文案，再继续生成视频。

适合：

1. 从零开始做一条短视频。

2. 只有产品、观点或主题，还没有完整文案。

3. 想让 AI 帮你补齐选题、结构和表达。

### **作品链接**

看到一条值得参考的抖音或小红书作品，可以把分享口令或作品链接复制进来。

适合：

1. 参考爆款结构。

2. 把同行内容改成自己的表达。

3. 从视频里提取文案，再生成新视频。

推荐流程：

```Plain Text
复制作品链接 -> 提取文案 -> AI 二创 -> 生成视频 -> 发布
```

重点不是搬运原视频，而是保留有效结构，换成你的产品、案例、观点和用户场景。

如果你粘贴的是账号主页，而不是单条作品，建议使用“账号定位分析”。系统判断链接像主页或不完整作品链接时，也可能提示你确认后再继续。

### **现成文案**

如果你已经有一段文案，可以直接粘贴进来，让 AI 优化后继续生成视频。

适合：

1. 已经写好初稿。

2. 从别处整理了一段内容。

3. 想跳过选题环节，直接做成视频。

### **现成视频**

如果你已经有拍好的视频，可以从“现成视频”开始，上传视频或粘贴可访问的视频 URL，然后做标题、封面、包装和发布。

适合：

1. 已经拍好口播、探店、产品展示或素材混剪。

2. 想给原视频补标题、封面、字幕或平台文案。

3. 想把同一条视频包装后发到多个平台。

### **选题控制台**

如果还没有具体链接，也没有明确想法，可以先进入“短视频工作台 -> 选题控制台”找选题。

选题控制台适合配置账号关键词、行业关键词、竞品关键词、对标账号、排除词和最低互动要求。系统会把符合条件的候选视频汇总到候选池，你可以把有价值的视频加入备选、取消，或转成短视频流水线任务。

适合：

1. 每天持续找短视频选题。

2. 监控竞品和对标账号的新内容。

3. 从行业关键词里筛出可二创的参考视频。

4. 先人工确认候选，再转成正式生产任务。

### **账号定位分析**

如果你想先判断一个账号应该怎么做，或想分析竞品账号，可以使用“工具箱 -> 账号定位分析”。

你可以粘贴抖音或小红书账号主页、单条作品链接，或完整分享文案。系统会基于公开数据整理账号资料、作品表现、发布时间规律、内容标签、生命周期曲线、样本表现洞察，并在可用时生成 AI 定位报告。

适合：

1. 分析自己的账号定位是否清晰。

2. 研究竞品账号和对标账号。

3. 找出高表现作品的共性。

4. 为选题控制台和后续内容生产提供方向。

账号定位分析不是直接生成视频的入口。它更适合放在前期调研阶段：先看清账号和内容方向，再把可参考的作品或关键词带到选题、文案和视频生产流程里。

## **2. 手动模式和自动流水线**

### **手动模式**

第一次使用建议先手动跑通一条：

```Plain Text
文案 -> 视频 -> 检查 -> 发布
```

手动模式适合：

1. 第一次熟悉流程。

2. 想精修文案。

3. 想自己判断用动画、白板，还是页面已开放的数字人等形式。

4. 发布前要仔细检查标题、封面、字幕和内容。

### **自动流水线**

如果你已经知道要做什么，并且想批量生产，可以开启自动流水线。

自动流水线适合从“我有想法”“作品链接”“现成文案”“现成视频”继续往下处理。如果你只是用选题控制台找方向，建议先选定一条具体候选视频，再进入后续流程。

流水线会连续处理：

```Plain Text
来源解析 -> 文案生成/二创 -> 视频生成 -> 标题描述生成 -> 发布执行/结果同步
```

适合：

1. 同一个产品每天换多个角度。

2. 同一个账号持续做系列内容。

3. 团队想减少重复操作。

4. 已经有产品库、图片素材或稳定内容方向。

建议先手动跑通 1 条，再用流水线批量做。

## **3. 做流量内容还是带货内容**

ClawGC 既可以做泛内容，也可以做带货内容。两种内容的准备方式不一样。

### **做流量内容**

如果你的目标是涨粉、出圈、获取曝光，可以先不绑定产品库。

适合：

1. 观点内容。

2. 知识科普。

3. 热点解读。

4. 个人 IP 表达。

这种内容重点是选题、钩子、观点和完播率。

### **做带货内容**

如果你的目标是卖货、获客、介绍产品，建议先维护产品库和产品图片。

产品库会保存你的产品信息，例如：

1. 产品名称。

2. 核心卖点。

3. 适合人群。

4. 使用场景。

5. 产品截图、商品图、案例图或实拍图。

选择产品库后，系统会在生成文案和动画视频时自动带入产品信息和产品图片，生成更像“可转化内容”的视频，而不是泛泛讲概念。

适合：

1. 电商带货。

2. 本地门店获客。

3. 课程、咨询、服务介绍。

4. SaaS、工具、软件产品介绍。

5. 一个产品批量换角度测试内容。

简单说：

只是博流量，可以先不选产品库。

想卖货或获客，建议一定选产品库。

### **产品库和图片库怎么准备**

产品库负责保存产品信息，例如产品名称、核心卖点、适合人群、使用场景、价格规格等。

图片库负责保存视频里会用到的视觉素材，例如商品图、实拍图、细节图、对比图、案例图或软件截图。

如果你要做带货视频，建议把产品库和图片库一起维护好。这样生成动画视频时，系统可以把产品信息和图片素材带进去，做出来的视频会更具体，也更适合转化。

图片上传后如果显示“处理中”，说明系统还在分析和整理图片。等处理完成后再用于生成视频，效果会更稳定。

## **4. 视频形式怎么选**

### **数字人视频：适合做人设和信任感**

数字人视频适合让一个固定人物持续出镜讲内容。

数字人能力会按账号和页面开放情况逐步启用。如果你当前页面暂时没有数字人入口，可以先使用动画视频、白板视频或现成视频包装。

适合：

1. 个人 IP。

2. 老板、老师、顾问、主播口播。

3. 高信任、高转化的产品介绍。

4. 需要“有人出来讲”的内容。

如果你要做自己的数字人，需要先准备形象和音色。

形象视频建议：

1. 正面对着镜头。

2. 脸部清楚，嘴巴不要被遮挡。

3. 动作幅度不要太大。

4. 光线干净，背景不要太乱。

5. 如果是卖货，可以手里拿产品或放在身边，但不要挡脸和嘴。

音色录制建议：

1. 在安静房间录。

2. 尽量没有回声和杂音。

3. 最好使用领夹麦或质量较好的麦克风。

4. 语速自然，声音清楚，不要忽大忽小。

### **动画视频：适合产品介绍和带货转化**

动画视频适合把文案变成有节奏的信息动画。

如果绑定产品库和产品图片，它尤其适合做带货视频、产品种草、功能介绍和案例展示。

适合：

1. 产品卖点拆解。

2. 软件、工具、SaaS 介绍。

3. 电商商品种草。

4. 门店服务说明。

5. 用产品图、截图、案例图增强转化。

如果你做的是带货内容，优先考虑：

```Plain Text
产品库 + 产品图片 + 动画视频
```

### **白板视频：适合讲方法和流程**

白板视频是手绘讲解风格，适合把逻辑、步骤和方法讲清楚。

适合：

1. 教程。

2. 方法论。

3. 流程说明。

4. 知识科普。

5. 课程或咨询类内容。

白板视频也可以服务带货，但更适合“先讲清楚问题和方法，再引出产品或服务”。

### **现成视频包装：适合已有成片再发布**

如果你已经拍好或剪好视频，可以直接上传现成视频，选择简单包装或高级包装，再补齐标题、封面、描述和发布平台。

简单包装适合快速补齐发布素材。高级包装适合把原视频和包装画面组合成横版分屏成片：保留原视频人声，同时在包装区域展示字幕和信息画面。它适合口播、探店、产品展示、课程片段等“已经有真人或实拍画面，但还想增强信息表达”的视频。

适合：

1. 线下已经拍好产品、门店或口播视频。

2. 已经有一条可发布成片，只想补发布素材。

3. 想把同一条视频按不同平台重新包装。

## **5. 一个完整例子**

假设你要做“卖窗帘给年轻人”的短视频。

### **如果你要带货**

建议先在产品库里准备：

1. 窗帘名称。

2. 遮光、颜值、安装简单等卖点。

3. 适合租房、卧室改造、年轻人审美等场景。

4. 产品实拍图、安装前后对比图、细节图。

然后输入：

```Plain Text
帮我写一条卖窗帘给年轻人的短视频文案，适合发小红书。重点讲租房卧室改造、遮光好、颜值高，语气不要太硬广。
```

推荐选择：

```Plain Text
产品库 -> 动画视频 -> 生成带产品图片的介绍视频
```

这样生成的视频会更具体，更容易承接转化。

### **如果你要做人设**

如果你的账号已开放数字人能力，可以选择数字人视频，让“设计师”“店主”“家居顾问”这样的角色出镜讲。

适合表达：

1. 我为什么建议年轻人先换窗帘。

2. 租房卧室变高级的三个细节。

3. 买窗帘最容易踩的坑。

### **如果你要讲方法**

可以选择白板视频，讲一个清楚的步骤：

```Plain Text
租房卧室改造三步：先解决遮光，再统一色系，最后用窗帘提升空间质感。
```

## **6. 快速上手流程**

### **从想法生成一条视频**

1. 在首页选择“我有想法”。

2. 写清楚你要做的主题、目标平台、受众和语气。

3. 生成文案后，检查开头钩子、产品信息和表达是否准确。

4. 选择动画视频、白板视频，或页面已开放的其他视频形式。

5. 视频生成后检查字幕、封面、标题和描述，再进入发布。

### **从作品链接二创一条视频**

1. 在首页选择“作品链接”。

2. 粘贴你想参考的抖音或小红书作品链接。

3. 提取文案后，保留结构，改成自己的产品、案例或观点。

4. 选择适合的视频形式并生成视频。

5. 发布前重点检查是否已经充分改写，避免直接搬运原视频内容。

### **上传现成视频并包装**

1. 在首页选择“现成视频”。

2. 上传本地视频，或粘贴可访问的视频 URL。

3. 按需要选择简单包装或高级包装。

4. 补齐标题、描述、封面和发布平台。

5. 检查视频比例、字幕、封面和平台文案后发布。

### **用账号定位分析做前期判断**

1. 在左侧进入“工具箱 -> 账号定位分析”。

2. 粘贴账号主页、单条作品链接或分享文案。

3. 选择平台、作品数，并按需要开启 AI 报告。

4. 查看账号资料、发布规律、生命周期曲线、内容标签和高表现作品。

5. 把结论用于后续选题、文案二创、产品库补充或发布策略调整。

### **用选题控制台找候选视频**

1. 在左侧进入“短视频工作台 -> 选题控制台”。

2. 配置账号关键词、行业关键词、竞品关键词或对标账号。

3. 点击“执行一次”采集候选视频，或按需要开启每日自动采集。

4. 在候选池里把视频标记为备选、取消，或转成短视频任务。

5. 转成任务后，到“流水线任务”里继续查看进度、补充配置和检查结果。

## **7. 发布和插件**

ClawGC 支持把生成好的视频继续送到发布环节。当前建议优先用于抖音、小红书、视频号、头条号、微博等平台。实际可用平台以发布页和浏览器插件检测结果为准。

如果要使用一键发布，通常需要先安装浏览器插件。发布页会提示下载入口，按提示下载后安装即可。

简要步骤：

1. 在发布页点击下载浏览器插件。

2. 下载到本地后解压。

3. 打开 Chrome 或 Microsoft Edge。

4. 进入浏览器扩展管理页面。

5. 打开“开发者模式”。

6. 点击“加载已解压的扩展程序”。

7. 选择刚才解压出来的插件文件夹。

8. 回到 ClawGC 发布页，按页面提示检测插件和发布账号。

目前建议使用 Chrome 或 Microsoft Edge。安装过程中如果浏览器提示不同，以浏览器页面实际文案为准；遇到具体浏览器操作问题，也可以直接搜索“Chrome 加载已解压扩展程序”或“Edge 加载已解压扩展程序”。

插件安装完成后，还需要在页面里完成授权发布扩展，并确认发布账号已经登录。Chrome、Edge 或不同电脑上的插件，可能会显示为不同发布设备。

如果希望任务生成好之后自动交给浏览器发布，可以打开无人值守自动化发布，并保持对应浏览器和发布插件在线。你也可以指定默认发布设备；不指定时，系统会尽量交给在线且可用的设备处理。

如果任务显示“自动发布已停止”，通常表示发布设备离线、插件未连接、账号未登录，或平台页面需要人工处理。内容和视频不会因此丢失，你可以检查插件和账号状态后重新发布，也可以手动发布。

## **8. 数据闭环：发布不是终点**

短视频不是生成完就结束。真正能提升效果的是持续测试和复盘。

ClawGC 会逐步把发布结果和平台反馈同步回来，让你看到哪些选题、文案、视频形式、发布时间和产品表达更有效。账号定位分析和选题控制台也可以作为数据闭环的一部分：先看账号和行业里什么内容表现更好，再决定下一批内容怎么做。

这些数据后续可以继续反哺内容生产：

1. 帮你判断哪些选题值得继续做。

2. 帮你比较不同视频形式的效果。

3. 帮你发现哪些产品卖点更容易转化。

4. 帮团队沉淀可复用的内容经验。

5. 帮后续 AI 生成更贴近真实效果的文案和视频策略。

所以 ClawGC 想做的不是一次性生成工具，而是一条可以持续优化的短视频增长流水线。

## **9. 发布前检查**

视频生成后，建议先检查：

1. 文案有没有事实错误。

2. 字幕有没有错别字。

3. 封面是否一眼能看懂。

4. 标题是否具体。

5. 产品信息是否准确。

6. 是否有夸大承诺、侵权或敏感表达。

目前建议优先发布到抖音、小红书、视频号、头条号、微博。其他平台以页面实际支持为准。

## **11. 常见问题**

### **第一次应该怎么用？**

1. 有对标作品，就粘贴作品链接。

2. 想先找方向，就用选题控制台。

3. 想分析账号，就用账号定位分析。

4. 没有参考作品，就从想法开始。

5. 已经有文案，就粘贴现成文案。

6. 已经有视频，就上传现成视频，或粘贴可访问的视频 URL。

7. 第一次建议先手动跑通一条，再用自动流水线批量做。

### **产品库什么时候必须用？**

只做流量内容，可以先不用。

想卖货、获客、介绍产品，建议使用产品库。

产品库能让系统在文案和视频里自动带入产品信息和产品图片，内容会更具体，也更适合转化。

### **视频生成效果不满意怎么办？**

优先改文案和素材。

常见问题：

1. 开头没有钩子。

2. 一句话太长。

3. 主题太散。

4. 产品卖点不清楚。

5. 图片素材不够清晰。

6. 内容太像广告稿，没有具体场景。

### **数字人效果不稳定怎么办？**

优先检查形象视频和音色质量。

形象视频要正脸、清楚、无遮挡；音色要安静、清楚、少回声。素材质量越好，数字人生成越稳定。

### **发布失败怎么办？**

请先检查：

1. 发布账号是否已登录。

2. 发布插件是否正常连接。

3. 视频、标题、描述、封面是否完整。

4. 平台页面是否出现验证码、弹窗或草稿提示。

5. 如果使用无人值守自动发布，浏览器和发布插件是否仍然在线。

如果仍然失败，可以带截图或录屏联系我们。

### **自动发布已停止怎么办？**

先检查发布设备是否在线、发布插件是否连接、平台账号是否仍然登录。如果平台页面出现验证码、弹窗或需要人工确认，先处理页面提示，再重新发布。

### **余额不足怎么办？**

可以进入账号或个人中心查看充值余额、会员额度和消费记录。余额不足时，按页面提示充值或购买套餐后再继续生成或发布。

### **发布插件装不上怎么办？**

先确认你使用的是 Chrome 或 Microsoft Edge，并且已经解压插件文件夹。进入扩展管理页后，打开开发者模式，再选择“加载已解压的扩展程序”。

如果仍然不行，可以截图给我们，或搜索对应浏览器的插件安装教程。
