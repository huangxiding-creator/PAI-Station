# WIZARD — 只有你能做的 5 步（做完工厂即可全自动）

> 工厂已装好：DevTools 2.02.2608070（E:\WeChatDevTools）+ miniprogram-ci 工具链 + hello 模板全绿。
> 下面是**必须本人操作**的步骤（涉及账号/资质/密钥），每步做完工厂就能接管剩余一切。

## 第 1 步：注册小程序（拿 AppID）⚠️ ~30 分钟

- 打开 https://mp.weixin.qq.com → 立即注册 → 小程序
- **主体类型选「企业」**——用你视频号企业认证的同套资质（营业执照/对公或法人验证）
- 类目：**先选「工具-效率」**起步（稳）；「商业资讯-研报」需要增值电信许可（CPN），P4 前不需要
- 注册完 → 登录后台 → 「设置→基本设置」里能看到 **AppID（wx开头）** → 填到第 3 步

## 第 2 步：生成上传密钥 + IP 白名单 ⚠️ ~5 分钟

- 后台 → 「开发→开发管理→开发设置→小程序代码上传」
- 点「生成密钥」→ 下载 `.key` 文件 → **存到 `E:\AI-Station\data\secrets\`**（红线区，永不入 git）
- 同页面「IP 白名单」→ 把本机公网 IP 加进去（百度搜"我的IP"即得；家宽 IP 会变，变了就更新）

## 第 3 步：填密钥配置 ⚠️ ~1 分钟

- 复制 `pipeline/secrets.example.json` → `data/secrets/weappforge.json`
- 填入：`appid`（第1步）、`privateKeyPath`（第2步的 .key 文件绝对路径）

## 第 4 步：开发者工具开服务端口（调试腿用）⚠️ ~1 分钟

- 打开 E:\WeChatDevTools\微信开发者工具.exe → 右上角「设置→安全设置→服务端口」→ 开启
- （扫码登录用你注册主体的微信）

## 第 5 步：告诉我做完了 ✅

之后运行 `node pipeline/forge.mjs` —— 一条命令：构建→上传到你的后台→出体验版二维码，全程计时落盘（这就是"4 小时从想法到后台"主张的实测仪表）。
