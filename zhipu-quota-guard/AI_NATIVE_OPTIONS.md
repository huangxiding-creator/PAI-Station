# AI_NATIVE_OPTIONS — Phase 0

| # | 选项 | 裁决 | 理由 |
|---|---|---|---|
| A | LLM 判断「何时重置」（每次决策问模型） | ❌ 核心不用 | 决策是确定性数学（消耗速率×剩余×刷新时刻×卡预算），LLM 引入不确定性与 token 成本；判断层三铁律「免费模型优先：确定性检查用代码」 |
| B | 确定性策略引擎 + LLM 仅作异常诊断（如契约漂移时摘要 diff） | ✅ 采纳 | verifier>generator：规则硬、解释软 |
| C | CC hook 集成（额度低时 CC 内提示） | ⏸ v2 | 有价值但非 MVP；先用企微+面板 |
| D | Agent 化（把护盾做成常驻 agent） | ❌ | 守护进程必须比被守护者更稳，纯进程最佳 |
