## 💡 它是什么

你的电脑里躺着你全部的工作痕迹：文档、邮件、会议、聊天、浏览器、内网……但没有一个 AI 真正"活"在这些数据里。

**PAI-Station 是一个 7×24 常驻 Windows 的个人 AI 工作站**：它读你读过的文件、听你开过的会、学你写过的每一版稿子，最终——

> **比用户更懂用户自己，比用户更懂用户的工作，比用户更早知道用户此刻需要什么。**

而且：**模型调用默认 ¥0 起步、永不锁定**（智谱免费链起跑，适配层 3 行配置可换任意端点，隐私 L2 档可全本地），数据 100% 本地，绿色免安装。

## 🧗 最难优先开发宪法（第 20 章）

**做最难的事——最难才有最大价值，才有门槛和护城河**。九大最难问题逐一攻坚（[提案第 20 章](PROPOSAL.md)）：

> **H1** diff 因果蒸馏引擎 · **H2** 分身责任转移 L1-L3 与 60 分奇点判定 · **H3** 亿级文件语义记忆 · **H4** 微信纯视觉只读通道 · **H5** 免费链上做复杂任务 · **H6** 交叉铸造引擎 · **H7** avatar.pai 分身资产标准 · **H8** 本地 7×24 实时性 · **H9** 技能市场双边信任

每项给出"为什么难/为什么无人做/攻坚路径/可证伪验收"，且每项都**先站在巨人肩上再攻坚**（H1 站 SKILL.md 标准、H3 站 OpenViking、H5 站智谱思考开关……）；自研工时 **≥40% 锁定难点**；容易的事缝合巨人肩膀、做基线、或干脆不做——**容易的事借巨人的肩，最难的事也是在巨人的肩基础上再自己扛**。

## 🤝 信任-上下文引擎：最长的那块板（第 21 章）

**信任是因，上下文是果，理解是复利**——与一切竞品的分水岭在于：以信任它的用户为基础，最大限度自动获取用户本人及其工作任务的上下文，多维度多层次深度分析，最大程度贴近真需求（[提案第 21 章](PROPOSAL.md)）：

- **TCN 四环飞轮**：信任→上下文→理解→真需求，价值兑现是唯一可信的信任充值；
- **信任四件套**：账本 / 预算 / 渐进阶梯 T0-T3（opt-in 铁律，Recall 反例入评审清单）/ 事故修复协议；
- **三层上下文**：显式 L0（说的）× 行为 L1（做的，diff 因果层）× 环境 L2（所处的），**需求三角定位法**——三层交汇处才是真需求；
- **18 源×4 态覆盖度仪表盘** + 新鲜度工程（上下文是有半衰期的资产）；
- **五维画像**（认知/行为/社会/情感/进化）× **任务四层解析**（事实/结构/意图/战略）；
- **需求逼近指数 NPI**：采纳率 / 下一步预测命中率 / 初稿一次通过率 / 纠正频率下降——M4 ≥60%，M6 ≥85%，"它就是懂我"的可度量形态。

结构性论证：云侧拿不到（数据主权）、本地侧没做全（止于记录或对话）、信任无法后补（Recall 逆序失败）——长板不在"能拿到上下文"，在"**被信任地拿到**"。
