## 💡 它是什么

你的电脑里躺着你全部的工作痕迹：文档、邮件、会议、聊天、浏览器、内网……但没有一个 AI 真正"活"在这些数据里。

**PAI-Station 是一个 7×24 常驻 Windows 的个人 AI 工作站**：它读你读过的文件、听你开过的会、学你写过的每一版稿子，最终——

> **比用户更懂用户自己，比用户更懂用户的工作，比用户更早知道用户此刻需要什么。**

而且：**模型调用默认 ¥0 起步、永不锁定**（智谱免费链起跑，适配层 3 行配置可换任意端点，隐私 L2 档可全本地），数据 100% 本地，绿色免安装。

## 🤝 信任-上下文引擎：最长的那块板（第 21 章）

**信任是因，上下文是果，理解是复利**——与一切竞品的分水岭在于：以信任它的用户为基础，最大限度自动获取用户本人及其工作任务的上下文，多维度多层次深度分析，最大程度贴近真需求（[提案第 21 章](PROPOSAL.md)）：

- **TCN 四环飞轮**：信任→上下文→理解→真需求，价值兑现是唯一可信的信任充值；
- **信任四件套**：账本 / 预算 / 渐进阶梯 T0-T3（opt-in 铁律，Recall 反例入评审清单）/ 事故修复协议；
- **三层上下文**：显式 L0（说的）× 行为 L1（做的，diff 因果层）× 环境 L2（所处的），**需求三角定位法**——三层交汇处才是真需求；
- **18 源×4 态覆盖度仪表盘** + 新鲜度工程（上下文是有半衰期的资产）；
- **五维画像**（认知/行为/社会/情感/进化）× **任务四层解析**（事实/结构/意图/战略）；
- **需求逼近指数 NPI**：采纳率 / 下一步预测命中率 / 初稿一次通过率 / 纠正频率下降——M4 ≥60%，M6 ≥85%，"它就是懂我"的可度量形态。

结构性论证：云侧拿不到（数据主权）、本地侧没做全（止于记录或对话）、信任无法后补（Recall 逆序失败）——长板不在"能拿到上下文"，在"**被信任地拿到**"。

## 🔩 OpenClaw 三级借用与伴生网关（第 22 章）

对"在 OpenClaw 框架上开发"的建议，源码级论证后定为**借件不借架**（[ADR-16](PROPOSAL.md)，[提案第 22 章](PROPOSAL.md)）：

- **L1 借设计**：通道 transport-only / 插件不 import 内核 / doctor 自修复——零成本写进规约；
- **L2 借组件**：feishu 扩展（8.2 万行，OpenClaw 唯一中国 IM 通道）逐文件研读，提取 **7 件生命周期工程**（指数退避重连 / 终态错误分类 / 状态三态发布 / Webhook 安全五件套 / 日志脱敏五正则 / durable 先落账后应答 / 归一化事件契约），Python 重写 ≈800 行——[PoC 骨架](poc/channel_adapter_skeleton.py) **7 项自测全过**，借件成本 ≈ 借架 0.4%；
- **L3 逃生门**：M6+ OpenClaw 可作**伴生网关**经本机 OpenAI 兼容 API 接入（只见对话文本、可逆）；
- **fork 仅作保险**：通道子系统 fork 预案留 M0.5 复核点，预计不触发；
- **元发现**：OpenClaw 自己也不写飞书 WS 协议（client.ts 全委托官方 SDK）——协议零自研是双方共识，借的是工程纪律，不是代码本体。

## 🌱 共同成长引擎：产品与用户双螺旋（第 23 章）

**产品自己要成长（知识/技能/业务能力），还要让用户成长——两条成长链互相喂养**（[提案第 23 章](PROPOSAL.md)）：

- **自动化悖论**：纯自动化 → 产品越强、用户越弱（用进废退）→ diff 燃料枯竭 → 产品成长封顶——价值呈倒 U 曲线；共成长 → 产品强、用户也强 → 燃料再生 → **超线性增长**。共成长是数学必然，不是道德选择；
- **双螺旋**：产品内螺旋（知识缺口探测 / 技能重生 / 能力审计三轨自成长）× 用户外螺旋（三档教学：**L1 教我懂**（苏格拉底式追问）/ **L2 带我练**（脚手架）/ **L3 替我做**（+一分钟复盘）——责任阶梯复用为教学档位）+ 三耦合器（主环 / 教学环"教中学"被问倒即知识缺口 / 价值环）；
- **多维螺旋上升机制**：6×2 成长维度矩阵（知识/技能/能力/判断/价值/信任 × 产品/用户）× 日微/周中/月宏三节律 + 螺旋上升判定器（连续两宏循环全维停滞才触发三根因诊断，防误报）；
- **PGI / UGI 双成长指数**：产品成长指数（知识覆盖/技能净增/奇点域数/自主完成率）与用户成长指数（技能习得/决策质量/独立完成率/价值产出）各四指标加权，进成长周报；
- **FSRS 间隔重复**（py-fsrs，每日 3 张上限）+ explore_rate 0.1（Ericsson 边缘练习率落地）；
- **防退化五机制**：依赖度超阈只提示不强制 / 挑战模式 opt-in / 教练推送计入打扰预算 / 判断位永远保留给用户 / 成长永不与定价挂钩红线。
