# FDE 解决方案生产方法论（广产品线）

> 从一份语料到一份可上架的全案方案——PAI-Station V2 实证流水线的萃取。
> 代码即真相：本文每条对应 src/paistation/foundry/ 下的引擎模块；改动先改代码再同步本文。

## 一、定位与总纲

**FDE 方案 = 五段覆盖契约 × 三层方法论弹药 × 密度闸 × 市场环闭环。**

覆盖契约（prompts.DEFAULT_COVERAGE，每案必答全）：

```
行业诊断 → AI 机会识别 → 实施路线图 → 抄作业工具包 → 度量体系
```

## 二、三层方法论弹药库（methodology.py，36 卡）

| 层 | 用在 | 卡（各 12 张） |
|---|---|---|
| **L1 章层** | 目录骨架 | OODA／PDCA 双环／麦肯锡七步／金字塔／SCQA／MECE／系统冰山／双钻／精益循环／第二曲线／组合创新／JTBD |
| **L2 节层** | 章内子框架 | 五力／SWOT／蓝海四行动／商业模式画布／ICE 评分／艾森豪威尔／Fogg 行为／价值链／STP／风险矩阵／RACI／智能复利飞轮 |
| **L3 组件层** | 节内表达 | 清单革命／WBS／决策树／泳道图／对比矩阵／逆向思维／5Whys／负面清单／信息图／案例嵌入／业务公式／矛盾分析（毛选） |

配卡机制：`suggest_cards` 按章节标题 2 字滑窗计分推荐（k=6），**无命中回退前 k 张——弹药不断供**。卡库不可变元组，来源标注（券商框架库/麦肯锡/毛选/混沌/曾鸣…），只蒸馏结构不搬运原文（版权三态=结构参考）。

## 三、编排流水线（fde.py compose_plan）

```
目录(L1 配卡) → 逐节重构(L2L3 配卡 + 密度闸未过重生成) → 整案密度终检 → MD 渲染落盘
```

四条工程纪律：
1. **断点续传**：每节落 checkpoint（含 toc 本身——续跑不重掷目录，防章题漂移致 key 失配）；完工清除断点防陈旧复用。
2. **降级不假完成**：重生成仍未过闸的节带 `degrade_note` 进成品，读者可见——分数透明印在成品头部。
3. **长语料骨架摘要**：`digest_markdown` 保留全部标题+每段首行 200 字（上限 3 万字）注入提示词，防 context 爆炸。
4. **免费链韧性**（tools/fde_factory.py）：单节重试×3、90s 退避、案间 30s 冷却、ledger 跳过已完成——GLM ¥0 链上打满 20 案排产。

## 四、密度闸（density.py，六维 100 分，阈值 60）

| 维度 | 分 | 判据 |
|---|---|---|
| 章模型 | 15 | 每章有 L1 框架标注 |
| 节模型 | 15 | 每节有 L2 框架标注 |
| 九件套 | 25 | 组件≥2 件/节 |
| 三级目录 | 10 | 章-节-组件三层齐 |
| 四前提 | 20 | 标准化/流程化/数据化/知识化 逐节体现 |
| 案例 | 15 | ≥50% 节含小案例 |

## 五、市场环闭环（funnel.py，M7.6+M11）

- **五事件账本**：view→preview→purchase→feedback→custom_lead 逐事件落 `funnel_ledger.jsonl`；购买收入−返款=净进项 → 灵魂价值账本 ecosystem（幂等水位防重复记账）。
- **三段定价**：¥9.8–19.8 钩子（试读 20%+反馈入口）→ ¥198–498 全案 → 定制线索。定价实验：plan_id 哈希稳定分 A/B 桶（A=低价位 B=高价位）。
- **上架纪律**：manifest+试读进 `09 发布/store`；**全案只留 data/ 本地，付费内容不上公开仓**。
- **指标快照**：funnel_stats 四指标（上架/净进账/反馈/线索）——**零数据=0，不编造**。

## 六、交付形态（联：任鑫课程 04-落地参谋模式）

方案不是交付终点——「方案 + 落地参谋提示词 + 客户上下文」三件套才是：交付时先盘客户上下文（3 问×2 轮），按需检索方案内对应章节，输出带出处的 30 天落地地图 + 两周复盘钩子。

## 七、诚实纪律（贯穿）

- 密度不过闸=明示不过（C11 before→after 落账，如 EPC 研究 42→82）；
- 单源/无源结论卡标注，综合只用卡片不新增事实（C14）；
- 降级节可见、指标零不编、来源逐卡标注。
