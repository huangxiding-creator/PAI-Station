# 研究管线七步法（FDE 方案的上游）

> 语料 → 结论卡 → 密度报告的实证流水线；与「重构总论/FDE解决方案生产方法论」衔接。
> 首战实录：EPC 合同风险与索赔管理——600 问 / 599 有证（99.8%）/ 62.6 分钟 / ¥0 LLM。

## 七步管线（research_pipeline.py + tools/research_run.py）

```
① 主框架生成（章-节两级 master_framework，73 节）
② 问题生成（逐节出题 → 600 问，question_gen）
③ 证据检索（每问回捞语料段落，标注单源/多源/无源）
④ 结论卡（问题+证据+结论三件套 → conclusion_cards，599/600 有证）
⑤ 框架综合（frame_synthesis：节框架与章框架回填）
⑥ 密度报告（M9.5b 节级综合 → density_doc + report.md）
⑦ 验收（acceptance.json：before→after 落账，C11）
```

全程断点：question/conclusion/dense 三层 checkpoint 逐条落 jsonl，中断续跑只补未完成项。

## 关键改造：卡片拼贴 → 节级综合（M9.5b）

**失败模式（42 分不过闸）**：旧法每节取 4 张卡各截 200 字拼贴——同题干 Stakeholder 变体卡重复、组件行被丢弃、四前提全缺。

**新法（82 分过闸）**：每节把全部相关卡喂给 GLM 做一次**节级综合**，七字段输出：

```
综合（这节讲什么）｜标准（判断准则）｜流程（步骤）｜数据（量化点）
｜沉淀（方法论资产）｜案例（实例）｜组件（九件套选型）
```

三条铁律：
1. **只用所给卡片内容综合，不得新增事实**（C14）——卡片没提的维度老实写「本节卡片未覆盖」；
2. 组件非法值丢弃、上限 2 件，垃圾输出回退关键词匹配（领域词→九件套）；
3. 缺卡的节点明「（该节点结论卡待证——单源/无源标注）」，不装满。

**诚实残留示例**（过闸但记录在案）：知识化维度未在方案类节点体现、案例密度 15%——属语料层缺口，不是综合层缺陷；下一轮语料补案例素材即治本。

## 三条可迁移经验

1. **拼贴是密度天花板**：LLM 时代「多卡截断拼接」永远到不了 60 分，必须让模型在卡片集上做一次语义压缩——重复变体在综合中自然消解（无需机械去重）。
2. **闸门要打在半成品上**：逐节过闸+重生成，比整案写完再检省一个数量级 token（早失败早重试）。
3. **验收即凭证**：acceptance.json 记 before→after 与 failures，连同 manifest 落 08 成果——方案的可信度来自可审计，不来自形容词。

## 与器官的接口

- 产物归档：`08 成果/research/<主题>/`（manifest + report + acceptance + checkpoint）；
- 方法回流：本文件 + 重构总论 → 05 方法（R14 凭证 kind=method_distilled）；
- 商业出口：研究报告过密度闸 → fde_factory 生成全案 → funnel 三段上架。
