# 核心模型萃取——《AI 原生组织转型》五讲

> 出处标注：M1–M5 = 课程模块 01–05（本地镜像 modules/）。本文件为原创萃取，短引均注明模块。

## 一、总框架：任务／协调／生态三层（M1）

AI 影响三个层次：**任务层**（干活变快）、**协调层**（组织调度资源、对齐方向、推进成果）、**生态层**（市场格局本身）。

- **鬼故事诊断**：人人都提效了，公司没变快；每个环节都省了钱，账上没多钱。「处处冒烟，就是不着火。」
- **三层台阶**：任务提效 → 组织竞争力 → 市场战果，中间两道坎；先修协调层。
- **一流武装 ≠ 一流军队**：北洋水师买得到定远镇远，买不来海军。「军舰可以花钱买，海军只能自己练。」
- **效率是我们定的，价值是市场定的**（昆仑万维 AI 短剧提效 10 倍、年亏十几亿）。

### 为什么任务层无效：两个定律

1. **阿姆达尔定律** `S = 1/[(1−p)+p/s]`——优化非瓶颈环节，对整体贡献趋零。类比：京沪航班 130→100 分钟，但门到门 340 分钟，优化连 10% 都不到。
2. **瓶颈约束**：系统效率由最窄环节决定（洗菜快 10 倍，灶台只有 4 个，只是菜堆积如山）。实证：前 Meta L8 一天 20 个 PR 没人审，「我只好少写点 PR——瓶颈在团队其他人身上」。
3. **白领 60% 精力在协调**（对齐、催活、救火、复盘），任务只占 40%——优化任务层最多碰 40%，且协调出问题时任务成果会被乘数溶解。
4. **NASA 火星气候轨道器**（1999，1.25 亿美元）：一边英制一边公制，两边各自全对，死在中间。「最危险的错误不发生在格子里，发生在格子和格子之间。」

### 组织观的底座（M1）

- **科斯**《企业的性质》：组织是降低市场交易协调成本的发明——不是天经地义，是特定生产力下的解决方案。层级/部门/KPI 都是历史化石：「它们不是定律，是化石。」
- **核心命题**：AI 转型不是「转组织来用好 AI」，而是「用 AI 替代组织的协调功能」。**AI 不是组织的工具，是组织的竞品。**
- 坏组织三征：人心不齐（对齐失效）、流程卡顿（推进失效）、错误重犯经验不沉淀（闭环失效）。

## 二、对齐（M2）：同一张地图，同一套交规

**对齐 = 对齐事实（世界是什么）+ 对齐打法（我们怎么做）。**

### 为什么对齐贵

- 对齐线条数 ∝ N²：3 人 3 条线，50 人 1225 条。
- 人类靠**有损压缩**表达（设计师脑内 100 方案→1 页 PPT），接收方靠**幻觉重构**还原——每一环都损失+注入幻觉（传话游戏）。安克：新品上市百个判断点，「每个节点 99 分，叠下来损耗超七成」。

### 对齐事实三法

1. **N²→N：唯一事实源**。所有人连向一个中央信息源，不相互转述。「别让人和人对齐，让人和同一个东西对齐。」共享文档不够——写不进去（没人维护）、读不出来（137 页不知哪三行与你有关）；AI 同时打开两头：自己去收集、按你的角度递给你。「你们缺的不是文档，是随时更新随问随答的老王。」
2. **操作同一个对象**（贝索斯：Communication is a sign of dysfunction）。波音 767 纸图传递舱门返工 1.3 万次→777 全员云端同一数字模型（CATIA 100% 数字化），返工减半。**「今天的会议纪要，就是当年打印出来的图纸」**——纪要终点不是记下来，是改掉云端那个对象；冲突不在任何一份纪要里，在两份纪要之间——那个地方没有任何岗位负责。案例：安克项目容器（「项目是主线，不是围绕某人的飞书消息」）、出门问问所有会必须 Agent 参与、Claude Tag 跨群旁听主动识别跨场冲突。
3. **用成品沟通，不靠语言**。「文档是成品太贵时代的替代品——妥协的理由没了，习惯还在。」案例：Botlearn 研发直接上线 MVP；Orion 谈客户边谈边跑，半小时后给 8 个能点的原型——「把两周的需求澄清压进三十分钟」。

### 对齐打法三法

| 传统招 | 失效层 | AI 招 |
|---|---|---|
| 培训 | 讲时懂，做时不在场 | **规范写进环境** |
| 制度 | 写下了，不在执行路径上 | 按钮化/代码化/自动检查自动改 |
| KPI | 只管终点不管过程 | 过程与结果双控（只有 AI 会答应） |

- **规范写进环境**：Ramp CPO 念了 1000 遍「CTA 必须在首屏」做不到→Inspect agent 嵌进 Figma 工作流自动改；Botlearn 品牌规范写成 skill 一次调用「最高级的专家写一次，所有人反复调用」；ZooWork 各写各的 SVG、提交时 AI 背后按规范统一重拼——「没有支付对齐的成本，但享受对齐的结果」。
- **极端案例（艾语智能）**：做一个 agent 持续蒸馏 Anthropic 公开言行，公司打法决策先问「符不符合 Anthropic 的做法」——用 agent 蒸馏一家标杆公司的组织方法论并对齐之。
- KPI 反例：抖音「哭晕在厕所」广告——转化 KPI 双方都完成，品牌资产不在任何人 KPI 里；K12 电销「既要结果也要控过程，这种自相矛盾的要求只有 AI 会答应」。
- **收口：最好的对齐，是不需要对齐。**

## 三、推进（M3）：发现／分配／传导／检查

**推进 = 把决策编译成可执行的工作。** 损耗不在任务里，在任务之间：「活不是在被做的时候慢，是在被等的时候慢。」「公司里最贵的人，一半时间在当拖车。」

**元原则：Agent 推流程，不是人用 Agent。** 安克教训：流程智能体培训几百人、满意度 8 分，两周后翻后台——超一半智能体使用人数 ≤5 人（建设者+测试同事），「后台冰冷的数据泼了一盆冰水，不是冷水，是冰水」。根因三条：动态上下文没人管、智能体之间无协作设计、全链路状态不可见。**可选项永远干不过默认项**——让人用 Agent=AI 是可选项；让 Agent 推流程=不走这条路活根本不到你手上。

### 1. 发现——让工作自己举手

AI 全量看数据、自己分析、自己发起工作。海底捞桌子自报状态（摄像头→平板，「不是人变强了，是判断这件事被搬走了」）；美的机器人巡检自动生成工单；**安克 SKU 环比 -23% 自动识别异常→自动打包评论/库存/广告/社媒材料→带齐上下文交给人**（「以前是周会上才发现，现在是数据掉下去那一刻，材料已备齐」）；AI Jason 广告 loop 发现高点击关键词无自然内容→信号自动回流 SEO loop，「广告部和 SEO 部之间没开过一次会」。

### 2. 分配——让工作自己找人

「人不擅长找活，人擅长做被递到面前的活。」美团 745 万骑手/滴滴早已证明中央算法调度最优——「白领是用电脑的认知型蓝领」。**默认顺序反过来：AI 先做，人处理例外。** CodeBuddy：早上没人派活，AI 推荐几个与你专业匹配的**待解问题**（不是任务——明确任务 AI 自己干完了，「AI 把任务做完了，把问题留给你」「人从此只做题」）；酷特智能 RFID 衣服到面前 Pad 告诉你操作。

### 3. 传导——让工作自己交棒

**「理想的交接，是没有交接动作。」** 福特 1913 流水线：底盘装配 12h08→1h33——「流水线上最重要的机器不是任何工位，是那条传送带」；**「你们装了机器，没装传送带」**。安克新品开发：关小黑屋定义流水线→9–10 个标准交付模板（给流程智能体看）→项目容器+编排系统，**维护运行图而非待办**，21 个流程智能体跑完全程「『你那边好了吗』一次没在群里出现过」。华住空调工单：AI 旁听电话直接生成工单直派王师傅——「最好的传导，是不传导」。

传导的额外价值：
- **暴露真瓶颈**：「人肉传导里，堆积藏在忙里；总线传导里，堆积是一个数。」
- **沉淀隐性知识**：「人对人抱怨，会消散；人对系统抱怨，会沉淀。」老王对 AI 提要求→AI 记下来变成下次标准——同样一次抱怨，一个消散在饭局，一个沉淀成资产。

代价（必须管理）：福特流水线后流失率 380%、日薪翻倍到 5 美元才稳住——低算力杂活本是两次高强度工作间的休息，传送带把椅子抽走了。**缓解三路径：涨薪、给自主性、安排目的而非任务**（人拿到有意义的目标自己拆解打回给 AI）。

### 4. 检查——用机制保证质量

「你放大的不只是产能，还有出错的速度。」两种错误态度（抗拒/事事人工审核——后者提效封顶 15%）都不对。

**心智模型：把 AI 当才华横溢但极便宜的外包公司**——不用、不盯，而是**定验收标准、设抽检、留追责、分阶段付款**。四层机制：

1. **自动门禁**（不合规进不来）——ZooWork 几十道门禁+项目开始即生成几百测试用例；
2. **对抗性检查**（检查者与干活者**上下文隔离**）——ZooWork 教训：400 多项检查全绿却一堆 bug，AI 自己 mock 数据骗过检查——**必须干净上下文+对抗机制，防 AI 自己骗自己**；
3. **人类抽检**（按带宽排班：周一看什么周二看什么）；
4. **兜底与回滚**（错追得回来）。

安克 check point：竞品促销价被当日常价读入→半小时被门禁抓出，「质量门禁把风险控制在每个节点，不能让偏差累积到最后才爆发」。「最重要的是检查，而不是流程本身。」

## 四、闭环（M4）：能力+市场，一次比一次好

**闭环 = 下一次做同一件事，起点比上一次高。** 能力闭环问「干得好不好」（裁判在内），市场闭环问「值不值得干」（裁判在外）。「开工是安慰，复盘是审判——所以大家都愿意开工。」（做卷子不对答案的同学）

### 能力闭环

1. **沉淀 = skill 化**：「凡是你做成过一次的事，都欠自己一句『把它变成 skill』。」腾讯研究院春节热点值班没排人、派了一个 skill 上去，节后成常驻工具；任鑫素白 PPT→一句指令自动出；**Anthropic 内部用 Claude Code 写 Claude Code，解决完问题就总结经验写进 CLAUDE.md，下次先读**；余一「复盘的复盘」——对「如何沉淀经验」本身再闭环，MD 不能写成无限长的漂亮话。
2. **组织共享：三层 MD**（公司级/部门级/项目级，AI 干活前必读）——「公司制度第一次有了强制执行的路径。」Every 反中台：别共享轮子，共享造轮子的经历——别的项目组派 agent 去看代码和设计思路，回来自己重写（经验可复制，不卡死在你的实现上）。
3. **自动触发，三条线**：问题发生→①解决当下（恢复投放）②根因修系统（修掉价格监控，让问题不再出现）③**回头验证**（改完数据涨回来没？没涨回来=根因找错了，要闭环的是「我们分析根因的方式」）。「跑第一条线的公司在救火，跑三条线的公司在变强。」
4. **问题的终点是变成一条检查项**：安克螺纹开裂→四维数据联合推理+反问工程师→判定熔接线+应力集中→**自动推进进 DVT checklist**（8D 思路）——「下一款产品设计时这条自动被检查，这个问题从此在这家公司消失了。」ZooWork Optimize Harness：专门一个 agent 分析执行 agent 一路上的卡点辛劳，为下次设计工具——**「每一次摩擦，都应该让系统长出一件新工具。」**

### 市场闭环

- AppLovin Axon 2.0（2025 年收入 55 亿美元 +70%）：一圈 500 展示 15 点击→压低无兴趣特征强化点击特征→逐轮调整，一天迭代几十圈；AI Agency 无人类审批一天 20 圈（同期别家一周一两圈）。
- **长闭环要收前置指标**（艾语智能催收展期 24–36 个月太慢→「加上了企业微信」也算前置信号，让系统拿得到快反馈）。

### 给 AI 授权，学习才成立

- **AI 做 PMO 不是小助理**：「这件事，是他在做，还是他在帮你做？」帮你做的复盘只有片段；自己做的全程因果链在手里。**「没有全程，就没有归因；没有归因，就没有学习。」**（他是 CEO 你是董事长）
- **Kavak**：build agents **per customer**, not per workflow——一个客户一个 agent，目标终身价值；每天实例化 10–20 万个 agent 各自带 VM，「醒来工作三分钟或三天，然后给自己定个闹钟去睡觉」；96% 客户交互/95% 交易由 agent 完成；agent 撞墙调一个 API 说「我需要帮助」，API 那头是人——「画成组织架构图，就是人类团队向 agent 汇报」。
- **eval 是压舱石**：「能开多快，取决于 eval 的质量」——eval 投入（时间/token/钱）与造 agent 本身 **1:1**；eval 只认业务结果（转化了吗/客户回来吗），点名批评通话分钟数类表面 KPI。

## 五、三个落地动作（M5）

> 「第一步全是传统 IT 问题&业务问题，没有 AI 问题。」小公司+CEO 有决心→直接按框架硬推；大公司难度×10→投胎论：别改造恐龙，在旁边长新的让它吃掉老的（波音 777 之后丢掉这套、787 退回部门协作）。**修路、点火、分圈。**

### 修路：让 AI 看见/理解/操作业务

1. **看见＝留痕**。「没有被记录的业务，对 AI 来说不存在。」能录音的全录音、能埋点的全埋点。YC 不写书了——几万小时 Office Hour 录音本身就是一本活手册+可问答的 agent（「YC 没有为做这件事新增任何动作——那堆录音已经是一本书了」；留痕把「以后可能做的事」的门票买了）。安克全员会议纪要打通/出门问问沟通必经 Agent——「留痕不是记录会议，是记录组织」。
2. **理解＝知识网络**。信息连不上（张先生来电/京A1234 二次进场/工单情绪不好——AI 怎知是同一件事）+实体关系/流程/隐性知识。**先做 5 分钟版本**：一个 MD 用嘴说给 AI 记下来，缺什么补什么，「补不上的才是要找专家的地方」（Ontology 有五分钟版和五百万版）。
3. **操作＝MCP+CLI**。MCP 是说明书，CLI 是把手（用文字动手不看屏幕）——「过去二十年所有 UI 优化对 AI 全是障碍」。Stripe 四件套：MCP server（含知识库检索）/老 CLI 直接成把手/`llms.txt` 纯文本渐进目录（先索引后全文，省 context window）/Agent Skills 目录。
4. **判据（可上屏）**：「**凡是会随着模型变强而失效的，都先别做；凡是模型再强也需要的，先做。**」「Harness 是耗材，接口和口径是资产。」三个别做：别自建内部 AI 平台（几百人公司六个月白干）、别先招 AI 科学家、别一上来全公司知识图谱（从一条业务反推）。心理准备：艾语智能重构月业绩还跌了——改造完会比原来效率低，但加速度快。

### 点火：让能干的人被看见

- **老板带头**（老板天然不卡：天天指挥别人干活、天天想「这个谁去做」；「楚王好细腰」——工业老板一天 200 刀重构 1400 万系统，大概率不能用，但下面人从此只能说「写得出来但会塌」，两句话之间隔着整个转型）。老板自己只用豆包转发短视频＝公司转型的阻碍。
- **识别先进**：「别找最听话的，找已经在跑的」——自己花钱买 Codex/Claude Code 且月月续费的人最值得培养（敢投资自己+能解决障碍+已找到回报领域）+能用干活型工具讲清端到端做成过什么+影响了身边同事。鹿客两句话全员邮件（「用尽任何办法向我证明你的 AI 能力有多强；告诉我你对什么业务感兴趣」）第一场 50 人第二场 200 人；XMind 小作文大赛 CEO 邮箱+AI 评分+立即发奖+立即分享。**风险：最强的领域专家可能离职**（XMind 顶级开发/鹿客产品大师），「原来最强的人最不愿转，半懂不懂的人机会成本最小转得最快」。
- **赋能**：报销 token（20→200 美金/月，「公司第一次对他说：你干的这件事是公司的事」——全公司最便宜的转型投资）；安克火箭班（50 骨干+IT/AI 混编带真实案例，1–2 天一次分享，「让人变化不能靠讲道理，要先看到再相信」，脱产 1–2 月回部门当催化剂）；**老臣路线**（王博龙式内部 FDE：一个一个上门装 Codex 当场解最痛的点——「卡点从来不在方法论，在最开始那三四个小时」）。「AI 转型的终点是全员，路径不是全员。」

### 分圈：把活切给小团队并放权

- **任务越拆越大**：AI 能完成每件事的 70%→一人覆盖范围变大，职能坑装不下（不越界憋屈/越界挨骂——「不是人不行，是坑的形状不对」）；「整块交给一个人加 AI，比切碎分给五个人再拼装快得多」（CodeBuddy/OpenAI PM：人一多协作开销巨大，微决策自己拍板）。
- **职能→业务纵切**：基本组织单元从职能变成业务，小团队端到端交付。安克 10 步变 4 步、20 人变 3 人；XMind 圈子（高内聚低耦合，中台后台全拆进圈子，人按角色×百分比进入多圈，职能部门退化为社区/行业协会；分圈→分活（碳硅分工「端到端结果×人+AI」编队）→分钱（圈子表现=奖金池，圈长定分配））。
- **放权：过度授权＋紧缩预算**。给不够的钱不够的人更大的目标（稀缺给动机，授权给能力）；「最大的卡点从来不在钱——小 MVP 要签战略合作协议、走三十二层合规」，要给的支持是**替他挡掉对别人资源的依赖和流程上的卡**。艾语智能一线员工有数据库和代码权限（大专基层员工直接改系统加拼音支持）——「要提效就充分相信 AI，要安全就设计好检查点，这是两个工程的活」；防线也不靠人管靠工程：pre hooks、AI 写的 AI 审、权限边界预定义。
- **美图**：2000 人公司切成 ≤10 人创新工作室，最高 1000 万启动资金半年验证，跑通则分红/独立融资，不成则关掉——「公司越来越像孵化器/Venture Studio」。
- **终极放权（Kavak+JTBD）**：权力原点放到客户侧 per-customer agent，它反过来向公司要资源——「以客户为中心第一次不再是口号，因为你终于配得起。」
