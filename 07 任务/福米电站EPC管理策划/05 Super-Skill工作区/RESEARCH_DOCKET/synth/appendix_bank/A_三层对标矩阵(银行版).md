## 二、标尺图例（三套卓越标尺的构成）

**PMBOK第7版（2021）8个绩效域**：干系人 / 团队 / 开发方法与生命周期 / 规划 / 项目工作 / 交付 / 测量 / 不确定性；12条原则中本方案重点落位：原则5（系统交互）、原则7（情境裁剪）、原则8（质量内建）。

**PMI项目管理大奖六维**（2024–2026现行体系）：①背景与挑战识别；②成果、价值与类别契合；③与组织战略目标一致性；④项目管理卓越性；⑤PMI文化价值观体现；⑥总体成功（按PMI扩展定义：交付的价值证明投入与投资的合理性）。建设/基础设施类别奖标准三句=计划·进度·沟通·成本·风险·安全六项管理卓越 + 多干系人多承包商复杂性的协调治理 + 领导力·干系人参与·创新施工实践。

**IPMA国际卓越项目管理大奖（PEB v1.0，3域9准则）**：A人员与宗旨（A1领导力与价值观 / A2目标与策略 / A3项目团队、合作伙伴与供应商）；B过程与资源（B1项目管理过程与资源 / B2其他关键过程与资源管理）；C项目成果（C1客户满意 / C2项目团队满意 / C3其他相关方满意 / C4项目成果与环境影响）。三领域等权，"使能50%/结果50%"均衡哲学。
