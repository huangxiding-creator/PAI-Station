# 对标研究与国别条件全集(外网研究提取)

> PMI/IPMA大奖标准/几内亚国别/Fomi国际面/C-PMBOK研究结论, 每条带来源


## 核心发现

- 现行官方评奖模型为《IPMA Project Excellence Baseline》(PEB) v1.0(2016年发布、公开可得)，结构为3大领域9项准则：A人员与宗旨(领导力与价值观/目标与策略/项目团队·合作伙伴与供应商)、B过程与资源(项目管理过程与资源/其他关键过程与资源管理)、C项目成果(客户满意/团队满意/其他相关方满意/项目成果)；模型官方自述源自TQM与EFQM等卓越模型传统，PEB中专门附图将三大领域与EFQM准则对标，并引用EFQM“使能因素50%/结果50%”的均衡评分理念。
- 评分与权重：子准则按0-100%打分，三领域各占总分1/3(公式聚合：人员与宗旨=三准则均值再平均；过程与资源=(B1+B2)/2；项目成果=((C1+C2+C3)/3+(C4a+b+C4c)/2)/2)；获奖层级为决赛入围(≈铜)/奖主义(≈银)/大奖得主(金)三级；核心评奖哲学是“结果只有作为领导力与管理过程的后果才被认可”，三领域均衡且高水平是卓越团队的标志。
- 申报材料与门槛(2025年官方)：全英文申请表(项目名/业主/项目经理/国家城市/联系人/项目类型/预算档)+按官方模板撰写的Application Report申请报告；截止4月30日；申报费Mega(>2亿欧元)2000欧/Large(5000万-2亿欧元)1000欧/中小型(<5000万欧元)500欧；大型/超大型最优项目须接受5名国际评审员书面评审+3天现场考察(重要相关方访谈+文件研究)两道关卡，获奖者须出席颁奖礼并作项目演讲；所有申报者均获覆盖PE模型全部准则的反馈报告。
- ICB4个人能力基线(2015)“能力之眼”=三大能力域29个能力要素：Perspective环境/视角域5个(战略/治理结构与流程/合规标准与法规/权力与利益/文化与价值观)、People人员域10个(自我反思与自我管理/个人诚信与可靠/个人沟通/关系与融入/领导力/团队协作/冲突与危机/足智多谋/谈判/结果导向——覆盖个人与人际两类能力)、Practice实践域14个(项目设计/需求目标与收益/范围/时间/组织与信息/质量/财务/资源/采购/计划与控制/风险与机会/相关方/变革与转型/选择与平衡——末项仅适用于项目集群与项目组合)；同一模型适用于项目/项目集群/项目组合三个域，每要素下含关键能力指标(KCI)。
- 水电/水务/工程类最佳对标案例：赣江下游尾闾综合整治工程2026年IPMA金奖(中国水利工程首金，采用EPC+全过程工程咨询+科技总承包模式，从15国18个决赛项目中胜出，现场考察覆盖项目管理/技术研发/质量安全/生态环保四维度)——与福米水电站EPC总承包场景最贴近；洪湖水质净化厂一期2024年银奖(中国水务行业首个)；能源类有南非Medupi电站2016年金(GE蒸汽电力系统)、国家电网巴西美丽山二期±800kV特高压2025年可持续项目经理金奖、荷兰Ecowende海上风电2026年新设可持续特别奖、克罗地亚DRAVA LIFE河流综合管理2026年中小型可持续金奖。

## 带源事实

- IPMA PE Award官方评审依据为《Project Excellence Baseline for Achieving Excellence in Projects and Programmes》v1.0(2016)，评奖员与评委均按该公开标准培训（来源：IPMA官方申报手册Invitation2021-PEA.pdf，https://www.ipma.world/assets/Invitation2021-PEA.pdf；PEB原文https://products.ipma.world/wp-content/uploads/2016/02/IPMA_PEB_1_0.pdf，2026-11-02读取）
- PEB模型结构：3大领域9项准则——A人员与宗旨：A1领导力与价值观、A2目标与策略、A3项目团队/合作伙伴与供应商；B过程与资源：B1项目管理过程与资源、B2其他关键过程与资源管理；C项目成果：C1客户满意、C2项目团队满意、C3其他相关方满意、C4项目成果（来源：PEB 1.0官方PDF第3章）
- 模型渊源官方表述：“基于全面质量管理(TQM)及相关模型(如EFQM)”；PEB以附图将三领域与EFQM准则对标，并引用EFQM评奖“使能因素50%/结果50%”均衡理念（来源：Invitation2021-PEA.pdf及PEB 1.0）
- 沿革：卓越项目模型(PEM)最初由德国GPM于1990年代发布，IPMA自2002年起以PEM为基础举办国际卓越项目大奖，大奖自1996年起每年颁发；2013年IPMA决定修订PEM，2016年发布PEB取代旧模型（来源：PEB 1.0历史章节）
- 旧版模型(1996-2015在用)为9项主准则/23项子准则、分“使能”与“结果”两区（来源：ResearchGate论文页《The Project Excellence Model revised》，https://www.researchgate.net/publication/296668068）
- 现行模型子准则共20项（来源：IPMA官方新闻《2020 IPMA Large- & Mega-Sized projects Award Finalists》，“evaluated against all twenty Project Excellence Model sub-criteria”，https://awards.ipma.world/news/2020-ipma-large-mega-sized-projects-award-finalists）
- 评分方法：子准则0-100%打分；聚合公式——人员与宗旨=((A.1a+A.1b+A.1c)/3+(A.2a+A.2b+A.2c)/3+(A.3a+A.3b+A.3c)/3)/3，过程与资源=(B.1+B.2)/2，项目成果=((C.1+C.2+C.3)/3+(C.4ab+C.4c)/2)/2；三领域均衡汇总（来源：PEB 1.0附录B评分表）
- 评奖哲学：“卓越项目必须在项目管理各方面(人员/宗旨/过程/资源/成果)均表现卓越；结果只有作为领导力与管理过程的后果才被认可”；“三大领域均衡且高水平的结果”是卓越团队特征（来源：Invitation2021-PEA.pdf原文）
- 认可层级：合格申报→决赛入围者(相当于铜)→奖主(银)→大奖得主(金)；所有申报团队均获覆盖PE模型全部准则的反馈报告（来源：PEB 1.0；Invitation2021）
- 评估流程(大型/超大型类)：申请表→申请报告→5名国际评审员各自独立评估→第一份评委报告→3天现场考察(重要相关方访谈+文件研究)→第二份评委报告→评委会决定决赛名单及金银铜→颁奖礼+反馈会（来源：Invitation2021-PEA.pdf）
- 申报类别与费用(2025官方)：中小型<€5000万(分7领域，含Construction/Engineering/Infrastructure，费用€500)；大型€5000万-2亿(€1000)；超大型>€2亿(€2000)；截止4月30日；全部材料须英文（来源：官方Submission Guideline 2025，https://awards.ipma.world/wp-content/uploads/2021/11/word-IPMA_Global_PE_Submission_Guideline_2025_Large_Mega.pdf）
- 申报材料构成：带*必填的申请表(项目名称/业主/项目经理/项目所在国与城市/联系人姓名职务邮箱电话/项目类型下拉选/预算档下拉选)+经IPMA奖协调员审核通过后按模板链接撰写的Application Report申请报告；大型/超大型最优候选受邀Site Visit；获奖者获奖杯+全体团队成员证书+Winners Package并须出席颁奖礼作项目演讲（来源：Submission Guideline 2025）

## 评奖标准图谱

- 领域A 人员与宗旨(People & Purpose)——总分权重1/3：A1领导力与价值观 / A2目标与策略 / A3项目团队、合作伙伴与供应商（每准则各含a/b/c三子项，按均值计入）[来源：PEB 1.0官方标准]
- 领域B 过程与资源(Processes & Resources)——总分权重1/3：B1项目管理过程与资源 / B2其他关键过程与资源管理 [来源：PEB 1.0]
- 领域C 项目成果(Project Results)——总分权重1/3：C1客户满意 / C2项目团队满意 / C3其他相关方满意 / C4项目成果(含目标达成C4a+b与成果绩效C4c，按((C1+C2+C3)/3+(C4ab+C4c)/2)/2聚合) [来源：PEB 1.0附录B]
- 评分标尺：全部子准则按0-100%百分比打分，三领域等权(各1/3)汇总为项目卓越总分；现行模型子准则共20项 [来源：PEB 1.0；IPMA官方2020决赛新闻]
