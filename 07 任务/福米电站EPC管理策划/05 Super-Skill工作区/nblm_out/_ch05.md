### 二、 风险量化评估标准与动态管控机制

1. **评价维度与临界值设定**：
   - **极高风险（得分15–25分）**：列入项目最高级别风险控制清单，由EPC项目总经理与业主高层亲自督办，必须具备前置闭环预案方可开工。
   - **高风险（得分10–14分）**：由总包部各业务部门负责人按周进行动态跟踪，按月向业主出具风险评价报告。
2. **风险防范策略分类**：
   - **预防与减轻（Mitigation）**：如在雨季（5–10月）到来前完成枢纽下部结构混凝土浇筑（如二期围堰截流于2028年4月底完成，截流抛投总量36,449m³）。
   - **转移与保险（Transfer）**：通过投保工程一切险（备用金单列2,673,159.41欧元）转移自然灾害与不可抗力风险。
   - **自留与应急储备（Contingency）**：安排不可预见费1,747,629.63欧元及专项备用金。
3. **风险信息报告与例会督办制度**（兰州水源地/莫莫克项目制度实证移植）：

| 制度件 | 运转规则 | 输出物与督办责任 |
| :--- | :--- | :--- |
| 周例会+督办清单双件套 | 议定事项按“问题—建议方案—会议结论—完成时间及责任人”五列纪要表记录，逐项列入督办清单限期办结、专人督办（督办时限1周，兰州水源地实证） | 周例会纪要＋督办清单，专人督办逐项销号 |
| 报告制度三级链 | 周报（周五17:00报、综合管理部门次日15:00汇总报班子）→月报（项目经理审批后报上级/业主/监理）→重大风险信息即时上报（莫莫克实证） | 周报/月报＋重大风险即时快报 |
| 会议制度体系 | 合同交底会（合同生效1周内）、业主开工会议（3周内）、项目开工会议（4周内）、月度汇报会、周例会（莫莫克实证） | 编号纪要归档，议定事项转入督办清单 |
4. **数字化风险监测预警数据源**：风险登记册滚动管控的偏差感知与预警触发，以数字总包平台5.0偏差闭环四步诊断系统（偏差感知与自动识别→归因分析与责任穿透→预警触发与纠偏推送→执行跟踪与闭环销号）与挣值分析（EVM）实时监测（PPM系统实时抓取工程量与费用进度、按月对比SV/CV，6.1.2节）为数据源——进度、成本及质量安全偏差自动进入本节分级督办与5.4节四级应急响应机制（平台机制详见第15章15.1）。
5. **待补充与待核事项**：
   - 【待核：几内亚企业所得税适用税率最终裁决（35%与25%两说并存）】
   - 【待供给：几内亚劳工部关于本工程本地用工配额法定义务的具体批文细则】

## 5.2 FIDIC银皮书风险分配与固定总价包干储备金机制

本节部署投资锁定三重机制：FIDIC银皮书（EPC/交钥匙总承包）合同模式下的风险划分界限、固定总价包干投资结构与“变更为限”的储备金动态管理，确保投资严格控制在批复预算之内；“超支谁兜底”的权责边界按下列清单可直接查表执行。

### 一、 FIDIC银皮书下“超支谁兜底”的边界划分

根据FIDIC银皮书的标准风险分配原则及本项目的特定商务安排，“超支谁兜底”遵循如下严格的权责边界：

1. **EPC总承包商包干兜底范围（完全兜底）**：
   - **工程设计与技术方案责任**：因工程设计深度、方案优化或技术缺陷导致的成本增加，完全由EPC总承包商包干承担。
   - **采购与施工成本超支**：包括水泥（短缺涨至9.5万–10万 GNF/袋）等材料涨价风险、施工设备折旧及高峰用工（2686人，总工日63.3万工日）人工成本增加，在固定总价合同范围内由EPC总承包商完全兜底。
   - **工期延误与履约责任**：在可研2026版规定的41个月总工期（筹建期6个月不计入，首台机组于开工后第33个月发电）内，非业主原因造成的工期延误及相关赶工费用，由EPC总承包商承担。
2. **业主（几内亚政府/业主方）兜底与承担范围**：
   - **移民搬迁与征地补偿**：移民15662人（可研淹没口径）的搬迁实施与费用由业主另行实施，超支与征地延误责任完全归于业主。EPC总承包商仅履行协助边界声明。
   - **不可抗力与政治风险**：战争、政变（如2021年9月政变类事件）、全国大罢工以及法律法规剧烈变更（如税率调整、特例许可审批延迟等）导致的超支，由业主承担或通过保险索赔。
   - **业主主动要求工程变更**：业主提出的超出原可研与EPC建设边界的重大范围变更，其增量费用由业主兜底支付。

### 三、 “变更为限”预警与四重风险兜底屏障机制

为杜绝工程建设中的无序超支、确保投资严格控制在批复预算之内，总包部建立“变更为限”的防超支四重屏障：

1. **第一重屏障：工程一切险（2,673,159.41 欧元）风险转移**
   针对暴雨洪涝（科纳克里雨季降雨3800–4300mm）、围堰过水损失及不可抗力等自然灾害，通过工程一切险进行赔付转移，不占用工程本体预算。
2. **第二重屏障：不可预见费（1,747,629.63 欧元）严格审批**
   枢纽工程单列不可预见费 1,747,629.63 欧元，仅限用于施工现场不可预见的地质条件变化（如厂房建基面变质页岩开挖等）。使用时需经咨询工程师与业主代表联合签字。
3. **第三重屏障：固定总价包干硬约束**
   土木建筑工程（253,401,809.20 欧元）、机电设备（38,457,570.37 欧元）与金属结构（13,624,949.88 欧元）严格实行总价包干。由于EPC承包商原因导致的任何工程量增加或建材涨价（如水泥涨至9.5万–10万 GNF/袋），一律不得追加合同金额。
4. **第四重屏障：业主责任与缺口隔离**
   将移民搬迁（15662人）及业主侧缺口（约1.6亿美元+移民约1亿美元）彻底隔离在EPC建设边界之外，防止业主侧债务或移民延误风险传导至EPC工程账户。

### 四、 业主侧前置条件传导与违约救济

边界隔离划定“超支谁兜底”的账务责任，但交地与资金闭合两条传导链仍会影响EPC关键路径（二期围堰截流2028年4月底、第33个月首台发电、41个月总工期）与放款回收节奏，总包部以“合同救济+情景预案+资金闭合”三项管理动作处置。

1. **交地里程碑与工期索赔联动**：将业主交地（含移民征地交地前置闭环）、库区清理、环保特例许可（L/97/038/AN法框架）等前置条件逐项列入合同里程碑清单，与EPC关键路径节点一一挂钩；每发生一次交地或前置条件延误，即在合同索赔时限内发出书面索赔通知，主张工期延长及相应费用【待核：最终签约版FIDIC银皮书专用条件的索赔程序与时限条款】。同步建立《业主前置条件履约台账》，按月与业主、咨询工程师三方对账，任一里程碑滞后即触发红色预警并进入索赔立项，杜绝"延误既成事实、索赔坐失时限"的被动局面。
2. **库区清理延期情景的偿债缓冲安排**：库区清理工程（单列1,748,400.00欧元）虽在EPC包干边界外单列，但其一旦延期将直接推迟蓄水发电里程碑，并传导为项目现金流与还款压力。管理动作：由总包部向业主与融资方提交《库区清理延期情景下的工期与现金流影响分析》，建议在融资协议中预设偿债缓冲安排以吸收发电推迟期的还款压力【待供给：工行外方融资具体条款、担保协议及违约兜底补充协议文本】；同时申明EPC固定总价包干内的备用金（14,889,497.91欧元）仅覆盖建设期成本侧动态调控，不得挪作业主侧还款缓冲，防止缓冲责任错配。
3. **移民资金闭合时间表**：移民资金（约1亿美元）闭合时间是还款传导链的源头闸门。总包部建议业主与融资方将移民资金闭合时间表列为放款硬前置条件【待供给：几内亚财政部关于移民资金闭合时间表的正式文件】。

以上“合同救济+情景预案+资金闭合”三线并进，即风险登记册R10（移民征地延误与社会稳控风险，极高风险20）的应对部署：按5.1节分级规则列入项目最高级别风险控制清单，由EPC项目总经理与业主高层亲自督办，前置闭环预案齐备方可开工。

## 5.3 关键料源缺口勘探闭环与燃油供应链双重保供预案

针对料源缺口与燃油断供两类供应链风险，本节部署“前置闭环勘探”与“双源保供+现场高冗余储能”两项预案；工程量与强度边界见各节表内，不再另述论证。

### 一、 石料场花岗岩70万m³缺口与勘探前置闭环程序

福米水电站枢纽主体工程包含心墙堆石坝（最大坝高45m）、二期上游围堰（轴线长748.95m、高27m、填筑量107.71万m³）以及混凝土总量44.0万m³等庞大工程量，施工高峰期土石方填筑强度达45.7万m³/月。项目面临**石料场花岗岩70万m³开采缺口**的重大料源风险，同时市场伴随水泥等大宗建材短缺涨价（2025年水泥涨至9.5万–10万 GNF/袋）的严峻挑战。为彻底消除料源断供风险，总包部建立“勘探前置-质量认证-闭环审批”的前置闭环管控程序。

```
[施工准备期/净准备期(3个月)]
       │
       ▼
【阶段一：划定补充勘探区】──► 联合几内亚地质矿业部，在坝址周边及进场路（坝址至康康88km）沿线划定新花岗岩料场勘探网格
       │
       ▼
【阶段二：理化性能与储量闭环认证】──► 进行打钻取芯与爆破试验，核验花岗岩抗压强度、风化程度及实际可采储量（须达到≥100万m³储量储备，覆盖70万m³缺口）
       │
       ▼
【阶段三：开采特许权与环保闭环】──► 办理L/97/038/AN法框架下的开采许可与用地手续，确保满足自然栖息地保护与矿山复垦要求
       │
       ▼
【阶段四：开工前置核准门禁】──► 形成《新料源勘探闭环终审报告》，经咨询工程师与业主联合签字核准后，方可启动主体坝体填筑
```

#### 料源与大宗建材风险防控要点清单
1. **花岗岩缺口前置补齐**：在开工前3个月净准备期内，完成新料源详查。优先利用主体工程基坑开挖料（如二期导流利用开挖料填筑75.84万m³），降低外购与采石开挖成本。
2. **建材价格锁定与进口备通道**：针对水泥短缺涨价（9.5万–10万 GNF/袋），签订跨国供货锁价协议；依托科纳克里港清关（5–15天周期）及西非共同体关税（ECOWAS CET + 18%进口VAT），建立进口水泥与本地采购双轨应急保障。
3. **补充数据要求**：
   - 【待供给: 需新石料场详查地质勘探报告、花岗岩岩体物理力学试验数据与矿权许可审批批复文件】
   - 【待核：新料源距坝址实际运距及运输道路改造预算金额】

### 二、 燃油供应链双源保供与现场高冗余配置

2023年12月几内亚首都发生油库大爆炸（导致25人死亡、459人受伤），直接造成全国性燃油断供与物流瘫痪。福米工程高峰期配备施工高峰人数1050人（总工日63.3万工日）、20t自卸车28辆及大量重型开挖填筑机械，燃油供应链成为项目施工履约与防汛安全的“生命线”。

#### 燃油供应链双重保供架构表

| 维度 | 保供措施与技术指标 | 现场执行标准与控制目标 | 风险响应与兜底机制 |
| :--- | :--- | :--- | :--- |
| **现场储能冗余** | **配置大容量现场备用储罐区** | 现场储罐总容积需满足高峰期（土石方开挖17.0万m³/月、填筑45.7万m³/月）**至少30天连续满负荷施工**的燃油消耗量。 | 防范油库爆炸等极端突发断供事故，确保基坑抽水与二期围堰防汛设备不停机。 |
| **采购供应链** | **双源保供（Dual-Sourcing）协议** | 严禁单一供应商绑定，联合几内亚国家石油公司（Total/Shell等）及跨国贸易商签订双源保供合同。 | 当一级供应商受损时，二级供应商在24小时内无缝接管供油承诺。 |
| **运输与物流** | **进场路干线公路防阻保障** | 依托已建成的坝址至康康88km进场路，建立燃油专用运输车队与沿线安全护送机制。 | 避开科纳克里港单一运输瓶颈，备用从邻国（如马里/塞内加尔）陆路转运燃油通道。 |

- 【待供给: 需现场油罐区具体设计储量容积（m³）、日均柴油消耗量估算表及双源供应商意向协议文本】

## 5.4 突发事件四级19项应急预案与动态演练机制

针对5.1节已定级的政局（R01）、罢工（R06）、燃油（R07）、公卫（R08）等风险，总包部建立四级响应+19项专项预案的应急管理体系，并按“演练—评估—迭代”年度循环运转。

### 一、 四级应急响应分级架构

```
【Ⅰ级：特别重大响应 (国家级/政治巨变)】
 ├── 触发条件：政局剧烈更迭（政变/大选战乱）、全国性恶性传染病大爆发、军事封锁
 └── 指挥层级：EPC项目总经理 + 几内亚大使馆 + 集团总部应急指挥中心

【Ⅱ级：重大响应 (行业级/跨区域动荡)】
 ├── 触发条件：全国大罢工、燃油/大宗建材全国断供、超标准特大洪涝过堰
 └── 指挥层级：总包部副总经理 + 现场各分部负责人 + 业主代表

【Ⅲ级：较大响应 (项目级/区域性事件)】
 ├── 触发条件：现场爆发局部传染病疫情（疟疾/埃博拉局部确诊）、劳工群体性罢工、进场路断绝
 └── 指挥层级：现场安环总监 + 施工分局局长 + 现场医疗保障组

【Ⅳ级：一般响应 (现场级/局部事故)】
 ├── 触发条件：单项设备重大故障、局部基坑涌水、一般性工伤事故
 └── 指挥层级：施工队长 + 现场安全员
```

### 三、 动态演练与预案迭代机制

1. **实操演练频次**：
   - **Ⅰ级/Ⅱ级预案**：每年至少开展 **1 次** 联合桌面推演与实景撤离演练（重点为政局更迭撤离与全国大罢工闭环响应）。
   - **Ⅲ级/Ⅳ级预案**：每年在雨季来临前（**4月上旬**）开展 **1 次** 现场防汛过堰与防疟/防埃博拉突击演练。
2. **闭环评估与预案迭代**：
   - 每次演练结束后 **24 小时内** 必须出具《演练实效评估报告》，针对演练中暴露的物资短缺（如防疟药品、燃油储备）或响应时延进行限期整改。
   - 根据几内亚当地法律变更（如劳动法修订、税率变化）与政治形势，每半年动态更新一次19项预案文本。
