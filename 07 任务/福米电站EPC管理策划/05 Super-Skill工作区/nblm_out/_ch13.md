# 《几内亚福米水电站EPC建设管理策划方案》
## 第13章 试运行移交与75人属地化运维衔接打通商业闭环

**本章核心响应**：针对中国工商银行（ICBC）审贷官关于“项目建成后靠什么还钱、后期运维由谁管理”的核心审贷关切，通过确立黄河院与水电三局联合运维责任主体、构建75人“中几联合”三阶段过渡团队、规范单机72小时试运行零外溢移交标准，以及锁定电网网关计量与铝土矿税置换还本付息链条，全面打通项目全生命周期商业与运营闭环 [6]。

## 13.1 《运维计划V3》全生命周期运维规划与联合实施机制

为确保福米水电站从建设期向运营期平稳过渡，解决审贷官关于“后期运维由谁管理”的风险担忧，EPC承包商联合体正式执行由黄河勘测规划设计研究院有限公司（黄河院）与中国水利水电第三工程局有限公司（水电三局）联合署名的《运维计划V3》 [11, 14]。该计划覆盖建设期第15个月提前介入、5年商业运维保障及50年全寿命周期大修规划。

### 1. 《运维计划V3》全生命周期时间轴与阶段划分

《运维计划V3》将工程运维管理划分为三个核心阶段，时间跨度从建设期延伸至50年运营期：

- **建设期提前介入阶段（第15个月至第33个月）**：
  - **介入节点**：在工程建设期第15个月，运维团队正式进场 [11, 14]。
  - **衔接节点**：匹配可研2026版“开工后第33个月首台机组发电”节点（工程总工期41个月）。
  - **核心任务**：全程参与设备安装督导、图纸会审、隐蔽工程验收、运维规程编制及属地化人员实操培训。【待供给: 《运维计划V3》建设期介入阶段详细培训手册与驻场准备预算】
- **5年商业运维与过渡阶段（首台机组发电至商业运营第5年）**：
  - **服务承诺**：由黄河院与水电三局提供为期5年的商业运维保障服务 [11, 14]。
  - **核心任务**：联合团队全面负责电站发电调度、日常巡检、设备保养与突发故障抢修，同步推进75人团队的技能转移与属地化管理交接。
- **50年大修与远期运营规划阶段（第6年至第50年）**：
  - **规划周期**：建立覆盖50年全寿命周期的枢纽大修及设备更新规划 [11, 14]（注：可研国民经济评价计算期为44年=建设4年+运行40年，运行期编制为50人）。
  - **核心任务**：定期开展水工建筑物（心墙堆石坝最大坝高45m、溢流坝段最大坝高50m）安全监测评估、水轮发电机组（3×30MW）大修及开关站（140m×59m）设备更新。【待供给: 50年大修规划具体节点分布表与专项储备基金提存方案】

### 2. 黄河院与水电三局联合实施职责分工

联合体双方发挥“设计+施工+运维”一体化优势，明确权责边界：

## 13.2 75人“中几联合”三阶段过渡团队搭建与属地化管理

为解决几内亚本地电力技术人员匮乏问题，同时满足高管属地化政策要求，项目组搭建“30名中方专家+45名几方员工”共计75人的三阶段过渡运维团队，实现技术无缝转移与管理风险可控 [11, 13, 14]。

### 1. 75人过渡团队人员构成与岗责配置

- **团队总规模与配比**：过渡期编制为75人，由30名中方专家与45名几方员工组成，几方人员占比达60% [11, 13, 14]。（注：可研长远运行期人员编制为50人，年工资福利15k欧元/人/年；过渡期额外增加25人编制专用于“一对一”带徒培训与安全冗余）。
- **高管岗位属地化突破**：副总经理等核心高管岗位明确由几方人员担任，打破中方单一管理壁垒，增强当地政府与社区认可度 [11, 13, 14]。

### 2. 三阶段属地化过渡演进机制

75人团队通过三阶段动态调整，逐步完成从“中方主导”到“几方独立运维”的交接：

```
[阶段一：中方主导与带徒期] (第15-33个月建设期及商业运营第1-2年)
  ├── 中方专家(30人)：担任总经理、总工程师及关键岗位，全面把控运行安全
  └── 几方员工(45人)：担任副总经理 [11, 13, 14] 及跟岗操作员，开展“一对一”实操培训
        │
        ▼
[阶段二：中几并行与交叉授权期] (商业运营第3-4年)
  ├── 几方员工：接管部分部门经理及值长岗位，副总经理深度参与经营决策 [11, 13, 14]
  └── 中方专家：退居技术顾问与质量督导岗位，中方人数逐步核减【待供给: 逐步退场计划】
        │
        ▼
[阶段三：几方主导与中方保障期] (商业运营第5年及以后)
  ├── 几方团队：独立承担电站日常运行与巡检维护
  └── 中方保障：仅保留极少数核心专家进行50年大修督导及重大技术支持 [11, 14]
```

## 13.3 单机72小时试运行与竣工验收移交标准程序

为响应中国工商银行（ICBC）审贷官关于“试运行及移交阶段成本与责任界面外溢”的风险关切，项目建立单机72小时试运行与竣工验收移交标准化程序，明确试运行期电量结算、设备损耗及安全责任界面，确保试运行期实现“零额外成本外溢”。

### 1. 单机72小时满负荷试运行标准程序

根据工程配置，福米水电站机组采用3台单机容量30MW的水轮发电机组（总装机90MW，水轮机同步转速136.4r/min，额定水头22.5m）。试运行严格执行以下四阶段标准程序：

- **第一阶段：无水/有水单机调试与空载运行**
  - 完成发电机、变压器及开关站（尺寸140m×59m）电气试验，充水后完成水轮机无故障空载连续运行。
- **第二阶段：单机72小时满负荷连续试运行**
  - 每台机组须在额定水头22.5m条件下，连续完成72小时满负荷（30MW）带电网运行。
  - 试运行期间，机组瓦温、振动、摆度及电气参数必须全部符合设计规范；若中途因承包商设备或安装质量问题中断，须重新计时计算72小时。
- **第三阶段：3机（共90MW）联合联合调试与网关测试**
  - 联合运行测试电网接入Linsan-Fomi线路（坝下20km）的甩负荷与系统调压能力。【待供给: 几内亚国家电网输变电接口与甩负荷测试专项规程】
- **第四阶段：竣工验收与移交签署**
  - 完成72小时试运行后，由业主（几内亚能源部/水利部）、EPC联合体（黄河院+水电三局）及几内亚国家电力公司（EDG）共同签署《机组移交与商业运行启动证书》。

### 2. 试运行期零额外成本外溢控制边界表

| 风险/成本控制节点 | 标准程序与责任界面 | 费用与收入结算归属 | 零外溢保障机制 |
| :--- | :--- | :--- | :--- |
| **试运行调试电量收入** | 72小时试运行及试运行期间发出的上网电量，按网关计量设备精确核算。 | 调试电量收入优先冲抵试运行期柴油、水费及电力消耗成本。【待供给: 试运行期调试电价结算协议】 | 锁定购电方消纳责任，避免“发出来电无收入/不结算”导致的成本损失。 |
| **设备缺陷与消缺成本** | 72小时试运行期间发生的设备损坏或安装缺陷，由EPC联合体负责消缺。 | 消缺费用全部涵盖在EPC合同静态总投资（405785k欧元）及预备费内。 | 严禁向业主增索追加费用，同时通过设备质保金约束分包商。 |
| **电网故障导致中断损失** | 因外网（如Linsan-Fomi输电线路）故障导致72小时中断的，责任归属业主/电网。 | 停机等待期电费成本与延期责任由业主承担/免责。 | 签订防范外网故障免责协议，防止承包商承担电网原因造成的额外窝工费。 |
| **损耗与运行运维费用** | 试运行期间的日常运维由第15个月提前介入的“30中+45几”75人团队承担。 | 运维人员工资已列入建设期管理预算，不产生额外增量编制费用。 | 75人团队直接就位，防止临聘外部专家产生高额额外咨询费。 |

## 13.4 几马电网网关计量与铝土矿税置换资金链闭环

本小节直接回应审贷官关于“项目建成后靠什么还钱”的融资可行性关切。通过建立几内亚-马里（几马）电网网关双向计量，配合“资源换贷款/资源置换收益金”机制，第5-17年每年锁定14449k欧元（即每年1444.9万欧元）的铝土矿税置换收益金，与PPA电费现金共同支撑每年26128k欧元的还本付息——按PPA现金口径如实表述为“紧平衡”：矿税托管账户为主（55.3%）、电费现金为辅（44.7%）；第18-19年矿税置换续签【待核】，各项偿债法律文件均【待供给】（见本节末补件时间表位）。

### 1. 项目融资结构与还本付息财务基准

根据可研2026版财务评价及数字基准表，项目的资金筹措与债务结构如下：

- **项目总投资与融资比例**：
  - 静态总投资：405785k欧元（4.058亿欧元）。
  - 资金筹措架构：采用『资源换贷款/资源置换收益金』机制。
    - **债务融资（贷款本金）**：262260k欧元，占比64.6%。
    - **资本金**：185618k欧元，占比35.4%。
- **债务偿还条件（第5-19年）**：
  - 贷款利率：5.5%（暂取值，融资条款未定）【待供给: 融资协议/贷款条款正式文本】。
  - 贷款期限：共19年，其中**宽限期4年**（建设期第1-4年），**还款期15年**（第5-19年）。
  - 还本付息方式：等额本息还款，还款期内每年需偿还**26128k欧元**（约2612.8万欧元/年）。

### 2. 靠什么还钱：矿税托管账户+PPA电费现金两支柱紧平衡偿债

还款期（第5-19年）的偿债资金由两大支柱构成——**铝土矿税托管账户为主（占年还本付息的55.3%）+PPA电费现金为辅（占44.7%，即差额11679k欧元/年）**，两支柱合计覆盖每年26128k欧元还本付息，属“紧平衡”结构、无单支柱冗余：

1. **第一支柱（主支柱）：铝土矿税资源置换收益金托管账户**
   - **资源置换机制**：基于几内亚丰富的铝土矿资源，几内亚政府将铝土矿特许权税/矿业税划拨至指定还贷托管账户（Escrow Account）。
   - **置换金额与年限**：还款期前13年（即第5年到第17年），**每年锁定资源置换收益金14449k欧元（1444.9万欧元/年）**，承担每年26128k欧元还本付息中的55.3%（第18-19年是否续签【待核】）。
   - **法律文件**：矿税划拨托管账户的政府法律生效文件【待供给】（见本节末补件时间表位）。
2. **第二支柱：PPA电价电费现金与网关计量**
   - **网关计量设置**：在坝下20km处的Linsan-Fomi电网接入点设立几马电网双向高精度网关计量关口，锁定输往几内亚国家电网及马里（根据2014几马协议与区域电网互联）的售电量。
   - **电价机制**：上网电价参照阿玛利亚（Amaria 300MW电站）购电协议（PPA），在40年运行期内逐年递增，电价区间为**0.0891 → 0.1793 欧元/kWh**；福米项目自身PPA正式文本【待供给】。
   - **偿债现金口径（按PPA现金测算）**：起点电价0.0891欧元/kWh×本期年发电量290GWh（2.9亿kWh）≈**2,580万欧元/年**电费现金收入，再减运维支出即为可支配偿债现金；对照年还本付息2,612.8万欧元（26128k欧元），电费现金单独不足，须与矿税托管账户（为主，55.3%）合成紧平衡覆盖，电费支柱承担差额11679k欧元/年（44.7%）。运维支出全额口径【待核】（可研仅载运行期人员编制50人、15k欧元/人/年）。
3. **财务评价指标如实分层**
   - 全部投资IRR为2.95%，资本金IRR为4.88%，投资回收期28.9年，最高资产负债率由62.5%逐步降至0%——该收益水平系“资源换贷款/资源置换收益金”模式的常态特征：项目偿债保障不建立在高财务回报假设之上，而建立在矿税托管账户+PPA电费现金两大支柱及其法律文件（均【待供给】）之上。
4. **国民经济评价口径（非偿债现金流，仅限本小节使用）**
   - 影子电价口径（替代柴油发电成本0.376欧元/kWh）下，本期年发电量290GWh对应年发电效益106866k欧元；该数字属国民经济评价的经济效益口径，**非偿债现金流**，不得用于偿债覆盖论证。
   - 国民经济评价EIRR达17.9%（17.87%），ENPV为566419k欧元，效益费用比2.32；在投资增加10%/效益减少10%的极限敏感性测试下，EIRR仍达15.12%（>8%），项目宏观经济效益与抗风险能力稳健。
