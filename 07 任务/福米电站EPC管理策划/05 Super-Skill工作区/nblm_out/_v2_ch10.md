### 10.1.2 一/二/三级计划架构与P6+PPM动态纠偏机制
项目建立“一级合同计划 - 二级执行计划 - 三级工序计划”多级计划管控体系，基于 Primavera P6 与 PPM（项目组合管理系统）平台实施资源费用加载与动态纠偏，保障41个月总工期控制节点实现。

```
[一级合同计划] → 锁定里程碑节点 (第33个月发电 / 第41个月完工)
 ↓
[二级执行计划] (项目部综合排程) → 加载人/机/料资源与资金S曲线 (月度/季度动态纠偏)
 ↓
[三级工序计划] (9大作业工区) → 精细化至周/日工序排程与现场搭接
```

#### 1. 三级计划分级管控要点
* **一级合同计划（里程碑控制层）**：以开工后第33个月首台机组发电、第41个月整体完工为最高控制节点，锁定导流截流、围堰填筑、土石坝填筑、厂房混凝土浇筑与机电安装等关键线路。
* **二级执行计划（资源排程管理层）**：由项目部按月度/季度进行综合排程，将施工工程量按时间轴分解，深度加载人工、机械装备及资金支出预算（S曲线），作为现场施工调度与资源配置的直接依据。
* **三级工序计划（现场作业执行层）**：由**9个作业工区**（开挖工区、填筑工区、混凝土工区、基础处理工区、金结机电制安工区、砂石加工混凝土拌和工区、机械工区、综合工区【待供给: 另外1个作业工区具体名称与职责】）编制周/日作业计划，落实到具体班组与工序搭接。

#### 2. P6+PPM资源费用加载与动态纠偏
* **资源与费用加载**：在P6软件中建立全过程WBS结构，将劳动力（高峰2686人）、施工机械（如20t自卸车28辆等）及直接费强度加载至网络计划节点，生成动态资源直方图与费用S曲线。
* **挣值分析（EVM）与预警机制**：基于PPM系统实时抓取现场实际工程量与费用进度，按月对比进度偏差（SV）与费用偏差（CV）。一旦进度绩效指数（SPI）低于临界值，自动触发资源重组与工艺优化程序，确保关键线路零延误。【待供给: P6与PPM系统集成接口参数及动态纠偏算法模型】

#### 3. 进度管理制度依据与审批链（体系文件）
三级计划体系执行EPC项目管理体系文件《项目进度管理》章（移植兰州水源地EPC体系文件），覆盖进度计划编制与审批、分包工作进度计划、计划实施与工作界面进度控制、进度纠偏、进度考核、进度报告全流程。分包三级计划实行**规定提交时限+分批组织进度会议**管理（兰州项目例会做法："项目部给施工分包单位规定提交三级计划的时间，分批组织进度会议"）；P6应用服务归口信息条线统一提供（兰州项目信息部工作手册列P6服务专节）。【待供给: 福米版《项目进度管理办法》文本及三级计划编报时限表】

## 10.3 “日保周、周保月、月保季”进度考核与黄橙红三级预警机制

### 10.3.1 “日保周、周保月、月保季”四级联动进度考核体系
项目建立“日跟踪、周调度、月考核、季纠偏”四级联动进度管控机制，将一级合同计划与二级执行计划目标分解落实到每日工序与施工班组，防止总工期控制节点出现累积性偏差。

#### 1. 四级联动控制要点清单
* **日保周（日计划与工序跟踪）**：各作业工区每日盘点当日实际完成工程量，严格对照三级工序计划。凡当日未完成的工序，必须在次日通过增加作业班次或调配机械补齐，确保不拖延周计划。
* **周保月（周调度与资源协调）**：每周由工程管理部组织召开进度调度会，盘点周计划完成率，重点协调劳动力（高峰期2686人，高峰月份两说【待核】）、施工机械（如20t自卸车28辆等）与大宗物资（水泥、钢筋、截流备料等）的现场调配，消除工序交叉冲突。
* **月保季（月考核与绩效挂钩）**：按月对比实际进度与P6+PPM生成的计划S曲线，开展挣值分析（EVM）。月度考核结果直接与项目部及各作业工区绩效奖惩挂钩，按进度履约情况结算工程款。
* **季纠偏（季盘点与气候适应）**：结合几内亚5-10月雨季与11-4月旱季的气候交替特点（另有5.1.1等处“12-3月旱季”版本并列注记），每季度对二级执行计划进行综合盘点与动态优化，防范季末累积延误。

#### 2. 进度考核分级控制矩阵表

| 考核层级 | 责任主体 | 控制频次 | 核心控制目标 / 动作 | 绩效挂钩与纠偏手段 |
| :--- | :--- | :--- | :--- | :--- |
| **日保周** | 作业工区 / 施工班组 | 每日 | 盘点单日工序完成量，实现工序无缝搭接 | 日清日毕，未完成工序次日加班或加机补齐 |
| **周保月** | 工程管理部 / 施工经理 | 每周 | 评估周计划完成率，消除现场跨工区作业冲突 | 动态调配现场机具装备与劳动力资源 |
| **月保季** | 项目经理 / 六部负责人 | 每月 | 对比P6月度计划与资金/资源S曲线，计算EVM | 绩效考核挂钩，触发预警与进度款结算 |
| **季纠偏** | 项目决策层（7人组） | 每季度 | 盘点季度里程碑，依据雨旱季气候调整下季计划 | 动态调整下季度资源配置与施工班次 |

#### 3. 周例会督办制度与进度管理措施（移植兰州水源地EPC做法）

* **周例会与督办清单制度**：每周项目经理例会，纪要采用**"问题-建议方案-会议结论-完成时间及责任人"五列格式**（兰州项目单次例会议题26项、督办事项17项，每项督办明确"1周内"时限+责任人）；纪要按文控编码规则编号归档（兰州式样"黄设兰水/JLB[2015]纪要002号"——福米替换为本项目编码位并增设法语/业主方代码位）。督办事项逾期未销项自动升级进入下周调度会议程。
* **文控与进度文件流转时限链**（进度计划、批复、变更文件全走此链）：外部来文30分钟内分发→部门负责人3天内处理完毕走完审批→逾期须主动申请延期、不得终止流程→每周六下午在办文件汇总批复；90%以上文件在信息系统中流转，配套月度KPI扣分制全量化考核（收文30分钟分发/当天发出或归档/服务器月故障<1次且<2小时等）。
* **进度可视化双重点**：4D进度监控系统（BIM模型挂接进度计划）+现场每日视频（视频质量不达标视为未提交）；数字工地二维码标志牌按"单位页+工作面页"8要素（地理位置/设计信息/施工方案/进度节点/现场报表/工作表单/建设动态/参建单位）覆盖全部作业工区（兰州项目11家施工单位+23个工作面）。
* **分包进度考核上岗制**：分包商关键管理岗位**考核上岗、通过考试方可上岗**；分包工作进度计划按体系文件规定编报审批；分包信息报送质量与支付挂钩（兰州项目"支付建议权"做法：信息系统质量/进度/HSE模块信息上报的及时性、完备性不达标→影响支付建议）。
* **进度信息化支撑建制**：信息/文控复合部门9人7岗（信息总控工程师/网络工程师/文控工程师/档案管理员/信息宣传员/对外汇报助理/会议室管理员），P6应用服务归口该条线；文控按分包商分人对接。
* **会议制度体系**（莫莫克合同制度条款移植）：合同交底会（合同生效1周内）→业主开工会议（3周内）→项目开工会议（4周内）→月度汇报会→周例会，配信息传递矩阵。
* 【待供给: 福米《项目进度管理与考核办法》本土化细则、法语版文控编码表、周例会纪要与督办清单模板】

#### 进度监测-偏差分析-纠偏闭合流程（赶工与纠偏机制）

预警触发后按四步闭合处置，销项验证前预警不解除：

```
进度监测（工区日工程量盘点 / 周计划完成率 / 月度EVM对比P6计划S曲线 + 4D进度可视化与每日视频）
 → 偏差分析（区分关键线路/非关键线路；量化SV、SPI；归因识别：资源/供应/气候/设计接口）
 → 纠偏决策（按预警分级响应：加班次加机具补齐 → 资源重组调配 → 二/三级计划调整+全场资源重配）
 → 纠偏实施与销项验证（督办清单列为跟踪事项、1周时限销项；纠偏效果在下周例会复盘确认后方可闭项）
```

* **刚性窗口约束**：粘土填筑全年有效施工天数仅**148天**（5-10月雨季停工）、石料**308天**（可研10.4.2/表10.4-2）；一二期截流均须抢4月初枯水窗口（截流流量63.9m³/s）；3#底孔下闸至首台发电仅4个月（2029年5月→9月底，靠P=85%来水蓄至死水位383m）——**错过旱季窗口的进度偏差无法用日历时间弥补，必须以资源强度补偿**。
* **赶工资源预置**：关键工序备料按含损耗配置（截流抛投总量36,449m³含30%备料损耗的做法推广至骨料/粘土旱季备料仓）；机械工区落实高峰期设备完好率管理，赶工优先调配20t自卸车等主线设备至关键线路；砂石加工混凝土拌和工区建旱季备料仓防雨季供料中断。

## 10.4 现场矩阵式组织架构与工期履约保障

### 10.4.1 “决策层7人+六部+专家顾问组”现场组织架构
项目部采用**矩阵式管理**模式，建立集中统一的现场指挥体系，保障41个月总工期实现。

#### 1. 现场组织架构要点清单
* **决策层（7人）**：由**项目经理、施工经理、商务经理、财务总监、总工、设备物资经理、HSE总监**组成，对项目进度、质量、安全、成本与商务履行行使最高决策权。
* **职能部门（六部）**：
 * **工程管理部**：负责P6+PPM多级计划编制、日周月进度调度、现场施工组织与计量。
 * **经营管理部**：负责商务合同、进度款结算、合同纠偏与变更索赔。
 * **质量管理部**：负责施工质量过程控制、隐蔽工程验收与质量检测。
 * **安全环保部（HSE）**：负责现场安全生产、环境保护及几内亚当地HSE合规管理。
 * **设备物资部**：负责施工机械装备（如20t自卸车28辆等）、大宗材料（水泥、钢筋、截流备料等）采购与供应链保障。
 * **综合事务部**：负责当地雇员（高峰2190人）外联、行政后勤、业主与政府关系协调。
* **专家顾问组**：为复杂地质条件下的土石坝填筑（3,181,509m³）、导流截流（双岸立堵、49.1m³/s演算）及高边坡处理提供技术支撑与重大技术方案把关。

### 10.4.2 9大作业工区矩阵式管控与资源保障
