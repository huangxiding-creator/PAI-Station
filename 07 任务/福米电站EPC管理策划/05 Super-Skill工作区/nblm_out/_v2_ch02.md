# 第2章 工程特点、重难点分析与应对

## 2.1 重难点综述

1. **难点性质**：本工程难度不在单点技术峰值，而在「几内亚实施条件、混合坝型、停摆十年重启」三重叠加。单一内陆运输通道与雨季窗口是全局性约束，直接决定41个月工期成败。
2. **分类治理**：十四项重难点按三类治理——实施条件类六项靠「排程与保供预案」化解，工程技术类五项靠「设计定案+施工组织设计」化解，管理类三项靠「接口清单与风险登记」化解。
3. **应对依据**：可研2026版为定稿设计文件，水电三局施组（2018年投标版）提供全套施工组织设计，运维计划V3提供属地制度与应急预案。
4. **数据纪律**：无据事项以【待供给】【待核】明确列示，不作估算填补；两版本并存无法裁定者并列标注。

## 2.3 几内亚实施条件类六项解析

### 一、 A1 雨季窗口刚性约束

1. **雨量高度集中**：坝址流域多年平均降雨约1,900mm（Kankan站1,898mm），5-10月雨季占全年92%、7-9月占61%；科纳克里年降雨3,800-4,300mm、7-8月单月可超1,100mm，为全球最湿首都之一。
2. **填筑窗口收窄为刚性边界**：粘土填筑全年有效施工天数仅148天（5-10月雨季停工5个月），石料308天；全年极端最低气温8.0℃不影响填筑——约束唯一来自降雨。
3. **雨季降效有先例**：2025年9月强降雨致科纳克里港作业瘫痪、内陆道路恶化；港口清关与干线运输必须按雨季降效系数预留缓冲。
4. **应对措施**：粘土填筑与土石方高峰锁定11-4月旱季，雨季转室内机电安装、边坡截排水与防护；「旱季抢填筑、雨季保厂房」波浪式推进做法与雨季施工措施12条可直接复用；汛期24小时值班与基坑撤退预案前置。

### 二、 A2 科纳克里港650km内陆单一通道

1. **通道唯一**：材料设备均自科纳克里港公路运输，几内亚国内无铁路通达坝址区域；全国约95%货物与人员流动依赖公路；科纳克里-康康窄轨铁路1993年起停运，西芒杜600余km铁路为矿石专线不对外承运。本文统一采用科纳克里—坝址650km版本（555km为旧版本不采用）；可研10.5.1另有库鲁萨530km/康康620km并列版本。
2. **末端接驳已具备**：坝址至Kankan约88km专用进场道路已建成投用（右岸方案2：6号公路26km+改建约46km+新建约6km）。
3. **港口与清关基准**：科纳克里自治港年约800艘船/700万吨/8万TEU、航道13m、4台40t岸吊+125t移动吊；清关常规5-15天（单证齐备后）、到港90天提离红线、单证不齐为延误首因。
4. **重大件为最高风险项**：内陆重大件运输系几内亚工程最高风险项之一；转轮直径4.70m、单机水轮机约340t、发电机约330t、主变3台40MVA、坝顶门机单重365t；金结运输单元限制≤3.5×3.5×12m/≤50t。沿线桥梁荷载与路面承载力专项评估【待供给：科纳克里至坝址650km内陆大件运输沿线桥梁限载及公路修复专项方案】；科纳克里港重大件装卸工程参数（桥吊/滚装泊位/吃水）与N1桥涵载荷限制未获取【待供给，需委托当地运输商实测补采】。
5. **应对措施**：科纳克里+马木两级中转站（人员进退场/设备存放/救援/道路维护）；西芒杜走廊21-57吨级重大件运输实践可资参照。

### 三、 A3 当地建材与现场能源短板

1. **水泥短缺涨价有先例**：2025年6月几内亚全国性水泥短缺，袋装水泥涨至95,000-100,000几郎/袋（约11美元，此前约7-8美元），拖慢全国公私项目；几内亚零熟料线、全部为进口熟料粉磨站（CIMAF/GIC/Massayah/西非水泥）；可研版本水泥可首都附近水泥厂采购。
2. **钢材辅料全进口**：几内亚无大型钢厂及火电厂，钢筋、粉煤灰需周边国家进口；钢材本地供应与骨料本地产能价格无公开数据【待供给，需现场考察或代理询价】。
3. **细骨料需加工掺配**：河床天然砂细粒超标，需清洗并掺破碎花岗岩调整级配。
4. **现场能源单线**：工程区电网严重不足，施工全程自备柴油发电；施组配6台1000kW 10kV柴油发电机；工程区无手机信号覆盖，以海事卫星电话+对讲机保障。
5. **应对措施**：水泥保供协议带价格联动与保供条款（锁定CIMAF/GIC）；坝址自建砂石系统（550t/h毛料/440t/h成品系统，施组5.1/5.2·2018投标版版本）；钢材粉煤灰汛前战略备料。

### 四、 A4 劳工制度与属地化法定义务

1. **劳动法硬约束**：现行《劳动法典》为2014年1月10日第L/2014/072/CNT号法律；法定周工时40小时，加班费不低于125%、每周强制连续休息24小时；最低工资SMIG为550,000几郎/月（2022年6月总统令，此前440,000）；CDD定期合同同一雇主每年最多签两次；外籍员工须事前许可+居留证+工作许可。
2. **属地化是法定义务而非成本选项**：几内亚雇员最低配额与几籍高管、周边社区优先招聘为法定义务（采矿法典第108条范式+世行版本）；外籍用工法定配额比例无法条级来源【待供给：几内亚劳动部/ANEPIJE现行细则审定】。
3. **用工结构样本**：施组样本高峰2,686人=中方496+当地雇员2,190（约1:4.4）、当地雇员独立营地9,340m²/400间；可研2026版版本高峰1,050人，两版本并存按文件分别标注。
4. **技能短板有解法**：几内亚无特种作业资格体系，参照中国标准培训考核发证；一专多能、内部培训≥12个月。
5. **应对措施**：属地用工比例设为政府关系KPI；劳工关系专岗+工资足额按期发放内控（防范2024-02全国总罢工与2025-11西芒杜欠薪罢工先例重演）。

### 五、 A5 政局安保与社会安全

1. **政局过渡期风险**：2021年9月政变后至2025年12月28日大选完成过渡（杜姆布亚86.72%当选、最高法院2026-01-04确认）；军政府持续更替高官（2026年8月仍在）；2025年经济增速约7.4%、世行预测2026年8.8%（矿业驱动）。
2. **社会安全事件先例**：2024-02-26全国总罢工瘫痪首都与矿业；2023-12-18科纳克里油库爆炸（25死459伤）引发全国燃油危机、IMF确认2024全年燃油供应不稳；东南边境马里武装外溢威胁矿区；2023-11-04科纳克里枪声（使馆紧急提醒）；2025-11西芒杜中资承包商欠薪罢工。
3. **安保应急已成文**：运维V3四类19项应急预案汇编（社会安全/自然灾害/事故灾难/公共卫生）、卫星电话每年2次应急演练、与当地政府和警方信息互通联动，《宪兵管理细则》《安保工作管理办法》中法双语制度在册；中国私保公司在非洲护卫高管与工地已成业态。
4. **燃油储备**：施组油库（坝区6×50m³+石料场2×50m³）仅约7天用量，须按油库爆炸危机情景扩容储备。
5. **卫生防疫**：几内亚100%人口处疟疾高传播区（WHO 2024）、全国患病率约44%；2014-16埃博拉疫情起源于几内亚（终计约3,811例/2,543死）、2021-02复发；血吸虫等列入可研健康防疫包。

### 六、 A6 汇率与税收环境

1. **几郎贬值趋势**：几内亚法郎GNF管理浮动、非西非法郎区；1美元兑几郎由2025-12-31美国财政部官价8,717升至2026年10月市场30日均价约8,817（区间8,785-8,857）；BCRG央行外汇拍卖主导分配、2024年几郎现金短缺。BCRG购汇获批比例/等待时长/利润汇出文件时限等实操细节未稳定核验【待供给】。
2. **进口税负模型**：进口增值税18%（按CIF+关税+RTL基数，2017年财政法起）、ECOWAS CET关税+统计税1%；企业所得税35%与25%两版本并存【待核：以几内亚现行财政法审定】。
3. **法律保障与既有商务框架**：投资法（L/2015/008/AN）第17条外汇保障、第13/14条棘轮稳定条款、第28条战略性优先项目延长条件；建设期首台套设备进口免征关税及TVA（仅需TE 0.5%+RTL 2%×CAF）；可研商务框架：资源置换收益金14,449千欧元/年（前13年）。
4. **应对措施**：美元/欧元计价合同+本地支出比例封顶+汇率对冲条款+购汇时效风险储备金；设备临时/永久进口税务筹划在合同谈判期前置锁定。

## 2.4 工程技术类五项解析

### 一、 B1 花岗岩料源缺口（98.9万m³ vs 70万m³）

1. **缺口事实**：坝址上游右岸约2km花岗岩体（Morinimaya石料场为主、Kato补充）两场已勘探储量仅70万m³，小于工程需求约98.9万m³（反滤/骨料/护坡共需开采），新料源勘探为下阶段必办事项——属尚未解决的料源供给风险。
2. **需求全账可核**：心墙粘土23.7万m³+围堰粘土2.1万m³、均质坝粘土213.6万m³、堆石料58.9万m³（利用泄洪系统开挖28.6万+页岩料场30.3万）、混凝土44.0万m³、反滤料12.4万m³、过渡料22.3万m³、块石护坡23.2万m³、浆砌石7万m³。
3. **土料储量满足需求**：大坝上游两岸Ⅰ级阶地及缓坡粉质/砂质粘土可用层厚2-4m、地下水埋深3-4m，储量质量可满足；心墙粘土用坝址右岸MD-1粘土料场。
4. **地质附加项**：河床粉细砂层1-3m（最厚6m）；坝基岩体弱-强透水、基坑涌水需排水设计。
5. **应对措施**：花岗岩新料源勘探列开工前必办清单；开挖料利用率双版本（70%与50%）引用时逐项选定标注。

### 二、 B2 两期导流与截流（无导流洞方案）

1. **分期导流全参数**：一期先围左岸（全年10年一遇1,370m³/s），滩地建一期土石围堰（均质土、堰顶373.0m、最大堰高约5m、轴线长1,130m、堰顶宽7m），右岸束窄河床过流，施工左岸滩地土石坝及全部重力坝段；二期（全年20年一遇1,540m³/s）建上下游围堰（上游堰顶378.5m/最大高13.5m、下游堰顶373.5m/最大高9m），由3孔10m×10m导流底孔过流（进口高程366m），施工右岸河床段心墙堆石坝。
2. **截流与下闸时序**：一二期截流均为4月初、标准10年一遇月平均流量63.9m³/s，二期单戗立堵截流；2029年1月1#/2#底孔下闸（流量127m³/s、下闸水位368.0m），封堵期Q5%=238m³/s由3#底孔下泄；2029年5月初3#底孔下闸蓄水（流量63.9m³/s、下闸水位368.7m），按P=85%来水至2029年9月底蓄至死水位383m满足发电。下闸月份4月与5月初两处版本以表10.6-2为准。
3. **截流水力学设计**：施组（2018投标版版本）截流设计流量49.1m³/s、龙口60m→15m六级演算（落差峰值2.2m、流速2.51m/s、单宽能量3.9t·m/(s·m)）、双岸立堵分区抛投四级配料、设计抛投36,449m³、平均抛投强度559m³/h/最大671m³/h——重大施工方案专项论证实例。
4. **度汛组织**：项目经理任防汛第一责任人、汛期24小时值班、基坑撤退预案（先人后机）、块石/钢筋笼/抽水泵等物资储备；截流及雨季度汛水位淹没分析与应急预案【待供给】。

### 三、 B3 粘土心墙与土石坝填筑

1. **混合坝型长坝线**：枢纽为两岸土石坝+河床混凝土坝段布置，坝顶高程401.50m、坝顶总长1,525m；均质坝最大坝高46.5m、心墙堆石坝45m、溢流坝段50m（采用值）；混凝土总量44.0万m³。
2. **填筑窗口与强度双重挤压**：粘土有效施工148天/年（见A1）；土石方填筑高峰45.7万m³/月（可研版本；施组另载主坝高峰26.62万m³/月·2018投标版版本，两版本按文件分别标注）。
3. **分区碾压工艺定型**：粘土填筑3m³挖掘机装25t自卸、进占法、8t凸块碾、铺厚30-50cm碾8遍；反滤料「先土后砂法」14t振动碾30cm×8遍；过渡料60cm×6-8遍；坝壳料14t光面碾50-80cm×6-8遍。
4. **土石方平衡与开挖料利用**：多区并行开挖（Ⅰ/Ⅱ/Ⅲ区+右岸+厂房坝段+引渠+消力池海漫）、分层钻爆-挖装-运输一体化流水、临近建基面小梯段与预裂爆破控制、石料场台阶式分层开采；堆石料58.9万m³中28.6万m³利用泄洪系统开挖料。
5. **应对措施**：碾压试验先行、工艺参数表标准化交底、填筑强度按旱季窗口倒排；雨季含水量控制与防冲刷覆盖（截排水沟引流+塑料膜覆盖）。

### 四、 B4 大直径机组重大件运输与安装

1. **机组选型已定案**：ZZ550-LJ-470型机组3台，转轮直径4.70m、额定水头22.5m（最大28.75/最小12.50m）、额定流量151.32m³/s、额定转速136.4r/min（排除综合说明150r/min误记）、额定出力30.93MW、吸出高度-6.84m、GD²≥3,895t·m²。
2. **重大件运输为组合约束**：单台水轮机约340t、发电机约330t、主变3台40MVA、坝顶门机单重365t（可研6.2/8章；施组3.4.6/15.1·2018投标版版本），叠加650km内陆通道与港口125t移动吊能力边界（见A2）——重大件专项运输方案为必办件。
3. **安装调试衔接关键节点**：首台机组发电为开工后第33个月；施组记载机组安装211-213天/台、三台机组间隔3个月滚动发电。
4. **应对措施**：设备采购与运输计划按「港口-中转站-坝址」全链时序倒排；安装工序与厂房土建交付界面用网络计划锁定；试运行按单机72小时标准程序执行。

### 五、 B5 225kV送出工程与跨国并网消纳

1. **送出方案已定**：建设1条开关站至225kV Fomi变电站的225kV双回架空线路，LGJ-400/35钢芯铝绞线、2根24芯OPGW、自立式角钢塔；225kV Fomi变电站规划于坝址附近、不在本次EPC设计范围。
2. **边界即风险**：变电站接口在业主侧，送出线路与变电站投运时序直接约束并网发电与电费收益——接口责任与时序须入接口管理清单专责协调。
3. **属地标准与走廊约束**：绝缘污秽等级按IEC60815 Ⅱ级设计（爬电距离≥20mm/kV）、线路走廊清理净宽≥50m——走廊清理涉及属地协调。
4. **消纳保障双通道**：几马电网覆盖5城市年缺电5.9亿kWh（约为本期年发电量290GWh的2倍，各市靠柴油机组独立供电）；225kV几内亚-马里互联（PIEGM）获世行8,400万美元+欧洲团队3.3亿欧元共同融资，其中康康-福米段为全线最先进段。

## 2.5 管理类三项解析

### 一、 C1 停摆十年重启

1. **停滞根因在融资不在工程**：2017年9月与几内亚能源与水利部签署EPC总承包合同；2021年4月项目停滞（国际河流组织称「无任何融资落实」）；2018-2026年停摆、2021年政变后进一步停滞。
2. **两国机制定调重启**：2022年10月第7次几马部长级联席会议（康康）确认Fomi列入中几框架协定优先项目；2026年5月第8次联席会议（科纳克里）明确「重启并续建」——Fomi列入中几框架协定二期优先项目、几马按NBA法律文书定为「共同利益基础设施」、建议2026年内复工、启动成本-效益分摊研究；几内亚能源/计划/水利三部长、马里能源水利部长、NBA执行秘书、中国驻几大使孙勇与YREC代表与会。
3. **几方密集表态**：2026-02计划部「复兴关键一步」、2026-05「从承诺走向行动」、2026-06能源部长「为实际开工加紧行动」；重启原因为两国框架下铝土矿税偿还安排与区域电力一体化需求。
4. **基准文档时效风险与对策**：可研已更新至2026年7月版（正文14章+约220表，含全套融资测算）；环评更新版几内亚方审查中（荷兰NCEA 2024-06-14就ESIA工作大纲出具独立意见SEV-2024-05）；施组（2018投标版49个月/2018-12-01开工）与可研（2026版41个月/2027-01-01开工）两代版本并存，一切引用必须注明版本；运维V3（2026-08）载396m旧版本参数，引用前须统一到本期393m基准。

### 二、 C2 总包-分包界面

1. **界面格局既定且已有实际投入**：2018年12月水电三局与黄河院签署施工分包协议，涵盖土建、金属结构及机电设备采购安装；三局已实际投入（下游交通桥桥墩+营地砖房）；施组2018版即三局全案深度（分期导流/截流水力学/度汛/设备配置/十节点）。
2. **采购主导权留有调整余地**：设备采购分标段依法依规招标、「机电金结专门章节」、「采购要不要拿回来，也有可能拿回来」——策划按「总包统筹、依法分标、择优调整」执行。
3. **风险影响**：界面责任不清则结算扯皮、履约失控；采购主导权调整影响标段结构与供应链组织。
4. **应对措施**：强矩阵组织+策划控制中心16类总控职能统筹界面；分包进度款支付与信息系统上报质量及HSE履职硬挂钩、六类违约18种情形分类处置。

### 三、 C3 移民界面

1. **责任边界**：移民征迁由几方业主单独实施、总包提供技术协助；禁用「砍掉/瘦身」措辞，对外统一「经与利益相关方达成一致，明确本期建设内容与业主另行实施内容的边界」。
2. **台账数据在手**：水库淹没1,590户/15,662人（Kankan省6,412人+Kouroussa省9,250人）、淹没面积367km²、回水62km；实物指标原始数据出自黄河院2017年5月水库淹没区人口抽样调查——对工行采用可研2026审定版，外网版本（几内亚境内4.8万人等）不采用、仅作风险提示。
3. **接口风险**：移民进度直接制约2029年5月蓄水节点；施工期社区界面（库区3个CRD：Kiniéro/Koumban/Moribanya）由承包商管理。
4. **国际声誉前车之鉴**：苏阿皮蒂移民安置遭HRW/International Rivers国际批评（101村/约1.6万人搬迁，HRW 2020-04报告）；库区涉上尼日尔国家公园（严格保护区受影响约6.5%/陆域损失36.5km²/补偿22km²/L/97/038/AN特例许可）与Ramsar湿地Niger-Niandan-Milo（10,464km²）；国际河流组织/湿地国际/Both Ends长期在册Fomi——环评透明与主动沟通为既定策略。
5. **两国水利约束**：下泄流量≥100m³/s为两国共识、设计保证下泄101m³/s——施工期供水与生态基流由放水管保障（二期导流最低水头376m时过流21.9m³/s）。
