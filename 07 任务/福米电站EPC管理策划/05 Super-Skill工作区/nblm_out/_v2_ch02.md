## 2.1 重难点识别总判断

1. **难点性质判断**：本工程难度不在单点技术峰值，而在「几内亚实施条件×混合坝型×停摆十年重启」三重叠加。单一内陆运输通道与雨季窗口是全局性约束，直接决定41个月工期成败。
2. **分类治理判断**：十四项重难点按三类治理——实施条件类六项靠「排程与保供预案」消化，工程技术类五项靠「设计定案+施工组织实证」消化，管理类三项靠「接口清单与风险登记」消化。
3. **武器在手判断**：每项难点均有既有武器对应——可研2026版已闭合设计口径〔D04〕，水电三局施组（2018年投标版）提供全套施工组织实证〔D05，引用一律标注口径〕，运维计划V3提供属地制度与应急预案〔D08〕。
4. **零造假判断**：本章一切数字带出处；无据事项以【待供给】【待核】显性列示，不作估算填补；两口径并存无法裁定者并列标注〔K-18纪律〕。

## 2.3 几内亚实施条件类六项解析

### 一、 A1 雨季窗口刚性约束

1. **雨量高度集中**：坝址流域多年平均降雨约1,900mm（Kankan站1,898mm），5-10月雨季占全年92%、7-9月占61%〔可研1.3/3.3；K-05〕；科纳克里年降雨3,800-4,300mm、7-8月单月可超1,100mm，为全球最湿首都之一〔R02〕。
2. **填筑窗口收窄为刚性边界**：粘土填筑全年有效施工天数仅148天（5-10月雨季停工5个月），石料308天〔可研1.9.3/10.4.2/表10.4-2〕；全年极端最低气温8.0℃不影响填筑〔可研10.4.2〕——约束唯一来自降雨。
3. **雨季降效有实证**：2025年9月强降雨致科纳克里港作业瘫痪、内陆道路恶化〔R02〕；港口清关与干线运输必须按雨季降效系数预留缓冲〔R02〕。
4. **应对指向**：粘土填筑与土石方高峰锁定11-4月旱季，雨季转室内机电安装、边坡截排水与防护；「旱季抢填筑、雨季保厂房」波浪式推进方法论与雨季施工措施12条可直接复用〔施组上册6.4/2.2.2·2018投标版口径〕；汛期24小时值班与基坑撤退预案前置〔施组上册8.6.2·2018投标版口径〕。

### 二、 A2 科纳克里港650km内陆单一通道

1. **通道唯一**：材料设备均自科纳克里港公路运输，几内亚国内无铁路通达坝址区域〔可研1.9.4〕；全国约95%货物与人员流动依赖公路〔R02〕；科纳克里-康康窄轨铁路1993年起停运，西芒杜600余km铁路为矿石专线不对外承运〔R02〕。本文统一采用科纳克里—坝址650km口径（附录A所载555km为旧口径不采信）〔施组上册1.5.5.1·2018投标版口径〕；可研10.5.1另有库鲁萨530km/康康620km并列口径。
2. **末端接驳已具备**：坝址至Kankan约88km专用进场道路已建成投用（右岸方案2：6号公路26km+改建约46km+新建约6km）〔可研1.9.4/10.5.1〕。
3. **港口与清关基准**：科纳克里自治港年约800艘船/700万吨/8万TEU、航道13m、4台40t岸吊+125t移动吊〔R02/R05〕；清关常规5-15天（单证齐备后）、到港90天提离红线、单证不齐为延误首因〔R02〕。
4. **重大件为最高风险项**：内陆重大件运输系几内亚工程最高风险项之一〔R02〕；转轮直径4.70m、单机水轮机约340t、发电机约330t、主变3台40MVA、坝顶门机单重365t〔可研6.2/8章；施组3.4.6/15.1·2018投标版口径〕；金结运输单元限制≤3.5×3.5×12m/≤50t〔可研8章/表8-1〕。沿线桥梁荷载与路面承载力专项评估【待供给：科纳克里至坝址650km内陆大件运输沿线桥梁限载及公路修复专项方案】；科纳克里港重大件装卸工程参数（桥吊/滚装泊位/吃水）与N1桥涵载荷限制未获取【待供给，需委托当地运输商实测补采】。
5. **应对指向**：科纳克里+马木两级中转站（人员进退场/设备存放/救援/道路维护）〔施组上册2.2.8·2018投标版口径〕；西芒杜走廊21-57吨级重大件运输实践可资参照〔R02〕。

### 三、 A3 当地建材与现场能源短板

1. **水泥短缺涨价有实证**：2025年6月几内亚全国性水泥短缺，袋装水泥涨至95,000-100,000几郎/袋（约11美元，此前约7-8美元），拖慢全国公私项目〔R02〕；几内亚零熟料线、全部为进口熟料粉磨站（CIMAF/GIC/Massayah/西非水泥）〔R02〕；可研口径水泥可首都附近水泥厂采购〔可研1.9.1〕。
2. **钢材辅料全进口**：几内亚无大型钢厂及火电厂，钢筋、粉煤灰需周边国家进口〔可研1.9.1〕；钢材本地供应与骨料本地产能价格无公开数据【待供给，需现场考察或代理询价】。
3. **细骨料需加工掺配**：河床天然砂细粒超标，需清洗并掺破碎花岗岩调整级配〔可研2.5/10.2〕。
4. **现场能源单线**：工程区电网严重不足，施工全程自备柴油发电〔可研1.9.1〕；施组配6台1000kW 10kV柴油发电机〔施组4.7·2018投标版口径〕；工程区无手机信号覆盖，以海事卫星电话+对讲机保障〔施组4.9·2018投标版口径〕。
5. **应对指向**：水泥保供协议带价格联动与保供条款（锁定CIMAF/GIC）；坝址自建砂石系统（550t/h毛料/440t/h成品系统，施组5.1/5.2·2018投标版口径）；钢材粉煤灰汛前战略备料。

### 四、 A4 劳工制度与属地化法定义务

1. **劳动法硬约束**：现行《劳动法典》为2014年1月10日第L/2014/072/CNT号法律；法定周工时40小时，加班费不低于125%、每周强制连续休息24小时〔R02/R05〕；最低工资SMIG为550,000几郎/月（2022年6月总统令，此前440,000）〔R02〕；CDD定期合同同一雇主每年最多签两次〔R02〕；外籍员工须事前许可+居留证+工作许可〔R02〕。
2. **属地化是法定义务而非成本选项**：几内亚雇员最低配额与几籍高管、周边社区优先招聘为法定义务（采矿法典第108条范式+世行口径）〔R02〕；外籍用工法定配额比例无法条级来源【待供给：几内亚劳动部/ANEPIJE现行细则终裁】。
3. **用工结构样本**：施组样本高峰2,686人=中方496+当地雇员2,190（约1:4.4）、当地雇员独立营地9,340m²/400间〔施组7.3/4.2·2018投标版口径〕；可研2026版口径高峰1,050人〔可研10.6.2/表10.6-3，K-07〕，两口径并存按文件分别标注。
4. **技能短板有解法**：几内亚无特种作业资格体系，参照中国标准培训考核发证；一专多能、内部培训≥12个月〔D08运维V3 4.1.3/§5〕。
5. **应对指向**：属地用工比例设为政府关系KPI；劳工关系专岗+工资足额按期发放内控（对冲2024-02全国总罢工与2025-11西芒杜欠薪罢工先例〔R02〕）。

### 五、 A5 政局安保与社会安全

1. **政局过渡期风险**：2021年9月政变后至2025年12月28日大选完成过渡（杜姆布亚86.72%当选、最高法院2026-01-04确认）；军政府持续更替高官（2026年8月仍在）；2025年经济增速约7.4%、世行预测2026年8.8%（矿业驱动）〔R02/R05〕。
2. **社会安全先例库**：2024-02-26全国总罢工瘫痪首都与矿业；2023-12-18科纳克里油库爆炸（25死459伤）引发全国燃油危机、IMF确认2024全年燃油供应不稳；东南边境马里武装外溢威胁矿区；2023-11-04科纳克里枪声（使馆紧急提醒）；2025-11西芒杜中资承包商欠薪罢工〔R02〕。
3. **安保应急已成文**：运维V3四类19项应急预案汇编（社会安全/自然灾害/事故灾难/公共卫生）、卫星电话每年2次应急演练、与当地政府和警方信息互通联动，《宪兵管理细则》《安保工作管理办法》中法双语制度在册〔D08运维V3§5.5-5.6〕；中国私保公司在非洲护卫高管与工地已成业态〔R02〕。
4. **燃油生命线**：施组油库（坝区6×50m³+石料场2×50m³）仅约7天用量，须按油库爆炸危机情景扩容储备〔施组4.2·2018投标版口径；R02〕。
5. **卫生防线**：几内亚100%人口处疟疾高传播区（WHO 2024）、全国患病率约44%；2014-16埃博拉疫情起源于几内亚（终计约3,811例/2,543死）、2021-02复发；血吸虫等列入可研健康防疫包〔R02；可研12.3.9〕。

### 六、 A6 汇率与税收环境

1. **几郎贬值通道**：几内亚法郎GNF管理浮动、非西非法郎区；1美元兑几郎由2025-12-31美国财政部官价8,717升至2026年10月市场30日均价约8,817（区间8,785-8,857）〔R02〕；BCRG央行外汇拍卖主导分配、2024年几郎现金短缺〔R02〕。BCRG购汇获批比例/等待时长/利润汇出文件时限等实操细节未稳定核验【待供给】。

## 2.4 工程技术类五项解析

### 一、 B1 花岗岩料源缺口（98.9万m³ vs 70万m³）

1. **缺口事实**：坝址上游右岸约2km花岗岩体（Morinimaya石料场为主、Kato补充）两场已勘探储量仅70万m³，小于工程需求约98.9万m³（反滤/骨料/护坡共需开采），新料源勘探为下阶段必办事项〔可研10.2.2〕——属尚未闭合的供给风险。
2. **需求全账可核**：心墙粘土23.7万m³+围堰粘土2.1万m³、均质坝粘土213.6万m³、堆石料58.9万m³（利用泄洪系统开挖28.6万+页岩料场30.3万）、混凝土44.0万m³、反滤料12.4万m³、过渡料22.3万m³、块石护坡23.2万m³、浆砌石7万m³〔可研10.2.2/表10.6-1〕。
3. **土料无虞**：大坝上游两岸Ⅰ级阶地及缓坡粉质/砂质粘土可用层厚2-4m、地下水埋深3-4m，储量质量可满足；心墙粘土用坝址右岸MD-1粘土料场〔可研2.5/10.2〕。
4. **地质附加项**：河床粉细砂层1-3m（最厚6m）〔可研2.4〕；坝基岩体弱-强透水、基坑涌水需排水设计〔可研2.4/5.5.4〕。
5. **应对指向**：花岗岩新料源勘探列开工前必办清单〔可研10.2.2〕；开挖料利用率双口径（70%与50%）引用时逐项择源标注〔施组上册3.4.4.2/11.4.1·2018投标版口径，两处口径不一〕。

### 二、 B2 两期导流与截流（无导流洞方案）

1. **分期导流全参数**：一期先围左岸（全年10年一遇1,370m³/s），滩地建一期土石围堰（均质土、堰顶373.0m、最大堰高约5m、轴线长1,130m、堰顶宽7m），右岸束窄河床过流，施工左岸滩地土石坝及全部重力坝段；二期（全年20年一遇1,540m³/s）建上下游围堰（上游堰顶378.5m/最大高13.5m、下游堰顶373.5m/最大高9m），由3孔10m×10m导流底孔过流（进口高程366m），施工右岸河床段心墙堆石坝〔可研1.9.2/10.3/表10.3-4〕。
