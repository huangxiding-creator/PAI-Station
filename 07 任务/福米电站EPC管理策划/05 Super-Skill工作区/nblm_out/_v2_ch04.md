# 第4章 设计院牵头EPC模式的优势

设计院牵头EPC为国家政策确立的工程总承包主导路径（国办发〔2017〕19号、建市〔2016〕93号、建市规〔2019〕12号、GB/T 50358-2017），政策与行业定位不赘述；本章以国际设计-建造（DB，与设计院牵头EPC同属设计施工一体化交付）对照研究数据与黄河院实证说明该模式在福米项目的优势，公司实力明细见第1章表1.4-1。

#### 表4-1 国际交付绩效研究数据表（DB对照DBB/CMR）

| 研究 | 样本 | 核心结论 |
| :--- | :--- | :--- |
| Konchar与Sanvido经典研究（1998） | 351个项目（1984–1998） | 单位成本低约6%；成本增长少5.2%；工期增长少11.4%；施工速度快约12%；交付速度快约33% |
| Pankow基金会复刻研究（2018） | 212个项目（81 DB/78 CMR/53 DBB） | 交付速度较DBB快102%、较CMR快61%；施工速度快36%；中位成本增长0.85%对1.90%；中位进度增长0.00%对2.49% |
| ASCE元分析（2017） | 21项研究、4,600个项目 | 成本增长DB +2.8%、DBB +5.1%、CMR +5.8%；DB最稳定优势在速度与增长控制 |
| 联邦公路管理局研究 | 23个州、64个项目 | 平均工期缩短14.1%；造价降2.6%；96%业主评价质量等于或优于DBB；变更索赔不足总造价0.1% |
| 市场选择印证 | 美国非住宅建筑DB份额2018年39%首超DBB（27%），2028年预计近50%；新加坡设计施工一体化约占新建项目价值72% | 市场以份额投票，验证绩效结论 |
| 国际水电案例印证 | 苏布雷275MW提前竣工（约3.7年）、下凯富峡750MW、南欧江梯级1,272MW、凯乐塔240MW 40个月全面投运 | 非洲与东南亚水电EPC普遍由一体化主体交付并提前或按期投产 |

#### 表4-2 六大优势量化证据与黄河院实证总表

| 优势 | 核心量化依据 | 黄河院实证 |
| :--- | :--- | :--- |
| ①设计施工深度融合 | 最优组78%项目在设计深度≤30%组建一体化团队（最差组29%） | 兰州水源地15项前置报告10个月办结创全国第一；TBM制造周期由1年压缩至半年、主隧洞TBM段月均进尺782m |
| ②设计主导采购优化 | 电力勘测设计行业EPC占比81.19%；中设协前50家家均125亿元 | 技术协议设计盖章＋厂家图纸反向审定；福米机电与金结约5,208万欧元设备采购由设计端技术规格书直接锁定 |
| ③投资源头控制 | 设计阶段决定60%–75%工程费用（设计费仅占约5%）；元分析成本增长+2.8%对+5.1% | 莫莫克取水口优化压降单项概算21.8%；兰州固定总价47.78亿元52个月按期建成通水 |
| ④技术集成与标准输出 | 参编国标80余项、专利700余项；凯乐塔全盘中国标准 | CCS 1500MW为中国海外独立设计最大水电；凯乐塔工程形象印上几内亚2万法郎纸币 |
| ⑤设计变更主动管理 | 变更索赔不足总造价0.1%、平均单项目约8万美元；变更单约少6% | 库尔楚边坡裂隙当天连线定策、4年变形监测零异常未影响工期 |
| ⑥进度序优化 | 交付速度快33%–102%；平均工期缩短14.1% | 兰州可研到开工不到2个月、整体审批较同类缩短近1年；岱海134.24公里合同工期19个月 |
| 产业链生态 | 子公司深圳先河水电持有水利水电施工总承包壹级资质，江河咨询持有检验检测机构资质认定 | 全产业链自有能力 |
