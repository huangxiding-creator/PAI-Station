# 第19章 数字化管理

## 19.1 数字总包平台5.0与岗位工作室

数字总包平台5.0对福米水电站（Niandan河，装机90MW）建设过程实行全流程数字化管理，涵盖工程总承包管理体系下24个核心管理岗位工作室，标准化接口实现多端协同与数据实时归集。

### 表19-1 岗位工作室（四类代表）

| 岗位工作室 | 核心功能 | 数据联动 |
| :--- | :--- | :--- |
| 项目经理/高管工作室 | 综合管控看板、重大决策支持、全局风险预警 | 资金流、4D进度、安全隐患与重大偏差汇总 |
| 施工与技术管理工作室 | 现场施工组织、技术方案审批、物理工程量核对 | 实体工程量（混凝土总量44.0万m³）、施工进度日志 |
| 商务与财务管控工作室 | 资金计划编制、计量支付审核、合同成本控制 | 静态投资与融资拨付、实际结算数据 |
| 质量与安全监督工作室 | 隐患排查、质量抽检跟踪、安全预警闭合 | AI眼镜实时视频流、隐患台账与销号凭证 |

分包商按施组第27章将进度、质量、安全、商务、环水保、文档六类信息全量录入PMIS（月报表当月25日报出、安全事故24小时内书面上报），平台按「进度、质量、HSE、合同、费用、沟通」六大模块承接（兰州水源地母版），与分包PMIS双向对接、自动勾稽。

**偏差闭合四步诊断。** ①偏差感知：实际进展对比进度/成本基线，自动识别滞后与计量异常；②归因分析：结合施工环境与资源配置（如5–10月雨季影响）落实责任单位与岗位工作室；③预警触发：按偏差等级多级预警，自动推送纠偏措施建议库；④执行跟踪：「识别-归因-预警-纠偏」全过程闭合销号。算法阈值与响应时限随开工令随基线冻结发布（与第11章预警阈值统一）。

**平台运维与文控组织。** 依托信息/文控复合部门建制（兰州水源地9人7岗位母版与月度KPI扣分制，建制与考核标准见18.3），福米岗位编制与KPI考核表随开工令发布。

## 19.2 可视化数据驾驶舱与三流联动

「资金流—工程量—4D进度」三流实时联动：以总工期41个月、第33个月首台发电为进度基线，BIM模型挂接时间维度，动态展示大坝（心墙堆石坝最大坝高45m）、溢流坝（最大坝高50m）及厂房形象进度；绑定全站44.0万m³混凝土总量及料场开采/浇筑进度，独立工程师可远程比对BIM模型节点与实际完成工程量。

### 表19-2 远程核查视图

| 核查维度 | 业主视图焦点 | 独立工程师视图焦点 | 联动机制 |
| :--- | :--- | :--- | :--- |
| 进度基线 | 关键节点支付条件达成度 | 关键线路实际进度与4D模型形象比对 | 4D节点与施工日志、影像数据实时校核 |
| 工程量真实性 | 计量支付对应的物理工程量凭证 | 混凝土总量（44.0万m³）、大坝填筑实测完成度 | 「设计图纸-现场实测-计量申报」三表合一核验 |
| 资金流合规 | 静态投资与融资拨付匹配度 | 节点计量审核与单价对应关系 | 拨付进度与实际产值自动勾稽 |

## 19.3 水利安全AI眼镜数据集成

功能模块、应用场景（大坝开挖、混凝土浇筑、孔邦石料场梯段爆破、高边坡支护、雨季安全巡查等）与配发佩戴制度按13.1.4节执行。本章安排与平台5.0的数据集成：①前端智能感知：多目标识别算法实时抓取不安全行为与违章隐患；②第一视角连线处置：重大疑难隐患远程连线后方专家，接收AR辅助作业指令；③数据自动勾稽：视听数据加密上传平台，同步归入现场安全档案与PMI Evidence Pack数据库，整改数据推送质量与安全监督工作室，未整改自动升级预警；④与数字工地衔接：工作面二维码工单与眼镜隐患工单同入平台闭合。硬件型号、续航、防护等级与算法库参数随配发制度发布，工作面二维码布设清单随工作面划分定稿发布。

## 19.4 报奖与审计证据工程化留存（PMI Evidence Pack）

按PMI标准建立四大证据归档包：

### 表19-3 四大证据包

| 证据包 | 归档核心内容 | 审计/报奖目标 | 归档频率与存储 |
| :--- | :--- | :--- | :--- |
| 进度与履约（Time Pack） | 4D BIM进度模型快照、第33个月里程碑签署文件、41个月总工期执行日志 | 业主进度核查、完工履约审计 | 按月自动快照，加密存档 |
| 成本与财务（Cost Pack） | 静态投资明细、计量支付单据、变更签证台账 | 独立工程师财务核验、专项资金审计 | 伴随计量支付实时归档 |
| 质量与安全（Quality/HSE Pack） | AI眼镜巡查记录、混凝土配合比检测报告（C25/C30/C35等24组）、隐患整改闭合单 | 质量竣工验收、鲁班奖（境外工程）/国优金奖申报 | 检测巡检完成后24小时内归档 |
| 合规与社会责任（ESG Pack） | 当地用工配额台账、15662人移民协助记录、环保与法律合规凭证 | 国际金融机构ESG审计、FIDIC工程项目奖申报 | 依事件节点与月度报告定时归档 |

**留存机制。** 业务审批、计量支付、4D更新及AI眼镜巡检数据自动打时间戳与区块链防篡改标记，直通归档库；报奖素材对照国家级与国际奖项评选标准结构化归集，避免完工后人工补料；文控编码按「单位简称/部门代码[年份]文函类型流水号-收文单位代码」统一执行（规则与时限按第18章文控制度），福米增设法文与业主方代码位，代码表随开工令发布。

**信息安全与保密（GB/T 50358-2017第15.5条）。** ①信息分级：交敏感（几马联席文件）与商务敏感（合同价、融资条款）信息分级标识与阅签范围控制；②权限与备份：按岗位角色赋权，业务数据月度快照双备份、证据包加密存档；③保密义务：中外员工及分包商签署保密承诺，涉外信息发布由项目部统一出口。
