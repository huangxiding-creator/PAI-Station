# 第8章 总包穿透管控与水电三局王牌分包实现施工无缝衔接

> **本章回应**：工行审贷官对施工分包“管不住、界面结算失控”风险的担忧 [1, 2]；并同步回应水电三局关于总包界面结算规则的诉求与独立工程师对施工分包管控的要求 [1, 2]。

## 8.1 黄河院总包统筹与水电三局施工分包界面划分及结算管控机制

本小节旨在明确黄河院总包部与水电三局施工分包方的职责边界，确立标准化界面结算规则，并建立“先扣后返”与关键岗位变更红线等严苛管控工具箱 [1, 2]。

### 一、 界面划分与职责边界

1. **黄河院总包统筹职责**：
   黄河院（YRCC）作为工程总承包方，全面负责项目总体统筹、勘察设计、采购管理、穿透式质量与HSE监管、独立工程师对接以及整体项目履约 [1, 3]。总包部配置管理及技术人员539人（其中研究生学历占比58%），全面实施穿透式现场监督与工程计量复核 [1, 3]。

2. **水电三局施工分包职责**：
   水电三局作为主体施工分包商，承担现场具体施工履约，包括枢纽工程各项建构筑物施工 [1]。核心工程量覆盖：
   - 混凝土坝段总量178,555m³（计划施工工期519天），具体包含泄洪坝段34,425m³（垫层500m³、齿槽1,378m³、固结灌浆629m³、底板EL372~376共9,753m³、EL376以上22,035m³、二期混凝土127m³）、引水发电坝段56,696m³（1#坝段18,653m³、2#坝段16,058m³、3#坝段18,844m³）、左右岸连接坝20,212m³（左岸9,062m³、右岸11,150m³）、消力池海漫45,097m³（截渗墙3,791m³、混凝土16,609m³、土石方回填24,697m³）、引渠段22,125m³（左挡墙9,129m³、右挡墙9,192m³、底板3,804m³） [4]。
   - 心墙堆石坝（最大坝高45m）、均质坝（最大坝高46.5m）、溢流坝段（最大坝高50m）等主体结构施工 [5]。

3. **界面结算规则回应**：
   针对水电三局提出的总包界面结算规则诉求，确立“按图计量、凭令开工、依据合同单价结算”的穿透式结算流程 [1, 2]。【待供给: 水电三局与总包界面结算单价拆分表及费用分摊细则】。

### 二、 “先扣后返”与关键岗位变更严苛工具箱

1. **“先扣后返”进度款结算扣留机制**：
   施工分包进度款支付必须严格挂钩现场履约质量与管理达标情况 [1]。在每月审核通过的工程进度款中，总包部统一扣留一定比例的质量与履约暂扣款（即“先扣后返”），待分包商完成阶段性质量验收、HSE合规上报及进度目标后按节点予以返还 [1]。【待供给: “先扣后返”的具体扣留百分比（如5%或10%）与节点返还细则】。

2. **关键岗位人员变更红线与违约处置**：
   水电三局必须保障项目经理、技术负责人、安全总监、质量总监等核心关键岗位人员的现场履约连续性 [1]。
   - **违约判定红线**：现场关键岗位人员未经总包部书面批准擅自更换，或累计变更率**超过20%**，即直接认定为施工分包商严重违约 [1]。
   - **严苛处置工具箱**：对于触发变更红线的违约行为，总包部有权直接扣除履约保证金【待供给: 违约扣罚具体金额标准】，责令限期整改；整改不力的，总包部保留强制指令撤换不合格人员乃至切除部分分包工程量的权力 [1]。

## 8.2 水电三局王牌分包履约依托与属地检测优势

本小节阐述水电三局在几内亚及西非地区的王牌工程业绩，发挥其正创甲级中心实验室属地化检测优势，全面回应独立工程师关于施工分包管控要求 [1, 2]。

### 一、 水电三局在几内亚同类工程王牌履约业绩

水电三局作为中国电建旗下水利水电施工骨干企业，在几内亚拥有极为丰富的国际水电工程与粘土心墙坝交付经验，可为福米水电站（装机90MW(3×30MW)，心墙堆石坝最大坝高45m [5]）提供强有力的技术与管理支撑 [1, 2]：

1. **几内亚凯乐塔（Kaléta）水电站**：
   - **工程规模**：装机240MW（3×80MW），位于孔库雷河，距首都科纳克里110km [2, 6]。
   - **履约记录**：EPC合同额4.46亿美元（2011年8月15日签署），Exim优买信贷3.3465亿美元（2013年1月4日，20年期/宽限9年/2%利率） [6]。2012年4月18日开工，2015年5月29日机组提前发电，2015年9月29日正式投用，2015年10月10日举行竣工典礼 [2, 6]。
   - **交付效益**：截至2019年1月31日累计发电27.08亿kWh，使几内亚供电能力翻倍，机电设备90%采用中国造并执行中国技术标准 [2, 6]。

2. **几内亚苏阿皮蒂（Souapiti）水电站**：
   - **工程规模**：装机450MW（4×112.5MW），位于孔库雷河，为西非最大坝，RCC重力坝最大坝高120m，坝轴线长约1,164m，总库容63亿m³，设计年发电量20.16亿kWh [2]。
   - **履约记录**：EPC合同额13.83亿美元（2016年1月22日签署），2015年12月24日开工，四台机组于2020年11月8日至2021年3月25日陆续并网，2021年6月24日投入商业运行，2022年7月取得最终验收证书 [2]。

3. **粘土心墙坝施工与环境适应性实绩**：
   - 水电三局具备成熟的粘土心墙堆石坝填筑与防渗施工工法，在几内亚属地积累了应对极端气候（如Conakry年降雨3800-4300mm vs Kankan年降雨1441.8mm的气候双轨 [7]，5-10月雨季集中施工安排 [5]）及供应链波动（水泥2025年短缺涨至9.5-10万GNF/袋 [7]、GNF汇率浮动1USD≈8717-8851GNF [7]、95%货运依赖公路运输 [7]）的丰富实战经验 [1, 7]。

### 二、 正创甲级中心实验室属地检测优势与独立工程师管控回应

1. **正创甲级中心实验室属地检测能力**：
   - 水电三局拥有正创甲级资质的中心实验室，在几内亚现场配备了专业齐备的试验检测设备与技术团队 [1]。
   - **现场检测覆盖**：实验室可对福米工程44.0万m³混凝土原材料（水泥、骨料、外加剂） [5]、混凝土配合比及强度、心墙粘土料物理力学指标、土石方填筑压实度等提供全套现场试验检测 [1, 5]。
   - **属地响应优势**：克服几内亚内陆运输靠公路（坝址距Kankan 50km，距交汇口70km）的物流局限 [5, 7]，提供现场即时检测与快速出证服务，有效避免跨国或异地送检导致的工期延误 [1, 7]。

2. **回应独立工程师对施工分包的管控要求**：
   - 本方案全面回应独立工程师关于分包质量与检测行为的穿透监管要求 [1, 2]。
   - **数据穿透与闭环机制**：正创甲级中心实验室建立严格的样品盲检与数据穿透共享机制，所有试验检测数据实时同步至总包部与独立工程师 [1, 2]。
   - **平行检测与第三方比对**：独立工程师可随时对中心实验室的试验设备进行计量标定检查，并开展不低于规定比例的平行抽样检测 [1, 2]。【待供给: 独立工程师规定的平行抽检具体比例与比对试验偏差阈值】。

### 要点清单：水电三局王牌履约实绩与属地实验室支撑

- **凯乐塔（Kaléta）电站交付经验**：240MW（3×80MW）装机，4.46亿美元EPC合同，提前实现首台机组发电，累计发电27.08亿kWh [2, 6]；为福米水电站首台机组开工后第33个月发电 [5] 提供成熟的技术与管理体系依托 [1, 2]。
- **苏阿皮蒂（Souapiti）巨型枢纽实绩**：450MW（4×112.5MW）装机，RCC坝高120m，库容63亿m³，13.83亿美元合同 [2]；提供了大型水电枢纽高强度施工及属地用工（如符合劳动法L/2014/072/CNT周40h及SMIG 55万GNF要求 [7]）的成熟管理规程 [1, 7]。
- **粘土心墙坝属地工艺支撑**：依托在几内亚积累的心墙填筑技术，针对福米心墙堆石坝（最大坝高45m [5]），精准把控5-10月雨季 [5] 的施工停工与干季（Kankan年降雨1441.8mm [7]）高强度填筑节奏。
- **正创甲级实验室检测保障**：属地中心实验室为44.0万m³混凝土 [5] 及大坝填筑提供权威现场检测 [1]，全面向总包部及独立工程师开放检测过程与数据，满足独立工程师对分包管控的严苛合规标准 [1, 2]。

## 8.3 施工分包进度款支付与信息系统及HSE履职硬挂钩机制

本小节规定水电三局施工分包进度款支付的前置条件，建立工程质量检验与HSE履职数据的数字化穿透监管机制 [1]。

### 一、 进度款支付前置挂钩逻辑与穿透流程

1. **信息系统质量数据实时上报与前置审核**：
   - 规定施工分包进度款支付与“信息系统上报质量及HSE履职”硬挂钩 [1]。
   - 水电三局必须将现场施工中的“三检制”验收表单、隐蔽工程验收记录、混凝土浇筑许可（涵盖混凝土坝段总量178,555m³各部位）等质量控制数据，即时、完整地录入黄河院总包部工程管理信息系统 [1, 2]。
   - 未在信息系统中按时完成质量数据上报或检测数据不全的，总包部一律不予以办理当月进度款计量审核 【待供给: 信息系统上报时限要求与质量考核评分细则】。

2. **HSE履职穿透与属地高风险防控**：
   - 鉴于几内亚属全国100%疟疾高传播区及埃博拉起源地，且存在2023年12月油库大爆炸（25死459伤）等供应链与安全突发风险 [3]，分包商必须在信息系统中逐日上报HSE履职台账。
   - 上报内容须严格覆盖：现场全员安全教育、高风险作业许可、传染病日常防控、燃油与危险品供应链冗余检查，以及属地用工劳动合规（执行劳动法L/2014/072/CNT周40h与SMIG 55万GNF标准）[3]。
   - HSE履职考核结果作为当月进度款支付的一票否决项，考核不达标者暂扣当月进度款【待供给: HSE履职考核扣款比例与暂扣返还细则】。

## 8.4 六类违约18种情形分类处置与关键路径劳动力切除机制

本小节建立标准化违约分类处置机制，强化关键路径劳动力资源投入监控，防范工期滞后风险 [1]。

### 一、 “六类违约18种情形”分类处置机制

1. **违约分类框架**：
   - 建立六类违约18种情形分类处置机制 [1]。
   - **六类违约划分**：涵盖质量违约、HSE安全违约、进度与资源投入违约、关键岗位人员违约（如关键岗位人员变更超20%即判违约）、信息系统与履职上报违约、合同管理与违规再分包违约【待供给: 18种违约情形的逐条认定标准清单】 [1]。

2. **阶梯式违约处置工具箱**：
   - **一级处置（轻微）**：口头警告并下发限期整改通知单；
   - **二级处置（中度）**：暂扣当月工程进度款，按合同约定扣减履约保证金【待供给: 具体违约金扣罚标准】；
   - **三级处置（严重）**：执行差价扣款，强制切除部分施工分包任务；
   - **四级处置（极重）**：没收全部履约保证金，终止分包合同并清退离场。

### 二、 关键路径劳动力资源管控与切除分包机制

1. **批准方案用工基准**：
   - 施工组织设计批准的高峰用工总量为2686人（其中中方496人，当地2190人）[5]。

2. **90%劳动力红线与处置措施**：
   - 针对枢纽工程关键路径（包含混凝土坝段178,555m³施工，如泄洪坝段34,425m³、引水发电坝段56,696m³、左右岸连接坝20,212m³、消力池海漫45,097m³、引渠段22,125m³，以及心墙堆石坝最大坝高45m填筑）[2, 6]：
   - **违约红线认定**：若水电三局在关键路径上的实际到场劳动力低于批准施工方案的**90%**，直接认定为严重履约违约 [1]。
   - **差价扣款**：总包部直接按照缺额劳动力对应的工效损失与管理成本差价，从当月进度款中进行强制扣款 [1]。
   - **切除分包工程量**：经总包部下发整改指令后限期内仍未补足劳动力至90%以上的，总包部有权直接**切除水电三局该关键路径的部分或全部施工分包工程量**，由总包部另行调配第三方施工力量或接管施工，由此产生的一切费用与差价由水电三局承担 [1]。

| 劳动力到位率区间 | 违约判定等级 | 触发条件与影响范围 | 处置手段与惩戒机制 |
| :--- | :--- | :--- | :--- |
| **≥ 90%** | 正常履约 | 满足高峰用工（中方496+当地2190人）及关键路径进度计划 [5] | 按常规流程审核并支付进度款 [1] |
| **80% ≤ 到位率 < 90%** | 一级违约 | 关键路径（如178,555m³混凝土或45m心墙坝）出现工期滞后风险 [1, 2, 6] | 发出书面预警，**实行差价扣款**，限期7天补足人员 [1] |
| **< 80% 或限期整改不力** | 严重违约 | 关键路径进度严重偏离，威胁首台机组第33个月发电节点 [1, 6] | **直接切除该关键路径施工分包任务**，没收部分保证金 [1] |
