## 16.1 《运维计划V3》全生命周期运维规划与联合实施机制

EPC承包商联合体执行由黄河勘测规划设计研究院有限公司（黄河院）与中国水利水电第三工程局有限公司（水电三局）联合署名的《运维计划V3》（2026年8月成文，739行17表），实现建设期向运营期平稳过渡。运维服务期共69个月，分两阶段：第一阶段建设期运维由EPC总承包单位负责（含生产准备阶段9个月，涵盖首台机组发电、后续机组投产、工程试运行至全部机组具备投产发电条件）；第二阶段运行期运维由业主负责、EPC承包商协助，运行维护期5年（工程完工后起算，含消缺期1年）。计划内容涵盖建设期第15个月提前介入、5年商业运维保障及50年全寿命周期大修规划。

### 1. 《运维计划V3》全生命周期时间轴与阶段划分

《运维计划V3》将工程运维管理划分为三个核心阶段，时间跨度从建设期延伸至50年运营期：

- **建设期提前介入阶段（第15个月至第33个月）**：
 - **介入节点**：在工程建设期第15个月，运维筹备组（中方专职4名：水工/电气/金结/观测各1，编入项目部相关部门）进场。
 - **衔接节点**：对应可研2026版“开工后第33个月首台机组发电”节点（工程总工期41个月）；第一台机组启动前2-3个月运维人员全部到位（运维V3 4.1.1）。
 - **核心任务**：全程参与设备安装督导、图纸会审、隐蔽工程验收、运维规程编制及属地化人员实操培训。【待供给: 《运维计划V3》建设期介入阶段详细培训手册与驻场准备预算】
- **5年商业运维与过渡阶段（首台机组发电至商业运营第5年）**：
 - **核心任务**：联合团队全面负责电站发电调度、日常巡检、设备保养与突发故障抢修，同步推进75人团队的技能转移与属地化管理交接。
- **50年大修与远期运营规划阶段（第6年至第50年）**：
 - **规划周期**：电站设计服役年限按50年以上考虑，《运维计划V3》已编列运营期间大修计划（4.4）与翻新计划（4.5）（注：可研国民经济评价计算期为44年=建设4年+运行40年，运行期编制为50人）。
 - **大修与翻新节点（运维V3 4.4/4.5）**：3台机组大修安排在运营第8/16/24/32年（当年和第二年分别对2台机组大修、按需请设备厂家技术指导）；225kV开关站设备大修在第10/20/30/40年；大修统一更换保质期低于8年（开关站为10年）的备件。翻新按设备使用寿命实施，每台机组停机约1年完成整体修复，翻新后重新确定运行参数。
 - **核心任务**：定期开展水工建筑物（心墙堆石坝最大坝高45m、溢流坝段最大坝高50m）安全监测评估、水轮发电机组（3×30MW）大修及开关站（140m×59m）设备更新。【待供给: 大修翻新专项储备基金提存方案】

## 16.2 75人“中几联合”三阶段过渡团队搭建与属地化管理

项目设“30名中方专家+45名几方员工”共计75人的三阶段过渡运维团队，解决几内亚本地电力技术人员匮乏问题，落实高管属地化政策要求，实现技术转移与管理交接。

### 1. 75人过渡团队人员构成与岗责配置

- **团队总规模与配比**：过渡期编制为75人，由30名中方专家与45名几方员工组成，几方人员占比达60%。（注：可研长远运行期人员编制为50人、年工资福利15k欧元/人/年〔可研14.2/14.4〕；过渡期较长远编制多25人，用于“一对一”带徒培训与交接期安全冗余）。
- **高管岗位属地化**：副总经理等核心高管岗位由几方人员担任。

### 2. 三阶段属地化过渡演进机制

75人团队通过三阶段动态调整，逐步完成从“中方主导”到“几方独立运维”的交接：

```
[阶段一：中方主导与带徒期] (第15-33个月建设期及商业运营第1-2年)
 ├── 中方专家(30人)：担任总经理、总工程师及关键岗位，全面把控运行安全
 └── 几方员工(45人)：担任副总经理 及跟岗操作员，开展“一对一”实操培训
 │
 ▼
[阶段二：中几并行与交叉授权期] (商业运营第3-4年)
 ├── 几方员工：接管部分部门经理及值长岗位，副总经理深度参与经营决策
 └── 中方专家：退居技术顾问与质量督导岗位，中方人数逐步核减【待供给: 逐步退场计划】
 │
 ▼
[阶段三：几方主导与中方保障期] (商业运营第5年及以后)
 ├── 几方团队：独立承担电站日常运行与巡检维护
 └── 中方保障：仅保留极少数核心专家进行50年大修督导及重大技术支持
```

## 16.3 单机72小时试运行与竣工验收移交标准程序

本节为试运行与验收移交的实施安排：先明确试运行组织与72小时调试程序（机组启动试运行按施组16.3.10执行），再安排阶段验收→完工验收→竣工验收与资料移交路径；试运行期电量结算、设备损耗及安全责任界面按责任边界表控制。

### 1. 试运行组织与72小时调试安排（机组启动试运行程序）

根据工程配置，福米水电站机组采用3台单机容量30MW的水轮发电机组（总装机90MW，水轮机同步转速136.4r/min，额定水头22.5m）。

**（1）试运行组织**
- **启动验收委员会**：机组启动试运行由启动验收委员会主持，72小时试运行、停机检查合格后经启动验收委员会验收后移交（施组16.3.10）。
- **运维力量就位**：首台机组发电前6个月，运维筹备机构升格为福米电站运维项目部；第一台机组启动前2-3个月运维人员全部到位（运维V3 4.1.1）。
- **启动前条件**：按运维V3 4.1.4机组启动前准备工作要求执行；安全生产规章制度及运维规程在分部试运行前3个月完成初稿、总启动前完成修订，系统图与典型操作票分部试运前3个月备毕（运维V3 4.1.2）。
- **首台机组发电前调试投运逻辑链**：225kV设备→厂用电/直流/通讯→接地电阻→保护极性校核→升流升压→倒送电→主变冲击→并网带负荷→72h试运行（施组16.3）。

**（2）单机调试与72小时试运行程序（逐级放行条件，施组16.3.10）**

| 序 | 程序节点 | 放行条件/控制参数 |
| :---: | :--- | :--- |
| 1 | 无水调试→充水试验 | 尾水倒灌充尾水流道→压力管道蜗壳充水 |
| 2 | 空载试运行 | 首次启动3-5min升至50%额定转速、维持2-3min→80%切高压顶起→100%；过速试验115%记录振动摆度、140%核验测速节点与机械过速装置 |
| 3 | 升流升压 | 电流10%递升；电压25/50/75/100%逐级，最高定子电压持续5min且不超1.3倍额定 |
| 4 | 线路倒送电与开关站受电 | 线路冲击三次 |
| 5 | 主变冲击 | 冲击5次、间隔10min |
| 6 | 假同期/并网带负荷 | 25/50/75/100%逐级带负荷（躲开振动区） |
| 7 | 甩负荷试验 | 25/50/75/100%及最大出力；甩25%测接力器不动时间 |
| 8 | 调速器低油压关机试验 | 按规程判定关机可靠性 |
| 9 | **72小时连续试运行** | 每台机组在额定水头22.5m条件下连续72小时满负荷（30MW）带电网运行；瓦温监测前半小时每5min一次、其后每10min一次；若因承包商设备或安装质量问题中断，重新计时72小时 |
| 10 | 停机检查→验收后移交 | 停机检查合格、启动验收委员会验收后，由业主（几内亚能源部/水利部）、EPC联合体（黄河院+水电三局）及几内亚国家电力公司（EDG）共同签署《机组移交与商业运行启动证书》 |

（电气试验配套控制值：硅元件均压系数不低于0.9、均流系数不低于0.85。）

**（3）联合调试与网关测试**：3机（共90MW）联合调试测试电网接入Linsan-Fomi线路（坝下20km）的甩负荷与系统调压能力。【待供给: 几内亚国家电网输变电接口与甩负荷测试专项规程】

## 16.4 几马电网网关计量与铝土矿税置换偿债资金安排

通过建立几内亚-马里（几马）电网网关双向计量，配合“资源换贷款/资源置换收益金”机制，第5-17年每年锁定14449k欧元（即每年1444.9万欧元）的铝土矿税置换收益金，与PPA电费现金共同支撑每年26128k欧元的还本付息——偿债结构为“紧平衡”：矿税托管账户为主（55.3%）、电费现金为辅（44.7%）；第18-19年矿税置换续签【待核】，各项偿债法律文件均【待供给】。

### 1. 项目融资结构与还本付息财务基准

根据可研2026版财务评价及数字基准表，项目的资金筹措与债务结构如下：

- **项目总投资与融资比例**：
 - 静态总投资：405785k欧元（4.058亿欧元）。
 - 资金筹措架构：采用『资源换贷款/资源置换收益金』机制。
 - **债务融资（贷款本金）**：262260k欧元，占比64.6%。
 - **资本金**：185618k欧元，占比35.4%。
- **债务偿还条件（第5-19年）**：
 - 贷款利率：5.5%（暂取值，融资条款未定）【待供给: 融资协议/贷款条款正式文本】。
 - 贷款期限：共19年，其中**宽限期4年**（建设期第1-4年），**还款期15年**（第5-19年）。
 - 还本付息方式：等额本息还款，还款期内每年需偿还**26128k欧元**（约2612.8万欧元/年）。

### 2. 偿债资金两支柱：矿税托管账户+PPA电费现金

还款期（第5-19年）的偿债资金由两大支柱构成——**铝土矿税托管账户为主（占年还本付息的55.3%）+PPA电费现金为辅（占44.7%，即差额11679k欧元/年）**，两支柱合计覆盖每年26128k欧元还本付息，属“紧平衡”结构、无单支柱冗余：

1. **第一支柱（主支柱）：铝土矿税资源置换收益金托管账户**
 - **资源置换机制**：基于几内亚丰富的铝土矿资源，几内亚政府将铝土矿特许权税/矿业税划拨至指定还贷托管账户（Escrow Account）。
 - **置换金额与年限**：还款期前13年（即第5年到第17年），**每年锁定资源置换收益金14449k欧元（1444.9万欧元/年）**，承担每年26128k欧元还本付息中的55.3%（第18-19年是否续签【待核】）。
 - **法律文件**：矿税划拨托管账户的政府法律生效文件【待供给】。
2. **第二支柱：PPA电价电费现金与网关计量**
 - **网关计量设置**：在坝下20km处的Linsan-Fomi电网接入点设立几马电网双向高精度网关计量关口，锁定输往几内亚国家电网及马里（根据2014几马协议与区域电网互联）的售电量。
 - **电价机制**：上网电价参照阿玛利亚（Amaria 300MW电站）购电协议（PPA），在40年运行期内逐年递增，电价区间为**0.0891 → 0.1793 欧元/kWh**；福米项目自身PPA正式文本【待供给】。
 - **偿债现金版本（按PPA现金测算）**：起点电价0.0891欧元/kWh×本期年发电量290GWh（2.9亿kWh）≈**2,580万欧元/年**电费现金收入，再减运维支出即为可支配偿债现金；对照年还本付息2,612.8万欧元（26128k欧元），电费现金单独不足，须与矿税托管账户（为主，55.3%）合成紧平衡覆盖，电费支柱承担差额11679k欧元/年（44.7%）。运维支出全额版本【待核】（可研仅载运行期人员编制50人、15k欧元/人/年）。
3. **财务评价指标**
 - 全部投资IRR为2.95%，资本金IRR为4.88%，投资回收期28.9年，最高资产负债率由62.5%逐步降至0%——偿债保障依靠矿税托管账户与PPA电费现金两大支柱及其法律文件（均【待供给】）。
4. **国民经济评价版本（非偿债现金流，仅限本小节使用）**
 - 影子电价版本（替代柴油发电成本0.376欧元/kWh）下，本期年发电量290GWh对应年发电效益106866k欧元；该数字属国民经济评价的经济效益版本，**非偿债现金流**，不得用于偿债覆盖论证。
 - 国民经济评价EIRR达17.9%（17.87%），ENPV为566419k欧元，效益费用比2.32；在投资增加10%/效益减少10%的极限敏感性测试下，EIRR仍达15.12%（>8%）。
