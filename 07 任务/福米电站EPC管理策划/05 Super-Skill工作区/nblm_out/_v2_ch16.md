# 第16章 属地合规与社会管理

## 16.1 移民征迁责任边界与淹没搬迁合规辅导

移民征迁由几内亚方业主单独组织实施，资金约1亿美元属业主筹资划拨范畴，不纳入EPC总包合同支付与风险担保范围；EPC承担技术协助与合规辅导，履约权责按合同界定。

### 表16-1 移民征迁责任界面与合规要素对照表

| 管理要素 | 业主（几方）责任界面 | EPC技术协助边界 | 采用数据与合规标准 |
| :--- | :--- | :--- | :--- |
| 征迁实施与资金 | 组织实施与资金筹措 | 测量、水文淹没线复核、地形地质测绘 | 移民资金约1亿美元 |
| 淹没搬迁人口 | 补偿发放、用地审批、安置房建设 | 15,662人搬迁合规辅导 | 1,590户/15,662人（Kankan省6,412人+Kouroussa省9,250人，可研2026审定版） |
| 水库淹没与回水 | 划定移民红线与搬迁禁建区 | 水文淹没与库区回水技术图纸 | 淹没面积367km²，回水长度62km |
| 生态保护区补偿 | 审批补偿方案并落实征地 | 生态合规监测与环境评估辅导 | 库亚严格保护区陆域损失36.5km²（补偿22km²）；Ramsar湿地10,464km² |
| 多版本数据管理 | 当地社区沟通与媒体响应 | 把关融资与合同文本数据版本 | 外网EJAtlas 4.8万人/PAP 12万人仅作风险评估用 |

## 16.3 「技能培训+持证上岗」技术转移与属地产业工人建设

属地产业工人培养结合高峰2,190名几方用工分阶段、分工种实施；针对运行期编制50人（年工资福利1.5万欧元/人，可研2026版），建设期遴选优秀几方技术工人进入核心岗位跟班实习，接管团队按第17章三阶段人力进场计划提前进场，首台机组启动前2–3个月全部到位。

### 表16-3 技术转移与属地工人培养实施矩阵

| 实施阶段 | 目标人群 | 核心培训与技术转移内容 | 考核与持证标准 |
| :--- | :--- | :--- | :--- |
| 岗前入职期 | 全体几方新进员工 | 劳动法合规（周40h）、安全生产规程、疟疾/埃博拉防疫 | 100%岗前安全合规考试合格（法文版教材随培训计划发布） |
| 施工高峰期 | 几方技术工种工人 | 土石坝填筑、混凝土浇筑、金结安装实操 | 技能等级评定+持证上岗 |
| 试运行/运营期 | 几方属地化运维骨干 | 电站运维、设备检修、水文调度实操 | 运营期岗位胜任力认证（按运维专项合同执行） |

培训机制：①分级培训体系（岗前安全合规+专业工种实训+考核持证），关键技术工种考核合格并持证后方可上岗；②496名中方管理与技术专家对口带徒，技术转移完成度纳入分包商履约绩效考核；③沿用中法双语管理制度（《交通车辆管理办法》《宪兵管理细则》）与「参照中国标准培训当地特种作业员工并考核发证」路径（运维V3 5.4.8），「培训计划—课次台账—考核记录」三件运转。【待供给：几方官方技能认证体系标准、考核发证机构授权文件及各工种培训大纲】
