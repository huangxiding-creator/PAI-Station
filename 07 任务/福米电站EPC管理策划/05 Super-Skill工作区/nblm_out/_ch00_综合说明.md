# 《几内亚福米水电站EPC建设管理策划方案》开篇：综合说明

**综合说明（执行摘要：给工行行领导的一页式驾驶舱）**

黄河勘测规划设计研究院有限公司（黄河院）作为牵头总承包商，联合中国水利水电第三工程局有限公司（水电三局）施工分包，凭借水利行业唯一参编国标 GB/T 50358 的规范地位、初设深度设计沉淀、十年自费坚守投入及凯乐塔/苏阿皮蒂同国别成功经验，辅以数字总包平台 5.0 与 AI 眼镜等数字化增强项，围绕静态投资 4.058 亿欧元（405,785,243.00 欧元）+中方融资框架约 3 亿美元的融资安排，以 41 个月总工期、开工后第 33 个月首台机组发电为履约目标值，为中国工商银行（ICBC）融资审查提供可追溯的履约安全垫。

### 三、黄河院四大核心优势与一项数字化增强项

1. **规范参编地位**：黄河院系水利行业唯一参与编制国家标准《建设项目工程总承包管理规范》（GB/T 50358-2017）的勘察设计单位，确立了工程总承包行业“标准制定者”的权威管理地位 [`c01_工程事实全集`，`c05_S2黄河院素材台账` A-03/A-05，`c12_GB条款对照与终裁`]。
2. **设计深度已到初设**：已自主完成2026审定版可研（14章220表）及初设深度设计，复核SNC-Lavalin等四轮国际可研，勘察成果获2018年全国勘察设计行业二等奖及2021年“国际先进水平”鉴定 [`c05_S2黄河院素材台账` A-07/A-08/G-09，`c09_福米可研报告2026`]。
3. **十年坚守投入**：2017年签约后自费投入超1000万美元完成补勘与深化设计，几内亚分公司长期留守，2026年几马第8次联席会议明确其“负责Fomi大坝建设的公司”法定地位 [`c05_S2黄河院素材台账` B-16，`c06_S3读者工程与海外专章`，`c08_编制需求与口述纪要`]。
4. **数字化增强项：数字总包平台5.0与AI眼镜（非核心优势）**：数字总包平台已迭代至5.0版，用于质量、安全、资金与进度的远程可视化管控；“水利安全AI眼镜”已获合作意向函、尚未落地，作为现场安全管控的增强性工具储备，不纳入履约核心能力承诺 [`c05_S2黄河院素材台账` E-01/E-08/E-09，`c08_编制需求与口述纪要`]。
5. **凯乐塔同国别经验**：独立完成几内亚凯乐塔水电站（240MW）全套中国标准设计（成果图案印上几内亚2万法郎纸币），并成功主导苏阿皮蒂（450MW）勘测设计，具备扎实的西非属地履约底蕴 [`c05_S2黄河院素材台账` B-14/B-15，`c06_S3读者工程与海外专章`]。

### 四、管理底线承诺

黄河院承诺严格恪守 GB/T 50358-2017 国家标准与工行审查要求，以设计龙头控造价、以策控中心管分包、以数字平台增透明，将41个月总工期完工、投资控制在静态投资4.058亿欧元概算内、安全责任事故零发生与一次验收合格率100%设为履约目标值（历史纪录佐证见核心量化承诺表），以可量化指标支撑中非水利合作与EPC全生命周期履约。
