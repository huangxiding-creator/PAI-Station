# 第6章 多级计划体系与旱季施工高峰排程保障41个月工期兑现

> **本章响应**：几内亚业主与中国工商银行（工行）对41个月工期承诺可行性与可信度的质疑。通过基线澄清、多级动态计划加载以及基于水文特性的旱季高峰排程，提供严密的工程逻辑与数据支撑。

## 6.1 工期基线重塑与P6+PPM多级动态计划体系

### 6.1.1 41个月总工期基线判定与口径对照
针对几内亚业主与融资方工行对工期承诺的关切，本策划案明确**采信2026可研审定版41个月总工期**作为全项目EPC建设管理的核心基线，确定关键节点为：**开工后第33个月首台机组发电、第41个月项目整体完工**。

对历史文献及不同版本中的工期口径进行严格澄清与界定，消除外部质疑：

| 工期版本 / 口径 | 总工期 | 首台机组发电节点 | 口径说明与采信判定 |
| :--- | :--- | :--- | :--- |
| **2026可研审定版（本方案采信）** | **41个月** | **开工后第33个月** | **【采信控制基线】** 2026年最新审定定稿口径，作为EPC履约与银行融资文本唯一基线。 |

### 6.1.2 一/二/三级计划架构与P6+PPM动态纠偏机制
为保障41个月总工期控制节点的无偏差兑现，构建“一级合同计划 - 二级执行计划 - 三级工序计划”多级计划管控体系，并基于 Primavera P6 与 PPM（项目组合管理系统）平台实施资源费用加载与动态纠偏。

```
[一级合同计划] (面向业主/工行) → 锁定里程碑节点 (第33个月发电 / 第41个月完工)
       ↓
[二级执行计划] (项目部综合排程) → 加载人/机/料资源与资金S曲线 (月度/季度动态纠偏)
       ↓
[三级工序计划] (9大作业工区)   → 精细化至周/日工序排程与现场搭接
```

#### 1. 三级计划分级管控要点
*   **一级合同计划（里程碑控制层）**：面向几内亚业主与工行，以开工后第33个月首台机组发电、第41个月整体完工为最高控制节点，锁定导流截流、围堰填筑、土石坝填筑、厂房混凝土浇筑与机电安装等关键线路。
*   **二级执行计划（资源排程管理层）**：由项目部按月度/季度进行综合排程，将施工工程量按时间轴分解，深度加载人工、机械装备及资金支出预算（S曲线），作为现场施工调度与资源配置的直接依据。
*   **三级工序计划（现场作业执行层）**：由**9个作业工区**（开挖工区、填筑工区、混凝土工区、基础处理工区、金结机电制安工区、砂石加工混凝土拌和工区、机械工区、综合工区【待供给: 另外1个作业工区具体名称与职责】）编制周/日作业计划，落实到具体班组与工序搭接。

#### 2. P6+PPM资源费用加载与动态纠偏
*   **资源与费用加载**：在P6软件中建立全过程WBS结构，将劳动力（高峰2686人）、施工机械（如20t自卸车28辆等）及直接费强度加载至网络计划节点，生成动态资源直方图与费用S曲线。
*   **挣值分析（EVM）与预警机制**：基于PPM系统实时抓取现场实际工程量与费用进度，按月对比进度偏差（SV）与费用偏差（CV）。一旦进度绩效指数（SPI）低于临界值，自动触发资源重组与工艺优化程序，确保关键线路零延误。【待供给: P6与PPM系统集成接口参数及动态纠偏算法模型】

### 6.2.2 旱季（11-4月）高峰施工排程与劳动力动态平抑
几内亚雨旱季极度分明（5-10月为雨季，11-4月为旱季；另有5.1.1等处“12-3月旱季”口径并列注记）。施工组织采取**“强拉旱季、避峰雨季”**的强约束排程策略，将土石方填筑与混凝土浇筑高峰全面集中于旱季窗口期。

#### 1. 土石坝填筑与混凝土浇筑高峰排程
*   **土石坝填筑排程（控制工期1187天）**：
    *   **工程大盘**：土石坝工程总量为**3,181,509m³**（约318.15万m³）。
    *   **左岸土石坝（3,117,627m³）**：划分为三区推进——
        *   Ⅰ区（1,080,363m³）：含素防渗墙400m³ + Ⅰ-1填筑431,969m³ + Ⅰ-2填筑479,714m³ + Ⅰ-3填筑158,400m³ + 混凝土板护坡9,096m³ + 坝顶结构784m³。
        *   Ⅱ区（847,779m³）：含素防渗墙183m³ + 填筑592,993m³ + 填筑240,219m³ + 护坡13,242m³ + 坝顶结构1,142m³。
        *   Ⅲ区（1,189,485m³）：含素防渗墙2,976m³ + 坝体填筑1,178,987m³ + 护坡6,925m³ + 坝顶结构597m³。
    *   **右岸土石坝（63,881m³）**：含填筑62,313m³ + 混凝土护板1,119m³ + 坝顶结构449m³。
    *   **旱季排程策略**：利用11-4月旱季连晴天气，拉满采掘、运输与碾压设备，完成坝体填筑与防渗结构的大头工程量；雨季则转入基岩处理、设备维护或非防渗料防冲刷保护。
*   **混凝土浇筑排程**：
    *   **工程总量**：采信**44.0万m³**（注：10.5.2节之36.4万m³判旧版残留不采）。
    *   **旱季强度排程**：溢流坝段（最大坝高50m）、厂房等关键结构集中于旱季高强度连续浇筑，确保水下工程在汛期来临前达到安全度汛高程。

#### 2. 劳动力动态配置与雨旱季平抑曲线
项目通过雨旱季劳动力规模的动态调控，既保证旱季高峰产能爆发，又避免雨季人员窝工。以下劳动力曲线出自施组7.3（2018投标版口径，仅作施工组织能力实证，不构成对41个月控制基线的日历承诺），统一按**相对工期月**表述（M=开工当月，M+第N月=开工后第N个月，相对月按施组自身开工时点折算）：

```

      ↓
攀升期(约M+第12月): 2484人
      ↓
旱季高峰期: 2686人 (中496/本地2190) 【高峰月份两说：施组正文载M+第15月、表7.3-1载M+第27~28月，待核】
      ↓

      ↓
收尾期(M+第48月): 270人 (中50/本地220)
```

*   **全场用工高峰**：最高峰达**2686人**（其中中方管理与核心技术人员496人，当地雇员2190人；人数采信自数字基准表·施组7.3）。【注：高峰出现月份两说——施组正文载开工后第15个月进入高峰，表7.3-1中2686人出现在第27~28个月，矛盾待核；两说月份均落在11-4月旱季窗口，与“旱季高峰”定性不冲突】。
*   **时序动态演变**（相对工期月，M=开工当月）：
    1.  **开工初始期（M+第0月）**：进场427人（中方79人）。
    2.  **全面展开期（约M+第12月）**：快速扩充至约2484人。
    3.  **旱季高峰期（M+第15月或M+第27~28月，两说待核）**：达到高峰2686人，集中攻坚土石方与混凝土强度。
    4.  **雨季平抑期（M+第17月及M+第29~32月）**：首轮雨季用工规模主动收缩降至1188人；次轮雨季维持2079人，进行现场精细化整理与室内防腐安装。
    5.  **竣工收尾期（M+第48月）**：全场收缩至270人（中方50人）。

## 6.3 “日保周、周保月、月保季”进度考核与黄橙红三级预警机制

### 6.3.1 “日保周、周保月、月保季”四级联动进度考核体系
为确保41个月总工期控制节点不发生累积性偏差，项目建立“日跟踪、周调度、月考核、季纠偏”的四级联动进度管控机制，将一级合同计划与二级执行计划的目标精准分解穿透至每日工序与施工班组。

#### 1. 四级联动控制要点清单
*   **日保周（日计划与工序跟踪）**：各作业工区每日盘点当日实际完成工程量，严格对照三级工序计划。凡当日未完成的工序，必须在次日通过增加作业班次或调配机械补齐，确保不拖延周计划。
*   **周保月（周调度与资源协调）**：每周由工程管理部组织召开进度调度会，盘点周计划完成率，重点协调劳动力（高峰期2686人，高峰月份两说【待核】）、施工机械（如20t自卸车28辆等）与大宗物资（水泥、钢筋、截流备料等）的现场调配，消除工序交叉冲突。
*   **月保季（月考核与绩效挂钩）**：按月对比实际进度与P6+PPM生成的计划S曲线，开展挣值分析（EVM）。月度考核结果直接与项目部及各作业工区绩效奖惩挂钩，按进度履约情况结算工程款。
*   **季纠偏（季盘点与气候适应）**：结合几内亚5-10月雨季与11-4月旱季的气候交替特点（另有5.1.1等处“12-3月旱季”口径并列注记），每季度对二级执行计划进行综合盘点与动态优化，防范季末累积延误。

#### 2. 进度考核分级控制矩阵表

| 考核层级 | 责任主体 | 控制频次 | 核心控制目标 / 动作 | 绩效挂钩与纠偏手段 |
| :--- | :--- | :--- | :--- | :--- |
| **日保周** | 作业工区 / 施工班组 | 每日 | 盘点单日工序完成量，实现工序无缝搭接 | 日清日毕，未完成工序次日加班或加机补齐 |
| **周保月** | 工程管理部 / 施工经理 | 每周 | 评估周计划完成率，消除现场跨工区作业冲突 | 动态调配现场机具装备与劳动力资源 |
| **月保季** | 项目经理 / 六部负责人 | 每月 | 对比P6月度计划与资金/资源S曲线，计算EVM | 绩效考核挂钩，触发预警与进度款结算 |
| **季纠偏** | 项目决策层（7人组） | 每季度 | 盘点季度里程碑，依据雨旱季气候调整下季计划 | 动态调整下季度资源配置与施工班次 |

## 6.4 现场矩阵式组织架构与工期兑现履约保障

### 6.4.1 “决策层7人+六部+专家顾问组”现场组织架构
项目部采用**矩阵式管理**模式（参照图7.1-1/表7.1-1），形成高度集权与高效调度的现场指挥体系，确保41个月工期承诺在组织层面得到坚实保障。

#### 1. 现场组织架构要点清单
*   **决策层（7人）**：由**项目经理、施工经理、商务经理、财务总监、总工、设备物资经理、HSE总监**组成，对项目进度、质量、安全、成本与商务履行行使最高决策权。
*   **职能部门（六部）**：
    *   **工程管理部**：负责P6+PPM多级计划编制、日周月进度调度、现场施工组织与计量。
    *   **经营管理部**：负责商务合同、进度款结算、合同纠偏与变更索赔。
    *   **质量管理部**：负责施工质量过程控制、隐蔽工程验收与质量检测。
    *   **安全环保部（HSE）**：负责现场安全生产、环境保护及几内亚当地HSE合规管理。
    *   **设备物资部**：负责施工机械装备（如20t自卸车28辆等）、大宗材料（水泥、钢筋、截流备料等）采购与供应链保障。
    *   **综合事务部**：负责当地雇员（高峰2190人）外联、行政后勤、业主与政府关系协调。
*   **专家顾问组**：为复杂地质条件下的土石坝填筑（3,181,509m³）、导流截流（双岸立堵、49.1m³/s演算）及高边坡处理提供技术支撑与重大技术方案把关。

### 6.4.2 9大作业工区矩阵式管控与资源闭环

#### 1. 作业工区配置与职责清单
现场设立**9个作业工区**（参照表7.1-1），推行矩阵式管理，将进度指标直接穿透至现场生产一线：
1.  **开挖工区**：负责坝基、厂房及溢流坝段等土石方开挖与边坡支护。
2.  **填筑工区**：负责左岸土石坝（3,117,627m³）、右岸土石坝（63,881m³）及二期围堰（上游107.71万m³、下游4.2万m³）的填筑施工。
3.  **混凝土工区**：负责厂房、溢流坝段（最大坝高50m）等全场44.0万m³混凝土浇筑。
4.  **基础处理工区**：负责坝基防渗墙（如左岸土石坝Ⅰ/Ⅱ/Ⅲ区素防渗墙等）及帷幕灌浆施工。
5.  **金结机电制安工区**：负责水轮发电机组（装机90MW，3×30MW）及金属结构设备的制造与安装。
6.  **砂石加工混凝土拌和工区**：负责全场骨料加工与混凝土拌和供应。
7.  **机械工区**：负责全场大型施工机械（如20t自卸车28辆等）的维护、调度与运行管理。
8.  **综合工区**：负责临时设施维持、现场道路维护（坝址至Kankan约88km进场路已建成）及辅助工程。
9.  **第9作业工区**：【待供给: 第9作业工区具体名称与职责明细】。
