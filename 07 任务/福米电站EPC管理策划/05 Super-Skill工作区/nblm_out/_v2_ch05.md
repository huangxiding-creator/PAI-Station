# 第5章 工作分解结构与总体部署

工作分解结构按“五个交付域×八个管理域”组织：设计、采购、施工、试运行、运维移交五个交付域决定“做什么”，八个管理域统一规定“怎么管”。总体部署采取"筹建期6个月＋实施期41个月"两段式，实施期以一二期分期导流为主轴、以11-4月旱季为施工高峰窗口。

---

## 5.2 总体部署

总体部署按“筹建期与实施期分离、两期导流转换、旱季高峰集中”三项原则展开：筹建期6个月（融资闭合/招投标）不计入总工期；实施期41个月按净准备期3个月＋主体施工期30个月＋完建期8个月组织；土石方填筑与混凝土浇筑高峰全面集中于11-4月旱季窗口。总体安排如下表。

### 表5-2 总体节奏表（筹建期6个月＋实施期41个月，两期导流主轴）

| 部署阶段 | 时序（相对月） | 安排要点 |
| :--- | :--- | :--- |
| **工程筹建期** | M-6~M-1（6个月，不计入总工期） | 融资闭合、招投标；新料源勘探列入筹建期必办任务清单（花岗岩料场缺口约28.9万m³，否则第2年堆石与骨料供应强度受限） |
| **净准备期** | M+0~M+2（第1-3个月） | 开工；场内道路（36km）与跨河桥、砂石加工系统（380t/h）、HL180拌和楼安装调试；88km进场路运输保障落实；机电设备长周期采购同步启动 |
| **一期导流施工** | M+3~M+14（第4-15个月） | M+3一期截流（围左岸滩地、右岸束窄河床过流）；施工左岸滩地均质坝段与全部混凝土坝段；M+14泄洪系统混凝土浇至382m度汛控制高程 |
| **二期导流转换** | M+15~M+23（第16-24个月） | M+15二期截流（河床段、3孔导流底孔过流）；二期围堰填筑闭气与基坑排水；河床段心墙堆石坝基础开挖与基础混凝土灌浆；M+23泄洪系统完工（含金结安装） |
| **蓄水发电** | M+24~M+32（第25-33个月） | M+24 1#/2#导流底孔下闸封堵；M+28 3#底孔下闸、水库蓄水启动（按P=85%来水于M+32蓄至死水位383m）；M+32首台机组发电（**第33个月**） |
| **完建期** | M+33~M+40（第34-41个月） | 2#/3#机组投产（推排M+35/M+38）；剩余坝体填筑、护坡与坝顶结构收尾；金结机电剩余安装调试与机组试运行；M+40工程完工（**第41个月**），完工验收移交 |

本表仅列总体安排，全量11个一级进度里程碑总表、三级计划体系与动态纠偏机制、劳动力动态配置与雨旱季平抑曲线等明细随各专业章展开，不重复整表。
