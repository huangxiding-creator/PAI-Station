# 第3章 项目实施基本原则

本项目实施遵循设计牵头、五位一体控制、属地化融合、数字化支撑四项基本原则，分别明确牵头主体、控制内容、用工组织与支撑工具；各原则的要点与落实机制见下表，制度与配置安排详见第7章、第19章。

#### 表3-1 四项基本原则落实机制表

| 原则 | 要点 | 落实机制 |
| :--- | :--- | :--- |
| **设计牵头** | 设计阶段决定工程投资与造价的70%以上 | EPCC四维接口矩阵（长周期设备招标前锁定接口参数、厂家图纸反向审定、技术协议设计盖章确认）；限额设计四步程序（±3%预警线，未过经济分析不出图）；供图前置7天三方会审与「图纸未会审不下发现场、交底未完成严禁开工」两不原则；BIM正向设计与三维交付、工程量动态对比核算；设计代表处挂牌驻场、设代归口项目部管理；现场技术问题2小时赴勘、24小时出《设代通知单》、48小时后方专家组终审 |
| **五位一体控制** | 质量、安全、进度、费用不可偏废，由策划控制中心16类商务总控统一归口平衡 | 强化型「3+1」质量管控（三检制上总包独立复检）＋三级验收评定；三级计划体系P6+PPM动态纠偏＋「日保周、周保月、月保季」考核＋黄橙红三级预警；限额设计源头控制＋全生命周期资金流治理＋EVM挣值月度对比；行政、技术、实施、监督四大安全责任体系＋风险抵押金季度考核＋四级19项应急预案；环保并入安全域，水质、噪声、空气监测日志常态化 |
| **属地化融合** | 属地化用工为几内亚法定义务，高峰当地雇员2190人、占81.53%（约1:4.4） | 劳动法L/2014/072/CNT全项遵从（周40h、SMIG 55万GNF、台账月度报劳动监察备案）；特种作业100%持证上岗，当地人员中方培训考核后发证；88km进场道路社区开放共享、生态补偿与Ramsar湿地监测协助；中法双语安保与管理制度、文控法语文函代码；移民协助边界（15,662人淹没搬迁由业主实施、总包技术协助） |
| **数字化支撑** | 数字总包平台5.0＋水利安全AI眼镜构成数字化底座，控制基准成为可远程核查的实时数据 | 24岗位数字化工作室按偏差四步诊断处置；三流联动驾驶舱向业主与监理开放；AI眼镜现场隐患识别与远程连线；六项控制基准随开工令冻结并按月快照；四大证据包按业务流自动记录时间戳归档 |

---

**数据管理纪律**：本章数字全部取自数字基准表与既有章版本，零新增；机制明细以各责任域现行规定为准。
