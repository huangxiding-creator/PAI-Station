> 把 EPC100 已量产的 40 份工程总承包行业研报直接上架「总包学园」小程序，建成 **检索推荐 → 前20页免费试读 → ¥498 解锁全文+下载 → 点赞赠报告 / 批评评分退款 → 情报卡海报裂变** 的完整变现闭环——报告生产的边际成本≈0，商城的每个环节都兼作增长引擎。

## 一、真实意图揣摩（三句话）

1. **资产变现**：EPC100 产线日夜在产研报，粮仓已满（40 份 docx 成品+持续产出），缺的是把库存变成现金的**销售终端**。
2. **质量飞轮**：批评退款不是售后成本，是把读者变成**质检员+改进顾问**——每条真诚批评自动回流报告产线，研报越卖越好。
3. **零成本获客**：¥498 高客单撑得起裂变激励，海报+赠报告+组队把获客成本压到近 0——这是咨询公司和研报平台都做不到的。

## 二、The 10× claim（可证伪十倍门）

- **最强轴**：`onboarding_time`——用户从发现到读到正文 **0.5 分钟**（扫码→落地页直读，无登录墙）vs 传统研报获取链路（搜索→注册→联系客服→付款→邮件交付）≈240 分钟 → **480×**
- **佐证轴**：`cac` 60×（裂变+长尾落地页 vs 行业 B2B 内容销售）｜`deploy_cost` 40×（content_pipeline 全自动批处理 0.1 人时/份 vs 人工上架 4 人时）｜`price` 3.79×（¥498 vs 同形态实锤价 ¥1888）
- **TenX index = 2.681（tenx_qualified），multiplier 479.7×**，脚本输出见 `tenx_result.json`；基线数字与「估算/实测」标注见 `tenx_claims.json`（C14：实测=RUN_LEDGER，估算=已逐条标注）

## 三、Problem & persona

- **Persona**：工程总承包（EPC/施工总承包）企业的投标商务、市场经营、企业管理人员——需要逐省逐市逐业主的商机与竞争情报做投标决策。
- **Pain**：招标网站信息碎片无深度；咨询公司定制报告数万元一份且周期长；专业研报平台（发现报告/慧博）单篇 ¥1000-3000 且无工程垂直内容——**deep_competitors 实锤：工程垂直市场无单篇深度研报竞品，定价权在我**。
- **付费意愿信号**：发现报告研选 ¥1888/300 页有成交市场（cred 0.7）；盐选年卡 238 万级付费习惯；基建通类 B2B 平台年费几百至上万（deep_competitors 表①）。

### 4.3 点赞赠报告 / 批评退款 → 「诚意批评官」制度（核心创新）

**点赞赠报告**：
- **站内点赞**（绝不绑分享——利益-分享因果链是红线）→ **必得**一份随机报告（从用户未购清单随机指定，每日限1份）→ 属**附条件赠送**，无中奖不确定性，无概率公示义务（deep_refund 5.1，规范促销行为暂行规定第11条）；赠品池规则仍主动公示（信任加分）。
- 边际成本=0（存量报告做赠品），用户「意外得到→再读→再点赞→再赠」= 复购永动机。

**批评评分退款**（用户核心创意，升级为四层制度）：

| 层 | 设计 | 证据/依据 |
|---|---|---|
| ①资格闸 | 须有真实阅读行为（未读者不可发起）；每报告每用户1次；每月退款≤2次 | 知乎Live消费深度门槛先例（deep_refund 1.2）；Panera 死于无频次上限（1.1） |
| ②AI评分（证据先行） | 确定性预筛（代码）：字数50-300上限（LLM 冗长偏差校正）+ 与历史批评查重（n-gram+语义）+ **语义锚定**（批评须引用具体章节/数据点，模板化话术锚定分=0）→ 判断层（免费模型优先）：真诚度/真实度/建设性 0-100%，**输出评分依据**（批评哪句↔报告哪节）→ 确定性硬门：熔断 | 假评论检测语义特征>n-gram（deep_refund 4.1，LSTM 94.56%/n-gram 89.6% 基线）；LLM-as-judge 三偏差校正（Zheng NeurIPS 2023） |
| ③退款映射 | 得分≥50 → 按分退款（50分→50%，100分→100%，线性）；<50 → 不退+感谢券。**Android：refund_order API 自动原路退（180天内退手续费）；iOS：开发者不可主动退→等额书券补偿+引导苹果通道双轨**（规则公示讲清） | deep_pay Q4（iOS 主动权在苹果）；映射规则事前进协议（承诺即合同，deep_refund 2.2） |
| ④反馈回流+荣誉 | 批评自动进 EPC100 报告改进队列 → v2 版本**致谢批评者署名**；月度真诚批评家榜单；年度「首席批评官」=全年免费阅读权 | 把退款变质量飞轮；Steam 滥用者剥夺权先例做黑名单兜底 |

- **熔断**：单报告退款率>25% 或全站周退款额>营收15% 自动停+人工复核（Steam 基线 11%/个案 21%，deep_refund）。
- **公示即护身符**：评分标准/映射/频次/申诉通道全部事前进用户协议+支付页可见；退款率日报推企微。
- **为什么敢做**：meta 分析 21 篇研究实证宽松退款净效应为正（购买增量>退货增量，Janakiraman 2016 被引507+）；84% 用户下单前查退款政策——**这本身就是转化率武器**。
