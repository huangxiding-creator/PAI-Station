# 向导：开通虚拟支付（总包学园 wxfdb55b184756e89e）——您操作，其余交给我

> 依据：官方文档《虚拟支付：企业、个体户》developers.weixin.qq.com（deep_pay 深研实读，cred 0.95）。企业主体已确认 ✅。

## 开通前准备（一次备齐，避免中途卡住）

- [ ] **管理员微信**：能扫码登录 mp.weixin.qq.com 的微信号（小程序管理员）
- [ ] **营业执照**：照片/扫描件清晰在手机或电脑里
- [ ] **对公账户信息**：开户名（公司全称）、开户银行、银行账号（虚拟支付专用新商户号的结算账户；企业提现走对公）
- [ ] **法人/经办人身份信息**：按页面提示
- [ ] **小程序简称**：iOS 端虚拟支付要求已配置小程序简称（后台「设置→基本设置→小程序简称」，若已配置可跳过）

## 官方 6 步（跟着点）

1. **进入入口**：电脑打开 `mp.weixin.qq.com` → 管理员微信扫码 → 选择「总包学园」小程序 → 左侧菜单 **【功能（或「支付与交易」）→ 虚拟支付】**
   - ⚠️ 若入口提示「类目不支持」：先到「设置→服务类目」把类目调整到虚拟支付开放清单内（教育/知识付费/工具方向），保存后再回来
2. **阅读协议**：第一步阅读《虚拟支付服务协议》并同意
3. **提交商户资料**：填写营业执照、对公账户等 → 系统为你开通一个**虚拟支付专用独立新商户号**（和普通微信支付商户号是两回事，不用已有的）
4. **账户状态查询与资料审核**：提交后在此页查看审核状态（时长以官方提示为准）
5. **账户验证**：按页面指引完成打款验证或信息核验
6. **扫码签约**：管理员微信扫码签署协议 → 完成

## 开通后：配置道具（第 6 步之后的商户管理后台）

进入 **商户管理后台 → 道具/商品管理**，先只建 **1 个道具**（跑通全链再扩）：

| 配置项 | 填什么 |
|---|---|
| 道具名称 | 研报单篇解锁 |
| productId（道具ID） | 例如 `xy_report_unlock`（自定义，见后台规则） |
| 价格 | **¥498.00（=49800 分）** |
| iOS 价格 | 若后台强制双端分价：¥498 保持同价（推荐）；不允许同价则按官方允许档位就近 |

> 设计说明：所有报告统一定价 ¥498，所以**一个通用道具**就够——具体解锁哪份报告由我们的订单系统（outTradeNo）绑定，不需要 40 个道具。后续若要分报告定价再逐个加道具。

## 最后：把 3 个值发我

开通+建好道具后，把后台看到的：
1. **offer_id**（虚拟支付发售单元 ID）
2. **product_id**（道具 ID）
3. iOS 实际价格（若与 ¥498 不同）

发到对话里即可。我这边：填 `data/secrets/virtual_pay_xueyuan.secret` → 引擎重启即生效 → 真机走一遍支付全链实测。

## 常见卡点速查

| 现象 | 处置 |
|---|---|
| 找不到「虚拟支付」入口 | 多在「功能」或「支付与交易」分组；没有=类目/主体不符，先查类目 |
| 审核中等待 | 正常流程，不影响我开发（支付腿=即插组件，未开通时 503 降级灰置） |
| 要求小程序简称 | 「设置→基本设置」配置简称后回来 |
| 对公账户填错 | 审核阶段可重新提交资料 |
