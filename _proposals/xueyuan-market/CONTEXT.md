# CONTEXT — 统一语言表（ubiquitous language）

> Phase 3 产出。本表是「总包学园·研报商城」全项目唯一词汇表：后续所有文档、代码（表名/列名/接口名/注释）、commit message、企微报告中，术语一律按本表使用；**禁用同义词不得出现**。
> 新术语入表规则：先查重（含禁用列），再在本文档 MR 中定义并注明出处文件。定义依据主要来自 PROPOSAL.md、KNOWLEDGE_BASE/ 七件、SCHEMAS.md。

| 术语 | 定义 ｜ 禁用同义词 |
|---|---|
| 道具 | 虚拟支付的最小售卖单元，本项目=一个通用道具「研报单篇解锁」（productId `xy_report_unlock`，49800 分），解锁哪份报告由订单系统 outTradeNo 绑定，不需按报告建道具。｜禁用：商品 SKU、代币、金币、点数 |
| offer_id | 虚拟支付**发售单元 ID**——MP 商户管理后台开通后由官方生成、用户回传三值之一，服务端签名腿必填。｜禁用：appid（那是小程序 ID）、商户号 |
| product_id | **道具 ID**——后台道具配置中自定义（如 `xy_report_unlock`），与 offer_id 一同回传；SCHEMAS orders.product_id。｜禁用：goods_id（API 侧另有 goodsPrice 等字段名，语义按本表） |
| 试读章 | 前端包内**带正文**的免费章节（默认前 2 章，≈20% 行业舒适带；chapters.is_trial=1，html=正文）。｜禁用：免费章节、预览章 |
| 空壳章 | 前端包内**只有标题、html=""** 的付费章占位（防反编译包内泄漏）；正文由服务端按权益下发。｜禁用：加密章、锁章、占位章 |
| 决策卡 | 试读结束页转化组件：已读 X 页/全文还有 Y 章 Z 页/未解锁 N 条核心结论模糊预览+目录树。｜禁用：付费卡、引导页 |
| 书券 | 非现金虚拟权益券，内循环锁客：邀请解锁/批评感谢券（<50 分）/iOS 退款等额补偿三源发放，攒券换报告（vouchers 表）。｜禁用：优惠券（优惠券是折扣语义）、积分、余额、代金券 |
| 批评评分 | 对已购报告的批评做四层闸处理后按分退款的制度（criticisms 表）：资格→AI 评分（证据先行）→退款映射→反馈回流。｜禁用：评价退款、好评返现（返现=红线词） |
| 真诚度 | 判断层三评分之一（0-100）：批评者意图是否真诚（llm_scores.sincerity）。｜禁用：诚意分、态度分 |
| 真实度 | 判断层三评分之一（0-100）：批评内容是否真实可核（llm_scores.authenticity）。｜禁用：可信度、准确率 |
| 锚定分 | **语义锚定分**（anchor_score）：批评引用具体章节/数据点的程度（embedding+实体命中正文）；模板化话术=0 → 直接不给退。｜禁用：相关性分、引用分 |
| 熔断 | 确定性财务硬门：单报告退款率>25% 或全站周退款额>营收 15% → 自动停「新发起」+人工复核（已公示义务继续履行）。｜禁用：风控开关、紧急下架（下架是另一动作） |
| 归因三表 | 海报裂变归因的 poster_code / share_event / invite_relation 三表（另设 scan_visit 作漏斗第一环度量，合称三表+一环）。｜禁用：埋点表、tracking 三件套 |
| 首触归因 | invite_relation 的归因策略：被邀请人+报告唯一，**第一个**有效邀请人先到先记（first-touch）。｜禁用：末次归因（last-touch，本项目不用） |
| 情报卡 | 服务端生成的裂变海报（社交货币定位）：封面+最狠 1 数据+1 句结论+品牌条+小程序码（右下）+「长按识别 免费读前 20 页」。｜禁用：推广图、分享图、宣传海报 |
| K 因子 | 人均邀请数×邀请转化率，由 invite_relation 聚合；冷启动保守基线 K≈0.1-0.2，不拿爆款当目标。｜禁用：裂变系数、病毒系数 |
| 组队 | 3 人组队读研报：组队价 ¥998/3 人，全队各得阅读权（微信读书同款安全样本）。｜禁用：拼团（拼团是电商语；且「拼团」易联想到砍价红线）、团购 |
| 邀请解锁 | 邀 2 位新用户扫码→自己解锁完整免费部分+50 元书券；分享是**路径之一非唯一**，虚拟权益非现金。｜禁用：助力（助力=外链规范 2.1.2 违规词）、任务宝 |
| 503 降级 | offerId/secret 未到位时支付腿返回 503 的运行形态：可试读、可收藏、支付灰置；凭证即插生效。｜禁用：支付关闭、功能下线 |
| pay_sign | 引擎服务端签名腿：持 appsecret 生成虚拟支付所需 paySig/signature 双签名（zongbao 在役，签名单测 5 向量）。｜禁用：支付密钥、签名接口（口误时易与 appsecret 混） |
| env | 支付环境标志：**0=正式，1=沙箱**（orders.env 同源；沙箱单不进营收对账）。｜禁用：prod/test、is_sandbox |
| outTradeNo | 订单幂等键 `{reportId}_{ts}`：重复请求幂等 200，已解锁再购 409；道具与报告的绑定载体。｜禁用：订单号（泛称时用「订单号」指 orders.id 语义，幂等键专指 outTradeNo）、trade_no |
| pay_log | 订单对账明细（orders 表承载，raw_notify 存回调原文），与官方账单逐单核对（biaoxun 同款惯例）。｜禁用：流水表、支付日志（日志是 log 文件语义） |
| 附条件赠送 | 点赞即赠的法定定性：确定给付、无概率 → 不构成抽奖，无概率公示义务（《规范促销行为暂行规定》第 11 条）。｜禁用：抽奖赠送、 lucky draw |
| 道具直购 | 虚拟支付 mode=`short_series_goods`：直接以人民币金额购买道具；与代币模式（short_series_coin，本项目不做）相对。｜禁用：直充、买断充值 |
| 双 PDF | 每报告两份交付件：trial.pdf（试读版=前 N 章）+ full.pdf（完整版，压缩待办）。｜禁用：正副版、上下册 |
| 水印版 | 带购者昵称水印的下载 PDF，防转传；可转赠好友 1 次（P2）。｜禁用：加密版、专属版 |
| 批评官 | 批评者荣誉体系：月度真诚批评家榜单；年度「首席批评官」=全年免费阅读权；v2 版本致谢批评者署名。｜禁用：质检员（内部语，不对外） |
| 黑名单 | 批评退款滥用者清单：历史退款率>30% 转人工；滥用者剥夺 AI 退款权（Steam 先例）；终审=用户。｜禁用：封禁名单（封禁是账号处置，黑名单只降权转人工） |
| 四层闸 | 批评退款制度结构：①资格 ②AI 评分（证据先行）③退款映射 ④反馈回流+荣誉。｜禁用：四步流程、审核链 |
| 感谢券 | 得分<50 时不退款、发放的书券（source=criticism_thanks）。｜禁用：补偿金、安慰奖 |
| 短码 | scene 放不下参数时的映射键（如 `s=Xk29fA`→poster_code 行还原业务参数）。｜禁用：邀请码（邀请码是另一语义）、口令 |
| scene | getUnlimited 小程序码携带参数：最大 32 可见字符、不支持 %；本项目直拼 `r=报告短ID&i=邀请人短ID`。｜禁用：query 参数（page 不能带参数，query 只能在 scene） |
| 归因降级 | scene 解析失败/映射查不到→无邀请人进入（免费内容兜底优先于归因）。｜禁用：归因失败报错（不报错，静默降级） |
