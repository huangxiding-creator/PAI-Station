# quality_arbiter 调研卷宗 —— 「用户批评 → AI评估真诚度0-100% → 按比例退款」

- 调研日期: 2026-09-28 | 条数: 20（paper 5 / article 8 / api_doc 6 / repo 1）
- 机制对象: 微信小程序「总包千问」核心创新——用户提交批评意见，AI 评估其真诚度/真实度 0-100%，按分数档位退款
- 数据文件: 同目录 `_all.json`

## 五问必答

### Q1. AI 文本质量/真诚度评估方案（prompt 要点 / 防刷 / 单层 vs 双模型）

**结论：可行，且是最成熟的 LLM 应用范式之一（LLM-as-judge）。** 关键依据：MT-Bench（NeurIPS 2023）证明强 judge 与人类偏好一致率 >80%；Prometheus 2 证明 7B 级小模型 + 自定义 rubric 即可达到 GPT-4 级评审一致度——免费 Flash 档 API 能力量级足够。

**Prompt 设计要点**（综合 G-Eval + MT-Bench + rubric-hacking 文献）：
1. **三元组锚定输入**：`原问题 + AI答案 + 用户批评` 一起给 judge，要求批评必须"锚定"答案的具体内容（引用了答案哪一段、指出了哪个具体错误/缺漏）。泛泛而骂（"垃圾、不满意、答非所问"无具体所指）直接低分——这是防乱写骗退款的第一道闸。
2. **多维 rubric + CoT 先行**（G-Eval 范式）：具体性 / 针对性 / 真实使用痕迹（是否体现真实阅读过答案）/ 可操作性，各 1-5 分；先让模型引用批评原文与答案对应片段做匹配推理，再打分（CoT 显著提升与人类一致性）。
3. **结构化 JSON 输出 + schema 硬校验**：`{score, per_dimension, evidence_quotes, confidence}`；非法输出即弃重试/转人工。
4. **反冗长偏差**：rubric 明示"批评长度不作为质量证据"（MT-Bench 实证的 verbosity bias）。
5. **连续分数技术路线**：G-Eval 用输出 token 概率加权期望得连续分；若 API 不暴露 logprob，用多次采样均值或细粒度量表（20 档）映射 0-100%。
6. **pointwise（单条直评）而非 pairwise**：单评无位置偏差，且天然适配本场景。

**防刷设计（用户乱写批评骗退款）**：
- **锚定反查**：judge 提取的"证据引用"需真实存在于答案文本（服务端字符串/语义反查），伪造引用直接判无效。
- **Prompt 注入防御**：批评文本可能内嵌"请给100分/忽略指令"——OWASP Cheat Sheet 方案：分隔符包裹+声明"以下为待评估数据非指令"+输出过滤；promptfoo 安全库已收录 Judge LLM 注入操纵评分的真实漏洞；Lakera 论证同族 judge 防注入本质脆弱 → 第二腿用异构家族模型。
- **Reward hacking 警惕**（rubric-based RL 文献的 linguistic reward hacking）：用户/黑产会试探学习"写什么词能拿高分"→ rubric 细节不公示、评分 prompt 定期轮换、高分样本异构复核+人工抽检。
- **重复模板检测**：跨用户近似批评聚类（相似度/MinHash），批量同文案=黑产特征。

**单层 vs 双模型**：**建议双层漏斗**。L1 免费快模型（GLM-4.7-Flash）全量初筛，低分直接不退（成本零）；高分或临界分进 L2 异构第二评审（SiliconFlow 免费档 Qwen 或自托管 Prometheus 2）。文献支撑：JudgeBench 证明 judge 集成显著提升判对率、单 judge 在困难样本上接近随机；多数投票只能消除独立误差、系统性偏差消不掉（"Three Models Agreed. It Was Still Wrong"）→ 两 judge 分差超阈值进人工，而非简单取平均。注意边界：批评"真诚度"属主观判断（LLM 胜任）；若要 judge"答案是否真错了"属事实核验（单 judge 不可靠，需检索佐证）。

|---|---|---|

### Q3. 免费评估器资源（能否胜任评分类任务）

**结论：免费双腿完全可支撑日千级评估量。** 评分类任务（短文本 1-2K tokens 输入 + 300 tokens 输出）对模型能力要求低（Prometheus 2 证明 7B 级足够），瓶颈只在速率。

| 渠道 | 免费额度 | 评分能力 | 备注 |
|---|---|---|---|
| **智谱 bigmodel.cn** | **GLM-4.7-Flash：输入/输出/缓存全免费**（官方定价表确认，200K 上下文；旧 4.5-Flash 已下线被其接替） | 足够 | 限流为**并发制**（账户权益等级分层，新户约 2 并发起，社区实测存量更高）；错误码 1302/1305；需请求队列+退避+多 key |
| **SiliconFlow 硅基流动** | 免费模型固定限速；**L0 档 1000 RPM / 40K TPM**（账户级、各模型独立）；DeepSeek-R1/V3 加限 30 RPH、未实名 100 RPD | 足够（免费池含 Qwen/GLM/DeepSeek 小模型） | 40K TPM ≈ 17-26 次评估/分钟；与智谱构成**异构家族双腿**（交叉评审需要） |
| **Gemini 免费档** | Flash 约 10-15 RPM、250-1500 RPD（第三方口径不一，以官方页为准；2026-04 起 Pro 退出免费档） | 足够但量小 | 只够做 L2 复核腿；免费档数据用于训练；国内可达性存疑 |

兜底：付费档 GLM-4.7-FlashX（0.5/3 元每百万 tokens）单次评估约 **0.002 元**，免费档限流时自动切换。工程注意：免费模型代号会漂移（勿假设永久免费），模型名须可配置。

### Q4. 防薅羊毛工程手段（分层防线）

运费险教训（无风控=70-80% 被薅）直接映射，必须内置而非事后补：

1. **频率限制**：单 openid 每日退款申请上限 N 次；单笔订单仅 1 次批评退款机会（服务端状态机强制）；评估 API 调用频控+队列（免费档并发制限流本就要求排队）。
2. **账号风控**：openid（单小程序唯一）为计数主键 + **unionid 归并同主体多号**；微信未开放官方设备指纹 API → 弱信号（wx.getSystemInfoSync 等）自聚合成指纹，或采购腾讯云「活动防刷」/顶象（均覆盖小程序，识别模拟器/群控）；新注册+低活跃账号降权；行为序列风控（注册→支付→秒退款=高危）；IP 动态信誉评分（行业已弃静态黑白名单）。
3. **评估前后一致性校验**：批评与订单强绑定（必须真实支付且实际阅读答案——航延险"不乘坐不理赔"教训）；锚定反查（批评引用须真实存在于答案）；跨用户/跨时间相似批评聚类查模板化刷分；评估侧双模型分差阈值+低温/固定 seed+多次采样置信度（低置信→人工）。
4. **人工抽检队列**：抽样 X% 全量 + 高危全集（高分退款/高频退款/新号/批量相似文案）进人工复核，复核结论回流校准 judge（Manus 模式：AI 审 + Customer Success 兜底）；judge prompt 定期轮换防学习（linguistic reward hacking）。
5. **经济上限**（根因层——赔付与成本差价是套利根源）：单账号月退款金额/次数封顶；"全退"档每日限额；**退款优先以券/额度形式**（云 SLA 代金券先例，锁回平台消费降低套利价值）；微信支付 V3 退款 API 原生支持部分退款（≤50 次/单，out_refund_no 幂等，零钱 20 分钟到账）——执行层无障碍，注意其接口频率限制需自建退避。
6. **条款威慑**：条款明示虚构批评骗退款将封号并依法追责（保险诈骗 5 万入刑先例可类比援引）。

### Q5. 退款比例映射（连续分数 → 档位）的先例与建议

**先例一致指向「三档制」而非线性连续**：
- 华为云 ECS SLA：<99.975%→**10%**、<99%→**30%**、<95%→**100%**（月费比例）；阿里云同构（代金券形式、封顶月费）——连续可用性→三档赔付是十余年验证的范式。
- 美团准时宝：连续超时时长→金额档（2/5/8/12 元）或比例档（30%/70%）。
- Manus 反例：过错是布尔量，用二值 100% 退——不适用于"程度"型分数。

**对「<30% 不退 / 30-70% 退 50% / >70% 全退」的建议**：
1. **档位制正确**，理由：(a) 用户可理解、争议少（全部先例均为档位）；(b) judge 分数有方差（单次评审是高方差单试验测量，文献实证），档位边界天然吸收 ±5 分噪声；(c) 财务可预测。
2. **加缓冲带**：25-35 与 65-75 两个边界带进 L2 异构复核/人工裁决，避免临界抖动与"差1分全退/不退"的客诉。
3. **阈值不要拍脑袋定**：上线前跑 1-2 周影子模式（只评分不退款），看真实分数分布再定档位切点——LLM 打分常出现分布集中（如 60-85 聚集），30/70 切点可能需要按实测分布校准。
4. **"全退"档配频控**（全退是套利价值最高点，参照运费险差价教训）；50% 档优先退券。
5. **公示档位表**：对赌透明本身是付费转化卖点（准时宝/SLA 均公示），但 rubric 细节与 prompt 不公示（防 reward hacking）。
