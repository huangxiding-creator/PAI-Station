# IDEA_SEED — 总包千问（工程大脑→从业者付费咨询小程序）

> intake 时间：2026-09-28 ｜ 来源：用户直接交底（功能四件+凭证全套）｜ 状态：已揣摩真实意图

## 一句话

把「秘塔工程大脑」（用户在 metaso.cn 搭建的工程总承包知识库）包装成微信小程序「总包千问」：工程总承包从业者语音/文字/截图提问 → 工程大脑级回答 → 免费试用漏斗（每日3次）→ 1元解锁全文 → 质量对赌（点赞赠次/批评退款）→ 海报裂变增长。

## 用户画像与痛点

- **画像**：工程总承包从业者（施工/投标/项目管理人员）——现场问题急、专业口径要准、没时间读长文
- **痛点**：专业问题问通用 AI 不懂工程黑话与规范；问同行欠人情；查规范/定额耗时。用户自己搭了秘塔工程大脑=已有「答案引擎」，缺的是**面向从业者的产品化分发**

## 用户原始需求四件（已交底）

1. **多模态咨询**：语音对话、录音咨询、截图咨询
2. **试用付费漏斗**：微信登录每日3次免费；超次免费看前200字，付1元看完整回复
3. **质量对赌**：点赞→赠1次免费（每日上限1次）；批评+意见→真诚度/真实度评分0-100%→按比例退款（50%分退50%，100%分退100%）
4. **海报裂变**：回复生成精美海报（问题+前200字）→社交媒体扫码→免费看完整内容

## 揣摩的真实意图（比表面深一层）

1. **离钱近的第一天变现闭环**（任鑫三筛全中）：不是做工具做流量再想变现，而是每次咨询即付费机会——1元超低门槛=微信支付的心理零门槛
2. **质量对赌=信任货币**：敢承诺"批评就退款"的产品自证答案质量——这是差异化品牌记忆点，比"AI很聪明"可信一万倍
3. **裂变海报=内容即广告**：每条好答案自动变成获客素材，扫码看全文=精准获客（看完整答案的人=有相同问题的人=目标用户）
4. **秘塔工程大脑=数据壁垒**：通用AI问答没壁垒，工程垂直知识库+持续喂养=复利壁垒（用户已有）
5. **潜在未言明**：此产品跑通后，WeAppForge 工厂第2个小程序=资产复利实测（P3 判据：≤1人日）；总包学园+总包千问=总包系产品矩阵（学园=深度研报，千问=轻咨询，互相导流）

## 约束与红线

- **秘塔 API=积分制付费资源**（09-24 用户令：批量禁用只做必要性单查）——产品化调用=必要性单查获授权，但**积分成本必须进商业模型核算**（1元收入-积分成本-微信抽成=毛利）
- 密钥外置 R7：秘塔 API key/AppSecret/上传密钥入 data/secrets/ 红线区，永不入 git/前端
- 支付合规：1元解锁数字内容=**虚拟支付唯一合规通道**（Android 1%/iOS 12% 抽成；**退款 API 存在性待调研**——批评退款的合规实现路径是本提案关键风险位）
- 内容安全：AI 回复上墙（海报裂变）前过 msgSecCheck（200万次/天免费）
- 账号安全四件套：API 调用节流/冷却/日限额/熔断（防积分被刷爆=日预算硬顶 R 红线）
- WeAppForge 七腿管线复用（工厂已就位：v0.2.0 已上「总包学园」验证过全链）

## 成功形态（success_form）

从业者现场遇到问题 → 打开总包千问语音问一句 → 10秒内得到带出处的专业回答 → 觉得值→点赞/分享海报 → 同事扫码看到完整答案 → 也来问 → 付费1元成为日常。**周留存提问用户付费转化≥5%**为北极星验收位（首月）。

## 价值假设（value_hypothesis）

- H1：工程从业者愿为「带出处的专业即时回答」付1元（价格锚点低于一瓶水，低于问人情）
- H2：质量对赌显著提升信任与转化（敢退款=自信=可信）
- H3：海报裂变 CAC≈0（内容自传播），无需投放
- H4：1元收入覆盖秘塔积分成本+微信抽成后毛利为正（待积分定价数据验证——**证伪点**）
