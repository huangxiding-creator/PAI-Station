## 状态机

- 每产品一行状态：`work/pipeline_state.json` → `[{sku, stage, ts, notes}]`
- 推进规则：段出口门全绿才进下段；**S1.5 只认用户原话**（approve --note 落账）
- 红线继承：数字零造假 / 账本回填 / 密钥不进仓 / 推送冻结令在役（本地 commit 可以）
