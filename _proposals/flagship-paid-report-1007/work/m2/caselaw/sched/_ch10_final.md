**【本章导读与解题说明】**
诉讼与仲裁面临周期长、鉴定繁、成本高、结果难测的现实困境，ADR（替代性争议解决）由此成为造价争议的降本主战场。本章两大制度支柱：**争议评审（DAAB）**——过程争议即时消化，评审意见有临时拘束力、可转换为终局决定（第一节）；**调解协议司法确认**——民间调解成果经法院裁定确认即获强制执行力（第二节）。判例谱系覆盖确权、履行、翻悔、执行四条战线（第三、五节），并以造价工程师的复合调解策略与协议合规条款收口（第四节）。方法论主线一句话：**ADR的价值不在"和解的姿态"，而在"可执行的成果"**——评审意见的终局转换、调解协议的司法确认，都是把合意变成能拿去执行的文书；没有执行力加固的调解，只是下一次诉讼的庭前会议（本句为本研究导读性判断）。

读者可带着四个场景进入本章（本段为本研究使用指引）：施工还在进行、争议已经冒头，等竣工再算总账还是现在就评（第一节）；调解达成了协议，怎么让它变成能直接执行的文书（第二节、第四节）；对方在调解书签了字又想翻悔（第五节）；工程款调解协议签了、对方不履行，从哪里开始执行（第五节）。四个场景，五节作答。

## 第一节 争议评审（DAAB）：过程争议的即时消化机制

### 1.1 制度定位与规则体系（元数据级锚源上的归纳）

争议评审的定位是"过程消解"——评审组随项目走、争议随发生随评，而非"终点裁决"（本研究归纳）。

工程造价争议具有技术复杂性与动态累计特征——争议推迟到竣工结算集中爆发，代价是证据灭失、鉴定漫长与资金链断裂（行业共识，本研究归纳）。争议评审机制的核心理念是**关口前移**：评审组在履约期内即时消化变更、签证、索赔与计量争议，防止技术分歧演化为法律诉讼。

规则体系（据检索名录所载，元数据级）：国内机构争议评审规则以《北京仲裁委员会建设工程争议评审规则》为代表——名录载有两种版本的规则文件（192.58KB与765.83KB，分别存于工程争议评审与纠纷裁决库路径） (P000908)；在分会层面，中国电子节能技术协会工程总承包分会于2024年7月31日发布《建设项目工程总承包争议评审规则》公告（名录载有该公告文件，2.15KB） (P000908)——两套规则分别代表**仲裁机构示范规则**与**行业组织专门规则**两条路径：前者依托仲裁机构的名册与程序监督、与后续仲裁无缝衔接；后者侧重工程总承包（EPC）领域的设计施工交叉、变更频繁与总价包干争议，路径更贴近行业痛点。2024版清单计价标准设争议评审条款（本书结算章已述其"首次以'争议评审'为核心构建多元解纷机制"的定位）；FIDIC合同条件的DAAB（争议避免/裁决委员会）机制是国际渊源 (P000908)。

本章对该节的写作纪律（边界声明）：检索名录仅载规则文件的名称、体积与路径，**规则正文未在库**——本节对评审程序细节的论述限定为行业通行的制度框架（本研究归纳），涉及具体机构规则的条文（评审员人数、异议期天数、费用分担），一律不作转述，实务适用以规则正式文本为准 (P000908)。

### 1.2 临时拘束力与终局转换的行业框架（本研究归纳）

评审意见的效力设计是整个制度的枢纽——它要在"说了算"与"还能争"之间取得平衡：立即说了算（保障施工与付款继续），保留异议通道（保障不服方的程序权），异议失权则终局（保障争议真正了结）。

机构争议评审的通行效力框架（行业通行规则归纳，本研究整理）：

```
┌─────────────────────────────────────────────────────────────┐
│ 争议评审意见的效力框架（行业通行，细节以各规则文本为准）    │
├─────────────────────────────────────────────────────────────┤
│ 第一态：临时拘束力——评审意见作出即约束双方，先行履行       │
│         （发包方按意见拨付临时款；承包方继续施工）         │
│ 第二态：异议期——不服方须在规则约定期限内提出书面异议，     │
│         逾期未异议的进入第三态                             │
│ 第三态：终局决定——异议期满未异议，意见转换为终局决定，     │
│         效力等同合同补充协议，后续仲裁/诉讼直接采信        │
└─────────────────────────────────────────────────────────────┘
```

对合同起草者的操作注解（本研究设计）：把上述三态写进合同时，至少锁定四个变量——评审组的组成与任命时点（开工即设、随项目走）、临时履行的支付期限、异议期的具体天数、终局转换后与仲裁/诉讼的衔接条款；变量缺一个，评审机制就在关键节点上失灵。该框架与FIDIC条件下的裁决（Adjudication）机制同构：即时性（先履行、后争议）与终局性（异议失权）的组合，让争议在施工仍在进行时就地解决。评审与司法的分工（本研究归纳）：评审管"过程的技术定性"——量是多少、价怎么套、责任在谁；司法管"权利的终局裁断"——评审失灵或未约定评审时的兜底。评审意见被司法直接采信的前提是其自身的程序合规（约定期限内作出、双方程序权利得到保障），这也是机构规则优于临时评审组的原因：机构的名册、程序监督与异议机制，本身就是司法采信的信用背书。对造价工程师的角色含义：评审程序中既做技术事实的厘定者（量、价、定额口径），也做合同规则的执行者（变更程序、索赔条件）——与本书第四节复合调解的角色定位一致。

## 第二节 调解协议司法确认：给调解成果装上执行引擎

### 2.1 法定基座：《人民调解法》实收条文

司法确认制度的全部要件都能在这部法律里找到原文——这是本章与借条类"实践规则"最大的不同：每一步都有现成的法条作依据，写作与审查均照原文核对。

人民调解法（中华人民共和国人民调解法，2010年8月28日第十一届全国人民代表大会常务委员会第十六次会议通过，2011年1月1日施行）第五章对调解协议的效力与司法确认作出完整规定（以下条文均系资料库实收原文） (P000914)：

- **第二十八条**：经人民调解委员会调解达成调解协议的，可以制作调解协议书。当事人认为无需制作调解协议书的，可以采取口头协议方式，人民调解员应当记录协议内容——口头协议须记录的规则，为简易纠纷留下快速通道（但司法确认以书面协议书为审查基础，需执行的调解应作成协议书）。
- **第二十六条**（配套）：人民调解员调解纠纷，调解不成的，应当终止调解，并依有关法律、法规的规定，告知当事人可以依法通过仲裁、行政、司法等途径维护自己的权利——调解组织的退出告知义务，为调解失败预留程序衔接。
- **第二十九条**：调解协议书可以载明下列事项——当事人的基本情况；纠纷的主要事实、争议事项；各方当事人的责任以及达成调解协议的内容、履行的方式、期限。**调解协议书自各方当事人签名、盖章或者按指印，人民调解员签名并加盖人民调解委员会印章之日起生效。**
- **第三十一条**：经人民调解委员会调解达成的调解协议，**具有法律约束力**，当事人应当按照约定履行。人民调解委员会应当对调解协议的履行情况进行监督。
- **第三十二条**：当事人之间就调解协议的履行或者调解协议的内容发生争议的，一方当事人可以向人民法院提起诉讼。
- **第三十三条**：双方当事人认为有必要的，**可以自调解协议生效之日起三十日内共同向人民法院申请司法确认**，人民法院应当及时对调解协议进行审查，依法确认调解协议的效力。**人民法院依法确认调解协议有效，一方当事人拒绝履行或者未全部履行的，对方当事人可以向人民法院申请强制执行。**

### 2.2 申请条件与审查要点（法定框架＋实务归纳）

```
┌─────────────────────────────────────────────────────────────┐
│ 调解协议司法确认程序流程（依实收条文归纳）                  │
│  发包方＋承包方在调解组织主持下达成造价调解协议             │
│         ↓（当事人签名盖章或按指印＋调解员签名＋调委会印章） │
│  协议书生效                                                 │
│         ↓（30日内 · 双方共同 · 书面申请）                  │
│  基层人民法院特别程序审查（主体/意思/内容/案由）            │
│      ├── 裁定确认有效 → 一方不履行 → 对方直接申请强制执行  │
│      └── 裁定不予确认 → 重新调解或提起普通诉讼             │
└─────────────────────────────────────────────────────────────┘
```

先立定位（本研究归纳）：司法确认是特别程序——不开庭辩论、不作实体判决，法院只审查协议的合法性与可执行性；审查通过出具的是**民事裁定书**而非判决书——裁定书即执行依据，这是它与普通诉讼最直观的产物差别。

申请司法确认的四要件（法定框架归纳自实收条文） (P000914)：**调解组织合规**——协议须由依法设立的人民调解委员会（或符合最高法院规定的特邀调解组织，如建工行业调解中心）主持达成；**共同申请**——必须由双方当事人自愿共同向法院提出书面申请，单方申请不予受理；**期限三十日**——自调解协议生效之日起三十日内提出，逾期申请不予受理、当事人只能通过普通民事诉讼解决争议；**形式完备**——当事人签名/盖章/按指印＋人民调解员签名＋人民调解委员会印章三件齐备（第二十九条的生效要件同时是司法确认的审查要件）。四要件中**期限最容易失手**：协议生效日以最后一方签章日起算，商务人员须建立三十日倒计时台账（本研究归纳）。
管辖的判定（实务归纳） (P000914)：司法确认案件由基层人民法院管辖——中级人民法院及专门法院原则上不受理；具体向调解组织所在地基层法院提出（与人民调解委员会的属地监督关系对应），个案以受诉法院口径为准；与第五节判例九的专属管辖合并记忆：调解与确认走基层法院，调解失败转诉讼走工程所在地法院——两条路各有各的门。

审查要点与不予确认情形（实务归纳框架，基座为实收条文的"依法确认"审查权） (P000914)：法院审查兼顾形式与实质——
- **当事人**：是否具备完全民事行为能力与诉讼主体资格；
- **意思表示**：是否真实自愿，有无胁迫、欺诈或重大误解；
- **内容**：是否明确具体、具备直接履行与强制执行的可操作性（结算金额、付款期限、账号、违约责任是否清晰精确）；
- **案由**：是否属于法院受理民事案件范畴。
存在下列情形之一的，裁定不予确认或驳回（情形框架归纳） (P000914)：

```
不予确认/驳回申请的法定情形框架
  ├── 1. 损害国家利益、社会公共利益或第三人合法权益
  ├── 2. 违反法律、行政法规的强制性规定（如违法分包、无资质转包的结算套现）
  ├── 3. 恶意串通、虚假调解逃避债务或套取工程资金
  ├── 4. 意思表示不真实（欺诈、胁迫、重大误解）
  ├── 5. 内容不明确、存重大歧义、无法强制执行
  └── 6. 逾期申请（超过三十日）或单方申请等其他要件缺失
```**虚假调解是建工场景的高发雷区**（本研究归纳）：其一，内部项目经理与承包人串通虚增造价、虚构工程量——侵占国有资产或逃避银行抵押权；其二，母子公司、关联公司之间以调解转移资产逃避债务；其三，无真实施工背景的"套取工程款"型调解（本书第八章判例三的套取案即其样本）。三类协议一经法院发现即驳回确认申请，当事人还可能面临虚假诉讼的法律责任——造价工程师参与调解时对工程量真实性的专业核验（图纸对量、现场勘验），正是这道防线中不可替代的一环。

### 2.3 效力来源与执行衔接

强制执行效力的直接法源即第三十三条第二款（实收原文）——确认有效的民事裁定书属于具备执行力的法律文书，一方拒绝履行或未全部履行的，对方可直接申请强制执行 (P000914)。未经司法确认的调解协议则只有合同约束力（第三十一条），履行争议仍须诉讼（第三十二条）——**确认与不确认之间，隔着的是"直接执行"与"重新起诉"的天壤**（本研究归纳）。

使用指引（本研究）：达成调解协议后的决策树——需要直接执行力的（对方信用存疑、已有违约迹象），30日内申请司法确认；双方互信良好且分期付款有担保的，可暂以合同效力运行、违约再诉，但须承担第三十二条的诉讼成本。决策的唯一输入是对方的履约信用。

两轨道的时序成本对比（本研究归纳）：确认轨道——协议生效→30日内共同申请→特别程序审查→裁定→对方不履行即申请执行（总耗时以周计）；不确认轨道——协议生效→对方违约→重新起诉（一审可能历经鉴定）→二审→执行（以年计）。判例一（35天解封）与判例十（按协议履行终执）是确认轨道的速度样本；判例十六（撤诉后协议裸奔）是不确认轨道的反面教材。调解的所有谈判成果，最终都要在这个时间差里兑现成现金流。

### 2.4 判例一至三：司法确认与调解书效力的三个样本

**判例一：调解书达成即解封冻结款**——（2017）鲁1302民初12499号之一，山东省临沂市兰山区人民法院 (P000902)：解除保全申请人林清福与被申请人天元建设集团有限公司第四建筑工程公司、天元建设集团有限公司、临沂市临河防水材料有限公司建设工程合同纠纷一案中，林清福于2017年11月7日向法院提出财产保全申请，法院于同日作出（2017）鲁1302民初12499号民事裁定书，冻结了天元公司在中国建设银行临沂中支行账户（尾号37×××04）的存款——应冻结280万元、已冻结280万元；后经法院主持调解，双方达成调解协议，法院出具（2017）鲁1302民初12499号民事调解书；林清福于2017年12月11日持调解书申请解除保全。- **争议焦点**：法院调解书生效后，保全申请人据此申请解除财产保全的，法院应否立即解除对工程企业账户存款的冻结？（依裁定争点归纳） (P000902)
- **裁判要点**：法院审查认为，双方达成的民事调解书能够证明调解协议已合法成立并生效；依照《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第一百六十六条第一款第四项之规定，裁定**立即解除对天元公司该银行账户内280万元存款的冻结**（2017年12月12日；裁定立即开始执行，不服可在五日内申请复议一次，复议期间不停止执行）。- **实务教训**（本研究归纳） (P000902)：调解书一旦生效即具完结效力——从保全冻结（2017年11月7日）到调解书解封（12月12日）约35天，被冻结的280万元工程资金快速恢复流动性；这是调解对现金流的最直接价值：官司可以慢慢打，资金链等不起。保全申请人一方的对称提示：解除保全后若对方再违约，重新保全须另走程序——解封决定应与调解书的付款担保（违约条款、履约保证）联动评估，别让"解封快"变成"追款慢"。

**判例二：部分撤诉的边界**——（2017）川0322民初1803号，四川省富顺县人民法院 (P000902)：原告四川省韦业房地产集团有限公司（住所地富顺县赵化镇，法定代表人李远阜）与被告四川杰辉建设有限公司（住所地成都市武侯区）建设工程施工合同纠纷一案，双方在法院组织下达成调解，自愿解除双方签订的《建设工程施工合同》及《补充合同》；2017年12月20日，原告向法院申请撤回起诉。- **争议焦点**：双方已就解除合同的诉讼请求达成调解协议后，原告申请撤回全部起诉的，已调解部分的撤诉应否准许？（依裁定争点归纳） (P000902)
- **裁判要点**：法院裁定认为：原告书面申请撤回起诉，是对自己诉讼权利的处分，符合法律规定；**但双方已经就解除合同的诉讼请求达成一致意见**——该部分诉讼请求所涉权利义务已被调解协议确认并产生法律效力，故对解除合同部分的撤诉不予准许；仅准许原告撤回要求被告支付违约金3360000元的诉讼请求；案件受理费16840元由原告负担（2017年12月26日）。- **实务教训**（本研究归纳） (P000902)：调解协议中关于合同解除、造价确认等实体权利义务的约定一经达成即生不可逆效力，单方撤诉不能否定——法院对撤诉的审查穿透到诉请与调解的重叠面：违约金请求（3360000元）未入调解的可以撤，合同解除已调解的不能撤；诉讼策略上，"撤什么、留什么"要对照调解协议逐项核对，而不是一刀切全撤——撤错了想再诉，可能已过时效或失了筹码。

**判例三：分支机构签的调解协议穿透法人**——（2010）浙衢民终字第593号，浙江省衢州市中级人民法院 (P000903)：原告杜某承建被告浙江省某某集团有限责任公司内设二级分支机构（人才劳务公司）发包的金某某公司厂房工程；经决算，土建及水电工程造价2050139元，扣除已付工程款1280980元后仍欠640000元。此前，该建工公司曾起诉业主金某某公司并达成调解协议，约定金某某公司支付建工公司820000元及诉讼损失49070元；后因金某某公司无可供执行财产，法院向建工公司出具"案件拟终结执行告知书"——建工公司据此主张对内部承包名义下的杜某不承担支付义务。- **争议焦点**：公司内设分支机构签订的内部承包协议及其对外调解协议，法律责任由谁承担？与业主达成的调解协议执行不能，能否对抗实际施工人的付款请求？（依判决争点归纳） (P000903)
- **裁判要点**：衢州中院二审认定：企业法人的分支机构不具备独立法人资格，其以自身名义签订的内部承包协议及调解协议的法律责任，**依法由企业法人一体承担**；建工公司与业主金某某公司达成的调解协议未能实际执行到位（终结执行），不能作为拒绝向实际施工人杜某支付工程款的抗辩理由——判决建工公司支付杜某工程款640000元，并按同期贷款基准利率支付利息。- **实务教训**（本研究归纳） (P000903)：分支机构名义的造价调解协议，其法律后果由法人一体承受——法人分支机构不具备独立法人资格，其以自身名义签订的内部承包协议与调解协议的责任由企业法人一体承担；"上游调解没拿到钱"（对业主的820000元调解协议终结执行）不构成对下游（实际施工人640000元）的抗辩——付款义务随各自的合同关系独立运行，上下游风险不传递；企业端的风控动作：分支机构的对外结算与调解授权一律书面化、限额化，别让一个项目部的签章牵动整个集团的资产负债表。

## 第三节 判例谱系：确权、履行与连带

**判例四：竣工盖章不等于质量封顶（跨章复用案）**——（2018）粤19民终12052号，广东省东莞市中级人民法院（一审广东省东莞市第一人民法院（2017）粤1971民初6901号） (P000919)：上诉人东莞市精研粉体科技有限公司（住所地东莞市东城区）因与被上诉人广东泓泉电力工程有限公司建设工程施工合同纠纷不服一审判决提起上诉——泓泉公司完成厂区电力工程施工后出具《工程竣工报告》，精研公司在该报告上盖章确认案涉工程验收合格；结算争议诉讼中，精研公司又以工程存在多处严重质量缺陷（变压器容量不符、谐波干扰致设备故障）为由主张扣减结算款（本书工期章已详其技术定性断面）。- **争议焦点**：发包方在工程竣工验收报告上盖章确认合格，是否直接阻断其后续基于工程质量瑕疵主张扣减工程款的抗辩权？（依判决争点归纳） (P000919)
- **裁判要点**：东莞中院二审认定：精研公司在《工程竣工报告》中盖章确认案涉工程验收合格，**并不意味着该工程便不存在任何质量问题**——对于竣工后显露的质量隐患或隐蔽工程瑕疵，发包方依法仍享有主张维修、扣减相关造价损失的权利；发包方已盖章接收工程并投入使用的，其单方主张的质量缺陷不能成为拒付剩余工程款的合法抗辩（结算侧终局规则详见本书结算章）——质量救济与付款义务分轨运行。教训（本研究归纳） (P000919)：二审明确了"工程验收合格盖章"与"免除质量缺陷责任"在法律效力上的界限——对竣工后显露的质量隐患或隐蔽工程瑕疵，发包方依法仍享有主张维修、扣减相关造价损失的权利。落到调解与结算谈判：承包方要让质量切割条款写明"盖章验收即视为放弃一切显性及隐蔽瑕疵扣款主张"（争取不到这一条，就让质量责任单独计价）；发包方则应在验收前后保留书面质量异议凭证，避免协议文字歧义导致扣减权丧失——判例划了界限，协议文字必须自己把门关上。这个界限对调解的直接含义：质量条款是调解桌上必须明说的议题，留白的代价由留白者承担。

**判例五：退场协议确权＋班组收据抵扣＋违约金核算**——（2015）滨塘民初字第7984号，天津市滨海新区人民法院 (P000918)：原告马鞍山市宏胜劳务有限责任公司与被告中建六局第三建筑工程有限公司曾签订劳务分包合同；2014年4月23日，双方在同日签订两份《退场协议》约定原告退场、相关施工内容由被告另行分包——退场协议同时承担了"结算协议＋付款计划＋违约条款"三重功能：第一份确认应付工程款4056669元（4月30日前付70万元、5月10日前付至300万元、6月10日前付清），第二份确认802583元（5月10日前付60万元、6月10日前付清），均约定逾期按银行同期贷款利率2倍支付违约金；协议签订后原告按约完成退场，被告经案外人天津青年阳物业管理有限公司（经工商查询系被告持股90%的控股股东关联企业）分8笔共支付360万元，仍拖欠其余工程结算款1259252元——原告诉请：支付剩余结算款1259252元；支付拖欠工程款违约金349932元（暂算至2015年8月31日、主张至实际支付之日止）。被告抗辩：2014年9月11日向原告下属班组支付放线盒款7500元（班组成员关安民出具收据）应予扣除，且违约金过高请求酌减。- **争议焦点**：一是退场结算协议中约定的"2倍银行同期贷款利率"违约金条款是否有效及应否酌减；二是被告向承包方下属班组私下支付的款项能否直接抵扣已调解确认的工程结算款。（依判决争点归纳） (P000918)
- **裁判要点**：法院认定：双方签署的两份《退场协议》系真实意思表示，内容合法有效，确认的结算金额（4056669元＋802583元）及付款计划对双方具备约束力；被告2014年9月11日向原告下属班组支付的放线盒款7500元——因班组成员关安民出具了收据，**认定为已付工程款予以扣减**；关于违约金，结合欠款金额、违约时长及实际损失，对逾期付款违约金依法予以核算支持（原告诉请暂计349932元）。- **实务教训**（三则，本研究归纳） (P000918)：其一，退场协议的结算确权效力高于事后异议——两份协议的金额与期数结构即付款计划的"合同化"，签字前算清，签字后认账；其二，**班组收据视同已付款**——被告向原告下属班组关安民支付的7500元凭一张收据即获扣减认定，承包方必须严控现场领款授权（领款权限书面限定于公司账户与授权代表）、防止班组擅自出收据稀释结算款；其三，2倍利率违约金须有损失依据支撑——本案法院结合欠款金额、违约时长与实际损失核算支持；关联公司代付（持股90%的物业公司分8笔支付360万元）不改变付款主体认定——走谁的账本是财务安排，欠谁的债看合同关系。

**判例六：阶段性结算单确权＋附条件放弃（跨章复用案）**——（2016）豫0327民初1133号，河南省宜阳县人民法院 (P000913)：汇河公司与灵山国诚公司边设计边施工模式下，2014年11月18日签署《汇河公司莲花公园工程结算单一》，确认温泉区汤池、马车、树屋宾馆项目总造价7522400元；2015年5月22日签署《莲花公园决算单》，确认23项零星工程项目总造价5180000元——两单合计12702400元；另有12项零星工程总造价1017870元未结算，决算总额15190038.4元。原告的证据链还包括：被告公司总经理郭朝阳2014年6月22日签字确认的《工作日志》载明5D电影院单价350元/㎡、施工面积3441㎡，捉鱼城面积7732㎡、水上娱乐园假山面积18446.8㎡——单价与面积的双重签认构成结算单的底账。原告在诉中声明：如被告对原告施工项目的工程量及价款没有异议，只主张两份结算单确认的12702400元，**其他未结清部分的工程款2487638.4元原告自行放弃**；如被告不认可上述工程款总价，则原告不放弃主张全款的权利（诉请构成为温泉汤池等工程款7522400元＋23项零星工程款5180000元及各自利息）。- **争议焦点**：一是"边设计边施工"项目下双方签署的阶段性《结算单》与《决算单》能否直接作为定案造价依据；二是当事人在诉讼中附条件放弃部分造价主张的法律生效要件。（依判决争点归纳） (P000913)
- **裁判要点**：法院认定：《汇河公司莲花公园工程结算单一》与《莲花公园决算单》具备法律约束力，明确代表双方对对应工程量与单价的最终结算确认；被告关于质量裂缝渗漏与未开发票的抗辩不能对抗已签字确认的结算效力；原告附条件放弃的声明在条件成就时有效——以确认金额为基数支持诉请（全案详见本书签证章）。- **实务教训**（本研究归纳） (P000913)：附条件放弃条款的双刃结构——放弃以对方认可为触发条件、以对方争议为失效回退，攻防两向的触发与失效要件都写在明处（这在诉前调解的策略文书里尤其值得效仿：让步留后门，争议保全款）；分阶段结算单在无图纸项目中的确权价值已由本书签证章与本章双重印证；总经理签字的工作日志（单价350元/㎡＋面积）证明——单价签认不必等格式化签证，有权人员签认的单价记录同样构成结算底账。

**判例七：口头结算＋合伙连带**——（2018）湘3123民初897号，湖南省凤凰县人民法院 (P000919)：原告田某某1、石某某受被告蒋某某、王某某夫妇之邀于2014年4月到土桥垅"蛋子丘"砌堡坎，因朋友关系未签书面合同，口头约定全包（包工包料）每立方米280元据实结算；2014年底全部完工并结算，共砌790多立方米石方，已付4万元、尚欠182415.2元；蒋某某2018年3月2日出具书面证明确认欠款182415.2元（本案2018年11月1日受理、12月14日开庭，简易程序）。八名被告系2013年合伙建房协议的当事人（刘某负责办手续、田某某2负责外围协调，二人未出资但参与盈余分配）；蒋某某与王某某原系夫妻。其余被告抗辩自己并非合伙人或未签署书面合同——王某某答辩对二原告诉讼请求及事实理由均无异议。- **争议焦点**：口头达成的造价结算约定对未签字的个人合伙成员是否具备法律约束力？未出资但参与分工分利者是否属于合伙人？（依判决争点归纳） (P000919)
- **裁判要点**：法院认定：蒋某某出具的欠款证明与合伙建房事实相互印证；刘某（办手续）、田某某2（外围协调）虽未出资但参与分工及盈余分配，**依法认定为合伙人**；合伙人代表在结算中确认的造价债务属合伙共同债务——判决王某某、蒋某某、刘某、杨某某1、田某某2、詹某某、杨某2共同向二原告支付工程款182415.2元并承担连带清偿责任；利息请求因缺乏明确约定未获支持。- **实务教训**（本研究归纳） (P000919)：口头结算的对手方若是个人合伙，穿透核查实体组织形态是第一动作——未出资但参与分工与盈余分配的仍属合伙人（本案刘某办手续、田某某2外围协调二人未出资仍连带）；调解协议必须让主要合伙人共同签字或取得授权委任，并写明"全体合伙人承担连带清偿责任"；利息请求因缺乏明确约定未获支持——口头关系下连利息都要单独约定；对合伙方的对称教训：合伙结构里"没签字"不等于"没责任"，组织形态核查在签约前而非诉讼后。

**判例八：主体资格与诉请匹配的程序门槛**——（2014）湛吴法民一初字第309号（广东省吴川市人民法院）与（2015）绍虞民初字第45号（浙江省绍兴市上虞区人民法院） (P000920)：- **案情**（湛吴法民一初字第309号）：林鸣与中铁六局集团有限公司茂湛铁路工程第一项目部、中铁六局集团呼和浩特铁路建设有限公司建筑设备租赁及工程结算纠纷（本书工期章已详其租金之债穿透法人），审理中法院重点审查分支机构、项目部与法人实体之间的授权委托链条——原告持有的授权文件能否代表承包工程，直接决定其请求权基础的成立；
- **案情**（绍虞民初字第45号）：原告张强起诉被告浙江康利新型建材有限公司、王海浪、中利建设集团有限公司，主张提供黄沙、石子等建材的欠款89427元；绍兴市上虞区人民法院审查认为，**起诉的事实和理由与诉称事实不相符，不符合民事诉讼法第一百一十九条规定的起诉条件**，裁定驳回起诉。- **争议焦点**：分公司、项目部的授权链条如何认定？起诉的事实理由与诉请根据不符时法院如何处理？（依两案争点归纳） (P000920)
- **实务教训**（本研究归纳） (P000920)：调解与司法确认前先过主体关——项目部、分公司这类内设机构签署的调解文书缺法人书面授权的，执行力悬空；诉请与法律关系张冠李戴（买卖错列施工分包）的，连实体审理都进不去、直接裁定驳回起诉——程序门槛的失败不审实体，重来的成本远高于事前的核对；两案合并的操作清单：**签约核授权、起诉核案由、调解核签章、执行核主体**——四个节点一道门槛，每个都是分钟级的核对，漏过任何一个都是月级的返工。

## 第四节 造价工程师的复合调解策略

### 4.1 从单向计量到技术-法律多轮（本研究框架）

在工程造价争议解决中，纯法律思维往往难以厘定复杂的现场计量与施工工艺，纯技术思维又易忽视合同效力、举证时效与责任归属——复合调解由此成为高质量协议与顺利通过司法确认的核心保障。

传统造价工程师在调解中是"算账员"——被动核对工程量与单价；复合调解要求转变为**技术-法律双轮驱动**的专家（框架为本研究设计）：技术轮——工程量核算、单价套用、定额口径、替代方案折算；法律轮——合同效力识别（黑白合同、违法分包对计价依据的影响，本书第八章）、证据效力判断（签证、日志、微信记录的证明力，本书第五章）、程序时限意识（索赔时效、除斥期间，本书第七、九章）。三轮之外还有第三只轮：**方案轮**——针对设计变更、地质条件变化引发的造价大涨，从工程技术合理性出发提出"技术替代方案折算造价"的中立建议，为当事人搭建商业谈判的让步阶梯——技术上可行的折中，常比法律上纠缠的责任划分更快打开僵局（本研究归纳）。

本书前九章的裁判谱系在此汇流为调解桌上的谈判筹码——每一章的"裁判预期"都是复合调解的定价锚：无效合同的参照计价（第八章）定了争议区间下限、优先权与利息的剔除规则（第九章）定了执行回收的上限预期、鉴定的十维质料（第六章）定了诉讼路径的时间成本——把这些讲给对方听，就是最有力的"继续打官司不划算"论证（本研究归纳）。

### 4.2 谈判五步法（本研究设计）

五步法是复合调解的标准作业程序，每一步的产出物都可归档、可复用（本研究设计）：

1. **争议拆解与清单化**：把复杂争议拆为独立技术模块——超挖量、支护变更、停窝工、人工材料调差、质量缺陷修复费各自成行；无争议金额率先签字冻结（判例六的两单冻结12702400元即其样本——先锁定的不只是金额，更是谈判的心理锚点（无争议项冻结得越多，争议项的谈判压力越小）），集中火力调解争议项；拆解的产出物是一张双栏对照表：左栏无争议（已冻结）、右栏争议（待谈），右栏每项标注双方主张额与证据强弱（本研究设计）；
2. **技术-法律双链核验**：技术链（图纸、变更单、隐蔽验收记录、施工日志、踏勘照片）×法律链（索赔时效是否超期、签署人是否具表见代理权限、签证单是否有监理与发包方代表双重签字）逐项过筛——本书签证章的证据层级表与工期章的延误责任对照表在此复用；单链强的项目走快调，双链弱的项目先补证（本研究设计）；
3. **三层造价模型**：乐观线（证据完全充分、法律支持度高时的结算金额）/中立线（计入双方诉讼风险、鉴定时间成本折算后的合理调解金额）/保底线（进入诉讼司法鉴定可能面临的最不利扣减结果）——区间一出，谈判空间货币化；三线的依据源即本书各章的裁判谱系（鉴定章的质证要领决定保底线深度、无效章的参照规则决定乐观线口径）；中立线与保底的差额，就是对方"省下的诉讼成本"，也是让步空间的天然上限（本研究设计）；三层模型的作业要点：每条线都注明依据（哪个判例、哪份证据），让对方看得见你的定价逻辑——黑箱式的"最后报价"只会激起对抗，有依据的区间才能引导理性成交；三层线的最终用途是在调解协议里锁定"中立线"金额——它就是七大条款第2项的那个唯一终局数额。
4. **技术闭门会商**：谈判遇僵局时组织双方造价员与商务经理开技术会商会——避开抽象的法律责任争吵，直接针对工程量计算规则、定额子目套用、市场价格信息期别等技术细节逐项核对，利用专业中立性消除双方的技术认知壁垒；会商的成果即时形成《技术共识备忘录》（哪怕只锁定两三个子目），把僵局切成可消化的片段（本研究设计）；
5. **拟制可执行协议**：金额精确到分、付款日期与银行账户明确、违约金计算公式清晰、30日内共同申请司法确认的配合义务写入条款——协议起草的每一条对应第二节的法定要件与审查要点，让文书一次通过司法确认审查（本研究设计，基座为第二节法定要件与第四节的七大条款）。

### 4.3 协议七大合规条款（本研究设计，法定基座为实收条文）

调解协议要通过司法确认审查，文本本身必须先过合规关——七大条款即按照第二十九条形式要件、第三十三条确认要件与本章判例教训反向设计的自检清单（本研究设计）：

1. **主体与机构合规**：协议首部载明调解组织法定全称（"经某某市某某区人民调解委员会调解达成"）与调解员姓名；当事人信息与营业执照及法定代表人身份证明一致；分支机构参与的附总公司专项授权委托书——判例三（分支机构协议穿透法人）与判例八（授权链条审查）的双重教训；
2. **数额唯一终局**：结算总价大写精确＋"再无其他争议"终局句（判例六的放弃条款结构）；
3. **付款期数与账户**：写具体年月日（"第一期于某年某月某日前支付若干元"）＋指定收款账户（开户行、户名、账号）——禁用"竣工后付清""资金到位后支付"等模糊语（不明确的付款条款在司法确认审查中被视为不可执行的高危表述）；判例五的两份退场协议即是分期付款条款的标准样本（期数×日期×金额三要素齐备）；
4. **质量一次性切割**：基于判例四的教训双向设计——承包方版本："结算总价已包含若干元作为保修期瑕疵修复补偿款，发包方确认后不得再以显性或隐蔽质量缺陷为由扣减"（把判例四保留的扣减权买断）；发包方版本："对已发现的某某缺陷，承包方限期修复并另行扣减若干元，其余质量问题按保修条款处理"（把已知缺陷与未知缺陷分开处理）；
5. **违约与执行承诺**：约定"未按期足额支付任何一期的，守约方有权就剩余全部未付款项及按日计违约金直接申请强制执行"——33条执行效力＋判例五的违约金核算边界（2倍利率获支持但以损失依据为锚）；
6. **司法确认配合义务**：写明"自本协议生效之日起三十日内（即某年某月某日之前），双方共同向基层人民法院申请司法确认"——把法定三十日变成双方的合同义务；配违约金条款（"任何一方拒绝配合提交申请材料的，向对方支付违约金若干元"），让拖延确认本身变成可索赔的违约（本研究设计）；
7. **份数与生效要件**：一式数份（当事人各执、调解委员会留存、司法确认申报各一份）；生效要件逐项落笔——各方当事人签名盖章或按指印＋人民调解员签名＋加盖人民调解委员会印章，三件齐备之日起生效（第二十九条原文的合同化转写）——签章要件既是生效开关也是确认审查的第一道门（本研究设计） (P000914)。

七条款的检验法（本研究归纳）：写完后做一次"假设检验"——假设对方明天就违约，拿这份协议能否直接申请执行？金额可执行（唯一终局数额）、账户可执行（期数与账户齐备）、主体可执行（授权与连带落定）、质量已切割（无翻案点）、确认已锁定（三十日配合义务与违约金在手）——五问全过，协议才算装上了执行引擎；任何一问含糊，回到对应条款补笔，比事后在法庭上解释歧义便宜百倍。

## 第五节 诉讼与执行衔接：管辖、执行与翻悔

### 5.1 管辖：专属规则压倒协议约定

调解协议或结算协议中的管辖约定，能否改变法定的专属管辖？答案是否定的——建工纠纷按不动产纠纷确定管辖的规则，优先于当事人的协议安排；对承包人这反而是好消息：无论对方在调解协议里塞了什么管辖法院，回法院的路始终指向工程所在地（本案工程施工地塔河县）（本研究归纳）。

**判例九**——（2020）黑27民辖终7号，黑龙江省大兴安岭地区中级人民法院 (P000915)：水利水电集团第二工程公司与塔河县红平运输队施工合同纠纷（一审（2020）黑2722民初197号，本书结算章已详），上诉人主张双方未签订书面合同、无从约定管辖，请求移送哈尔滨市阿城区人民法院审理。二审经审查认定：本案案由为建设工程施工合同纠纷，依司法解释规定按不动产纠纷确定管辖、由工程所在地法院管辖（工程施工地在塔河县）——**专属管辖的法定规则压倒调解协议或结算文件中自行约定的不符管辖条款**；调解不成转入诉讼的，仍由工程所在地法院管辖；驳回上诉维持原裁定。本章教训（本研究归纳） (P000915)：调解协议里写管辖条款是常见动作（都想留在"自己方便的法院"），但建工专属管辖不吃这一套——写专属管辖之外的约定等于白写，还可能让对方多一道管辖异议的程序拖延；调解协议若真想锁定解纷地，应与司法确认的管辖（基层法院）和争议评审条款的衔接一并设计，而不是单写一个对抗法定规则的法院名。

### 5.2 执行：履行完毕、追加第三人与划拨

执行是检验调解成果的终点站——确认裁定/调解书进入执行程序后的三个高频场景：按协议履行完毕的终执（好结局）、追加第三人扩大责任财产（攻坚）、以及对被执行人财产的查冻划拨（常规兑现）。

**判例十**——（2019）豫1222执886号之四，河南省三门峡市陕州区人民法院 (P000916)：申请执行人乔文波与被执行人中十治集团有限公司（住所地西安市碑林区）建设工程合同纠纷执行实施案，被执行人按照调解协议确定的付款计划履行了法律文书确定的金钱给付义务——法院审查认定义务已履行完毕，依法裁定**本案执行终结**（2019年12月2日）。- **争议焦点**：执行实施中债务人按调解协议履行完毕后，执行程序如何终结认定？（依执行程序归纳） (P000916)
- **实务教训**：在造价调解协议履行期内，付款方必须妥善保存每一笔工程款转账凭证与收据，并在执行法院留痕——履行完毕后依法取得执行终结裁定，及时解除被冻结的账户与资产；本案同时展示了调解成果的"完整生命周期"：调解协议→执行立案→按期履行→终结裁定——从谈判桌到结案，每一步都有文书为证（本研究归纳） (P000916)。

**判例十一**——（2019）鄂0117执异40号，湖北省武汉市新洲区人民法院 (P000916)：申请人（申请执行人）新八建设集团有限公司（住所地武汉市新洲区）与被执行人武汉奥顺酒店管理有限公司（住所地武汉市汉阳区）建设工程施工合同纠纷执行审查案中，新八公司申请**追加第三人**张学（1964年2月3日生）、杨强军（1972年11月5日生）、邓汉生（1948年12月5日生）参加执行程序（源文语料截断于申请段，追加理由与结果未载——本句为本研究证据边界声明）。- **争议焦点**：申请执行人能否在执行审查程序中申请追加案外第三人以扩大责任财产？（依执行程序归纳） (P000916)
- **实务教训**：执行阶段的主体扩张（申请追加第三人）是执行救济的重要一环——调解协议对签署方的约束不能自动及于案外第三人，追加程序因此成为承包人执行攻坚的常规动作；对被执行人的资产代持与由持股企业代付款等安排（判例五的代付结构为其镜像），追加与异议程序是穿透的法定通道（本研究归纳） (P000916)。

**判例十二**——（2020）辽0214执2760号，大连市普兰店区人民法院 (P000915)：申请执行人李洪广（1970年7月4日生）与被执行人赵卫（1983年7月10日生）、沈阳众成菲思特装饰工程有限公司建设工程合同纠纷执行实施案（2020年12月4日裁定），法院依生效法律文书对被执行人名下财产采取强制执行措施——生效文书给付义务的常规兑现路径。- **争议焦点**：生效法律文书确定的金钱给付义务，在被执行人未主动履行时如何通过执行实施程序兑现？（依执行程序归纳） (P000915)
- **实务教训**：生效文书（含司法确认裁定与民事调解书）确定的造价给付义务，最终由执行程序的查封、冻结、划拨兑现——执行的起点是文书，文书的起点是调解桌；本节三案合并的操作启示：履行中留痕（判例十）、不足则追加（判例十一）、再不足则划拨（判例十二）——执行救济的三级火箭（本研究归纳） (P000915, P000916)。

### 5.3 翻悔：再审与二审对调解合意的尊重

当事人在调解协议签署后，常以"造价未经审计""存在重大误解""金额显失公平"为由在二审或再审中翻悔——司法机关对此的统一态度是：自愿达成的合意系意思自治，无欺诈胁迫证据的翻悔一律驳回（三案样本见下）。这道防线保护的不只是个案协议，而是整个调解制度的信用基础——若签字可以随意反悔，就没有人敢在调解桌上让步了（本研究归纳）。

**判例十三**——（2017）浙民申3281号，浙江省高级人民法院 (P000917)：王卓成与浙江引拓建设有限公司建设工程施工合同纠纷再审审查（本书鉴定章已详其税金断面——涉案工程结算款769734元、含税金100400元）。本章断面：再审申请人主张双方此前达成的调解/结算协议存在造价计算重大误解、请求重新进行司法鉴定。浙江高院审查认为：当事人在诉讼或调解过程中，在平等协商基础上对工程造价金额、扣减事项达成一致意见并签署协议，**系对其民事权利的自主处分**；在无充分证据证明存在欺诈、胁迫等法定无效情形下，仅凭"结算金额低于市场价"或"未行司法鉴定"申请再审翻悔协议的，法院依法不予支持——裁定驳回再审申请。- **争议焦点**：当事人自愿签署造价调解/结算协议后，能否在再审程序中以造价未经司法鉴定为由请求撤销协议？（依裁定争点归纳） (P000917)
- **实务教训**（本研究归纳） (P000917)：调解协议中的造价让步属于合法的商业风险自担——一旦签署生效，司法机关不会轻易介入干预当事人的意思自治；造价人员在签署协议前必须核算清楚底线（三层模型的保底线即为此设），切勿寄望于事后通过诉讼翻悔；"未行司法鉴定"不是翻悔理由——鉴定是查明事实的工具，不是协议效力的前提；翻悔门的唯一钥匙在法定无效与撤销事由（欺诈、胁迫、显失公平的法定要件），而这些事由的举证门槛极高——把功夫花在签字前，是唯一理性的策略。

**判例十四**——（2017）渝民申2129号，重庆市高级人民法院 (P000917)：重庆半山一号房地产有限公司与望建（集团）有限公司建设工程施工合同纠纷再审审查（本书工期章、鉴定章已详）。本案工程未办理施工许可证即开工、2015年3月3日停工、双方均同意解除；已完工部分经**双方共同委托的中介机构进行结算审定**，确认无争议部分结算金额41625890元，争议部分（74#-84#/16#/45#-46#楼桩基础超深277032.98元与4、5标段围墙40446元）系发包人要求施工的合同外工程、应按审定金额支付。- **争议焦点**：双方共同委托中介机构结算审定后，一方在再审程序中能否翻悔要求重新鉴定？（依裁定争点归纳） (P000917)
- **裁判与断面**：再审程序中单方翻悔要求重新鉴定结算的，不予准许——共同委托审定的成果与调解协议同享"意思自治屏障"；再审同时确认：发包人仅凭照片不足以证明完工部分质量不合格（各施工节点已验收合格）；双方原因（未批先建行政处罚＋发包人对外纠纷）导致的停工，中止施工违约金不予支持（2017年12月25日驳回再审）。

**判例十五**——（2017）湘民终628号，湖南省高级人民法院 (P000917)：
- **案情**：上诉人（原审原告）孙耀强（1969年6月11日生，住长沙县）与被上诉人湖南望新建设集团股份有限公司、中冶长天国际工程有限责任公司建设工程施工合同纠纷二审案（2017年12月25日裁定，双方委托诉讼代理人到庭），双方在二审期间达成调解合意，法院依法处理终结原诉讼程序（源文系程序裁定，合意内容与履行细节未载——本句为本研究证据边界声明）。
- **实务教训**：二审阶段的调解合意同样获得司法采信与程序尊重——ADR成果在各审级通用，调解不是一审的专利（本研究归纳） (P000917)。要点：二审阶段的调解合意同样获得司法采信，ADR成果在各审级通用（本研究归纳） (P000917)。

**判例十六**——（2019）鄂1081民初1657号，湖北省石首市人民法院 (P000916)：中科恒源（益阳）新能源科技有限公司与易事特集团股份有限公司建设工程施工合同纠纷（2019年10月21日立案，原告住所地益阳市高新区，被告住所地东莞市松山湖），原告于2019年12月2日向法院申请撤回起诉——法院认为当事人有权处分自己的诉讼权利，裁定准许撤诉（本书工期章已详其函件断链教训）。本章断面：**诉前调解达成协议后申请撤诉获准**——但撤诉时未同步办理司法确认的，协议仅具第三十一条的合同约束力、不具直接执行效力；债务人拒不履行的，债权人仍须依第三十二条重新起诉。- **争议焦点**：诉前调解达成协议后申请撤诉，法院的审查要点及撤诉后协议的法律状态？（依裁定争点归纳） (P000916)
- **实务教训**（本研究归纳） (P000914, P000916)：诉前调解的收尾有且只有一个正确顺序——**先确认、后撤诉**：司法确认裁定书到手、协议获得强制执行力之后，再撤诉结案；先撤诉的，协议退回第三十一条的合同效力，对方违约时只能依第三十二条重新起诉，谈判成果裸奔；撤诉还有一个隐性代价——诉讼时效与保全措施随撤诉回落，重新起诉时一切从零，时间与费用的双输。

3. **确权与履行判例**：调解书即解封280万元冻结款、35天恢复流动性（判例一）；实体调解部分不许撤诉、未入调解的3360000元违约金请求可撤（判例二）；阶段性结算单两单冻结12702400元＋附条件放弃2487638.4元（判例六）；竣工盖章不封顶质量扣款——验收合格与责任免除的界限（判例四）；退场协议确权＋班组收据7500元抵扣＋2倍利率违约金核算＋关联公司代付不改变付款主体（判例五）。

6. **复合调解操作体系**：技术-法律（加方案）多轮定位＋谈判五步法（拆解冻结、双链核验、三层模型、技术会商、可执行协议）＋协议七大合规条款——把裁判预期变成谈判区间、把调解成果变成执行文书；四条战线十六判例构成定价与条款的判例锚（框架为本研究设计，各要件有法定与判例锚源） (P000913, P000914)。
