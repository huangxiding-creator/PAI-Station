工程款保护的最后一道法定防线是优先受偿权——它排在银行抵押权之前，却常常死于程序细节。实务四大痛点构成本章四节：**主体资格**——转包、挂靠下的实际施工人能不能直接主张？（实证样本186件中超八成被驳）**期限起算**——18个月除斥期间从哪天起算？竣工日？应付款日？最后一期？（第一节、第二节）；**范围与顺位**——优先权保什么、不保什么？停窝工损失、利息、违约金为何被剔除？与消费者购房人、银行抵押权怎么排序？（第二节）；**失权防范**——银行逼签的《放弃优先受偿权承诺书》有效吗？放弃之后还有救吗？（第四节）。利息与垫资的起算规则作为工程款保护的延伸单列第三节。方法论主线一句话：**优先受偿权是"有主体的权利、有期限的权利、有边界的权利"**——主体错、期限过、范围溢，任何一项都足以让法定优先权归零（本句为本研究导读性判断）。

读者可带着四个场景进入本章（本段为本研究使用指引）：转包链条下的实际施工人想去优先受偿，法院八成会怎么说（第一节）；工程款拖了两年，优先权还有没有救——从哪天起算（第一节、第二节）；胜诉确权了，工程却被别的债权人先行查封拍卖（第一节执行衔接）；银行放贷前递来一纸《放弃承诺书》，签还是不签（第四节）。四个场景，四节作答。

## 第一节 优先受偿权的行使主体与期限规则

### 1.1 主体资格：从承包人到实际施工人的实证图景

建设工程价款优先受偿权系法律直接赋予特定承包人的法定权利——对其权利性质，学界与实务有法定抵押权说与法定优先权说之辩（司法观点文集对两说均有梳理，实务界主流见解倾向于按法定权利对待），但无论定性为何，其"法定优先于抵押权与普通债权"的效力无人争议 (P000816, P000851)。2002年《最高人民法院关于建设工程价款优先受偿权问题的批复》（已失效）确立了三项基础规则：承包人的优先受偿权优先于抵押权和其他债权，但对已经交付全部或大部购房款的消费者不具有优先性；优先受偿的工程款范围仅包括工作人员报酬、材料款等实际支出费用，不包括因发包人违约造成的损失；行使期限自竣工之日或约定竣工之日起算 (P000851)。主体与范围的骨架，在批复时代已经立起。

**勘察设计人与装饰装修人**：民法典关于建设工程合同的定义涵盖勘察、设计、施工（资料库转引），但通说认为优先权保障的是物化于工程实体的投入，单纯勘察设计不属保护主体；装饰装修工程的承包人若其施工物化于不动产并提升价值，则属主体范围（通行裁判立场，本研究概述归纳）。

**实际施工人的实证图景**（转引实证研究论文） (P000851)：2004年解释提出实际施工人概念但未明其优先权；早期江苏、河北、浙江、广东、安徽等地方高院意见曾在一定条件下允许实际施工人主张；2011年《全国民事审判工作会议纪要》第29条明确对无效施工合同中实际施工人主张优先受偿权的不予支持。实证样本给出了精确刻度：**样本一**（起诉欠款并一并主张优先权，186例）：被驳回151例、获支持仅35例，**占比不足20%**——驳回理由集中于主体不适格、欠付金额未确定、工程属公益性不宜折价拍卖；**样本二**（债权已由生效裁判或调解书固定后提起优先受偿权确认之诉，26例）：支持18例、驳回8例，驳回理由多为超出法定除斥期间或债权不属于物化工程价款。两组数据合并的启示：直接主张是窄门，先固定债权再确权是宽门——样本一里"欠付金额未确定"这一驳回理由，在样本二中已被生效裁判预先解决（本研究归纳） (P000851)。样本一的驳回理由谱系本身即一张体检表：主体不适格（转包挂靠无直接合同）、金额未确定（未结算或结算未生效）、客体不宜执行（公益性工程）——起诉前逐项自查，胜算立现（本研究归纳）。

**代位权路径**（实证论文的结论性主张） (P000851)：无效施工合同的承包人不应享有优先受偿权，但有效合同中的总承包人、转包人或出借资质人怠于行使优先受偿权时，应当允许实际施工人以代位权诉讼方式主张。2026年《建工解释二》第七条将该路径制度化——借用资质、接受转包或违法分包的单位或个人可代位主张工程价款优先受偿权（资料库转引）；该条与第19条（债权受让人行使优先权的合理对价审查）共同回应了两大长期争议 (P000830)。专业解读并从法定担保与身份依附双重属性论证了"为何只有实际施工人可代位、普通债权人不可"的体系逻辑 (P000830)。

### 1.2 判例一至四：主体资格的四个样本

**判例一：挂靠人物化投入获早期支持**——（2015）齐民一终字第179号，黑龙江省齐齐哈尔市中级人民法院（齐齐哈尔奇兴房地产开发有限公司与王庆伏） (P000851)：王庆伏、施泽龙以挂靠形式订立建设工程分包合同、系案涉工程的实际施工人；王庆伏在实际施工中支付了大量材料款与人工费，该部分资金已物化并转化为建设工程实体价值；因发包人奇兴公司欠付工程款，王庆伏起诉请求支付工程款并对案涉工程拍卖、折价价款优先受偿。法院认为其对工程支付的材料款、人工费已实际物化进入工程、转化为工程实体价款，为保护实际投入资金与劳动的施工主体权益、符合当时批复的立法精神——判决支持其优先受偿请求。教训（本研究归纳） (P000851)：本案系早期侧重物化权益保护的裁量样本——法院的论证核心是"资金已物化转化为工程实体价值"，这与优先权制度的立法目的同频；但2011年纪要之后、解释二明确主体限定以来，同样的物化主张已难获直诉支持。实际施工人的现行路径选择即由此展开：优先代位权诉讼（总包怠于行权时），或如判例三以事实施工关系补正主体资格——物化仍是权利的实体基础，程序之门却要换钥匙开。

**判例二：违法分包人主体不适格被驳**——（2017）川08民终1210号，四川省苍溪县人民法院（四川永同岩土工程有限公司与四川水电建设工程（集团）有限责任公司、苍溪县江河水电开发有限公司） (P000851)：永同公司作为分包人与承包人四川水电公司签订分包合同、承包苍溪江河水电公司开发的水电站岩土工程；分包合同因违法分包被认定无效，永同公司施工完毕且工程合格后起诉请求确认对分包工程的优先受偿权。法院认为：优先受偿权是以合法有效施工合同为基础设立的法定权利，无效分包合同的实际施工人不具备法律意义上的主体资格——驳回其优先受偿权请求。教训（本研究归纳） (P000851)：分包合规审查必须前置——合同无效不止引发折价补偿的计价问题，还直接斩断优先受偿权：违法分包的实际施工人在质量合格后可主张折价补偿款，但对该折价补偿款主张优先受偿将被驳回——同为"要钱"，一个有优先保障、一个排队当普通债权人，差别只在合同的合规性。造价与法务人员的分包准入清单（资质、招标程序、转包禁止）由此多了一层优先权的分量。

**判例三：事实施工关系确权成功**——（2019）鄂08民终72号，湖北省荆门市中级人民法院（黄显林与湖北荆门团结科技产业园投资管理有限公司） (P000851)：黄显林作为挂靠施工人借用资质承揽工程；但履约过程中，其直接与发包人团结公司签署多份补充协议、工程联系单并直接办理工程结算，团结公司亦直接向黄显林支付工程进度款。二审法院认定：黄显林虽名义上系挂靠施工，但双方在实际履约中直接进行工程变更、结算与款项支付，已建立事实上的建设工程施工合同关系——黄显林实为与发包人直接订立并履行合同的承包人，符合司法解释的主体规定，确认其享有优先受偿权。教训（本研究归纳） (P000851)：挂靠人破身份之锁的钥匙是**履约证据链**——发包人直接下指令、直接结算、直接付款的书面痕迹；判例一与判例三构成对照组：同是挂靠，一个靠物化说理（早期获支持）、一个靠事实施工关系立证（现行获支持）——实体逻辑未变，证明的技术路线已从"我投入了什么"转向"我们之间发生了什么"。留存补充协议、联系单、结算单、付款凭证四类直接交互文件，就是挂靠人给自己的优先权投保。

**判例四：零星无效工程按楼栋确权**——（2017）赣0802民初1153号，江西省吉安市吉州区人民法院（黄称瑞与邓火琴、赣州华隆房地产） (P000809)：邓火琴挂靠华隆公司开发湖滨华府小区，将零星工程肢解发包给不具备资质的黄称瑞施工；工程项目为凸窗护栏、阳台护栏、楼梯扶手、楼宇对讲门、卷帘门、围墙护栏、入户防盗门、小区大门（工程预算价480000元、包工包料）；黄称瑞完成了各楼栋护栏、扶手及楼宇对讲门、车库卷帘门、小区大门的安装；2017年2月10日双方结算确认工程款566778元，约定以房抵款未实际履行；黄称瑞与胡贞生等八名施工人员共同向华隆公司送达通知函主张权利后诉至法院。法院认定：肢解发包合同虽无效，但工程已完工验收合格，合同无效不影响实际施工人主张优先权——判令邓火琴偿付工程款566778元（判决生效后七日内付清）、华隆公司承担连带清偿责任；黄称瑞在566778元范围内对其施工的湖滨华府各栋楼折价或拍卖价款优先受偿。教训：零星工程施工人的确权要点是**精准锁定楼栋物理范围**——"六栋楼"写进判决主文，执行才有靶心（本研究归纳） (P000809)。

### 1.3 期限规则：从6个月竣工日到18个月应付款日

除斥期间两阶段演进（转引资料库实证） (P000830, P000803)：2002年批复定为6个月、自竣工之日或约定竣工之日起算——工程款尚未结算、债权未届清偿期，权利"未成熟即消灭"，招致剧烈批评 (P000802)；2018年解释二第22条修正为"自发包人应当给付建设工程价款之日"起算，2020年解释一第41条统括、期限最长18个月 (P000830)；2026年解释二第21条延续18个月并细化起算时点 (P000803)。除斥期间不适用诉讼时效中止、中断与延长——届满即彻底消灭（通则，资料库转引）。

18个月起算点的类型化规则（转引漫谈系列归纳） (P000803, P000804, P000805)：

| 场景 | 起算基准 |
| :--- | :--- |
| 合同约定分期付款 | 最后一期工程款应付之日（分期系同一债务的分期履行） |
| 质量保证金 | **不得**以质保金返还时间起算；除质保金外最后一期结算款应付日起算 |
| 工期顺延等客观原因书面变更付款日 | 变更后的应付款之日（须有客观顺延事实，虚构协议延后将涉恶意串通审查） |
| 未约定付款期、后签结算协议 | 结算协议约定的付款日或分期最后一期到期日 |
| 未竣工中途解除 | 合同解除之日或核定的已完工程款应付之日 |
| 多单体整体付款 | 整体认定起算时间，不按单体拆分 |

类型化表的攻防读法（本研究归纳）：对承包人，第五行是护身符——只要付款未分单体，先行竣工的单体就不启动各自的18个月倒计时（判例五的实证）；对发包人，第一、四行是攻击面——"最后一期"与"结算协议付款日"都是可以协商延后的节点，但判例五同时警示：无客观顺延事实而虚构协议延后的，涉恶意串通审查、变更不生对抗效力。期限规则不是中立的日历，而是双方都能动的棋盘 (P000803)。

### 1.4 判例五至六：起算点的最高法样本

**判例五：和解协议重置起算＋整体不拆分**——（2019）最高法民再105号（某建工公司与某地产公司，转引漫谈文章） (P000803, P000804, P000805)：2010年9月乙公司承建宾馆及住宅小区三期工程，约定竣工验收合格付至85%、备案后付至92%、决算审核后留3%质保金付清；2014年6月首次起诉后双方7月14日达成《和解协议》重新约定付款期限，甲公司再违约后乙公司2015年4月重新起诉主张优先受偿权。最高法院再审认定：工程价款未确定或未届清偿期时行权前提尚不成立，《和解协议》变更了付款期限，起算点自变更后的应付款之日起算；工程虽分期验收，但付款从未区分单体且《和解协议》系整体结算——优先权作为**一个整体**认定起算点，驳回拆分抗辩。教训：多单体项目争取整体付款约定；拖欠后以补充协议/和解协议重锁付款期，可依法重置18个月起算（本研究归纳） (P000803)。

**判例六：结算协议分期付的末日线**——（2021）最高法民申5725号（某装饰公司与某汽车科技公司，转引漫谈文章） (P000803, P000804, P000805)：2014年12月5日双方签署对账清单确认欠款2290万元、载明"完工后付清"；其后乙公司又进行了零星施工；2016年3月17日双方签署《工程结算协议》，约定分四期支付余款、最后一期为2019年1月1日前支付790万元，同时约定逾期付款违约金自2014年12月5日起算；发包人未付款，乙公司起诉主张优先受偿权——发包人主张应以对账日为起算点、优先权已超期。最高法院裁定：2016年结算协议才最终完成债权债务结算，分期付款系同一债务的分期履行，最后一期应付之日（2019年1月1日）为整体到期日——起算自最后一期，未超期。教训：结算协议分期条款中**最后一期的具体日期就是安全起算线**——写清日期，就是给自己的优先权续命（本研究归纳） (P000803)。

### 1.5 行使方式与执行衔接

民法典第807条规定催告、协议折价与申请拍卖三种实现方式 (P000830)。实务演化要点（归纳自实证与漫谈）：

- **催告的定位**：催告系给发包人设定期限的预警程序；司法解释二征求意见稿曾以三个条文设置催告义务并区别催告与否的保护期限——专业文章质疑其立法性解释嫌疑并检视条款前后矛盾 (P000829)；现行体系下催告非严格前置程序，但书面催告留痕是行权准备的一环（本研究归纳）。
- **行权方式的稳妥级差**：单方发函缺乏公示性、易生倒签争议——优先权涉及对抗抵押权与其他债权人的物权效力，发承包双方倒签日期恶意串通的风险使单方函件的证明力日益从严；**最稳妥的方式是提起诉讼、申请仲裁，或在发包人为被执行人的执行程序中直接向执行法院主张优先受偿**（裁判立场归纳）。三种方式的共同点是进入司法程序——由第三方固化行权时点，倒签即无处遁形（本研究归纳）。
- **协议折价的两条边界**：不得损害第三人（已设抵押的工程折价明显低估的，抵押权人可行使撤销权）；排除不宜折价拍卖的工程（违法建筑、公益性设施等）。
- **物上代位**：2026年解释二第20条确立优先权及于保险金、赔偿金、补偿金 (P000822, P000823, P000824)——工程毁损、灭失或被征收后，承包人就该工程的保险金、赔偿金、补偿金优先受偿；基于代位性，优先权不因标的物物理灭失而落空，而是转移到金钱代位物之上（规则转引）。物上代位与判例七的追及力构成权利的"两翼"：追及力对付资产转移（物还是物），代位对付标的灭失（物变成钱）——发包人无论把工程变成重组资产还是保险赔款，都在优先权的射程之内（本研究归纳） (P000816, P000822)。
- **债权受让**：第19条为受让人主张优先权设置条件——工程是否竣工验收合格、是否结算、转让合同是否有效、**是否支付合理转让款**等因素个案衡量 (P000825, P000826, P000827, P000828)；专业文章从债权本体移转与行使资格两套评价体系论证该审查的体系正当性 (P000830)。

**判例七：追及力击穿债务重组**——最高人民法院（2011）执监字第15号驳回申诉通知书（吉林中城建中大房地产开发有限公司与东奥公司，转引司法观点文集） (P000816)：东奥公司对中大公司开发的B区工程享有法定工程价款优先受偿权；在东奥公司未放弃优先权的情况下，中大公司与中控公司签署《债务重组协议》将B区土地及地上物处置给中控公司，中控公司又将该资产对外处置；东奥公司提起诉讼主张追及B区资产优先受偿——最高法院审委会讨论认定优先权系法定权利、效力优先于一般债权及意定物权，债务重组处置损害法定优先权——东奥公司有权追及B区资产主张优先受偿，财产已处置的有权直接向中控公司追偿变价款。教训：发包人借债务重组、以物抵债转移资产，斩不断法定优先权（本研究归纳） (P000816)。

**判例八：顺位优先≠排除执行**——（2015）松民二初字第106号确权案延伸的案外人执行异议之诉（华宇广泰建工集团松原建策有限公司与东北农业生产资料有限公司、松原市博翔房地产开发有限公司，转引文集） (P000816)：华宇广泰公司经法院生效判决确认对博翔大酒店工程价款享有优先受偿权；后东北农业公司因与博翔公司的借款纠纷申请法院强制执行博翔大酒店；华宇广泰公司提起案外人执行异议之诉请求停止执行——一、二审均不支持，公司申请再审。最高法院认定：优先受偿权系对工程变价款**清偿顺位的优先**，属价值担保而非排他占有，不属于"足以排除强制执行"的民事权益——无权要求停止拍卖变卖，应在价款分配环节主张优先受偿。教训：异议之诉是错路，参与分配是正路——持确权文书向执行法院申报优先债权、锁定第一顺位（本研究归纳） (P000816)。

### 1.6 行权六步法（本研究设计）

1. **主体审查**：核查合同主体链；转包分包项目立即核查总包对发包人的优先权状态并评估代位诉讼可行性；EPC项目先做设备费剥离（见第二节）；
2. **价款核算**：编制优先受偿专项清单——剔除违约金、利息、停窝工损失与设备费（第二节规则）；
3. **边界锁定**：整理图纸、竣工验收单、界面划分协议，明确对应楼号标段——判例四的楼栋清单即范本，本节六步法即作业程序；
4. **起算推算**：建18个月倒计时台账，以最后付款日为基准倒排预警线；顺延或重新协议的，书面锁定新日期；
5. **留痕催告**：到期前书面催告并留送达凭证——催告未必是前置程序，但函件是行权准备的证据；
6. **司法确权**：18个月内起诉或仲裁，诉请主文写明"对某工程折价拍卖价款在某金额内优先受偿"；标的已被查封的，立即向执行法院提交参与分配声明（本研究设计，锚源散见本节）。

## 第二节 优先受偿权的范围与清偿顺位

### 2.1 范围：物化投入的精确边界

优先受偿权的保护范围，2020年解释一第40条第1款规定"依照国务院有关行政主管部门关于建设工程价款范围的规定确定"——授权行政部门规则划界的立法技术 (P000811)；住建部与财政部2013年《建筑安装工程费用项目组成》界定的建安费用要素为：**人工费**（直接从事建筑安装工程施工的生产工人开支）、**材料费**（构成工程实体的原材料、辅助材料、构配件、零件、半成品）、**施工机具使用费**（机械使用费与仪器仪表使用费）、**企业管理费**（组织施工生产与经营管理费用）、**利润**与**税金**（应计入造价的增值税等） (P000811)。六要素清单即优先权基数的正面清单——清单内入保、清单外出局，与批复"实际支出费用"的口径一脉相承 (P000851)。2002年批复同旨：仅含工作人员报酬、材料款等实际支出费用，不含违约损失 (P000851)。

**法定剔除项**（2026年解释二第17条第2款为现行终局规则） (P000806, P000819)：

> "承包人就发包人原因造成的停工、窝工等损失主张享有建设工程价款优先受偿权的，人民法院不予支持。"

剔除的法理（归纳） (P000806, P000811)：其一，**债权属性错位**——停窝工损失与材料价差系发包人过错引发的违约损害赔偿债权，非工程建造本身的物理对价；其二，**物化缺失**——停窝工期间的机械停滞费与人员窝工费未真正物化为建筑物物理结构、未增加不动产价值（机器停转、人员停工，投入的是时间而非工程）；其三，**职权审查**——人民法院在确权案件中**依职权主动审查**，无论发包人是否抗辩，均须将结算文件中的停窝工索赔款、价差索赔款从优先总额中核减，并在判决主文中直接列明精确的可优先金额 (P000806)。

**EPC项目的设备费剔除**（行业专业文章的限缩论证） (P000811)：工程总承包有DB与EPC两种基本模式（中价协《建设项目工程总承包计价规范》第3.1.1条）——DB模式下总承包范围为设计与施工、不含设备采购，多用于房屋建筑与市政项目；真正EPC（广泛适用于发电厂特别是光伏风电、化工厂、冶金厂）总承包范围含设计、采购、施工，承包人需向发包人提供大型装置与设备。设备采购（P）的法律定性：本质属买卖合同关系，开具13%增值税设备发票而非建筑安装工程服务发票；依《建筑安装工程费用项目组成》，设备费不参与企业管理费、利润与规费的取费计算；民法典第791条未将设备采购纳入工程总承包规制（系DB模式语境），而建筑法第24条第2款与《建设工程质量管理条例》明确规制设备采购——立法分野正是边界划分的依据。设备本体不构成建设工程实体——**工程设备费必须从优先受偿范围剔除**，总承包人仅能就设计、施工安装及设备安装工程费用主张 (P000811)。对设计费能否纳入，该文章亦作为问题提出（工程总承包语境下设计费与设备费的入范判断仍是开放争点） (P000811)。民法典第791条未将设备采购纳入规制（系DB模式语境），而建筑法与质量管理条例明确规制设备采购——立法的分野正是优先权边界划分的依据 (P000811)。对房屋建筑与市政项目中设备费已深度物化于建安实体的，应结合造价构成另行甄别（边界声明）。

### 2.2 判例九至十：范围与客体的最高法样本

**判例九：停窝工损失剔除的公报样本**——（2014）民一终字第56号（《最高人民法院公报》2016年第4期刊载，转引漫谈文章） (P000806, P000819)：甲工程公司承建乙交通公司开发的高速公路工程；施工过程中因乙公司资金不到位、土地征拆滞后等原因，工程多次大面积停工；停工期间甲公司产生巨额的人员停窝工工资、施工机械停滞租赁费、材料仓储维护费以及因工期延误导致的材料价格上涨价差损失；竣工后双方对停窝工损失及价差剧烈争议，甲公司起诉请求支付拖欠工程款、停窝工损失赔偿及材料价差补偿，并主张就上述全部债权对高速公路工程优先受偿。最高法院支持其停窝工损失与价差的赔偿请求，但明确驳回将该部分纳入优先受偿范围的诉求——优先权保护的仅为实际投入形成工程物理价值的价款。教训：**双轨核算机制**——实体结算价款与违约索赔款在结算书与诉状中分列；索赔款混入优先基数的，法院依职权主动核减（第17条第2款的审查义务），承包人还多担按虚增标的计算的诉讼费；对发包方的对称提示：双轨核算同样是防守工具——对方打包主张的，质证时逐项请求剥离，剥离下来的每一项都从优先顺位降为普通债权 (P000806)（本研究归纳）。

**判例十：专项工程对应性**——（2021）最高法执复48号（人民法院入库案例2023-17-5-202-020，转引漫谈文章） (P000806, P000819)：甲建设公司承建某置业公司开发的大型商业地产项目中的中央空调专项安装工程；竣工结算后双方确认尚欠工程款29340082.14元，生效判决确认甲公司就该中央空调安装工程价款在欠付的29340082.14元范围内享有优先受偿权；发包人资金链断裂进入执行程序，执行法院对整个商业地产项目整体司法拍卖，将部分拍卖款直接分配给抵押权人乙投资公司——既未对甲公司中央空调工程对应价值作专项评估，亦未制作优先受偿分配方案；甲公司执行异议被驳后向最高人民法院申请执行复议。最高法院认定：优先权具有严格的**工程对应性**，范围限于承包人实际施工形成的具体工程及对应价款；执行法院未区分专项工程物理范围与价值直接分配系执行不当——撤销原裁定，责令查明对应价值依法优先清偿。教训：裁判主文与执行申请必须列明**专项施工的物理界面**（某楼栋空调系统、某标段机电），执行中主动申请对该专项工程在整体不动产中的价值贡献比进行司法评估，严防被整体不动产的银行抵押权侵蚀优先份额；本案的另一层警示面向执行法院——整体拍卖＋不区分专项价值的直接分配构成执行行为不当，承包人的复议与监督程序因此成为权利的最后一公里（本研究归纳） (P000806)。

### 2.3 清偿顺位图谱

```
┌─────────────────────────────────────────────────────────────┐
│ 建设工程变价款法定清偿顺位（归纳自批复规则与文集）           │
├─────────────────────────────────────────────────────────────┤
│ ① 消费者商品房买受人（交付全部或大部购房款者，批复规则）    │
│ ② 建设工程价款优先受偿权（仅物化本金＋垫资本金）           │
│ ③ 银行抵押权及其他不动产担保物权                           │
│ ④ 普通债权（工程款利息、垫资利息、停窝工损失、违约金）     │
│ ⑤ 发包人一般无担保信用债权                                 │
└─────────────────────────────────────────────────────────────┘
```

顺位的第一位是2002年批复明文：承包人优先权优于抵押权和其他债权，**但已交付全部或大部购房款的消费者除外** (P000851)——消费者购房人生存居住权的特别保护自此确立，并延续于后续规则体系（司法观点文集对此有专章梳理） (P000816)。顺位的实战含义（本研究归纳）：承包人在破产与执行分配中的对手不是普通债权人而是银行——优先权确认一日未完成，银行对变价款的分配就随时可能完成；第一节的"18个月内司法确权"与第二节的"参与分配"，本质上都是在与银行的分配赛跑。垫资的双轨处理（通则归纳，资料库转引）：**垫资本金**——承包人垫资购买材料、支付工资的款项已物化为工程实体，属工程价款组成部分、享有优先权、列第二顺位——"垫资"改变的只是资金来源，不改变款项的工程属性；**垫资利息**——资金融通的法定孳息与资金成本，不属物化实体造价，不享优先权、列普通债权。工程款利息同理：无论进度款逾期利息还是结算款逾期利息，绝对不享优先权，仅在优先权与抵押权清偿后作为普通债权按比例受偿（通则归纳） (P000806)。本金与利息的顺位剥离意味着（本研究归纳）：在破产与执行分配中，承包人的利息债权与其他普通债权人同池竞争——对利息的主张力度应据此校准，为利息打漫长诉讼的性价比常不如以利息让步换本金的优先确认。

### 2.4 折价协议：第18条的四个要件

2026年解释二第18条为协议折价主张优先权设置要件（漫谈系列解读） (P000821)：该条的立法旨趣在于给"以房抵款""以物抵债"式的自行清算开出合法通道，同时以要件审查防止折价沦为逃废债工具——依专业解读归纳为四要件核对：**质量合格**（折价协议主张优先权的前提）、**协议真实**（双方真实意思、无恶意串通）、**折价时点**（在行权期限内、程序合规）、**金额相当**（折价与市场估值相当，不损第三人） (P000821)。实务定位（本研究归纳）：折价协议是诉讼之外最快的行权方式——不用等排期开庭，协议签成即锁定受偿；但四要件中任何一项的瑕疵（尤其金额显著低估），都会把最快通道变成撤销权诉讼的标的。结合第一节折价边界（不损第三人、排除不宜折价工程），承包人以折价协议行权的合规清单为：工程合格证明＋协议双方真实＋价格参照市场估值＋物理范围明确（本研究归纳） (P000821)。

## 第三节 工程款利息与垫资利息的起算

### 3.1 利息起算的约定优先与三节点推定

约定优先：当事人对欠付工程款利息计付标准有约定的按约定处理（判例十二判决原文援引该口径并据当事人变更后的诉请按央行同期同类贷款利率计息） (P000810)；对付款时间有约定的，利息从约定付款日的次日起算（通则归纳）。无约定或约定不明时的三节点法定推定（裁判文书援引的司法解释规则，判例十二判决援引第十七、十八条） (P000810)：

```
┌─────────────────────────────────────────────────────────────┐
│ 工程款利息法定推定起算三节点（依次递进）                    │
│ ① 工程已实际交付 ─────────→ 交付之日起算（含发包人擅自使用）│
│ ② 未交付但已提交结算文件 ──→ 提交竣工结算文件之日起算       │
│ ③ 未交付且未结算 ──────────→ 起诉/申请仲裁之日起算          │
└─────────────────────────────────────────────────────────────┘
```

结算审定日与宽限期的衔接：委托审价并出具结算审核报告或签署结算协议、约定付款宽限期的，利息自宽限期届满之次日起算——判例十一即其样本 (P000807)。这条规则的机制（本研究归纳）：审价报告本身不产生付款义务的到期——它只是把"欠多少"固定下来；让钱"到期"的是合同里的宽限期条款——"结算完成后多少天内支付"把审定日转化为应付款日；两者相加才是利息的起跑线。中途停工项目尤其要核对合同是否保留此类条款：没有宽限期约定的，回退到三节点推定，起算日可能大幅后移（于发包人有利）或前移（于承包人有利），个案攻防的胜负手常在这一条。

### 3.2 判例十一至十四：起算与利率的四个样本

**判例十一：结算审定日＋宽限期**——（2017）渝民申2129号，重庆市高级人民法院（重庆半山一号房地产有限公司与望建（集团）有限公司） (P000807)：望建公司承建重庆曼哈顿城项目二期4、5标段花园洋房工程；因未办理施工许可证即开工遭行政处罚、发包资金不到位等多重原因，工程于2015年3月3日被迫停工，双方均同意解除合同并共同委托中介机构对已完工程结算审定；2015年9月25日结算审定：无争议部分41625890元，争议部分为74#-84#/16#/45#-46#楼桩基超深277032.98元与4、5标段围墙40446元（属合同外工程、按建设单位要求施工、应按审定金额支付）；合同约定"结算完成后21天内支付至结算造价的95%、留5%保修金"。重庆高院再审认定：最迟应于2015年10月16日前支付，逾期即违约，**自2015年10月17日起算欠款利息**；停工系双方原因（未批先建受行政处罚、发包人与第三方纠纷等），中止施工违约金请求不予支持；未竣工未验收且未协商解除的，以停工作为保修期起算"明显错误"——驳回再审。教训有三（本研究归纳） (P000807)：其一，中途停工项目速走共同委托审价锁定金额——无争议部分与争议部分在审定中分列（本案41625890元与两笔争议款），确权与执行都有精确靶心；其二，利息起算＝审定日＋约定宽限期，宽限期临界点按日核算——21天宽限期的届满次日就是起息日，差一天就是真金白银；其三，停工原因的归属同步决定违约金命运——双方原因停工（未批先建＋发包人纠纷）之下，发包人的中止施工违约金请求同样被驳，攻防双向适用。

**判例十二：欠条承诺付款日的次日**——（2009）甬慈民初字第2087号，浙江省慈溪市人民法院（陈飞与马孟君） (P000810)：二建公司承建宁波洪都花园工程后违规分包给无资质的马孟君；2006年5月10日，马孟君又与陈飞签订《花岗岩工程施工合同》，将B、C区花岗岩铺设工程非法转包给陈飞；陈飞施工完毕，工程于2006年11月竣工验收合格；2007年4月15日双方结算，马孟君出具欠条确认尚欠工程款138000元、承诺"于2008年4月15日前付清"。到期拒付后陈飞起诉，请求支付工程款138000元并自2008年4月16日起按央行同期同类贷款利率计付逾期利息至清偿日。法院认定：转包合同无效，但工程验收合格，欠条系双方对工程价款及付款时间的真实处分——自**2008年4月16日**（承诺付款日次日）起按央行同期同类贷款利率计付利息至清偿日，受理费3310元由被告负担。教训（本研究归纳） (P000810)：无效合同的结算欠条照样锁定利息起跑线——欠条中"某年某月某日前付清"的承诺就是利息条款：承诺日次日起算、按央行同期同类贷款利率计至清偿日；判决同时按司法解释第十七条处理利息标准、第十八条处理起算节点——无效合同之下的利息规则与有效合同同一框架，结算文件的日期条款是双方唯一需要认真写的条款。

**判例十三：高额垫资利息的争点样本**——（2010）东二法民二初字第399号，广东省东莞市第二人民法院（周锦标与东莞汇嘉置业有限公司、东莞市虎门镇金洲社区竹洲居民小组） (P000810)：周锦标2008年10月29日与汇嘉公司签订《工程承包合同》（约定施工工期与付款方式），因汇嘉公司资金周转困难，双方11月14日补签《补充协议》：汇嘉公司承诺2008年12月31日前再支付进度款200万元（11月30日前150万元、12月31日前50万元），由周锦标继续施工至主体封顶，并约定对垫资的300万元工程款自2008年12月1日起按月息2%计付垫资利息——汇嘉公司主张已付797.52077万元（工程款749万元、利息36万元、增加工程12.52077万元），周锦标未取得建筑施工资质。2008年10月29日签《工程承包合同》、11月14日《补充协议》约定周锦标垫资施工至主体封顶，汇嘉公司承诺2008年12月31日前再付进度款200万元（11月30日前150万、12月31日前50万），并约定对垫资的300万元工程款自2008年12月1日起按**月息2%**计付垫资利息；周锦标诉请工程款6735233.50元及按月息2%计的垫资利息82.0002万元；汇嘉公司抗辩合同无效（周无资质）且月息2%违反利率限制（源文语料至答辩段截断，判决主文未收录——本句为本研究证据边界声明）。争点价值：垫资利息的利率红线（不得高于同期同类贷款利率，超出部分无效）系司法解释通则，本案的月息2%约定正是红线审查的典型标的——高息条款在诉讼中面临强制裁减（通则转引＋本案争点归纳） (P000810)。本案的攻防结构还提示（本研究归纳）：垫资条款的争议从来不是单点——合同效力（资质）→付款承诺（两笔进度款）→垫资利息（月息2%）→已付金额（797.52077万元的三项构成）环环相扣，任何一环的举证缺口都会传导到全局；书面约定的清晰度，直接决定庭审的主动权归属。

**判例十四：日2000元违约金的欠条样本**——（2017）苏0312民初1702号，江苏省徐州市铜山区人民法院（刘竟争与张洁、刘磊、徐州市云天市政建设工程有限公司） (P000807)：云天公司承包粮库维修改造工程后转包，张洁（刘磊现场带班人员）与刘竟争签约、刘磊付定金10000元后刘竟争2014年5月底进场施工、7月初退出；2014年7月10日张洁出具欠条："欠刘竟争大彭镇粮管所粮仓修缮3号仓、7号仓夹心板工程款陆万元正（60000元），于8月15日前付清。备注：如不付清，愿每天赔偿刘竟争2000元违约金"——同日刘磊转账支付30000元；刘磊到庭认可与云天公司系挂靠关系。法院认定：欠条系施工后结算凭证（出具时间、工程范围、给付日期三重印证），张洁系职务行为、责任归刘磊；云天公司无论转包还是挂靠均担连带责任——判决刘磊给付60000元、云天公司连带清偿（判决主文两条；欠条中违约金条款的处理源文未载，本章不转述——本句为本研究证据边界声明）。教训：欠条的三要素（时间、范围、日期）就是其结算效力的证明结构；天价违约金条款与其依赖事后酌减，不如事前按法定口径约定（本研究归纳） (P000807)。

### 3.3 垫资的两条红线与调解四步法

垫资规则两红线（司法解释通则，资料库转引）：**明示约定原则**——对垫资利息没有约定的，承包人主张利息不予支持，无书面利率的垫资按无息处理（法律严禁将单纯"垫资条款"推定为有偿借贷）；**利率上限**——约定利率高于央行同期同类贷款利率（或LPR）的，超出部分无效、法院对超出部分不予支持。两红线的谈判含义（本研究归纳）：垫资条款的利率约定宁低勿空——写了超标利率的，法院只裁超出部分，本金照付、约定落空；干脆不写的，连利息都没有；恰好卡在红线上的约定，才是可全额兑现的约定。本金入优先权、利息入普通债权的顺位剥离已见第二节（通则归纳）。

**利息算定与顺位调解四步法**（本研究设计）：

1. **四分法拆解**：物化工程款本金＋垫资本金（优先权基数）｜垫资利息与工程款利息（普通债权）｜违约金与停窝工损失（普通债权）——四栏分列的债权结构表是谈判与诉讼共用的底账；
2. **起算对账**：按三节点与宽限期规则逐笔对账——交付凭证、结算送达凭证、起诉状日期三类证据对应三类起算；
3. **顺位方案**：诉讼火力集中于本金优先权确认；利息与损失作让步筹码——以减免利息换本金优先权的书面认可与快速支付（判例九的双轨核算为其裁判基础）；
4. **协议防线**：调解协议写入利息截止与重置条款（"本协议确认截至某日的本金及利息；逾期按原标准恢复计息"）与**优先权保留条款**（"在发包人全额付清本息前，承包人对案涉工程的优先受偿权不予消灭或放弃"）——严禁出现"放弃一切优先受偿权"字样：第四节将说明，概括弃权条款纵使被认定有效，也让承包人在银行与普通债权人面前门户洞开（本研究设计）。

## 第四节 预先放弃优先受偿权承诺的效力

### 4.1 商业背景与四学说

发包人以在建工程或土地使用权抵押向银行等金融机构融资时，金融机构为保障自身抵押权的第一顺位，通常要求承包人签署《放弃建设工程价款优先受偿权承诺书》，或要求施工合同直接写入预先放弃条款 (P000852)。放弃行为的形态（论文的类型化梳理）：以成立时点分产生前的预先放弃与产生后的事后放弃，实践以预先放弃为主；以意思表示形式分单方允诺（承诺书）与双方协议，实践以单方允诺为主；以相对人分对发包人的放弃与对抵押权人（特别是贷款银行）的放弃，实践以对抵押权人为主——极少对无抵押权的普通债权人放弃 (P000852)。关于预先放弃的效力，学位论文对检索案例与文献的归纳形成四学说 (P000852, P000853)：

```
┌─────────────────────────────────────────────────────────────┐
│ 预先放弃优先受偿权承诺效力的四学说（论文归纳）              │
├─────────────────────────────────────────────────────────────┤
│ ① 有效说（裁判多数）——财产性权利可自由处分、意思自治、     │
│    事后主张无效违背诚信、无禁止性规定                       │
│ ② 无效说（少数）——法定物权不得预先排除、架空立法目的、    │
│    霸王条款（含最高法民一庭仲伟珩法官助理观点）             │
│ ③ 部分有效说——人工工资部分无效（涉农民工基本人权）、      │
│    纯财产性权益部分有效                                     │
│ ④ 区别效力说——损害特定法益且无担保则无效；有担保措施      │
│    确保工程款实现则有效                                     │
└─────────────────────────────────────────────────────────────┘
```

实证底数（转引论文）：以优先受偿权为关键词检索裁判文书网可得案件3500余件（民事1700余件），以能否放弃为争议焦点的30余件——**绝大多数法院认定有效** (P000853)；个别案例认定无效但缺少说理 (P000852)。

### 4.2 论文引述判例群：四学说的裁判注脚

**常山案（有效说代表）**——浙江衢州中院（常山县住宅建筑有限公司与浙江泰源铜业有限公司、第三人工商银行常山支行，论文引述） (P000852)：法院认为：建设工程价款优先受偿权系财产性权利，住宅建公司在出具给工行常山支行的承诺书中表示放弃该项权利，其行为并不违反法律强制性规定——住宅建公司理应受该承诺约束，在其承诺放弃优先受偿权的贷款范围内，工程款债权不得优先于工行常山支行的抵押权。同院王勇法官的解读：优先受偿权属私权、当事人可自由处分 (P000852)。同案不同判的注脚：**浙江常山法院**在另案（常山县住宅建筑与常山县日成铜业、工行常山支行）中认定放弃行为应属无效——但判决书未说明理由 (P000852)；最高法民一庭法官助理仲伟珩亦持不能以事先放弃限制法定物权效力的立场 (P000852)。

**太戈案（部分有效说代表）**——浙江嵊州法院（嵊州市房屋建筑工程有限公司与嵊州太戈服饰有限公司、钱南华、浙江风之美电器有限公司、浙江嵊州豪顺丝织制衣有限公司及第三人嵊州市经济开发区投资有限公司，论文引述） (P000852)：法院认为人工工资关系农民工基本人权，原告又无其他偿付能力，放弃农民工工资部分的优先权已损害生存利益——**该部分放弃无效**；对纯财产性权益的放弃属自行处分民事权益——**该部分有效**；判决：被告支付原告工程款（数额略——源文金额字符缺损，本章不转录具体数额，此为本章证据边界声明），原告对其中**含人工工资部分和未放弃优先受偿权部分**的工程款，就其施工的工程经折价、拍卖所得价款享有优先受偿权——无效的部分与有效的部分在同一份判决里精确切割 (P000852)。

**南通四建案（区别效力说代表）**——江苏南通中院（南通四建集团有限公司与南通润通置业有限公司、第三人江苏南通农村商业银行股份有限公司，论文引述） (P000852)：法院认为：由于建设工程价款往往涉及材料款和农民工工资——材料款债权在一定程度上具有所有权取回权的性质，农民工工资债权则具有基本生存保障的性质——法律创设优先受偿权即为保护这些特定法益；承包人放弃优先受偿权将损害这些特定法益的，放弃行为应属无效；但如果放弃的同时已有一定担保措施确保工程款有效实现，则放弃可以认定有效。就本案：**四建公司承诺放弃优先受偿权的条件——润通公司向农商行贷款用于支付其工程款——已于承诺函出具次日成就**，故放弃行为应为有效；否则其在农商行抵押权之前实现工程款权利，事实上属于对同一法益的重复保护，会导致四建与农商行之间权利义务明显失衡，有违公平原则与诚实信用原则。判决并强调：四建公司并非绝对放弃优先受偿权，其承诺函**具有相对性、有特定的对象与特定前提** (P000852)。

**东方建设案（相对性样本）**——浙江衢州中院（东方建设集团有限公司与浙江华叶铜业有限公司、第三人工商银行常山支行，论文引述） (P000852)：法院明确指出：法院明确指出东方建公司**仅针对工行常山支行**放弃优先受偿权，并未对华叶公司及其他债权人放弃——优先受偿权依然存在；工行实现抵押权后，东方建公司对剩余变价款仍优先于其他普通债权人受偿 (P000852)。

**嘉兴天顺案（诚信原则样本）**——浙江嘉兴南湖区法院（嘉兴市天顺建设有限公司与嘉兴市南湖区宝玛日用品有限公司、第三人上海浦东发展银行股份有限公司嘉兴分行，论文引述） (P000852)：天顺公司主张出具承诺书时受发包人胁迫且违反优先权法定原则，请求确认承诺书无效；法院认为：原告并未提供证据切实证明在出具承诺的过程中受到欺诈、胁迫的情形，其主张承诺无效的意见有违诚实信用原则与"禁反言"原则——在浦发银行抵押债权范围内不得主张优先受偿 (P000852)。与天顺案同旨的还有浙江嘉兴中院蔡广明诉森大木业、嘉兴银行海宁支行执行分配方案异议之诉案——"并没有法律、法规或司法解释规定不可以放弃该项权利"（论文引述） (P000852)。

**海泰案（意思自治样本）**——浙江海宁法院（海泰建设有限公司诉浙江威仕达光电材料有限公司普通破产债权确认纠纷案，论文引述） (P000852)：法院认为建设工程款的优先受偿权是一项民事权利，民事权利的行使由权利人的意思决定——有效说在破产程序中的地方表达 (P000852)。

**无效说的注脚**：与常山案的"有效"形成同院对照的，是浙江常山法院在另案（常山县住宅建筑有限公司与常山县日成铜业有限公司、第三人工商银行常山支行）中认定放弃行为应属无效——但判决书并未说明无效之理由 (P000852)；持无效立场的还有最高法民一庭法官助理仲伟珩"不能采取事先放弃的形式限制建设工程价款优先受偿权的法定物权效力，承包人或者劳动者同意放弃的意思表示均应认定无效"的观点 (P000852)。有效说占多数但"易于证成"、无效说居少数且"缺少说理"——论文对两说的这一观察本身即实务的警示：无效主张缺乏说理支撑，承包人不能把翻案的希望寄托在无效说上（本研究归纳） (P000852)。

### 4.3 放弃效力的限制与救济

**实体限制**（转引放弃效力论文） (P000853)：放弃承诺应当有**具体指向和限制**、不能无限延伸扩大——衢开民初字第874号判决要旨（论文引述）：放弃的具体指向涵盖面积、数额、组成、对象等具体条件，约定范围内的放弃视为有效放弃；范围标准的实证样本：嘉海行初字第1号判决认可承诺书载明"多晶炉车间，建设规模59967.49平方米"范围内的放弃效力——超出该车间范围的部分不在放弃之列，弃权的边界由承诺书的文字划定 (P000853)。对承包人的操作含义（本研究归纳）：承诺书里的每一个限定词（哪个车间、多少面积、哪笔贷款）都是给自己保留的领地——写得越具体，弃权失去的就越少。**附条件放弃**的生效审查：沪高民一(民)再终字第2号案中，承包商承诺"确认外墙门窗、电梯安装工程款并收到100万元监管资金后放弃该部分优先权"——因监管款未付且担保方未签字追认，所附条件未成就，放弃未生效、优先权仍存 (P000853)。

**效力相对性的三重边界**（归纳自论文引述判例） (P000852, P000853)：

1. **对发包人：债权对抗而非债务豁免**。施工合同中的放弃条款在发承包之间产生约束——发包人有权以已承诺放弃为由抗辩承包人折价或拍卖；但放弃优先权绝不等于放弃工程款债权：优先权只是顺位保障手段，发包人清偿全部工程款的义务分文未减，承包人仍可作为普通债权人起诉付款并申请执行发包人其他财产。
2. **对特定银行：顺位让渡而非全盘消灭**。对象相对性——弃权仅对明确承诺的特定银行生效，不及于其他普通债权人，也不及于未获承诺的后位抵押权人（东方建设案）；金额相对性——仅在该笔贷款本息限额内让渡，银行抵押债权清偿后，剩余变价款承包人仍优先于其他债权人受偿。两重相对性共同确保：承包人让渡的是"这一家银行这一笔钱的顺位"，而不是自己的整个优先权 (P000852)。
3. **对实际施工人与农民工：不得越权处分他人法益**。总承包人单方弃权属自身处分行为——未经实际施工人书面授权，放弃行为对实际施工人不产生直接处分效力；总包无偿放弃优先权（放弃法定物权担保）致责任财产减少、无力清偿下游工程款与劳动报酬的，实际施工人或农民工可依债权人撤销权规则（债务人无偿处分财产权益损害债权人的，债权人可请求撤销——资料库概述）提起撤销权诉讼，将总包列为被告、发包人与贷款银行为第三人 (P000852, P000853)。

### 4.4 应对四步法（本研究设计）

1. **拒签概括弃权**：坚决剔除"无条件放弃全部优先权"字样——概括条款无具体指向，面临限缩与无效风险（论文四标准之范围标准） (P000853)；
2. **双重限缩**：必须出具文件的，嵌入"特定对象＋额度上限"——标准化表述："承包人仅针对某银行某支行某笔借款合同项下的人民币若干万元贷款本息范围内，同意在受偿顺位上让渡于该笔贷款设立的抵押权；本承诺不对发包人的其他任何债权人或后续抵押权人生效"（东方建设案的相对性判决、南通四建案的对象特定前提认定为其裁判基础） (P000852)；
3. **支付联动先决条件**："本承诺为附条件生效文件；生效前提是贷款资金直接划入发承包双方共管专户、发包人按期将该笔贷款的一定比例用于支付已完工程进度款；银行未放款或发包人未按期支付的，本承诺自始不发生效力"（沪高民一(民)再终字第2号的条件未成就审查为其裁判基础——该案中监管款未付、担保方未签字，弃权即未生效） (P000853)；
4. **人工费专户隔离**：单独编制人工费预算、专户直拨——阻断"工资部分弃权损害生存利益"的撤销风险（太戈案的部分无效判决为其裁判基础） (P000852)。

## 本章小结要点

1. **主体资格与代位路径**：优先权原则上归与发包人直接立约的承包人；勘察设计人一般不属主体、装饰装修人物化者属之；实际施工人直诉支持率不足两成（186例中151例被驳，驳回理由谱系：主体不适格/金额未确定/公益工程），可行路径四条——事实施工关系立证（判例三：发包人直接指令结算付款的书证链）、债权固定后确权（样本二26例中18例支持）、按楼栋精准确权（判例四：判决主文写明六栋楼）、代位权诉讼（解释二第7条制度化，法定担保与身份依附双重属性的体系论证） (P000809, P000830, P000851)。
2. **18个月起算类型化**：自应付款日起算（2018年修正、2020年第41条、2026年第21条延续）；分期付款看最后一期、质保金剔除、客观顺延书面变更可重置、结算协议重锁、解除看解除日、整体付款不拆分（判例五、六） (P000803, P000830)。
3. **范围与顺位**：物化本金（人材机管理费利润税金＋垫资本金）入优先权；停窝工损失、价差、利息、违约金一律剔除（第17条第2款＋判例九）；EPC设备费剔除（13%发票＋不参与取费的双重判准）；顺位为消费者购房人＞优先权＞抵押权＞普通债权（批复规则＋文集） (P000806, P000811, P000851)。
4. **行权与执行**：诉讼/仲裁/执行程序中主张为稳妥方式（单方函件证明力从严）；催告前置性属征求意见稿讨论议题而非现行硬性规则；折价协议四要件（第18条）；物上代位及于保险金赔偿金补偿金（第20条，与追及力构成"物转资产/物变钱"的两翼）；债权受让须付合理对价（第19条四因素衡量）；追及力击穿债务重组（判例七），但顺位优先不能排除执行——案外人异议之诉必败、参与分配是正路（判例八） (P000816, P000821, P000822, P000825, P000829, P000830)。
5. **利息与垫资**：约定优先＋三节点推定（交付日/结算文件日/起诉日）；审定日＋宽限期届满次日（判例十一）；欠条承诺付款日次日（判例十二）；垫资无约定不计息、利率超同期贷款利率红线部分无效（判例十三争点）；结算欠条三要素印证效力（判例十四） (P000807, P000810)。
6. **放弃承诺**：有效说为裁判多数（3500余件检索），但四重边界——相对性（仅特定银行特定金额，东方建设案）、附条件（条件未成就则未生效，沪高案）、生存权益（工资部分无效，太戈案）、区别效力（担保到位则有效，南通四建案）；承包人应对按四步法：拒概括、限对象额度、设支付联动、建人工费专户 (P000852, P000853)。

使用本章的正确方式（本段为本研究使用指引）：签约时核主体链与设备费构成，EPC项目先做剥离预案；履约中建18个月倒计时台账，每笔付款节点入账，顺延与和解务必书面重锁；结算时按四分法拆债权——本金归优先、利息损失归普通，双轨列示；行权时选诉讼仲裁或执行分配，主文写明楼栋与金额；面对弃权要求，按四步法逐项设防。优先受偿权是法律给承包人的最后一件武器——但它只保护会用的承包人（本段为本研究使用指引）。
