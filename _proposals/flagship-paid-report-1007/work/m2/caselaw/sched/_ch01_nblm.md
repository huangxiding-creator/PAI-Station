# 《工程造价争议判例谱系与调解实务研究报告·2026》

## 第1章 导论：工程造价争议全景与谱系方法论

**【本章导读与解题说明】** 
本章旨在解决工程造价工程师、商务经理、工程法务与建工律师在应对建设工程造价纠纷时长期面临的四大核心痛点：**其一，“计价机理”与“法律规则”割裂**，导致造价人员不懂法律效力边界、法务人员不懂工程计价逻辑、管理层不懂两条规则如何衔接；**其二，司法裁判尺度不一与同案不同判现象存在**，造成商务谈判与诉讼风险预判失准；**其三，过度依赖造价司法鉴定**，导致诉讼周期拖延、鉴定意见被动接受或被法官直接否定；**其四，法律法规、司法解释、部门规章与人民法院案例库规则交织**，缺乏清晰的效力传导与裁判适用层级指南。通过引入**“判例谱系方法论”**，本章以司法统计数据与裁判文书为实证支撑，剖析 EPC 及 DBB 模式下的高发争点，对抗检验裁判稳定度与鉴定依赖假设，建立“三层稳定度谱系”，为工程造价争议的非诉调解、合同风控与诉讼攻防提供精准的可执行步骤与决策依据[12, 19]。

## 第一节 建设工程造价争议全景剖析与高发争点统计

### 1.1 “模式错配”与“三不懂”困境下的造价争议演变

当前我国建设工程领域正经历计价规则与裁判规则的“双重换轨”[19]。一方面，以《建设项目工程总承包计价规范》（2023版）与《建设工程工程量清单计价标准》（GB/T 50500-2024）为代表的计价规范相继推行，试图从传统的“施工承包（DBB）”计价逻辑向“工程总承包（EPC）”及过程结算模式转型[19]；另一方面，最高人民法院发布《关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释〔2026〕12号）及配套典型案例，重塑了中标前实质性谈判、资质借用全链条否定、固定总价解除后“比例法”清算以及行政审计/财政评审与司法鉴定衔接等裁判规则[12, 19]。

然而，市场主体普遍面临制度性**“模式错配”**的严峻考验：我国现行造价规则与建工裁判规则，整体上仍建立在“施工承包（DBB）”的传统语境之上，而工程总承包在法律定性、资质边界、发包阶段及风险分担机制上与传统施工存在本质分野[19]。这种错配直接引发了市场主体的**“三不懂”困境**[19]：
1. **造价人员不懂法律效力的边界**：盲目依赖合同约定的计价条款，忽视了法律对“先定后招”、“实质性背离”等无效条款的强制性否定[12, 19]；
2. **法务人员不懂计价规则的机理**：仅从法条字面理解合同效力，无法剖析工程变更、清单错漏项15%调整规则、定额套用与降效损失的专业造价形成过程[15, 19]；
3. **管理层不懂两条规则如何衔接**：在履约管理中未能建立台账化证据链，导致结算难、调价难、索赔程序性失权以及司法鉴定陷入被动[15, 19]。

因此，造价争议已从单纯的“算账问题”演变为涉及“合同效力-计价规则-证据闭环-裁判裁量”的综合性法律与商务博弈[15, 19]。

### 1.2 造价争议案由分布、诉讼程序与统计口径大数据剖析

为准确把握建设工程造价争议的司法审判全景，基于司法案例数据库（以2025年1月1日至12月20日公开的801件建设工程施工合同纠纷裁判文书为样本）及地方高院大数据统计进行定量分析[07]：

#### 1.2.1 审理法院级别与诉讼程序分布
在801件样本案件中，各级人民法院的审理分布呈现出明显的金字塔结构[07]：
* **基层人民法院**：530件，占比高达 **66.17%**[07]；
* **市级中级人民法院**：147件，占比 **18.35%**[07]；
* **省级高级人民法院**：89件，占比 **11.11%**[07]；
* **最高人民法院**：35件，占比 **4.37%**[07]。

在诉讼程序分布上，**一审案件**为434件（占比 **54.18%**），**二审案件**为116件（占比 **14.48%**），**再审案件**为120件（占比 **14.98%**），由此推算建设工程施工合同纠纷的上诉率约为 **26.73%**[07]。这表明建工造价纠纷具有案件基数大、争议解决周期长、社会矛盾集中的典型特征[07]。

#### 1.2.2 裁判结果的可视化分布与风险口径
对不同诉讼阶段的裁判结果进行可视化剖析，揭示了造价纠纷在司法裁判中的风险分布[07]：

```
+-----------------------------------------------------------------------------------+
|                            建设工程施工合同纠纷裁判结果统计                             |
+-------------------+---------------------------------------------------------------+
| 一审裁判结果 (434件) | · 撤诉: 314件 (72.85%)                                         |
|                   | · 全部/部分支持: 87件 (20.18%)                                  |
|                   | · 其他/驳回起诉/调解: 33件 (6.97%)                              |
+-------------------+---------------------------------------------------------------+
| 二审裁判结果 (116件) | · 维持原判: 70件 (60.34%)                                       |
|                   | · 二审撤诉: 26件 (22.41%)                                       |
|                   | · 改判/发回重审/提审: 20件 (17.25%)                              |
+-------------------+---------------------------------------------------------------+
| 再审裁判结果 (120件) | · 维持原判: 99件 (86.09%)                                       |
|                   | · 提审/指令审理: 9件 (7.82%)                                    |
|                   | · 改判/其他: 12件 (5.09%)                                       |
+-------------------+---------------------------------------------------------------+
```

* **一审阶段高撤诉率与低胜诉率**：一审中撤诉案件达314件（占比 **72.85%**），而获得法院全部或部分支持的仅为87件（占比 **20.18%**）[07]。这说明大部分造价争议在诉讼过程中通过诉讼外调解、庭后和解或因举证不能而撤诉，实际走完一审判决的案件比例不足三成[07]。
* **二审改判率与维持率**：二审维持原判占 **60.34%**（70件），改判占 **10.35%**（12件），发回重审占 **2.59%**（3件），提审/指令审理占 **1.72%**（2件），二审撤诉占 **22.41%**（26件）[07]。二审维持原判为主导，改判和发回重审难度较大[07]。
* **再审高度稳定性与极低翻盘率**：再审案件中，法院裁定维持原判的占比高达 **86.09%**（99件），指令审理/提审占 **7.82%**（9件），直接改判的仅占 **1.74%**（2件）[07]。数据证实，一旦经过一、二审事实认定与造价鉴定，进入再审程序后翻盘的概率极低[07]。

### 1.4 判例谱系的核心追问：“树子问”（Q1, Q2, Q3）

为了打破造价争议解决中的盲目性，研究总监团队提炼出造价争议判例谱系的三大核心追问（简称**“树子问”**）[12, 15, 18, 19]：

#### 追问一（Q1：效力传导与法律适用逻辑）：裁判依据的权威传导层级如何约束造价规则？
在《民法典》、建工司法解释、人民法院案例库以及部门规章（如清单计价标准）交织的背景下，当合同约定、造价规范与司法解释发生冲突时，法院如何进行法律效力的层级传导？对于非强制性国家标准（如2024版清单标准）及地方行政文件，如何认定其在司法裁判中的证明力与效力位阶[12, 15, 19]？

#### 追问二（Q2：裁判规则稳定度划分）：造价争议的裁判规则是否存在确定性梯队？
纷繁复杂的造价争点中，哪些规则属于法官自由裁量空间极小的“高稳定实体规则”？哪些规则属于受履约程序与证据固化影响的“中风险审核规则”？哪些规则又属于裁判尺度高度离散、同案不同判高发“高分歧保护规则”？如何通过分类预测诉讼与调解走向[04, 06, 12, 16, 17, 18]？

#### 追问三（Q3：鉴定与司法裁量边界）：造价鉴定意见在裁判中扮演何种角色？
法院在面对专业造价问题时，如何划分“造价事实认定”、“鉴定技术评价”与“法律适用裁判”的边界？在法官裁量权与造价鉴定意见发生冲突时，司法实践如何防止“以鉴代审”，又如何避免忽视造价技术规律的盲目裁判[04, 06, 12, 15, 18]？

## 第二节 判例谱系方法论与 H1/H2 假设实证对抗检验

### 2.1 判例谱系构建的基本方法与可执行步骤

**判例谱系方法论**，是指将海量建设工程造价裁判文书按照“法律争议要点-计价技术机理-司法实证数据”三维坐标进行归类、提炼与对抗检验，从而梳理出裁判规则稳定度梯队的技术路线[06, 12, 18]。

其可执行的**四步操作流程**如下[06, 12, 15, 19]：

```
+-----------------------------------------------------------------------------------+
|                           判例谱系构建四步法可执行步骤                             |
+-----------------------------------------------------------------------------------+
| 第一步：案例抽取与要素解构                                                           |
| 针对特定造价争点（如黑白合同、固定总价变更），检索最高法院及省高院典型判例，解构出「案情 |
| 基础-争议焦点-鉴定依据-裁判逻辑-最终结果」五项关键要素[04, 06, 18]。                |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
| 第二步：裁判逻辑法理归宗                                                           |
| 将裁判逻辑与《民法典》合同编、建工司法解释及人民法院案例库入库案例进行比对，识别裁判依据是  |
| 属于效力性强制规定、任意性规范还是法官裁量裁决[06, 12, 15]。                         |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
| 第三步：稳定度梯队定级                                                             |
| 依据裁判偏离率与同案同判率，将规则归入「计价实体规则（高稳定）」、「程序审核规则（中风险）」 |
| 或「权利保护规则（高分歧）」三层谱系[04, 12, 16, 17, 18]。                         |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
| 第四步：非诉调解与履约风控反向应用                                                  |
| 根据稳定度定级结果，反向指导合同条款起草（设置风险防火墙）、履约证据固化（形成证据闭环）及 |
| 诉讼调解策略（精准锁定谈判筹码）[12, 15, 19]。                                      |
+-----------------------------------------------------------------------------------+
```

### 2.2 H1假设（司法规则统一性假设）实证对抗检验

#### 2.2.1 H1假设内容
**H1假设（规则统一/同案同判假设）**认为：随着最高人民法院建工司法解释的相继颁布以及人民法院案例库的建立，司法审判在造价争议领域已实现了裁判尺度的绝对高度统一，只要查明合同约定与工程事实，即可获得确定的裁判结果[06, 12]。

#### 2.2.2 基于裁判文书的数据对抗检验与反驳
通过对海量判例的实证检索与比对分析，**H1假设被部分否定**[01, 09, 13, 14]。实务中在多个关键领域依然存在显著的同案不同判与裁判尺度离散现象[01, 09, 13, 14]：

1. **“黑白合同”实质性内容背离判定上的尺度分歧**：
   * 部分判例严格认定，只要在中标合同之外另行签订变更工程价款、计价方式、工期或质量的补充协议，一律构成“实质性背离”而认定补充协议无效，强制以备案中标合同结算[01, 13, 14]；
   * 另一部分判例（如最高法（2007）民一终字第74号、最高法（2020）最高法民终903号）则认为，如果在合同履行过程中，因发生了订立合同时难以预见的客观情况变化（如工程多次停工、原材料暴涨、设计重大变更），双方协商一致签订补充协议调整价格或赔偿损失，属于对合同的正常变更，不属于规避招投标监管的“黑白合同”，应认定补充协议有效[13, 14]。
2. **非必须招标项目自愿招投标的规则适用偏离**：
   * 观点一认为，非必须招标项目一旦选择招投标，即应受《招标投标法》全面约束，招投标前的实质性谈判导致中标合同无效[13, 14]；
   * 观点二（如最高法（2020）最高法民终744号）则认为，非必须招标项目下，当事人虽办理了招投标手续，但若双方不具有规避法律强制性规定的故意，且真实意思表示一致，补充协议可作为认定权利义务的依据[14]。

**对抗检验结论**：司法解释与案例库有效统一了基础法理，但在“实质性背离认定”、“客观情况变化判断”等需要结合履约细节的领域，裁判尺度仍存在较大离散度[01, 09, 13, 14]。

### 2.3 H2假设（造价鉴定决定论假设）实证对抗检验

#### 2.3.1 H2假设内容
**H2假设（造价鉴定决定论假设）**认为：工程造价争议具有极强的专业技术性，法官不具备造价审核专业能力，因此造价争议的裁判金额完全由司法鉴定意见书决定，诉讼攻防的核心在于影响鉴定人[04, 15]。

#### 2.3.2 基于司法裁判主导权的对抗检验与反驳
实证裁判数据表明，**H2假设不能成立，造价鉴定意见受到司法裁判权的强烈约束与裁量修正**[04, 06, 12, 15, 18]：

1. **诉前结算协议对司法鉴定的绝对排除**：
   * 根据长三角高级人民法院典型案例裁判规则（裁判规则13）及最高法裁判逻辑，当事人在诉讼前已经就工程造价达成结算协议或书面确认的，一方在诉讼中申请工程造价司法鉴定的，法院明确不予准许[04, 15]。裁判权直接以结算协议作为定案依据，排除鉴定程序的启动[04, 15]。
2. **“以行政审计/财政评审为准”结算条款的法律干预**：
   * 即使合同约定“以财政评审或政府审计结论作为结算依据”，若发包人或审计机关无正当理由拖延审计，根据法释〔2026〕12号《建工司法解释（二）》第六条规定，承包人催告后在合理期限内仍未出具审计结论的，法院可直接准许承包人启动司法鉴定的申请，打破行政审计对造价认定的封锁[04, 12, 16, 19]。
3. **鉴定材料与证据采信的法官主导权**：
   * 根据长三角高院裁判规则（裁判规则18），鉴定人将有争议且未经法庭质证的材料作为鉴定依据的，法院应当组织质证；未经质证的材料不能作为定案依据[04]。对于单方委托的鉴定意见（裁判规则5），法院仅视其为当事人的陈述或主张，必须结合全案证据重新认证，绝不盲目采信[04]。

**对抗检验结论**：造价鉴定仅是协助法官查明工程造价事实的辅助技术手段，法律效力认定、证据采信、合同解释以及结算依据的选择完全由法官依法行使司法裁判权[04, 06, 12, 15]。

### 2.4 H1/H2 假设对抗下的典型判例精析

为了让工程商务经理、法务与建工律师直观掌握裁判逻辑，以下选取四组具有代表性的最高人民法院典型判例，严格按照**「案情-争议焦点-裁判要点-实务教训」**格式进行实战拆解[13, 14]：

#### 判例一：固定总价合同结算中价格调整与“实质性背离”判定案
* **案号**：（2018）最高法民终153号[13]
* **案情**：
  发包人与承包人就某大型基建工程签订招标施工合同，合同约定采取固定总价与固定单价相结合的计价模式。在履约过程中，因发包人变更设计及施工现场条件发生重大变化，双方签订补充协议，对部分工程量及计价单价进行了调整，并约定了新的工程款结算规则。后发包人以补充协议违反了《招标投标法》第四十六条关于“不得订立背离合同实质性内容的其他协议”的规定为由，主张补充协议无效，要求按原备案中标合同结算[13]。
* **争议焦点**：
  履约过程中双方因设计变更与现场条件变化签订的价格调整补充协议，是否构成对中标合同实质性内容的违背而归于无效[13]？
* **裁判要点**：
  最高人民法院审理认为，《招标投标法》第四十六条第一款所禁止的“背离合同实质性内容的其他协议”，旨在防止招标人和中标人通谋串通、架空招投标法定程序[13]。本案中，双方在合同履行过程中，针对设计变更与现场实际发生的施工条件变化，对固定单价、固定总价的表述及价格进行的合理调整，不属于《招标投标法》第四十六条所禁止的背离合同实质性内容的情形，补充协议合法有效，应作为结算依据[13]。
* **实务教训**：
  1. **商务经理**：切勿误以为中标合同约定了“固定总价”就绝对不能调整。在发生设计变更或发包人原因导致现场条件改变时，必须及时签订补充协议固化计价调整，该补充协议受法律保护[13, 16]；
  2. **建工律师**：在诉讼中主张补充协议无效时，不能仅凭“修改了中标合同价格”即断定无效，必须举证证明该修改属于通谋规避招投标监管，而非履约过程中的正常变更[13, 14]。

---

#### 判例二：中标合同无效情形下“实质性背离”规则的排除适用案
* **案号**：（2017）最高法民终175号[13]
* **案情**：
  发包人与承包人就依法必须进行招标的工程签订了《备案合同》，并在建设行政主管部门办理了备案。然而，双方在招投标程序之前即已私下签订了《施工合同》及《补充协议》，对工程价款结算方式进行了大幅让利折让。后双方发生结算争议，承包人主张《备案合同》无效，但应依据《建工司法解释》第21条（原）规定，以备案的中标合同作为结算依据；发包人则主张应按私下签订的《补充协议》结算[13]。
* **争议焦点**：
  在经过备案的中标合同本身因“先定后招”或违反强制性规定而无效时，能否适用“以备案的中标合同作为结算依据”的规则[13]？
* **裁判要点**：
  最高人民法院审理认为，《建工司法解释》第二十一条关于“以备案的中标合同作为结算工程价款的根据”之规定，其适用的前提必须是**备案的中标合同本身合法有效**[13]。本案中，虽然案涉工程经过了招投标程序并在主管机关备案，但该备案合同因存在违规串通及先定后招等违法行为而归于无效[13]。无效的备案合同并不具有比其他无效合同更优先参照适用的效力，故不存在适用该条规则的前提[13]。法院最终结合工程实际质量与履行情况，参照当事人在履约中真实履行的结算约定进行折价补偿[13]。
* **实务教训**：
  1. **工程法务**：不能盲目迷信“备案合同”的法律效力。如果招投标过程存在法定无效事由（如明标暗定、串通投标），备案合同同样无效，无法作为兜底结算的法律护身符[04, 13, 19]；
  2. **造价工程师**：在备案合同与补充协议均无效的“双无效”困境下，造价结算将直接转化为“参照真实履行的合同要素进行折价补偿”，需重点固化工程实际施工成本与施工图纸签证[01, 13, 15]。

#### 判例三：非必须招标项目“先定后招”及补充协议效力认定案
* **案号**：（2020）最高法民终744号[14]
* **案情**：
  甲公司将其开发的商品房项目采取邀请招标方式进行发包，乙公司中标并签订了四份《备案合同》[14]。然而在招标开始前，甲公司与乙公司即已就工程范围、工程价款等进行了实质性谈判并签订了《施工合同》[14]。在履约阶段，双方又签订了多份《补充协议》，对原合同的付款节点与计价方式进行了重塑[14]。发生纠纷后，甲公司主张《施工合同》系对备案合同的实质性背离，应按照备案合同结算[14]。
* **争议焦点**：
  非必须招标项目下，因违反邀请招标程序导致备案合同与施工合同均无效时，补充协议能否作为工程价款结算的依据[14]？
* **裁判要点**：
  最高人民法院审理认为：
  1. 根据《必须招标的工程项目规定》（2018年第16号令），涉案商品房住宅项目不属于依法必须进行招标的工程项目[14]；
  2. 但由于甲公司自愿采取邀请招标方式，即应受《招标投标法》约束。因甲公司违反了向三个以上具备条件的法人发出邀请书的法定规定，且存在中标前实质性谈判行为，四份《备案合同》与《施工合同》均属无效[14]；
  3. 在《备案合同》与《施工合同》均无效的情况下，**不存在所谓对中标合同实质性条款背离的问题**[14]。因双方签订的《补充协议》系因工程未能按期开工、双方就原条款进行调整的真实意思表示，且不存在规避法律强制性规定的故意，法院最终以《补充协议》作为认定双方权利义务与工程结算的根据[14]。
* **实务教训**：
  1. **建工律师**：在处理商品房等非必须招标项目时，首先应依据《必须招标的工程项目规定》核查项目属性。若合同无效，应转向审查双方真实履行的补充协议或结算协议，而非机械套用“以中标合同为准”[12, 14]；
  2. **商务经理**：非必须招标项目自愿招标的，切记招投标程序的严肃性。若需调整合同，应以“客观情况变化”为由签署补充协议，固化调整理由，确保补充协议在主合同无效时仍可作为折价补偿的裁判依据[14, 15]。

#### 判例四：停工损失赔偿与固定单价变更协议的独立效力案
* **案号**：（2007）民一终字第74号[13]
* **案情**：
  赤峰建设公司与凤辉地产公司签订建设工程施工合同，约定采取固定总价方式结算。工程开工后，因发包人未能按时提供施工图纸及办理施工许可证，导致工程多次发生大面积停工[13]。为解决停工给承包人造成的严重窝工损失及材料价格上涨问题，双方在履约中期签署了一份《补充协议》，约定将结算方式由原合同的固定总价变更为按实际完成工程量以“固定单价”结算，并增设了停工补偿条款[13]。工程竣工后，凤辉地产公司抗辩称该《补充协议》系迫于工期与返迁压力签订，且变更了中标合同的实质性价格条款，属于“黑白合同”，要求按原中标固定总价结算[13]。
* **争议焦点**：
  为补偿因发包人原因造成的停工损失而变更结算方式的《补充协议》，是否属于无效的“黑白合同”[13]？
* **裁判要点**：
  最高人民法院审理认为，《建工司法解释》第21条（原）关于黑白合同的规定，针对的是当事人在中标合同之外另行签订协议以架空中标合同、规避监管的情形[13]。而本案双方签订的《补充协议》，是在双方履行施工合同过程中，为了解决因发包人原因导致多次停工给承包人造成的损失而签订[13]。该协议仅变更了工程款结算方式，其他工程质量、工期等主要内容并未改变，其性质属于**对停工损失赔偿及履行条件变化的正常变更约定**，不属于“黑白合同”，补充协议对双方均有约束力，应作为结算依据[13]。
* **实务教训**：
  1. **商务经理与造价工程师**：遇到发包人原因导致停工、延误或重大变更时，必须将“损失补偿”与“计价方式调整”结合起来签订补充协议。在补充协议中务必写明“鉴于发包人原因导致停工及市场价格变动，双方协商调整结算方式”，以此锁定协议的合法有效性[13, 17]；
  2. **工程法务**：发包人以“胁迫”或“迫于压力”为由主张撤销补充协议的，必须在《民法典》规定的撤销权行使期限内提出；逾期未主张撤销且已实际履行的，补充协议具有法律拘束力[13, 15]。

## 第三节 工程造价争议“三层稳定度谱系”划分与实务裁量基准

### 3.1 稳定度谱系划分原则与量化评定标准

工程造价争议并非处于同一离散度的法理混沌状态[07]。基于对海量裁判文书的实证抽取与裁判逻辑复盘，司法实践对不同造价争点的裁量空间与审判尺度存在显著的分层现象[04][12]。为了帮助工程造价工程师、商务经理、工程法务与建工律师在非诉调解、合同审查与诉讼攻防中建立精准的裁判结果预期，本报告将工程造价争议裁判规则划分为**“三层稳定度谱系”**[07][09][15]：

```
+-----------------------------------------------------------------------------------+
|                        工程造价争议“三层稳定度谱系”结构图                             |
+-----------------------------------------------------------------------------------+
| 第一层：计价实体规则 (高稳定度 / 偏离率 < 5%)                                         |
| · 契约自治与折价补偿规则                                                           |
| · 诉前结算协议不可反悔与排除鉴定规则                                                 |
| · 未经验收擅自使用视为质量合格与质量鉴定抛弃规则                                       |
| · 窝工损失排除管理费与税金定额规则                                                   |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
| 第二层：程序审核规则 (中风险度 / 偏离率 15%-30%)                                     |
| · 结算文件“逾期默示认可”书面约定生效规则                                             |
| · 行政审计/财政评审拖延下启动司法鉴定条件规则                                         |
| · 工程签证缺损下的“程序优先”与证据链补正规则                                          |
| · 单方委托鉴定意见与未经质证鉴定材料效力审查规则                                       |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
| 第三层：权利保护规则 (高分歧度 / 偏离率 > 35%)                                       |
| · 实际施工人突破相对性追索发包人的“诉讼路径压缩”规则                                   |
| · 建设工程价款优先受偿权范围、起算点与受让审查规则                                     |
| · 固定总价合同解除后“比例法”清算与单价调整规则                                       |
| · 非必须招标项目自愿招标下“先定后招”与补充协议效力规则                                 |
+-----------------------------------------------------------------------------------+
```

1. **第一层：计价实体规则（高稳定度，偏离率 < 5%）**：此类规则直接源于《民法典》强制性规定或最高人民法院确立的定型化裁判要旨，法官自由裁量空间极小，各地法院裁判尺度高度统一[04][12][15]。当当事人具备该类规则所要求的法定事实时，诉讼结果具有确定性，应作为商务调解与诉讼决策的坚实底线[04]。
2. **第二层：程序审核规则（中风险度，偏离率 15%-30%）**：此类规则的适用高度依赖当事人在履约过程中的程序性动作（如书面催告、签证提交、异议保留、台账留存等）[15][19]。裁判结果取决于当事人能否提供完整闭环的程序性证据，属于可以通过规范工程商务管理进行风险预防的范畴[15]。
3. **第三层：权利保护规则（高分歧度，偏离率 > 35%）**：此类规则涉及多方利益博弈、法理冲突或国家政策的动态调整，同案不同判现象高发[01][02][03][12]。法官在此类规则中享有较大的自由裁量权，属于诉讼攻防中的核心博弈区与非诉调解的高频妥协区[02][12]。

### 3.2 第一层：计价实体规则（高稳定度）裁量基准与典型判例

计价实体规则是建工司法审判的硬性基石，无论合同效力如何演变，法官在适用此类规则时均遵循高度统一的法理逻辑[04][12]。

#### 3.2.1 契约自治优先与合同无效下的折价补偿规则
* **裁量基准**：
  1. **有效合同依约定结算**：当事人对建设工程的计价标准或者计价方法有约定的，严格按照约定结算工程价款，司法裁判绝不轻易以“市场价格波动”或“显失公平”为由干预当事人的真实计价合意[15]；
  2. **无效合同合格折价补偿**：建设工程施工合同无效，但建设工程经验收合格的，承包人有权参照合同关于工程价款的约定请求折价补偿[12][15]；
  3. **质量不合格的分类处置**：施工合同无效且工程质量不合格的，若修复后经验收合格，发包人可以请求承包人承担修复费用[12][15]；若修复后仍经验收不合格，承包人无权请求参照合同约定折价补偿[12][15]。若发包人对工程不合格存在过错（如提供缺陷图纸、强令盲目施工），应承担相应过错责任[15]。

#### 3.2.2 诉前结算协议的不可反悔性与排除司法鉴定规则
* **裁量基准**：
  当事人在诉讼前已经就工程造价达成结算协议、签署对账确认单或达成折价补偿协议的，法院对一方当事人在诉讼中提出的工程造价司法鉴定申请**明确不予准许**[04][12]。
* **规则细化**：
  根据法释〔2026〕12号第十二条，即使建设工程施工合同无效，只要工程质量合格，发包人与承包人就折价补偿款达成的清算协议原则上合法有效，一方主张按协议确定权利义务的，法院应予支持[12]。这确立了“事后结算协议优于司法鉴定”的绝对裁判铁律[04][12]。

#### 3.2.3 擅自使用视为质量合格与抛弃质量鉴定权规则
* **裁量基准**：
  建设工程未经竣工验收，发包人擅自使用的，以**建设工程转移占有之日**为竣工日期[04]。发包人以工程质量不符合约定为由拒付工程款或申请启动工程质量司法鉴定的，法院不予支持[04]。
* **实务边界**：
  发包人擅自使用工程后，即被法律推定为对工程质量的认可，从而抛弃了通过质量鉴定拒付工程款的抗辩权[04]。对于擅自使用后发现的质量缺陷，发包人仅能要求承包人承担工程质量保修责任，而无权扣减已完工程的折价补偿款[04]。

#### 3.2.4 窝工损失排除管理费与税金定额规则
* **裁量基准**：
  发包人拖欠工程款或未提供施工条件致承包人窝工的，窝工损失必须根据合同协议及现场实际证明核算，且**窝工损失的核算范围明确不包括管理费和税金损失**[04]。施工合同无效时，合同中设定的违约金条款自始不具有法律约束力，不能作为计算逾期付款损失的依据[04]。

```
+-----------------------------------------------------------------------------------+
|                        第一层：计价实体规则实务裁判指南                              |
+-------------------+---------------------------------------------------------------+
| 适用规则          | 裁判结果确定性与实务应对                                         |
+-------------------+---------------------------------------------------------------+
| 合同无效折价补偿   | 确认工程质量合格是前提；妥善保存竣工验收单或转移占有证据[12][15]                |
| 诉前结算协议      | 协议具备不可反悔效力；阻断对方启动司法鉴定的企图[04][12]                      |
| 擅自使用视为合格   | 锁定转移占有节点；阻断发包人以质量缺陷为由扣减工程款[04]                        |
| 窝工损失剔除管税   | 算账时直接扣除管理费与税金比例；仅按人工与机械摊销索赔[04]                       |
+-------------------+---------------------------------------------------------------+
```

### 3.3 第二层：程序审核规则（中风险度）裁量基准与证据固化

程序审核规则涉及造价形成过程中的程序性要件[15]。此类争议在司法实践中的分歧并非来自法理冲突，而是来自当事人举证责任的履行程度与程序履行的合规性[04][15]。

#### 3.3.1 竣工结算“逾期默示认可”条款的严格适用条件
* **裁量基准**：
  通用条款中关于“发包人收到竣工结算文件后在约定期限内不予答复的，视为认可结算文件”的规定，**必须以合同当事人在专用条款中有明确书面约定为适用前提**[15][19]。
* **裁判逻辑**：
  若合同专用条款未明确约定“逾期未答复即视为认可”的法律后果，仅约定了审核期限的，发包人逾期未答复属于一般违约行为，承包人不得直接主张以其单方提交的结算书作为定案依据，法院仍应启动造价鉴定或结合履约证据审查[15]。

#### 3.3.2 行政审计与财政评审条款的法律边界与鉴定启动条件
* **裁量基准**：
  当事人明确约定工程价款结算以行政审计或财政评审结论为准的，原则上尊重其约定[04][12]。但如果发包人或财评审计机关无正当理由拖延结算，经承包人书面催告后在合理期限内仍未出具审计/财评结论的，根据法释〔2026〕12号第六条及长三角高院裁判规则，**法院准许承包人启动造价司法鉴定的申请**[04][12][19]。
* **操作要点**：
  承包人必须留存书面送审台账、催告函及邮寄凭证，证明财评审计已超出了法定或合理的清算周期，以此打破发包人以“审计未完成”为由无限期拖延付款的防线[12][19]。

#### 3.3.3 工程变更与签证的“程序性失权”与证据链补正
* **裁量基准**：
  工程变更签证是工程量确认的最直接依据，体现“工程管理程序优先”原则[15]。合同约定“承包人未在约定期限内提出变更顺延或价款增加申请视为放弃权利”的，原则上按约定处理[04]；但若承包人能证明变更系发包人指令且已实际施工，并能提出包含施工日志、会议纪要、微信沟通记录、进场材料台账在内的完整证据链的，法院对程序性失权抗辩不予支持，工程价款应予增加[04][15][19]。

#### 3.3.4 单方委托鉴定与未经质证鉴定材料的审查规则
* **裁量基准**：
  1. **单方委托鉴定意见的证明力**：诉前一方当事人单方委托造价咨询机构出具的鉴定意见，在诉讼中仅具有当事人陈述或主张的效力，对方不予认可的，不能作为认定造价的直接依据，必须重新启动司法鉴定（长三角高院裁判规则5）[04]；
  2. **鉴定材料的质证强制原则**：鉴定人将有争议且未经法庭组织质证的送审材料作为鉴定依据的，法院必须组织当事人质证（长三角高院裁判规则18）[04]。未经质证的材料，绝不能作为司法鉴定的计算基础[04]。

### 3.4 第三层：权利保护规则（高分歧度）争议焦点与审判尺度

权利保护规则处于建工司法裁判的最前沿，受法释〔2026〕12号《建工解释二》重塑的影响最为深刻[12]。此类规则在不同法院之间裁量尺度离散度较高，属于诉讼博弈的核心[02][03][12]。

#### 3.4.1 实际施工人突破相对性追索发包人的“诉讼路径压缩”
在法释〔2026〕12号颁布前，“实际施工人”常被概括化套用以直接突破合同相对性向发包人主张工程款[02][12]。法释〔2026〕12号对这一乱象进行了精准修正与诉讼路径重塑[12]：

```
+-----------------------------------------------------------------------------------+
|                  法释〔2026〕12号关于“突破相对性”请求权路径重新校准                  |
+-------------------+---------------------------------------------------------------+
| 主体类型          | 裁判路径与责任认定规则                                         |
+-------------------+---------------------------------------------------------------+
| 接受转包/违法分包方| 原则上不得直接起诉发包人；仅能参照合同向转包人/违法分包人主张折价补偿款(第6条)[12] |
| 资质借用(挂靠)方   | · 发包人不知情：不得直接起诉发包人付款(第4条)[12]                |
|                   | · 发包人知道/应当知道：法院通知出借资质企业为第三人，判发包人承担责任(第4条)[12] |
| 债权人代位权路径  | 挂靠方、转包/分包受让方可依据《民法典》第535条，以转包方/出借方怠于行使到期债权为由，|
|                   | 向发包人行使代位权诉讼(第7条)[02][03][12]                      |
+-------------------+---------------------------------------------------------------+
```

* **审判尺度**：
  1. **转包与违法分包的绝对相对性**：接受转包、违法分包的单位或个人，原则上不得直接要求无合同关系的发包人支付折价补偿款（法释〔2026〕12号第六条）[12]；
  2. **挂靠情形下发包人“知情状态”决定责任**：借用资质方起诉发包人的，发包人订约时**不知道且不应当知道**挂靠情形的，借用资质方无权要求发包人付款[12]；唯有证明发包人**知道或应当知道**挂靠事实的，法院方判令发包人向借用资质方承担折价补偿责任（法释〔2026〕12号第四条）[12]；
  3. **代位权成为法定突破路径**：实际施工人追索工程款的合规路径被引导至《民法典》第五百三十五条规定的**债权人代位权诉讼**，必须证明转包人或出借资质企业怠于向发包人行使到期债权（法释〔2026〕12号第七条）[02][03][12]。挂靠人本身绝不享有建设工程价款优先受偿权（长三角高院裁判规则3）[04]。

#### 3.4.2 建设工程价款优先受偿权的精细化裁量
* **争议焦点**：
  优先受偿权的行使期限、受偿范围以及债权转让后的受让人能否行使优先受偿权[03][15][19]。
* **审判尺度**：
  1. **行使期限为18个月**：自发包人应当给付工程价款之日起算，属于除斥期间，不适用诉讼时效中断或中断规定[15]；
  2. **受偿范围排除惩罚性债权**：优先受偿范围严格限定为承包人实际支出的建筑材料款、人工费等实际成本，**明确不包括利息、违约金以及因发包人违约造成的损失赔偿**[15]；
  3. **权利对抗消费者购房权**：对于购买商品房的消费者，若已支付大部分购房款，优先受偿权不得对抗该买受人[04]；但对于购买商业用房（非商品房）且支付大部分款项的买受人，承包人就该商业用房享有的工程价款优先受偿权**可以对抗买受人**（长三角高院裁判规则16）[04]。

#### 3.4.3 固定总价合同解除后的“比例法”清算与单价调整
* **争议焦点**：
  固定总价合同未履行完毕即行解除的，已完工程价款如何确定？
* **审判尺度**：
  1. **固定价格原则尊重风险分配**：在合同正常履行状态下，当事人不得仅以人工、材料价格发生重大变化为由请求调整固定价款（法释〔2026〕12号第九条）[12]；
  2. **解除后适用“比例法”清算**：固定总价合同解除后，已完工程价款的清算不得简单套用预算定额按实结算，而应采用**“比例法”**——即先通过造价鉴定确定已完工程量占全部工程量的百分比，再以该比例乘以合同约定的固定总价计算工程价款（法释〔2026〕12号第十条、长三角高院裁判规则2）[04][12][19]。这完整保留了原合同固定总价对双方风险分配的合意[12][19]。

### 4.2 顶层基本法与行政法规对造价契约自治的强制性边界

造价管理的基础在于合同约定（契约自由），但契约自由必须在基本法与行政法规划定的法律红线内运行[15]。

#### 4.2.1 《民法典》作为民事基本法的基石作用
《民法典》合同编是处理造价纠纷的总源头[15]：
1. **合同效力与折价补偿**：《民法典》第793条确立了施工合同无效时“经验收合格参照合同约定折价补偿”的法律后果[12][15]，彻底否定了无效合同下按预算定额全面重新套价的“按实结算”主张；
2. **通谋虚伪表示规则**：《民法典》第146条关于“行为人与相对人以虚假的意思表示实施的民事法律行为无效”的规定，直接成为认定“阴阳合同”、“先定后招”以及阴合同无效、折价补偿依据选择的底层法理[01][12][13]。

#### 4.2.2 《招标投标法》与《建筑法》对造价契约的效力性强制边界
1. **《招标投标法》对价格背离的否定**：《招标投标法》第四十六条第一款关于“招标人和中标人不得再行订立背离合同实质性内容的其他协议”的规定，属于效力性强制规定[01][13][14]。凡在中标前后私下签订让利协议、阴阳合同以变相降低工程价款的，该约定一律无效[01][13][14]；
2. **《建筑法》对资质与转包的严厉禁止**：《建筑法》第二十六条、第二十八条关于禁止无资质承揽工程、禁止转包与违法分包的规定，构成了司法解释否定资质借用费、否定转包合同效力的上位法依据[02][12][15]。

#### 4.2.3 行政法规对造价费用的刚性保护
根据《建设工程质量管理条例》与《建设工程安全生产管理条例》，发包单位不得任意压缩合理工期，不得迫使承包方低于成本竞标，且安全施工措施费等关乎公共安全的费用必须纳入工程概算并按实计取[15]。任何在合同中将安全措施费作为竞争性让利扣减的条款，均因违反行政法规的强制性规定而归于无效[15]。

### 4.3 司法解释（法释文件）与人民法院案例库的同案同判拘束力

在司法审判实务中，最高人民法院发布的专项司法解释与人民法院案例库入库案例，是法官判定案件最直接、最具有约束力的裁判依据[12][16][17][18]。

#### 4.3.1 《建工司法解释（一）》与《建工司法解释（二）》（法释〔2026〕12号）的规则重塑
1. **效力新旧衔接与适用范围**：
   法释〔2026〕12号自2026年6月30日起施行，施行后人民法院新受理的一审建设工程施工合同纠纷案件全面适用本解释；此前司法解释与本解释不一致的，以本解释为准[12]。
2. **请求权路径精细化**：
   法释〔2026〕12号摒弃了过去“以实际施工人概念泛化处理所有建工纠纷”的粗放模式[12]。其通过23个条文，精细化区分了必须招标项目范围变化（第1条）、先谈后招与先签后补（第2条）、资质借用管理费否定（第3条）、发包人知情对挂靠责任的影响（第4条）、违法转分包不可直接追索发包人（第6条）、代位权路径（第7条）、固定总价解除比例法清算（第10条）以及事后折价补偿协议效力（第12条）等重大裁判规则[12]。

#### 4.3.2 人民法院案例库入库案例的“参照适用”机制
人民法院案例库建立后，最高人民法院发布的入库案例具有**“类案参照”**的强拘束力[12][16][17][18]：
* **法官检索义务**：法官在审理疑难造价纠纷案件时，应当在案例库中检索类案[12]。对于事实要素与争议焦点高度相似的入库案例，法官在裁判文书中应当进行参照适用或对偏离理由进行充分释明[12]。
* **实务应对**：工程法务与律师在提交代理意见时，应优先检索人民法院案例库中关于“固定总价变更（如（2018）最高法民终153号）”[13][14]、“工期顺延与窝工”[04]、“工程变更与签证”[18]的入库判例，以案例库的权威要旨约束法官自由裁量权[12][16][17][18]。

#### 4.3.3 地方高级人民法院裁判指引的补充与填补功能
长三角高级人民法院典型案例裁判规则等地方高院司法解答（如杨唐全主编《建设工程施工合同纠纷裁判规则》总结的上海、浙江、江苏、安徽高院判例）[04][05]，虽然不属于法定司法解释，但在辖区法院内具有极高的裁量参考价值[04]。特别是在鉴定材料质证（规则18）、诉前结算协议阻断鉴定（规则13）、擅自使用抛弃鉴定权（规则14）等具体操作细节上，地方高院规则填补了最高法司法解释的细化空白[04]。

### 4.4 计价规范（2023版/2024版）与裁判规则的“双重换轨”衔接机制

当造价领域的“工程计价规范”遇上法律领域的“司法裁判规则”，如何处理两者的衔接冲突是工程商务与法务必须解决的焦点[19]。

#### 4.4.1 2024版清单标准（GB/T 50500-2024）的效力转变与司法适用
* **效力结构重大调整**：
  2024版《建设工程工程量清单计价标准》（GB/T 50500-2024）因上位法及政策变化，**由原先的强制性国家标准转为推荐性国家标准**[19]。
* **司法裁判适用逻辑**：
  推荐性国家标准本身不具备法律上的强制约束力，当事人不能仅凭合同条款违反了GB/T 50500-2024的某项规定（如未采用工程量清单计价）即主张合同条款无效[19]。但在下列两种情形下，法官会将清单标准引入作为裁判依据[19]：
  1. **合同明确约定引入**：当事人在合同专用条款中约定“本工程计价与结算遵照GB/T 50500-2024执行”的，该推荐性标准即转化为合同合意，对双方具有合同约束力[19]；
  2. **作为计价惯例与解释工具**：当合同对变更单价调整、清单错漏项规则约定不清时，法官及造价鉴定人可参照GB/T 50500-2024中的行业惯例（如清单错漏项超过15%时的单价调整规则）进行计价解释与补充认定[19]。

#### 4.4.2 2023版《建设项目工程总承包计价规范》与EPC裁判衔接
工程总承包（EPC）模式下，传统的DBB计价逻辑已无法适配[19]。2023版《建设项目工程总承包计价规范》与国内首个《工程总承包裁决指引》（铜陵仲裁委发布）的出台，确立了EPC计价与裁判衔接的三大机制[19]：

```
+-----------------------------------------------------------------------------------+
|               2023版《工程总承包计价规范》与司法裁判衔接三大机制                     |
+-------------------+---------------------------------------------------------------+
| 衔接机制          | 规则要点与司法裁量标准                                         |
+-------------------+---------------------------------------------------------------+
| 变更界定机制      | 严格区分“发包人要求变更”与“承包人自行设计优化”。发包人要求变更方可增减价款；|
|                   | 承包人为满足“发包人要求”而进行的深化设计优化，不得增加总价[19]              |
| 争议评审(DAB)机制  | 引入工程争议评审机制；将造价争议解决节点前移，评审意见经双方签字即具备合同约束力，|
|                   | 阻断后续漫长的诉讼与司法鉴定[19]                                |
| 过程结算机制      | 推行施工过程分段结算；分段结算协议具备诉前结算效力，竣工后不得就已结算部分|
|                   | 重新申请造价司法鉴定(法释〔2026〕12号第12条)[12][19]                     |
+-------------------+---------------------------------------------------------------+
```

1. **“发包人要求变更”与设计优化的界定**：
   EPC固定总价合同下，严禁将承包人为了满足原定功能而进行的正常深化设计或技术优化认定为工程变更[19]。唯有发包人主观提出突破原“发包人要求（Employer's Requirements）”的范围、标准或功能提升，方能构成发包人要求变更，进而触发调价机制[19]；
2. **争议评审机制（DAB）的效力化**：
   倡导在合同中引入贸仲或行业协会的《建设工程争议评审规则》[19]。争议评审组在施工现场作出的专业裁决，经当事人认可或在约定时间内未提出异议的，转化为合同补充协议，在诉讼中直接作为法官认定事实的依据[19]；
3. **“施工过程结算”对竣工总结算的防线作用**：
   通过过程结算将隐蔽工程、阶段工程量在履约期间逐期核定并签署过程结算文件[19]。根据法释〔2026〕12号第十二条，已签认的过程结算文件视同当事人达成的阶段性折价补偿协议，在竣工诉讼中具有排除造价司法鉴定的强力法律效力[12][19]。

## 第五节 工程造价争议非诉调解实务与商务-法务-造价协同解决路径

### 5.1 商务经理、造价工程师、工程法务与建工律师四位一体协同机制

在工程造价争议解决实践中，企业往往因“造价人员不懂法律效力边界、法务人员不懂计价规则机理、管理层不懂两条规则衔接”而陷入“结算难、调价难、索赔失权、鉴定被动”的制度性困境 [19]。要破局这一“模式错配”难题，必须打破部门壁垒，构建由商务经理、造价工程师、工程法务与建工律师构成的“四位一体”协同解决机制 [19]。

```
+-----------------------------------------------------------------------------------+
|                    工程造价争议“四位一体”非诉调解协同机制                            |
+-------------------+---------------------------------------------------------------+
| 角色分工          | 核心职责与协同节点                                             |
+-------------------+---------------------------------------------------------------+
| 造价工程师        | 负责工程量、变更单价、定额套用、降效与窝工成本的技术精算 [19]            |
| 商务经理          | 负责履约台账管理、现场签证催告、商业谈判与和解方案制定 [19]              |
| 工程法务          | 负责合同效力审查、诉讼时效/除斥期间把控、证据链闭环与法律风险隔离 [12, 15]   |
| 建工律师          | 负责判例谱系检索、三层稳定度定级、裁判结果预期测算与诉讼攻防演练 [12, 19]     |
+-------------------+---------------------------------------------------------------+
```

为了将造价争议消化在诉讼之前，研究总监团队总结出工程造价争议非诉调解全流程**“六步实战法”**：

1. **第一步：争议事实与计价要素摸底**
   由造价工程师与商务经理共同对案涉项目的合同约定、图纸变更、工程量清单、现场签证、工程结算书及双方往来函件进行全面梳理，核算争议金额的构成要素（如直接工程费、管理费、规费、税金及窝工损失等）[15, 19]。
2. **第二步：合同效力与三层稳定度规则对标**
   由工程法务与建工律师核查项目招投标与缔约流程，判断合同是否存在“先定后招”、“明招暗定”、资质借用或违法分包等无效事由 [12, 13, 14]。同时，将各项争议要点归入“三层稳定度谱系”（计价实体规则、程序审核规则、权利保护规则），评估各项诉求在司法裁判中的胜诉概率 [04, 12]。
3. **第三步：证据台账闭环核查与失权风险排查**
   重点排查索赔程序性失权条款（如未在28天内提出索赔申请）、签证签章效力、工程质量验收凭证及擅自使用事实，补齐证据链短板，剔除无法举证或缺乏法律依据的虚高诉求 [04, 15]。
4. **第四步：裁判预期与调解心理区间测算**
   结合大数据统计（如一审撤诉率高达 72.85%、二审维持原判率 60.34%、再审维持率 86.09%），向管理层客观展现诉讼/仲裁的时间成本、造价鉴定费用分担（长三角高院裁判规则12）及诉讼风险，精准测算调解让步的心理底线 [04, 07]。
5. **第五步：非诉谈判方案拟定与折价补偿谈判**
   利用“第一层计价实体规则”的确定性锁定基础工程款，利用“第二层程序审核规则”在签证与催告证据上的优势逼迫对方让步，针对“第三层权利保护规则”的分歧点寻求商业妥协方案 [12, 15]。
6. **第六步：调解协议/结算协议法理固化**
   当双方达成一致时，依据法释〔2026〕12号第十二条，将调解成果签署为书面清算协议或折价补偿协议，明确工程质量合格、应付折价补偿款数额、付款节点及放弃其他诉求的条款，依法阻断后续诉讼与造价司法鉴定 [12]。

### 5.2 诉前证据固定、风险隔离与谈判筹码锁定机制

在非诉调解与商务博弈中，证据是决定谈判筹码归属的核心关键。工程商务与法务人员应重点建立以下三大证据与风险隔离防线：

#### 5.2.1 隐蔽工程、工程变更与现场签证台账化证据链闭环
1. **书面确认优先原则**：工程变更与签证是工程量核定的首要依据，直接体现“工程管理程序优先”原则 [15]。商务团队必须建立台账化管理，将项目经理、监理工程师及发包方现场代表签署的变更单、洽商记录、会议纪要按时间序列归档 [15, 19]；
2. **无签证时的证据链补正**：对于发包人代表拒签但实际已施工的变更项目，承包人应通过施工日志、隐蔽工程验收记录、进场原材料检验单、第三方检测报告及微信/邮件沟通记录形成旁证证据链，以证明变更事实已实际发生 [15]；
3. **窝工损失的定额剔除与证明**：主张因发包人原因导致窝工损失时，承包人除需提供停工令、复工申请及人员机械闲置台账外，在核算损失金额时应主动剔除管理费和税金损失，直接按人工费与机械折旧/租赁费索赔，防止因诉求不合法被法院直接否决 [04, 19]。

#### 5.2.2 财政评审与政府审计拖延下的催告与证明力固化
1. **合同约定以审计/财评为准的破局路径**：当合同约定“以行政审计或财政评审结论作为结算依据”时，承包人切不可被动等待 [04, 12]。根据法释〔2026〕12号第六条及长三角高院裁判规则6，承包人应向发包人及审计/财评机关书面提交完整的竣工结算资料，并留存盖章签收凭证 [04, 12]；
2. **合理期限催告函件的固化**：在提交结算资料后，若审计/财评机关超出合同约定或法定审核期限，承包人应定期发送《关于尽快出具竣工结算审计/财评结论的催告函》，明确指出无限期拖延已构成违约 [12, 19]。若发包人经催告后在合理期限内仍未促成结论出具，该催告函及邮寄凭证将直接作为诉讼中请求启动司法鉴定、打破审计封锁的法定依据 [12, 19]。

#### 5.2.3 无效合同下“折价补偿款”书面确认与优先受偿权防线
1. **无效合同清算协议的文本表达**：在违法分包、转包或资质借用导致施工合同无效的场景下，双方达成的结算协议名称与条款表述应严格规范为“已完工程折价补偿款确认协议”，避免使用“继续履行原合同”等易被认定为再次违法的表述 [12]。根据法释〔2026〕12号第十二条，该折价补偿协议只要内容不违反法律强制性规定且工程质量合格，即可获得法院全额支持 [12]；
2. **建设工程价款优先受偿权的防线阻断**：承包人必须牢记优先受偿权的行使期限为 **18个月**，自发包人应当给付工程价款之日起算 [03, 15]。在非诉调解中，承包人可将“启动优先受偿权保全/诉讼”作为强制发包人履约的终极筹码，但应注意挂靠的实际施工人自身不享有优先受偿权，需通过债权人代位权诉讼或由被挂靠企业主张 [02, 03, 04]。

### 5.3 争议评审（DAB）、贸仲规则与诉讼/仲裁的策略选择

工程造价争议解决路径的选择，直接决定了争议处理的成本、效率与保密性。

```
+-----------------------------------------------------------------------------------+
|                     工程造价争议多元化解决路径（ADR）选择矩阵                        |
+-------------------+---------------------------------------------------------------+
| 解决路径          | 适用场景、优势与法律效力                                       |
+-------------------+---------------------------------------------------------------+
| 工程争议评审 (DAB) | 适合EPC及大型复杂项目；由行业专家现场裁决；经双方签认转化为合同约束力 [19]    |
| 仲裁 (如贸仲/铜陵) | 适合商业保密要求高、专业性强项目；一裁终局、实行专家断案；适用专有裁决指引 [19]  |
| 诉讼 (人民法院)   | 适合缺乏信任基础、需申请司法保密/查封或管辖明确的项目；受法释〔2026〕12号约束 [12] |
+-------------------+---------------------------------------------------------------+
```

#### 5.3.1 贸仲《建设工程争议评审规则》与工程争议评审机制应用
1. **争议评审组（DAB/CDB）的嵌入**：2023版《建设项目工程总承包计价规范》积极推行争议评审机制 [19]。当事人在合同中约定适用中国国际经济贸易仲裁委员会（贸仲）《建设工程争议评审规则》的，可在项目开工初期选定1名或3名造价、法律专家组成争议评审组 [19]；
2. **评审意见的效力转化**：在履约过程中发生变更调价、工期顺延或索赔争议时，评审组深入现场进行听证并快速出具评审意见 [19]。若双方在约定时间内未提出书面异议，评审意见即对双方产生合同约束力；发包人拒绝执行的，承包人可将其作为已核定的结算依据直接申请仲裁或诉讼，避免了竣工后漫长且不可控的司法鉴定程序 [19]。

#### 5.3.2 施工过程结算（过程分段结算）在EPC及大型项目中的控风险机制
根据2024版《建设工程工程量清单计价标准》（GB/T 50500-2024）与2023版总承包计价规范，施工过程结算已被提升为防范“结算难”的关键制度 [19]：
1. **分段核算与价款支付**：发承包双方按工程节点（如地下室封顶、主体验收、设备安装完成）对已完工程量及变更签证进行阶段性核算并支付过程结算款 [19]；
2. **防范总结算翻账**：过程结算文件一经双方签认，即具备诉前清算协议的法律效力 [12, 19]。在最终竣工总结算时，除合同另有约定外，双方不得对已完成过程结算的部分重新申请司法鉴定或反悔翻账，彻底切断了造价争议累积至竣工爆发的隐患 [12, 19]。

#### 5.3.3 诉讼与仲裁路径选择判定矩阵
在决定采取诉讼还是仲裁管辖时，企业商务与法务团队应结合下表策略选择判定矩阵进行决策：

| 评估维度 | 诉讼路径（人民法院管辖） | 仲裁路径（仲裁委员会管辖） |
| :--- | :--- | :--- |
| **管辖与程序** | 属于专属管辖（不动产所在地人民法院管辖）[20]；实行两审终审制，上诉率约 **26.73%** [07]。 | 需有明确仲裁协议；实行一裁终局制，程序快捷高效 [19]。 |
| **裁判专业度** | 依赖法官对建工司法解释的理解，对技术造价倾向于委托司法鉴定 [04, 12]。 | 可指定建工造价专家、建工律师担任仲裁员，专业裁判能力强 [19]。 |
| **案例拘束力** | 受人民法院案例库入库案例及上级法院裁判指引的强约束 [12, 15]。 | 参照仲裁委裁判指引（如铜陵仲裁委《工程总承包裁决指引》）[19]。 |
| **保密与保全** | 裁判文书原则上公开；财产保全由审理法院直接裁定并执行 [07, 20]。 | 审理过程完全保密；财产保全需由仲裁委转交法院裁定执行 [19]。 |

## 本章小结要点

1. **“模式错配”与“三不懂”困境**：当前工程总承包（EPC）及传统施工领域正经历计价规范与裁判规则的“双重换轨” [19]。造价人员不懂法律效力边界、法务人员不懂计价机理、管理层不懂两条规则衔接，是导致“结算难、调价难、索赔失权、鉴定被动”的根源 [19]。必须构建商务、造价、法务与律师“四位一体”的协同机制 [19]。
2. **判例谱系与 H1/H2 假设验证**：
   * **H1假设（规则统一）被部分否定**：黑白合同实质性背离认定、非必须招标项目自愿招投标的效力等领域，不同法院间仍存在裁判尺度离散与同案不同判现象 [01, 13, 14]；
   * **H2假设（鉴定决定论）不能成立**：诉前结算协议直接排除司法鉴定（长三角高院规则13），行政审计拖延可启动鉴定（法释〔2026〕12号第6条），法官对鉴定材料与证据采信享有绝对主导权 [04, 12]。
3. **“三层稳定度谱系”划分**：
   * **第一层（计价实体规则/高稳定）**：有效合同依约定结算、无效合同合格折价补偿（《民法典》第793条）、诉前结算协议不可反悔、擅自使用视为合格，偏离率 < 5% [04, 12, 15]；
   * **第二层（程序审核规则/中风险）**：默示认可条款书面约定生效、行政审计拖延催告、签证缺损证据链补正、单方鉴定意见认证，偏离率 15%-30% [04, 12, 15]；
   * **第三层（权利保护规则/高分歧）**：挂靠/转包下突破相对性路径校准（法释〔2026〕12号第4/6/7条）、优先受偿权18个月除斥期间与范围限定、固定总价解除“比例法”清算（第10条），偏离率 > 35% [02, 03, 12]。
4. **效力传导层级与规范衔接**：造价争议裁判遵从“顶层基本法（民法典/建工法/招投标法） → 行政法规/国家标准（质量条例/清单标准） → 最高院司法解释（法释〔2026〕12号） → 案例库入库案例与地方指引”的四层效力传导体系 [12, 15]。2024版清单标准（GB/T 50500-2024）转为推荐性标准，作为合同合意或行业惯例适用 [19]；2023版总承包计价规范通过变更界定、争议评审与过程结算实现与司法裁判的衔接 [19]。
5. **非诉调解与风险防控落地**：通过“六步实战法”推进行前调解 [07, 12]；建立隐蔽工程与变更签证台账化证据链 [15]；利用催告函打破行政审计拖延 [12]；推广工程争议评审（DAB）与施工过程结算，将造价争议化解在履约阶段 [12, 19]。

## 本章证据边界

为了保障本报告的学术严谨性与实务适用精准度，现对本章研究所依赖的证据边界与数据局限说明如下：

1. **数据样本与地域空间局限**：
   * 本章引用的定量分析数据（如801件建工施工合同纠纷案件）主要来自司法案例数据库（时间跨度为2025年1月1日至12月20日），样本覆盖最高人民法院及福建省各级人民法院 [07]；
   * 地方高院裁判规则主要归纳自长三角地区（上海、浙江、江苏、安徽）高级人民法院近3-5年的典型判例（杨唐全主编《建设工程施工合同纠纷裁判规则》）[04, 05]。虽然长三角及沿海地区的裁判规则具有较强的示范与引领作用，但不同省份（如中西部地区）在裁量自由度的把握上可能存在区域性差异 [04, 07]。
2. **时间跨度与法规更新衔接**：
   * 本章裁判规则梳理已全面衔接《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释〔2026〕12号，2026年6月30日施行）及国家发展改革委《必须招标的工程项目规定》（2018年第16号令）[12, 14]；
   * 对于2026年6月30日前已审结或正在进行再审审查的历史案件，仍适用当时有效的司法解释及司法政策 [12]。读者在引用本报告规则时，应注意区分案件受理时间与法规生效节点 [12]。
3. **实证假设的适用场景限制**：
   * 本章对 H1/H2 假设的对抗检验结论，建立在一般商事建设工程施工合同纠纷的语境之下 [01, 04]；
   * 对于涉及国家重大保密工程、军事工程、涉外 FIDIC 条款工程或存在严重刑事犯罪（如行贿受贿、强迫交易、重大安全事故）的特殊项目，法律适用与裁判主导权将受到刑事法律及国家特许政策的优先调控，不完全适用本章梳理的民商事裁判谱系 [04, 15]。
4. **专业造价技术与司法裁判权的边界**：
   * 本报告所提炼的“三层稳定度谱系”与裁判要旨，旨在提供法律效力认定与裁判逻辑的框架性指引 [04, 12]；
   * 司法实践中，具体的工程造价数额仍需结合工程施工图纸、现场勘验笔录、质证后的送审材料以及造价鉴定人的专业计算确定 [04, 15]。法律裁判规则不能替代具体的工程量计算与定额套用技术工作，必须坚持“法律定性由法官裁判，技术定量由专家辅助”的司法裁量边界 [04, 06, 12]。
