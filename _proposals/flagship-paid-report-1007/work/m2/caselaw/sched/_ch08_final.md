**【本章导读与解题说明】**
合同效力瑕疵与黑白合同是造价争议中金额最大、最易"同案不同判"的重灾区。实务三大难题构成本章三节：**其一，黑白合同的识别与结算依据颠覆**——招标备案的"白合同"之外另有私下协议时，哪一份算数？"实质性内容变更"的边界在哪（第一节）？**其二，合同无效后的折价补偿计价**——合同无效了，参照约定、按定额重组价、还是按市场价评估？原让利折扣还扣不扣（第二节）？**其三，实际施工人的直接诉权与结算敞口**——转包、挂靠链条下，实际施工人能否越过前手直接告发包人，发包人如何防范双重支付（第三节）？方法论主线一句话：**效力认定决定结算依据，结算依据决定计价口径**——合同效力之争从来不是纯法律问题，而是"以哪份合同、哪种价格算钱"的造价前哨战（本句为本研究导读性判断）。

读者可带着四个场景进入本章：中标之外被迫签了让利"补充协议"，结算时对方拿它压价（第一节）；合同因挂靠被认定无效，对方要求按定额重算——价格反而比合同高（第二节）；实际施工人越过总包直接告到发包人头上（第三节）；调解桌上双方对"按哪份合同谈"僵持不下（第3.8节）。四个场景对应本章四条防线，每条防线都有判例坐标可查。

## 第一节 黑白合同的认定标准与"白合同"结算规则

### 1.1 概念起源、规范演进与项目类型化

黑白合同（阴阳合同）术语最早见于2003年10月27日全国人大常委会执法检查组关于检查中华人民共和国建筑法实施情况的报告：建设单位除公开签订合同外，又私下与中标单位签订合同，强迫中标单位垫资带资承包、压低工程款，"黑白合同"问题相当突出——这是该术语第一次进入官方文书 (P000751)。其根源在于建筑市场供求失衡、发包方占据绝对主导地位——优势地位被用来在中标合同之外索取垫资、压价、赠送面积等让利 (P000751, P000752)。专题论文的实证观察还揭示了双向动因：承包方为承揽工程往往被迫接受甚至主动承诺让利，与发包方的优势地位形成"一个愿打一个不得不挨"的合谋结构 (P000752)——这也是黑白合同屡禁不止的市场土壤：法律否定的只是合同的效力，否不掉的是失衡的供求关系本身（本研究解读）。

规范体系的支柱如下（转引资料库实收文本）：《招标投标法》第46条——招标人和中标人应当自中标通知书发出之日起三十日内，按照招标文件和中标人的投标文件订立书面合同，**招标人和中标人不得再行订立背离合同实质性内容的其他协议** (P000751)；司法解释（一）（法释〔2020〕25号）第2条——招标人和中标人另行签订的建设工程施工合同，在工程范围、建设工期、工程价款、工程质量等方面与中标合同不一致，一方当事人请求按照中标合同确定双方权利义务的，人民法院应予支持 (P000753)；同解释第22条——当事人就同一建设工程订立数份施工合同且内容不一致，中标有效的，应当以中标合同作为结算工程价款的依据 (P000751)。三个条文一层比一层具体：第46条立禁止、第2条给救济、第22条定结算——从"不许签"到"签了不算"到"按白合同算"，规范的牙齿逐级咬合（本研究归纳）。

学术分歧与实务回应（转引论文） (P000752)：有学者（如朱树英）提出黑合同往往体现双方履约中的真实意思，一刀切以白合同结算可能导致承包人借规则规避其自愿作出的让利承诺；司法解释最终确立的是"维护招投标公共秩序优先于私法意思自治"的价值取向——只要中标有效，黑合同的背离条款一律无效，结算强力回归白合同。项目类型化区分（归纳自专题论文） (P000752)：

- **依法必须招标项目（含自愿招标且完成程序者）**：适用上述强制规则——黑合同背离中标合同实质性内容的无效，无论签订于中标前还是中标后，强制以备案白合同结算；制度逻辑在于剥夺黑合同的经济利益、遏制利用优势地位索取让利的不良风气——若私下让利可作结算依据，招投标制度即形同虚设（制度目的归纳自论文） (P000752)；
- **非必须招标项目**：不适用白合同强制结算规制——多份合同不一致时按虚假意思表示规则处理：为应对审批备案而签的虚假"白合同"无效，私下真实签订并实际履行的协议单独判断效力，不违反强制性规定的可作为结算依据。两类项目的分野对造价人员的直接含义：非招标项目的"备案价"没有招标法上的光环，结算之争回到意思表示与实际履行的证明战——谁握有履约轨迹证据，谁就握有结算依据（本研究归纳） (P000752)。

### 1.2 "实质性内容变更"的认定标准

判断黑白合同的核心前提，是私下协议是否对中标合同作了**实质性变更**（要素框架为本研究归纳自专题论文） (P000752)：

```
┌─────────────────────────────────────────────────────────────┐
│ 四大法定要素（司法解释明示）                                 │
│   工程价款（计价方式/总价折扣/让利/免费赠送）                │
│   建设工期（无正当理由的大幅压缩或延长）                     │
│   工程质量（等级标准/材料设备规格的降低）                    │
│   工程范围（主体工程段的私下剥离切割）                       │
├─────────────────────────────────────────────────────────────┤
│ 司法扩展要素（部分地区裁判扩展）                             │
│   履约担保与保证金（无垫资变巨额带资）                       │
│   付款节点与支付方式（严重拖延支付节点）                     │
│   违约责任与争议解决方式的单方加重                           │
├─────────────────────────────────────────────────────────────┤
│ 例外排除情形（正当合同变更）                                 │
│   设计变更与客观施工条件变化引起的按约调价签证               │
│   不可抗力与材料价格暴涨引发的合理补差协议                   │
│   中标合同事先准予变更的约定且不损害公共利益                 │
└─────────────────────────────────────────────────────────────┘
```

例外排除情形的制度逻辑值得点明（本研究归纳）：正当变更豁免的不是"变更"本身，而是变更的**成因与程序**——以真实的设计变更、地质变化为因，按原合同计价规则与签证程序为道的调价，双方权利义务的基盘未动；反之，以"补差""备忘""让利承诺"为名绕开原计价体系的，无论名称如何友好，都已踏进实质性背离的领地。认定"不构成黑白合同"的三大裁判情形（实证归纳自专题论文） (P000752)：其一，**合同仅有一份**——东营开发区法院（2021）鲁0591民初3774号案：双方仅签一份设计合同，不存两份合同对冲，无黑白合同问题；其二，**招投标前签合同但招后未签中标合同**——陕西高院（2020）陕民终950号案：招投标前实质谈判签约并缴纳保证金，但招投标后未签中标合同，缺乏"中标合同"这一比照基准，不属司法解释规制的黑白合同；其三，**自愿招标项目未实际招投标**——属意思自治范畴。三项情形共同圈定了黑白合同规则的地基：**先有白，才有黑**。

### 1.3 判例一：两份合同无实质差异不构成黑白合同

**——（2019）浙05民初130号，浙江省湖州市中级人民法院（浙江中屹建设集团与安吉唐韵影视文化投资、安吉弘骏投资）** (P000752)

- **案情**：浙江中屹建设集团与安吉唐韵影视文化投资公司、安吉弘骏投资公司就案涉工程先后签订两份施工合同，仅一份依法行政备案；履约后双方因工程价款结算发生争议，发包方主张未备案合同属"黑合同"、应当认定无效，以便按己方有利的版本结算 (P000752)。
- **争议焦点**：两份合同中未备案的那一份，是否与备案合同构成"黑白合同"？备案与否是否就是效力分水岭？(P000752)
- **裁判要点**：湖州中院判定：两份合同虽仅一份备案，但在工程范围、价款、质量、工期等主要内容上**并无实质性差异**，不构成法律意义上的黑白合同；两份合同均系真实意思表示、不违反禁止性规定、不损害第三人权益，均合法有效——结算按合同约定正常进行，不触发"以白废黑"的强制规则 (P000752)。
- **实务教训**：判定黑白合同的核心是"实质性背离"而非"是否备案"——备案只是行政监管动作，未备案的补充协议若仅是对细节的微调补充、不动四大要素，不触发无效规则；商务人员签补充协议时的自检清单即"四要素不动"（价款、工期、质量、范围）。本案的另一层价值在于给发包方提了个醒（本研究归纳）：以"未备案"为由主张对方合同无效的投机主张，法院不买账——效力之争回到实质差异的证明，而实质差异的举证远比"翻出一份没备案的协议"艰难。

### 1.4 判例二：结算阶段大幅削减价款被穿透认定黑合同

**——（2021）鲁02民终13864号，山东省青岛市中级人民法院（陈文平与李宛增等）** (P000752)

- **案情**：陈文平与李宛增等的工程进入结算阶段，当事人提交一份私下签署的结算文件，对原中标合同约定的工程价款大幅削减，致最终结算价格**低于施工方的实际施工成本**；施工方诉至法院请求按中标合同结算 (P000752)。
- **争议焦点**：竣工结算阶段签署的大幅削减价款协议，是否构成违法"黑合同"？(P000752)
- **裁判要点**：青岛中院认为：当事人提交的结算文件对工程价款进行了大幅度削减，导致价格低于实际成本——此行为与通过签订"阴阳合同"（黑白合同）降低中标价款在实质上无异，应认定成立"黑白合同"——削减价款的私下协议无效，应按中标合同结算 (P000752)。裁判的穿透技术值得细品（本研究归纳）：法院没有停留在"结算协议系自愿签署"的形式面，而是以**价格与成本的关系**为试纸——低于成本的"合意"必然背离真实意思，其背后必有不正当压力；这与显失公平制度的逻辑相通，但打击面更精准：不问主观状态，先看客观价差。
- **实务教训**：发包方勿试图以事后"大幅让利结算协议"压款——**低于成本的削减协议将被穿透认定**为变相黑合同；对承包方的对称提示：已签此类协议的，收集优势地位强迫压价与结算价低于成本的证据（成本测算报告、同期市场价对照），主张协议无效、恢复按中标合同结算；本案把"低于成本"立为客观化的试纸，等于给所有结算谈判划出了一条不可逾越的底线——让利可以，让到成本之下就是无效（本研究归纳） (P000752)。

### 1.5 判例三：套取工程款的虚假合同无效

**——（2022）湘07民终2182号，湖南省常德市中级人民法院（湖南草字头生态环境建设与湖南顺昌建筑）** (P000752)

- **案情**：湖南草字头生态环境建设公司与湖南顺昌建筑公司签订建设工程分包合同，双方在履行中发生工程款结算争议；经法院审查发现，双方私下签订案涉合同的真实目的是**套取工程款**，且合同签订后并未实际按约履行 (P000752)。
- **裁判要点**：常德中院认定：当事人签订案涉合同是为了套取工程款而没有实际履行，该行为不具有正当目的，应认定构成"黑白合同"情形——私下合同归于无效 (P000752)。本案与判例一的对照构成"目的检验"的两极（本研究归纳）：同样是不涉实质差异的两份文件，一个有真实施工履行作底、均有效，一个以套取资金为目的、全无效——**有没有真实的工程履行，是合同效力的最终试金石**。
- **实务教训**：施工合同必须具有真实施工背景——借合同套取资金、补贴或偷逃税款的，将被认定恶意串通或虚假表示而无效，还可能牵出行政与刑事责任；"未实际履行"在司法审查中是显性信号：无人进场、无施工记录、无付款轨迹的"合同"，其效力审查必然滑向目的正当性的拷问——与判例一的"真实履行保效力"合并记忆：**履行是效力最好的辩护，空转是无效最铁的指控**（本研究归纳） (P000752)。

### 1.6 判例四：通用条款的程序性强硬约束（工期断面）

**——（2011）滕民初字第1592号，山东省滕州市人民法院（滕州香江信雅大饭店与北京百合建业），裁判日期2013年12月20日** (P000705)

- **案情**：2009年6月28日，滕州香江信雅大饭店与北京百合建业签订《香江信雅大饭店9层、10层客房装修改造工程协议书》，工程内容涵盖拆除工程、土建工程、给排水、消防、中央空调、电器安装工程，价款暂定3000000元、工期80天；合同通用条款对工程变更、工期延误（第11.1、11.2、13.1、13.2条）、工程质量（第15.1、16.2条）、竣工验收（第32.1至32.8条）及违约责任（第35.1、35.2条）作了体系化约定。履约中原告主张被告施工严重超期且质量低劣，诉请赔偿损失1387652.65元；被告辩称系原告未按时拨付工程款、合同外增加工程量以及停水停电导致工期顺延（P000705）。
- **争议焦点**：施工过程中因工程变更、停水停电及进度款支付延误导致的工期顺延与追加价款责任归属，以及通用条款的效力约束 (P000705)。
- **裁判要点**：法院严格对照通用条款审理：依第13.1款，发包人未按约定支付进度款、设计变更和工程量增加、一周内非承包人原因停水停电累计超8小时等情形，经工程师确认工期相应顺延——被告主张的三类顺延事由（欠款、增量、停水停电）逐一对照认定；依第32.8款，工程未经竣工验收或未通过验收发包人不得使用，**发包人强行使用的，发生的质量问题由发包人承担责任**；再依第35.1、35.2条违约责任条款，对原告1387652.65元损失诉请与双方责任作了切割 (P000705)。
- **实务教训**：示范文本通用条款关于签证、索赔与工期顺延的程序性约定（限期书面报告、限期答复）具有强硬约束力；本案放在黑白合同章的意义在于其反面印证——**条款本身不是黑合同，违反条款的程序才致命**：变更与索赔必须踩着通用条款的时点与书面形式走，否则实体权利随程序失权（本研究归纳） (P000705)。

### 1.7 实务防控三步法（本研究设计）

1. **签约前一致性审查**：拟签合同与招标文件、投标文件逐条比对，四要素完全一致；严禁中标合同外的让利、垫资、赠送"抽屉协议"——此类协议法律上无效，商业目的落空还埋雷；对发包方，"抽屉协议"换来的让利在结算时会被判例二式的穿透打回原形——省下的钱终归要还，还搭上诉讼成本（本研究归纳） (P000751, P000752)。
2. **履约中变更合规把关**：补充协议须以真实设计变更、签证为据，计价严格循原中标合同的计价方法；禁止借补充协议把固定单价整体改为定额按实结算等计价体系根本置换 (P000752)。
3. **结算阶段依据锁定**：以中标通知书、招投标文件、备案合同及合法签证为唯一计价依据；对"二次大幅削减协议"（尤其低于成本价）坚决拒签——已签的按判例二路径主张无效，举证重点是"低于实际成本"与"优势地位强迫"两组证据，前者可借造价咨询成本测算固定（本研究设计） (P000752)。三步法的位置感：第一步在签约桌、第二步在履约中、第三步在结算谈判——黑白合同的攻防全在合同 lifecycle 的三个节点上，错过节点再补救的成本以诉讼计（本研究归纳）。

## 第二节 合同无效后的折价补偿：计价标准选择

### 2.1 从"恢复原状"到"参照约定"的规则重塑

民法传统上无效合同的后果是返还财产、折价补偿（通则规则，本研究概述）；但施工合同的特殊性在于履约过程即把人工、材料、机械物化附着于发包人的土地与建构筑物——拆除返还等于毁掉双方的全部投入，"恢复原状"在建设工程语境里是双输的代名词 (P000717)。这也是折价补偿规则只能前行、不能回退的物理原因：法律不得不面对"楼已经盖在那儿"的事实（本研究解读）。2004年司法解释之前，部分法院对无效合同简单套用定额重新鉴定组价，导致无资质方在合同无效后反而拿到高于有效合同约定的价款——"违法者反而获利"的悖论 (P000752)。矫正之道即"参照合同约定折价补偿"：合同无效但竣工验收合格的，承包人请求参照合同约定支付工程价款的，应予支持（资料库实证见判例九的裁判援引） (P000707)。折价补偿款的法律性质是对物化劳动的价值补偿，而非有效合同的履行利益 (P000717)。

2026年《建工解释二》第十二条再进一步——其立法史意义在于把裁判实践中长期存在的"折价补偿协议独立有效"经验（本章判例五、六、七均系解释出台前的判决，与条文规则一致）升格为明文规则 (P000717)。条款原文（转引） (P000717)：

> "建设工程施工合同无效，建设工程质量合格，发包人和承包人就折价补偿款达成协议，一方当事人主张按照该协议确定双方权利义务的，人民法院依法予以支持。发包人、承包人与接受转包或者违法分包的单位或者个人就折价补偿款达成协议，参照前款规定处理。"

其核心是把无效合同的折价补偿这一法定后果**契约化**——补偿协议独立于原无效合同，具有法律约束力 (P000717)。解读文章概括其条文主旨：在工程质量合格的前提下，发包人与承包人之间就折价补偿款达成的协议，独立于原无效施工合同、具有法律效力——无论原合同因何种原因无效，协议的效力都不受牵连；第二款把同样的效力扩展到"发包人、承包人与接受转包或违法分包的单位或个人"的三方协议——这正是第3.7节三方收口机制的规范支点 (P000717)。

### 2.2 计价标准的三重博弈

折价补偿的计价选择不是抽象的法理之争，而是每单争议都要现场对表的三选一——承包人想抛低价合同奔定额，发包人想按更低的市场价评估，而裁判的主流立场是回到双方签过的那份协议。三重博弈的格局如下（本研究归纳自裁判谱系）：

```
┌─────────────────────────────────────────────────────────────┐
│ 折价补偿计价标准三重博弈（本研究归纳自裁判谱系）             │
├─────────────────────────────────────────────────────────────┤
│ ① 按政府定额重新组价 ──► 原则否定：防违法者因无效反而多拿   │
│ ② 按市场价评估折价 ────► 严格限定：约定缺失/显失公平/      │
│                          需核算物化成本三条件齐备           │
│ ③ 参照原合同约定 ──────► 主流原则：单价/包干/取费参照，     │
│                          让利折扣同比例扣减                 │
└─────────────────────────────────────────────────────────────┘
```

1. **定额计价的原则否定**：承包人主张"合同无效则低价条款失效、回归定额"的逻辑被司法一致拒绝——若允许因无效改按较高定额结算，将激励低价中标者主动主张无效套取差价；原约定有明确计价依据（固定单价、总价、清单）的，不启动定额重鉴（裁判立场归纳自语料与论文） (P000752)。定额的用武之地只剩两处：原合同计价方法完全空白、或施工图纸大幅变更致原计价依据丧失参照基础——此时定额作为鉴定确定物化成本的辅助参考，而非重算整案的引擎（本研究归纳） (P000752)。
2. **市场价的严格限定**：仅在原计价约定缺失或无法查清、约定严重显失公平无法补正、且质量合格确需核算物化成本时适用——三条件是并列的门槛而非任选；鉴定以施工时当地市场信息价为基准，扣减未实际发生的管理费与利润，就直接物化的人材机成本折价（归纳自论文与语料） (P000752)。市场价路径对承包人的诱惑在于"信息价常高于合同价"，但扣减管理费利润后的净额未必占优——选择计价路径前先做两口径试算，是造价工程师在无效案件里的第一件事（本研究实务建议）。
3. **参照约定的主流原则与折扣扣减**：原合同的单价、包干幅度、取费标准及让利承诺在折价计算中均有约束力——原约定定额基础上下浮12%的，折价时在核算基准价中等比例扣除12%；规则背后是"任何人不得从违法行为中获得高于合法行为之利益"的公平原则（归纳自论文与语料） (P000752)。折扣扣减的攻防在鉴定环节最易失守：鉴定人埋头算量组价，常把让利条款漏在基准价之外——收到鉴定初稿的第一件事即核对折扣是否同比例扣除（本书鉴定章十维质证的维度六在此复用）（本研究跨章归纳）。

### 2.3 中标无效下黑白合同均无效的结算分流

必须招标项目因串标、明招暗定等致中标无效时，白合同与黑合同均无效。此时参照哪份折价？裁判路径已从机械套白合同演进为**回归真实履行**（归纳自论文） (P000752)：双方实际按黑合同履行的（进度款核算、签证变更、施工指令均依黑合同执行），参照黑合同计价折价；实际按白合同履行的，参照白合同；事后达成折价补偿协议的，协议依第十二条直接取代原黑白合同成为最终依据 (P000717)。

"真实履行"的判定证据（本研究归纳）：进度款的计算口径（按哪份合同的单价报的）、签证单的引用依据（援引哪份合同的条款）、往来函件的措辞（以哪份合同自称）——履约的纸面轨迹会诚实地记录双方心中"真正算数的那份合同"；诉讼中争"参照哪份"，先把这些履约证据排成时间线，答案往往自明。

### 2.4 判例五：实际施工人的补偿协议独立有效

**——（2026）川20民终389号，四川省资阳市中级人民法院（唐某与某甲公司）** (P000717, P000718)

- **案情**：2022年1月，某丁公司与某甲公司签订《输变电工程专业分包合同（土建）》，将输变电工程的基础部分专业分包给甲公司；唐某主张其借用第三人某乙公司及某丙公司名义，与甲公司就上述分包工程签订《工程劳务分包合同》及《工程劳务派遣协议》。2023年1月，甲公司与某乙公司、唐某签订《土建部分的补偿协议》；同时，甲公司与唐某**个人**签订《组塔架线部分的补偿协议》。因工程款纠纷，唐某以实际施工人身份诉至法院，要求甲公司支付案涉工程款 (P000717)。
- **裁判要点**：资阳中院认定：唐某系案涉工程实际施工人，具有适格原告资格；《土建部分的补偿协议》系某甲公司与某乙公司、唐某共同签订，权利主体是某乙公司与唐某而非唐某个人——因涉及第三人某乙公司的利益且存在尚未结清的款项，法院不予直接支持；《组塔架线部分的补偿协议》系唐某（挂靠第三人某丙）以个人名义与被告所签，应直接约束唐某与被告——**该补偿协议作为双方的清理结算协议，应推定为对之前付款行为作出了统一结算处理**，系双方真实意思表示，对双方具有约束力——判令其按协议支付尚未结清的款项 (P000717)。
- **实务教训**：其一，实际施工人应争取与相对方**单独签署**书面补偿协议——协议独立于无效合同，直接成为诉请依据，免入造价重鉴泥潭；其二，协议的**主体签署形式决定权利归属**——以个人签的归个人，连同他人签的涉他人利益，本案两份协议两种命运即其教材；其三，该案系解释二出台前的判决却与第十二条规则完全一致——裁判实践先行、司法解释追认的演进路径，意味着即便旧案新审，独立补偿协议的效力预期也是稳定的（本研究归纳） (P000717)。

### 2.5 判例六：主合同无效不牵连补偿协议

**——（2018）最高法民终117号，最高人民法院（某建设公司与某房产公司）** (P000717, P000718)

- **案情**：2013年1月，某建设公司与某房产公司签订《建设工程施工合同》，约定承包某房屋建筑工程、采用固定单价结算；后该合同因违反招标投标法律强制性规定被认定无效。履约期间的2014年8月，因发包人方案调整、施工设计图变更及延期开工造成承包人经济损失，双方先后签订《建设工程补偿协议书》《开工延误、误工、保证金利息补偿认定单》《设计变更补偿协议书》——涉及工程款支付、延期开工损失、设计变更补偿款、误工损失补偿款、保证金利息损失等多项争议；发包人主张主合同无效则上述补偿协议随之无效 (P000717)。
- **争议焦点**：主施工合同因违反招标投标法律被认定无效，履行中因方案调整、设计变更、延期开工等事由签署的各项补偿协议是否随之无效？工程款的支付是否以竣工验收合格为条件？ (P000717)
- **裁判要点**：最高法院终审判定：主合同虽无效，但双方其后签订的《补偿协议书》及各类补偿认定单系针对方案调整、设计图纸变更、延期开工、停工误工等事由达成的补偿协议，其内容虽与施工合同存在关联，**并不是施工合同的从合同**；补偿协议不存在违反法律法规强制性规定的内容，合法有效，甲公司应按补充协议约定履行补偿赔偿义务——且工程款支付不以工程竣工验收合格为条件，发包人应以支付工程款的形式偿付承包人的投入 (P000717)。
- **实务教训**："主无效从有效"的关键在于协议的**独立性表述**——以独立事由（变更、误工、保证金利息）为内容、以独立签署为形式；从合同的无效以"从属性"为前提，而补偿协议对号入座地切断了从属性：它不担保主合同履行，而是清理主合同的后果。主合同存效力瑕疵的项目，应通过独立补偿协议把索赔与折价标准契约化——最高法院对这类协议的效力保护是坚定的（本研究归纳） (P000717)。此外，该案还有一层常被忽略的规则：工程款支付不以竣工验收合格为条件——发包人应以支付工程款的形式偿付承包人的投入（裁判要旨原意），这与"质量合格是折价前提"的一般规则并行不悖：前者针对已物化投入的清偿，后者针对折价请求权的成立（本研究解读） (P000717)。

### 2.6 判例七：停工补偿协议的再审全额支持

**——（2023）皖民终595号，安徽省高级人民法院（某工程公司与某置业公司）** (P000717, P000718)

- **案情**：某工程公司与某置业公司因工程款支付、停工补偿及违约金等事项发生争议：承包方主张发包方拖欠工程款及停工损失，要求支付相应款项及利息、违约金并享有优先受偿权；发包方则对工程款数额及停工补偿协议效力提出异议，主张部分款项已支付且停工责任不在己方；案件经一审判决、**检察机关抗诉后再审**，至安徽省高级人民法院终审 (P000717)。
- **裁判要点**：安徽高院综合双方诉辩意见确认：再审一审判决对工程价款的认定及支付情况基本准确，依法确认甲公司已支付工程款总额及欠付金额；认定**停工补偿协议合法有效**，赔偿损失数额合理、利息及违约金计算方式无明显不当；对部分付款明细及债务转让协议存在异议的，因证据不足不予采纳——最终全额支持协议项下的补偿 (P000717)。
- **实务教训**：合同无效背景下自行达成的补偿协议，只要数额合理、无胁迫显失公平，连抗诉再审都撼不动——协议是对无效后果的自行处分，法院完全尊重；对承包方，这份"雷打不动"正是把停窝工损失契约化的最好理由；对发包方，该案同时提示协议的**证据配套**同样重要——法院对已付总额与欠付金额的确认，依托的是付款明细的完整举证，付款凭证缺失的部分连协议都救不回来（本研究归纳） (P000717)。

### 2.7 判例八至十：无效折价的三个反面样本

三个反面样本分别踩中折价补偿的三条暗礁：授权之礁（表见代理不成立）、参照之礁（低价协议如影随形）、前提之礁（未开工无物化）——正面规则在暗礁处折返的形状，恰是规则本身的轮廓（本研究归纳）。

**判例八：越权转包不构成表见代理，折价追偿落空**——（2013）苏民终字第0181号，江苏省高级人民法院（江苏浩辉与浙江申盛，原审（2012）宿中民初字第0064号） (P000702)

- **案情**：2011年4月17日，案外人陈如爱以浙江申盛建筑公司滨河花园项目部名义，与宿迁东胜公司签订施工合同，约定将申盛公司承建的滨河花园2#、4#、5#楼土建、水电、门窗安装工程包工包料转包（工程造价约7000万元、500万元定金条款）；陈如爱系申盛公司滨河花园项目部办公室主任（关联（2013）泗民初字第0016号裁定认定）；项目初期负责人倪建庆因非法吸收公众存款，被泗阳法院（2012）泗刑初字第0615号刑事判决判处有期徒刑四年二个月并处罚金12万元；江苏浩辉公司（东胜公司更名）诉请申盛公司支付工程款并返还双倍保证金。- **争议焦点**：无资质非法转包与项目部人员越权出具借据、签单下，原告能否主张折价补偿及相关债务的约束力 (P000702)。
- **裁判要点**：江苏高院二审认定：倪建庆将申盛公司承建的工程全部违法转包，陈如爱等人的行为超出授权范畴，浩辉公司未尽到审慎注意义务、**不构成表见代理**；违法转包合同绝对无效，申盛公司对无授权的私下借款及转包协议不承担赔偿责任——维持原判驳回 (P000702)。- **实务教训**：违法转包链条中，勿仅凭项目部公章或人员签字就签转包协议与资金借据——主从合同双无效且无表见代理时，折价追偿将彻底落空；与本书签证章"授权外衣三件套"的表见代理判例对照，**链条越违法，外衣越要厚**——合法交易中一枚项目章足以表见，违法链条中连刑事判决加持的负责人身份都未必够（本案项目初期负责人获刑、办公室主任经办，仍被认定越权）；本案还叠加了刑事交叉的背景（非法吸收公众存款判决），提示转包链条的资金往来极易滑向刑民交叉的深水区，签约前的背景核查应包含对经手人职权与项目资金脉络的穿透（本研究归纳） (P000702)。

**判例九：内部承包实为转包，参照原约定折价**——（2009）杭西民初字第2888号，杭州市西湖区人民法院（励进与广厦建设集团有限责任公司舟山分公司），裁判日期2009年12月21日 (P000707)

- **案情**：原告励进系未取得建筑施工企业资质的个人，与被告广厦建设集团舟山分公司签订《工程项目内部承包协议》承包相关工程；履约后双方因工程款结算涉诉 (P000707)。
- **争议焦点**：个人签订"内部承包协议"的法律性质与合同无效后的折价结算依据 (P000707)。
- **裁判要点**：西湖区法院认定协议法律性质属违法转包，依司法解释第一条（无资质）认定无效；工程竣工质量合格，**参照原协议约定的计价取费标准折价补偿结算** (P000707)。- **实务教训**："内部承包"的名头挡不住转包的认定——名为内部承包、实为无资质个人承包工程的，依司法解释认定无效；无资质个人勿幻想合同无效后改按定额全额索赔——**参照的正是你签过的那份低价协议**：下浮率、取费标准、计价方法一项不少地跟着你走。对出借名义的企业端，本案与判例十二共同划出责任曲线：分公司签的协议、总公司担的责任——"内部承包"省下的管理成本，最终以连带清偿的形式连本带利归还（本研究归纳） (P000707)。

**判例十：未开工的无效合同只退保证金**——（2017）皖0304民初1968号，蚌埠市禹会区人民法院（朱小林与淮南市敏青建筑装饰工程公司），裁判日期2017年12月7日 (P000706)

- **案情**：朱小林与敏青公司签订施工合同并缴纳履约保证金；敏青公司未能按承诺安排朱小林进场施工，合同无法履行，朱小林起诉请求确认合同无效并返还保证金 (P000706)。
- **争议焦点**：施工合同无效且工程未实际开工时，保证金返还与损失赔偿责任 (P000706)。
- **裁判要点**：法院认定因承包人无资质致合同无效；因**工程未实际开工，不产生折价补偿问题**——敏青公司因无效合同取得的履约保证金应全额返还并承担利息损失 (P000706)。- **实务教训**：折价补偿以物化为前提，未开工的无效合同走"返还＋过错赔偿"通道——保证金全额返还并计息；对发包方的对称提示：收保证金而不安排进场的"空手套"式发包，无效之后返还的是本金加利息，商业计划全盘落空——无效合同的代价从来是双向的（本研究归纳） (P000706)。

### 2.8 实务防控三步法（本研究设计）

1. **效力诊断与参照底数锁定**：结算争议初起即排查效力瑕疵（资质、招标、转包——本书第2章第3至6条规则群即其清单），同时梳理原合同的计价底数（单价表、清单、下浮率）——无效来临前先知道"参照的是什么"；诊断的产出物是一张**效力风险清单**：每项瑕疵对应的最坏后果（无效/部分无效/可撤销）与相应参照基准，让后续谈判与诉讼始终踩在已知的地形上 (P000752)。
2. **用第十二条签独立补偿协议**：竣工或停工清退时（关系尚可谈判的窗口期）签书面《折价补偿协议》，载明质量合格确认、最终包干金额、原合同纠纷一次性终结条款——协议独立有效，斩断事后翻悔与造价重鉴；协议文本的三道保险（本研究设计）：①"本协议系双方就折价补偿款达成的最终独立结算协议"的定性句（对照第十二条文义）；②质量合格的明示确认（折价权的成立前提）；③一次性终结与违约金条款（翻悔的成本威慑） (P000717)。
3. **鉴定防御与折扣扣减**：对方申请定额重鉴的，书面异议强调原约定计价明确、必须参照——异议书的锚点是"固定单价表/清单/下浮率"这些实打实的计价依据，而非抽象的公平口号；鉴定初稿核查让利折扣是否同比例扣除，未扣除的立即提交书面更正请求（本研究设计） (P000752)。三步法的时序同样是前移的：效力诊断在争议萌芽期完成，协议签署在关系可谈时完成——等诉讼开打再想签协议，对手已无动机（本研究归纳）。

## 第三节 实际施工人直接诉权与结算敞口防范

### 3.1 双层级结构与效力切割

多层级施工结构呈"双层级合同"（框架归纳自论文） (P000715)：第一层级——发包人与总承包人（被挂靠企业）的施工合同，**原则上有效**：转包违法分包多发生在履行阶段，不能以履行的违法倒推成立时无效；除非发包人明知或积极追求转包挂靠，构成恶意串通损害公共利益而无效。第二层级——总包与转包人、违法分包人、实际施工人的转包/分包/挂靠协议，违反建筑法禁止性规定，**一律绝对无效** (P000715)。

效力切割的实务含义——两层合同两层账（本研究归纳）：发包人不能以"总包转包了"为由主张第一层级合同无效来逃避付款义务——合同有效则按合同付款；反之，实际施工人也不能借第二层级无效去撼动第一层级的结算框架——第二层级的无效只在总包与实际施工人之间发生折价补偿效力。两个层级各算各的账，这正是第3.2节"三重风险"得以防范的法理基座。

"实际施工人"的排他性范畴（归纳自论文与语料） (P000715)：仅指非法转包的受让人、违法分包的承包人、无资质借用资质的挂靠人；**合法分包承包人、劳务分包承包人、材料供应商、设备租赁商、普通劳动者均不属之**，不得直接起诉发包人。

### 3.2 直接诉权的法定条件与三重风险

实际施工人跨层级起诉发包人须满足（条件框架归纳自论文与语料） (P000715)：前手合同关系停滞或怠于主张权利；发包人对总包尚存欠付工程款；责任以欠付金额为限（已付清则不担责）；法院应追加转包人/违法分包人为第三人或共同被告查明事实。

实际施工人跨层级起诉发包人的四项法定条件（条件框架归纳自论文与语料） (P000715)：其一，**前手停滞或怠于主张**——转包人破产、解散、下落不明或明示拒绝索款，实际施工人的物化对价陷入无法清偿的绝境；其二，**发包人尚存欠付**——发包人享有工程合格的物化利益而未结清总包款；其三，**限额担责**——发包人对实际施工人承担的并非连带责任，而是以其对总承包人欠付的工程价款为最高限额，已付清或超付的不担责；其四，**追加中间方**——法院应追加转包人/违法分包人为第三人或共同被告查明造价与已付事实，不得缺席裁决发包人付款。四条件的举证分工（本研究归纳）：条件一由实际施工人证（前手失灵的事实）、条件二三是法院依职权查的重点（欠付数额）、条件四由程序保障——实际施工人起诉时主动申请追加中间方，既是配合查明，也是防判后"事实不清发回"的程序自觉（判例十一的三道程序即其反面成本）。

发包方与总包方随之面临三重风险（框架为本研究归纳） (P000703, P000706, P000715)：**重复诉讼与双重支付**——已付清总包款但凭证瑕疵，或被挂靠人截留款项致实际施工人不认总包付款效力；**结算敞口与重鉴风险**——实际施工人未签主结算协议，主张发包总包恶意串通压价、申请按定额重鉴击穿包干价；**超付与质量追偿悬空**——直接付款后实际施工人退场，质保金扣减与缺陷追偿两头落空。三重风险的共同根源是**信息不对称**：发包人看不见总包与实际施工人之间的结算，实际施工人看不见发包人与总包之间的付款——第3.7节的三个机制（报备核销、共管直拨、三方协议）本质上都是打通信息墙的工程（本研究归纳）。

### 3.3 判例十一：欠付事实举证不能则直诉不获全额支持

**——（2017）辽0212民初1805号，大连市旅顺口区人民法院（何海波与大连安泰安连分公司、大连安泰、解放军92060部队、大连万盛公司），原审（2016）辽0212民初3063号、发回裁定（2017）辽02民终3689号，裁判日期2017年12月20日** (P000703)

- **案情**：何海波作为实际施工人，承接中国人民解放军92060部队发包、大连万盛房地产公司参与、大连安泰建设公司安连分公司及大连安泰建设公司承包链条下的工程施工任务；一审起诉请求四被告共同支付拖欠的工程款及利息，旅顺口区法院作出（2016）辽0212民初3063号判决，何海波不服上诉；大连中院以（2017）辽02民终3689号裁定认定原判事实不清，撤销原判发回重审 (P000703)。
- **争议焦点**：实际施工人跨层级向发包方及总包方主张工程款时，欠付工程款事实与具体金额的举证责任如何分配？发包人与总包未完成最终结算时直诉的边界何在？（依判决争点归纳） (P000703)
- **裁判要点**：重审认定：实际施工人向发包人主张权利，必须严格举证证明发包人对总承包人存在欠付工程款的事实以及具体欠付金额——举证的颗粒度要到"欠多少、凭什么说欠"；在发包人与总包尚未完成最终竣工结算或已付清主合同款项的情形下，直接要求发包人付款的诉请无法获全额支持；实际施工人应首先向与其建立直接合同关系的转包方或被挂靠方主张结算清偿 (P000703)。
- **实务教训**：跨层级起诉前先"审计先行"——调取主合同付款凭证或申请司法审计锁定欠付精确数额；发包人已足额付款的，直诉将被驳回；本案历经一审、上诉发回、重审三道程序才把"欠付事实"的举证责任说清，程序成本本身就是教训的一部分。对发包方的对称教训：**付款凭证的完整归档就是最好的防御工事**——凭证链完整则直诉无门，凭证链残缺则解释成本高企（本研究归纳） (P000703)。

### 3.4 判例十二：挂靠链条的三方责任划分

**——（2016）吉0202民初1343号，吉林市昌邑区人民法院（吉林尚峰钢结构与吉林耿屯粮食、张文彪、吉林凇汇建筑安装），裁判日期2017年12月25日** (P000703)

- **案情**：吉林市尚峰钢结构公司作为实际施工人，承建耿屯粮食经销公司发包、张文彪经手、吉林凇汇建筑安装公司被挂靠的钢结构厂房工程；工程完工后，各方对工程造价结算金额及欠付款项数额分歧严重，尚峰公司将发包方与张文彪（第三人）、被挂靠的凇汇建筑安装企业一并诉至法院，请求连带支付工程款及利息 (P000703)。
- **争议焦点**：违法分包与挂靠链条下，发包方、被挂靠企业与实际施工人之间的折价补偿责任如何划分 (P000703)。
- **裁判要点**：法院认定施工合同因违反资质管理规定归于无效；工程质量合格的，参照原合同约定折价补偿；在发包方耿屯粮食公司尚未向凇汇公司全额结清工程款的范畴内，判令耿屯公司对尚峰公司的工程折价补偿款承担**有限支付责任**；第三人张文彪与被挂靠的凇汇建筑安装企业对欠付工程款承担直接清偿与连带责任 (P000703)。
- **实务教训**：被挂靠企业出借资质收"管理费"是高风险生意——合同无效、管理费不保，还要对实际施工人工程款承担连带清偿；发包方的责任有欠付限额的天花板，但举证责任在自己——本案三方各得其所的根源，是法院把三方证据都摆到了明处（本研究归纳） (P000703)。对挂靠链条的责任地图，本书第2章第3至8条的规则群（借用费全链条剥夺/明知分水岭/表见代理/代位权转导）与本节的裁判谱系互为印证——2026年解释二施行后，被挂靠方的风险只增不减（本研究跨章归纳）。

### 3.5 判例十三：司法所终止协议的扣减支持

**——（2017）闽0212民初3481号，厦门市同安区人民法院（何方元与张拥仪），裁判日期2017年12月18日** (P000706)

- **案情**：2016年8月22日，张拥仪与无资质的何方元签约，由何方元承建厦门市同安区西洪塘坂下里49号房屋，约定单价与工期；施工后张拥仪累计支付进度款118500元（何方元主张仅收到112000元——收付款之争埋下伏笔）。因何方元拖延工期且工程存在质量缺陷，双方于2017年5月11日在祥平司法所主持下达成《工程合同终止协议书》，约定终止合同并委托第三方张保建对未完工程量进行评估；评估未完工程量为26000元后，何方元反悔起诉索要尾款26933.8元；张拥仪提起反诉，要求退还多付进度款22143.6元（含保修金10000元）、赔偿逾期租金损失51477元及公证费6000元（合计85620.6元） (P000706)。
- **裁判要点**：法院认定何方元无施工资质、合同绝对无效；**司法所主持达成的《工程合同终止协议书》系双方真实意思表示、合法有效**——终止协议不因主合同无效而失效；对张拥仪雇请他人修复质量缺陷支付的返工工资3600元及扫尾工资35000元予以确认；何方元逾期施工130天构成违约，结合实际情况对张拥仪主张的租金损失、公证费与返还多付工程款请求作了裁决扣减 (P000706)。
- **实务教训**：与无资质实际施工人终止合同时，走司法所/调解委员会程序签书面终止协议，锁定已完工程量与未完退款；协议约定的瑕疵返修费与逾期损失扣减将获坚定支持——第三方主持本身就是协议效力的加固件；本案的细节还示范了协议的配套动作：委托第三方评估未完工程量（26000元）、雇请他人修复并留存工资凭证（返工3600元＋扫尾35000元）——协议＋评估＋凭证三件套，让一场本可能缠讼数年的纠纷一次算清（本研究归纳） (P000706)。

### 3.6 判例十四：总包对项目部分包监管不力的清偿责任

**——（2010）门民初字第0061号，海门市人民法院（陆进超与成庙生、江苏南通三建），原审（2009）门民一初字第1209号、发回后重审，裁判日期2010年12月12日** (P000707)

- **案情**：陆进超作为实际施工人与成庙生、江苏南通三建集团发生分包合同纠纷；海门法院2009年8月20日作出（2009）门民一初字第1209号判决，陆进超上诉后南通中院2009年12月7日裁定撤销原判发回重审，海门法院另组合议庭重审 (P000707)。
- **争议焦点**：违法分包链条中总承包企业与转包人对实际施工人工程款及利息的责任形态 (P000707)。
- **裁判要点**：重审认定成庙生将南通三建承建的项目违法分包给无资质的陆进超，分包合同无效；南通三建作为施工总承包企业**对项目部监管不力**，在未结清工程款范围内对陆进超承担折价补偿支付责任；成庙生作为违法分包人对欠付工程款及利息承担直接给付责任 (P000707)。- **实务教训**：总包企业对项目部公章与项目经理的分包行为必须穿透监管——项目经理私下违法分包的，总包在欠付范围内直接对实际施工人清偿；"监管不力"四字在判决中的分量，是把分包风控从"项目部内部事务"升格为"总公司合同义务"——总分包管理制度的落实台账（分包审批记录、现场核查记录），在诉讼中就是"已尽监管"的证明（本研究归纳） (P000707)。与本书签证章的项目部印章案（椭圆形章表见代理）合并观察，总包端的风险画像完整成形：**章管不住，债躲不开**（本研究跨章归纳）。

### 3.7 结算敞口防范三步法（本研究设计）

1. **主合同设报备与核销条款**：开工前书面报备全部分包与实际负责人名册——名册是后续一切核销动作的底账；每期进度款支付以前一期已足额付至实际施工人的盖章凭证与银行流水为前提，未提供则暂停支付且不担违约——核销机制把发包人的付款义务与总包的转付义务捆绑联动，实际施工人拿不到钱，下一期的闸门就关不上（本研究设计） (P000717)。
2. **三方共管与穿透支付**：大体量或挂靠隐患项目设工程款专户（发包、总包、银行三方监管协议），人工费与实际施工人应得款由专户直拨其账户——资金轨迹本身就是最好的付款证据，判例十一的欠付之争在共管账户面前自动消解；每次拨款取得签字按印的《收悉与无争议承诺书》，载明已收期数、金额与"无争议、不跨级起诉"的承诺——承诺书与本书结算章的权利保留条款互为镜像：一方防的是过度主张，一方防的是权利流失（本研究设计）。
3. **第十二条三方折价补偿协议**：竣工结算邀请实际施工人共同参与对账——工程量、单价、变更签证、扣款金额三方现场确认，切忌发包总包私下二人结算把实际施工人晾在一边（那正是"恶意串通压价"抗辩的温床）；三方签署《折价补偿结算协议》——确认折价总额、尾款直拨实际施工人、发包人付款义务终结、实际施工人放弃直接诉权；依第十二条第二款，含实际施工人的三方协议同样获得独立效力保障 (P000717)。三步法的递进关系：报备核销管过程、共管直拨管资金、三方协议管终局——过程与资金是日常动作，协议是一锤定音；没有前两步的日常留痕，第三步的谈判桌上就没有筹码（本研究归纳）。

### 3.8 调解场景中的效力与折价定价（本研究实务指引）

效力争议进入调解，定价逻辑先于金额谈判（本研究归纳）：**第一步，效力预判**——双方各自亮出效力论据（招标程序、资质、转包链条），按本章规则请调解员作初步定性：合同有效则按合同谈折扣，合同无效则进入折价轨道——效力定性直接决定计价坐标系。**第二步，参照系对表**——有效合同按原约定对表；无效合同则按"原合同计价＋折扣扣减"对表，让利折扣在调解中同样要扣——把法院的裁判预期（判例九的参照原约定）摆上桌，比空喊"合同无效就该重算"有效得多；对表作业的产出物是一张双栏对照表：左栏按对方主张口径试算、右栏按裁判预期口径试算，两栏差额即谈判空间的货币化——调解桌上摆数字，永远比摆道理快（本研究归纳）。**第三步，第十二条收口**——调解成果以独立折价补偿协议落地（范本结构见第2.8节步骤二的三道保险），载明质量合格确认与包干金额——协议独立生效、免于事后翻悔与重鉴，调解的成果由此从"君子协定"升格为"法定契约" (P000717)；调解员的价值在效力争议中尤为突出：双方对"按哪份合同算"的分歧，往往因诉讼前景的不确定性而僵持——调解员以本章判例谱系给出裁判预期的区间（判例九的参照原约定即其下限、第十二条协议即其上限），区间一出，谈判空间自现（本研究归纳）。三方在场的，把实际施工人拉进协议——一份三方协议同时解决折价、直诉与付款核销三个问题（本研究归纳）。

## 本章小结要点

1. **黑白合同的认定**：核心是实质性变更——四大法定要素（价款、工期、质量、范围）加司法扩展要素（担保、付款节点、违约责任）；正当变更（设计变更签证、材料暴涨补差、事先准予变更约定）以"真实成因＋原计价程序"为豁免要件；无实质差异的双合同均有效、备案与否非标准（判例一），仅一份合同或无中标合同比照基准的不成立黑白合同（陕950号、鲁3774号情形），低于成本的结算削减与套取资金的虚假合同被穿透否定（判例二、三） (P000752)。
2. **白合同强制结算与穿透**：中标有效的必须招标项目强制以备案白合同结算（招标投标法第46条＋解释一第2条、第22条）；结算阶段低于成本的大幅削减协议将被穿透认定为变相黑合同而无效（判例二）；套取工程款的虚假合同同样无效（判例三）；通用条款的程序约束（顺延事由、强行使用担责）在效力之争外独立发挥作用（判例四） (P000705, P000751, P000752)。
3. **无效折价的计价规则**：质量合格参照合同约定折价补偿——折价款是物化劳动补偿而非履行利益；定额重鉴原则否定、市场价严格限定（三条件并列）、让利折扣同比例扣减——任何人不得因无效获利（判例九及裁判谱系）；未开工的无效合同无折价可言、只退保证金（判例十）；中标无效下黑白均无效时回归真实履行的合同计价（第2.3节） (P000706, P000707, P000752)。
4. **第十二条折价补偿协议的独立效力**：双方或含实际施工人的三方补偿协议独立于无效合同，真实意思即受保护——个人签的归个人（判例五）、独立事由的不受主合同无效牵连（判例六）、合理数额的抗诉再审不破（判例七）；工程款支付不以竣工验收为条件的要旨与质量合格系折价前提两条规则并行不悖；工程质量合格是绝对前提，不合格且拒不修复的丧失折价权 (P000717)。
5. **实际施工人直诉与敞口防范**：直诉四条件（前手停滞、欠付存在、限额担责、追加第三人）＋排他性主体范畴（合法分包、劳务分包、供应商、租赁商、劳动者除外）；欠付举证不能则直诉不全支持（判例十一），挂靠方连带清偿（判例十二），总包监管不力在欠付范围内担责（判例十四）；发包与总包的三重风险以三步法对冲——报备核销条款、三方共管直拨、三方折价补偿协议斩断诉权；效力切割（第一层级原则有效/第二层级绝对无效）是全部防范的法理基座（判例十一至十四） (P000703, P000706, P000707, P000715, P000717)。

使用本章的正确方式（本段为本研究使用指引）：签约时按第一节自查——招标文件、投标文件、合同三对照，四要素不动；补充协议以真实变更为据、按原计价方法调价，"抽屉协议"一律不签。合同可能无效的项目，趁关系未破裂按第二节签独立补偿协议——质量合格确认、包干金额、一次性终结三条款缺一不可，个人签约个人担、法人签约法人担；诉讼中守住"参照约定"的阵地，阻击定额重鉴，鉴定初稿先查折扣扣减。面对实际施工人，发包方按第三节三步法收口——名册报备、凭证核销、三方协议；作为实际施工人，则反向备战——锁定欠付证据、单独签署补偿协议、留存授权外衣。调解桌上按第3.8节三步走——效力预判、参照系对表、第十二条收口（本段为本研究使用指引）。

5. **跨时段样本的地域差异**：本章判例横跨2009至2026年、多地法院；实际施工人直诉的认定尺度存在地域差异（部分省高院解答对挂靠人直诉从严），实务应结合受诉法院辖区口径调整 (P000715)；本章三篇专题学位论文对判例的归纳各自成系，本研究以P000752为主要归纳源、另两篇（P000751、P000753）提供规范史与规则适用视角，三源互证后采用；论文中引述的个别案例（如陕950号、鲁3774号）未收判决全文，以"情形"定位并已随文标注。
