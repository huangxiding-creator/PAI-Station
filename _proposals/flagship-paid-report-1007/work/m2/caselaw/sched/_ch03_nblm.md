# 第3章 固定总价与总价包干争议：范围、调价与风险分担

本章旨在为工程造价工程师、商务经理、工程法务与建工律师解决固定总价与总价包干合同在履约与结算阶段最顽固、最高频的四类核心痛点：一是如何精准界定“总价包干”的合同范围边界，厘清施工图变更、发包方指令增加与原图纸/清单重大缺项漏项的补偿红线；二是在面对“包干合同原则上不予鉴定”的司法裁判铁律时，如何通过法定突破例外（如设计重大变更、合同中途解除、价格剧烈波动）依法重构结算逻辑；三是在遭遇合同解除或工程量削减时，如何运用《建工司法解释二》第十条的“按比例折算”规则进行造价还原与反失权辩护；四是在签约与履约阶段，如何搭建“总价包干 + 风险边界 + 变更调价机制”的闭环条款与动态签证防线。通过梳理最高人民法院及各级法院的司法判例谱系，本章将实务经验转化为可操盘、可复用的战术指引，助力工程实务人员在造价争议中守住利润与法律底线。

## 3.1 固定总价与总价包干的范围边界与补偿标准厘清

### 3.1.1 固定总价/总价包干的法律属性与风险分担边界

固定总价（又称总价包干）是建设工程施工合同中最为普遍的价格形式，其核心法律特征在于“总价包干、风险预分配、结算程序简化”[19]。在法律属性上，固定总价合同是发承包双方对工程建设成本、市场价格波动及一般性施工风险所作出的契约性风险分配[19]。然而，建工实务中普遍存在将“固定总价”误读为“绝对不调价”或“无条件包干一切”的认知偏误[18]。

司法裁判认定“总价包干”的风险边界遵循“包计价不包未定变更，包已知风险不包不可抗力/发包方过错”的基本原则[18]。具体而言：

1. **计价方式固定与工程量可调的分离**：固定总价固定的是合同订立时依据特定施工图纸、招标清单和技术规范所计算出的基准总价，而非对未来一切工程量变化的无条件封顶[19]。当发生发包方指令的变更、设计图纸重大修改或发包方原因导致的工程量增减时，包干的基础已发生颠覆，增减部分必须脱离原固定总价按实调整[05, 19]。
2. **风险分担的合理限度**：承包商承诺承担的风险仅限于签约时可合理预见的市场价格一般波动（通常为合同约定的5%-10%幅度内）及常规施工技术风险[11, 16]。若超出合理预见范围（如政策性重大调整、材料价格异常暴涨暴跌、发包方提供的地质勘察资料严重失真），强行要求承包商单方承担将违背民法典的公平原则与诚实信用原则[19]。
3. **合同文件的解释顺序与范围确定**：在认定包干范围时，裁判机关严格依据合同文件优先解释顺序（合同协议书、专用条款、通用条款、中标通知书、投标函及其附表、施工图纸、工程量清单）[08, 09]。当工程量清单与施工图纸不一致时，若合同未明确约定“以清单为准”或“以图纸为准”，司法实践通常认定图纸承诺的施工范围属于承包范围，但清单漏项部分的计价调整需结合发包方编制清单的责任归属确定[06, 08]。

### 3.1.2 施工图变更与发包方指令增加工程量的补偿计算

在固定总价合同履约过程中，施工图变更（设计变更）与发包方指令增加（现场签证/变更指令）是突破原固定总价最常见的法定事由[04, 05]。

#### 1. 施工图变更与发包方指令增加的补偿认定标准

发包方发出的工程变更指令或设计院出具的图纸变更通知，只要超出了原招标图纸或合同约定施工图的范围，即构成合同履约基础的变更[04, 05]。对此类增加部分的补偿计算，司法裁判标准如下：

- **合同有适用单价的**：直接套用合同约定的相应清单单价或综合单价乘以签证工程量进行追加计价[04]。
- **合同有类似单价的**：参照合同中类似的综合单价，结合变更工程的材料、工效差异进行换算调整[04, 19]。
- **合同无适用或类似单价的**：参照合同订立时工程所在地建设行政主管部门发布的定额标准、取费标准及市场指导价，编制补充综合单价；若合同约定了下浮率，增项部分通常须同比例乘以中标下浮率[04, 19]。

#### 2. 施工图变更与指令追加可执行操作步骤

为了确保施工图变更与发包方指令追加的追加价款能够成功进入结算，商务经理与造价工程师必须执行以下标准化操作步骤：

```
[步骤1: 变更指令识别与对比]
收到变更图纸/发包方指令后 3 个工作日内，对比原招标图纸与合同清单，标记增减工程量及技术要求变更点。
        │
        ▼
[步骤2: 成本与工期影响评估]
造价员编制《工程变更造价与工期影响评估表》，明确拟追加费用及需顺延的工期天数。
        │
        ▼
[步骤3: 及时提交书面变更意向与签证单]
在合同约定期限内（通常为 14 天），向发包方及监理工程师提交《变更工程量签证确认单》及《工程索赔意向通知书》。
        │
        ▼
[步骤4: 现场工程量三方见证与影像留存]
对隐蔽工程、拆除工程或新增隐蔽节点，联合发包方代表、监理工程师进行现场实测实量，签署见证记录并拍摄高清影像资料。
        │
        ▼
[步骤5: 签署补充协议或造价确认单]
推动发包方签署《工程变更价格确认单》或《施工合同补充协议》，明确变更计价口径及付款进度，防止拖延至竣工结算结算被拒。
```

#### 树子问 Q4：发包人提供招标清单存在缺项漏项，固定总价合同下能否索赔？

- **裁判规则拆解**：招标工程量清单是发包方编制并作为招标文件的组成部分。依据国家《建设工程工程量清单计价规范》的基本原则，发包人对其提供的工程量清单的准确性和完整性负责[06]。然而，在固定总价合同中，发包方经常通过专用条款约定“承包人已充分复核清单，清单缺项漏项均已包含在总价中”[05, 08]。
  - **情形A（合同有明确风险包干倒扣条款）**：若合同明确约定“本工程为图纸总价包干，工程量清单仅供参考，清单缺项漏项不予调整”，法院通常认定承包人作为专业施工企业，具有审查图纸与清单对应关系的专业能力，其未在投标阶段提出异议即视为接受风险，对清单缺项漏项不予支持追加[05, 08]。
  - **情形B（合同未约定或约定不明）**：若合同未明确将清单缺项风险划归承包人，或合同约定“按工程量清单包干”，则由于清单编制主体系发包方，因发包方编制原因导致清单项目漏项或工程量计算计算出现重大偏差的，承包人有权就缺项部分要求按实追加[06, 08]。

- **实务索赔可执行步骤**：
  1. **签约前对照盘点**：在投标阶段即建立《图纸与清单差异对比表》，对重大缺项漏项留存书面记录。
  2. **履约期书面澄清**：施工中发现清单缺项，立即向发包方及监理提交《清单缺项核定联系单》，说明缺项内容系施工图纸所必需但清单未列项。
  3. **锁定施工事实**：对缺项部分独立单列施工工程量签证，由现场监理及发包方代表签署确认实际工程量[08]。

#### 树子问 Q5：施工图纸本身存在设计重大缺陷或重大漏项，承包人按图施工或修正后增加的费用由谁承担？

- **裁判规则拆解**：设计图纸由发包方委托的设计单位编制，发包方依法对设计图纸的合法性、完整性及可施工性承担法律责任[04]。
  - 若原施工图纸存在重大设计漏项（如地基基础未考虑特殊地质处理、结构图纸漏配钢筋、消防系统缺失关键设备），导致承包人按图施工无法达到工程质量验收标准或发生安全事故，发包方必须承担由此增加的全部造价与工期顺延责任[04, 08]。
  - 承包人在施工中发现设计缺陷并履行了告知义务后，根据发包方或设计院出具的设计变更图纸进行施工的，增加的工程量一律认定为设计变更追加，原固定总价条款不得约束该增加部分[04, 08]。

- **实务索赔可执行步骤**：
  1. **图纸会审留痕**：在图纸会审与技术交底阶段，将图纸重大漏项写入《图纸会审纪要》，并由发包方、设计方、施工方、监理方四方盖章确认。
  2. **停止隐患施工**：发现重大设计缺陷可能危及工程安全的，立即书面通知发包方暂停相关部位施工，防止损失扩大。
  3. **追认变更签证**：取得设计单位出具的《设计变更图纸》或《技术核定单》后，方可开展新增工程施工，并及时办理造价签证[04, 08]。

#### 树子问 Q6：发包人指令变更与承包人自发优化/合理化建议增加费用的判定与补偿依据

- **裁判规则拆解**：
  - **发包人指令变更**：属于发包方单方意思表示的合同变更，具有强制约束力。只要承包人完成了指令变更内容并取得书面签证，发包方必须按照合同变更调价条款支付追加价款[04, 05]。
  - **承包人合理化建议/自发优化**：承包人在施工过程中提出的技术优化或方案变更，**必须以取得发包方及设计单位的书面确认/采纳为前提**[05]。若未经发包方书面书面同意，承包人擅自改变施工方案、提高建材标准或增加工程量，即使该优化客观上提升了工程质量，司法裁判一律认定为承包人的自发行为，对由此增加的造价不予支持[05]。若合理化建议经发包方书面采纳且合同约定了节约造价的奖励机制，承包人可依据约定主张奖励或追加工程款[05]。

## 3.2 剖析“包干合同原则上不予鉴定”的裁判铁律及其法定突破例外

### 3.2.1 “包干合同原则上不予鉴定”的裁判逻辑与法律依据

在建设工程造价司法鉴定实践中，“约定固定价/总价包干合同原则上不予鉴定”属于司法裁判的一项基本铁律[18]。该铁律的核心法律依据源于《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第十九条（以及原《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第二十二条）的明文规定：“当事人约定工程价款实行固定价结算，一方当事人申请对工程造价进行鉴定的，人民法院不予支持”[18]。

司法机关恪守这一裁判铁律的底层法理逻辑在于对“契约自由与意思自治”原则的严格维护[19]。当发包方与承包方在签订合同时自愿选择固定总价计价模式，即意味着双方已经对项目施工图纸范围内的工程量、市场价格波动及一般性施工风险完成了预先分配与定额锁定[19]。如果允许一方在履约后因市场行情变化、人工材料价格波动或自身报价策略失误，动辄通过向法院申请司法鉴定来重新按政府定额据实结算，将彻底颠覆原合同的商业风险分配基础，损害另一方当事人的合理预期，进而导致建设工程市场契约信用体系的坍塌[19]。

因此，在诉讼程序中，当合同合法有效且约定了固定总价时，法院审查造价鉴定的首要裁判立场是“以不鉴定为原则，以启动鉴定为例外”[18]。只要承包商施工的内容未超出合同约定的承包图纸与风险包干边界，即使其实际施工成本显著高于或低于合同固定总价，法院亦直接以合同约定的固定总价作为确定工程价款的终局依据，坚决驳回任何一方提出的造价鉴定申请[18]。

│ 例外四   │ 发包方隐瞒重大地质条件或提供虚假资料│ 对因发包方过错导致额外增加的地基处理、拆除│
│         │                                   │ 及措施费用启动独立司法鉴定[08]           │
└─────────┴───────────────────────────────────┴──────────────────────────────────────────┘
```

1. **情形一：施工图设计重大变更导致施工范围发生根本性改变**
   当发包方发出的设计变更、技术核定单或现场指令彻底颠覆了原招标图纸时，原固定总价所涵盖的施工边界已被冲破[04]。此时，法院并非对整项工程进行全盘据实重算，而是采取“割裂式鉴定”路径：对原图纸未变更部分继续锁定固定总价，仅对设计变更所诱发的增加或减少工程量部分，启动司法鉴定以确定新增部分的造价[05]。

2. **情形二：合同中途解除或未完工即终止履行**
   当发承包双方因违约、不可抗力或协商一致导致固定总价合同在中途解除时，由于工程未能全部竣工，原合同约定的固定总价无法直接作为结算终值[19]。此时必须启动司法鉴定，但鉴定的目的并非否定固定总价，而是为了评估已完工程量与全部工程量的造价数值，从而计算出已完工程占合同总范围的比例系数，为后续套用固定总价进行比例折算提供技术依据[19]。

3. **情形三：情势变更与材料价格暴涨暴跌（市场剧烈波动）**
   若在合同履约期间发生国家政策重大调整、异常通货膨胀或主要建筑材料（如钢材、水泥）市场价格暴涨暴跌，且价格波动幅度远超合同约定的风险包干阈值（如超出5%-10%），继续强行按原固定总价结算将显失公平[11]。裁判机关可依据民法典情势变更原则或公平原则，准许对超风险范围的材料价差启动专项造价鉴定，对超出合理预见范围的价差损失予以调价补偿[11]。

4. **情形四：发包方隐瞒重大现场地质条件或提供虚假勘察资料**
   若发包方在招标阶段提供的地质勘察报告与现场实际地质情况存在重大偏差，或隐瞒了地下障碍物、地下管线等关键信息，导致承包人必须采取极为昂贵的额外施工措施或增加大量土石方工程时，发包方的过错行为破坏了固定总价的计价前提[08]。法院准许就发包方过错所引发的额外工程量及措施费启动独立司法鉴定[08]。

│         │ 2. 承包商切忌试图利用部分变更否定整个固定总价合同，而应精准就增量及损失申请  │
│         │    单项鉴定[05]。                                                       │

## 3.3 固定总价合同中途解除后已完工程价款确定规则——《建工司法解释二》第十条深度应用

### 3.3.1 《建工司法解释二》第十条的立法本意与适用前提

建设工程实践中，固定总价合同因发包方资金链断裂、承包方违约撤场或不可抗力等原因导致工程未完工即中途解除的情形屡见不鲜[19]。在此类“半拉子工程”中，已完合格工程的价款如何结算，历来是建工司法审判中最具争议的难题[19]。

为了统一全国法院的裁判标准，《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释[2018]20号，下称《建工司法解释二》）第十条（现统编为新建工司法解释相关条款）作出了里程碑式的规定[19]。条款原文如下：

> **《建工司法解释二》第十条**：“采用固定总价的建设工程施工合同解除后，当事人就质量合格的已施工部分工程价款没有约定且不能协商一致的，人民法院可以参照合同订立时建设工程所在地建设行政主管部门发布的计价标准、计价方法或者工程建设领域相关规范，确定承包人已施工部分工程价款占全部工程价款的比例，并以该比例乘以合同约定的固定总价确定承包人已施工部分工程价款”[19]。

该条款的立法本意在于：**在尊重固定总价合同“风险包干”契约精神的前提下，确立“按比例折算（价款比例法）”作为通常计算路径**[19]。其核心逻辑是避免两个极端——既防止脱离原固定总价直接按政府定额据实结算（对发包方显失公平），也防止机械套用固定总价导致无法计算未完工程（对承包方显失公平）[19]。

依据法条原文与最高人民法院的权威解读，适用第十条“按比例折算”规则必须同时满足以下三项必备前提条件：

```
                    ┌──────────────────────────────────┐
                    │  建工司法解释二第十条适用前提三要件  │
                    └─────────────────┬────────────────┘
                                      │
         ┌────────────────────────────┼────────────────────────────┐
         │                            │                            │
         ▼                            ▼                            ▼
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│ 条件一：合同已依法解除│        │ 条件二：已完工程质量合格│        │ 条件三：无预先约定且事后│
│ (履约提前终止)   │        │ (付款请求权实体要件)│        │ 无法协商一致     │
└──────────────────┘        └──────────────────┘        └──────────────────┘
```

1. **前提一：施工合同已经依法解除**
   无论合同解除的原因系发包方违约、承包方违约还是不可抗力，合同约定的权利义务关系提前终止，是启动中途解约清算规则的程序前提[19]。
2. **前提二：承包人已施工部分的工程质量经验收合格**
   施工质量合格是承包人享有工程价款折算请求权的法定实体条件[19]。若已完工程质量不合格且无法通过修复达到合格标准，承包人无权适用本条主张工程款[19]。
3. **前提三：当事人事先对解约结算没有约定，且事后未能协商一致**
   本条充分尊重当事人的意思自治[19]。若合同中已预先约定了中途解约的结算公式，或解约后双方达成了结算协议，法院应直接适用其约定；只有在“既无事先约定、又无事后协议”的真空状态下，才启动本条的司法折算法律路径[19]。

### 3.3.2 “按比例折算”法的算术模型与三种计价思路横向对比

在司法解释二第十条出台前，司法审判实践中对固定总价合同中途解除后的价款结算存在三种主要的计价思路[19]：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                   固定总价合同中途解除结算的三种历史计价思路横向对比                             │
├─────────┬───────────────────────────────┬──────────────────────────────────────────────┤
│ 计价思路 │ 具体计算公式                   │ 司法评价与优缺点分析                          │
├─────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 思路一   │ 已完价款 = 已完工程定额预算价  │ 优点：计算直接；缺点：彻底抛弃了合同固定总价  │
│ 正向计算 │ × (1 - 下浮率)                │ 的约定，将定额重新作为核心，破坏契约基础[19]│
├─────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 思路二   │ 已完价款 = 合同固定总价 - 未完│ 优点：维持总价框架；缺点：当未完工程量较大时  │
│ 反向计算 │ 工程定额预算价                │ ，计算出的已完价款极易出现负数或严重失真[19] │
├─────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 思路三   │ 已完价款 = 合同固定总价 ×     │ 优点：借助同一计价标准算出比例系数，既尊重总价│
│ 按比例折算│ (已完定额价 / 全部定额价)      │ 约定，又符合工程造价规律，被法释[2018]20号采纳│
└─────────┴───────────────────────────────┴──────────────────────────────────────────────┘
```

#### 1. “按比例折算”的通用数学公式与推导逻辑

《建工司法解释二》第十条采纳的“按比例折算”法（又称价款比例法），其标准算术公式表达如下：

\\[\text{已完工程结算价款} = \text{合同约定的固定总价} \times K\\]

其中，**比例系数 \\(K\\)** 的计算公式为：

\\[K = \frac{\text{已完工程部分的定额预算价（或计价标准价）}}{\text{全部工程部分的定额预算价（或计价标准价）}} \times 100\%\\]

- **公式推导原理**：司法鉴定机构参照合同订立时工程所在地的建设行政主管部门发布的统一定额和取费标准，在**完全相同的同一计价标准与取费基准下**，分别计算出“已完工部分的定额价（分母）”和“全部施工图工程的定额总价（分子）”[19]。两者相除得出的百分比系数 \\(K\\)，精准反映了承包人实际完成的工作量在整个合同施工范围中的经济价值权重[19]。最后用该系数乘以双方签约时确定的固定总价，即可完美还原出已完工程在原固定总价体系下应得的价款[19]。

#### 2. 指导判例应用拆解：最高人民法院典型案例

在最高人民法院为配套《建工司法解释二》发布的一起典型案例（某建设集团公司与某置业公司建设工程施工合同纠纷案）中，该公式得到了精准应用[19]：

- **案情数据**：乙公司与甲公司签订固定总价为 **8900万元** 的施工合同[19]。履约中双方合同解除，乙公司已完工程质量合格[19]。
- **鉴定过程**：司法鉴定机构参照当地定额标准，分别计算出已完工部分的工程价款为 **8100余万元**，全部工程的总价款为 **9700余万元**[19]。
- **系数推导**：
  \\[K = \frac{8100\text{万元}}{9700\text{万元}} \approx 83.5\%\\]
- **裁判结果**：法院判决甲公司按照合同固定总价 \\(8900\text{万元} \times 83.5\% = 7431.5\text{万元}\\) 向乙公司支付已完工程价款[19]。

### 3.3.3 不平衡报价与工程中途解除时的折算风险与防失权辩护策略

尽管“按比例折算”法成为了司法裁判的主流标准，但在复杂的商业工程博弈中，机械套用该公式可能诱发严重的不平衡报价失衡与公平性争议[19]。

#### 1. 不平衡报价在解约折算中的风险暴露

承包商在投标阶段往往采用**不平衡报价策略**——即在总价固定的前提下，将前期先施工的分部分项工程（如地基基础、土石方）单价报高，将后期施工的分部分项工程（如装饰装修、机电安装）单价报低，以此实现前期快速回笼资金[19]。

```
                             不平衡报价与解约折算博弈
                             
【投标阶段策略】
  前期工程 (地基/主体) ───► 故意报高单价 (提前回笼资金)
  后期工程 (装饰/安装) ───► 故意报低单价 (维持固定总价)
                             
                             │
                             ▼ 中途合同解除
                             
【机械套用比例折算 $K$ 带来的失衡】
  由于定额标准是均质的，若按统一定额算出 $K$，再乘以固定总价，
  会导致承包商前期已通过高单价收取的工程款与折算价款发生剧烈冲突：
  ┌──────────────────────────────────────────────────────────┐
  │ 风险A：发包方违约解约 ──► 承包商前期高造价被折算下浮拉低   │
  │ 风险B：承包商违约解约 ──► 违约方利用折算获取不当利益     │
  └──────────────────────────────────────────────────────────┘
```

当合同在中途解除时，若直接按照政府统一定额（均质标准）计算比例系数 \\(K\\)：
- 若承包商前期不平衡报高，按统一定额折算出的已完工程比例 \\(K\\) 可能低于其实际投入或报价比例，导致守约承包商损失惨重[19]；
- 反之，若发包方故意违约解除合同，以避免后期支付高额工程款，机械适用比例折算法将导致违约的发包方从不平衡报价中获得不当利益[19]。

#### 2. 防失权实务辩护策略与裁判修正路径

工程法务、商务经理与建工律师在面临中途解约造价折算争议时，必须掌握以下四大防失权辩护策略：

1. **策略一：启动“违约不获利”原则，主张裁判修正计价路径**
   根据最高人民法院公报案例（2014）民一终字第69号案的裁判精神，《建工司法解释二》第十条规定“可以参照”而非“应当参照”，赋予了法官司法裁量权[19]。若对方系违约方，且适用“按比例折算”将导致违约方获取巨大不当利益或守约方遭受显失公平损失时，律师应坚决主张排除比例折算法，申请法院改按“定额据实结算”或“固定总价扣减未完工程预算价（反向扣减法）”进行结算，以实现实质正义[19]。

2. **策略二：采用“工程量比例折算”替代“价款比例折算”**
   在工程内容相对均质、报价结构平稳的项目中，若各分项工程造价难以套用定额，可主张采用山东高院《解答》第四条及上海高院《解答》第十一条认可的“工程量比例折算法”——直接以实际完成的物理工程量占图纸总工程量的比例，乘以固定总价进行清算，简化鉴定程序[19]。

3. **策略三：签约阶段预设“中途解约防失权闭环条款”**
   在合同签约阶段，务必参照《建设工程造价鉴定规范》（GB/T 51262-2017）第5.10.7条的规则，在专用条款中嵌入差异化解约结算公式[19]：
   - **因发包方违约导致解约**：约定“已完工程按工程所在地同时期定额及市场价据实结算，并同比例补偿管理费与可得利益”[19]；
   - **因承包方违约导致解约**：约定“按合同固定总价扣减未完工程定额预算价结算，并由承包方承担另行发包价差”[19]。

4. **策略四：严格锁定“解约前现场节点签证与移交凭证”**
   合同解除发生时，承包商必须在撤场前联合监理及发包方完成《已完工程量现场实测实量确认单》及《已进场材料设备移交清册》[08]。避免因撤场后现场被第三方破坏或后续施工队伍进场交叉，导致已完工程量无法复核，最终在司法鉴定中承担举证不能的败诉风险[08]。

## 3.4 签约与履约阶段“总价包干 + 风险边界 + 变更调价机制”防失权闭环条款设计与实务操盘

### 3.4.1 签约阶段闭环条款设计要点：筑牢“包干 + 风险 + 调价”三位一体防御体系

在建设工程固定总价与总价包干合同的签约博弈中，发承包双方争议的根源往往在于合同条款对“包干”的理解过于绝对或含糊，未能建立起清晰的风险对等平衡机制 [19]。商务经理、工程法务与建工律师在拟定或审查合同专用条款时，必须抛弃“一包到底”的粗放思维，设计“总价包干 + 风险边界 + 变更调价机制”的三位一体闭环防失权条款 [19]。

#### 1. 风险包干范围的定量化与动态剥离条款

固定总价合同并非绝对不可调价，“包干”仅限于双方在缔约时能够合理预见的风险 [19]。为了防止履约中因材料暴涨暴跌或政策调整引发无休止的诉讼，合同必须明确将超出合理预见范围的非人为风险从“包干总价”中动态剥离：

- **材料价格波动风险划界条款**：明确约定主要建筑材料（如钢材、水泥、混凝土、沥青等）的价格风险包干阈值（通常设定为基准价格的 \\(\pm 5\%\\) 或 \\(\pm 10\%\\)）[19]。当市场价格波动超过该阈值时，超过部分必须脱离固定总价，按工程所在地造价信息价或市场确认价格进行单项差价调整 [19]。
- **政策性与法规调价条款**：明确约定因国家政策调整、税率变更、建设行政主管部门发布的规费与人工单价调整，均属于包干范围之外的法定调整事由，一律按实调整合同总价 [19]。
- **地质与隐蔽工程风险排除条款**：明确发包方对其提供的勘察报告及地下管线资料的真实性、准确性承担绝对法律责任，因现场实际地质条件与勘察报告不符所引发的额外地基加固、土石方增加及地下障碍物清理费用，不属于固定总价包干范围 [08]。

#### 2. 变更工程量与新增项目调价机制闭环条款

为了防止发包方利用“固定总价”掩盖设计变更或拒付追加工程款，必须在合同中设定明确的变更调价递进规则 [19]：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        变更工程量与新增项目递进调价闭环机制                              │
├─────────┬───────────────────────────────────┬──────────────────────────────────────────┤
│ 适用场景 │ 调价规则与计价口径                 │ 合同条款精细化要求                        │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 场景一   │ 合同中有适用项目单价的             │ 直接套用合同已有的清单综合单价乘以变更量 [19]│
│ 现有项目 │                                   │                                          │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 场景二   │ 合同中有类似项目单价的             │ 参照类似单价换算，仅调整材料与工效差价 [19]│
│ 类似项目 │                                   │                                          │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 场景三   │ 合同中无适用或类似单价的           │ 参照合同订立时当地定额、市场价编制补充综合│
│ 新增项目 │                                   │ 单价，同比例乘以中标下浮率 [19]          │
└─────────┴───────────────────────────────────┴──────────────────────────────────────────┘
```

同时，合同必须明确定价确认的时效与视为认可规则：承包商提交变更造价申请后，发包方须在约定期限（如 14 天）内审核完毕；逾期未提出书面异议的，视为发包方认可该变更造价，并直接作为追加工程款纳入当期工程进度款支付 [04, 19]。

#### 3. 清单与图纸冲突时的优先级与缺项索赔保留条款

针对招标工程量清单与施工图纸不一致引发的“树子问 Q4”争议，合同条款必须厘清清单与图纸的关系 [19]：

- 若采用“图纸总价包干”模式，条款应明确发包方对招标清单的准确性与完整性负责 [19]。若发包方编制的工程量清单存在缺项漏项或计算错误，且该缺项属于施工图纸所必需的施工内容，承包商有权主张将缺项部分按新增变更项目计入总价 [19]。
- 明确合同文件的优先解释顺序：当工程量清单与施工图纸存在重大矛盾时，除双方另有补充协议外，按照《施工合同专用条款》约定的优先顺序解释，防止发包方利用套用通用条款排除承包商的合法索赔权利 [04]。

#### 4. 合同中途解除清算预设条款（对标 GB/T 51262-2017 第 5.10.7 条）

为了规避合同解除后司法折算的巨大不确定性，合同应参照《建设工程造价鉴定规范》（GB/T 51262-2017）第 5.10.7 条的规定，预设差异化的解约清算条款 [19]：

- **因发包方违约导致解约**：约定已完工程按照工程所在地同时期适用的定额及市场价据实清算，发包方须同比例补偿承包商的现场管理费、总部管理费摊销以及合同履行后的可得利益损失 [19]。
- **因承包方违约导致解约**：约定可以参照工程所在地同时期适用的计价依据计算未完工程价款，再以合同约定的固定总价款扣减未完工程价款（反向扣减法），避免承包商因违约解除而获得不当利益 [19]。

### 3.4.2 履约阶段动态签证、留痕与反失权防御指引

在固定总价合同履约过程中，承包商往往面临“做了变更却签不到字”、“发包方拖延不盖章导致索赔超期”等致命失权风险 [04, 08]。必须建立全流程的动态留痕与抗辩体系。

#### 1. 变更指令与隐蔽工程三方签证闭环管理

- **“无签证不施工”原则的严格贯彻**：收到发包方或监理方的口头变更指令后，承包商必须在 48 小时内向发包方出具《书面变更确认催告函》。若发包方在约定期限内未予书面答复亦未否认的，方可启动施工，并留存催告函送达凭证 [04]。
- **隐蔽工程与拆除工程的现场见证留痕**：对因设计变更引发的隐蔽工程重做、地基加固或旧结构拆除，承包商必须联合发包方现场代表、监理工程师进行三方实测实量 [08]。记录表必须载明具体坐标、工程量尺寸、施工工效与机械台班，并由三方代表签字确认；若发包方代表拒绝签字，承包商须通过公证留痕或邀请第三方监理机构共同见证 [08]。

#### 2. 智慧工地与数字化凭证打包归档机制（BIM + AI 存证）

随着工程造价争议司法审判对证据链要求的提高，传统纸质签证容易遗失或被否认签署权限，利用现代数字化智慧工地手段建立自动化存证机制成为反失权的核心工具 [01]：

```
                    智慧工地数字化存证与造价抗辩闭环
                    
[BIM 模型与现场物联网设备] ──► 实时捕捉施工工程量与隐蔽节点 [01]
                                       │
                                       ▼
[AI 视觉与无人超市智能焊材库] ──► 自动归档材料领用与工效数据 [01]
                                       │
                                       ▼
[合同第 5.2.3 条请款凭证打包] ──► 生成不可篡改的电子证据链 [01]
                                       │
                                       ▼
[司法鉴定与诉讼举证] ──► 强力反击发包方“无原件/无权限”抗辩 [01]
```

- **合同第 5.2.3 条请款凭证打包归档**：建立基于 BIM 模型与物联网（IoT）的数字化施工日志 [01]。将每次变更施工的现场照片、无人机航拍影像、智能焊材库与物资出入库刷卡记录、GPS 机械定位轨等数据，自动打包归档并与当期工程进度款请款凭证绑定 [01]。
- **电子证据链的法律效力**：在诉讼中，当发包方以“现场代表无签字权限”或“签证单无公章”为由抗辩拒付工程款时，承包商可直接调取智慧工地归档的不可篡改电子证据链，证明变更工程量已实际施工且发包方已实际接受工程成果，从而获得法院对变更造价的认定 [01]。

#### 3. 节点付款抗辩与先履行抗辩权实务操盘（对标最高法（2016）最高法民终 695 号案）

在固定总价合同中，发包方经常以“项目尚未竣工结算”或“承包商未完成全部包干范围”为由，拖延支付已完节点工程款 [02]。承包商必须学会依法行使先履行抗辩权与停工抗辩权 [02]。

- **案例裁判规则对标**：在最高人民法院审理的达华电力公司与陇川鸿宇安生物质发电公司 EPC 总承包合同纠纷案（案号：（2016）最高法民终 695 号）中，双方签订固定总价合同后将合同拆分为 E、P、C 三部分 [02]。履约中发包方欠付工程款高达 **53,485,080 元**，并以节点付款条件未成就提出抗辩 [02]。最高人民法院深入审查合同履约事实，认定发包方未按期支付节点进度款已构成违约，承包商有权暂停施工并主张欠付款项及利息，驳回了发包方利用节点条款恶意拖延付款的抗辩 [02]。
- **实务操盘指引**：当发包方拖延支付节点款达到合同约定违约程度时，承包商应立即发出《付款催告函》；催告期满仍不付款的，依法发出《暂停施工通知书》，并妥善留存停窝工损失凭证 [02]。切忌在发包方严重违约欠款的情况下盲目垫资施工，防止损失无限扩大 [02]。

### 3.4.3 争议调解与诉讼中的造价还原实战操盘 SOP

当固定总价与总价包干争议进入诉讼或调解阶段时，如何通过造价还原与证据重构打破对方的封锁，是决定案件胜负的关键 [19]。工程法务与建工律师应按照以下四步标准化 SOP 进行实操操盘：

```

│                   固定总价争议诉讼造价还原与诉讼操盘 SOP 四步法                        │

│ 步骤阶段 │ 核心操盘动作                       │ 战术要点与防失权防线                     │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 步骤一   │ 履约证据图纸化与签证闭环核查       │ 建立《变更签证与图纸对照表》，锁定超出固定│
│ 证据梳理 │                                   │ 总价范围的全部增量工程量 [04, 08]        │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 步骤二   │ 司法鉴定范围“割裂式”划定           │ 坚守“原图不鉴定、变更/解约启动鉴定”，阻击│

├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 步骤三   │ 造价还原计算路径精细选择           │ 对比“比例折算法”、“定额据实法”与“反向扣  │
│ 路径选择 │                                   │ 减法”，选择对本方利益最大化的算术模型 [19] │
├─────────┼───────────────────────────────────┼──────────────────────────────────────────┤
│ 步骤四   │ 司法裁判价值引导与反失权辩护       │ 引用最高法公报案例（2014）民一终字第 69 号 │
│ 庭辩引导 │                                   │，向法官阐明“违约不获利”与公平原则 [19]  │
└─────────┴───────────────────────────────────┴──────────────────────────────────────────┘

#### 步骤一：履约证据图纸化与签证闭环核查

1. 组织商务人员与造价工程师整理全套招标图纸、施工图纸、设计变更单、技术核定单、现场签证及会议纪要 [04, 08]。
2. 绘制《工程变更与图纸差异对照图》，将每一笔现场签证精准定位到具体的图纸节点与物理位置，形成一一对应的证据索引链，确保每一笔追加主张都有书面凭证支撑 [08, 19]。

#### 步骤二：司法鉴定范围“割裂式”划定

1. 在向法院提交鉴定申请或对对方鉴定申请提出异议时，坚决贯彻“割裂式鉴定”战术：申请法院明确锁定“原合同图纸范围内工程按合同固定总价直接认定，不予鉴定”[05, 19]。
2. 将鉴定范围严格限定在“发包方指令变更增加部分”、“图纸重大漏项追加部分”以及“因发包方违约导致的停窝工损失部分”，防止鉴定机构无端扩大鉴定范围，用通用定额冲淡合同约定的高利润单价 [05, 19]。

#### 步骤三：造价还原计算路径精细选择

根据案件具体的履约状态与自身诉讼地位，测算并选择最有利的计算路径 [19]：
- 如果承包商前期不平衡报价较高且属守约方，应优先争取按《建工司法解释二》第十条的“比例折算法”计算已完工程款 [19]；
- 如果按比例折算会导致本方收益被大幅下浮拉低，或对方属于故意违约方，应申请法院排除比例折算法，直接改按“定额据实结算”或“固定总价扣减未完工程预算价（反向扣减法）”进行结算 [19]。

#### 步骤四：法庭辩论中的“违约不获利”与公平原则价值引导

在法庭辩论阶段，律师应紧扣最高人民法院公报案例（2014）民一终字第 69 号案的核心裁判要旨 [19]：
- 向合议庭指出，《建工司法解释二》第十条规定“可以参照”而非“应当参照”，裁判者享有根据个案公平原则选择计价路径的裁量权 [19]。
- 强调“司法裁判不能让违约方因违约解除合同而获得额外经济利益”，如果适用比例折算会导致违约方免除应承担的损失或剥夺守约方的合理利润，法院应当果断修正计算方法，选择最符合当事真实意思与公平原则的据实结算标准 [19]。

## 小结要点

1. **固定总价的风险边界并非绝对不可突破**：固定总价固定的是合同订立时特定施工图纸和技术规范下的基准总价 [04, 19]。当发生施工图设计重大变更、发包方指令增加工程量、原图纸存在重大设计缺陷或发生超出合理预见的材料价格剧烈波动时，超出的部分必须脱离原固定总价按实调整 [04, 19]。
2. **恪守“包干合同原则上不予鉴定”及其四大法定例外**：司法审判以维护契约自由为原则，坚守“固定总价不予鉴定”铁律 [05, 19]。但在“施工图重大变更”、“合同中途解除”、“价格剧烈波动触及情势变更”以及“发包方隐瞒重大地质条件”四类例外情形下，准许启动司法鉴定，但鉴定应严格限定在变更增量或已完/未完工程比例评估范围内 [05, 19]。
3. **贯彻《建工司法解释二》第十条“按比例折算”规则**：合同中途解除后，已完合格工程清算优先尊重当事人约定 [19]。在无约定且协商不成时，通常适用“价款比例法”（即：已完工程结算价 = 合同固定总价 \\(\times\\) 已完定额价 / 全部定额价）[19]。但在适用中应谨防不平衡报价引发的失衡，结合最高法公报案例（2014）民一终字第 69 号案确立的“违约不获利”原则，主张法院通过司法裁量权修正选择最公平的据实结算路径 [19]。
4. **构建签约与履约的全流程闭环防失权防线**：签约阶段应嵌入“定量化材料调价阈值 + 递进式变更计价 + 差异化解约清算”条款 [19]；履约阶段应强化 14 天签证索赔时效，引入“BIM + AI”智慧工地数字化证据打包存证机制 [01]，并善用先履行抗辩权对抗发包方的拖延付款行为 [02]。
