## 第一节 固定总价与总价包干的范围边界与补偿标准厘清

### 1.1 固定总价的法律属性与风险分担边界

固定总价是建设工程施工合同中常见的合同价格形式，因其具有**总价固定、风险分配明确、结算简便**的特点，被广泛应用于各类工程施工合同 (P000224)。在法律属性上，固定总价合同是发承包双方对工程建设成本与一般性施工风险的契约性预分配——这一点在《建工解释二》第十条的适用逻辑中得到明示：按比例折算规则的确立，正是"在尊重固定总价合同'风险包干'属性的基础上"，兼顾契约自由与工程造价结算规律 (P000224)。

但实务中普遍存在将"固定总价"误读为"绝对不调价、无条件包干一切"的认知偏误。司法判例反复展示的边界是（框架归纳为本研究，各点均有判例锚源）：

1. **计价方式固定不等于工程量封顶**：固定总价固定的是合同订立时依据特定图纸与清单计算的基准总价；当发包方指令变更、设计重大修改颠覆履约基础时，增量部分脱离原总价另行清算——北京城建案中，原合同总价50598996元的工程，因医院大量设计变更，承包人主张完工造价达199184235.77元，该主张构成级别管辖标的额的认定基础 (P000201)。
2. **包干风险的合理限度**：承包人承诺承担的是签约时可合理预见的一般风险；超出合理预见、且不可归责于承包人的事由（如发包方过错），不属包干射程——发包方隐瞒现场条件或提供资料失真引发的额外费用，法院准许独立清算（见第二节例外四） (P000205)。
3. **约定优先，包干从约**：包干范围最终以合同约定为准。启东顾建辉案的合同写明"完成图纸内所有通风工程；在甲方不提出超出预算内容变更的情况下不再结算，结算金额即为合同金额；如发生重大变更以甲方书面确认内容及价格作为增加项目计入结算"——严苛型包干条款之下，无甲方书面确认的增项不在结算之列 (P000202)。

### 1.2 施工图变更与发包方指令增加工程量的补偿路径

施工图变更与发包方指令增加是突破原固定总价最常见的法定事由 (P000201, P000202)。对增加部分的计价，实务通行三级路径（本研究归纳；其规范支点为《建设工程造价鉴定规范》GB/T 51262-2017关于按工程所在地计价依据计算的规定 (P000224)）：

- **合同有适用单价的**：直接套用合同清单综合单价乘以签证工程量计价；
- **合同有类似单价的**：参照类似单价换算，调整材料与工效差异；
- **合同无适用或类似单价的**：参照合同订立时工程所在地计价标准与市场价格编制，或由鉴定机构依当地定额确定——上游协议"如今后涉及工程变更和增加工程量的，增减部分按实结算"的约定，为该路径的合同化表达 (P000202)。

**签证与书面确认是补偿的生命线**：休宁县法院支持的凌良宝案中，2014年10月22日业主与总包签订的《工程承包协议书》约定一次性包死总价（每平方米970元）的同时明确"增减部分按实结算"，2016年6月20日经结算出具载明208000元的欠条，法院据此判付 (P000202)；反之，顾建辉案承包人拿不出甲方书面确认，增项主张整体落空 (P000202)。两案对照构成"有确认则补、无确认则包"的完整证据链闭环。值得注意的是，凌良宝案的链条是双层的——上游《工程承包协议书》的"增减按实结算"条款解决"能不能补"的合同依据问题，下游结算欠条解决"补多少"的金额确认问题；实务中两层缺其一，增项主张都会在诉讼中折半（本研究对两案对照的解读）。

### 1.3 清单缺项漏项与图纸缺陷争议拆解（树子问 Q4/Q5/Q6）

针对行业经典的三问，本章以"树子问Q4/Q5/Q6"框架拆解（框架为本研究设计，各栏规则均有锚源）：

| 问题 | 核心争议 | 裁判规则与索赔路径 |
| :--- | :--- | :--- |
| **Q4 清单缺项漏项** | 发包人提供的招标清单缺项漏项，总价包干下能否索赔？ | 有明确"清单仅供参考、缺项含入总价"约定的，承包人自担风险；无此类约定且清单系发包方编制的，缺项部分按变更增量路径主张（本研究依判例归纳） |
| **Q5 图纸缺陷** | 施工图设计缺陷/漏项，按图施工或修正后增加费用由谁担？ | 设计变更图纸/技术核定单项下的新增工程量，一律按设计变更追加结算，原固定总价不约束该部分 (P000201) |
| **Q6 指令变更与自发优化** | 发包人指令变更与承包人自发优化的补偿分野？ | 发包方书面指令变更：强制追加（签证为凭）；未经发包方书面确认的自发优化：不得主张追加——"如发生重大变更**以甲方书面确认**内容及价格作为增加项目计入结算" (P000202) |

- **Q4的攻防要点**：签约前建立图纸与清单差异对照记录；履约中发现缺项立即书面澄清；对缺项部分独立单列签证（流程为本研究设计）。清单缺项类语料中，法院的核心审查点始终是"合同对清单风险的分配条款"与"缺项部分实际施工的证据"（本研究对语料切片的归纳） (P000203, P000205)。
- **Q5的攻防要点**：设计变更以设计单位变更图纸或技术核定单为凭；北京城建案中大量设计变更使结算争议金额达到原合同总价的数倍量级，最高法院在管辖裁定中明确：承包人基于设计变更等事实主张的结算价款构成诉讼标的额，管辖审查不应作实体预断 (P000201)。
- **Q6的攻防要点**：口头指令必须转化为书面确认；未经确认的"好心优化"，按顾建辉案口径由承包人自担 (P000202)。

### 1.4 典型判例深度剖析（判例一至判例六）

以下六案均取自裁判文书语料切片，按「案情—争议焦点—裁判要点—实务教训」统一结构剖析：

**判例一：北京城建集团有限责任公司与江西省人民医院建设工程施工合同纠纷管辖裁定案**（最高人民法院（2013）民一终字第174号，2013年12月15日） (P000201)

- **案情**：2003年12月18日双方签订《建设工程施工合同》，约定固定总价50598996元承建医院综合病房楼土建安装工程。履约期间医院进行大量设计变更，一、二期工程分别于2005年11月15日、2008年8月18日竣工交付；双方于2008年12月17日就结算原则达成《补充协议书》，承包人2009年10月12日提交全部结算资料。承包人主张完工工程造价199184235.77元、医院已付109790000元、尚欠89394235.77元工程款及200万元保证金未返还，另主张利息损失1205408.38元与逾期结算付款损失1452558元；医院方则主张中国建设银行江西省分行造价咨询中心2009年12月31日《审核报告》核定结算总价97942327.35元、至2008年12月止已付款11779万元，反称承包人应返还超付款15847672.65元，并据此提出管辖权异议 (P000201)。
- **争议焦点**：大量设计变更与补充协议后，结算主张金额（约为原固定总价的3.9倍，本研究测算own_calc）能否构成级别管辖标的额？ (P000201)
- **裁判要点**：最高法院裁定撤销江西高院（2013）赣民一初字第5号民事裁定，本案由江西省高级人民法院审理——承包人基于大量设计变更等事实主张的结算价款及欠款，构成本案诉讼标的额，管辖审查不应涉及实体结算金额的实质判断 (P000201)。
- **实务教训**：固定总价遭遇大量设计变更时，"总价包干"的计价基础已被变更工程量冲刷；承包人应及时以补充协议重新界定计价标准，避免陷入长达数年的结算与程序拉锯（本研究实务归纳） (P000201)。

**判例二：福州绿榕园林工程有限公司与游开香、福建省莆田市电力工程有限公司施工合同纠纷再审案**（最高人民法院（2013）民申字第1623号，2013年12月18日） (P000201)

- **案情**：游开香挂靠绿榕公司承建莆田电业局调度大楼景观工程土建水电部分，分包约定工程量及单价按业主清单及预算书、工程量变动按监理签证与业主确认，结算价＝绿榕公司实际完成造价×（1－中标下浮率13.5%），下浮率固定不变。履约中工程量增加，鉴定意见仅明确部分有争议项目"工程造价为347302元"；一审二审认定工程总造价按总包与业主结算总价加增加部分共6096228元。绿榕公司再审主张：福建华广工程造价咨询公司受电力公司委托出具的《结算审核报告》只在电力公司与绿榕公司之间适用、不能据此确定其与游开香分包合同的结算价格；原审认定的工程款中含游开香无权获得的保修金；其支付的工人工资及材料费为873828元（经游开香代理律师签名确认），原判却认定为829618元、少认定44210元 (P000201)。
- **争议焦点**：固定下浮率包干框架下，变更增量的鉴定认定与上游结算报告对分包人的约束力 (P000201)。
- **裁判要点**：最高法院裁定驳回再审：约定下浮率13.5%固定不变，工程量变动经监理签证和业主确认有效；鉴定意见仅明确部分争议项目造价347302元，对工程款其他部分游开香应承担举证不能的后果；对少认定44210元的主张，绿榕公司因二审未上诉，二审不予审查并无不当 (P000201)。
- **实务教训**："签证确认＋上游结算传导"是多层分包结算的传导链；对一审认定的付款扣款细节必须在二审明确上诉，严防程序性失权（本研究实务归纳） (P000201)。

**判例三：成都市维刚电子工程有限责任公司与泸州市英豪房地产开发有限责任公司施工合同纠纷再审案**（四川省高级人民法院（2017）川民再205号） (P000205)

- **案情**：2011年7月25日双方签订《英豪·龙城丽都弱电系统工程施工合同》，约定合同总价包干；合同第六条特别约定"工程量的确认：以发包人指定人员现场签收方量为准"。2013年9月8日双方签署《工程竣工移交书》及《主要设备移交清单》。原一、二审委托司法鉴定出具造价报告，但鉴定未采纳双方签字确认的移交清单与签证文件；维刚公司再审主张原审以鉴定报告替代书面签证违法，请求支付工程款676689.02元、违约金254957.496元及漏判质保金122330.7元 (P000205)。
- **争议焦点**：双方已签署书面签证与移交清单的，司法鉴定能否推翻签证按通用定额重新计算？ (P000205)
- **裁判要点**：四川高院再审改判支持维刚公司：合同已明文约定工程量以发包人指定人员现场签收为准，司法鉴定仅具辅助性，不能推翻双方履约中依法签署的工程量确认书面文件；原审抛开书面签证采信鉴定意见属认定事实错误，改按双方签署的签证和移交清单据实结算 (P000205)。
- **实务教训**："签证优先于鉴定"——诉讼中应坚决抗辩鉴定机构对已签证工程量的越权重算（本研究实务归纳） (P000205)。

**判例四：浙江佳合房地产开发有限公司嵊州分公司与浙江省一建建设集团有限公司施工合同纠纷案**（浙江省绍兴市中级人民法院（2009）浙绍民终字第1316号，2009年12月21日） (P000206)

- **案情**：2002年10月22日双方签订施工合同，由浙江一建总承包嵊州市滨江城市花园2、4、6、8、10号商住楼土建及水电安装工程，工程款8743000元，合同价款采用"**可调价格合同**"方式确立；此前10月15日的施工补充协议约定工程量计付采取浙江省94定额作为计价依据，履约保证金165万元由施工方于协议签订三日前交付，"本项目不得转包，如转包视同乙方中途放弃承包处理违约责任；如乙方未经甲方同意，专业工程分包合同无效并扣除保证金165万元"，并约定"工程量核减超过5%的，审计费由乙方承担"、未创"越乡杯"承担违约金10万元。工程于2004年7月6日竣工验收合格，施工中因工程地质原因经协商顺延2号楼工期205天、其他工程40天。被告未经原告同意，将水电安装、阳台与屋面栏杆、楼梯扶手制作安装等分项分包给不具有施工资质的自然人，相关案件生效裁判确认的工程量为834832元。2006年1月5日浙江立兴造价师事务所受托对2号楼作出审计结论：核定总造价4989007元、核减538020元、核增354934元、净核减173086元；4、6、8、10号楼核定造价9275487元。一审酌定浙江一建承担违法分包违约金40万元及未创杯违约金10万元，原告佳合方面不服提起上诉 (P000206)。
- **争议焦点**：高额违法分包违约金（165万元）的司法酌减 (P000206)。
- **裁判要点**：绍兴中院二审维持：合同及补充协议合法有效；浙江一建在法庭辩论终结前依《合同法》第一百一十四条第二款及合同法解释（二）第二十七条、第二十八条提出违约金酌减抗辩，法院**结合违法分包工程量占总工程量的比例**，将违约金从165万元酌减至40万元；未创"越乡杯"依约扣减10万元 (P000206)。
- **实务教训**：违约金条款再高，也逃不过"以实际损失与违约程度为锚"的司法酌减审查；发包方设定惩罚性条款时应预期其可执行上限，承包方则应主动行使酌减抗辩权（本研究实务归纳） (P000206)。〔口径说明：本案合同系可调价格合同而非固定总价包干，列入本章系其违约金酌减与审计核减规则对包干类合同结算同样适用（本句为本研究口径说明）。〕

**判例五：顾建辉与黄盛建设工程施工合同纠纷案**（江苏省启东市人民法院（2017）苏0681民初6216号，2017年12月29日） (P000202)

- **案情**：《圣合玫瑰园通风班组承包协议》约定：将启东市曹家镇圣合玫瑰庄园4号楼地下室通风项目发包给原告施工，采用固定总价合同，"所有工作内容均包括，完成图纸内所有通风工程（包含人工工资、日常医药费、养老保险费、相应辅料费）；在甲方不提出超出预算内容变更的情况下不再结算，结算金额即为合同金额；如发生重大变更以甲方书面确认内容及价格作为增加项目计入结算"；合同总价29万元，包工、包料、包调试、包安全责任、包运输、包保险等一切费用（不含任何发票）；工期30天（2014年8月20日至9月20日）。顾建辉施工后主张图纸外增加内容按实追加工程款 (P000202)。
- **争议焦点**：严苛型固定总价条款下，无发包方书面确认的增项能否结算？ (P000202)
- **裁判要点**：法院驳回超额工程款请求：合同明确排除无甲方书面确认的追加结算，顾建辉未能提供黄盛书面确认重大变更的签证证据，必须受29万元固定总价约束 (P000202)。
- **实务教训**：严苛包干条款下，发包方书面签证是打开总价的唯一合法钥匙；无签证强施工增项，承担举证不能的败诉后果 (P000202)。

**判例六：陈某诉肖某等建设工程分包合同纠纷案**（江西省高级人民法院（2022）赣民再74号；人民法院案例库入库案例2023-16-2-115-015） (P000224)

- **案情**：2019年，肖某以某建设公司名义与陈某签订旋挖钻桩施工劳务协议，约定工程量176根桩基、总包干价126万元。后因发包方设计变更，工程仅需施工148根，陈某实际完成148根且经验收合格；肖某已付777763元，陈某起诉请求支付剩余工程款 (P000224)。
- **争议焦点**：固定价合同因设计变更致实际工程量少于约定（148根＜176根）时，能否机械按原固定总价结算？ (P000224)
- **裁判要点**：涉案合同**因陈某不具有相应劳务资质而无效，但项目已竣工验收合格，可以参照合同约定结算**；工程设计变更致施工量减少且双方均无过错，可采用"按比例折算"：以已完工部分工程量与合同约定总工程量对比计算系数，再乘以固定价确定应付价款；再审法院依公平原则认定实际工程价款968575元，改判肖某支付劳务工程款240812元。裁判要旨明示："发包人与承包人约定按照固定价结算工程价款的，因工程设计变更导致承包人未完成合同约定的工程量时，已完工部分经验收质量合格的，可以采用'按比例折算'的方式" (P000224)。
- **实务教训**：固定总价并非单向封顶——发包方设计变更削减工程量时，按比例折算同步向下修正；合同无效但验收合格的，参照约定结算的通道依然敞开 (P000224)。对发包方的对称警示同样成立：试图以"包干"名义对已削减的未施工项目照付全额包干价，在公平原则下无法获得支持 (P000224)。本案与判例七构成比例折算规则的"一down一up"双向坐标：量减时向下折算保护发包人（本案），违约解除折算致失衡时向上修正保护守约人（判例七）——第十条的"可以参照"正为这种双向校准预留了裁量空间（本研究对两案关系的解读） (P000224)。

## 第二节 固定价合同造价鉴定的克制立场与突破通道

### 2.1 克制立场的裁判逻辑

对固定价合同，司法实践对造价鉴定申请一贯保持克制立场：固定总价意味着双方对图纸范围内工程量与一般风险已完成预分配，若允许任何一方事后借鉴定回到定额据实重算，将颠覆合同的商业风险分配基础（法理归纳为本研究）。判例谱系反复印证这一立场：

- **原包干范围不鉴定**：咸阳中院在宝鸡北阳设备安装案中明确划定边界——对原合同约定的设备安装固定总价包干范围，直接以合同约定价格认定；仅对发包方现场指令变更追加的工程量及停工损失部分，准许专项鉴定 (P000202)。
- **签证优先于鉴定**：维刚案再审改判确立：双方依法签署的工程量确认书面文件，效力高于鉴定机构的重算 (P000205)。
- **放弃鉴定则评估定案**：达州张代富案中，法院释明后当事人未申请重新鉴定的，发包方委托评估机构的结论直接作为定案依据 (P000205)。
- **严苛包干直接锁定总价**：顾建辉案无书面签证的增项主张被整体驳回，29万元总价即为终局结算额 (P000202)。
- **结算合意排除鉴定**：李作双案中，发包方出具工程核算书确认总造价144万元、欠款33万元，该书面核算文件直接构成结算依据，无需另行启动造价鉴定——双方事后达成的结算合意，与固定价约定一样具有排斥鉴定的效力（裁判逻辑归纳自源文） (P000204)。

五项立场合并观察，司法的态度可以一句话概括：**凡是双方以书面文件固定下来的合意——无论其形式是包干条款、签证单、移交清单、结算书还是核算书——法院都优先于鉴定予以执行；鉴定只是合意缺位时的补充装置**（本研究归纳） (P000202, P000204, P000205)。这也解释了为什么本章把防失权体系的重心放在签约条款与履约留痕，而非诉讼技巧。

### 2.2 启动鉴定/清算的例外通道

固定总价所赖以存在的基础条件因客观情况变化而被颠覆时，鉴定与清算的通道打开。本章语料实证的四类例外：

```
┌──────────────────────────────────────────────────────────────────────────┐
│                固定总价突破"不鉴定"立场的例外通道                          │
├──────────┬────────────────────────────────┬──────────────────────────────┤
│ 例外通道  │ 触发事由                       │ 鉴定/清算范围                │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 通道一    │ 施工图重大变更/发包方指令增减   │ 仅变更增量部分鉴定，原图范围 │
│ 变更增量  │ 工程量 (P000201, P000202)      │ 锁定总价 (P000202)           │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 通道二    │ 合同中途解除/未完工终止         │ 同一取费标准下已完/全部双重  │
│ 解除清算  │ (P000224)                      │ 测算定比例系数 (P000224)     │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 通道三    │ 设计变更致工程量减少且双方无过错│ 按比例折算向上或向下修正     │
│ 量减折算  │ (P000224)                      │ (P000224)                    │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 通道四    │ 发包方过错（资料失真/虚报反证） │ 过错引发的额外费用独立清算；│
│ 过错清算  │ (P000205)                      │ 一方证据失效后评估兜底       │
└──────────┴────────────────────────────────┴──────────────────────────────┘
```

1. **通道一（变更增量）**：北阳案的"割裂式"处理是范本——原包干范围不鉴定，仅指令变更增量与停工损失进入鉴定 (P000202)；北京城建案的大量设计变更则使增量争议达到原总价的数倍量级，构成独立诉讼标的 (P000201)。
2. **通道二（解除清算）**：合同中途解除后已完工程价款的确定，正是《建工解释二》第十条的规整对象（详见第三节） (P000224)。
3. **通道三（量减折算）**：赣民再74号案确认设计变更削减工程量时按比例向下折算 (P000224)。
4. **通道四（过错清算）**：张代富案中，施工方虚报工程量、编造领款凭证，其自行测量主张被刑事供述否定后，法院采纳发包方委托的评估结论定案 (P000205)。〔边界声明：价格剧烈波动情形下的调价通道，本章语料未含直接判例实证，实务中须以合同调价条款与情势变更规则为据个案主张（本句为本研究边界声明）。〕

### 2.3 判例深度剖析（判例七至判例十二）

**判例七：某建安公司与某置业公司建设工程施工合同纠纷案**（最高人民法院（2014）民一终字第69号；最高人民法院公报案例2015年第12期） (P000224)

- **案情**：双方签订固定总价施工合同（单价1860元/㎡一次性包死、合同总价款6835万元），基础和主体工程完工验收合格后甲公司要求解除合同，乙公司撤场后起诉索款。一审采用"按比例折算"认定已完工比例76.6%、已完工程价款3127万余元；乙公司上诉 (P000224)。
- **争议焦点**：发包方违约解除时，能否机械套用比例折算？ (P000224)
- **裁判要点**：最高法院二审对三种计价方法逐一评析——第一种（下浮比例法）：鉴定预算价并非当事人缔约时依据的预算价，反推比例与意思表示无关，且违约方甲公司能获取910余万元额外利益，不应适用；第二种（工期比例法）：符合交易习惯但计算结果明显高于定额预算价，对甲公司明显不公，不应采用；第三种（定额据实结算）：比合同总价仅高出36万余元，最趋合理，予以采用——二审改判按定额标准计算已完工程价款。裁判要旨："对于约定了固定价款的建设工程施工合同，双方未能如约履行致使合同解除的，在确定工程价款时，不宜直接以合同约定总价与全部工程预算总价的比值作为下浮比例，而应当综合考虑案件实际履行情况，并特别注重双方当事人的过错和司法判决的价值取向等因素来确定" (P000224)。
- **实务教训**：固定总价解除结算中"不能让违约方因违约而获利"的司法价值取向由此确立 (P000224)。

**判例八：凌良宝与郑建文、黄山市方圆建工有限公司建设工程合同纠纷案**（安徽省休宁县人民法院（2017）皖1022民初1034号，2017年12月11日） (P000202)

- **案情**：2014年10月22日，业主白岳置业与郑建文签订《工程承包协议书》，将滨江福庭1号、5号楼总包给无资质的郑建文（包工包料、一次性包死总价每平方米970元，"如今后涉及工程变更和增加工程量的，增减部分按实结算"）；2014年11月10日白岳置业与方圆建工就该工程签订备案《建设工程施工合同》，11月26日双方就支付方圆建工挂靠管理费签订《补签协议》；2015年2月10日郑建文将砖工以每平方米108元包清工分包给凌良宝。2016年6月20日双方结算，郑建文出具载明208000元的欠条。凌良宝起诉索要劳务工资208000元 (P000202)。
- **争议焦点**：包清工单价之下，经结算欠条确认的劳务工资的给付 (P000202)。
- **裁判要点**：法院判令支付：包干单价约束原范围工程量，经双方结算确认的欠条直接构成给付依据 (P000202)。
- **实务教训**：包干合同+变更增量按实结算的组合条款，加上结算欠条的书面确认，构成劳务分包索赔的最短路径（本研究实务归纳） (P000202)。

**判例九：李作双与方建、唐普前、唐普平、王小成、张素兰建设工程施工合同纠纷案**（四川省安岳县人民法院（2017）川2021民初1762号，2017年12月4日） (P000204)

- **案情**：李作双按被告方提供的设计图纸完成兴隆镇田中商住楼6层共2050平方米建修面积施工。合同约定工程总造价170万元左右、分段付款（修建至浇铸1楼楼板时拨付首批工程款20万元、此后每层支付12万元、主体竣工支付20万元、尾款交付后付清）、验收后2%质量保证金在无安全质量问题下一年后支付；施工期间被告分批共付111万元（含李作双出具的34.5万元收条一张、16份收条及工人直接出具的2万元收条共97.5万元）。2015年12月完工交付，2017年4月1日经结算，被告方建作为代表出具工程核算书认定总工程款144万元、尚欠33万元；被告后以包干及部分签名非本人为由抗辩拒付 (P000204)。
- **争议焦点**：双方签署的工程核算书对原包干合同价款的修改效力 (P000204)。
- **裁判要点**：法院支持李作双：发包方出具的核算书确认总造价144万元且欠款33万元，该书面核算文件直接构成结算依据，无需另行启动造价鉴定 (P000204)。
- **实务教训**：履约中双方签署的核算确认文件具有高于初始包干条款的结算效力 (P000204)。

**判例十：达州市城镇污水治理站、张代富建设工程施工合同纠纷案**（四川省达州市达川区人民法院（2017）川1703民初2527号，2017年12月27日） (P000205)

- **案情**：张代富承包污水治理站1号、2号安置房净化池工程（双方未签订书面合同），两工程分别于2013年10月26日、12月15日完工验收并签署工程量收方单，2014年1月28日、2月4日依站方2013年1月10日颁布的达市污治〔2013〕5号《关于经营管理办法的通知》进行结算：1号净化池290845元、2号净化池240378元、合计529911元，站方已付34万元。嗣后张代富因向时任站方负责人行贿被追究，（2015）万源刑初字第61号刑事判决载其供述承包化粪池土石方工程"有多增多算"；站方委托评估机构的评估结果与其主张方量差距较大，法院释明后张代富未申请重新鉴定 (P000205)。
- **争议焦点**：施工方虚报工程量且证据失效后，评估结论的定案效力 (P000205)。
- **裁判要点**：收方单证据因刑事供述暴露的多增多算而不予采信；张代富对评估结果有异议但经释明不申请重新鉴定，评估机构结论客观公正，直接作为确定工程款的定案依据 (P000205)。
- **实务教训**：虚构工程量与伪造凭证将招致证据整体失效乃至刑事风险；放弃重新鉴定权利的一方接受评估结论约束 (P000205)。

**判例十一：杭州××××投资咨询估价监理有限公司与平湖市光明××开发有限公司建设工程监理合同纠纷案**（浙江省平湖市人民法院（2009）嘉平民初字第814号，2009年12月30日） (P000203)

- **案情**：监理方（源文简称信××公司）与开发商签订总价包干监理合同；履约中东湖世纪某D6、E5幢房屋发生整体南向倾斜，地基鉴定分析报告证实系地基不均匀沉降引起，开发商据此扣减监理酬金拒付尾款；监理方起诉要求按包干合同支付监理费并按约主张滞后金 (P000203)。
- **争议焦点**：服务类总价包干合同履约中发生质量缺陷与地基事故时，包干酬金能否扣减 (P000203)。
- **裁判要点**：法院结合地基沉降鉴定报告划分责任，对包干酬金相应扣减后清算剩余金额——总价包干服务合同同样受质量履约责任约束（依源文裁判逻辑归纳） (P000203)。
- **实务教训**：总价包干不是责任豁免牌；重大质量事故引发的鉴定，同样可以打破包干抵扣 (P000203)。

**判例十二：宝鸡市北阳设备安装有限公司与陕西晋盛节能科技有限公司等施工合同纠纷案**（陕西省咸阳市中级人民法院（2017）陕04民终2122号，2017年12月4日） (P000202)

- **案情**：宝鸡北阳设备安装方承包安装工程签订固定总价包干合同，履约中因发包方原因频繁停工并发生现场指令变更；承包方诉请对全案工程造价及停工损失重新鉴定 (P000202)。
- **争议焦点**：发包方停工与指令变更能否引发全案重新鉴定？ (P000202)
- **裁判要点**：咸阳中院划定鉴定边界：原合同设备安装固定总价包干范围坚守不鉴定、直接按合同价认定；仅对现场指令变更追加的工程量及停工损失，准许专项鉴定追加确定 (P000202)。
- **实务教训**：法院严格区分"原包干范围"与"变更溢出范围"；切忌试图以部分变更否定整个固定总价，应精准就增量与损失申请单项鉴定 (P000202)。

**判例十三：湖北宏森建筑工程有限公司与老河口融尚光电科技有限公司施工合同纠纷案**（湖北省老河口市人民法院（2017）鄂0682民初1031号，2017年12月5日） (P000234)

- **案情**：2015年9月18日双方签订《建筑安装工程承包合同书》，由宏森公司包工包料承建融尚鞋业产业园图纸内土建、水电、装饰、装修、消防及图纸外厂区道路硬化、下水管网等工程；总建筑面积13.5万平方米（厂房10万平方米、宿舍3.5万平方米），总造价1.8亿元。合同签订后原告支付100万元合同保证金，2015年9月28日开工通知下达后进场施工（四台桩基同时作业）；2015年11月16日被告口头通知停工并要求桩基在工地停工等待，此后未恢复施工。原告诉请终止合同并主张：经结算书确认的基础管桩、修路、清表、水电、活动板房、管理人员工资260万元，杂项开支45万元，停工损失85万元，垫支360万元的利息1332000元及退还保证金100万元，合计6232000元；庭审后变更诉请，其他损失另案主张 (P000234)。
- **争议焦点**：发包人口头通知停工致合同目的无法实现时，结算书确认价款的给付、保证金返还与利息起算 (P000234)。
- **裁判要点**：法院缺席审理后判决：合同合法有效；双方以《老河口市融尚鞋业产业园项目基础工程及停工损失垫资利息等项工程结算书》形式确认的260万元予以支持；因工程已按发包人要求停工、合同目的无法实现，100万元保证金予以返还；工程款利息——合同约定按工程进度节点付款，工程停工后**以双方对已完成工程量确认之日（2016年7月27日）起算**，按月利率2%支持；保证金利息因无约定不予支持。判决援引《合同法》第一百零九条、第二百八十四条及建设工程司法解释第十七条 (P000234)。
- **实务教训**：其一，停工解除场景下"结算书确认价款＋保证金返还＋利息分段主张"的组合拳路径清晰；其二，利息起算点锚定"工程量确认之日"而非停工通知日——书面确认文件再次成为权利起算的坐标；其三，停工损失等未决项目及时另案主张，避免一案缠讼（本研究实务归纳） (P000234)。

## 第三节 《建工解释二》第十条"按比例折算"规则的深度应用

### 3.1 第十条的定位与三项适用前提

固定总价合同因故未完工即解除的情形并不罕见，已完工程价款如何结算，是司法实践中争议较大的重难点问题 (P000224)。《建工解释二》第十条为此确立了统一的裁判标准：其核心是在尊重固定总价合同"风险包干"属性的基础上，采用既尊重当事人契约自由、又符合工程造价结算规律的按比例折算方式，公平保护当事人权益 (P000224)。

适用第十条需**同时满足三项前提条件** (P000224)：

```

                │   建工解释二第十条适用前提三要件   │
                └─────────────────┬────────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         │                        │                        │
         ▼                        ▼                        ▼
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 条件一：合同已经   │    │ 条件二：已完工程  │    │ 条件三：合同没有   │
│ 依法解除          │    │ 施工质量合格      │    │ 约定且事后未协商   │
```

### 3.2 三种计价思路与第十条的选择

在《最高人民法院建设工程施工合同司法解释（一）理解与适用》中，最高法院将固定总价未完工价款结算总结为三种主要思路 (P000224)：

| 思路 | 计算方式 | 司法评价 |
| :--- | :--- | :--- |
| **正向计算** | 依据定额标准对已完工工程据实结算，并按一定比例下浮 | 按定额结合已完工量确定价款，重新将定额作为核心计价依据，具有一定合理性 |
| **反向计算** | 依定额计算未完工工程价款，用固定总价减去该数额 | 维持总价框架 |
| **按比例折算** | 同一取费标准下分别计算已完工部分价款与全部工程总价款，得出系数乘以固定总价 | 以往司法实践中各地法院大多采用；尊重当事人约定、符合固定总价特点 |

**地方规则全景**（按比例折算与工程量比例两族） (P000224)：

- **价款比例族**：重庆高院、四川高院2022年12月联合发布的《关于审理建设工程施工合同纠纷案件若干问题的解答》第十五条是典型代表："建设工程施工合同约定工程价款实行固定总价结算，在未全部完成施工即终止履行，已施工部分工程质量合格，承包人要求发包人支付工程价款的，可以采用'价款比例法'的方式，由鉴定机构根据工程所在地的建设工程定额及相关配套文件确定已完工程占整个工程的比例，再用合同约定的固定总价乘以该比例确定发包人应付的工程价款（即：已完工部分工程价款＝固定总价×已完工部分定额价/定额总价）"；北京高院《关于审理建设工程施工合同纠纷案件若干疑难问题的解答》第十三条、河北高院《建设工程施工合同案件审理指南》第二条第九款、河南高院审监庭《有关建设工程施工合同纠纷事实查明的思路与方法（二）》第一条第四款均作类似规定。
- **工程量比例族**：山东省高级人民法院《关于审理建设工程施工合同纠纷案件若干问题的解答》第四条、上海市高级人民法院《建设工程施工合同纠纷审判实务相关疑难问题解答》第十一条曾采用工程量比例折算——计算简便直观，但若不同分部分项工程在成本投入、施工难度、利润空间和价值权重上差异较大（尤其存在不平衡报价、前期投入较大时），单纯按工程量比例折算容易失衡，一般不宜脱离工程内容、报价结构和履行状态单独适用。

《建工解释二》第十条吸收的是实践中更为普遍的"按比例折算"方式 (P000224)。从时间线看，这一统一切实有迹可循：重庆高院、四川高院2022年12月联合解答第十五条率先在辖区层面固定"价款比例法"公式，北京、河北、河南等地规则同族呼应，司法解释的全国统一是对地方成熟经验的收编——理解这一演进，就能理解为什么第十条明文采取"由鉴定机构根据工程所在地的建设工程定额及相关配套文件确定已完工程占整个工程的比例"的技术路径：它原样保留了地方解答中鉴定作业的取费口径 (P000224)。

### 3.3 配套典型案例的精准应用

**案例一（最高法2026年配套典型案例）**：某建设集团公司与某置业公司案——固定总价8900万元合同解除后（乙公司完成大部分施工任务，其余工程由第三人施工完成，已施工部分质量合格），双方就如何计算已施工部分工程价款不能协商一致；鉴定机构参照当地计价标准分别计算出已完工部分工程价款8100余万元、全部工程价款9700余万元，两者相除得出比例系数**83.5%**，再用合同固定总价8900万元乘以该比例确定已完工部分价款；法院最终判决甲公司以合同约定的固定总价8900万元乘以比例系数83.5%，向乙公司支付欠付的工程价款及利息等。裁判要旨："固定总价合同解除后，当事人就已施工部分价款如何结算没有约定的，按照已施工部分占全部工程的比例乘以合同固定总价确定工程价款，而非据实结算。"本案系最高法为便于准确理解《建工解释二》配套发布的六个典型案例之一，集中体现第十条核心要义：已完工程预算价÷全部工程预算价＝比例系数，再乘以合同固定总价——既尊重总价固定的契约精神，又合理反映承包人履约实际 (P000224)。

**案例二（赣民再74号，案例库入库案例）**：148根对176根的向下折算（详见判例六）——再审法院特别强调公平原则：双方均无过错时，按比例折算"既避免了完全按固定总价结算对发包人不公，也避免了按实际工程量逐项计价对承包人不公" (P000224)。

**案例三（民一终69号，公报案例）**：比例折算的公平修正阀——发包方违约解除时机械折算将使违约方获910余万元额外利益，最高法院改采定额据实结算（详见判例七） (P000224)。

### 3.4 不平衡报价下的失衡风险与防失权策略

承包商投标时常采用不平衡报价——总价固定前提下，前期先施工的分部（地基、土石方）单价报高、后期分部（装饰、安装）报低，以实现前期资金回笼（策略描述为本研究归纳，其制度风险为P000224明示）。中途解除时机械套用统一定额系数折算，会与不平衡报价结构发生对撞：工程量比例折算法在"存在不平衡报价、前期投入较大或者不同施工阶段利润分布不均时，容易导致计价结果失衡" (P000224)。防失权的四条路径：

1. **"违约不获利"修正**：第十条正式文本由征求意见稿的"人民法院应予支持"调整为"人民法院**可以参照**"，反映比例折算法并非排他性强制规则，仅是无约定且协商不成时的指导裁判路径；适用将致显失公平时，法院可综合过错因素采用更公平的计价方式——民一终69号即其先导 (P000224)。
2. **计价路径的穷举主张**：第十条出台后，"定额据实计算、固定总价扣减未完工程价款、工程量比例折算等方法并未被当然排除，在合同明确约定或个案确有必要时仍可作为计价路径加以选择"——诉讼中应测算各路径结果，选择主张 (P000224)。
3. **签约预设差异化解约清算条款**：参照《建设工程造价鉴定规范》（GB/T 51262-2017）第5.10.7条按解除原因区分——因承包人违约解除的，参照工程所在地同时期计价依据计算未完工程价款，再以合同约定总价款扣减；因发包人违约解除的，可按工程所在地同时期计价依据计算已完工程价款。该规则虽有工程价款清算与违约责任承担混同、偏离固定总价价格安排的风险，但能为预约定制提供参考 (P000224)。
4. **解除时点的现场锁定**：撤场前完成已完工程量与进场材料的书面确认，防止后续施工交叉致工程量无法复核（流程为本研究设计，其证据规则锚定维刚案签证优先原则） (P000205)。行业研究并提示一个常被忽视的深渊：在合同终止或解除时，极易陷入**现场物权归属不清、分包商侵权强占现场及债务交叉纠纷**——解约撤场环节的物资盘点与物权锁定（AI盘点资产清册化的实践工具）应与工程量确认同步完成，使"干完的活"与"堆在现场的料"在同一时点固化归属 (P000251)。

还应提示守约方的救济结构问题：合同解除后，守约方另行主张停窝工损失、机械闲置损失、管理成本摊销、可得利益损失、另行发包价差或修复费用，通常面临较高的举证难度；若将工程价款清算与损害赔偿完全切割，可能出现"形式上规则清晰、实质守约方救济不足"的结果——这正是GB/T 51262-2017第5.10.7条按解除原因区分计价、并在合同中预约定制化清算条款的实务价值所在 (P000224)。当事人若拟在合同中采用工程量比例折算法，也应对其适用条件、工程量确认方式及特殊费用处理作出明确约定 (P000224)。四条策略的共同底色，是把计价方法的选择权从司法裁量尽量前置到合同约定——司法解释为无约定情形备好了默认路径，但默认路径永远不如量身条款贴合项目的报价结构与风险布局（本研究归纳） (P000224)。

## 第四节 "总价包干＋风险边界＋变更调价机制"防失权闭环的搭建

### 4.1 签约阶段：三位一体条款设计

争议处理的重点应前移到合同条款设计 (P000224)：

1. **风险边界的显性划界**：固定总价仅覆盖缔约时可合理预见的风险；对超出预见范围的非人为风险（主要材料价格异常波动、政策调整），应约定脱离包干、按信息价或市场确认价单项调整的阈值与公式（条款设计为本研究建议）。行业先进实践已将调价因子管理数字化——通过BIM模型数据流与现场感知网络的实时交互，把工程物理实体与造价调价因子、设备安装费率及节点付款凭据进行数字化锚定，并配套"BIM-概算动态调价模型"：以初步设计图尺寸、类似工程造价数据与地区人材机差异系数为输入，输出结构变化修正概算指标与拟建工程动态成本单价，使设计深化引发的价格重估在包干边界谈判中有据可依 (P000251, P000252)。同时明确：发包方对其提供的勘察报告与地下管线资料的真实性负责，现场地质条件与资料不符引发的额外费用不属包干范围——过错清算通道（通道四）的合同化 (P000205)。
2. **变更调价的递进机制**：照通行三级路径约定——有适用单价用适用单价、有类似单价参照换算、均无则按当地计价标准编制补充单价（本研究归纳，规范支点见第一节）。同时约定变更造价申请的审核期限与逾期视为认可规则，防止变更价款悬置（条款设计为本研究建议）。
3. **解约清算的差异化预设**：按GB/T 51262-2017第5.10.7条的区分结构，在专用条款中分别预设发包方违约解除与承包方违约解除的计价公式，并约定守约方停窝工损失、机械闲置、管理成本摊销、另行发包价差的举证与计算口径 (P000224)。
4. **清单与图纸关系的厘清**：明确"图纸总价包干"抑或"清单包干"，对清单缺项风险的归属作出明示约定——Q4争议的合同端消解（本研究建议）。

签约自检可归结为一张条款清单（清单为本研究设计，各条款要素均有前文锚源）：

| 条款族 | 必备要素 | 缺失后果的判例警示 |
| :--- | :--- | :--- |
| 包干范围界定 | 图纸/清单基准、包干射程、风险幅度阈值 | 范围含糊即生Q4/Q6争议（判例五：无书面确认增项失权） |
| 变更调价机制 | 三级计价路径＋签证时效＋逾期视为认可 | 变更价款悬置，结算拉锯数年（判例一） |
| 增量确认规则 | "以发包人指定人员现场签收为准"式条款＋移交清单 | 签证缺位则鉴定主导，重算风险（判例三） |
| 解约清算预设 | 按解除原因区分计价公式（对标GB/T 51262-2017第5.10.7条） | 无约定即落入第十条司法折算，计价口径失控（第三节） |
| 请款文件义务 | 节点请款文件包清单（完工报告、工程量表、试验记录等） | 文件缺口即先履行抗辩抓手（695号案） |
| 保证金与利息 | 保证金返还条件、利息基数与起算约定 | 无约定则利息主张落空（判例十三：保证金利息不予支持） |

### 4.2 履约阶段：签证闭环与数字化存证

1. **书面确认的强制转化**：口头变更指令必须转化为书面签证或确认函，否则按顾建辉案口径承担增项失权风险 (P000202)；维刚案进一步提示：合同中"工程量以发包人指定人员现场签收方量为准"的条款＋双方签署的移交清单，是效力最高的工程量证据 (P000205)。操作层面的两条铁则（本研究设计）：其一，收到口头指令后立即发函确认并留痕送达，对方书面否认前不视为最终合意但已固定"指令来源"事实；其二，隐蔽工程与拆除工程在覆盖前完成三方实测实量，见证记录随施工节点同步归档——事后补签的签证，其证明力在对方质证下将大幅折损。
2. **数字化凭证归档链**：行业先进实践已形成"节点请款凭证自动归档链"——以无人超市式智能焊材库（BIM焊缝比对＋实时扫码领用＋余料称重回存）、物资领用实名台账、身份识别与烘干出库记录等数字化手段，将履约过程凭证自动归档，形成符合合同第5.2.3条要求的5类请款文件包及《进度款支付证明》签署件，支撑里程碑节点进度款申请与先履行抗辩防御 (P000251)。传统纸质签证易遗失或被否认签署权限，自动化归档的电子证据链在诉讼中可直接回应"无原件/无权限"抗辩（本研究实务解读） (P000251)。与之配套的管理指标也已行业化：初步设计概算误差控制在±5%以内（概算定额法精度基准，概算指标法约±10%）、节点技术文件交付归档率达到100%、高价值物资实名领用与余料回存——"物资轨"控成本、"履约轨"控凭证的双轨机制，使造价控制与证据留存同源 (P000251, P000252)。

### 4.3 节点付款攻防：从695号案吸取的方向性教训

固定总价与EPC合同下的节点付款攻防，方向性教训来自达华电力与陇川鸿宇安生物质发电案（最高人民法院（2016）最高法民终695号）：2013年9月25日，发包人陇川鸿宇安公司与EPC总承包人达华电力公司就云南陇川2×15MW生物质发电厂签订《EPC总承包合同》，约定固定总价；因国家金融机构贷款要求专款专用，各方将EPC合同分拆——设计（E）分拆给中机电力公司、采购（P）签订三方协议（发包人、达华电力、中设石化）、施工（C）分拆给西北电建四公司。履约中达华电力起诉要求发包人支付欠付款项53485080元；**发包人以节点付款条件未成就行使先履行抗辩权，该抗辩获法院支持**，总包方资金链断裂——研究合集将其列为"盲目垫资"类典型风险情景 (P000251, P000252)。

教训与防线（本研究归纳）：

1. **抗辩成立的病因要看清**：研究合集对该案抗辩逻辑的复盘直指要害——承包人**未能提交合同第三卷附件5约定的过程技术文件（工厂试验标准、检验记录、质控计划）**，发包人行使先履行抗辩权拒付进度款"合法合规"；且发包人此前同意支付第一节点款项的行为，"不能扩张解释为变更了后续节点的法定/约定付款条件" (P000252)。换言之，先履行抗辩的支点不是抽象的"节点条件"，而是合同明列的请款文件义务——文件缺口即抗辩抓手。
2. **每期请款文件包的完整闭环**：承包方必须让每期请款都完整满足合同约定的请款文件要求（节点完工报告、实际完成工程量表、设备/材料工厂试验标准与记录等），使抗辩失据——这正是"节点请款凭证自动归档链"的价值场景 (P000251, P000252)。
3. **融资分拆的全局统筹**：EPC合同因金融机构贷款专款专用要求分拆E、P、C时，必须签署总揽全盘的补充协议，并确保书面变更经授权代表签字；行业复盘将"为满足贷款要求分拆E、P、C合同，但主合同未签总揽补充协议、书面变更缺乏授权代表签字"列为"阴阳分拆合同履约脱节"的反模式 (P000252)。合规防控的核心口诀是"**三算合一**"（估算、概算、预算口径贯通）与"**文实相符**"（技术文件与实际履行对应）(P000252)。
4. **垫资节奏的控制**：切忌在发包方欠付已构成违约时盲目垫资施工，应通过催告、暂停施工通知并留存停窝工损失凭证控制损失扩大（本研究实务建议）。

### 4.4 争议阶段：造价还原与诉讼操盘四步法

```
┌──────────────────────────────────────────────────────────────────────────┐
│                固定总价争议造价还原与诉讼操盘四步法（本研究设计）          │
├──────────┬────────────────────────────────┬──────────────────────────────┤
│ 步骤一    │ 履约证据图纸化与签证闭环核查    │ 变更签证逐一锚定图纸节点，    │
│ 证据梳理  │ (P000201, P000205)             │ 锁定包干外全部增量 (P000205)  │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 步骤二    │ 鉴定范围"割裂式"划定            │ 原图范围不鉴定、仅增量/解除  │
│ 鉴定界定  │ (P000202)                      │ 折算进鉴定 (P000202, P000224)│
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 步骤三    │ 计价路径精细测算与选择          │ 比例折算/定额据实/反向扣减   │
│ 路径选择  │ (P000224)                      │ 并举测算，择优主张 (P000224)  │
├──────────┼────────────────────────────────┼──────────────────────────────┤
│ 步骤四    │ "违约不获利"价值引导            │ 援引公报案例69号，主张法院   │
│ 庭辩引导  │ (P000224)                      │ 依"可以参照"裁量修正 (P000224)│
└──────────┴────────────────────────────────┴──────────────────────────────┘
```

步骤一的锚定物是维刚案式的签证与移交清单 (P000205)——把每一笔增量锚定到图纸节点，形成一一对应的证据索引链；步骤二的边界是北阳案式的割裂处理 (P000202)——在鉴定申请与异议中明确锁定"原合同图纸范围按固定总价直接认定"，将鉴定范围严格限于指令变更增量、图纸重大漏项与停窝工损失，防止鉴定机构以通用定额冲淡合同单价；步骤三的依据是第十条"并未当然排除"其他路径的解读 (P000224)——守约承包人宜测算比例折算、定额据实与反向扣减三条路径的结果后择优主张，违约方在场的案件则须预判机械折算对己方的失衡方向；步骤四的武器是公报案例69号"不能让违约方因违约而获利"的价值取向与第十条"可以"而非"应当"的裁量空间 (P000224)——向合议庭阐明：司法解释赋予的是指导路径而非强制公式，个案的过错结构足以支撑计价方法的修正。

调解场景同样适用这套操盘逻辑：调解谈判前完成步骤一的证据梳理，即掌握了谈判底牌的"可证实部分"；以步骤三的多路径测算结果为区间，设定调解底线与开价；以步骤四的裁判价值取向为杠杆，引导对方理性评估诉讼预期——把诉讼操盘法前移为调解筹码，正是"判例谱系方法论"在非诉场景的落点（本段为本研究实务指引） (P000205, P000224)。

## 本章小结要点

1. **包干有边界**：固定总价的属性是"总价固定、风险分配明确、结算简便"，固定的是缔约时特定图纸清单下的基准总价；施工图重大变更、发包方指令增量、设计变更削减工程量与发包方过错，均构成突破包干的正当通道 (P000201, P000202, P000224)。
2. **鉴定有立场**：司法实践对固定价合同的鉴定申请保持克制——原包干范围不鉴定（北阳案）、签证优先于鉴定（维刚案）、严苛包干锁定总价（顾建辉案）、放弃鉴定则评估定案（张代富案）；例外通道为变更增量、解除清算、量减折算与过错清算四类 (P000202, P000205)。
3. **解除有公式**：《建工解释二》第十条以"三前提（依法解除＋质量合格＋无约定且协商不成）＋价款比例折算"确立统一标准（8900万元×83.5%典型案例）；比例系数＝已完工程价款÷全部工程价款（同一取费标准）；但"可以参照"非排他——69号公报案例以"违约不获利"确立公平修正阀 (P000224)。
4. **攻防有先手**：签约端预设风险划界、变更递进调价与差异化解约清算条款（对标GB/T 51262-2017第5.10.7条）；履约端以书面签证与数字化凭证归档链（智能焊材库＋5类请款文件包自动归档）固化证据；争议端按四步法操盘 (P000224, P000251)。
5. **教训有方向**：695号案警示——发包方节点付款先履行抗辩可获法院支持，总包方请款凭证不完备即垫资施工，资金链断裂；防御之道在每期请款文件包的完整闭环与EPC分拆协议的全局统筹 ("三算合一""文实相符") (P000251, P000252)。
6. **谱系有主线**：十三个判例贯穿范围界定、鉴定立场、解除清算与价款支付四个战场——书面确认文件（签证/结算书/核算书/欠条）优先于鉴定，比例折算双向适用并受"违约不获利"修正，程序失权（未上诉/不申请重鉴）比实体败诉更隐蔽；签约条款清单六族（包干范围/变更调价/增量确认/解约清算/请款义务/保证金利息）是全部判例教训的合同化收口（谱系与清单为本研究归纳）。

使用本章的正确方式：接到包干争议先画"包干边界图"——原图范围内锁定总价，边界外逐项归类四通道；遇到解除清算，先核对第十条三前提是否满足，再并行测算三条计价路径；签约审查时，用第四节第1小节的六族条款清单自检；履约全程，让每一笔增量的书面确认先于施工；进入争议阶段，按四步法操盘并随时核对判例谱系总览表中同战场的先例坐标。地图不能替代个案法律意见，但能让每一步主张都有判例与规则作底（本段为本研究使用指引）。
