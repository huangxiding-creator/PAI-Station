# 第8章 数字化与 AI 智慧工地：从 BIM 模型到无人超市式智能焊材库

## 章首三件套与顶层架构设计 (Chapter Triad & Operational Framework)

### 1. 本章解决什么问题

*   **项目痛点**：在传统工业、电力及化工 EPC 工程现场，焊材、合金管材等高价值设备材料领用粗放，偷漏损耗过高、领发料台账不清；同时，设计 BIM 模型数据流与施工现场工程量及形象进度严重脱节，导致节点付款所需的“履约证据链”撕裂与不全。
*   **违约与失控代价**：由于缺乏全流程数字化物料与过程技术文件追踪体系，总承包方在申请里程碑节点工程进度款时，极易因无法提供完整的过程技术文件而引发发包方依法行使先履行抗辩权拒付工程款 [来源: 《2018中国建设工程争议解决年度观察》.pdf.pdf]；在合同终止或解除时，易陷入现场物权归属不清、分包商侵权强占现场及债务交叉纠纷的深渊 [来源: 《2018中国建设工程争议解决年度观察》.pdf.pdf]。
*   **适用场景**：适用于化工、电力、环保及新能源工程 EPC 项目现场物资防偷防漏、AI 智慧工地实时感知管控及里程碑节点自动化凭证核验场景。

### 2. 本质一句话重定义

将“AI 智慧工地与数字化”重定义为：**通过 BIM 模型数据流与现场物资/施工 AI 感知网络的实时交互，将工程物理实体与造价调价因子 $K$、设备安装费率及节点付款凭据进行数字化锚定的精密控制系统。**

### 3. 读完能干什么与工具清单

*   **明确阅读效益**：工程管理者能够建立一套基于数字化履约凭证的 EPC 物资与节点款把控机制，实现物资损耗精细化控减与过程技术凭证自动化归档，有效防御发包方的进度款支付抗辩，并在解约撤场时锁定现场物权 [来源: 《2018中国建设工程争议解决年度观察》.pdf.pdf]。

## 课程简介

在数字化时代，是否具备数字化生存能力已经是企业能否存活、发展的关键。但数字化究竟该怎么做？从营销入手，还是从品牌起步？业务为先还是工具为先？如何判断一家企业数字化已经成功？企业数字化建设短期内难有成效，该如何坚持？这些问题，都是传统企业数字化所必须回答的。
 
居然之家，成立于1999年，目前市值为476亿港元。作为一家拥有近四百家门店、房租和人力成本高企的典型的传统企业，居然之家早在2012年就开始信息化建设，2018年牵手阿里巴巴，并以自主探索的方式开始多渠道发力数字化建设。从2018年起，居然之家连续三年蝉联天猫“双十一”家居行业第一名，2020年淘宝“618”直播新零售行业（包含家居、家电、美妆等细分行业）第一名。
 
居然之家是如何穿着房租和人力两只“铁鞋子“开始了数字化转型？它的数字化路径是怎样的？它踩过哪些数字化的”坑“？数字化建设当中，最难的组织建设，它是怎么做的？
 
居然之家执行总裁王宁老师迄今在居然之家已经服务22年，亲身参与了居然之家数字化的全过程。本次课程，他将从以下四个部分来拆解居然之家的数字化：
 
第一部分 数字化转型：”焦虑“带来的产业机会
第二部分 业务数字化：关键打法
第三部分 组织数字化：原则与制度
第四部分：数字化转型过程中的几点思考

# **灵光技术方案剖析**

灵光是蚂蚁集团推出的 AI 产品，30 秒生成“闪应用”，支持 3D、音频、图标、动画、地图等全模态信息输出，其形态在市面上还是比较独特的。

我们通过观察灵光 App 行为，输出时的思考过程， 简单抓一下接口 ，来简单分析一下灵光的技术方案。

## **概览**

整体上，灵光回答问题时，会先进行网络搜索，收集一批信息，随后模型开始生成全模态（HTML）的回复，或者按需生成一个“闪应用”。闪应用在页面中被渲染后，会根据应用需求，进行数据请求等操作。

## **流式全模态生成**

一般的大模型应用输出都是纯文字，或者是 Markdown 格式的内容，想要展示更丰富的内容，一般有两个方案：HTML 输出和 支持插件的 Markdown 渲染器。

HTML 输出方式很好理解，模型直接输出代码，前端渲染，天然就带丰富的样式，甚至可以模型输出一些 JS 逻辑，生成的内容可以交互。当然这种方案一般也会有一个组件库/样式库，不会完全让模型从头输出，这样整体的样式也比较统一，相对也安全一些。

> *模型的输出应当视为不可信的，在攻击者够早的提示词下，模型是有可能输出危险内容和代码*

而 Markdown 渲染器则需要额外开发，整体而言是扩充 Markdown 的语法，比如让他支持图标的渲染，需要自行解析语法，并进行渲染。这块也有一些开源的方案，比如 Ant Design X Markdown

针对建筑钢结构多层多道焊接中工艺参数自适应控制不足、全流程数据贯通的局限性等难题，提出一套模型驱动的钢结构焊接机器人作业系统。在离线规划阶段，以BIM深化模型为载体，通过实体关系重构与模型语义信息增强方法，构建了融合几何拓扑特征与焊接工艺属性的焊接工艺模型，提出从BIM设计源头到机器人执行终端的全流程模型驱动闭环方法。

** _1 系统总体架构_**

本研究提出模型驱动焊接机器人作业系统总体架构，如图1所示，由离线规划与在线执行两阶段组成。通过建立几何拓扑与工艺参数之间的关联映射关系，解决BIM设计模型与机器人实际作业过程间的语义信息断层问题，实现从数字模型到物理制造的全流程闭环管理。

△作业系统总体架构

1）离线规划阶段，首先依托制造执行系统（manufacturing execution system，MES）进行模型信息提取与工艺参数匹配，建立从BIM构件几何属性到焊接工艺参数的逻辑映射关系，形成包含完整制造信息的焊接任务包。随后借助计算机辅助制造系统（computer aided manufacturing，CAM），将任务包中的关键几何信息与工艺参数解析为焊接工作站控制系统可直接读取的焊接任务，最后焊接工作站依据该任务完成工件的自动定位与参数化建模，生成初始的多层多道焊道排布方案。

2）在线执行阶段，则通过引入基于激光视觉的闭环控制技术将焊接过程中实时扫描的焊道点云数据与BIM深化设计模型进行配准，计算焊道高度与宽度偏差。随后利用自适应算法动态修正后续焊道的工艺参数，实现焊接过程由预设轨迹执行转换为实时感知与纠偏控制的转变，以应对实际作业过程中可能存在的工况扰动情况。最终，全过程焊接工艺数据被实时回传至CAM/MES系统，为后续作业提供初始化的工艺参数依据。

# EPC总承包企业建立项目管理模板文件库的意义

EPC总承包企业建立项目管理模板文件库具有重要意义，具体体现在以下几个方面：

1. **提高工作效率和质量**：通过标准化的模板文件库，可以确保各类文档的一致性和规范性。例如，在设计、采购、施工等环节中，使用统一的模板能够减少错误和遗漏，提高工作质量和效率。
2. **实现全面覆盖和持续改进**：EPC总承包项目管理体系包括多个模块和管理规定，如策划管理、设计管理、采购管理等，共包含75个管理文件模板。这些模板文件库不仅实现了对整个总承包管理过程的全覆盖，还通过“PDCA”迭代循环不断完善，从而逐步提高工程质量、缩短建设工期和节省工程投资。
3. **加强信息管理和控制**：建立信息编码系统和管理流程，有助于对项目文档进行有效管理，确保其完整性和规范性。这不仅提高了文档处理的效率，还能为后续的审计和评估提供可靠的数据支持。
4. **促进资源优化配置**：通过模板文件库，可以更好地管理和调配资源，如设计单位、材料供应商、设备制造商等。这种资源库建设能够实现资源共享，提升企业的竞争力，并形成合作共赢的模式。
5. **保障项目合规性和透明度**：在政府投资项目中，需要编制并报批一系列设计、概算、施工图设计文件等。使用标准化的模板文件库可以确保这些文件的准确性和合规性，避免因文件不规范而引发的问题。
6. **支持跨专业或跨区域协作**：模板文件库覆盖全国各专业的工程竣工验收资料，可以在一个工程内跨专业或跨省份调用模板，提高了工作的灵活性和适应性。

总之，EPC总承包企业建立项目管理模板文件库，不仅能够提高工作效率和质量，还能实现全面覆盖和持续改进，加强信息管理和控制，促进资源优化配置，并保障项目的合规性和透明度。这些都为实现高质量、高效率的工程建设目标提供了有力的支持。

#### **EPC总承包企业在建立项目管理模板文件库时面临的主要挑战是什么？**

EPC总承包企业在建立项目管理模板文件库时面临的主要挑战包括以下几个方面：

2. **缺乏专业人员**：EPC合同范围广、专业性强，对专业技术要求很高，但目前高级管理人才匮乏，限制了EPC模式的推广。这使得项目管理团队难以有效应对各种复杂的管理需求，从而影响到项目管理模板文件库的建立和维护。
3. **风险管理和协调难度大**：EPC模式下，总承包商需要承担原本由业主承担的大部分风险，包括政治、社会、经济和法律等风险，以及不可抗力因素导致的延期或完工困难风险。这些风险需要通过有效的风险管理措施来控制，而这也对项目管理模板文件库提出了更高的要求。
4. **供应链管理复杂**：EPC项目涉及设计、采购和施工等多个环节，供应链管理的复杂性也给项目管理带来了挑战。需要在模板文件库中包含详细的供应链管理策略和流程，以确保各环节的顺利衔接。
5. **技术和组织能力提升需求**：面对项目组织模式改革的机遇和挑战，EPC总承包企业需要不断提高其技术、组织和合同管理水平。这不仅需要在模板文件库中加入相应的指导文件和技术规范，还需要定期进行培训和更新，以适应不断变化的市场需求和技术进步。
