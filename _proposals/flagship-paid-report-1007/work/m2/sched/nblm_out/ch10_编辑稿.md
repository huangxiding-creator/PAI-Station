# 第10章 组织与人才：进度管理团队的角色与能力要求

## 【本章导言】本章帮助读者解决什么问题

在施工企业的工期管理与延误索赔实战中，许多项目之所以陷入“进度屡屡延误、索赔频频败诉”的双重困境，根源往往不在于进度计划表绘制得不够美观，而在于**进度管理组织架构畸形、岗位权责错位、现场人员授权失控以及团队缺乏实质性进度控制能力**。

对于施工企业的项目经理、商务、造价与法务人员而言，本章旨在系统性解决以下五大核心实战痛点：

1. **解决“有责无权”与资源调配瘫痪问题**：打破传统职能部门与项目部之间的壁垒，明确不同项目组织模式下项目经理（设总）与职能部门经理的权力边界，解决项目经理调不动资源、管不住进度的沉疴。
2. **解决“现场乱签证、后方难索赔”的授权与证据漏洞**：确立现场人员的书面授权边界与规范履职流程，防止现场人员越权签署不利文件，同时确保项目团队在工期延误发生时能够及时、合规地留存具有法律效力的签证与证据链。
3. **解决“多头管理与界面扯皮”的组织内耗**：建立基于WBS（工作分解结构）与OBS（组织分解结构）深度融合的六级进度计划分级管控体系，理清业主、工程总承包商、专业分包商之间的进度管理接口。
4. **解决“后知后觉”的盲目赶工风险**：掌握“沙盘推演”事前情景模拟与压力测试工具，避免在进度滞后时盲目增加人手而陷入“越加人越延误”的Brooks法则怪圈。
5. **解决“合同边界阻碍进度推进”的跨单位协同难题**：吸收重大工程“前敌指挥部”与“班组红绿灯评价”等跨单位组织力穿透经验，将进度控制延伸至最底层的作业班组。

## 10.1 工程进度管理组织的模式演进与选型实战

### 10.1.1 传统直线职能型组织的局限与弊端

在传统的工程建设与设计管理中，普遍采用总部高度集权的**直线职能型组织结构** [1, 2]。在这种模式下，企业总部设立项目管理部、设计管理部、采购部、施工管理部、商务合同部等职能部门，项目现场的各部门仅仅作为总部职能的延伸 [3, 4]。

随着建设工程规模日益庞大、技术复杂度提升以及多项目同时推进，直线职能型组织在进度管理中的严重弊端暴露无遗 [3, 4]：

* **总部权力高度集中，现场响应迟缓**：管理上缺乏分级授权，总部习惯于“遥控指挥” [3, 4]。当现场遇到设计变更、设备到货延误或交叉施工冲突时，现场项目部无权直接决策，信息需层层上报总部审批，导致现场工程问题无法得到及时解决 [3, 4]。
* **无法做到“以现场施工为中心”**：设计、设备采购、合同支付等环节与现场施工需求脱节，横向协调能力差，缺乏组织弹性 [3, 4]。
* **人力资源利用效率低下**：职能部门强界限导致人员专业固化，无法根据项目不同阶段的进度峰值进行跨部门动态调配 [3, 4]。在同时开展多种复杂技术堆型或跨专业工程时，直线职能型结构往往瘫痪 [1, 2]。

### 10.1.2 矩阵制组织模式（弱矩阵、平衡矩阵、强矩阵）的演进与权责划分

为了克服直线职能型的刚性与迟钝，工程企业普遍向**矩阵型组织结构**演进 [5-7]。矩阵制组织的核心在于实现“总部职能管理”与“项目现场管理”的双线平衡 [8, 9]：

1. **总部职能管理部门（“如何去做”及资源保障）**：负责提供标准化程序、管理工具、技术标准及培训，培育专业技术特长，负责人员的招聘与调配，并在职能层面进行监督 [8, 9]。
2. **项目管理团队（“做什么与何时做”及目标交付）**：以项目经理为核心，负责整个项目的具体执行，全面承担安全、质量、进度、技术、环境及项目层次盈亏的直接责任 [8, 9]。项目组成员由各职能部门抽调组成，日常工作向项目经理汇报，专业职能向原部门经理汇报 [8, 9]。

在施工企业和工程公司的具体实践中，根据项目经理拥有权限的大小，矩阵制可细分为三种形态，其演进与选择策略如下表所示 [5, 10]：

| 矩阵形态 | 项目经理（设总）地位与权限 | 职能部门经理权限 | 适用的工程项目类型 [5, 10] |
| :--- | :--- | :--- | :--- |
| **弱矩阵** | 仅充当技术协调人或进度协助者，无资源调控权与财权 [5, 11] | 掌握绝对的人员调配权、考评权与资金分配权 [5, 11] | 技术单一、工期宽松、多专业配合要求低的常规小型项目 [5, 10]。 |
| **平衡矩阵** | 拥有项目进度计划制定、现场指挥及部分预算调控权 [5, 12] | 掌握专业人员的行政归属与专业技术方案终审权 [12] | 企业核心经营业务、涉及多专业紧密配合的大中型新建工程 [5, 10]。 |
| **强矩阵** | 拥有独立的项目预算、人员选调否定权及现场考核分配权 [5, 10, 12] | 仅负责人才储备、通用技术标准制定及后勤保障 [5, 12] | 组织变革阻力小、工期极紧、技术极复杂的创新型或综合室管理试点项目 [5, 10]。 |

例如，宁波市电力设计院在组织改善中，考虑到变电类项目涉及专业室众多且属于常规主业，为减少激烈的变革冲击，将变电项目升格为**平衡矩阵形态**；而送电项目由于采取综合室管理且涉及面较窄，则直接试点**强矩阵形态**，显著提升了设总对进度的调控效率 [5, 10]。

### 10.1.3 团队型（Team-based）与EPCs总承包模式下的进度组织体系

当项目规模和不确定性进一步增加时，矩阵制的双重汇报线容易引发职能经理与项目经理之间的权力冲突 [9, 13, 14]。此时，现代工程组织演变出了**团队型项目组织（Team-based）**与**EPCs模式** [14-16]：

* **团队型项目组织**：突破了矩阵制中“职能经理决定由谁做、如何做”的限制，由一名授权充分的项目总经理统领全盘，将工程设计、采购、施工、调试、进度控制、商务合同等全套专业人员直接指派并划归项目团队 [9, 14]。做什么、什么时候做、如何做以及由谁做，完全由项目管理者统筹决策，消除了部门壁垒 [9, 14]。
* **EPCs总承包模式（设计、采购、施工监理总承包）**：在大型复杂工程（如核电、大型能源项目）中，业主往往采用EPCs模式，即总承包商负责设计、采购和施工监理，而施工主体由业主与专业施工承包商直接签约 [16, 17]。在此模式下，业主必须组建高度专业的项目管理机构，其进度控制部下设**综合进度管理科、设计进度管理科、采购进度管理科、施工进度管理科、调试进度管理科**五个专业科室，对全过程进度进行分级管控与接口协调 [18, 19]。

### 10.1.4 施工企业进度组织选型的可执行步骤

施工企业在承接新工程时，项目管理层应按以下**四步法**完成进度组织选型与搭建：

```
[步骤一：项目特征与风险评估]
  └─ 评估技术难度、工期紧迫度、多专业交叉程度及参建方数量 [10, 13, 20]
[步骤二：组织模式对照匹配]
  └─ 常规项目选平衡矩阵；紧迫/复杂项目选强矩阵或团队型 [5, 10, 14]
[步骤三：梳理OBS与权力清单]
  └─ 明确项目经理在人力调配、进度签认、奖金分配上的书面授权 [12, 21, 22]
[步骤四：搭建进度控制专业节点]
  └─ 设立专职进度控制岗位，配备CPM网络计划工具与沟通机制 [18, 23, 24]
```

1. **第一步：项目特征与风险评估**。分析拟建项目的技术复杂度（如是否包含“新设备、新工艺、新厂家”）、工期紧迫程度、参与专业数量及外部接口数量 [10, 13, 20, 25]。
2. **第二步：组织模式对照匹配**。若项目属于企业熟练掌握的重复性工程，可采用弱矩阵或平衡矩阵 [1, 5, 10]；若项目属于政治任务、首堆工程或工期节点违约金极高的高风险工程，必须采用强矩阵或团队型组织 [5, 10, 14, 26]。
3. **第三步：编制组织分解结构（OBS）与权力清单**。明确项目经理（设总）在项目组内的核心地位，以书面制度形式授予项目经理在人员进出项目组上的否定权、进度考核权以及按项目绩效提取收益的分发权 [6, 12, 22, 27]。
4. **第四步：搭建进度控制专业节点**。配置专职进度工程师，避免由技术员或造价员兼任 [11, 18]。进度控制人员必须具备网络计划编制与挣值分析（EVM）实战能力，建立定期沟通与进度偏差预警机制 [5, 23, 24, 28]。

## 10.2 进度管理团队的岗位设置、职责划分与授权控制

### 10.2.1 进度管理网络结构（WBS-OBS-FBS-PBS）四维匹配

要使进度管理团队高效运转，必须将项目的**工作内容、组织机构、能力要求与最终成果**进行精准的四维映射 [4, 6, 7, 29]：

* **WBS（工作分解结构）**：定义了所有要完成的工作任务，从单项工程、单位工程逐层分解至可管理的最小工作包 [4, 29, 30]。
* **OBS（组织分解结构）**：定义了项目管理的组织机构、责任分配及人员配备层次，确保每个WBS节点都有明确的部门和个人负责 [4, 6, 7, 29]。
* **FBS（功能分解结构）**：定义了完成各项WBS工作所需具备的专业资质、分析能力、硬件设备与技术能力 [4, 29]。
* **PBS（成果清单）**：定义了每个WBS节点必须提交的具体成果（如施工图纸、开工报告、隐蔽工程验收单、进度月报等） [4, 6]。

在实战中，必须确保“每一个WBS节点都有一个OBS责任人，具备对应的FBS功能能力，并按时产出PBS成果清单” [4, 6, 7, 29]。如果出现“一个岗位兼任多重冲突职能”或“关键WBS节点无具体责任人”的现象，进度控制必然失控 [3, 4]。

### 10.2.2 六级进度计划体系的编制分级与审核授权

大型工程项目应建立严密的**六级进度计划体系**，并实施分级授权管理，以确保“一级计划为龙头、六级计划保落实” [31-33]：

```
一级计划：工程总体里程碑计划（董事会/总经理批准） [32-35]
  └─ 二级计划：综合进度与专业接口计划（主管副总经理批准） [19, 32, 33, 35]
       ├─ 三级计划：各专业总体进度计划（进度控制部/EPC总包审批） [18, 35-37]
       │    ├─ 四级计划：年度进度计划（专业部门审查/备案） [18, 35, 38]
       │    └─ 五级计划：月度进度计划（项目部编制执行） [18, 35, 38]
       └─ 六级计划：周/日作业计划（班组落实与日清日结） [18, 33]
```

各级计划的具体内容、编制主体与审批权限如下表所示 [18, 19, 32-38]：

| 计划级别 | 计划名称与核心内容 | 编制责任单位 | 审批与发布权限 |
| :--- | :--- | :--- | :--- |
| **一级计划** | **总体里程碑计划**：涵盖第一罐混凝土、穹顶吊装、主设备安装、倒送电、装料、临界及商运等关键节点 [32, 33]。 | 业主/工程总承包总经理团队 [34, 35] | 公司董事会及上级主管部门批准 [34, 35]。 |
| **二级计划** | **综合进度与接口协调计划**：各专业（设计、采购、土建、安装、调试）的交接节点与图纸/设备到货原则要求 [32, 33, 37]。 | 业主/总包进度控制部 [35, 38] | 主管工程进度的副总经理批准 [19, 35]。 |
| **三级计划** | **专业总体进度计划**：细化至各子项分部工程、结构层及系统调试的起点和终点 [18, 37]。 | EPCs总承包商/施工总承包商 [35, 36] | 业主进度控制部审查批准 [35, 36]。 |
| **四级计划** | **年度进度计划**：将三级计划按年度分解，明确年度资金与资源需求 [18, 38]。 | 各专业分包商/项目部 [35] | 总承包商/业主专业进度管理科审批 [35, 36]。 |
| **五级计划** | **月度进度计划**：将年度计划按月细化，作为当月工程款支付与考核的依据 [18, 38]。 | 各施工项目部 [35] | 项目经理审核，报总包备案 [35]。 |
| **六级计划** | **周/日施工计划**：按周或日下达至作业班组的具体施工任务计划 [18, 33]。 | 施工队长与班组长 | 现场项目经理/施工经理审批。 |

### 10.2.3 关键角色职责定位与项目经理（设总）权责利重构

在一个典型的工程项目中，现场管理体系涉及七种核心角色，必须明确其职责分工，防止越位或缺位 [12, 21]：

1. **管理者代表（管代）**：项目最高决策者，拥有项目的终极否定权 [21]。
2. **商务/办公室**：负责市场开拓、合同接洽及外部沟通 [21]。
3. **技经/造价部门**：负责总体预算、技术质量要求定额及工程款结算审核 [21]。
4. **职能部室主任**：负责提供专业人力资源支持，监督专业技术质量，发放基础薪酬 [21]。
5. **项目经理（设总）**：**项目的直接责任人**，直接策划、组织和控制项目全过程，对工期、质量、成本和安全负总责 [8, 12, 21, 39]。
6. **内部资源（技术/施工人员）**：对项目经理负责，按计划完成具体工序，按项目提取效益提成 [21, 27]。
7. **外部资源（业主/监理/专家）**：配合项目实施，进行监督与验收 [12, 21]。

为了解决项目经理“有责无权”的难题，施工企业必须在管理制度中明确：**项目经理对项目的人力资源选择拥有建议权与否定权，对项目组成员的绩效考核与项目奖金分配拥有直接决定权** [5, 12, 22, 27]。同时，建立按项目节点提取收益的分配机制，打破按行政职务分配奖金的旧习，大幅提升项目团队的工期控制积极性 [27]。

### 10.2.4 现场人员授权边界管理与书面履职规范

施工企业在现场管理中极易出现“授权不清、口头承诺”导致的巨额损失 [40-42]。为防范法律与商务风险，企业必须建立**现场人员书面授权与履职三原则** [41-43]：

* **原则一：严禁越权签署“涉及工程造价与工期变更”的文件**。现场施工员、质检员、技术员仅有权签署“现场事实确认单”（如实际开挖深度、隐蔽工程尺寸），无权签署“同意顺延工期X天”或“同意赔偿费用X万元”的法律承诺 [41-43]。
* **原则二：实行“双签制”与“公章生效制”**。所有涉及工期索赔、重大设计变更、工程结算的往来函件，必须同时具备**项目经理（授权代表）签字**与**项目部/公司法人公章**，单人签字一律视为未完成确认 [41-43]。
* **原则三：建立关键事件日清日结书面记录**。管理者与现场工程师必须采用“关键事件记录法”，对因业主发包方原因导致的停工、图纸延误、场地未交付等事件，在发生当日记录时间、地点、原因、影响及现场影像，并形成书面联系函报送对方签收 [44, 45]。

## 10.3 进度团队法律风险防控与索赔防线构建（司法判例深度剖析）

在建设工程施工合同纠纷中，工期延误索赔往往是双方争执的焦点。许多施工企业虽然在现场付出了巨大代价，但因进度团队缺乏法务意识、签证不合规或证据链断裂，导致索赔请求被法院全盘驳回。以下结合司法实践中的典型判例，剖析进度团队的法律防线搭建。

### 10.3.1 判例一：现场签证缺乏合规授权与公章的法律后果

#### 【案情简介】（吉林长春新星宇公司案，案号：（2017）吉01民初107号）
原告长春新星宇建筑安装有限责任公司（承包人）与被告长春高新城市建设投资（集团）有限公司（发包方）签订《建设工程施工合同》，承建相关建筑工程 [41]。施工过程中发生多项变更，原告竣工后起诉要求被告支付工程欠款及工程变更签证费用 [41]。

原告提出了36份工程变更技术签证，要求按实计取变更价款及相关措施费 [41]。被告抗辩称：合同明确约定“工程建设内容变更，须经监理和发包人书面同意” [41]；原告提交的变更签证中，大部分**既无设计院盖章出具的书面变更材料，也无被告（发包方）公章确认**，仅有现场个别工作人员的个人签字，且签证之间存在内容矛盾与重复索要的情形；此外，部分签证内容已包含在投标综合单价范围内 [41]。

#### 【法院裁判】
长春市中级人民法院审理认为，双方签订的《建设工程施工合同》通用条款明确约定“施工中发包人需对原工程设计进行变更，应提前向承包人发出书面变更通知” [41]。对于新星宇公司主张的工程变更部分，**由于相关签证缺乏设计院盖章确认的书面变更材料，亦无高新城投公司公章确认**，不符合合同约定的变更程序与建设工程管理规范，对缺乏合规盖章与书面授权依据的变更签证费用不予支持；对已计入投标综合单价范围的措施费用，予以驳回 [41]。

#### 【教训与实战指南】
1. **书面授权与盖章是签证生效的法定要件**：施工现场项目经理及进度人员务必清醒认识到，对方现场工程师的口头答应或未授权个人签字，在法庭上极易被发包方否认 [41]。涉及工程变更、工期顺延与费用增加的签证，必须严格按照合同约定获取**发包方盖章及授权代表签字** [41, 43]。
2. **严防签证内容与投标单价重叠**：进度与商务团队在编制变更签证时，必须由造价人员核对投标清单，避免将已包含在综合单价或措施费中的项目重复报签，否则会导致整个签证的真实性受极高质疑 [41]。

### 10.3.2 判例二：指定人员签字与书面联系函对进度结算的约束力

#### 【案情简介】（湖北科联建筑公司案，案号：（2016）鄂11民初90号）
原告湖北科联建筑工程有限公司（承包人）与被告湖北华昊房地产开发有限公司（发包人）签订建设工程施工合同 [46, 47]。合同在签署时特别手写加注了防范条款：**“分包必须有朱良谦签字，没有朱良谦签字不得结算”** [48]。施工过程中，双方对地下室土方开挖、防水层厚度及换填等变更造价发生严重争议 [45, 47]。

原告主张按变更后的120mm厚度及特定土方单价结算，并提交了《工作联系函》及045号签证单 [45]。发包方抗辩称工程未竣工验收，且只认可单层防水及原设计厚度，对联系函不予认可 [45, 47]。原告举证表明，2014年10月21日双方签字确认的《工作联系函》上明确记载：“土方工程价款按开发公司周总承诺给土方公司的30元/立方米进入直接费计取” [45]。

#### 【法院裁判】
黄冈市中级人民法院审理认为：
1. 合同中明确约定的指定人员签字条款对双方具有约束力 [48]。
2. 关于土方及变更价款，双方于2014年10月21日**签字确认的工作联系函**已明确“按周总承诺的30元/立方米进入直接费计取”，该约定系双方对土方结算价款的真实变更确认，对发包方具有法律约束力，法院予以采信并纳入结算 [45]。
3. 对于原告主张的苗木养护费（79,400.32元）及超出规范的细石混凝土费用，因原告**未能提供现场管养与实际发生的签证证据**，法院坚决不予认定 [45]。

#### 【教训与实战指南】
1. **指定签字人条款是“一把双刃剑”**：合同中若约定了“必须由某某签字方可结算”，进度团队必须将该条款作为最高红线，所有工期与工程量确认单必须拿到该指定人员的亲笔签字 [48]。
2. **工作联系函具有强大的补充协议效力**：现场进度与商务人员应善于利用《工作联系函》。当发包方高层口头承诺调整价格或顺延工期时，应立即整理成书面联系函，载明承诺细节并诱导对方授权代表签认，此函件在司法审判中将被视为有效的合同变更依据 [45]。

### 10.3.3 判例三：停工窝工索赔中的现场记录认可与证据链搭建

#### 【案情简介】（湖南金瑞分公司与德胜公司案，案号：（2018）湘01民初613号）
原告湖北金瑞建筑工程有限公司湖南分公司（承包人）承建被告湖南省德胜房地产开发有限公司开发的“德胜001项目” [43, 49]。合同约定，主体工程封顶后支付第一次工程进度款 [43, 50]。施工中，因发包方手续不全被质监部门责令停工，且发包方爆发债务危机，原告于2015年9月27日全面停工 [43, 51]。

原告起诉请求解除合同，支付已完工程款67,88万元，并赔偿因停工窝工导致的塔吊租赁费、扣证损失及罚款 [52]。原告举证了向发包方项目部屈承光及监理签收的《进度总价报表》、现场工作联系函以及塔吊现场照片 [45, 53]。被告抗辩称：未经发包方公章盖章，项目部人员签收不代表公司认可进度，且未进行三方初验，未达到付款条件；塔吊窝工损失缺乏租赁合同支撑 [50, 53, 54]。

#### 【法院裁判】
长沙市中级人民法院审理后认定：
1. **关于工程进度与封顶状态**：虽然发包方未盖公章，但原告已于2015年8月4日向监理及发包方现场项目负责人（屈承光等）报送了进度结算资料并获得签收；结合现场实际施工状况，法院确认项目主体已封顶（砌体完成80%），发包方拒不组织初验构成违约，支付工程款条件已成就 [43, 45, 55]。
2. **关于停工窝工损失的驳回**：对于原告主张的塔吊停工窝工损失，原告虽提供了现场照片及设备进场验收单，证明塔吊在现场存在，但**未能提供塔吊租赁合同、实际支付租金凭证等核心证据**，属于证据链断裂，法院对其窝工损失索赔不予支持 [53]。

#### 【教训与实战指南】
1. **项目部现场人员签收可作为完成工期的关键事实依据**：即便发包方蓄意拒绝加盖公司公章，进度团队只要拿到对方现场代表（如项目经理、工程部负责人）对进度报表、开工/复工报审表的签收字样，即可在司法诉讼中证明“实际完成进度节点”的事实 [43, 45]。
2. **费用与延误索赔必须搭建“闭环证据链”**：索赔不仅要证明“停工延误的事实”（如工作联系函、停工告知书），更要证明“实际损失的金额” [53, 56]。必须同时提供：①租赁/采购合同、②进出场验收单、③人员/设备窝工台班日志、④发票与付款凭证，缺少任何一环都将导致索赔被法院驳回 [53]。

### 10.3.4 商务与法务协同下的现场进度证据链闭环管理步骤

施工企业进度团队应与商务、法务紧密配合，按以下**五步闭环法**管理现场工期与变更证据：

```
[第1步：书面授权盘点] ── 梳理合同中关于签证、变更、结算的指定签字人与盖章要求 [43, 48]
[第2步：动态日志记录] ── 每日填写施工日志，客观记录发包方原因导致的工期阻碍 [57, 58]
[第3步：48小时函告预警] ── 发生延误事件48小时内，发出《工期延误/停工工作联系函》 [45, 59]
[第4步：现场签认追索] ── 紧催对方现场代表签收，留下送达凭证与签收记录 [43, 45]
[第5步：财务损失留痕] ── 归集租赁合同、窝工人工签单、付款凭证，形成完整索赔案卷 [53]
```

## 10.4 跨单位组织力穿透与重大节点协同（沙盘推演与协同联建实战）

在大型工程或超复杂项目中，进度拖延往往不是因为某一家施工单位不努力，而是因为设计、采购、施工、监理及业主之间接口错综复杂，出现“跨单位壁垒”与“合同边界阻碍” [20, 60, 61]。吸收我国重大工程的成功实战经验，进度管理团队可引入以下创新组织机制。

### 10.4.1 穿透合同边界的跨单位联合指挥机制

在“华龙一号”全球首堆示范工程建设中，现场聚集了福清核电（业主）、中核工程（总包）、中核二三、中核二四、中核五公司等7家参建单位，涉及388个班组、1.1万名建设人员，客观上存在单位互不隶属、利益诉求不一、沟通成本极高的问题 [60-62]。

为了打破单位壁垒与合同边界，项目成立了**党建工作联合委员会（“前敌指挥部”）**，探索出跨单位协同的组织穿透机制 [26]：

* **明确“四个聚焦”与“三个不影响”原则**：联合委员会聚焦工程安全质量、重大节点推进、项目团队建设及品牌建设；同时不影响各单位行政隶属、不影响内部事务、不影响现场决策体系 [26]。
* **委员进支部与现场大事共商**：由业主主要负责人担任联合会主任，各参建单位派出1名党员班子成员任委员，联合委员会委员跨单位直接联系1个基层支部，每周/每月召开专题会议，现场协调处置跨单位的图纸提资、设备到货与施工面交接问题 [26, 63]。
* **问题快速响应机制**：现场设立“核区专家小组”，将施工方与设计方直接融合，遇到技术与进度交接困难共同处理，实现**2～3天内关闭一个现场复杂接口问题** [64]。

### 10.4.2 班组级进度控制与“红绿灯”考核评价机制

进度计划最终靠最底层的作业班组去落实 [63, 65]。为了将进度控制力穿透到班组，项目建立了**“党员进班组”与“红绿灯”考核评价机制** [63, 66]：

```
                   ┌─ 定性（周）：施工队从安全、质量、进度三维度评价 ─ (无偏差=绿灯 / 偏差=红灯) [66]
班组“红绿灯”评价体系 ─┤
                   └─ 定量+定性（月）：按4维度评估履职（参加活动/关爱成员/解决问题/促进建设） [66]
```

* **“红绿灯”评价维度**：
  * **周评价（定性）**：由施工队每周从**安全、质量、进度**三个维度对现场作业班组进行评估，无偏差记为“绿灯”，出现工期滞后或违章记为“红灯” [66]。
  * **月评价（定性+定量）**：请班组从“参加班组活动、关心班组成员、解决班组实际问题、促进班组建设”4个维度评价进驻党员与管理人员的履职情况 [66]。
* **“红灯历史台账”与整改闭环**：若班组连续出现“红灯”，立即启动原因查找、专项培训、现场安全进度教育及人员谈心；若整改不力，对对口管理人员进行更换 [66, 67]。
* **实战效果**：通过该机制，现场违章操作数由原来的每个班组每周几十条降至10条左右 [64]；2019年春节后一线工人返工率比2018年提高了13.5%，极大地保障了关键节点的工期按期实现 [68, 69]。

### 10.4.3 “三新”重大节点前的“沙盘推演”事前风险防控五步法

传统进度管理往往是“事后纠偏”，而在大型首堆工程或复杂施工中，任何一个重大节点的失败都是不可承受的 [25, 70]。福清核电项目在全国首次将军事领域的**“沙盘推演”**引入工程项目管理，特别针对**“新设备、新厂家、新工艺”（“三新”）**的重大施工节点进行事前情景模拟与压力测试 [25, 70, 71]。

沙盘推演的标准化实施包括以下**五步法** [72, 73]：

```
[第1步：推演前策划] ── 确定“三新”推演主题（如重大吊装、新设备采购），不预设结论 [25, 72]
[第2步：专家与团队组建] ─ 邀请行业专家组成推演组，对口接受推演的项目团队编制先期资料 [71, 72]
[第3步：五种方式推演] ── 综合运用访谈沟通、文件调阅、情景模拟、压力测试、模拟演练 [73]
[第4步：评价与行动项] ── 编制评估报告，梳理强项与待改进项，分级制定改进行动方案 [73]
[第5步：改进行动追踪] ── 建立定期报告与检查制度，回访落实改进行动，闭环提升 [73, 74]
```

#### 推演采用的五种具体方式 [73]：
1. **访谈沟通**：推演专家组对现场进度、技术与采购负责人进行深度访谈 [73]。
2. **文件调阅**：调阅项目策划、施工组织设计、网络计划及应急预案记录 [73]。
3. **情景模拟**：团队通过情景再现，模拟正常的管理与工序推进流程 [73]。
4. **压力测试**：假定关键条件发生偏离（如主设备延误20天到货、吊装风力超标、施工人员短缺），测试团队的应变与进度调整能力 [73]。
5. **模拟演练**：在真实或模拟场地对重大吊装（如穹顶吊装）、大体积混凝土浇筑进行实物演练 [71, 73, 74]。

在实战应用中，项目团队通过沙盘推演完成了**6次设计领域推演、36个“三新”设备采购包推演、8次模拟吊装及4次混凝土浇筑演练**，提前识别并化解了大量进度风险，确保了工程一、二级计划节点的精准达成 [71, 74]。

## 10.5 进度管理团队的胜任力模型与专业技能要求

在施工企业的工期管理与延误索赔实操中，进度控制绝非单纯的“画网络图”或“填日报表”，而是一项涵盖技术、商务、法务、组织协调与风险预判的综合性系统工程 [1][2]。许多项目之所以出现进度失控，往往是因为进度管理人员缺乏实质性的技术理解力、资源调配力与法律防线意识，导致“懂技术的不会算工期、会算工期的不懂合同、管合同的不了解现场” [1][3]。

### 10.5.1 项目经理（设总）的复合型能力结构

项目经理（在设计与技术管理体系中常称为“设总”）是工程项目进度与综合目标的直接责任人 [1]。在现代工程矩阵制或团队型组织形态下，项目经理（设总）必须具备以下四维复合型能力结构：

1. **全局计划控制与网络计划运用能力**：
   项目经理不仅要理解一、二级工程总体里程碑节点，更要熟练运用关键线路法（CPM）和网络计划原理，对复杂的工序交叉进行动态逻辑梳理 [1][2]。在现实施工策划中，许多项目经理仅经过短期的理论培训，缺乏使用专门计划工具对并列多项目进行动态调配的实战经验，导致项目推进全凭“头脑发热”与口头指令 [1]。合格的项目经理必须能够识别关键线路上的风险节点，做到“未雨绸缪”而非“火烧眉毛” [1][4]。

2. **跨专业沟通与资源整合能力**：
   工程项目涉及土建、安装、采购、设计等多个专业，项目经理必须具备强大的横向穿透力，能够打破专业室与各参建单位之间的接口壁垒 [5][6][7]。项目经理需要代表企业与业主保持紧密沟通，准确捕捉业主的技术与工期需求，快速协调内部人力资源与外部施工力量 [1][2]。

3. **商务合规与索赔预警意识**：
   优秀的项目经理必须具备深刻的“合同边界”意识，能够敏锐识别发包方原因导致的工期阻碍（如图纸延误、场地交付滞后、资金不到位），并及时安排团队留存现场影像、工日消耗与书面联系函 [1][3]。同时，项目经理须坚守授权底线，严禁在未获公司公章或法人授权的情况下向发包方口头承诺放弃工期顺延或费用索赔 [3]。

4. **危机处理与风险预判能力**：
   在面对“新设备、新厂家、新工艺”（“三新”）等高风险工程节点时，项目经理应具备组织压力测试与情景模拟的能力，提前评估可能出现的设备迟到、技术变更或人员短缺风险，并准备好替代备用方案 [4]。

---

### 10.5.2 专职进度控制工程师的核心硬核技能

在大型工程或EPCs总承包项目中，业主与施工企业均应在进度控制部设立专职的进度工程师 [2]。根据工程进度分级管控要求，进度控制工程师必须掌握以下各项硬核技能 [2]：

* **WBS（工作分解结构）与编码体系建立技能**：能够将庞大的单位工程逐步分解至最小可管理的施工卷册与工序单元，并建立统一、严谨的工程编码体系（如按项目结构分、按阶段分、按合同分），确保进度数据与成本、质量数据能够实现精准对齐 [1][5]。
* **工序资源消耗定额与数据积累技能**：熟悉企业内部的工工时消耗定额与工序费用定额 [1]。进度工程师不能仅靠经验预估工期，而应根据以往工程的统计数据，精确推算完成某一工序（如钢筋绑扎、混凝土浇筑、管道焊接）所需的人工工时、设备台班及材料消耗，从而制定出真实可行的施工计划 [1]。
* **挣值管理（EVM）与偏差分析技能**：能够通过对比计划工作量、实际完成工作量与实际成本支出，精准测算进度偏差与费用偏差，及时向项目经理发出“进度滞后”或“成本超支”的早期预警 [1][2]。
* **现场事实核查与日志审核技能**：进度工程师须深入施工一线，对每日进场的人员数量、机械设备台班、实际完成工程量以及因发包方原因导致的停工窝工进行客观记录，审核施工日志的真实性，防止现场数据虚假膨胀 [2][3]。

---

### 10.5.3 商务、造价、法务人员的进度协同能力

进度控制绝不是进度工程师一人的工作，商务、造价与法务人员必须深度融入进度管理网络，形成“三位一体”的防护体系 [2][3]：

```
                    ┌─ 商务/造价：核对进度款支付节点，确保赶工/变更费用不漏项
现场进度管理协同网络 ─┼─ 法务人员：把关往来函件法律效力，审核签证盖章与签字授权
                    └─ 进度工程师：提供现场工期延误证据、工日台班台账与停工记录
```

1. **商务与造价人员的协同**：
   造价人员在核算月度完成工程量与进度款支付申请时，必须严格对照五级月度计划与六级周计划的实际达成情况 [2]。在发生工程变更或赶工时，造价人员要核对投标综合单价与措施费范围，防止将已包含在投标报价中的内容重复报签，同时确保发包方承诺的赶工补贴与变更单价能够及时纳入结算 [1][3]。

2. **法务人员的协同**：
   法务人员应定期审查项目部的往来文书，监督《工作联系函》、停工告知书、会议纪要的格式与送达程序 [3]。法务人员需明确告知现场人员：未授权人员的单人签字无法产生法律约束力，所有涉及工期顺延与费用调整的文件必须拿到对方授权代表的亲笔签字并加盖公章，防止因现场管理疏漏导致索赔权丧失 [3]。

### 10.5.4 进度管理团队能力评估与选拔可执行步骤

施工企业在组建新项目的进度管理团队时，人力资源部与项目经理应按以下**四步法**完成团队能力评估与岗位选拔：

```
[步骤一：岗位胜任力指标制定] ─ 依据项目规模与风险级别，明确进度、商务、技术岗位技能指标
[步骤二：历史绩效与经验盘点] ─ 调阅候选人在以往项目中的里程碑达成率、索赔成功率及日志质量
[步骤三：实战场景演练评估] ── 采用无脚本压力测试或沙盘推演，评估候选人面对停工延误的应变力
[步骤四：签约履职与动态调整] ─ 签订项目目标责任书，将工期奖惩直接与考核得分挂钩，动态淘汰
```

1. **第一步：岗位胜任力指标制定**。根据项目的技术难度（是否属于首堆或复杂工程）、工期紧迫度及参建单位数量，编制详细的岗位职责与技能清单 [1][5]。
2. **第二步：历史绩效与经验盘点**。审查候选人在以往项目中的历史履职记录，重点核查其主持编制的网络计划实施效果、工期延误应对记录以及索赔案卷的归档质量 [1][3]。
3. **第三步：实战场景演练评估**。在选拔关键项目经理与进度控制主管时，引入“模拟压力测试”，设定“发包方图纸延误30天且拒绝顺延工期”等典型难题，考核候选人的合同运用能力与跨单位沟通技巧 [4]。
4. **第四步：签订履职责任书与动态考核**。明确项目团队成员的责权利分配，建立按项目节点提取收益的考核机制，对于无法胜任进度控制要求、导致现场证据断裂的人员及时进行调整更换 [1][6]。

## 10.6 进度管理团队的培训体系与沙盘演练实战

### 10.6.1 传统培训模式的脱节问题与实战化转型

许多施工企业在进度管理培训上投入了大量资源，但效果往往不尽如人意。传统培训普遍存在以下三大脱节问题：

* **理论与实操脱节**：培训过于偏重网络计划图编制等纯理论知识，参训人员虽然考取了证书，但在面对现场复杂的交叉施工与多项目并行时，依然不知如何使用计划软件进行实际调度 [1]。
* **课堂教学与现场风险脱节**：培训缺乏对真实工程风险（如设计频繁变更、设备延迟到货、地方关系协调阻碍）的应对演练，导致学员回到现场后“纸上谈兵” [4][3]。
* **管理层培训与一线班组脱节**：培训往往局限于总部与项目部中高层人员，未将进度控制要求、安全质量红线穿透到最底层的作业班组，导致“上头热、下头冷” [6]。

为破解上述难题，企业必须推动培训向**实战化、情景化与全员化**转型 [6][4]。

---

### 10.6.2 “三新”（新设备、新厂家、新工艺）节点的沙盘推演培训

在面对包含“新设备、新厂家、新工艺”的重大节点工程时，“沙盘推演”是快速提升团队进度控制与风险化解能力的有效实战培训工具 [4]。

沙盘推演的核心实施流程（“五步推演法”）以及访谈沟通、文件调阅、情景模拟、压力测试、模拟演练五种方式，已在本章10.4.3节结合“华龙一号”首堆实践系统阐述，培训组织中可直接沿用 [4]。培训场景下应重点用足两个环节：一是压力测试，随机设定“现场吊装风力突增至7级”“施工人员返岗率仅50%”等极限条件，逼迫学员在限定时间内重新调整网络计划与资源配置 [4]；二是模拟演练，在真实或1:1模拟场地进行实物演练（如重大设备模拟吊装、模拟混凝土浇筑），检验团队的现场指挥配合默契度 [4]。

---

### 10.6.3 “党员进班组”与一线作业人员进度安全双提升培训

班组是工程建设的最小单元，直接决定着进度计划能否最终落地 [6]。为了提升一线作业班组的执行力与安全质量意识，大型工程引入了“党员进班组”与“早班会微培训”机制 [6]：

```
                        ┌─ 党员与管理人员深入班组，参加每日早6点早班会
“党员进班组”微培训机制 ─┼─ 用工人听得懂的通俗语言宣贯安全规程与进度节点要求
                        └─ 建立“党员红绿灯”评价，每周对班组安全、质量、进度作定性评估
```

1. **早班会“微培训”与思想疏导**：
   进驻班组的管理人员与党员每日早晨6点与工人一同参加早班会，用一线工人听得懂的语言讲解安全规程与当日进度目标 [6]。针对工人普遍反感的“规章制度严、害怕罚款”等心理，进驻人员站在工人的角度做思想疏导，宣贯“安全了，家就幸福了”的理念，将被动接受管理转化为主动安全施工 [6]。

2. **班组“红绿灯”评价与闭环整改培训**：周定性评价（安全、质量、进度三维度）、“红灯历史台账”与整改更换机制已在本章10.4.2节详述。落到培训环节，对出现“红灯”的班组应立即安排专人深入班组查找原因，开展针对性的现场安全教育与技能补强培训，并将整改成效纳入下一轮评价，形成“评价—培训—改进”的联动 [6]。

---

### 10.6.4 进度管理团队培训实施的四步流程

施工企业建立日常进度培训体系应遵循以下**四步流程**：

1. **第一步：培训需求精准诊断**。对比项目实际进度绩效与岗位技能要求，找出现在团队在网络计划工具使用、签证报签或合同条款理解上的短板 [1][3]。
2. **第二步：编制分层培训大纲**。对项目经理侧重合同与综合协调培训，对进度工程师侧重软件与挣值分析培训，对一线班组侧重工序配合与安全微培训 [1][6][2]。
3. **第三步：组织实战演练与沙盘推演**。结合拟建项目的关键节点，开展情景模拟与压力测试，让学员在模拟战场中暴露问题、解决问题 [4]。
4. **第四步：培训效果跟踪与复盘考核**。将培训效果直接与后续项目的签证合格率、节点达成率挂钩，实现“以培训促管理、以管理检验培训”的闭环 [1][6]。

## 10.7 进度绩效考核、动态激励与Brooks法则的赶工风险应对

### 10.7.1 挣值原理（EVM）在进度绩效评估中的应用与限制

在现代工程项目控制中，**挣值原理（Earned Value Management, EVM）**是实现进度与成本综合控制的核心定量技术 [1][2]。

#### 1. 挣值原理的三大基本参数与进度偏差指标
* **计划工作预算费用（PV）**：根据批准的进度计划，到某一特定时间点预定完成的工作量的预算金额 [1]。
* **已完工作实际费用（AC）**：到某一特定时间点，实际已经完成的工作所消耗的全部费用 [1]。
* **已完工作预算费用（EV，即“挣值”）**：到某一特定时间点，实际已经完成的工作量按预算单价计算出的费用金额 [1]。
* **进度偏差（SV = EV - PV）**：当SV > 0时，表示实际进度提前；当SV < 0时，表示实际进度滞后 [1]。
* **进度绩效指数（SPI = EV / PV）**：当SPI > 1时，表示进度超前；当SPI < 1时，表示进度落后 [1]。

#### 2. EVM在施工企业应用的现实限制与前提条件
虽然EVM理论完善，但在施工企业的具体应用中存在两大前提条件：
* **前提一：必须具备完善的工序资源消耗定额体系**。如果企业缺乏以往项目的工时消耗与费用定额（如每道工序的人工工时、设备台班成本），就无法准确计算预算费用，挣值分析就会沦为“空中楼阁” [1]。
* **前提二：必须依赖高效的项目管理信息系统**。进度与成本数据量巨大，没有软件系统的即时收集与流转，手动计算难以满足动态控制的时效性要求 [1]。

因此，如宁波市电力设计院在推行矩阵管理初期，采取“直接成本核算 + 专家核定工工时”过渡方案，逐步积累工时数据，为全面应用挣值原理奠定基础 [1]。

---

### 10.7.2 项目团队绩效考核操作流程与奖金分配机制

为了充分调动项目团队的积极性，施工企业必须打破传统“科室主任凭印象分发奖金”的大锅饭模式，建立**按项目提取收益、绩效考核闭环**的分配机制 [1]。

#### 1. 项目经理（设总）与团队绩效考核操作流程

根据宁波市电力设计院等企业的成功实践，项目绩效考核操作流程包含以下五个阶段 [1]：

```
[绩效计划阶段] ── 经营班子确定企业年度目标，部门与项目经理签订《绩效考核计划表》
[绩效控制阶段] ── 建立持续沟通机制，定期召开会议，记录项目经理与成员的执行过程
[绩效评估阶段] ── 每月30日前收集部门数据，下月3日前评分，部门部长撰写述职报告
[绩效反馈阶段] ── 各级管理者与被考核者进行绩效面谈，签确认，公布考核结果
[结果应用阶段] ── 绩效考核得分直接与绩效奖金、职位调整、培训开发挂钩，闭环管理
```

#### 2. “按项目提取收益”的打破大锅饭激励机制
企业应花大力气建立**按项目提取收益的分配模式**：
* 改变按行政职务分配奖金的旧习，将项目产值、节点工期完成度、质量与安全得分直接作为奖金提取依据 [1]。
* 实行这种类似“计件”与“节点对赌”的办法，可以使贡献突出的优秀一线技术骨干和项目经理的月收入超过公司领导层 [1]。
* 实践证明，这种兑现到位的分配模式能够极大地激发一线员工的工作热情，稳定技术骨干队伍，彻底解决“干多干少一个样”的惰性问题 [1]。

### 10.7.3 Brooks法则在施工进度管理中的实战启示与赶工策略

当项目发生严重工期滞后时，管理层最常见的盲目反应就是“向现场大量增加施工人员或加班” [1]。然而，软件工程与项目管理中著名的**布鲁克斯法则（Brooks' Law）**揭示：**“为滞后的项目增加人力，往往会使其更加滞后。”**

#### 1. Brooks法则在工程施工中的表现机制
在施工现场，盲目追加人员和设备往往会导致以下负面效应 [1]：
* **沟通路径呈指数级增加**：新调入的人员对现场环境、施工图纸、质量规范不熟悉，需要老员工花费大量时间进行指导与培训，导致老员工的工作效率急剧下跌 [1]。
* **作业面拥堵与安全隐患激增**：施工现场空间有限，过度增加人员会导致交叉作业冲突，引发安全违章，甚至造成安全事故而被迫停工整顿 [1][6]。
* **疲劳效应与成本攀升**：盲目安排连续加班会导致工人体力透支、质量缺陷率上升，返工费用与加班激励成本不断向上攀升，最终陷入“越赶工越延误、越延误越亏损”的怪圈 [1]。

#### 2. 理性赶工的实战策略
当进度出现滞后时，项目经理应保持理性，按以下步骤实施赶工 [1]：

```
                    ┌─ 第一步：深入分析延误根源（是发包方原因还是内部效率低）
施工理性赶工四步策略 ─┼─ 第二步：优化关键线路逻辑（将顺序施工改为合理搭接/平行施工）
                    ├─ 第三步：适度增加关键工序资源，避免全盘盲目加人
                    └─ 第四步：若交付时限极不合理，通过沟通向发包方申请变更合理工期
```

* **分析延误根源**：首先判断延误是因为发包方图纸/资金到位滞后，还是内部组织不力 [1][3]。若是发包方原因，应优先发出联系函要求顺延工期并索赔赶工费，而非盲目自费赶工 [3]。
* **优化逻辑关系**：在不增加人手的前提下，通过改进施工方案，将原本串行的工序改为平行流水作业或合理搭接 [1][4]。
* **适度增加资源**：仅在**关键线路**的瓶颈工序上适度补充熟练工种，并做好事前培训 [1][4]。
* **协商调整时限**：如果发包方提出的交付时限严重违背客观规律，项目经理应通过积极沟通，以书面形式变更为合理时限，避免牺牲质量与安全 [1]。

---

### 10.7.4 工期延误责任追究与团队绩效考核可执行步骤

在工程结算或发生延误争议时，企业应按以下**四步法**对项目团队进行绩效考核与责任追究：

1. **第一步：核对实际里程碑与计划偏差**。对比实际完成节点与三级/五级计划，精准计算工期延误天数与受影响的关键线路 [1][2]。
2. **第二步：划分内部责任与外部责任**。调阅《施工日志》、工作联系函与现场签证，区分因业主发包方原因导致的停工与因项目部自身组织不力导致的延误 [3]。
3. **第三步：评估团队履职与证据留痕质量**。审查项目团队在延误发生期间是否按规定发函预警、是否留存完整窝工台账及公章签认凭证 [3]。
4. **第四步：落实绩效扣减与激励兑现**。对因自身失职导致工期延误或索赔失败的项目团队扣减绩效奖金；对成功化解延误风险、按期达成节点的团队兑现专项奖励 [1][6]。

## 10.8 本章总结与证据边界

### 10.8.1 本章小结要点

本章系统梳理了工程工期管理与延误索赔中“组织与人才”的核心逻辑与实战指南：

1. **组织形态决定管理效能**：施工企业应根据项目复杂度与工期风险，灵活选择矩阵制形态（平衡矩阵、强矩阵）或团队型组织 [1][5][7]。必须树立项目经理（设总）的核心地位，明确其在人员调配、现场指挥与奖金分配上的书面授权，破除“有责无权”的体制藩篱 [1][5]。
2. **构建严密的分级计划与职责网络**：依托WBS（工作分解结构）与OBS（组织分解结构）的精准匹配，建立覆盖一级里程碑至六级日计划的完整管控体系，明确业主、总承包商与分包商的授权边界 [5][2]。
3. **现场授权规范与索赔证据闭环**：现场签证必须坚守“双签制”与“公章生效制”，严禁越权签署涉及费用与工期的法律承诺 [3]。在司法实践中，未盖章或许可的签证将不予采信；而规范签收的《工作联系函》与进度报表则是证明实际工期与发包方违约的核心证据 [3]。
4. **穿透合同边界与事前风险管控**：针对超复杂工程，应建立跨单位的联合指挥机制，将进度与安全评价穿透至作业班组（如“红绿灯”机制） [6]；在“三新”重大节点前熟练运用“沙盘推演”五步法，实现从“被动事后补救”向“主动事前管控”的跨越 [4]。
5. **打造复合型团队与理性赶工**：进度团队需具备技术、商务与法务的复合能力；在面对工期滞后时，应警惕Brooks法则的负面效应，通过优化逻辑关系与适度配置资源实现理性赶工，并配合“按项目提取收益”的激励机制，彻底释放团队活力 [1]。
