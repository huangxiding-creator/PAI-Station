# 《EPC工程审计与决算实战研究报告》

## 第6章 送审策略与资料编制实务：提高审计通过率的作业清单

本章旨在帮助工程企业高管、商务经理、造价与审计人员以及工程法务彻底打破“五方竣工验收合格即等于顺利回款、利润锁定”的致命认知误区 [05, 06]。在EPC总承包与政府投资项目结算实战中，大量工程项目尽管现场施工质量达标、观感优良、顺利通过竣工验收，却因送审资料缺失、手续瑕疵、证据断层、时间线混乱或流程倒置，陷入无限期退审、大额核减、补正资料循环以及高额违约扣罚的泥潭，导致资金占用成本剧增、项目由盈转亏 [05, 06]。更严重的是，审计阶段遗留的资料缺陷在后续工程款诉讼中会直接转化为举证不能的败诉风险 [05, 06]。本章基于司法判例、官方审计标准与工程实务，系统梳理送审资料合规编制清单、剖析典型退审与审减案例、对接核心政策法规，并提供可落地的防范策略与作业指南，帮助企业建立“一次性过审”的闭环防御体系 [05, 06]。

### 6.1 EPC工程竣工结算送审的痛点诊断与“一次性过审”底层逻辑

#### 6.1.1 认知误区破除：竣工验收与结算回款的法律/审计鸿沟
在工程结算与诉讼维权实操中，施工单位普遍存在将竣工验收合格等同于回款保障的误区 [05, 06]。从政府投资项目审计规则与民事诉讼证据裁判逻辑来看，竣工验收仅代表施工工序在物理层面完成，并不代表工程量与价款获得法定认可 [05, 06]。

审计审核与司法鉴定遵循共同的底层逻辑：**无资料不计量、无签字不认可、无依据不计价、无影像不采信、无闭环不结算；审计阶段不予认定的证据，法庭在诉讼中大概率同样不予采信** [05, 06]。如果送审资料存在瑕疵，审计机关将实施直接退审或大幅核减；若双方协商无果进入诉讼，法院与司法鉴定机构同样会参照审计逻辑审查证据链，导致施工单位在民事诉讼中承担举证不能的不利后果 [05, 06]。

```
+-----------------------------------------------------------------------------------+
|                           竣工结算送审闭环与风险演进图                             |
+-----------------------------------------------------------------------------------+
|  物理施工完成 ──> 竣工验收合格 ──> 资料编制与送审 ──> 审计审核/定案 ──> 资金落袋回款  |
|                         │                 │                               |
|                         ▼                 ▼                               |
|                    【认知误区】      【资料合规瑕疵】                         |
|                    误以为验收过      手续缺失/证据断层                        |
|                    即锁定利润        时间线逻辑混乱                           |
|                                           │                               |
|                                           ▼                               |
|                                     全额退审/大额核减                      |
|                                     拖延回款 6-24 个月                     |
|                                           │                               |
|                                           ▼                               |
|                                     进入司法诉讼程序                      |
|                                     鉴定机构无法计量                      |
|                                     主张被驳回/亏损放大                    |
+-----------------------------------------------------------------------------------+
```

#### 6.1.2 官方真实审计退审与审减案例深度剖析

##### 案例一：深圳某市政管网改造政府投资项目全额退审与审减案
* **项目背景**：深圳某市政管网改造政府投资项目，现场施工全部完工，五方责任主体验收合格，施工质量、进度及安全管理均达到规范标准，现场无违规问题 [05, 06]。施工单位认为验收通过即可顺利结算，仓促打包送审资料递交审计机关 [05, 06]。
* **技术或商务做法**：
  1. 地下管线迁改、基底处理等关键隐蔽工序，未附带完整的隐蔽工程验收记录、原始标高复测资料及全过程现场带水印影像留痕 [05, 06]。
  2. 现场发生的增量工程仅附有简易签证单，缺乏前置专项协调会议纪要、发包人书面变更指令及监理单位审批依据 [05, 06]。
  3. 施工日志、监理日志、签证签署日期与工序验收时间前后冲突，时间线无法自洽 [05, 06]。
* **金额装机与成本收益数据**：
  审计机关认定该项目资料不符合合规要求，实施全额退审；对无前置依据的现场增量工程认定为“无依据私自施工”，直接核减结算金额 **48.6万元**，并导致结算审核停滞，项目回款拖延 **8个月** [05, 06]。在诉讼层面推演中，因缺乏基础佐证材料，司法鉴定机构无法计量，法庭驳回该部分工程款主张；叠加资金占用成本、管理费用及诉讼鉴定费，项目整体亏损超 **60万元** [05, 06]。
* **可复制教训**：
  1. 审计机关与法庭仅审查闭环合规资料，不采信口头陈述或现场施工辛苦程度 [05, 06]。
  2. 每一笔变更增量产值必须形成“书面指令→过程记录→隐蔽验收→签证盖章→影像留痕→计算书”的完整证据链 [05, 06]。
  3. 送审前必须对施工日志、监理日志、验收单与签证签署时间进行全面逻辑核查，确保时间线完全自洽 [05, 06]。

##### 案例二：南京下关码头候船厅修缮工程结构加固专业分包案
* **案号/法院**：南京市鼓楼区人民法院（2017）苏0106民初9500号民事判决 [02]。
* **项目背景**：2012年3月15日，发包人南京城建项目建设管理有限公司（城建公司）与总承包人南京市第十建筑工程有限公司（十建公司）签订《原下关码头候船厅西山工程施工承包合同》（总包合同），约定工期2012年2月29日至2012年8月31日，暂定合同金额为人民币 **10980000元**（1098万元），采用暂定合同价，分部分项费用优惠 **10%**，最终以政府决算审计批复数为准 [02]。总包合同特别约定：“如果监理单位对承包人所报结算的核减数超过承包人报审数的 **10%**，视为承包人违约，违约金为施工合同总价的 **1%**” [02]。2012年5月，十建公司与分包人江苏江南艺术装饰有限公司（江南公司）签订《建设工程施工专业分包合同》（分包合同），分包原下关码头候船厅修缮工程结构加固专业工程，约定价款以政府决算审计批复数为准；分包人承诺让利优惠 **13%**，支付总包管理配合费 **3%**，承担城建档案馆竣工资料档案管理整理费 **0.1%**；违约责任约定若总包拖延支付进度款需按银行同期贷款利率支付利息并承担分包合同总价 **1%** 的违约金 [02]。工程于2012年底整体竣工验收 [02]。
* **技术或商务做法**：城建公司组织对工程进行政府决算审计 [02]。在送审过程中，由于施工方报送的送审金额虚高且资料支撑不足，导致初审与审定金额发生重大审减 [02]。
* **金额装机与成本收益数据**：
  在《南京原下关码头候船厅修缮工程审核汇总表》审计结果中：
  1. 总包“原下关码头候船厅修缮工程”施工方送审价为 **18329573.54元**，初审价为 **15151846.85元**，审定价为 **13755163.24元** [02]。由于送审价与初审价的差额达到 **3177726.69元**（占送审价 **17.34%**），远超报审数 **10%** 的阈值，总包十建公司被发包方扣罚合同总价 **1%** 的违约金 **109800元** [02]。
  2. 分包案涉结构加固工程，江南公司送审价为 **4234860.52元**，初审价为 **3055396.46元**，审定价为 **3011715.79元**，审定价与初审价核减数额为 **43680.67元** [02]。分包送审价与初审价差额高达 **1179464.06元**（占送审价 **27.85%**） [02]。十建公司据此要求江南公司按比例承担向发包方支付的违约金 **56239.56元** [02]。
  3. 法院审理认定，分包合同约定分包人履行总包合同相应义务，江南公司送审价严重超标触发违约责任，判决江南公司承担违约金 **56239.56元** [02]。在扣除已付工程款 **2773757元**、让利优惠 **3%**、总包配合费 **3%**、档案管理费 **0.1%**、税费 **11112.67元** 及成本发票 **9994.25元** 后，判决十建公司仅需支付剩余工程款 **60110.09元** [02]。
* **可复制教训**：
  1. 施工企业送审时必须严密核算送审金额，严禁盲目虚报送审价 [02]。当合同中存在“审减率超10%按总价1%扣减违约金”的惩罚性条款时，送审价水分过大会直接引发高额违约扣罚 [02]。
  2. 总承包商与分包商在签订分包合同时，应明确送审资料编制责任与审减违约金的分担机制，避免因分包送审资料瑕疵引发连锁赔偿 [02]。

##### 案例三：浙江杭州红楼大酒店II标段及I、III、IV标段装饰工程结算审减案
* **案号/法院**：杭州市上城区人民法院（2009）杭上民初字第748号民事判决 [03]。
* **项目背景**：2005年8月，发包人浙江红楼实业发展有限公司（红楼实业）与承包人中天建设集团有限公司（中天公司）签订施工合同，发包杭州红楼大酒店II标段工程（总建筑面积约 **10166平方米**，合同价 **9343976元**，工期 **150个日历天**，约定2006年1月27日竣工） [03]。2005年8月20日双方签署补充协议，增加承包土建改扩建工程（门厅钢构、加层及观光电梯钢结构约 **1400平方米**）以及I标段（1至4层）、III标段（16至22层）、IV标段（23至27层）装饰装修工程，约定完工日期为2005年11月20日，并约定工期逾期违约罚款为每日 **8万元**（I标段每日 **3万元**、III标段每日 **2万元**、IV标段每日 **3万元**） [03]。工程于2005年9月28日开工，2006年3月28日提交竣工报告，2006年11月28日取得竣工验收备案表 [03]。
* **技术或商务做法**：红楼实业委托建设银行金华分行工程造价咨询中心及杭州全备建设咨询有限公司对工程结算进行审核 [03]。在审核过程中，施工单位报送的送审资料缺乏充分的过程签证与作废图纸说明，导致咨询机构实施大幅度审核扣减 [03]。红楼实业同时以中天公司逾期竣工为由诉请支付工期违约金 **4800000元**（480万元） [03]。
* **金额装机与成本收益数据**：
  造价咨询机构出具的结算审定结果显示：
  1. III、IV标段装饰装修工程：送审价为 **28355050元**，审定价为 **18389368元**，审减金额达 **9965682元**（审减率 **35.15%**） [03]。
  2. I标段及土建改造工程：送审价为 **43620216元**，审定价为 **27951724元**，审减金额达 **15668492元**（审减率 **35.92%**） [03]。
  3. II标段装饰水电安装工程：送审价为 **5699625元**，审定价为 **3251304元**，审减金额达 **2448321元**（审减率 **42.96%**） [03]。
  4. 汇总数据：中天公司报送的送审总价为 **77674891元**（7767.49万元），审定总价为 **49430805元**（4943.08万元），总审减金额高达 **28244086元**（2824.41万元，总体审减率达 **36.36%**） [03]。红楼实业已付工程款现金 **29760000元**、借款 **20000000元**、应扣款 **2856620.76元**，合计 **52616620.76元** [03]。
* **可复制教训**：
  1. 在多标段、大金额装饰与改造工程中，若送审资料缺乏严密的图纸会审、变更确认及量化计算书，第三方造价机构将依据最严审计标准核减工程量 [03]。
  2. 送审资料出现高达 **36.36%** 的审减率，会导致施工企业在资金结算中处于极度不利地位，引发长达数年的诉讼纠纷与资金沉淀 [03]。

#### 6.1.3 审计与诉讼双重视角下的三大黄金通关原则
基于对官方审计审核规则与司法裁判视角的总结，工程企业送审前必须贯彻以下三大黄金原则 [05, 06]：

```
+-----------------------------------------------------------------------------------+
|                        竣工结算送审三大黄金通关原则                               |
+-----------------------------------------------------------------------------------+
|  1. 完整闭环原则  │ 每笔产值配置完整链条:                                         |
|                   │ 联络单/指令 ──> 施工记录 ──> 验收确认 ──> 签证盖章 ──> 计算书  |
+-------------------+---------------------------------------------------------------+
|  2. 逻辑自洽原则  │ 时间线无缝匹配:                                               |
|                   │ 施工日志时间 ＝ 监理日志时间 ＝ 验收时间 ＝ 影像水印时间       |
+-------------------+---------------------------------------------------------------+
|  3. 签字合规原则  │ 身份与权限合法:                                               |
|                   │ 仅限合同约定授权人签署，严禁代签、漏签或非授权人员补签        |
+-----------------------------------------------------------------------------------+
```

1. **完整闭环原则**：每一笔增量产值必须配齐“发包方/监理指令文件→施工过程记录→隐蔽/工序验收确认→现场签证盖章→带水印影像留痕→工程量计算书”的完整证据链 [05, 06]。缺少任何一个环节，审计将予以全额审减，诉讼中法庭亦不予支持 [05, 06]。
2. **逻辑自洽原则**：施工时间、签证时间、验收时间、影像留痕时间及日志记录时间必须完全吻合，不得出现集中补填、时间前后倒置或逻辑矛盾 [05, 06]。审计机关对集中补签资料一律按无效凭证处理 [05, 06]。
3. **签字合规原则**：所有工程签证、会议纪要及验收单据的签字人员，必须为合同约定的法定代表授权人 [05, 06]。无授权人员签字、代签或漏签文件，在审计与诉讼中均被认定为无效凭证 [05, 06]。

### 6.2 竣工结算送审全套合规资料七大核心板块作业清单（上部）

#### 6.2.1 板块一：招投标及合同类资料（结算计价底层基准与诉讼裁判依据）

##### （1）完整合规资料清单
招投标与合同文件是结算审计的最高准则，也是诉讼裁判的首要法定依据 [05, 06]。送审前须配齐以下文件 [05, 06]：
* 中标通知书、全套招标文件（含补遗文件、答疑澄清纪要） [05, 06]。
* 完整投标文件（商务标计价文件及技术标施工组织设计） [05, 06]。
* 施工合同正本及副本、全套补充协议、安全文明施工协议、廉政协议 [05, 06]。
* 甲乙双方权责划分附件及风险分担专项约定文件 [05, 06]。

##### （2）审计核心核查重点与诉讼风险提示
* **审计核查重点**：核对项目计价模式（单价包干、总价包干或工程量清单计价）、材料调差阈值与调价公式、市场价格风险承担边界、签证与索赔的时效限制、工期违约金计算标准、甲供材料核销规则以及结算报送违约罚则 [05, 06]。
* **诉讼风险提示**：缺失招投标补遗或合同附件，发生争议时法院难以认定双方真实合意；超出合同约定的签证或索赔主张，审计不予采信，法庭亦无法予以支持 [05, 06]。

##### （3）送审前闭环合规编制步骤（可执行步骤）

```
+-----------------------------------------------------------------------------------+
|                     板块一：合同类资料送审编制五步法                              |
+-----------------------------------------------------------------------------------+
|  步骤一：合同文件全扫描 ──> 建立合同条款主台账 (锁定计价/调差/违约/时效条款)        |
|  步骤二：签署补充协议盘点 ──> 核查补充协议有效性与备案状态                        |
|  步骤三：商务标与技术标匹配 ──> 对照原投标清单与施工方案规避漏项                  |
|  步骤四：风险条款对账 ──> 整理材料调差单据与风险扣减凭证                          |
|  步骤五：卷宗编号与盖章 ──> 形成送审合同类资料独立卷宗 (附文件目录及交接单)        |
+-----------------------------------------------------------------------------------+
```

* **步骤一（合同文件全扫描）**：装订整理全套招投标与合同文件，建立《合同计价与结算核心条款台账》，逐项梳理计价模式、调价阈值及结算违约罚则 [05, 06]。
* **步骤二（补充协议效力核查）**：清查项目履约期间签订的所有补充协议，核对补充协议是否符合主体资质要求，涉及重大变更的须核查是否完成法定备案程序 [03, 05, 06]。
* **步骤三（投标标书一致性复核）**：核对商务标清单价格与技术标施工方案，重点复核措施费包干范围与综合单价组成，防范审计以“投标已包含”为由实施审减 [05, 06]。
* **步骤四（风险与让利条款对账）**：核对合同约定的优惠折扣率（如让利3%或13%）、总包配合费（如3%）及档案管理费（如0.1%），在送审汇总表中进行准确列示，防止二次核减纠纷 [02, 05, 06]。
* **步骤五（卷宗归档与交接）**：将合同类资料装订成册，编制目录并加盖公章，办理双签书面交接手续 [05, 06]。

#### 6.2.2 板块二：全套图纸类资料（工程量唯一计量依据与司法鉴定基础）

##### （1）完整合规资料清单与竣工图硬性要求
图纸是工程量计算与司法鉴定的核心载体 [05, 06]。必须提供 [05, 06]：
* 全套有效施工蓝图、图纸会审纪要、设计答疑记录 [05, 06]。
* 施工全过程设计变更说明及作废图纸留存归档记录 [05, 06]。
* 最终版合规竣工图（加盖竣工图章并经监理与发包方签字确认） [05, 06]。
* **竣工图硬性合规要求**：竣工图必须 **100%** 匹配现场实际施工工况，所有设计变更、现场增量、节点调整及工序改动必须完整标注、图实相符；图纸页码完整，签字盖章齐全，严禁使用未更新或已作废的图纸报送结算 [05, 06]。

##### （2）审计核心核查重点与诉讼风险提示
* **审计核查重点**：对照竣工图核查工程量计算书的真实性，重点审核是否存在旧图纸重复计算、作废变更未扣减、未按图施工或私自扩大施工范围等问题 [05, 06]。
* **诉讼风险提示**：竣工图与现场不符或变更未在图纸上标注，审计将直接核减对应工程量；司法鉴定机构无法依据存在矛盾的图纸进行计量，施工单位将面临举证不能的败诉后果 [05, 06]。

##### （3）图纸动态更新与计量闭环实操步骤（可执行步骤）
* **步骤一（蓝图与变更图纸清理）**：全面盘点施工蓝图、设计变更单及图纸会审纪要，标记所有发生局部调整或结构变更的轴线与图幅 [05, 06]。
* **步骤二（作废图纸封存）**：对因设计重大修改而作废的旧图纸进行加盖“作废章”封存，建立作废图纸目录，防止错误混入送审资料 [05, 06]。
* **步骤三（竣工图重新编制与重叠标注）**：依据设计变更通知单与现场签证，在竣工图上使用红笔或专业软件精准绘制变更节点，注明变更单号及签署日期 [05, 06]。
* **步骤四（五方盖章与审查闭环）**：将重新编制的竣工图递交现场监理工程师与发包方代表审核，加盖合规的“竣工图章”，并由项目经理、总监理工程师签字确认 [05, 06]。
* **步骤五（图实对应抽查校验）**：送审前由造价人员与质检人员对照现场实物进行随机抽查，校验竣工图尺寸、标高与实际施工是否完全一致 [05, 06]。

#### 6.2.3 板块三：施工过程管理资料（施工真实性佐证与工期争议防线）

##### （1）完整合规资料清单
过程管理资料是证明项目施工合法合规、工序完整及工期真实性的核心凭证 [05, 06]。包含 [05, 06]：
* 开工报告、复工报告、停工报告及工期顺延申请与正式书面批复文件 [05, 06]。
* 施工组织设计、专项施工方案及监理审批批复文件 [05, 06]。
* 全过程施工日志、监理日志、分部分项工程质量验收记录 [05, 06]。
* 五方竣工验收记录、竣工验收报告、竣工验收备案表及消防、环保、节能等专项验收资料 [05, 06]。

##### （2）审计核心核查重点与工期违约金对抗风险
* **审计核查重点**：核对全周期施工时间线，审查工期顺延申请是否在合同约定时效内提出并取得书面批复；审查专项施工方案的审批合规性，未经审批的措施费用不予计价；匹配施工日志与签证时间 [05, 06, 15, 18]。
* **诉讼风险提示**：缺乏正式工期顺延批复、开复工报告或施工日志，审计将扣减工期相关措施费；一旦发包方反诉主张高额工期延误违约金（如每天3万至8万元），施工单位将因缺少免责证据而承担巨额赔偿 [03, 05, 06, 15, 18]。

##### （3）过程管理资料动态留痕与责任确认步骤（可执行步骤）
* **步骤一（工期节点台账梳理）**：建立从开工报告、实际开工日、阶段性停工/复工日至竣工验收备案的全过程时间线台账 [05, 06, 15]。
* **步骤二（工期顺延闭环补正）**：针对因发包方原因（如图纸延误、征地拆迁阻碍、未按时支付进度款）导致的工期延误，整理对应的“发函-催办-顺延申请-监理/发包方书面批复”完整链条；若缺乏书面批复，补充监理日志与相关协调会议纪要作为佐证 [03, 05, 06, 15, 18]。
* **步骤三（施工日志与监理日志对账）**：抽查施工日志中的关键工序节点、气象记录及停窝工记录，与监理日志进行逐日核对，确保双方记录在关键时间与事件上高度一致 [05, 06, 14, 20]。
* **步骤四（专项方案审批归档）**：检查所有超过一定规模的危险性较大分部分项工程（如深基坑、高支模）专项施工方案，核查专家论证意见及监理工程师审批签字，确保符合计价条件 [05, 06]。
* **步骤五（验收文件汇总装订）**：将五方竣工验收记录及各专项验收表按时间顺序装订，确保盖章齐全、签字合规，形成过程管理送审卷宗 [05, 06]。

### 6.3 审计相关法律政策与司法解释深度对接（上部）

工程结算送审与审计攻防必须严格对接国家法律法规、最高人民法院司法解释以及行政监管文件。以下针对核心政策条款进行法律效力与应对实操解析。

#### 政策解读一：《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》（法释〔2004〕14号）

* **文件名与文号**：《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》（法释〔2004〕14号） [02, 03, 07, 12, 19, 16]。
* **核心条款**：
  1. **第二条**：建设工程施工合同无效，但建设工程经竣工验收合格，承包人请求参照合同约定支付工程价款的，应予支持 [02, 03, 16, 19]。
  2. **第三条**：建设工程施工合同无效，且建设工程经竣工验收不合格的，按下列情形处理：（一）修复后竣工验收合格的，发包人请求承包人承担修复费用的，应予支持；（二）修复后竣工验收不合格的，承包人请求支付工程价款的，不予支持 [16]。
  3. **第十四条**：当事人对建设工程实际竣工日期有争议的，按照下列情形分别处理：（一）建设工程经竣工验收合格的，以竣工验收合格之日为竣工日期；（二）承包人已提交竣工验收报告，发包人拖延验收的，以承包人提交竣工验收报告之日为竣工日期；（三）建设工程未经竣工验收，发包人擅自使用的，以转移占有建设工程之日为竣工日期 [03, 15, 18]。
  4. **第十九条**：当事人对工程量有争议的，按照施工过程中形成的签证等书面文件确认。承包人能够证明发包人同意其施工，但未能提供签证文件证明工程量发生的，可以按照当事人提供的其他证据确认工程量 [07, 10, 16]。
  5. **第二十条**：当事人约定承包人提交竣工结算文件后，发包人在约定期限内不予答复即视为认可竣工结算文件的，按照约定处理。承包人请求按照竣工结算文件结算工程价款的，应予支持 [02, 03, 12, 19]。
* **对投标与成本的影响**：条款明确了合同无效时的结算规则、实际竣工日期的法定判定标准、签证书面凭证的举证责任以及“限期不答复视为认可送审价”的法定效力。这直接决定了工程量签证留痕成本、工期违约金防范以及结算报送策略 [02, 03, 12, 19]。
* **应对要点**：
  1. 在施工合同中必须明确约定“发包人在收到竣工结算文件后结算审核答复的具体期限（如28天或60天），逾期未答复且未提出书面异议的，视为认可承包人送审结算文件” [02, 03, 12, 19]。
  2. 提交送审资料时，必须通过EMS邮寄或现场签收方式留存发包方签收凭证，锁定答复期限起算点 [02, 03, 12, 19]。
  3. 针对未签发书面签证的增量工程，须及时收集会议纪要、施工图纸、往来函件及现场影像，构建“其他证据链”以支撑工程量认定 [07, 10, 16]。

#### 政策解读二：《最高人民法院关于审理独立保函纠纷案件若干问题的规定》（法释〔2016〕24号）

* **文件名与文号**：《最高人民法院关于审理独立保函纠纷案件若干问题的规定》（法释〔2016〕24号） [01]。
* **核心条款**：第一条明确独立保函的独立性特征；第五条至第十二条规范独立保函开立、索赔条件、欺诈认定及止付令裁定标准 [01]。四川省高级人民法院等司法机关在涉及境外及大型EPC工程保函纠纷中，均严格援引本规定审理保函索赔抗辩 [01]。
* **对投标与成本的影响**：在大型EPC总承包及境外工程中，发包方往往要求开具见索即付的履约保函与预付款保函。若结算陷入争议，发包方可能通过恶意索赔保函强行扣款，导致承包人面临直接现金流损失与保函追偿成本 [01]。
* **应对要点**：
  1. 总承包商在送审结算过程中，须同步盘点履约保函与预付款保函的有效期限与索赔条件 [01]。
  2. 建立境外及大型工程分包介入权（Step-in Right）与独立保函索赔防范联动机制，确保底层施工资料完全闭环，一旦发包方无理索赔独立保函，能够迅速向法院申请止付令并提供欺诈索赔证据 [01]。

#### 政策解读三：《建设工程勘察设计管理条例》（国务院令第293号）

* **文件名与文号**：《建设工程勘察设计管理条例》（国务院令第293号） [20]。
* **核心条款**：第八条规定发包方不得将建设工程勘察、设计业务发包给不具有相应资质等级的单位；第十条规定编制建设工程勘察、设计文件，应当符合国家规定的质量标准和规范要求 [20]。
* **对投标与成本的影响**：在EPC工程中，设计与施工一体化融合。若设计分包单位缺乏资质或设计图纸未通过审图机构审查，将导致设计合同无效，进而影响变更设计计价的合法性与审计确认率 [20]。
* **应对要点**：
  1. 送审资料中须完整附带EPC总承包商及设计分包单位的资质证书、营业执照及施工图审查合格书 [20]。
  2. 对涉及主体结构的设计变更，必须核查是否由原设计资质单位出具并加盖注册结构工程师印章，确保变更资料符合法定形式要件 [05, 06, 20]。

### 6.2 竣工结算送审全套合规资料七大核心板块作业清单（下部）

#### 6.2.4 板块四：变更、签证、洽商与会议纪要（增量利润载体与价款争议主战场）

##### （1）完整合规资料清单
设计变更与现场签证是EPC工程与传统施工项目实现增量利润的核心载体，同时也是结算审计核减率最高、诉讼审理中双方对抗最激烈的领域[05, 06]。送审前必须配齐并核对以下资料：
* 设计变更通知单（由原设计单位出具，附变更图纸及注册结构工程师印章）[05, 06, 16]。
* 工程洽商记录与合规现场签证单（包含工程量现场核实单与隐蔽部位收方单）[05, 06, 10]。
* 工程联系单及发包人、监理单位书面现场施工指令[05, 06, 10]。
* 专项技术协调会议纪要、专题例会纪要（需附带参会各方人员签到表及会签盖章页）[05, 06]。
* 甲乙双方施工往来函件、催告函及完整书面签收送达记录[05, 06]。

##### （2）审计审核标准（铁规）与诉讼风险提示
* **审计审核铁规**：所有增量工程计价必须形成“**前置书面指令→施工过程记录→隐蔽/工序验收→现场签证盖章→带水印影像留痕→工程量计算书**”的完整逻辑闭环[05, 06]。审计机关实施严格的“无前置审批不计价”规则，仅有施工方单方填报的签证单，而无发包人前置会议纪要或书面指令的，一律认定为承包人擅自施工，增量产值全额审减[05, 06, 10]。
* **诉讼风险提示**：在司法诉讼中，发包人普遍抗辩现场签证属于承包人自行增加工程量或质量瑕疵修复[07, 10]。若承包人无法提供发包人前置指令或监理工程师的明确书面确认，司法鉴定机构将不予计量，法院亦不予支持该部分增量工程款[05, 06, 10]。

##### （3）变更签证防线构建与追溯确认步骤（可执行步骤）

```
+-----------------------------------------------------------------------------------+
|                  板块四：变更签证送审编制与追溯确认五步法                        |
+-----------------------------------------------------------------------------------+
|  步骤一：前置指令溯源 ──> 匹配变更通知单/会议纪要/书面指令                        |
|  步骤二：现场实测与收方 ──> 联合监理/发包方现场测量并签署收方单                    |
|  步骤三：闭环签署与盖章 ──> 取得合同约定授权人签字并加盖项目部/公章               |
|  步骤四：单价与计算书编排 ──> 依据合同计价规则编制变更单价与工程量计算书          |
|  步骤五：台账交叉检索 ──> 建立变更签证索引台账与图纸编号映射                      |
+-----------------------------------------------------------------------------------+
```

* **步骤一（前置指令溯源）**：清理项目所有增量签证，逐项核对前置依据。若缺乏正式变更通知单，必须从会议纪要、工程联系单批复或发包人现场指令函中提取书面指令依据[05, 06, 10]。
* **步骤二（现场实测与联合收方）**：针对涉及基坑开挖、地质条件变更等隐蔽增量，必须在覆土或封闭前邀请发包人现场代表及监理工程师进行实测实量，共同签署《现场工程量联合收方单》[05, 06]。
* **步骤三（闭环签署与授权确认）**：核对签证单上的签署人员身份，确保签字人为合同明确授权的项目代表或总监理工程师。严禁集中补签或由无授权资质的现场员代签[05, 06, 10]。
* **步骤四（变更单价与计算书编排）**：依据合同约定的变更计价原则（合同已有适用单价的按已有单价，有类似的参照类似单价，无适用的按定额编制认价），编写带详细计算过程的变更工程量计算书[05, 06, 17]。
* **步骤五（台账建立与交叉检索）**：编制《变更签证送审总台账》，列明签证单号、前置指令号、关联图纸轴线、送审金额及影像资料索引编号，实现审计调阅“一表即查”[05, 06]。

#### 6.2.5 板块五：隐蔽工程及验收资料（杜绝隐形亏损与司法鉴定必查）

##### （1）完整合规资料清单
隐蔽工程是工程结算审计审减率最高、最易发生“实际施工投入大却无法获得计价”的重灾区[05, 06]。工序覆土、封闭或浇筑完成后，现场物理原貌永久灭失，送审资料是固定施工事实的唯一凭证[05, 06]。必须提供：
* 隐蔽工程验收记录表（按分部分项及检验批分类装订）[05, 06]。
* 基底验槽记录、地基承载力检测报告及路基分层压实度检测记录[05, 06]。
* 建筑防水细部构造验收资料、钢筋隐蔽工程验收记录及管线预埋收方记录[05, 06]。
* 现场原始地貌标高测绘图、基坑开挖复测标高记录及联合收方单[05, 06]。
* 全过程带GPS定位与时间水印的隐蔽工序施工现场影像资料[05, 06]。

##### （2）审计铁规与诉讼风险提示
* **审计审核铁规**：所有覆土、封闭或浇筑的隐蔽工序，实施严格的“**无验收记录、无联合收方、无标高复测、无水印影像、无签字闭环＝零产值**”核算规则[05, 06]。无论施工单位现场实际投入多少人工、材料与机械成本，只要资料链断裂，审计机关一律按全额核减处理[05, 06]。
* **诉讼风险提示**：隐蔽工程资料缺失，进入司法诉讼程序后，司法鉴定机构无法对物理灭失的隐蔽工程进行现场勘验与重新计量[05, 06, 08]。法庭将依据证据裁判原则驳回该部分工程款诉求，施工单位将固化承担全部实际投入成本损失[05, 06, 08]。

##### （3）隐蔽工程全流程影像留痕与三维数据归档步骤（可执行步骤）
* **步骤一（开挖前原始地貌标高留痕）**：工程开挖或基底处理前，联合发包人代表、监理工程师及测绘单位对现场原始地貌进行标高测量，绘制《原始标高测绘图》并三方会签[05, 06]。
* **步骤二（工序隐蔽前联合验收）**：在钢筋绑扎、管线预埋、防水施工完毕及混凝土浇筑前，提前24小时通知监理及发包人代表进行现场隐蔽验收，签署《隐蔽工程验收记录》[05, 06]。
* **步骤三（现场收方与标高复测）**：对基坑深度、开挖土方量、换填厚度等几何尺寸进行实测，记录复测标高数据，签署《隐蔽工程收方结算单》[05, 06]。
* **步骤四（带水印影像资料归档）**：使用具备防篡改功能的影像设备拍摄现场施工过程，照片须清晰显示全局轮廓、局部细节、钢筋间距标尺及GPS经纬度与时间水印，按分项工程编号归档[05, 06]。
* **步骤五（数据映射至竣工图）**：将隐蔽工程的实测尺寸、标高数据及变更记录同步标注至竣工图对应节点，确保送审图纸与隐蔽资料数据完全对应[05, 06]。

#### 6.2.6 板块六：造价结算成套资料（定审回款核心文件与结算计价基础）

##### （1）完整合规资料清单
造价成套资料是项目报送审计、发包方确认定案金额以及确定最终工程款支付数额的核心成果文件[05, 06]。必须提供：
* 竣工结算编制说明及竣工结算汇总表[05, 06]。
* 分部分项工程量清单计价表、措施项目费明细表、其他项目费明细表、规费与税金计算表[05, 06]。
* 附带完整计算过程与公式的工程量计算书[05, 06]。
* 主要材料与设备价差调整表、材料设备认价汇总表[04, 05, 06]。
* 甲供材料/设备领用、耗用及退料扣卷台账[05, 06]。
* 施工期间奖惩扣款通知单及施工索赔费用计算书[03, 05, 06]。

##### （2）核心合规提醒与诉讼风险提示
* **核心合规提醒**：送审造价资料必须实现数据“**三统一**”，即纸质盖章版结算书、PDF电子扫描件以及计价软件电子工程文件（如广联达、神机妙算等格式）中的工程量、单价、费率及总价数据必须 **100%** 完全一致[05, 06]。工程量计算书必须附带清晰的列式计算过程，严禁仅附结果无计算式[05, 06]。
* **诉讼风险提示**：若送审结算资料版本混乱、前后数据冲突或缺乏计算式，审计机关将直接作退审处理[05, 06]。进入诉讼后，司法鉴定机构将认为承包人单方结算书缺乏可信度，进而直接采信发包人主张的结算金额或以定额下限进行鉴定，导致工程价款发生大幅缩水[05, 06, 08, 11]。

##### （3）造价成套资料逻辑校验与版本勾稽控制步骤（可执行步骤）

```
+-----------------------------------------------------------------------------------+
|                  板块六：造价结算成套资料逻辑校验五步法                           |
+-----------------------------------------------------------------------------------+
|  步骤一：计算式全过程勾稽 ──> 校验工程量计算书与竣工图/签证尺寸一致性            |
|  步骤二：甲供材对账与扣减 ──> 校验领用台账/定额消耗量与实际扣款数额              |
|  步骤三：认价与发票复核 ──> 对照材料认价单/采购发票与市场信息价                  |
|  步骤四：三版数据交叉校验 ──> 核对纸质/PDF/软件电子文件数据100%一致              |
|  步骤五：卷宗封卷与双签交接 ──> 编制结算书封面并由造价师签字盖公章送审            |
+-----------------------------------------------------------------------------------+
```

* **步骤一（计算式全过程勾稽）**：造价人员对工程量计算书进行全面交叉复核，检查计算式中的几何尺寸与竣工图、变更签证及隐蔽收方单是否完全吻合，消除计算笔误[05, 06]。
* **步骤二（甲供材对账与扣减核算）**：核对甲供材料领用台账，依据合同定额消耗率计算理论耗用量，对合理损耗与超耗部分进行准确列算，编制《甲供材结算扣款对账表》[05, 06]。
* **步骤三（认价单与发票复核）**：整理发包人签署的材料设备认价单，核对认价范围是否覆盖暂估价项目，并附带采购发票及询价佐证凭证[04, 05, 06]。
* **步骤四（三版数据交叉校验）**：在打印装订前，由专人对纸质文本、PDF文件与软件电子文件进行逐项比对，确保各表总价、分部分项小计及规费税金精确一致[05, 06]。
* **步骤五（封卷盖章与书面交接）**：结算书须由注册一级造价工程师签字并加盖执业印章，加盖施工单位公章，编制送审目录后向发包人办理书面交接[05, 06]。

#### 6.2.7 板块七：工程材料/设备认价与调差成套资料（成本核销与材料调差防线）

##### （1）完整合规资料清单
大型EPC工程与房建、市政项目运行周期长，大宗建筑材料（如钢筋、水泥、商品混凝土、沥青）及主设备价格波动剧烈，材料认价与调差资料是保障施工企业成本核销与合理利润的最后防线[04, 05, 06]。必须提供：
* 材料与大宗设备采购合同、增值税专用发票、付款银行流水凭证[04, 05, 06]。
* 发包人及监理单位会签的《材料/设备暂估价认价单》及询价三方会签表[04, 05, 06]。
* 施工期间各月份工程所在地造价管理部门发布的地方工程造价信息价对账表[04, 05, 06]。
* 大宗材料动态价格调差计算书（含基准期价格、风险系数及调差公式）[04, 05, 06]。
* 甲供材料交接验收单、现场入库单、领用台账及余料退库凭证[05, 06]。

##### （2）审计核心核查重点与诉讼风险提示
* **审计核查重点**：审核认价单签署人员的授权效力，核查认价金额是否包含运杂费及采保管费；核查材料调差的基准期月度信息价与实际施工进度的匹配度；审查甲供材料是否存在超耗未扣或损耗率计算错误[04, 05, 06]。
* **诉讼风险提示**：若未在施工过程中取得发包人的书面认价单，且合同未约定明确的调差公式，审计机关与司法鉴定机构将直接按造价信息价的下限计价，或拒绝调整市场暴涨差价，导致施工单位自行承担巨额材料亏损[05, 06, 08, 11]。

##### （3）材料设备认价与调差审核编制步骤（可执行步骤）
* **步骤一（询价与认价闭环）**：在材料采购前，向发包人及监理报送《材料设备暂估价认价申请表》，附带三家以上供应商询价对比表及采购合同草案，取得发包人书面认价批复[04, 05, 06]。
* **步骤二（信息价与基准价对账）**：梳理合同约定的基准期价格（如投标截止日前28天的造价信息价），收集施工期间各月信息价，确定风险承担范围（如±5%以内不调，超出部分调差）[04, 05, 06]。
* **步骤三（耗用量与进度区间映射）**：依据施工日志与工程款支付节点，将材料实际消耗量映射至具体施工月度，准确套用当月信息价计算价格差额[04, 05, 06]。
* **步骤四（调差汇总与送审编制）**：编写《大宗材料调差明细表》，列明材料名称、规格、合同基准价、施工期信息价、风险幅度、实际调差单价及调差总额，作为结算附件送审[04, 05, 06]。

### 6.3 审计相关法律政策与司法解释深度对接（下部）

#### 政策解读四：《关于促进建筑业持续健康发展的意见》（国办发〔2017〕19号）与《房屋建筑和市政基础设施项目工程总承包管理办法（征求意见稿）》（建市设函〔2017〕65号）

* **文件名与文号**：国务院办公厅《关于促进建筑业持续健康发展的意见》（国办发〔2017〕19号）、住房和城乡建设部《房屋建筑和市政基础设施项目工程总承包管理办法（征求意见稿）》（建市设函〔2017〕65号）[01]。
* **核心条款**：
  1. 国家大力推行工程总承包（EPC）模式，鼓励采用设计、采购、施工一体化建造方式[01]。
  2. 工程总承包项目宜采用总价合同，除合同约定可以调整的情形外，合同总价一般不予调整[01]。
  3. 建设单位不得将未完成初步设计与概算审批的项目盲目按EPC总承包发包；工程总承包企业对工程质量、安全、工期和造价全面负责[01]。
* **对投标与成本的影响**：政策文件确立了EPC工程“固定总价包干为主”的法定计价导向[01]。行政审计机关在对EPC项目进行审计时，不得随意将固定总价合同拆解为传统的单价定额预算进行全盘重算[01, 17]。但发包人往往利用审查机制，试图通过设计优化审减总价包干范围内的工程造价[01, 07, 17]。
* **应对要点**：
  1. 送审资料编制时，必须将工程划分为“合同内固定总价包干部分”与“发包人要求变更引起的增量调价部分”两个独立板块[01, 17]。
  2. 对合同内总价包干部分，送审资料重点提供合同、竣工图及五方验收合格凭证，坚决抵制审计机关对总价包干项目按定额细化审减[01, 17]。
  3. 对发包人原因导致的重大设计变更、主要设备规格调整或现场工况重大变化，严格按合同约定的变更调价条款报送增量结算[01, 10, 17]。

#### 判例解析一：重庆半山一号房地产有限公司与望建（集团）有限公司建设工程施工合同纠纷案

* **案号/法院**：重庆市高级人民法院（2017）渝民申2129号民事裁定[07]。
* **项目背景**：半山一号公司（发包人）与望建公司（承包人）签订《重庆曼哈顿城项目二期4、5标段花园洋房（62#-84#、16#、45#、46#）总承包合同》[07]。履约过程中双方发生争议解除合同，望建公司起诉要求半山一号公司支付已完工程款[07]。二审法院判决依据结算审核报告确定的金额支付工程款[07]。半山一号公司向重庆高院申请再审，主张已完工程质量存在缺陷、结算审核报告不能作为依据以及不应支付中止施工违约金[07]。
* **技术/商务做法与金额数据**：
  1. 双方在合同中约定：承包人施工进度得到发包人书面认可后申报进度款，完成每个工程付款节点及关键节点均需由发包人组织的设计委员会验收[07]。
  2. 合同解除后，双方共同委托中介机构出具了结算审核报告[07]。
  3. 重庆市高级人民法院裁定认为：合同解除后已经履行的部分因无法恢复原状，发包人应支付相应工程款[07]。案涉工程已办理交接并进入结算程序，二审法院以结算审核报告审定的金额作为工程款结算依据符合法律规定[07]。最终裁定：驳回半山一号公司的再审申请[07]。
* **可复制教训**：
  1. 合同中途解除时，施工单位必须第一时间与发包人完成已完工程量的现场交接与节点验收，共同委托第三方审核机构出具结算审核报告[07]。
  2. 审计与司法实践均表明，双方共同确认的结算审核报告具有极强的法律约束力，法院将直接采信审定金额作为工程款支付依据[07]。

#### 判例解析二：胡元昌与广州市住宅建设发展有限公司、广州市越秀区房屋管理局建设工程合同纠纷案

* **案号/法院**：广东省高级人民法院（2017）粤民申6291号民事裁定[08]。
* **项目背景**：越秀区房管局与住建公司签订《建筑工程施工合同》，后因故解除合同[08]。越秀区房管局向住建公司支付了 **48万元** 赔偿款（其中 **40万元** 为解除合同导致的利润损失赔偿，**8万元** 为前期投入赔偿）[08]。实际施工人胡元昌起诉主张其在施工前准备阶段支付了费用，要求住建公司支付施工前费用 **46.8万元**[08]。
* **技术/商务做法与金额数据**：
  1. 胡元昌主张其看守现场聘请人员的工资为前期准备费用，但未能提供有效发票及书面签证凭证佐证[08]。
  2. 一审及二审法院审理中，胡元昌不同意对施工前费用进行司法评估，且未能提供证据证明其前期费用的具体数额[08]。
  3. 广州市中级人民法院二审酌情判决住建公司向胡元昌赔偿 **5万元**[08]。广东省高级人民法院裁定认为：胡元昌未能对其前期费用提供充分证据，又不同意评估，应承担举证不能的法律后果，二审法院酌情判决符合公平原则[08]。最终裁定：驳回胡元昌的再审申请[08]。
* **可复制教训**：
  1. 项目停窝工或施工前准备阶段发生的各项费用（如看守工人工资、机械租赁费、临时设施费），必须保留完整的财务支付凭证、现场签到表及发包人书面确认凭证[08, 14, 20]。
  2. 在诉讼或审计中，缺乏书面凭证且拒绝申请司法造价鉴定，将导致绝大部分索赔主张被依法驳回[08, 11]。

#### 判例解析三：云南兴源建设工程有限公司与云南省麻栗坡县气象局建设工程合同纠纷案

* **案号/法院**：云南省麻栗坡县人民法院（2017）云2624民初700号民事判决[12]。
* **项目背景**：2014年8月4日，兴源公司与麻栗坡县气象局签订《建设工程施工合同》，承建麻栗坡县菜园小区33号山洪业务平台配套设施建设项目[12]。2015年9月28日工程竣工验收合格并交付使用[12]。
* **技术/商务做法与金额数据**：
  1. 麻栗坡县审计局出具麻审决【2015】39号《审计决定书》，审计认定该项目工程结算总款项为 **3629409.20元**[12]。
  2. 气象局至2016年1月29日分13次累计支付工程款 **3141700.00元**，2017年9月13日支付 **20000.00元**，尚欠工程款 **467709.20元** 未付[12]。兴源公司起诉请求判令气象局支付欠款 **467709.20元** 及利息[12]。
  3. 麻栗坡县气象局对兴源公司主张的事实及审计决定金额无异议[12]。法院审理认定，国家机关审计决定确定的金额在双方均认可的情况下，具备直接确定民事权利义务的效力，判决麻栗坡县气象局支付工程款 **467709.20元** 并按年利率 **6%** 支付逾期利息[12]。
* **可复制教训**：
  1. 在政府投资项目中，当合同约定以行政审计结论作为结算依据，且审计机关出具正式《审计决定书》后，审计结论即成为确定双方工程款的法定基准[12, 19]。
  2. 施工单位在收到行政审计决定后，若对审计数额无异议，应迅速取得发包人的书面确认，直接转化为民事债权依据进行催收或起诉[12]。

#### 判例解析四：浙江某工程有限公司与义乌市某镇西岸村民委员会建设工程施工合同纠纷案

* **案号/法院**：浙江省义乌市人民法院（2010）金义苏溪商初字第358号民事判决[19]。
* **项目背景**：2003年9月26日，施工方与西岸村委会签订承包合同，承建西岸村晒场、花坛、垃圾房等小五化建设工程，约定完工验收合格后付至 **90%**，让利优惠 **15.65%**（或16.65%）[19]。2005年5月30日，浙江新世纪会计师事务所受施工方单方委托，对工程款进行决算审计，出具审定工程款为 **173958元** 的报告[19]。施工方扣除已付 **4万元** 后起诉催收剩余工程款 **133958元**[19]。
* **技术/商务做法与金额数据**：
  1. 村委会抗辩称：合同约定工程竣工后，施工方应提交竣工报告并由发包人会同有关人员进行验收，待验收合格后方可付款，但施工方至今未提交竣工报告，亦未组织竣工验收[19]。
  2. 村委会指出施工方单方委托出具的审计报告在依据和计算上存在明显瑕疵[19]。
  3. 义乌市人民法院审理认为：施工方未按合同约定提交竣工报告及组织竣工验收，付款条件尚未成就；且单方委托的审计报告缺乏合同依据与发包人确认，不能作为结算依据[19]。判决：驳回施工方的诉讼请求[19]。
* **可复制教训**：
  1. 施工单位切忌单方委托中介机构出具结算审计报告强行索赔，未经发包人参与或合同明确授权的单方审计报告在司法裁判中不予采信[19]。
  2. 竣工验收与竣工报告提交是工程款支付的前置条件，送审资料中必须包含发包人签署的竣工验收凭证，否则将被法院判决认定为“付款条件未成就”而败诉[05, 06, 19]。

### 6.4 EPC工程送审策略与审计攻防战术（上部：送审时机与编制攻防）

#### 6.4.1 送审时机选择与“视为认可”条款的应用战术

##### （1）“视为认可”条款的适用要件与司法裁判边界
《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》（法释〔2004〕14号）第二十条规定，当事人明确约定承包人提交竣工结算文件后发包人在约定期限内不予答复即视为认可结算文件的，按约定处理[02, 03]。但在工程实战与司法裁判中，“视为认可”条款的成功触发必须同时满足以下四个严苛条件：
1. **合同条款明确具体**：合同中必须明确书面约定具体的答复期限（如“发包人在收到结算文件后28天内未提出异议，视为认可送审价”），仅约定“及时结算”或“按规定结算”的，不能触发“视为认可”效力[02, 03]。
2. **送审资料完整闭环**：承包人报送的送审资料必须包含完整的竣工图、工程量计算书及变更签证依据。若送审资料残缺不全，发包人提出补正要求的时间将中断答复期限[05, 06]。
3. **送达手续真实合法**：承包人必须保留发包人明确签收送审资料的书面凭证，签收人须为合同约定的授权代表[02, 03, 05]。
4. **发包人逾期未作实质异议**：发包人在约定答复期限内既未出具审核意见，亦未提出具体异议或申请延期[02, 03]。

```
+-----------------------------------------------------------------------------------+
|                  “视为认可”结算条款触发与送达控防战术                             |
+-----------------------------------------------------------------------------------+
|  战术一：合同拟定 ──> 明确约定“N天不答复即视为认可送审价”绝对排他条款            |
|  战术二：资料完备 ──> 严格自查七大板块资料，确保无资料缺项触发退审                |
|  战术三：合规送送 ──> 采用EMS邮寄(备注送审清单)+现场公证双签交接                    |
|  战术四：时效监控 ──> 建立28天/60天答复倒计时台账，到期及时发函确认                |
+-----------------------------------------------------------------------------------+
```

##### （2）送审时效锁定与书面签收闭环流程
为防止发包人以“未收到资料”、“资料不全”或“签收人无权限”为由进行抗辩，施工企业应执行以下送送闭环流程：
* **流程一（送送资料前自查）**：对照本章七大板块资料清单完成全面自查，由项目经理与造价负责人共同签署《送审资料完备性确认书》[05, 06]。
* **流程二（EMS专递与现场公证交接）**：采取EMS邮寄方式送达时，必须在快递单“内件品名”栏详细注明：“《××工程竣工结算送审文件全套（含竣工图×册、结算书×册、变更签证×份）》”[05, 06]。在大型项目或争议敏感项目中，邀请公证处对现场送达交接过程进行全程公证[05, 06]。
* **流程三（签收回执归档）**：取得由发包人盖章或法定授权代表签字的《送审资料签收回执》，明确记载签收日期与资料份数，作为锁定“视为认可”答复期限的起算依据[02, 03, 05]。

#### 6.4.2 EPC总承包“柔性矩阵”与节点付款成就率提升

##### （1）基于OEI（EPC组织柔性效能指数）公式中“节点付款成就率”的组织拆解
在特大型工业与能源EPC总承包项目中，基于全章核心锚点公式[01]：
\\[\text{EPC 组织柔性效能指数 (OEI)} = \frac{\text{目标达成率} \times \text{节点付款成就率}}{\text{组织冗余率} + \text{用工合规风险系数}} \times \text{本土化适配因子}\\]

“节点付款成就率”是决定总承包项目现金流流转与最终审计通过率的关键分子端指标[01]。传统EPC项目管理中，设计、采购与施工部门各自独立履约，导致工程节点已在物理上完成，但过程技术文件、检验记录与质量控制计划（QCP）无法及时归集，发包人拒绝签署《进度款支付证明》，造成节点付款条件无法成就，项目资金大量沉淀[01]。

##### （2）技术文件归集与《进度款支付证明》签署成功率控制路径
为提升节点付款成就率与送审过审率，EPC企业须建立“总部能力平台+项目柔性矩阵”的组织协同路径[01]：
1. **建立《节点技术文件完备性核查表》**：将工程每个付款节点（如P&ID图纸交付、主设备到场、基础浇筑完成、隐蔽工程验收）所需的QCP质量控制计划、工厂试验标准、现场检验记录及隐蔽验收单编制为标准核查清单[01, 05, 06]。
2. **跨专业柔性小组跟进**：在项目部设立由设计经理、商务经理、质检工程师与造价师组成的柔性审核小组，实施“工序完成与资料归集同步验收”制度[01]。
3. **节点付款条件前置确认**：在向发包人申请签署《进度款支付证明》前，提前5个工作日完成技术文件闭环归集，确保送发包人的请款资料无瑕疵，实现《进度款支付证明》一次性签署成功率达到 **95%** 以上[01]。

#### 6.4.3 结算审减攻防战术与造价司法鉴定对接

在EPC工程竣工结算审计与司法鉴定实战中，发包人及第三方审计造价机构往往针对工程量计算、综合单价确定、定额套用、材料调差及措施费用实施高比例扣减[05][06]。施工单位若仅被动接受审计核减，将导致项目合理利润流失甚至陷入亏损[05][06]。必须结合司法裁判逻辑，针对结算审减高发领域构建严密的反击战术[07][09][11]。

##### （1）结算审减攻防典型判例解析

###### 判例解析一：重庆市赐福不锈钢有限公司与浙江世贸装饰股份有限公司建设工程分包合同纠纷案
* **案号/法院**：重庆市江北区人民法院（2017）渝0105民初23823号民事判决[07]。
* **项目背景**：浙江世贸装饰股份有限公司（总包方）将其承包工程中的不锈钢分包工程发包给重庆市赐福不锈钢有限公司（分包方）施工[07]。工程完工后，双方就结算审核金额与审减扣款数额发生争议，分包方诉至法院要求支付欠付工程款[07]。
* **技术或商务做法**：在结算审计过程中，总包方主张依据第三方审核机构出具的审减数额扣减分包工程款，并要求分包方承担审减超标违约金[07]。分包方抗辩称审计核减缺乏事实依据，且部分审减项目属于发包人设计变更导致的工程量调整[07]。
* **金额装机与成本收益数据**：法院经审理查明，案涉分包合同虽因资质瑕疵被认定法律效力存在问题，但工程质量验收合格且已交付使用[07]。针对结算审减金额，法院依据实际施工证据与核算对比，对总包方无凭据的大额审减不予采信，依法判决总包方按照实际完工工程量及合理计价结算支付工程款[07]。
* **可复制教训**：
  1. 在分包结算审减攻防中，分包单位必须保留原始施工凭证与工程量联合收方单，防止总包单位直接将发包人的整体审减核减转嫁至分包头顶[07]。
  2. 即使合同效力存在争议，只要工程质量验收合格，法庭与鉴定机构仍将依据客观完成的工程量与定额标准重新复核结算金额，有效抵御不合理审减[07]。

###### 判例解析二：陈飞与马孟君建设工程施工合同纠纷案
* **案号/法院**：浙江省慈溪市人民法院（2009）甬慈民初字第2087号民事判决[09]。
* **项目背景**：慈溪市第二建筑工程有限公司（二建公司）承建宁波市洪都花园工程后，将部分工程分包给马孟君[09]。2006年5月10日，马孟君与陈飞签订《洪都花园B、C区花岗岩工程施工合同》，将其中的花岗岩铺设工程转包给陈飞施工[09]。陈飞按约施工完毕后，马孟君以二建公司结算扣扣及审计核减为由拒绝支付尾款，陈飞提起诉讼[09]。
* **技术或商务做法**：马孟君下落不明后缺席审理[09]。陈飞向法庭提交了《洪都花园B、C区花岗岩工程施工合同》、工程量结算单、现场收方记录及二建公司内部承包合同判决书作为证据[09]。
* **金额装机与成本收益数据**：法院审理认定，陈飞实际完成了花岗岩铺设施工，工程质量合格[09]。虽存在多重违法转包，但实际施工人陈飞主张工程款的权利受法律保护[09]。法院对马孟君主张的无依据审减不予支持，判决马孟君向陈飞支付欠付的工程结算款及法定利息[09]。
* **可复制教训**：
  1. 多级转包关系下的实际施工人送审结算时，必须妥善保管直接与上一手承包人签发的手续单据及工程量计算书[09]。
  2. 在诉讼程序中，当转包人试图以“上游审减”进行抗辩时，实际施工人可通过举证现场实际工程量与验收记录，阻断不合规的层层审减[09]。

###### 判例解析三：浙江中宇建设集团有限责任公司乍浦分公司与周小平、陈其根等建设工程施工合同纠纷案
* **案号/法院**：浙江省嘉兴市中级人民法院（2009）浙嘉民终字第208号民事判决[11]。
* **项目背景**：中宇建设乍浦分公司承包乍浦大浪淘沙娱乐广场装饰工程，后与周小平、陈其根等发生施工结算纠纷[11]。双方对施工过程中发生的工程量增加、减少及设计变更部分产生剧烈争议，无法达成结算一致[11]。
* **技术或商务做法**：在司法诉讼过程中，法院依法委托专业造价鉴定机构对案涉工程进行司法鉴定，出具《乍浦大浪淘沙娱乐广场装饰工程司法鉴定报告》[11]。鉴定机构对争议工程量进行现场复核与图纸对账，对发包人主张的工程量减少部分进行了 **333647元**（33.36万元）的鉴定核减，同时对承包人实际完成的变更增量给予计价[11]。
* **金额装机与成本收益数据**：嘉兴市中级人民法院二审审理认为，司法鉴定报告依据图纸、变更单及现场勘验事实出具，具备法律效力[11]。法院判决以鉴定报告核定的最终金额作为双方决算依据，扣减鉴定核减的 **333647元** 后，确定最终工程欠款并判令支付[11]。
* **可复制教训**：
  1. 当结算审减在协商阶段陷入僵局时，启动司法鉴定是打破审减拉锯战的关键路径[11]。
  2. 承包人应对鉴定机构提出的审减项目进行逐项核对，重点针对《工程项目变更单》与《预算书》进行举证，确保合理的增量产值不被盲目扣减[11]。

##### （2）结算审减五大高发领域与反击实操步骤（可执行步骤）

```
+-----------------------------------------------------------------------------------+
|                     结算审减五大高发领域反击实操五步法                            |
+-----------------------------------------------------------------------------------+
|  步骤一：工程量审减反击 ──> 提取竣工图/隐蔽收方单/GPS水印影像三对齐凭证            |
|  步骤二：综合单价审减反击 ──> 对照商务标与投标答疑锁定合同既有单价适用效力        |
|  步骤三：定额套用审减反击 ──> 编制施工工艺说明书与定额换算对照表驳回降级套用      |
|  步骤四：材料调差审减反击 ──> 建立月度信息价/采购发票/进度映射曲线抵御强制削减    |
|  步骤五：措施费审减反击 ──> 提交审批版专项施工方案/现场安全文明施工验收记录       |
+-----------------------------------------------------------------------------------+
```

* **步骤一（工程量审减反击）**：面对审计机关以“图纸标注不全”为由审减工程量，造价团队应迅速提取《竣工图》、现场《隐蔽工程联合收方单》以及带GPS定位与时间水印的照片，绘制工程量对照重叠图，重新核算计算式，形成《工程量审减异议申诉表》[05][06]。
* **步骤二（综合单价审减反击）**：针对发包人将新增项目单价按定额下限强行审减的行为，依据合同约定的变更计价条款，出具投标商务标类似单价分析表，证明新增项目与原投标项目在工艺及材料上的相似性，锁定既有综合单价[05][06]。
* **步骤三（定额套用审减反击）**：审计人员常通过“定额套高改套低”实施核减。施工单位须提交由总工程师签字的《施工工艺说明书》，说明实际施工采用的机械规格与人工工日，提供定额换算依据，驳回审计机关的不合理套用[05][06]。
* **步骤四（材料调差审减反击）**：针对材料暴涨期发包人强行扣减调差金额的问题，整理施工期间各月《工程造价信息价》、采购合同及付款发票，按月度施工进度节点列出材料消耗量曲线，编制《大宗材料调差复核计算书》进行攻防对账[05][06]。
* **步骤五（措施费用审减反击）**：审计机关常以“未实际发生”为由全额审减夜间施工增加费、大型机械进出场费及安全文明施工费。施工单位须出具经监理审批的《专项施工方案》、安全监督备案手续以及现场安全设施验收记录，证明措施费已实际投入并产生效益[05][06]。

#### 6.4.4 EPC工程停窝工损失与工期延误索赔送审闭环

在EPC总承包履约过程中，由于发包人图纸交付延误、征地拆迁滞后、未按时支付进度款或现场工况重大变化，极易引发大规模停窝工与工期延误[14][15][18]。停窝工损失与工期索赔是结算送审中最难过审、最易引发诉讼的板块[05][06]。必须掌握严密的索赔资料编制与举证规则[14][15][18]。

##### （1）停窝工与工期延误索赔典型判例解析

###### 判例解析一：十堰伟豪建业置业有限公司与薛仁国、第三人十堰市华厦建筑安装工程有限责任公司案
* **案号/法院**：十堰市茅箭区人民法院（2017）鄂0302民初4296号民事判决[14]。
* **项目背景**：伟豪置业公司（发包人）将卧龙城项目三号楼工程发包给华厦建筑公司承建，薛仁国实际组织施工[14]。2014年11月20日双方签订《补充协议》[14]。履约中由于发包人原因导致现场频繁停工，薛仁国主张退还保证金、支付进度款及停窝工损失[14]。伟豪置业公司起诉要求确认合同无效并判令薛仁国退场[14]。
* **技术或商务做法**：薛仁国在施工过程中保存了《施工承包合同》、《补充协议》、《补偿协议二》以及现场停工通知书、人工机械停窝工台账[14]。
* **金额装机与成本收益数据**：茅箭区人民法院审理认定，双方签订的合同及补充协议系真实意思表示[14]。发包人主张合同无效并强令承包人退场的诉求缺乏法律依据，判决驳回伟豪置业公司的全部诉讼请求[14]。薛仁国依据完整的停窝工与补偿协议成功保住了现场施工权益与索赔基础[14]。
* **可复制教训**：
  1. 发生停窝工事件时，承包人必须第一时间逼迫发包人或监理出具书面停工令，或主动签发《停工通知书》并留存送达回执[14]。
  2. 签署《补偿协议》或《补充协议》是锁定停窝工损失赔偿金的核心依据，能有效对抗发包人后续的违约强退[14]。

###### 判例解析二：南宁市青秀区法院方XX与李XX建设工程设计合同纠纷案
* **案号/法院**：南宁市青秀区人民法院（2011）青民一初第1918号民事判决[20]。
* **项目背景**：2011年5月19日，方XX（发包方）与李XX（设计方）签订《建设工程设计合同》，约定由李XX承担某某酒店室内装修工程设计项目，方XX付设计费 **80000元**（8万元）[20]。由于李XX无设计资质导致设计图纸无法交付，引发施工现场严重停工延误[20]。方XX起诉要求确认合同无效并退还设计费，李XX反诉主张报酬 **150000元** 及赶工费 **20000元**、违约金 **21600元**[20]。
* **技术或商务做法**：方XX向法庭提交了银行转账凭证及催告函，证明因设计图纸缺失导致后续施工停工延误[20]。李XX反诉主张赶工费及报酬，但未能出具发包人书面赶工指令及合规设计成果[20]。
* **金额装机与成本收益数据**：青秀区人民法院审理认定，李XX未取得建设工程设计资质，依据《建筑法》第十三条及《建设工程勘察设计管理条例》第八条、第十条规定，判决双方签订的《建设工程设计合同》无效[20]；判令李XX向方XX返还已付设计费 **80000元**；依法驳回李XX索要报酬 **150000元** 及赶工费 **20000元** 的反诉请求[20]。
* **可复制教训**：
  1. 在EPC项目中，设计分包资质瑕疵会导致设计合同无效，由此引发的施工停窝工损失无法向无资质设计方有效索赔赶工费[20]。
  2. 主张赶工费或停窝工补偿，必须以合法有效的合同及发包人书面赶工/停工指令为前提[20]。

###### 判例解析三：山西亿德人燃气有限公司与山西杰盛房地产开发集团有限公司案
* **案号/法院**：山西省长治市中级人民法院（2017）晋04民再1号民事判决[15]。
* **项目背景**：2006年5月5日，杰盛公司（发包方）与亿德公司（承包方）签订黎城县德盛苑小区《燃气初装合同书》[15]。在履行合同过程中，因发包方杰盛公司未能向承包方提供有利的施工条件（如施工场地未移交、管线冲突），致使工程未能按期完工[15]。发包方后续诉请承包方承担工期延误违约金及燃气设施二次改造费用[15]。
* **技术或商务做法**：亿德公司在诉讼中举证证明发包方未提供施工条件是导致工期延误的根本原因，且发包方未按约定支付工程款[15]。发包方出具的《关于德盛苑供气问题会议纪要》因缺乏承包方会签而不符合证据形式要件[15]。
* **金额装机与成本收益数据**：山西省人民检察院提起抗诉，山西省长治市中级人民法院再审判决认定：二审判决认定应由亿德公司承担二次改造费用及工期违约责任缺乏证据支持[15]。发包方未提供施工条件及拖欠工程款构成违约，判决撤销二审错误判决，免除亿德公司的工期延误赔偿责任[15]。
* **可复制教训**：
  1. 因发包方未提供施工条件导致工期延误时，承包人须保存场地未按时移交的书面凭证，以此作为免除工期违约金的核心抗辩依据[15]。
  2. 单方制作的会议纪要若无承包人会签盖章，在司法审查中不具备证明效力[15]。

###### 判例解析四：杭州信××监理公司与平湖市光明××开发公司建设工程监理合同纠纷案
* **案号/法院**：浙江省平湖市人民法院（2009）嘉平民初字第814号民事判决[18]。
* **项目背景**：2004年4月9日，信××监理公司与光明××开发公司签订《建设工程甲监理合同》，约定对东湖世纪某某二期工程Ⅱ标段实施监理，服务期 **12个月**，监理费总额按合同约定支付[18]。工程于2004年4月23日开工，因施工现场复杂及发包人原因导致工期严重延误，直至2007年4月27日才完成竣工验收备案，实际监理服务期长达 **36个月**（超期 **24个月**）[18]。
* **技术或商务做法**：监理公司在实际服务期延长后，多次向发包人报送工期延误说明及追加监理费申请[18]。发包人以合同约定固定监理费为由拒付追加费用，仅支付了 **697500元**（69.75万元），拖欠 **478780元**（47.88万元）[18]。监理公司诉至法院要求支付剩余监理费及延误追加补偿[18]。
* **金额装机与成本收益数据**：平湖市人民法院审理认为，《建设工程甲监理合同》合法有效[18]。因非监理人原因导致工程工期延误、监理服务期限大幅延长的，监理人有权要求追加合理的服务费用[18]。法院判决光明××开发公司向信××监理公司支付欠付的监理费 **478780元** 及相应的延期付款利息[18]。
* **可复制教训**：
  1. 工期延误不仅涉及施工单位索赔，同样引发监理及咨询服务费用的追加[18]。
  2. 留存竣工验收备案表与开工报告，准确计算实际延误月份，是索赔超期服务费用的关键证据[18]。

###### 判例解析五：朱大武与周建军建设工程施工合同纠纷案
* **案号/法院**：浙江省绍兴市中级人民法院（2009）浙绍民终字第1353号民事判决[16]。
* **项目背景**：中发公司将其纺织车间二、车间三工程发包给宝业公司，宝业公司转包给周建军[16]。2007年3月9日，朱大武与周建军签订工程承包协议，分包钢结构工程，包干总造价为 **3716591元**（371.66万元）[16]。朱大武按约施工并于2007年5月10日及5月20日通过了分项工程验收，但因朱大武至今未向周建军交付竣工验收所需资料，导致车间二、三至今未通过整体竣工验收[16]。周建军已付工程款 **200万元**，后又付汇票 **117万元**，尾款产生纠纷[16]。
* **技术或商务做法**：周建军抗辩称朱大武未交付竣工资料构成违约，导致整体工期延误且无法向发包方办理结算定案[16]。
* **金额装机与成本收益数据**：绍兴市中级人民法院二审审理认定，朱大武虽完成了分项施工，但未履行交付竣工验收资料的法定与合同义务，直接导致整体工程无法通过竣工验收[16]。二审判决撤销一审判决，对朱大武在资料未交付、整体验收未通过情况下的付款主张予以重新认定，扣减相应违约责任[16]。
* **可复制教训**：
  1. 施工单位完成物理施工后，必须及时向发包人或总包方移交完整的竣工资料[16]。
  2. 拒绝或扣押竣工资料将导致整体工程无法通过验收，不仅无法主张工期延误免责，还会被判定承担违约责任[16]。

###### 判例解析六：中际三立装饰集团有限公司与沈阳睿凡公共设施管理有限公司案
* **案号/法院**：沈阳市沈河区人民法院（2016）辽0103民初12994号民事判决[17]。
* **项目背景**：2013年10月底，中际三立公司（承包人）与沈阳睿凡公司（发包人）签订《建筑装饰工程施工合同》，承包沈阳北通天广场口部、风井及车库入口建筑装饰工程，合同固定总价为人民币 **230万元**（230万元），首期付 **30%**[17]。施工过程中，发包人因北通天广场被确定为2014年元宵节灯会主会场，向承包人下发《关于加强北通天广场安全防护的通知》及《关于拆除北通天广场口部钢结构的通知》，强制指令承包人停工、拆除已建钢结构并配合灯会防护，导致工期严重延误并产生拆除重建损失[17]。承包人起诉主张欠付工程款 **918000元**（91.8万元）及停窝工拆除赔偿[17]。
* **技术或商务做法**：中际三立公司完整保存了发包人下发的《关于加强北通天广场安全防护的通知》、《关于拆除北通天广场口部钢结构的通知》原件及《工程形象进度款相关情况说明》[17]。
* **金额装机与成本收益数据**：沈阳市沈河区人民法院审理认定，因发包人配合政府规划及灯会活动强制下发拆除与停工指令，属于发包人原因造成的工期延误与工程损失[17]。依据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第十三条及合同约定，判决沈阳睿凡公司向中际三立公司支付欠付工程款 **918000元** 及利息[17]。
* **可复制教训**：
  1. 面对发包人因外部活动或规划调整下发的临时拆除、停工指令，承包人须妥善保存书面通知原件[17]。
  2. 因发包人原因导致的反复拆建与停工，固定总价合同约束被打破，承包人有权就增量拆建成本与工期延误进行全额索赔[17]。

##### （2）停窝工与工期延误索赔资料编制与举证规则（可执行步骤）
* **步骤一（停工指令与因果关系链锁定）**：在发生发包人原因停工后24小时内，向发包人及监理发出《工期延误与停工告知函》；取得发包人书面停工指令或由监理签发的《工程暂停令》，锁定因果关系起算点[05][06]。
* **步骤二（现场资源停窝工动态登记）**：每日编制《停窝工人员及机械台账》，详细记录停工现场的人员名单、身份证号、岗位、机械设备型号、数量、租赁费标准及停置状态，由现场监理工程师每日签字确认[05][06]。
* **步骤三（停窝工损失财务凭证归集）**：归集停工期间支付的工人工资发放流水、机械租赁费发票、现场看管人员安保费用及临时设施摊销凭证，形成财务账目支撑[05][06]。
* **步骤四（工期顺延申请与复工闭环）**：具备复工条件时，提交《复工申请表》及《工期顺延综合索赔报告》，详细列算工期顺延天数与费用索赔总额，取得发包人书面批复[05][06]。

### 6.5 EPC项目送审后跟踪与全流程合规风控管理

#### 6.5.1 审计对决算效力对抗与行政审计复议/诉讼边界

在工程结算实践中，发包人常以“行政审计机关尚未出具审计决定”或“审计结论未定案”为由拖延支付工程款[12][19]。施工单位须明确行政审计与民事结算的法律边界，掌握审计效力对抗战术[12][19]。

##### （1）行政审计效力对抗典型判例解析

###### 判例解析一：东营益华石油科技有限责任公司与王培军、王培东、王培增、胜利油田东强设备安装工程有限责任公司案
* **案号/法院**：山东省东营市中级人民法院（2010）东民一终字第217号民事判决[19]。
* **项目背景**：2004年起益华公司实际控制人李雨春以益华公司名义从东强公司分包油泥砂工程，后将土建部分转包给王培军、王培东、王培增三人施工（2008年3月15日开工，2008年6月18日完工）[19]。完工后，李雨春委托东营万相工程造价咨询有限公司对工程量进行审计，审计工程款为 **743268.49元**（74.33万元）[19]。益华公司支付 **38万元** 后，以审计系内部委托、合同无效为由拒绝支付尾款 **363268.49元**[19]。东强公司已向益华公司全额支付工程款 **3781589.67元**（378.16万元）[19]。
* **技术或商务做法**：王培军等三人举证了李雨春委托出具的审计报告及益华公司付款凭证[19]。益华公司抗辩称合同无效且审计不具备效力[19]。
* **金额装机与成本收益数据**：东营市中级人民法院二审审理认为，虽然各方均无资质导致承包合同无效，但工程经验收合格并投入使用[19]。益华公司委托造价机构出具的审计报告已确定工程价款为 **743268.49元**，该审计结论具备确定民事债务的效力[19]。判决益华公司向王培军等三人支付剩余工程款 **363268.49元**[19]。
* **可复制教训**：
  1. 即使合同无效，双方委托第三方机构出具的结算审计报告仍是法院认定工程价款的最直接证据[19]。
  2. 发包人或承包人不得在审计结论出具后，随意以“合同无效”或“非政府审计”为由推翻已生效的造价审计结果[19]。

###### 判例解析二：潘宗球与吉林省交通建设集团有限公司、宁波交通工程建设集团有限公司案
* **案号/法院**：宁波市镇海区人民法院（2011）甬镇民初字第1337号民事判决[19]。
* **项目背景**：吉林交建公司与宁波交建公司承包交通工程后进行分包，实际施工人潘宗球承建具体施工内容[19]。工程完工后，发包方以政府审计机关尚未完成审计决算为由，长期扣压结算尾款[19]。潘宗球提起诉讼要求结算付款[19]。
* **技术或商务做法**：潘宗球举证了工程交工验收表、施工结算汇总表及实际施工工程量凭证，证明工程已具备结算条件，发包人无正当理由拖延审计[19]。
* **金额装机与成本收益数据**：镇海区人民法院审理认定，民事合同未明确约定以政府行政审计结论作为唯一结算条件的，发包人不得以政府审计拖延为由拒绝履行付款义务[19]。法院依法启动司法造价鉴定或直接依据已核实的结算凭证判决发包方支付工程欠款[19]。
* **可复制教训**：
  1. 面对政府投资项目审计长期拖延的情况，承包人可依据民事合同独立性提起诉讼，切断发包人以“行政审计未出”拖延付款的借口[19]。
  2. 只有在合同明确约定“以政府审计机关出的审计决定书作为最终结算依据”时，行政审计才具备拘束力；否则发包人必须按民事约定结算[12][19]。

###### 判例解析三：董文叶与连云港市恒远交通建设有限公司建设工程施工合同纠纷案
* **案号/法院**：江苏省连云港市中级人民法院（2017）苏07民终3480号民事判决[12]。
* **项目背景**：董文叶承包恒远公司发包的交通工程施工[12]。工程完工后，双方就行政审计扣减数额与最终结算金额产生分歧[12]。发包人主张直接扣减行政审计机关核减的数额，董文叶主张按双方签署的阶段性结算单进行民事结算[12]。
* **技术或商务做法**：董文叶向法院出示了双方会签的阶段性工程量确认单及工程款支付节点凭证[12]。恒远公司出示了行政审计机关出具的审计扣款意见[12]。
* **金额装机与成本收益数据**：连云港市中级人民法院二审审理认定，行政审计系国家对建设资金的行政监督行为，不能直接替代平等民事主体之间的合同结算约定[12]。在发包人未能证明合同明确约定以行政审计结论为准的前提下，判决按照双方民事会签的结算凭证支付工程款，驳回发包人按行政审计结果扣减的抗辩[12]。
* **可复制教训**：
  1. 行政审计监督不等于民事合同结算，施工单位在签订合同时应审慎对待“以审计为准”条款[12]。
  2. 已经双方签字确认的阶段性结算单具备民事合同约束力，可有效对抗后续行政审计的不合理扣减[12]。

#### 6.5.2 工程款优先受偿权保全与结算送审的联动机制

##### （1）工程款优先受偿权法律适用与专属管辖冲突判例解析

###### 判例解析：盛宏永（九江）实业发展有限公司与宁波建工股份有限公司建设工程合同纠纷案
* **案号/法院**：浙江省高级人民法院（2017）浙民终450号民事裁定[13]。
* **项目背景**：盛宏永实业公司（发包方，位于江西省九江市共青城）与宁波建工股份有限公司（承包方，位于浙江省宁波市）签订《建设工程施工合同》，发包合盛大厦项目[13]。履约中双方又签订《垫资协议》，约定因垫资产生的纠纷由宁波市中级人民法院管辖[13]。后因发包人拖延结算并欠付工程款，宁波建工依据《垫资协议》向宁波中院起诉，请求返还垫资款、解除施工合同、支付剩余工程款并主张对合盛大厦项目享有 **工程款优先受偿权**[13]。盛宏永公司提出管辖权异议，主张本案应由不动产所在地江西省九江市中级人民法院管辖[13]。
* **技术或商务做法**：宁波建工试图通过《垫资协议》约定的管辖条款，在承包人所在地法院锁定工程款及优先受偿权[13]。盛宏永公司依据《民事诉讼法》第三十三条及《民诉法解释》第二十八条关于不动产专属管辖的规定提出异议[13]。
* **金额装机与成本收益数据**：浙江省高级人民法院二审裁定认为：《民事诉讼法》第三十三条规定因不动产纠纷提起的诉讼由不动产所在地法院管辖，《民诉法解释》第二十八条明确建设工程施工合同纠纷按不动产纠纷确定管辖[13]。虽然双方在《垫资协议》中约定的管辖不违反一般规定，但垫资纠纷系在履行施工合同中产生，且诉请包含优先受偿权与工程款结算，纠纷性质仍属建设工程施工合同纠纷[13]。若认可垫资协议管辖，将导致专属管辖规定形同虚设[13]。最终裁定：撤销宁波中院一审判决，将本案移送江西省九江市中级人民法院审理，退回二审受理费 **51328.64元**[13]。
* **可复制教训**：
  1. 工程款优先受偿权的行使与结算送审密切相关，但涉及工程款及优先权主张的诉讼，必须严格遵循不动产所在地专属管辖规则[13]。
  2. 施工单位试图通过签订补充协议或垫资协议改变建设工程专属管辖的做法在司法审查中无法获得支持[13]。送审与维权必须在工程所在地法院提前做好证据保全[13]。

##### （2）送审时限与优先受偿权法定行使期限的衔接策略
依据相关法律规定，工程款优先受偿权的行使期限为发包人应当给付工程款之日起最长不超过18个月。在结算送审实战中，必须防止发包人通过拖延审计变相拖垮优先受偿权行使期限[05][06][13]：
* **策略一（送审盖章锁定应付款节点）**：在送审结算书递交时，明确要求发包人书面确认结算审核完成期限（如60天），并约定逾期付款利息起算点，锁定优先受偿权行使期限的起点[05][06]。
* **策略二（审计僵持期及时发函保全）**：若结算审计超过半年仍未出具结果，承包人须在优先受偿权法定期限届满前（建议在应付款之日起12个月内），向发包人送达《行使工程价款优先受偿权书面告知函》，或直接向不动产所在地法院提起诉讼并主张优先受偿权，防止优先权失效[05][06][13]。

#### 6.5.3 审计争议处置“五位一体”闭环解纷体系

针对EPC工程结算审计整改、造价争议及工程款催收，四川蓉城律师事务所·蓉城观筑律师团队总结出适配国企与政府投资项目合规要求的**“人民调解、商事调解、仲裁、公证赋强、民事/涉外诉讼”五位一体一站式闭环解纷体系**[05][06]。

```
+-----------------------------------------------------------------------------------+
|               工程结算争议“五位一体”闭环解纷与风控矩阵                            |
+-----------------------------------------------------------------------------------+
|  1. 人民调解 ──> 适用于施工现场小型劳资与分包矛盾，快速出具调解协议书              |
|  2. 商事调解 ──> 依托专业调解机构对造价争议实施技术对账，促成结算折衷方案          |
|  3. 仲裁解纷 ──> 依据合同仲裁条款，利用一裁终局特性快速锁定工程结算定案金额        |
|  4. 公证赋强 ──> 针对发包人承诺分期付款的结算协议，办理公证赋予强制执行效力      |
|  5. 司法诉讼 ──> 依托不动产专属管辖，申请司法造价鉴定并主张工程款优先受偿权        |
+-----------------------------------------------------------------------------------+
```

1. **人民调解机制**：在项目竣工送审阶段，针对施工现场引发的小型劳资纠纷或班组结算争议，及时引入项目所在地人民调解委员会，出具具备民事合同效力的《调解协议书》，防止底层劳资矛盾阻碍整体送审进度[05][06]。
2. **商事调解机制**：当承包人与发包人针对工程量审减或材料调差金额产生剧烈分歧时，联合引入工程造价协会或商事调解中心专业专家组成调解小组，进行技术性对账，促成双方签署《结算争议调解协议》[05][06]。
3. **仲裁解纷机制**：若合同约定了仲裁条款，在审计陷入实质停滞时，承包人可直接向指定的仲裁委员会申请仲裁[05][06]。仲裁裁决具备“一裁终局”效力，可有效规避民事诉讼一审、二审及再审的冗长周期，快速取得生效法律文书[05][06]。
4. **公证赋强机制**：在审计定案后发包人因资金紧张请求分期支付工程款时，双方签署《分期还款结算协议》，并共同向公证机构申请办理“赋予债权文书强制执行效力公证”（公证赋强）[05][06]。若发包人后续逾期付款，承包人无需经过法庭诉讼，可凭公证处出具的《执行证书》直接向法院申请强制执行发包人财产[05][06]。
5. **司法诉讼与优先权保全机制**：针对恶心拖延审计、强行大额扣减或拒不配合对账的发包人，承包人须在不动产所在地法院果断提起民事诉讼[05][06][13]。通过申请法院委托第三方机构实施司法造价鉴定，打掉不合理的行政或单方审计审减，同时依法行使工程款优先受偿权，确保工程结算资金真正安全落袋[05][06][13]。

### 6.6 本章小结要点

1. **破除“验收即回款”误区，树立资料闭环思维**：五方竣工验收合格仅代表物理工序完成，资料闭环、逻辑自洽、签字合规才是审计定案与资金落袋的法定前提[05][06]。送审资料瑕疵会导致全额退审、大额审减，并在后续诉讼中转化为败诉风险[05][06]。
2. **严控送审金额水分，防范惩罚性违约扣罚**：从南京下关码头案（苏0106民初9500号）教训来看，当合同约定“审减率超 **10%** 按总价 **1%** 扣减违约金”时，盲目虚报送审价将引发高额违约扣罚（总包被扣 **109800元**，分包被判定承担 **56239.56元**）[02]。送审前必须精准核算工程量与单价[02][05][06]。
3. **贯彻三大黄金通关原则，筑牢送审防线**：送审资料编制必须严格执行“完整闭环原则（指令-过程-验收-签证-影像-计算书链条完备）、逻辑自洽原则（时间线高度吻合，杜绝集中补填）与签字合规原则（仅限合同授权代表签署）”[05][06]。
4. **精细化编制七大板块资料，实现数据“三统一”**：送审资料须覆盖招投标合同、全套图纸、过程管理、变更签证、隐蔽工程、造价成套及材料调差七大板块[05][06]。工程量计算书必须附带详细计算过程，纸质版、PDF扫描件与计价软件电子文件数据必须 **100%** 精确一致[05][06]。
5. **依法运用政策与司法解释，有效对抗不合理审减**：严格对接法释〔2004〕14号、法释〔2016〕24号及国办发〔2017〕19号等文件[01][05][06]。对发包人未在约定期限答复的，依法主张“视为认可送审价”[02][03][05][06]；明确行政审计监督与民事合同结算的界限，拒绝发包人无合同依据强行按行政审计结果大额扣减[12][19]。
6. **建立停窝工与变更索赔闭环，构建“五位一体”解纷矩阵**：针对发包人原因引发的停窝工与变更，须保留书面指令、现场联合收方单及带GPS水印影像[05][06][14][17]。在送审跟踪阶段，灵活运用人民调解、商事调解、仲裁、公证赋强与司法诉讼“五位一体”解纷体系，并在法定期限内锁定工程款优先受偿权，保障项目合法利润稳健落袋[05][06][13]。
