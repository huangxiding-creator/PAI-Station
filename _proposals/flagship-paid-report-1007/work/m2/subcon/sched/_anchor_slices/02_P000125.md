# 合肥风华塑钢制品有限公司、合肥市华阳建设工程有限公司建设工程施工合同纠纷二审民事判决书

款156002.97元、业主罚款2000元、重大事故罚款100000元，电建一公司应当支付风华公司合同款263119.15元（521122.12－156002.97－2000－100000）。遂裁决：电建一公司自收到裁决书之日起10内向风华公司支付合同款263119.15元并支付逾期付款利息。仲裁裁决书生效后，电建一公司按裁决书认定的给付内容向风华公司支付了合同款263119.15元。华阳公司认为风华公司通过申请仲裁向电建一公司主张工程款损害了其利益，遂诉至本院。另查明：2017年4月14日，华阳公司向电建一公司出具了付款委托书，载明：华阳公司授权电建一公司将工程款直接付给风华公司，风华公司、华阳公司均在付款委托书上盖章。电建一公司向华阳公司发函称：“1#、3#楼门窗安装单位所雇民工魏作兵在施工中摔伤，因风华公司拖延为魏作兵申请工伤保险待遇，经劳动争议仲裁赔偿魏作兵13万元。上述费用计入我方与贵司的合同结算款项中，因1#、3#楼门窗由风华公司承包施工，我方将从门窗结算款中扣除此费用”。华阳公司项目经理丁光跃签字：“同意电建一公司意见将该款项从风华公司工程结算款中扣除”。电建一公司将该部分费用130000元从华阳公司的工程款中扣除。一审法院认为，本案审理的争议焦点在于二点：一、风华公司实际履行的是《铝合金门窗施工合同》还是《工业品买卖合同》；二、华阳公司主张从应付风华公司工程款中扣除以下费用：1.乙方应承担的1%水电费53921元；2.合同约定的总价款让利50000元；3.华阳公司代付魏作兵工伤费用130000元；4、其他杂项扣减费用合计66999元，以上共计300920元，是否成立。关于第一个争议焦点：电建一公司将涉案工程的1标段分包给华阳公司施工，华阳公司将其中的门窗制作安装工程分包给风华公司施工，双方签订了《铝合金门窗施工合同》，合同约定了风华公司和电建一公司签订采购合同，但采购合同仅作为付款依据，不作为结算依据。仲裁裁决书认定的合同结算金额5392119元，依据的是华阳公司和风华公司核算的结果且由华阳公司制作的面积汇总表，风华公司交付所制作安装门窗的合同对象是华阳公司，而非涉案工程的总承包方电建一公司。故华阳公司与风华公司之间是建设工程施工合同法律关系，且华阳公司提供的付款委托书上华阳公司、风华公司均盖章亦印证双方实际履行的是《铝合金门窗施工合同》。风华公司和电建一公司签订的《工业品买卖合同》并未实际履行。关于第二个争议焦点：风华公司依据《工业品买卖合同》申请仲裁，因仲裁审理仅针对合同当事人之间的纠纷进行仲裁，其调整的范围有限。仲裁庭对电建一公司提出的扣款费用予以部分支持，电建一公司已支付风华公司门窗工程总工程款5392119元的95%。现华阳公司主张应当扣除的费用分为四项：关于第1项水电费用，仲裁裁决书认定的涉案门窗工程工程量为5392119元是总工程量5446585元扣除1%水电费54466元计算出的实际工程量。因1%水电费已经扣除，原告诉请扣除1%水电费53921元系重复计算，此项扣除费用不成立。关于第2、3项费用均有合同依据；关于第4项费用已实际发生且电建一公司已从华阳公司工程款中扣除；故2、3、4项扣除费用成立。华阳公司主张的2、3、4项扣减费用合计246999元（50000元＋66999元＋130000元）。综上，华阳公司与风华公司签订的《铝合金门窗施工合同》是双方当事人真实意思表示，应为合法、有效，双方均应按约履行，风华公司应当按约和华阳公司结算工程款。《工业品买卖合同》并未实际履行，电建一公司凭《工业品买卖合同》向风华公司支付工程款并不代表其有权和风华公司直接结算。所谓结算，是建设工程施工合同的当事人对工程量的确认、工程量的增加、扣减项目的计算。风华公司施工的门窗工程是华阳公司作为涉案工程1标段总包方的部分工程，风华公司越过华阳公司申请仲裁，从电建一公司处结算了门窗施工合同工程量扣除1%水电费后的95%工程款，损害了华阳公司的权利。合同约定了：总价在合同价基础上让利5万元；因门窗工程引起的相关处罚由乙方承担；门窗固定件安装后由乙方自行负
