# 朱勇派与陈瑞宗、四川泰兴装饰工程有限责任公司建设工程分包合同纠纷一审民事判决书



案号: （2019）川1111民初771号

案件名称: 朱勇派与陈瑞宗、四川泰兴装饰工程有限责任公司建设工程分包合同纠纷一审民事判决书

法院: 乐山市沙湾区人民法院

所属地区: 乐山市

案件类型: 民事案件

审理程序: 民事一审

裁判日期: 2019-12-18

当事人: 朱勇派；陈瑞宗；四川泰兴装饰工程有限责任公司

案由: 建设工程分包合同纠纷



 四川省乐山市沙湾区人民法院 民 事 判 决 书 （2019）川1111民初771号 原告：朱勇派，男，1970年5月1日出生，汉族，农民，住四川省仁寿县。 委托诉讼代理人：徐东风，四川清正律师事务所律师。 被告：陈瑞宗，男，1964年2月16日出生，汉族，居民，住四川省资中县。 被告：四川泰兴装饰工程有限责任公司，住所地：四川省成都市高新区。 法定代表人：白晋菡，总经理。 委托诉讼代理人：黄雪韬，四川华敏律师事务所律师。 委托诉讼代理人：叶影，四川华敏律师事务所律师。 原告朱勇派与被告陈瑞宗、四川泰兴装饰工程有限责任公司（以下简称泰兴装饰公司）建设工程分包合同纠纷一案，本院于2019年11月5日立案后，依法适用简易程序，公开开庭进行了审理。原告朱勇派及委托诉讼代理人徐东风，被告陈瑞宗、被告泰兴装饰公司的委托诉讼代理人黄雪韬、叶影到庭参加诉讼。本案现已审理终结。 原告向本院提出诉讼请求：1、二被告按照合同约定办理工程结算并支付剩余工程款451,266.87元及迟延支付的利息（银行同期贷款利率）98,000.00元；2、本案诉讼费由被告承担。事实和理由：原告于2011年11月承接了郭某某故居博物馆建设工程（二期）项目外装饰工程，于2012年2月28日前完成了工程。2012年12月31日该工程竣工验收并投入使用。2015年乐山市沙湾区审计局出具的乐山审决（2015）7号审计报告核定工程总造价为2,276,256.00元。以上工程款扣除已支付给原告借资、管理费、部分材料费及人工费，二被告还应当支付原告451,266.87元。二被告未与原告办理结算并支付剩余工程款。 被告陈瑞宗庭审辩称，1、被告陈瑞宗与泰兴装饰公司2011年签订了现场管理合同承包案涉工程。被告陈瑞宗找到原告进行现场施工。案涉工程2011年11月进场，2012年12月竣工验收，2017年年底发包方支付完工程款；2、原告与被告陈瑞宗对被告陈瑞宗办理结算而支付的差旅费、人工工资及协调费的分担未达成一致意见，故一直未支付原告剩余工程款。 被告泰兴装饰公司庭审辩称，1、泰兴装饰公司与原告无工程转包或分包关系，无法定和约定承担共同或连带责任的义务。原告要求泰兴装饰公司支付工程款无事实和法律依据；2、原告诉称及提交的合同可以证实原告与被告陈瑞宗建立合同关系。被告陈瑞宗挂靠被告泰兴装饰公司承包案涉工程，系实际施工人。被告陈瑞宗应当与原告进行结算并履行义务；3、原告的诉讼请求缺乏事实和法律依据，原告所述工程未办理结算，合同金额无法确定，无权要求被告陈瑞宗支付工程款及利息。案涉工程2012年竣工验收，2015年沙湾审计局出具审计报告。截止目前为止，原告从未向泰兴装饰公司主张过任何权利。证实原告知晓合同相对方。同时，原告对泰兴装饰公司的诉讼请求已经超过诉讼时效。因此，请法院驳回原告对被告公司的诉讼请求。 双方当事人围绕诉讼请求提交了审计报告、幕墙分包合同、建设施工合同、代付摘要、业务回单、函件。承包经营协议书。微信聊天记录及记账凭证。经过庭审质证，双方当事人对建设施工合同、审计报告、承包经营协议书、微信聊天记录真实性无异议，本院予以确认并在卷佐证。 有异议的证据：原告提交《幕墙分包合同》证明原告与被告泰兴装饰公司的项目经理陈瑞宗签订了分包合同，被告应当支付剩余款项。被告泰兴装饰公司认为该合同没有公司负责人签字及公司印章，对真实性有异议。从合同约定的造价金额及挂靠管理费、税金等内容来看，该合同系转包合同。原告知晓该工程系被告陈瑞宗挂靠被告泰兴装饰公司。被告陈瑞宗为实际承包人。被告陈瑞宗对该份证据真实性无异议。本院认为，原告及被告陈瑞宗在《幕墙分包合同》上签字且对合同真实性无异议，本院予以确认。原告未提交授权委托书、劳动合同等证据证实被告陈瑞宗系被告泰兴装饰公司员工或者与原告签订合同系被告泰兴装饰公司授权，对原告的证明目的本院不予采信； 原告提交付款摘要证实被告代付材料款的事实。被告陈瑞宗无异议。被告泰兴装饰公司对真实性有异议。本院认为，被告陈瑞宗与原告对已付材料款的事实无异议，故对付款摘要中原告及被告陈瑞宗无争议部分即代付的材料款1,445,275.00元的事实本院予以认定； 原告提交业务回单证实由于被告迟延付款导致原告产生的损失。被告对关联性有异议。本院认为，业务回单与本案无关联，本院不予采信； 原告提交三份函件证实向二被告主张权利。被告泰兴装饰公司对三性不予认可。本院认为，原告并未提交相应的送达凭证，在被告泰兴装饰公司不予认可的情况下，上述证据不能证实原告向被告泰兴装饰公司在起诉前主张过相应权利，对三性本院不予采信； 被告陈瑞宗提交了记账凭证证实被告陈瑞宗除合同约定外支付的费用应当由原告进行分担。原告认为该记账凭证没有任何人签字，对三性不予认可。被告泰兴装饰公司认为无法核实真实性。本院认为，记账凭证没有签字及其他证据相印证，不能证实损失的实际发生及金额，对三性本院不予认可。 本院经审理认定事实如下：2011年11月21日，被告陈瑞宗借用被告泰兴装饰公司资质与乐山市沙湾区文化体育广播影视新闻出版局就郭某某故居博物馆建设工程（二期）项目外装饰工程签订《建设工程施工合同》，合同约定的工程内容为郭某某故居博物馆整个外立面装饰工程所有玻璃幕墙、铝合金格栅、铝塑板及外墙门窗工程等，合同总价款1,793,697.00元，承包方式为被告泰兴装饰公司承担材料采购、加工制造、安装施工，质量标准按照国家质量标准达到合格等。被告泰兴装饰公司在合同上盖章且被告陈瑞宗在本合同上签字。2012年2月11日，被告陈瑞宗与原告签订了《幕墙分包合同》，将整体工程转包给原告，由原告实际施工上述工程。被告陈瑞宗在本合同上签字。合同约定的工程承包方式为包工包料。本合同第4.2.1项约定工程总造价为1,793,697.00元。挂靠管理费及税金为总工程造价的6.5%，即11,690.30元，中介服务费为100,000.00元包干，甲方在本工程投标活动中所产生的费用以及现场管理费、利润费、业务费、竣工图、竣工资料费用、结算费用等一切费用为150,000.00元包干。总工程款扣除以上费用和增补签证的工程款均为乙方所得，即为1,427,107.00元+签证款；第4.2.2项约定本合同为单价包干合同，工程最终总造价应随工程量的变化进行结算，单价包括安装所需的人工费、材料费、机械费。现场管理费、税金、业务费由甲方承担，脚手架费用由乙方承担；第4.4.3项约定本工程约定甲方分成费用为150,000.00元包干，该费用包含了甲方在本工程投标活动中所产生的费用以及增加工程量费用，现场管理费、利润、业务费、竣工资料费用、结算费用等尽一切费用。该费用和中介费100,000.00元在本工程结算完成并支付剩余25%工程款后提取。本合同还对质量保修、工程施工等内容进行了约定。2012年12月31日，案涉工程竣工验收。2015年2月5日，经乐山市沙湾区审计局出具审计报告载明，案涉工程（含增加工程）的工程款审计定额为2,276,256.00元。庭审中，原、被告对被告应当支付工程款无争议的部分为总造价2,276,256.00元扣除已付工程款1,445,275.00元、100,000.00元中介服务费、150,000.00元的现场管理费、利润等费用及2,276,256.00元&times;6.5%的挂靠管理费及税金。被告陈瑞宗认可原告垫付了税金18,241.87元且同意在本案中一并处理。另查明：原告及被告陈瑞宗均不具备建设工程施工的相关承包资质。原告及被告陈瑞宗认可案涉工程的发包方已支付完毕工程款。工程施工及结算过程中，被告泰兴装饰公司没有支付过工程款给原告。 本院认为，被告陈瑞宗借用被告泰兴装饰公司资质承包案涉工程，同时将工程转包给原告施工。根据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第一条规定，建设工程施工合同具有下列情形之一的，应当根据合同法第五十二条第（五）项的规定，认定无效：（一）承包人未取得建设施工企业资质或者超越资质等级的。被告陈瑞宗违反法律禁止性规定将工程整体转包给未取得建设施工企业资质的原告，转包合同无效。根据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第二条规定，建设工程施工合同无效，但建设工程经竣工验收合格，承包人请求参照合同约定支付工程款的，应予支持。原告组织施工的案涉工程经竣工验收合格，有权要求转包人承担支付工程款的责任。根据《中华人民共和国民法总则》第一百七十一条、第一百七十二条规定，行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，经被代理人追认或者相对方有理由相信行为人有代理权的，代理行为有效。代理人实施的民事法律行为对被代理人发生效力。本案中，《幕墙分包合同》发包方处虽载有系被告泰兴装饰公司的名称，但是&ldquo;甲方签字&rdquo;处仅有被告陈瑞宗签字，并没有被告泰兴装饰公司的签字盖章。原告未向本院提交被告泰兴装饰公司向被告陈瑞宗出具的授权委托书、劳动合同等证据证实被告陈瑞宗的转包行为经被告泰兴装饰公司授权或者是被告泰兴装饰公司对转包行为明知或者自愿承担该合同项下的权利义务等情形，应当承担举证不能的法律后果。被告泰兴装饰公司庭审也未对该合同进行追认，故《幕墙分包合同》仅约束合同相对方即原告和被告陈瑞宗，对被告泰兴装饰公司不产生约束力。被告陈瑞宗与被告泰兴装饰公司庭审均认可双方系挂靠关系，即2011年11月21日，被告陈瑞宗借用被告泰兴装饰公司的资质承包案涉工程。被告陈瑞宗与被告泰兴装饰公司之间不存在产权联系，亦没有劳动关系及财务管理关系。被告泰兴装饰公司也并未参与工程建设、管理等。另外，在合同第4.2.1条及第4.2.2条对挂靠管理费的承担进行了明确约定。庭审中，原告也认可工程的结算、支付等事宜均是与被告陈瑞宗进行协商。以上可以说明原告在签订《幕墙分包合同》时明知或者应当知道被告陈瑞宗系挂靠人。原告对合同履行的信赖利益基于被告陈瑞宗而非被告泰兴装饰公司。原告也未举证证实被告泰兴装饰公司参与工程建设或者在工程履行过程中获取利润等情形，应当承担举证不利的法律后果。本案中，被告陈瑞宗借用被泰兴装饰公司的资质承包案涉工程后又以自己的名义将案涉工程整体转包给原告，应当对欠付原告的工程款承担支付责任。关于工程款数额问题。原告及被告陈瑞宗对被告陈瑞宗应当支付原告的工程款451,266.87元（2,276,256.00元-已付工程款1,445,275.00元-中介服务费100,000.00元-现场管理费、利润等150,000.00元-挂靠管理费及税金2,276,256.00元&times;6.5%+原告垫付税金18,241.87元）没有异议。双方争议的焦点在于付款摘要载明的&ldquo;10-郭沫-2013.1摊销结算费用200,000.00元（协调费160,000.00元业主、设计、签证、监理等、20,000.00元李德工资、20,000.00元差旅费）&rdquo;是否应当作为损失及原、被告之间如何分担的问题。本院认为，被告陈瑞宗将工程整体转包给原告的行为无效，除去工程款之外，办证、进场等实际产生的费用可以作为损失按照《中华人民共和国合同法》第五十八条规定予以处理，但是被告陈瑞宗并未提交证据证实上述费用实际发生及具体数额，应当承担举证不利的法律后果，故被告陈瑞宗应当支付原告工程款451,266.87元。关于原告主张利息损失的问题，《幕墙分包合同》第4.4.3项约定工程款的70%作为人工工资和材料款，原、被告双方不得予以挪用或者分成，其他的工程款在工程结算完成后按照合同约定比例予以付款。原、被告双方多次协商未就损失的数额及分担等达成一致意见进而未进行结算。2019年6月1日，原告向被告发送微信要求被告核对工程款数额，被告收悉。综合本案工程竣工、工程款支付等实际情况，本院确定以2019年6月1日作为计算资金占用利息的起算点。关于利率适用标准，双方并未明确约定欠付工程款的计息标准，故本院参照全国银行间同业拆借中心公布的贷款市场报价利率予以计算。 综上，原告的部分请求符合法律规定，本院部分予以支持。依照《中华人民共和国合同法》第一百零七条、第二百七十二条第二、三款，《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第一条、第二条、第四条、第十七条，《最高人民法院关于适用的解释》第九十条规定，判决如下： 一、被告陈瑞宗于本判决生效之日起十五日内一次性支付原告朱勇派工程款451,266.87元及资金占用利息（以451,266.87元为基数，从2019年6月1日起按照全国银行间同业拆借中心公布的贷款市场报价利率计算至全部清偿为止）； 二、驳回原告朱勇派的其他诉讼请求。 如果未按本判决指定的期间履行给付金钱义务，应当依照之规定，加倍支付迟延履行期间的债务利息。 案件受理费4,646.00元(减半收取)，由原告朱勇派承担1,146.00元，被告陈瑞宗承担3,500.00元（原告朱勇派已预交，被告陈瑞宗于本判决生效后七日内向本院缴纳）。 如不服本判决，可在判决书送达之日起十五日内，向本院递交上诉状，并按对方当事人的人数提出副本，上诉于四川省乐山市中级人民法院。 审 判 员　邓秀蓉 二〇一九年十二月十八日 法官助理　周海英 书 记 员　杨　敏
