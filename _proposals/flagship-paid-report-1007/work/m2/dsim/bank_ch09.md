# 活动报道｜勘察设计数字化实践与设计造价一体化交流会在武汉召开

2026-08-19 16:27 北京

8月18日，勘察设计数字化实践与设计造价一体化交流会在武汉召开。

▲ 会议现场

8月18日，中国勘察设计协会工程造价工作委员会在武汉组织召开了勘察设计数字化实践与设计造价一体化交流会。会议以“数智驱动・设计造价融合”为主题，围绕一模到底、设计造价一体化、BIM正向设计、全生命周期数智平台等内容，分享实操路径与项目案例，助力行业高质量发展。中国勘察设计协会理事长朱长喜，中国勘察设计协会工程造价工作委员会主任委员、浙江省勘察设计行业协会会长张金星，湖北省勘察设计协会会长、中南建筑设计院股份有限公司党委书记、董事长杨剑华出席会议。来自全国勘察设计行业企业负责人、数智化及工程造价有关专业负责人，其他工程咨询类企业技术骨干等180余人参加会议。

▲ 会议现场

开幕致辞

朱长喜在讲话中分析了国家“十五五”规划对城市建设、治理方面高质量发展的总体部署，提出在“十五五”期间，要加快推进数字化、绿色化、智能化、高端化转型，大力培育新质生产力，助力行业高质量发展。针对当前存在的问题，他提出了三点要求：一要树立工程建设全生命周期价值思维，打破设计、造价相互割裂的惯性，推动设计造价一体谋划、同步实施；二要把握行业从信息化迈向数字化的范式跃升，实现技术能力的创新发展；三要全面深化勘察设计企业体制机制改革，破解重技术、轻经济等问题，培育复合型专业人才，面向城市更新、乡村振兴等领域拓展全生命周期服务。

▲ 朱长喜

张金星在讲话中提出推进行业发展的四条实施路径：一是走设计结合之路，推动设计造价深度融合，破除二者割裂问题；二是走技术前沿之路，紧跟数智技术前沿，探索造价数据库、AI造价助手等创新应用；三是走立足服务之路，强化服务属性，汇聚资源促进行业协同；四是走聚焦发展之路，聚焦全过程工程咨询、数智化转型、高质量发展三大方向，推动造价工作与行业大势发展共振。他呼吁以造价管控赋能工程品质提升，共同促进行业高质量发展。

▲ 张金星

杨剑华在致辞中指出，当前全球新一轮科技革命与产业变革加速演进，数字化已是行业生存发展的必答题。本次会议旨在以数智化为纽带实现设计、施工、造价的深度融合，打造全生命周期服务能力，期待与行业同仁在技术攻关、标准制定、人才培养等方面开展更深层次交流合作，共同推动行业高质量发展。

▲ 杨剑华

### 1. 行业公式锚点：融合效能的量化表达

基于对空间细节、光谱深度与时间重访频率的权衡逻辑，我们建立以下融合效能（Fusion Efficiency）量化模型，用以评估融合系统的战略价值：

*   **损耗项（Risk Terms）**：配准误差是异质融合的头号卡点，直接导致重影与语义偏差；而 SAR 图像特有的斑点噪声（Speckle Noise）则是削弱融合图像可解译性的主要干扰源 [来源: 初次网络调研_PDF合并1.pdf]。

# EPC新趋势02：BIM“一模到底”，政策强推下BIM应用的机遇和风险

原创 EPC工程风险管理 2026-08-24 11:28 福建

EPC     BIM

你项目上的BIM模型，做完地下室管线综合优化，还会用吗？

政策层面BIM正向设计、“一模到底”已经铺天盖地，但工地上呢？

我们一个院校培训基地项目，合同里写着“应用BIM技术”。设计成果汇报会上，BIM工程师给甲方、监理演示三维动画模型，汇报了在地下室管线碰撞检查、砌体排砖应用，稀里糊涂就通过了。我私下问他：“设计阶段的BIM模型呢？施工图是用模型出的吗？”他挠挠头：“设计院给的是CAD图纸，我们拿到图之后翻的模。”

翻模。又是翻模。

BIM技术推广十几年了，绝大多数房建项目还停留在“先画图、后翻模”的阶段。模型是模型、图纸是图纸，两张皮。至于“一模到底”——设计用这个模型、施工用这个模型、造价算量也用这个模型——你见过吗？我反正没见过。

这一篇，我就从EPC总包方的视角，把BIM“一模到底”这件事掰开揉碎了说——为什么推不动、怎么推得动、推成了能赚什么钱。

一、BIM的尴尬：推了十几年，还在“翻模”

BIM技术进入中国建筑市场十几年了。政策层面早就铺开了，住建部“十四五”规划明确加快智能建造与新型建筑工业化协同发展；各地政府投资项目陆续要求应用BIM技术。但落到建筑项目的工地上，情况远没有那么乐观。

现状是：BIM应用普遍停留在“点状应用”，离“全生命周期”差得远。

我接触过的房建EPC项目，BIM最常见的用法就这几个：

地下室管线综合——把各专业的管道、桥架放到一起“碰一碰”，看看哪里打架了，调一调。这是BIM用得最多的场景。

砌体排砖——创优项目上，把砌块怎么排布用模型做出来，给工人参考。

汇报展示——做个三维模型动画，给业主汇报时显得“高大上”。

然后呢？模型就扔在那了。

问题出在哪？先搞清楚两个概念。

翻模是“先画图、后建模”，正向设计是“先建模、后出图”。看起来差不多，本质差远了。

为什么推不动？原因就三个：

第一，设计院不给“真模型”。 绝大多数设计院还在用CAD画图，画完了找个团队翻模。翻模的人不懂设计意图，模型只是图纸的“三维复印件”，没有数据价值。你拿着这个模型去算量，算出来的东西你敢用？

第二，“翻模-算量”两层皮。 设计一套模型、造价再翻一套模型算量，两个模型对不上。设计改了，造价不知道；造价算了，设计不认。最后结算的时候审计拿着两套数据来回砍你。

第三，投入产出算不清账。 翻一套模型几十万，用完了就扔，这笔钱花得值不值？没人说得清。

二、政策在推什么：“翻模”时代结束了

2026年被确立为智能建造全面推广元年，政策的核心转向就是从“鼓励试点”到“强制应用” 。

# BIM如香油——一位28年业主视角的行业观察

原创 业主大脑 2026-08-22 00:24 山西

在工程行业业主方摸爬滚打二十八年，我见过太多技术来了又走、概念热了又凉。关于BIM，我的体悟浓缩成一句话：BIM像一小瓶香油——香不香？真香。但中国的项目管理环境像一大盆水，香油倒进去，香味就散了。

这不是BIM的错，也不是水的错。香油就是香油，水就是水。问题出在——你偏要把整瓶香油倒进一大盆水里，却指望满屋飘香。

一、这瓶“香油”，到底香在哪？

1998年入行，从针管笔描施工图，到CAD普及，再到BIM进入视野，我亲历了工具迭代的全过程。BIM这套东西，本质上解决的是建筑行业一个千年顽疾——信息割裂。

传统模式下，设计院出一套图，施工单位按图施工，设备厂家提供资料，运维单位另建台账。每一阶段都在重复整理数据，每一次交付都意味着推倒重来。BIM试图改变的，正是这套信息流动方式——让设计、采购、施工、运维围绕同一套数据协同工作。

在美国，BIM确实跑通了。美国建筑行业以市场化为主导，企业对核心能力的培养向来不遗余力。大型业主单位大多有详尽的BIM标准，他们清楚自己要什么，不搞花架子，喜欢针对一个应用点做深做透。业内有个说法叫“Hollywood BIM”和“Real BIM”——前者装点门面，后者才真正创造价值。

这瓶香油，在美国那口锅里，确实煎出了醇厚的香气。

二、这盆“水”，究竟什么温度？

二十八年的业主方管理实践告诉我，国内项目管理环境有三大特征，与BIM这套“美国配方”天然不兼容。

第一，我们靠“现场应变”，而非“事前规划”。国内绝大多数工程是在不断修改与妥协中推进的，这种调整贯穿始终。前期可研往往是为立项而做，而且是静态的，实施过程朝令夕改、设计变更是家常便饭——遇到问题现场解决，这种应变节奏，BIM软件根本跟不上。国外设计师几年改一栋楼，我们几个月就要盖起来。BIM要求精细的事前推演，而我们擅长灵活的事后纠偏。这不是优劣之分，是两种截然不同的生存逻辑。

# 如何进行实践性大学BIM授课？更能贴合新型土木工程中的BIM应用

BIM（Building Information Modeling，建筑信息模型）正在从传统的“辅助设计工具”逐步发展为贯穿规划、设计、采购、施工、调试、运维和资产管理全过程的数字化管理平台。对于大型基础设施、城市轨道交通、公路桥梁、综合管廊以及EPC项目，BIM的价值尤其突出。如何进行实践性大学授课？让同学们学到的知识更贴近工作所需，技能上手。

一、BIM在规划阶段的应用

在项目立项和规划阶段，BIM可以将地形、道路、管线、建筑物、既有设施等信息进行数字化整合。

主要应用包括：

三维场地建模：建立项目周边地形及既有设施模型。

线路方案比选：用于地铁、公路、桥梁等线路方案的可视化分析。

地下管线分析：提前识别给排水、电力、燃气、通信等管线冲突。

工程量初步估算：利用模型快速提取工程数量，为投资估算提供依据。

施工可行性分析：提前判断施工场地、交通导改、临时设施等条件。

对于城市地铁和市政综合工程而言，地下空间的综合协调是BIM最有价值的应用之一。

二、BIM在设计阶段的应用

传统二维图纸容易出现“各专业各自设计”的问题，而BIM能够将建筑、结构、机电、市政、轨道、管线等专业集中到同一个三维环境中。

重点包括：

1. 三维可视化设计

将二维图纸转化为三维模型，使设计人员、业主、施工单位和监理能够直观理解工程。

2. 碰撞检查

例如：

给排水管道与结构梁冲突→ BIM提前发现 → 设计阶段调整 →避免施工阶段返工。

特别是在地铁车站、综合管廊、机电安装和大型工业项目中，碰撞检查具有很高的经济价值。

3. 设计优化

通过模型分析，可以对结构尺寸、管线走向、设备布置、施工空间等进行优化。

4. 工程量自动提取

模型与工程量数据关联后，可以辅助形成：

BIM模型 → 工程量 → 清单 → 预算 → 合同价

从而提高工程量计算效率。

三、BIM在施工阶段的应用

施工阶段是BIM真正创造经济价值的重要环节。

1. BIM+施工进度

将BIM模型与施工进度计划结合，可以形成4D BIM。

即：3D模型 + 时间维度 = 4D施工管理

BIM变更管理在实际操作中遇到的主要挑战

根据最新的行业研究与实践反馈，BIM变更管理在实际操作中面临的挑战，远不止技术层面的障碍，而是涉及工具能力、流程协同、人员组织和制度环境等多个维度的复杂问题。以下从实际操作视角，系统梳理主要挑战。

一、软件工具与技术能力瓶颈

1. 变更传播的"链式反应"难以控制

在BIM模型中，构件高度关联，一次看似微小的修改可能触发难以预料的连锁反应。例如在电气BIM模型中，由于专业间依赖关系复杂，移动一个设备的位置，可能会导致管道路径、馈线容量、面板排程、协调区域等多个方面同步受影响，形成难以手动管理的链式反应

。

2. 模型频繁更新引发"版本信任危机"

实时协同听起来高效，但实践中，过于频繁的模型更新反而会造成混乱。当模型变化太快，团队无法获得一个稳定的工作版本，成员会因"明天可能还会变"而犹豫是否推进工作，导致项目从"推进"状态滑入"反复确认"状态

。据相关行业报告，42%的BIM团队每周要花费8小时以上来协调冲突的版本，原因往往是不一致的命名规范。

3. 缺乏自动化的变更影响分析能力

早期研究即已指出，BIM工具存在明显短板：无法自动生成设计变更的对比偏差报告，外部分析软件与BIM工具之间的双向链接不可靠，且缺乏足够的人工智能来分析和推荐变更备选方案

。这一问题在复杂项目中尤为突出——BIM工具在检测空间依赖关系方面表现良好，但在追踪模型间的分析性关系（如结构荷载变化对下游的影响）方面能力有限。

4. 软件数据互通与版本兼容性问题

不同软件系统之间的互操作性仍是实操中的主要障碍。团队常需要在BIM建模工具、成本估算软件和项目管理系统之间迁移数据，互操作失败时数据不得不手动重新录入，增加了错误风险并耗费大量时间

。

二、流程与协同层面的混乱

1. 版本控制混乱与模型不同步

。

# 公司花50万上BIM，现在沦为"展示工具"——BIM为什么在中国工地活不下去？

原创 老蔡聊造价 2026-09-02 08:26 上海

我们公司前年花50万上了BIM：买软件、买培训、招了两个BIM工程师。老板当时说"以后算量靠模型，进度靠模型，成本靠模型"。一年不到，那两个工程师主要干一件事：把模型做得漂亮，拿去给业主汇报、投标可视化、评优评奖。算量还是广联达手搓，进度还是Excel，成本还是我对着图纸扒。50万买来的，是个展示工具。我干施工三十六年，见过不下十家这么搞的。说句实话：BIM在中国工地活不下去，不是软件不行，是用法错了——买的是工具，没买的是流程、标准和责任。

一、模型与现场，两张皮

多数项目的BIM是"专门团队"建的，跟施工员、造价员是两拨人。建模的按图纸建个好看的外壳，LOD（模型精度）到不了施工用的程度——钢筋怎么锚固、模板怎么支、土方怎么放坡，模型里没有。等真干起来，施工员不认模型，造价员还是拿广联达重新算一遍。模型建完就锁在那，现场一变更，模型不更新，慢慢连展示都懒得更新了。

二、数据不流转，各建各的

设计院给的模型，施工接不住；施工建的模型，运维不接。每个阶段各建各的，因为没有统一的编码和交付标准，信息全是孤岛。最典型：设计BIM、施工BIM、竣工BIM，三套数据对不上。花50万建的施工模型，竣工时没人要——运维单位自己另起炉灶。前面建的，白建。

三、投入产出错配：买了软件，没买流程

50万够买软件、够培训，但不够改流程。BIM工程师是"附加岗"，不嵌进生产：不算量、不管进度、不碰成本，那就只能做展示。真要用起来，得把BIM绑进算量、进度、成本考核——模型错了要追责、模型省了要奖励。没这套考核，BIM就是个花瓶，摆着好看。

四、结算不认BIM量，BIM就省不了钱

这是最要命的。甲方结算，按图算、按定额算，BIM模型不算数。施工方拿BIM提的工程量去结算，审计一句话："以施工图为准。"白搭。BIM省下的钱，前提是你拿模型当依据去争。结算不认，省的成本就落不了地，老板看不到回报，下一年预算就把BIM砍了。这死循环，不是BIM的错。

五、责任空缺：模型错了，谁担？

模型里少算了一道墙、错标了一个标高，施工照着干出了事，谁负责？现在法律层面，BIM模型不是结算和责任的法定依据，施工方不敢拿它当唯一准绳。没有"模型即责任"的闭环，BIM永远只是参考，不是依据。参考的东西，关键时刻没人信。

六、人的惯性，比软件难改

老师傅干了一辈子，靠经验和图纸，让他看三维模型他头大；年轻人会用BIM，但在工地上话语权低，说了不算。组织上又不强迫用——不用也不罚，用了也不奖。工具再好，落在"可用可不用"的灰色地带，最后一定不用。

# 从“两张皮”到“一体化”：一家能源央企的合规管理突围实录

原创 国信正通 2026-09-07 15:00 北京

导读

“以前我们的合规体系，就像挂在墙上的画，好看是好看，但跟业务跑的是两张皮。”

这是某大型能源央企下属储气库公司负责人在回顾过去时的真实感慨。在监管日益严苛的今天，像他们这样的大型企业，面临着巨大的合规压力：既要满足国资委《中央企业合规管理办法》的硬性要求，又要防止庞大的业务体系中出现风险漏洞。

CCFC

1

困局：体系有了，但“转”不起来

虽然企业早就建立了一套合规制度，但实际运行中却问题频出：

风险识别难：海量法规与具体业务对不上号，员工不知道哪里有风险。

责任落实难：合规是法务部的事，业务部门觉得是“额外负担”。

审核流于形式：外部机构来审核，往往只看文件齐不齐，看不出业务里的真问题。

企业急需的，不是一张冷冰冰的证书，而是一套能真正融入业务、防范风险的“免疫系统”。

2

破局：从咨询到认证，全链条重塑合规体系

国信正通介入后，没有急于发证，而是先做了一件事——深入诊断。我们派驻了由注册会计师（CPA）、法律专家组成的“实战型审核铁军”，用两周时间驻场调研，摸清了企业在采购、合同、安全生产等核心业务中的真实风险点。

在此基础上，我们为企业量身定制了合规管理体系建设咨询方案，并引入独创的“三位一体”合规管控体系：

给雷达：运用“滤镜识别”技术，从海量法规中筛选出与储气库业务强相关的风险点，建立动态风险图谱。

起抓手：利用“重点岗位模型”，把合规职责拆解到具体岗位，谁签字、谁负责，一目了然。

装阀门：在采购、合同等关键流程嵌入强制性合规审查节点，不合规，流程就走不下去。

咨询阶段完成后，企业已经拥有了一套“能用、好用”的合规体系。但国信正通的服务并未止步于此。

作为国家认监委批准的第三方权威认证机构，我们紧接着启动了合规管理体系认证服务，严格执行五阶段标准化认证流程：

1. 项目受理与合同评审：

明确认证范围，确认组织资质及体系文件，签订正式认证合同。

2. 审核策划与调度：

根据企业行业特点与组织规模策划审核方案，指派具备相应专业背景和行业经验的审核组。

3. 现场审核实施：

一阶段评估体系策划与准备情况，二阶段全面验证体系运行的符合性与有效性，末次会议通报不符合项报告。

4. 认证决定与证书颁发：

审核组提交报告后由技术委员会独立评定，通过后颁发证书并上报CNCA官网公示，确保认证决定的公正独立。

5. 监督审核与再认证：

三年认证周期内每年一次监督审核确保持续有效运行，期满后进行再认证审核以延续认证资格。

正是这种“咨询+认证”双轮驱动的模式，让企业的合规体系不仅“建得起来”，更“审得过硬”。
