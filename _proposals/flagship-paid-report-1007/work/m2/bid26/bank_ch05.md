01

事件概述

2023年，湖南益阳南县警方核查线索时发现，5家资质独立、看似无关的建筑企业，扎堆去投湖南多地的公路、水利项目，预留的投标联系人却是同一个人，这几家投的标还全中了。

负责投标的是彭天明，19岁，初中学历。

2020年7月，他进了长沙一家建筑公司，做招投标资料的整理和申报，一年多里经他报出的投标有110多次。

论资历，他几乎一片空白，没经营过企业，没有招投标资质，连这一行的基本从业条件都不符合。

可多家建筑企业的投标都归他管，报价定多少、要不要陪标，由他经办。

他并不是主事者，真正的核心和受益人是老板刘伟鹏，他只是被雇来干活的。

刘伟鹏说得直白，"我们从来不靠自己中标，赚的只是陪标好处"。

02

典型一案

2021年11月的南县某公路工程A标段，项目总标价2200万，12家企业投标。

操盘的是张超（化名），一家建设公司的业务经营部部长。

他干这行18年，握有公司的投标决策权，却没打算靠方案和报价去争。

他找到省内7家最强同行，开出"开标后每家给2万元资质使用费"的条件，请它们退出。

标前预备会上又冒出4家省外企业，张超让高中同学刘路（化名）去打点。

刘路在路桥圈摸爬多年，人脉广，是熟知的中间人。

他只谈成3家，却对张超说4家都谈妥了，收了3万元协调费。

刘路对接的另一头是刘伟鹏团队，他用1.6万元说定山西、安徽两家陪标，把报价下浮限在13%内，又花8000元请贵州一家配合。

当年12月开标，张超公司以1942万余元中标，事后给7家省内陪标企业各付2万元，给刘路3万元。

这伙人生意越做越大，终被警方拔起。

目前，11名犯罪嫌疑人已被移送检察机关审查起诉，案件进入诉讼程序，尚未宣判。

# 电子围标串标判定依据

成控顾问 2026-03-23 21:18 河南

引言：电子标查询围标串标，核心依据是法律法规 + 电子数据痕迹 + 文件内容异常 + 报价 / 行为 / 财务异常，全部可通过平台自动比对 + 人工复核锁定。下面分法律依据、技术电子证据、文件内容、报价行为、财务关联五大类完整说明。

一、法律依据（认定的根本）

1. 《招标投标法》第 53 条

禁止投标人相互串通投标报价、排挤公平竞争；

禁止招标人与投标人串通投标。

2. 《招标投标法实施条例》第 40 条（核心）

有下列情形之一的，视为投标人相互串通投标：

不同投标人的投标文件由同一单位或者个人编制；

不同投标人委托同一单位或者个人办理投标事宜；

不同投标人的投标文件载明的项目管理成员为同一人；

不同投标人的投标文件异常一致或者投标报价呈规律性差异；

不同投标人的投标文件相互混装；

不同投标人投标保证金从同一单位或者个人的账户转出。

3. 地方与部门规定

电子招投标办法：IP/MAC/ 机器码 / 计价锁号一致 → 直接认定串标

多地（福建、安徽、甘肃等）明确：同一设备 / 网络制作多份标书 → 废标 + 移送监管福建省发展和改革委员会

《政府采购法》第 77 条、《刑法》第 223 条（串通投标罪）

二、电子技术痕迹（电子标最主要筛查依据）

1. 网络地址重复（最常见）

上传 IP 地址相同（尤其异地公司 IP 一致）

MAC 地址、CPU 序列号、硬盘序列号相同

同一 WiFi / 局域网内多公司同时报名、下载、上传

认定：≥2 家投标人一致且无合理解释 → 串标

2. 电子设备与软件同源

同一计价软件加密锁号（造价锁号一致）

同一CA 数字证书、电子签名设备

同一台电脑创建 / 修改 / 保存标书（文档元数据：作者、保存者、创建时间）

同一设备打印、加密、上传

3. 文件标识码雷同

Word/PDF 元数据：作者、公司、版本、修订记录一致

XML 工程量清单软硬件信息一致

文件哈希值、GUID、创建标识码高度相似

三、投标文件内容雷同（直接认定依据）

1. 全文高度重复

技术标、施工方案连续文字重复≥30 字、段落顺序一致

格式完全一致：字体、行距、页眉页脚、页码、符号

冷僻术语、特定句式、自定义缩写完全相同

2. 错误完全一致（铁证）

错别字、标点、漏项、错项、公式错误完全一样

实质性内容两处以上细节错误一致 → 直接否决投标

3. 人员信息混同

法定代表人、授权人、项目负责人、联系人同一人

电话、邮箱、地址、传真多家公司完全相同福建发改委

股东、高管、办公地址高度关联福建发改委

四、报价与行为异常（行为学依据）

# 串标、围标、陪标的分辨方法

国企点滴谈  河北

串标、围标、陪标是业界3个“不成文”的概念，这3个词虽只有一字之差，但在具体所指上却有很大不同，不宜相提并论。

串标

串标是串通投标的简称，其在政府采购领域的含义可在《政府采购货物和服务招标投标管理办法》中找到答案。另外，串标是一种列入刑法罪名的违法行为，具有可识别的侵犯客体和可操作的认定标准。刑法第二百二十三条明确提出了串通投标罪，并规定，投标人相互串通投标报价，损害招标人或者其他投标人利益，情节严重的，处三年以下有期徒刑或者拘役，并处或者单处罚金。

围标

围标就是组团投标，是一种竞争策略，所有组团成员投出的价格平均数（算数平均值）与某成员的投标价接近或相同，并帮助这位成员最终中标。围标多见于设有标底（主要是复合标底）的工程建设项目，在政府采购中并不常见。其是对特定评审规则的应对策略，它的主要功能是提升中标概率，并没有明确的侵犯客体和损害后果。围标不是政府采购法规体系中部门规章以上制度文件界定的违法行为。

实践中，围标的成本高，风险大，但成功的几率却较低，参与人多是不得已而为之。

陪标

陪标则多见于政府采购项目。有些陪标的目的是避免招标活动因在开标时没有3家合格供应商而失败，这种策略其实本无恶意，初心含有一番保障采购效率、维护各方当事人利益的意味。但不管怎样，陪标是一种不规范的投标响应行为。

# 生态环境行政处罚办法 （2026年修正）

2026-09-30 11:19 河北

生态环境行政处罚办法

（2023年5月8日生态环境部令第30号公布，根据2026年9月20日《关于修改和废止部分规章的决定》修正）

第一章总则

第一条  为了规范生态环境行政处罚的实施，监督和保障生态环境主管部门依法实施行政处罚，维护公共利益和社会秩序，保护公民、法人或者其他组织的合法权益，根据《中华人民共和国行政处罚法》《中华人民共和国行政强制法》《中华人民共和国生态环境法典》等法律、行政法规，制定本办法。

第二条  公民、法人或者其他组织违反生态环境保护法律、法规或者规章规定，应当给予行政处罚的，依照《中华人民共和国行政处罚法》和本办法规定的程序实施。

第三条  实施生态环境行政处罚，纠正违法行为，应当坚持教育与处罚相结合，服务与管理相结合，引导和教育公民、法人或者其他组织自觉守法。

第四条  实施生态环境行政处罚，应当依法维护公民、法人及其他组织的合法权益。对实施行政处罚过程中知悉的国家秘密、商业秘密或者个人隐私，应当依法予以保密。

第五条  生态环境行政处罚遵循公正、公开原则。

第六条  有下列情形之一的，执法人员应当自行申请回避，当事人也有权申请其回避：

（一）是本案当事人或者当事人近亲属的；

（二）本人或者近亲属与本案有直接利害关系的；

（三）与本案有其他关系可能影响公正执法的；

（四）法律、法规或者规章规定的其他回避情形。

申请回避，应当说明理由。生态环境主管部门应当对回避申请及时作出决定并通知申请人。

生态环境主管部门主要负责人的回避，由该部门负责人集体讨论决定；生态环境主管部门其他负责人的回避，由该部门主要负责人决定；其他执法人员的回避，由该部门负责人决定。

第七条  对当事人的同一个违法行为，不得给予两次以上罚款的行政处罚。同一个违法行为违反多个法律规范应当给予罚款处罚的，按照罚款数额高的规定处罚。

实施行政处罚，适用违法行为发生时的法律、法规、规章的规定。但是，作出行政处罚决定时，法律、法规、规章已经被修改或者废止，且新的规定处罚较轻或者不认为是违法的，适用新的规定。

第八条  根据法律、行政法规，生态环境行政处罚的种类包括：

（一）警告、通报批评；

（二）罚款、没收违法所得、没收非法财物；

（三）暂扣许可证件、降低资质等级、吊销许可证件、一定时期内不得申请行政许可；

（四）限制开展生产经营活动、责令停产整治、责令停产停业、责令关闭、限制从业、禁止从业；

（五）责令限期拆除；

（六）行政拘留；

（七）法律、行政法规规定的其他行政处罚种类。

第九条  生态环境主管部门实施行政处罚时，应当责令当事人改正或者限期改正违法行为。

责令改正违法行为决定可以单独下达，也可以与行政处罚决定一并下达。

责令改正或者限期改正不适用行政处罚程序的规定。

# 借130家公司围标，多人获刑："陪标团"越大，刑期越长

原创 张栩宁 2026-09-13 12:30 北京

"围标串标，赢的是一次中标，输的是自由；'行业惯例'四个字，挡不住一纸刑事判决书。"

你参加过"陪标"吗？借几家兄弟公司的资质，围一个标，觉得是"行业惯例"？今天两个判例告诉你，这叫串通投标罪。西藏陈某某借多家公司围标5个市政项目，获刑10个月、罚金60万；芜湖戴某借130余家公司围标，多人获刑。"陪标"离刑事犯罪，只差一张立案决定书——而且这张纸，正在被大数据主动送上门。

一、一个扎心的事实：追诉门槛并不高

串通投标罪的立案标准并不高：直接经济损失50万元以上、违法所得10万元以上、中标项目金额200万元以上，满足其一即被追诉。换算一下：一个中等规模的市政项目就轻松超过200万元——也就是说，绝大多数"陪标"行为从动手那天起就在刑事红线之内，区别只是有没有被查到。行政责任同样不轻：串通投标被查实，轻则取消投标资格、没收违法所得并罚款，重则列入失信联合惩戒名单——对企业来说，"禁入"比罚金更致命：一定期限内不能投标，等于被市场开除。

近年判例密集：西藏陈某某借多家公司资质围标5个市政项目获刑10个月罚金60万；湖北姜某某等四股东借十余家公司围标5000万项目全部获刑；芜湖戴某借用130余家公司围标多人获刑。建市规〔2026〕2号文推行"人工智能+招投标监管"后，报价雷同、IP一致、文件同源等围标特征将被大数据自动识别。过去查围标靠举报、靠翻账，现在系统自动比对推送线索——电子标书从制作那一刻起就带着"机器指纹"：创建时间、作者信息、硬件特征、造价锁号，全程留痕。更值得注意的是行刑衔接：招投标行政监督部门发现围标线索，会移送公安机关处理，行政调查阶段收集的报价数据、投标文件、资金流水，直接成为刑事证据——很多串通投标案不是警方主动侦破的，而是监管部门"快递"上门的。

二、真实案例：围标=犯罪，不是惯例

▍真实案例

西藏陈某某案——借多家公司资质围标5个市政项目，构成串通投标罪，获刑10个月并处罚金60万元：中标项目金额超200万元即达追诉标准，"陪标"离刑事犯罪只差一张立案决定书。　（来源：西藏法院公开判例）

▍真实案例

芜湖戴某案——借用130余家公司资质围标，相关多人获刑："陪标团"规模越大，刑期越长；对照湖北姜某某案——四名股东借十余家公司围标5000万元项目，全部获刑：股东个人与公司同追刑责，老板别以为"公司办事公司担"。　（来源：安徽、湖北法院公开判例）

三个案子连起来看，量刑规律很直白：组织者的刑期与"陪标团"规模正相关。借三家公司是犯罪，借一百三十家还是犯罪——而且后者在判决书里会被认定为有组织的围标，主犯地位更突出，量刑更重。还有一个信号值得注意：这类案件的裁判文书大多上网公开，围标记录会跟着企业走，影响的是未来所有项目的资格审查。

# 19岁、初中文化、没干过一天工程：他凭什么经手110次投标？

原创 周周好 2026-10-08 14:34 北京

9月19日，央广网披露湖南益阳南县一起特大工程围标串标案：横跨5省、串通投标191个项目、涉案30亿元。

警方第一次注意到它，是因为一组反常数据：2021年，5家资质独立、注册地分散的建筑企业扎堆竞标，投标联系人却指向同一个人——19岁、初中文化、没干过一天工程的彭天明。

03 罚款顶格千分之十，刑期顶格三年

先算笔违法成本：撬动成本不到20万元，中标价却是1942万元。

行政罚款，《招标投标法》第五十三条设了上限：中标额千分之五到千分之十。中铁上海工程局因串通投标被罚117.09万元，占建安费价款千分之6.5，已算偏上。

刑事那边更扎眼。刑法第223条，串通投标罪顶格三年以下有期徒刑。191个项目、30亿案值，主犯也就三年。

2026年6月，《招标投标法（修订草案）》首次提请全国人大常委会审议，拟把罚款标准提至百分之二至百分之十，并增设资格罚。按1942万元算，罚款区间从不足20万元跳到约39万至194万元。

方向没错，只是草案还在路上。彭天明已满18周岁，作为从犯照常被追诉。

04 机器锁得住标书，锁不住资质

2025年2月，湖南试运行"机器管招投标"。到今年3月，平均投标家数从14.4家涨到42.5家，民企中标率从73.65%升到82.2%。

今年初，湖南公示拟将24家串通投标企业列入严重不良行为信用惩戒名单，5月正式公告26家。系统比对发现，这些企业投标文件"创建标识码"一致，判定串通投标，信用评价记零分、两年禁投。

技术确实管用。但机器锁得住"标书同源"，锁不住"资质挂靠"：一个人攥着8家公司经营权，证书、人员、场所样样合规，系统里就是8家独立企业。
