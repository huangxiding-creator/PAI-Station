“

旧周期彻底结束，但每个周期的终结，都伴随着新机会的诞生。

2026年上半年，建筑业用12.71%的降幅正式宣告：旧周期彻底结束。

但每一轮周期结束，都伴随着新机会的诞生。今天不讲「为什么跌」，讲跌完之后，机会在哪。

TRACK ONE

# 第14章 趋势：数字化·智能·绿色·出海

本章将深入剖析核电EPC（设计-采购-施工）总承包模式在数字化底座、智能化决策、绿色全生命周期管理及国际化出海四大维度的深度变革。本章主线基于“数据驱动—智能赋能—绿色增值—标准输出”的逻辑链条，通过ITER项目、华龙一号及中核工程标杆案例，论证核电EPC如何从传统的工程承包商转型为全球能源生态的价值共创者。关键结论预览：数字化交付已从单一工具升级为全产业链协同的“数字孪生空间”；智能化决策通过“机理-数据”双模型将风险防控从“事后补救”转向“事前预判”；绿色EPC正通过全生命周期资产管理实现资产价值的最大化；出海业务的核心竞争力已从技术输出转向标准与文化的双重输出。

---

### 14.1 数字化：从设计一体化到管理全集成的深层转型

数字化转型已不再是企业的可选配置，而是打破核电EPC“数据孤岛”、提升工程确定性的核心底座。通过全流程数据的标准化、对象化与集成化，企业正实现从单一设计工具应用向全产业链数字化生态的跨越。

#### 14.1.1 仪控标准安装的数字化设计革命
在核电设计领域，仪控（I&C）标准安装设计因涉及上千种仪表、数百种大宗材料及复杂的现场环境，历来是EPC总承包管理的难点。传统设计模式下，图纸、材料清单与设备清单往往以离散的文件形式存在，仅通过文字引用关联。在处理漳州1#、2#机组等大型三代核电项目时，这种模式极易导致统计失误、设计变更滞后以及现场材料“错买多买”等顽疾。

中国核电工程有限公司通过引入Engineering Base (EB) 数字化平台，发起了一场“对象化设计”革命。EB软件的核心价值在于通过“数据源清洗”，将离散的文档转化为具有层级架构的结构化对象。这一变革并非简单的软件替代，而是基于物理世界数字孪生的构建，通过对制造基地的厂房、生产线、设备进行三维建模，初步实现物理环境的虚拟还原，为跨部门协作提供了统一的空间参考框架[来源: 核电行业智库丛书丨创新驱动协同发展打造核岛_709.md]。

具体而言，EB平台的应用彻底摆脱了传统二维图纸交付模式的束缚。通过三维设计软件的应用，设计成果将更加直观、精准，推进设计流程的标准化与高效化。在设备布局优化方面，生产管理部门可通过模型快速评估产线调整方案，减少现场试错成本；在安全管控升级方面，安防团队可基于三维模型与智能安防监控系统协同，实时掌握全厂运行情况，提升安全隐患排查效率[来源: 核电行业智库丛书丨创新驱动协同发展打造核岛_709.md]。这种从“绘图”到“建模”的转变，确保了设计数据在采购、施工及调试阶段的唯一性与有效性，从源头解决了数据一致性问题。

此外，数字化设计还促进了设计方、设备制造厂及监管单位之间的数字化信息交互与共享，致力于构建一个开放、透明、互信的数字化信息交流平台，实现设计、生产、监管等环节数据的无缝对接与实时同步[来源: 核电行业智库丛书丨创新驱动协同发展打造核岛_709.md]。这种全链条的数字化贯通，不仅提升了设计效率，更为后续的智能制造与运维奠定了坚实的数据基础。

#### 14.1.2 EPC总承包模式下的文档元数据标准化
元数据（Metadata）是核电工程数字化交付的“指纹”。通过对《核电电子文件元数据》（EJ/T 1224）与《文书类元数据方案》（DA/T 46）的比较研究，专家指出，EPC总承包模式对元数据提出了更高的管理维度需求。

### 1. 行业公式锚点：融合效能的量化表达

基于对空间细节、光谱深度与时间重访频率的权衡逻辑，我们建立以下融合效能（Fusion Efficiency）量化模型，用以评估融合系统的战略价值：

`融合效能 (E) = (空间细节度 × 光谱丰富度 × 时间重访率) / (配准误差 + 噪声干扰)`

**核心因子深度解析：**
*   **空间细节度 (Spatial Fidelity)**：主要由全色（Panchromatic）图像资产贡献，其核心价值在于提供亚米级（如高分七号 0.8m）的精细几何结构与纹理特征 [来源: 初次网络调研_PDF合并1.pdf]。
*   **光谱丰富度 (Spectral Depth)**：由高光谱（Hyperspectral）资产驱动，捕捉地物精细的光谱特征曲线，其波段跨度可达几十至数千个，是识别目标材质、成分的关键维度 [来源: 初次网络调研_PDF合并1.pdf]。
*   **时间重访率 (Temporal Cadence)**：决定了对动态目标（如作物生长周期、战场态势）的响应速度，如 MODIS 提供的每日重访频率是时空融合方案的底层基石 [来源: 初次网络调研_PDF合并1.pdf]。

# 国际工程｜国际设计咨询行业六大趋势：从“设计服务”走向“投资决策与全生命周期专业服务”

原创 无名高手 2026-09-22 09:40 北京

深入研究国际设计咨询中国际前排的几大公司，这两三年内总体来看，可以得出一个基本的结论就是：国际设计咨询行业正在发生“工作边界重构”。

传统设计咨询公司的工作边界大致是项目立项 → 可研 → 初步设计 → 施工图 → 设计配合。

这几年国际领先工程咨询公司的业务边界已经明显分别或者综合向三个方向扩展：

向前：进入投资决策

战略 → 市场研究 → 投资机会 → 商业论证 → 可研 → 技术尽调 → 融资支持

向后：进入项目交付和资产运营

FEED → Design → Procurement → Construction Management → Commissioning → O&M → Asset Management

向侧面：进入风险、金融、数字和可持续发展

Technical Advisory + Commercial Advisory + Risk + ESG + Digital + AI + Climate + Finance

因此，国际设计咨询行业实际上正在从Engineering Design Company向Engineering & Professional Services Company转化，进一步向Engineering + Advisory + Program Management + Digital + Asset/Lifecycle Services演变。

这一变化不是简单地“增加几个新业务”，而是重新定义工程咨询公司的价值链位置，明显地呈现出六个方面的趋势。

趋势一：从“设计阶段服务”向“投资决策前端”延伸

传统设计院通常从业主已经决定建设一个项目之后才进入可研 → 设计 → 招标 → 施工服务

而国际咨询公司越来越早地介入项目，工作范围逐渐前移到投资机会识别 → 战略咨询 → 市场分析 → 投资可行性 → 商业模式 → 技术可行性 → 投资决策 → 融资准备 → FEED → Design

也就是说，咨询公司的客户不再只是问“这个项目怎么设计？”或者只是把咨询设计公司当做出图的单位，而是开始想从设计咨询公司这里知道“这个项目到底值不值得投资？”进一步他们希望设计咨询公司能够就以下问题给出更专业的答案，“应该投资多少？采用什么技术？怎样建设？风险在哪里？如何融资？”

# 生成式视频模型的法律风险与全球监管趋势

原创 方建伟 等 2026-09-16 18:27 北京

生成式视频正在进入短剧、广告、电商和影视制作流程。一段AI视频可能同时调用文字、图片、声音、动作和人物特征，风险也分布在训练数据、参考素材、模型输出和平台传播等多个环节。本文将以一部AI短剧的生产流程为线索，梳理主要法律问题及监管框架。

作者丨方建伟 江佳颖 杨梦蝶

2026年5月，中央网信办部署指导网站平台规范短视频内容标注，要求网站平台将内容标注设置为短视频发布的必经环节。发布者应当从六类“必选标签”中选择一项，其中包括“含有AI生成内容”。网站平台需对新增短视频标注情况进行巡检，同时对未标注或者标注不正确的存量视频进行补标或纠正。[1]

上述标注机制虽可使用户知悉相关内容是否由AI生成，但标注本身既不能反映人物参考图是否已取得授权，也不能说明模型在生成过程中是否使用了他人的面部特征。因此，“含有AI生成内容”标签本身并不能替代肖像权、著作权等许可。以一部AI短剧为例，其自脚本输入模型，经角色生成、配音与剪辑，至平台上线，各环节的审查重点均可能随之变化。要厘清前述风险，需先明确视频模型的技术运行逻辑。

一、生成式视频模型的技术特征

（一）视频生成与图片生成的技术差异

图片生成主要处理单一画面的空间关系，而视频生成还需处理时间维度，即人物外貌、场景及物体位置能否在镜头切换后保持连续，以及动作与音画是否协调。因此，视频扩散模型研究常常将时序连贯列为核心任务之一。

此外，生成式视频的输入已不限于提示词。人物照片、动作参考及既有视频等均可能参与内容生成。模型未对原图直接进行复制，并不等同于未处理与自然人相关的信息；输出内容发生变化，亦不当然排除著作权法上的实质性相似认定。

# 《关于进一步深化国资国企改革的方案（2026—2029 年）》  改革重点方向分析

原创 张智博 2026-09-08 11:45 北京

2026 年作为 “十五五” 规划开局之年，《关于进一步深化国资国企改革的方案（2026—2029 年）》全面落地实施，标志着我国国资国企改革正式迈入全新四年攻坚周期。回望十余载国企改革递进脉络：2020—2022 年国企改革三年行动聚焦市场化经营机制破冰，解决 “干部行政化、激励不灵活” 表层问题；2023—2025 年国企改革深化提升行动主攻公司治理效能，搭建现代化治理基本框架；而 2026 至 2029 年新一轮改革跳出单点修补模式，以布局重构、创新突围、机制定型、监管升级四大核心目标为抓手，直面国企增长动能不足、科技转化不畅、经营层守成、人才结构失衡、多层级监管复杂五大深层矛盾，推动国有经济从“规模扩张型” 全面转向 “战略价值型”，做强做优做大国有资本，筑牢服务中国式现代化的战略支撑。

不同于前两轮改革侧重单项制度落地，本轮改革突出系统性重构、分层分类施策、量化指标硬约束、时序化闭环推进四大鲜明特征。央企已率先启动方案细化与台账编制，南方电网在2026 年年中工作会议率先发布配套改革要点，细化 7 大领域、22 条方向、123 项落地举措，为全行业提供改革实操范本。

一、改革迭代逻辑：三轮改革层层递进，本轮实现质的跃迁

读懂2026—2029 年改革，首要厘清三轮改革的定位差异、解决问题与核心成果，清晰把握改革从 “形似” 到 “神似” 再到 “质变” 的完整演进路径。

（一）1.0 阶段（2020—2022 国企改革三年行动）：破局市场化机制，完成制度 “有形覆盖”

本轮改革的核心任务是搭建市场化经营基本框架，破解长期以来国企管理行政化弊病。改革抓手集中于经理层任期制和契约化管理、工资总额动态调整、混合所有制改革、三项制度改革落地。彼时国企最大痛点在于干部能上不能下、员工能进不能出、薪酬能增不能减，行政化考核压制经营活力。

通过三年攻坚，绝大多数国企完成契约化签约、全员绩效考核、混改试点落地，市场化经营机制实现全覆盖，但改革局限于机制改良层面，存在“重文件落地、轻实际运行” 问题：部分企业契约管理流于形式，薪酬分配平均主义未根本破除，改革停留在制度文件层面，未能深度匹配企业战略定位与产业发展需求。

（二）2.0 阶段（2023—2025 国企改革深化提升行动）：优化治理架构，提升董事会决策效能

在前一轮机制建设基础上，改革重心转向公司治理体系完善，核心目标是构建中国特色现代企业治理雏形。政策重点推动外部董事占多数落地，优化董事会专业结构，完善“党委前置研究、董事会战略决策、经理层经营执行、监事会监督制衡” 治理闭环，同步健全经营、决策、管理三重追责问责机制。

# “十四五”西北院答卷丨境之美：厚植生态底色，绘就美丽中国

- 来源: https://www.nwh.cn/col/col10756/art/2025/art_20c8f5335ed746dd8adbb0f562fdbcb0.html
- 栏目: 企业新闻
- 采集: 2026-10-05

【编者按】“十四五”时期，是西北院极不寻常、极具挑战的五年，更是砥砺奋进、硕果累累的五年。五年来，西北院始终以习近平新时代中国特色社会主义思想为指导，深入贯彻落实国家重大战略部署，牢牢锚定建设“国际一流科技型工程公司”目标，在改革发展的浪潮中勇立潮头，在科技创新的赛道上奋勇争先。

期间，西北院荣获全国五一劳动奖状、国家科学技术进步特等奖等多项国家级荣誉，两次获评国务院国资委科改示范“标杆”企业等多项高级别认证，成为陕西省首家“四综甲”资质企业，稳居陕西省百强企业前50强，以实打实的业绩为地方经济社会发展注入强劲动力。

“十四五”西北院答卷第三期聚焦水利与生态环境业务板块。五年来，西北院始终与绿同行、向美而生，紧扣“美丽中国”建设目标，以系统思维统筹山水林田湖草沙冰生命共同体，以专业力量守护绿水青山、赋能城乡发展，在“十四五”期间交出了一份厚重而亮丽的水利与生态环境答卷。

从黄河九曲的生态守护到南海之滨的岸线修复，从青藏高原的高寒筑坝到沙漠戈壁的输水润疆，西北院锚定国家水安全与生态文明建设大局，将技术攻坚与生态理念深植于每一项水利工程、每一处生态治理，用智慧破解水之困，用匠心守护水之美，在广袤大地上书写了保水安、兴水利、优水生态、惠水民生的生态答卷。

水利之基，在于安澜。五年来，西北院坚持以技术创新为引领，聚焦高寒、高海拔、沙漠、深厚覆盖层等复杂地质与气候条件下的工程建设难题，系统攻克一系列关键技术瓶颈，高质量建成一批具有行业示范意义的标志性水利工程，切实扛牢安全责任，有力支撑区域发展。

复杂条件下的工程实践： 在青海囊谦，建成国内海拔最高的堆石混凝土重力坝——晓龙沟水库，攻克高海拔冻融难题；在新疆阿克苏，打造国内最大四面围坝注入式平原水库，破解深厚砂砾石地基防渗难题；在陕西榆神，建成国内沙漠地区扬程最高、输水距离最长的供水工程，让沙漠变绿洲有了水保障；在云南丽江，完成公司首个千米超高扬程长距离提水工程，为滇中引水配套工程树立典范。

民生水利中的安全屏障： 从安徽池州平天湖三站（省内首个竖井贯流泵站）到杭州西湖区铜鉴湖防洪排涝工程，从西安市长安区库峪等三座水库到广信灌区水利改造，西北院的设计成果遍布城乡，既守护着江河安澜，又为农业灌溉、城市供水提供坚实保障，让“涝能排、旱能灌、供能稳”成为民生常态。

技术体系里的行业标准： 围绕千米级提水、数字孪生引调水、高寒地区生态修复等关键技术，形成成套解决方案，主参编国家、行业标准68项，其技术成果广泛应用于行业工程设计，有力支撑国家及行业标准制定，推动工程经验向规范化技术体系转化。

水美之魂，在于生态和谐。五年来，西北院秉持“山水林田湖草沙冰”系统治理理念，将生态修复贯穿于水利工程全过程，从内陆河湖到海岸带，从黑臭水体治理到矿山修复，让“清水绿岸、鱼翔浅底”的美景在多地重现。

流域治理的示范样本： 在雄安白洋淀、深圳宝安、江西南昌，一系列水环境治理项目圆满收官，让昔日黑臭水体变身生态廊道；杭州大运河文化工程成为亚运会配套标杆工程；陕西秦岭、安徽兆河山水治理工程获评自然资源部、央视样板工程；西安灞河治理后跻身国家水利风景区、“陕西省幸福河湖”名录，成为城市生态名片。

陆海统筹的生态实践： 践行“海洋强国”战略，在广西北海实施红树林生态修复与互花米草清理工程，中标防城港市海洋生态保护修复工程，构建起“诊断-设计-施工-监测-碳汇开发”的海岸带治理全链条，实现生态、安全与经济效益的统一。
