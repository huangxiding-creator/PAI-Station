# 前言

这本书写给工程企业里"签字前睡不着觉"的人：合规、法务、经营、纪检，以及被推到投标一线的项目负责人。

工程总承包招投标的合规问题，从来不是"知不知道法条"的问题。招标投标法及其实施条例、九部委的资格预审文件、住建部门的一连串规范性文件——这些都查得到。真正的问题是：在项目压力下，哪一个节点最容易踩线？踩线之后，处罚的判例尺度是什么？整改的窗口在哪里？出了纠纷，法院近十年到底怎么判？这些问题没有一本"法条汇编"能回答，需要把政策、判例、处罚通报、行业数据放到一张桌上对照着看。

我们把这张桌子搭起来了。本书的每一章都建立在数万件公开资料之上——政策原文、裁判文书、处罚通报、行业统计、国际规则文本——每个关键数字都标注了出处，读者可以按图索骥复核到原始文件。我们坚持一条纪律：书里没有一个凭记忆写下的数字；凡是推算，都摆出算式。

全书十二章，按买家的三个使用场景编排。**事前防**（第一至六章）：政策坐标系、全流程节点、评标红线、电子平台、围串标识别、资质准入——拿去对照自查。**事中守**（第七至九章）：合同条款风险、纠纷判例谱系、失败案例档案——出事前翻到对应章节。**事后学与向外看**（第十至十二章）：招标代理生态、FIDIC 与世行规则下的国际对标、未来数年的合规趋势预判——用于制度建设与战略选择。

预判一章请特别注意读法：每条趋势都给出了基线事实、推演逻辑与反证检验三件套。我们不贩卖确定性，我们贩卖的是"带着证据的判断"——包括判断可能错在哪里。

资料截至成书之日。法规会修订、判例会更新，我们会在后续版本中滚动修订。发现错漏，欢迎通过平台渠道指出——合规这件事，较真的人才做得好。

编者
二〇二六年十月
