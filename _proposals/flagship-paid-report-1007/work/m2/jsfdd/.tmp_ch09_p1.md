# 第9章 费用与成本：鉴定费谁承担

> 鉴定一旦启动，鉴定费、诉讼费、利息与审期就一起变成账面成本。谁申请、谁垫付、谁最终承担、什么情况下钱花了而结论不被采信——本章用公开裁判文本里的真实案件，把这笔账逐项拆给你看。

## 9.1 判项里的争夺：鉴定费从来不会“自动有人买单”

很多施工企业和开发商的法务有一个直觉：鉴定费反正最后由败诉方兜底，起诉时不必专门主张，判决时会“自动”处理。把本章检索到的公开裁判文本翻一遍，你会发现完全不是这么回事——鉴定费与诉讼费是当事人在每一个程序阶段都要白纸黑字写进请求的判项，而且不同案件、不同程序阶段的写法各有讲究。先看一组真实案件的费用请求表述：

| 案件 | 程序阶段 | 费用请求表述 |
|---|---|---|
| （2018）云民初168号（P9031） | 一审起诉 | 诉讼请求第五项：“判令被告承担本案诉讼费、鉴定费等全部诉讼费用” |
| （2019）最高法民终1356号（P9009） | 二审上诉 | 上诉请求第（6）项：“本案诉讼费用、鉴定费用由赤天化公司承担” |
| （2020）赣民终706号（P9011） | 二审上诉 | “判决被上诉人承担本案一、二审全部诉讼费用及鉴定费用” |
| （2019）豫04民终3383号（P9019） | 二审上诉 | “一审案件受理费、二审案件受理费以及反诉案件受理费、鉴定费全部由康龙公司负担” |
| （2021）豫01民再280号（P9017） | 再审申请 | 再审请求第二项：“本案一、二审的诉讼费、鉴定费由被申请人承担” |

这张表能读出四层信息。

**第一层：费用请求是逐级重申的“组合拳”。** 五个案件无一例外把诉讼费与鉴定费并列打包主张，从一审起诉（P9031）到二审（P9009、P9011、P9019）再到再审（P9017），每个程序阶段都要重新列明。为什么二审、再审阶段常常要专门补上“鉴定费”三个字？对比一件一审起诉状就能看懂：（2014）呼民初字第160号中，中材公司的第五项诉讼请求只写了“诉讼费用由二被告负担”（P9007）——起诉时鉴定还没发生，自然无从主张；鉴定是诉讼中段才启动的程序，费用也随之在后续审级的请求里逐一浮现。这给商务与法务的提示很直接：起草起诉状时要为“将来可能发生的鉴定费”预留请求空间，进入上诉、再审阶段时要记得把它显性补上；漏写或写得含糊，等于把判项的主动权交还给法庭。

**第二层：措辞颗粒度反映案件结构。** （2019）豫04民终3383号把“一审案件受理费、二审案件受理费以及反诉案件受理费、鉴定费”四项费用逐一列明（P9019），因为该案本诉与反诉交织——军安公司诉请改判康龙公司支付工程款4,597,737.38元及利息，康龙公司则以消防通风质量、地下室漏水、外墙面保修责任、迟延交工违约责任等事由对抗（P9019），费用判项必须与请求范围一一对应。值得注意的是，军安公司在上诉理由中同时援引“不诉不理”原则，指责一审判决超出当事人请求范围行使裁判权（P9019）——请求范围与费用范围互为镜像：你在费用上主张到哪里，法庭的处理边界通常就在哪里。

**第三层：大标的案件的费用敏感度更高。** （2018）云民初168号里，联营体起诉主张解除EPC总承包合同、支付欠付合同工程款38,672,952元、各项损失10,610,000元、暂计至2018年9月10日的逾期付款利息7,756,075元（P9031），即便诉请金额如此之大，第五项仍单独把“诉讼费、鉴定费等全部诉讼费用”列为独立判项请求（P9031）。（2020）赣民终706号中，一审法院认定本案工程款为62,117,409.54元，中云公司上诉请求改判电建公司支付工程款33,243,035.14元及利息、误工窝工等损失13,340,802.00元，费用请求明确覆盖“一、二审”两审全部诉讼费用及鉴定费用（P9011）——一审认定的工程款总额与上诉人主张的应付款之间相差28,874,374.40元（own_calc：62,117,409.54元−33,243,035.14元），在这样量级的分歧下，鉴定费与诉讼费本身就是不容忽略的显性成本。

**第四层：再审阶段的费用请求带有“附条件”属性。** （2021）豫01民再280号中，泵业公司的费用请求能继续争下去，前提是河南省高级人民法院于2021年5月16日作出（2021）豫民申715号裁定，指令郑州中院再审本案（P9017）；再审请求第一项是撤销（2019）豫0183民初4100号与（2020）豫01民终10417号两审判决，第二项才是“一、二审的诉讼费、鉴定费由被申请人承担”（P9017）。再审程序本身不是当然发生的程序，费用主张随程序存亡：再审申请被驳回，前两审已各自定格的负担结果就很难再翻动。这也解释了为什么精干的代理团队会把费用请求视为与本金、利息同权重的判项——程序每前进一步，它就多一次被重新分配的机会。

必须如实说明：本章所依据的节选文本只呈现了诉请与争点，上述各案的费用判项最终如何分担、鉴定费具体判给了谁，节选内并未载明。这不是素材缺陷，而是买方必须内化的现实——费用请求写没写、怎么写，是你在文本里能控制的部分；法庭最终怎么分，是攻防的结果。控制能控制的，主张必须主张的。

**所以呢？** 起诉状、上诉状、再审申请书中，鉴定费要与案件受理费分项单列、逐级重申；本诉反诉并存时按审级与诉的种类拆开写；不要默认“败诉方兜底”会自动落地。更重要的是，鉴定费主张的底气不来自措辞，而来自鉴定结论被采信的程度——这正是下一节要拆的启动端问题。
