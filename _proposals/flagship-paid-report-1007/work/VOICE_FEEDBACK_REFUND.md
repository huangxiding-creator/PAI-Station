# 语音反馈+大模型评分+按质退款+新版回馈提案（v3）

## 核心机制

```
读者购买报告 → 阅读后在详情页按住说话（60秒语音）
                        ↓
              语音转文字（微信小程序内置）
                        ↓
              大模型评分（≥6维度，满分100）
                        ↓
         ┌────────────────────────────┐
         │  退款 = 评分百分比           │
         │  (90分→退90%, 60分→退60%)   │
         └──────────┬─────────────────┘
                        ↓
         系统请求用户填写邮箱地址
                        ↓
         反馈进入报告改进管线（自动触发）
                        ↓
    ┌─────────────────────────────────────┐
    │  报告按反馈优化完成后                 │
    │  → 免费向用户邮箱发送新版报告 PDF     │
    │  → 附 personalised 改进说明          │
    │    「基于您的反馈，我们做了以下改进」  │
    └─────────────────────────────────────┘
```

**双重回报：退款（按质）+ 新版报告（免费）。**
反馈越好 → 退款越多 + 新版越好 → 用户成为长期客户 → 产线飞轮加速。

## 一、六维评分标准

### 维度1：真实性（Authenticity）— 15分

| 分数 | 标准 |
|------|------|
| 13-15 | 反馈基于实际阅读，引用了报告中具体页码/章节/数据 |
| 9-12 | 反馈与报告内容相关，但未引用具体位置 |
| 5-8 | 反馈泛泛而谈，可能未完整阅读 |
| 0-4 | 反馈与报告内容明显不符，疑为模板化投诉 |

### 维度2：针对性（Specificity）— 15分

| 分数 | 标准 |
|------|------|
| 13-15 | 指出了具体章节/段落/数据的问题，位置精确 |
| 9-12 | 指出了大方向的问题，但未定位到具体位置 |
| 5-8 | 只说「不好」「不满意」，没有说明哪里不好 |
| 0-4 | 完全没有指向报告的任何具体内容 |

### 维度3：专业性（Professionalism）— 15分

| 分数 | 标准 |
|------|------|
| 13-15 | 使用了行业术语/法律条文/技术标准，展现领域专业素养 |
| 9-12 | 表述清晰有逻辑，但未使用专业术语 |
| 5-8 | 表述口语化，逻辑一般 |
| 0-4 | 表述混乱，无专业内容 |

### 维度4：证据支持（Evidence Support）— 15分

| 分数 | 标准 |
|------|------|
| 13-15 | 引用了外部数据/法规/判例/行业实践来支持观点 |
| 9-12 | 引用了报告内部数据来支持观点 |
| 5-8 | 有观点但没有引用任何证据 |
| 0-4 | 纯主观感受，无任何证据 |

### 维度5：可操作性（Actionability）— 20分

| 分数 | 标准 |
|------|------|
| 17-20 | 提出了具体可执行的改进建议（如「第X章应补充XX内容」） |
| 12-16 | 指出了问题所在，隐含改进方向 |
| 6-11 | 只表达了不满，没有改进建议 |
| 0-5 | 无法从反馈中提取任何改进方向 |

### 维度6：对报告质量提升的价值（Improvement Value）— 20分

| 分数 | 标准 |
|------|------|
| 17-20 | 反馈如果被采纳，将显著提升报告质量（如发现数据错误/重大遗漏） |
| 12-16 | 反馈被采纳后会带来中等程度的改善 |
| 6-11 | 反馈对报告质量改善有限 |
| 0-5 | 反馈对报告质量没有改善价值 |

**总分 = 6 维度之和（满分 100）**

## 二、评分→退款转换

| 评分 | 退款比例 | 典型场景 |
|------|---------|---------|
| 90-100 | **退款 90%** | 专家级反馈：指出了具体数据错误+引用了判决书原文+提出改进建议 |
| 80-89 | **退款 80%** | 高质量反馈：准确定位问题+有证据+有建议 |
| 70-79 | **退款 70%** | 良好反馈：指出了真实问题但建议不够具体 |
| 60-69 | **退款 60%** | 合格反馈：有针对性但缺乏深度 |
| 40-59 | **退款 40%** | 一般反馈：只是表达不满但有些具体内容 |
| 20-39 | **退款 20%** | 低质量反馈：泛泛而谈 |
| 0-19 | **退款 0%** | 无效反馈：与报告内容无关/模板化投诉 |

**退款 = 购买价格 × 评分百分比**

### 2. 语音转文字

微信小程序内置 `wx.getRecorderManager()` + 腾讯云 ASR：
```javascript
// 录音 → base64 → 腾讯云语音识别 API → 文字
const recorderManager = wx.getRecorderManager()
recorderManager.start({ format: 'mp3', duration: 60000 })
// → 转文字 → 发送到后端评分
```

### 3. 大模型评分（引擎端）

```python
# qianwen-engine 新增 API
@app.post("/api/report/{sku}/voice-feedback")
async def voice_feedback(sku: str, request: Request):
    # 1. 接收语音转文字结果
    transcript = request.body.decode()

    # 2. 调用智谱 GLM-4 进行六维评分
    score_prompt = f"""
    你是研究报告质量评审专家。请对以下买家反馈进行六维评分。

    评分维度（各维度满分不同，总分100）：
    1. 真实性（15分）：反馈是否基于实际阅读，是否引用了具体页码/章节/数据
    2. 针对性（15分）：是否指出了具体章节/段落的问题，位置是否精确
    3. 专业性（15分）：是否使用了行业术语/法律条文/技术标准
    4. 证据支持（15分）：是否引用了外部数据/法规/判例来支持观点
    5. 可操作性（20分）：是否提出了具体可执行的改进建议
    6. 改进价值（20分）：反馈被采纳后对报告质量的提升程度

    报告标题：{report_title}
    买家反馈：{transcript}

    请输出 JSON：
    {{
      "authenticity": 0-15,
      "specificity": 0-15,
      "professionalism": 0-15,
      "evidence_support": 0-15,
      "actionability": 0-20,
      "improvement_value": 0-20,
      "total_score": 0-100,
      "refund_percentage": total_score,
      "scoring_rationale": "每维度一句话理由",
      "improvement_suggestion": "基于反馈的具体改进建议"
    }}
    """

    # 3. 解析评分结果
    scores = await call_llm(score_prompt)

    # 4. 存储反馈
    feedback_id = save_feedback(sku, transcript, scores)

    # 5. 触发企微通知（产线收到高质量反馈）
    notify_wecom(f"📝 新反馈: {sku} 评分={scores['total_score']} 退款={scores['refund_percentage']}%")

    # 6. 返回给买家
    return {"ok": True, "scores": scores, "feedback_id": feedback_id}
```

### 4. 退款执行

## 四、防滥用机制

| 规则 | 说明 |
|------|------|
| 单份报告限反馈 1 次 | 不允许反复反馈退款 |
| 语音时长≥10秒 | 防止极短无意义反馈 |
| 评分≤19 不退款 | 无效反馈不退 |
| 退款后保留反馈记录 | 反馈价值归产线所有 |
| 同一用户月退款≤3次 | 防止职业退款师 |
| AI 检测模板化反馈 | 重复率>80% 直接判0分 |

## 六、商业飞轮（升级版）

```
高质量反馈 → 高退款 + 新版免费 → 报告改进大 → 下一版更好卖
     ↓              ↓                        ↓
买家获得退款    买家获得新版              新买家愿意付更高价
+ 新版报告     (比原来更好)              (质量提升了)
     ↓              ↓                        ↓
买家成为        买家感受到               产线口碑提升
回头客         「被重视」                (「他们真的改了」)
(愿意买        (愿意推荐                 (愿意复购)
 下一份)        给同事)
     ↓              ↓                        ↓
     └──────────────┴────────────────────────┘
                        ↓
              产线飞轮越转越快
              (每次反馈=一次免费校准)
```

**本质：把退款从成本变成投资——每笔退款换回一条有价值的改进信号。**
