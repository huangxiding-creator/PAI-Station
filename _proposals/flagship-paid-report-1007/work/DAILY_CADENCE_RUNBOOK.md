## 七大摩擦点与工程解

1. **选型薄**（雷达常零候选）→ TOP-3预研池：雷达出多个候选时全部预跑S1轻量侦察，晨批时挑实证最厚的一个；信号源日刷（雷达自带）
2. **批准延迟** → 晨批批处理制（一次批当天全部动作：选题+笔记本生命周期+发布窗）
3. **NBLM波动** → 全速+信号驱动响应包（已沉淀：梯子/养号/单发/盘点件）；**100本帽=5天耗尽** → 需笔记本生命周期常令（见下问）
4. **公众号风控窗** → 稿件即时入箱（API全天通）；发布走引擎窗或会话活时直发；日帽内完成
5. **视频日帽4条** → 每报告固定3条H3（帽内）；huashu片=可选加餐
6. **脚本错拷污染** → report_factory_init.py 参数化生成全链件（消灭手拷类事故）
7. **重复生产** → 选型门硬绑 report.json 在架SKU账核验
