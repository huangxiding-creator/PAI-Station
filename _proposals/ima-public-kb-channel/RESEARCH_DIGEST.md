# RESEARCH_DIGEST — ima 公开知识库渠道 (三腿汇总)

调研日期: 2026-09-26 | 三腿: local_api(官方 OpenAPI 解剖+判据实测) +
github(35 项目四簇) + web_eco(生态/匿名可达面 22 条)

## 一句话
公开分享的 ima 知识库是一个**真实存在、规模可观、可免登录发现、可登录下载**
的语料生态 (官方口径 20+ 行业/4 亿+ 文件), 社区做了 35 个下载/同步工具但
无人把它做成采集渠道——信息差在我们手里。

## 三腿核心结论
1. **官方 OpenAPI 三腿全通** (判据级): search_knowledge_base 搜到第三方公开
   订阅库 (工程知识库超市矩阵) → get_knowledge_list 目录树 → get_media_info
   签名直链 (res-skb.ima.qq.com + 5 个 X-IMA-* 头)。
2. **GitHub 35 项目四簇** (下载6/MCP-CLI8/同步12/应用9): 三条独立通道
   (官方 OpenAPI/匿名 share_id cgi/web-token cgi) 均被社区打通, 增量断点/
   直连关代理/wechatarticle=HTML/COS 403 勿用等工艺全可吸收。
3. **web_eco**: 官方「知识库广场」在役; 分享页 SSR `ima.qq.com/wiki/?shareId=`
   匿名 200 直出库卡 (3/4 实测, 1 个 400=死链); 搜狗微信搜 URL 片段
   10/10 命中真实 shareId; 弹药级库点名 (IPO 问询 1 万内容/压力容器标准
   3000+ 文件/大坝安全)。

## 渠道设计定案 (进 PROPOSAL)
- **双腿**: 发现腿 (SSR 免登录 + 官方搜库扇出) / 下载腿 (官方 API 登录态)
- **四件套** 默认收紧; **死链检测+快照** (链接删除即 400); **同义词扇出**
  ('EPC'→0 而 '总承包'→1, 组合词降召回)

## 与既有资产的边界
- 既有 `ima` 渠道 = 本人订阅库检索 (enrich C 腿, CAP 20);
  新 `ima_public` = 公开生态发现+收割, 两者正交, 完备门并行过账。
