## ① 分享机制与链接形态（含 4 个真实样例实测）

### 机制（官方/社区交叉证实）

- 分享的基本单位是**共享知识库**（个人库不支持直接分享）。PC/网页版点「创建共享知识库」→上传文件（PDF 不超 1000 页）→右上角「分享」生成**链接 + 知识码（二维码）**两种形态。来源：360 AI 摘要 + 公众号文《腾讯 IMA 共享知识库太香了》。
- 发布到聚合面的路径：权限管理 →「发布到广场」（进入知识库广场）。共享库**不占个人空间，可无限创建**（腾讯云开发者社区文 2503414，2025-03-10）。
- 知识库三分类（2025-2026 演进）：个人知识库 / 共享知识库 / **订阅知识库（ima 知识号）**；知识号支持订阅变现（公众号《律锥·legalskill 解读》）。知识号 = 分享页上的「订阅知识库」按钮形态。
- 删除知识库 → 分享链接随之失效（app.js bundle 明确文案）。分享页 400 即失效/私密化表现。

### 链接形态

- **主形态：`https://ima.qq.com/wiki/?shareId=<64位hex>`**（sha256 风格 hash）。SSR 服务端渲染，未登录可读。
- 短链体系：web 端（knowledge-share.ima.qq.com）存在 `s/` 前缀 + `/cgi-bin/s/` 解析端点（app.js bundle: `ore="s/",$L="/cgi-bin/s/"`）。
- 知识码 = 二维码形态，扫码进小程序加入。

## ② 公开 KB 聚合/目录/合集的存在与入口

**存在，且是官方一级入口**：

1. **官方「知识库广场」**：web 入口 `https://knowledge-share.ima.qq.com/discover`（匿名 GET 返回 200 但仅 2KB SPA shell，列表由客户端签名 API 拉取）；客户端入口 = 共享知识库旁「发现」按钮。官方口径：覆盖科技/金融/教育/医疗/法律/政务等 **20+ 行业**，沉淀 **4亿+ 份知识库文件**（ima.qq.com/download 页；aigc.cn 2026-02 口径为 2 亿+，两说并记）。广场交互：可直接使用库内容 / 加入知识库后查看文档。
2. **第三方导航**：aigc.cn（AIGC 工具导航）有 ima 专页（www.aigc.cn/ima-knowledge-base）——仅产品解析，无 KB 清单。
3. **社区合集文章**：公众号文章是事实上的「目录层」——搜狗微信搜 `ima.qq.com/wiki shareId` 可直接命中文章内贴出的分享链接（本次 10/10 页命中，是最有效的链接发现姿势）。
4. 未发现独立第三方「ima 公开库导航站/爬虫目录」（github 腿由并行调研员覆盖）。

## ④ 未登录可达面结论

- **可达（匿名，无 JS）**：`ima.qq.com/wiki/?shareId=*` 分享页 SSR 层——库名、创建者、订阅人数、内容总计数、子目录计数、**条目列表（标题+来源类型+时间）**、推荐问题。≈ 元数据 + 目录层全量直出。
- **不可达（匿名）**：①文档正文/文件本体（「订阅知识库」动作需登录；正文 API 带签名+登录态）②广场 `/discover` 列表数据（SPA+签名 API）③`/cgi-bin/s/` 短链解析 API（裸调被拒）。
- **风险面**：分享链接可被创建者删除/私密化（400 实测）；无官方全量库目录 API 的公开证据。
- 工程含义：**「发现层」用分享页 SSR（免登录免签名）即可批量枚举元数据；「下载层」须登录态走官方 API/skill（协调方已实证）**。

## ⑤ 查询清单与死胡同（诚实记录）

### 走通的通路
- 360 搜索（www.so.com）：可用，真实 URL 藏 `data-mdurl` 属性，`/link` 跳转废。
- 搜狗微信（weixin.sogou.com）：列表页可用（普通 Chrome UA 即可，无需解验证码）；**直接搜 URL 片段（`ima.qq.com/wiki shareId`）= 真实链接发现器**；`/link` 跳转需 JS，curl 不可解（302 → 首页/antispider）。
- cn.bing.com：基础可用但结果池极窄，不同 query 收敛到同一池结果；`site:` 与精确短语操作符全部失效。
- 直接 curl 目标站：ima.qq.com 分享页 / knowledge-share 首页 / cloud.tencent.com / aigc.cn / bilibili（需 `--compressed`）/ static.ima.qq.com（需 `--http1.1`，HTTP2 握手失败 exit 35）。

### 死胡同（零命中/被墙）
- **WebSearch 工具**：底层 Z.ai 配额 429（周/月耗尽，15:20 重置）——本次全程不可用。
- **WebFetch 工具**：ima.qq.com 报「Unable to verify domain safe」（网络受限）——不可用。
- **webReader MCP**：同配额池 429——不可用。
- **百度**：www.baidu.com/s 直接「百度安全验证」墙——curl 不可用。
- **知乎**：zhuanlan 403 反爬——curl 不可用（两篇指南文仅标题级信息）。
- **CSDN**：521 反爬——不可用（两篇文仅标题级信息）。
- **wiki.ima.qq.com**（bundle 中出现）：302 回 ima.qq.com 主页——无独立公开帮助站。
- **Bing 搜 `"knowledge-share.ima.qq.com/s/"`**：被降级为 knowledge 词典页——公开 web 索引里未见 s/ 短链实体（分享链接走微信私域传播，公网索引稀少，Bing 只索引到 4 个 ima 官方页）。
- **PyPI**：`ima-copilot`、`ima-export` 均 404（npm 未及测，github/PyPI 深查由并行调研员覆盖）。
