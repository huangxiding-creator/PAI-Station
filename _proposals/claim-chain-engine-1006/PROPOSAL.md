# 研究报告生产方法论 v3「断言链」(Claim-Chain Engine)

> 状态：2026-10-06 用户令「设计比目录框架驱动更好的世界顶级全流程方法」+「同意①②提案、自主开发实施」。
> 一句话：**研究报告的生产单位从「章」改为「断言」，目录只是已验证断言集的投影。**
> 与用户方法的关系：目录框架驱动（Manus v3, 1006 收官）**保留并降位**——它是优秀的呈现合同生成器，
> 但它回答「写什么」，不回答「什么必须为真、真到什么程度」。本方法在其下垫两层合同、在其上加一层验证。

## 二、方法本体：三合同一飞轮

### 合同 1 研究合同（问题树 v2 = 研究的宪法）

- **点火源升级**：Manus v3 框架的每章 `question/sub_questions`（企业特定、问句式、可证伪）直接成为树节点——替代模板生成；模板库降为兜底。
- **视角发现步（STORM P1）**：生成大纲**之前**先从相关文献抽取 N 个独立视角（业主方/设计院/施工方/监管方/供应链…），每视角出问题再聚成树——STORM 实证对 outline-driven 基线组织性 +25%/覆盖广度 +10%（arxiv.org/abs/2402.14207）。
- **动态结构审查轮（Co-STORM/MindSearch P2）**：目录从冻结结构改为每轮采集后可增删的活结构——出现大纲外重要证据（unknown unknowns 入口）即新增/改章，连续两轮无结构变化才锁定（S3-2 四态状态机天然兼容：gap_scan 态即活结构期）；树的内部表示 = 子问题图（节点带依赖边），大纲仅是渲染层（arxiv.org/abs/2408.15232, 2407.20183）。
- **ACH 假设层强制点火**：每战役 3-7 竞争假设（扩张/恶化/分化 或 按报告主题定制），ach_arena 矩阵排除留痕；Heuer 规则全量落地——假设只能因**正面反证**转 disproved（「没证据支持」不构成删除理由）；排序**只数不一致项 I**（禁止加号计分）；终稿「前置结论式标题」必须引用被排除的假设并给出全部假设相对可能性——结论没有杀死过对立假设，不许下。假设经对抗筛选而非文档罗列（Google co-scientist 假设锦标赛同构，arxiv.org/abs/2502.18864）。
- **KAC 目录冻结前置门**：目录冻结前显式登记关键假设清单（「已被接受为真并构成评估基础」的隐含前提），每条 linchpin 假设强制配「出现什么新信息就必须放弃它」的指标——开工、定稿各跑一次（CIA Tradecraft Primer）。
- **开跑前 Premortem**：目录冻结与开跑之间插一轮「本报告发布后被证明是错的」生成（独立默写→轮读去重，Klein 协议），失败原因清单逐条映射{缓解措施|接受的风险}——与出稿前红队轮构成双门。
- **EEI 三腿制**：每问题正/反/权威口径三腿（G1 已内建），验收 = 三腿各 ≥1 证据 ∧ 独立源 ≥2 ∧ 等级达标（见合同 2）；EEI 按 PIR→KIQ→EEI 工单形态带来源映射（FM 34-2），**证据缺失本身记为证据**（「若该假设为真我们应看到什么？没看到是没发生、不可观测、被隐瞒、还是没去找？」——没有叫的狗）。

### 合同 2 证据合同（证据账本 = 诚实度量衡）

- **文档为原子**：杀 15× 通胀——当量、独立性、渠道集中度全部按文档级计（dedup 基键 = 剥 `#节点` 后缀）；pool_state 增文档级字段，旧字段只留不删（对账期双轨）。
- **权威度 A/B/C 真值化**：渠道规则表（年报/裁判文书/政府采购/官网=A；行业协会/主流行业媒体/券商研报/学术论文=B；自媒体/聚合/百科=C）+ 域名规则表（gov.cn/court/ccgp/cninfo→A …），零 LLM 启发式落值，Jev 抽检位兜底。
- **独立性三键**：域名 + 渠道 + 文档，三键任一同键 = 非独立；单渠道占比 >60% 触发渠道分散度告警。
- **诊断力预算（弹药有效性判定升级）**：弹药入池须对全部 alive 假设打 C/I/N/A 判定（ACH 矩阵列）；与所有假设一致的证据 diagnosticity=0、**不计有效弹药**；采集侧 KPI 从字数改为 `diagnostic_evidence_count`（使假设间产生区分的料数）——直接替换「按章字数收料」（Heuer ch.4/5：无对立假设则诊断力不可评估；增量信息只加自信不加准确）。
- **数据表为一等证据单元**：数字先成表（表号/口径/时点/来源文档锚），终稿数字 100% 表锚（own_calculations 前移到采集期，P1-3 升级形态）。
- **快照哈希**：valid 判定同事务落快照（METHODOLOGY §三.2 设计，接线位不变）。

### 合同 3 验证合同（断言账本 = 出货门）

- 写作层每个引用句落 `{断言, 断言类型(事实/预测/观点), eeis[], 证据ids[], 独立性类别(原创/转载/同源复读), 验证态(双独立源确证/单源/未确证), 确定性(高/中/低/极低), 降级旗标[], 反证urls[]}`（P1-6 task_ledger 升级为断言账本；字段映射 PRISMA+IFCN+GRADE，循证协议 1）。
- **ALCE 双指标回归门（P4）**：citation recall（多少论断有证据支撑）≥0.95 ∧ citation precision（证据真支撑该断言）≥0.9——引文质量从此可自动度量、版本间可回归（github.com/princeton-nlp/ALCE）。
- **GRADE 五降三升清单门（循证协议 2）**：每关键断言过 checklist——降级因子（来源偏倚/多源不一致/间接性/不精确/疑似洗稿）各 -1，升级因子（强效应/剂量-反应一致/残余偏差反向）各 +1，起点分由源等级定（A 级源=高起步，C 级源=低起步）→ 四级确定性强制写脚注。
- **CoVe 独立上下文验证环（P3）**：成稿后每章自动生成验证问题清单（关键数字/因果断言/时间点），用**独立上下文**重新检索作答，比对不一致处修订（arxiv.org/abs/2309.11495）；RARR 式最小编辑修订保风格（arxiv.org/abs/2210.08726）。
- **单源/零源断言自动进 gap 补采**（P1-7 三触发位扩展第四位）；补不齐的，终稿该句强制带「单一来源」标注或删除——诚实呈现优于充数。T0 断言（关键数字/引语/事件）须 双独立源确证∨一手官方文件 才进正文（RFE/RL+FRONTLINE 成文规则，循证协议 3）。
- **成稿红队轮**：premortem（这份报告为什么全错 ×3-5 条，每条须有树内证据回应）+ KAC（树根假设体检，against>0 的根假设进「关键假设与反证」节）——独立会话承担（Manus 独立 profile / contextTransfer 隔离），检查者与干活者上下文隔离。
- **校准账本**：每报告 ≥5 条关键判断落 `{判断, 概率, 验证口径, 截止}`，Brier score 到期对账，跨战役复利出校准曲线——「我方判断的可信度」成为可展示资产（GJP 实证：训练+协作+追踪的团队胜过情报分析师基线，doi:10.1177/0956797614524255）。
- **双维不确定性标注（ICD 203）**：每个关键断言输出 `{likelihood: 可能性词+数值区间(7档硬编码表), confidence: high|moderate|low, linchpin_assumptions[], indicators[]}`；置信度由证据侧自动推导（独立源佐证数/来源等级/碎片度三因子），**禁止作者手拍**；渲染层强制可能性词与置信度词分句；linchpin 假设无对应指标阻塞出稿；结论段必须同时呈现支持与相反证据。

### 一飞轮（系列复利——第 100 家揣着前 99 家的教训）

- **问题库**：每战役复盘「哪些 EEI 公开源不可答、为什么」→ 下一家先验（不可答问题不重复烧预算，直接改用 NB 深挖/访谈路线）。
- **信源效力账本**（G5 设计）：域名×问题维度的命中率/等级分布，渠道路由吃它。
- **判断校准**：Brier 曲线按判断类型分桶，系统偏差进提示词反例（「政策类判断一律降 10%」式）。
- **框架回灌**：Manus v3 提示词吃前一家复盘（贫血章位/waivers 位/被红队杀掉的结论类型）。

| Team A/Team B 教训 (1976 实验) | 竞争分析本身也需规则约束防政治化（后被判 "gross exaggeration and completely inaccurate"） | 红队轮边界纪律 |

## 三、为什么比「目录框架驱动」更好（可证伪判据）

| 判据 | 目录框架驱动 | 断言链 |
|------|------------|--------|
| 度量衡 | 字数当量（已证 15× 通胀） | 文档级当量 + 断言级溯源率 + 诊断力计数 |
| 「答没答」 | 章级三态（27.7% EEI 缺口不可见） | EEI 三腿门 + 断言账本，缺口逐句可见 |
| 结论可信度 | 标题判断句（无对抗过程） | ACH 排除留痕 + 等级/独立源机检 + 校准分 + ICD 203 双维标注 |
| 复利 | 提示词手改 | 问题库/信源效力/校准三账本自动回灌 |
| 失败模式 | 贫血章（事后补救） | 单源断言强制补采或标注（事前拦截） |
| **结构病根（Heuer 定锚）** | 先定目录=先打锚（锚10%组终估均值25%、锚65%组均值45%；意识到锚定≠解药）；无对立假设则**诊断力不可评估**，按章收的料大多与所有解释相容=零诊断力 | 视角/假设先行，目录=已验证断言投影；弹药按 C/I 翻转力计 |
| **信息边际（Heuer ch.5）** | 增量信息只加**信心**不加**准确**——按章堆字数堆的是过度自信 | 有效性=使至少一个假设的 C/I 判定翻转或新增一个 I |

验收方式（第 51 家试产时）：同一战役双轨对账——文档级当量 vs 行级当量、断言溯源率 vs 章级三态、ACH 排除记录 vs 无假设——差异全部留痕呈用户。
