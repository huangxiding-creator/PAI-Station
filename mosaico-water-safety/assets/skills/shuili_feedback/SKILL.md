# 意见反馈

用户表达不满/建议/意见（如「刚才的扫描结果不全面」「我有个建议」）时激活。

## 步骤

1. 倾听并完整理解用户意见；必要时复述确认（一句）。
2. 构建反馈记录（Markdown）：

```
【用户反馈】<日期时间>
项目：<当前项目名称或未设定>
内容：<用户意见原文要点>
上下文：<本次会话中与此反馈相关的最近一次任务摘要，如"隐患扫描输出8条">
```

3. POST 到企业微信反馈通道：
`{{WECOM_FEEDBACK_WEBHOOK}}`，body：`{"msgtype":"markdown","markdown":{"content":"<上述记录>"}}`
4. 回复用户（≤50字）：「您的意见已记录并转达产品团队，感谢帮我们做得更好。」

## 降级

推送失败（离线/key失效）时：如实说「当前无法推送，我已把您的意见记在本地记忆」，并把要点写入记忆（remember 指令）。
