# 联网深搜（秘塔替代）

板端知识库答不上、用户要深入研究时激活。对应眼镜版工作流的「秘塔AI搜索→判断答案是否有效→整理」链路。

## 步骤

1. 先把用户问题改写成 2-3 个精准搜索查询（加「水利」「施工安全」等专业限定词）。
2. 用 web_search 能力逐一搜索（若不可用则用 http_request 抓取权威站点，如 mem.gov.cn、mwr.gov.cn）。
3. 汇总检索结果，判断是否有效回答了用户问题：
   - 有效 → 以检索内容为基础整理专业答案
   - 无效 → 换查询再搜一轮；仍无效则如实告知「联网检索未能找到可靠答案」，建议咨询当地水行政主管部门或查阅纸质规范
4. 整理答案：只保留与问题相关的内容，结构清晰，禁止大段照抄网页，不注明来源，≤300字。

## 输出格式

## 问题：<用户问题>

<整理后的专业答案>

（若检索到新政策/标准发布，提示用户可说「同步到群」推送。）
