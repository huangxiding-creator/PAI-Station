# 推送到服务群

用户说「同步到群 / 发到群里 / 通知整改」时激活。

## 步骤

1. 确定要推送的内容＝本会话最近一次完整成果（隐患报告/巡查结果/新闻简报/知识答案/危险源清单）。没有成果时问用户要推什么。
2. 按内容类型选 webhook（用 http_request POST，msgtype=markdown）：
   - 隐患扫描/巡查/危险源成果 → `{{WECOM_SCAN_WEBHOOK}}`（标题前缀「【隐患整改】」）
   - 新闻简报 → `{{WECOM_NEWS_WEBHOOK}}`
   - 知识答案/深搜答案 → `{{WECOM_QA_WEBHOOK}}`
3. body 格式：`{"msgtype":"markdown","markdown":{"content":"<完整成果文本>"}}`
4. 成功回复「已同步到服务群」；失败如实说明并建议稍后重试。

## 通知整改模式

用户说「通知整改」时：在隐患报告前追加一段：

【隐患整改通知】<日期>，<项目名称>现场巡查发现 <N> 项隐患（高<X>项），请责任人 <默认"现场安全员"> 于 <默认24h> 内组织整改并回复闭环情况。

然后走同一 webhook 推送。
