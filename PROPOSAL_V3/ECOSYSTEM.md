# ECOSYSTEM — 自生长生态飞轮设计（V3）

> 依据：第 10 路调研 93 案例（RESEARCH_DOCKET/v3/10-oss-ecosystem-business/）+ 用户指令④⑤
> 使命：基于开源理念实现极大商业价值；产品能力自生长，生态本身也自生长、自循环、自进化
> 地位：FR16/FR17/L3b 的总设计图；M6.5（技能资产化）与 M6.9（市场接口）按此施工

## 0. 一句话

每个用户的日常工作自动沉淀成技能资产（FR16），资产可上架市场交易（FR17），
新用户下载技能获得开箱能力、作者获得积分→算力→更多自动化——
**用的人越多，技能越多，新人上手越快**，这是飞轮的全部。

## 1. 双层飞轮

### 飞轮 A：个体能力自生长（纯本地，无需网络）

```
感知（语音/打字/云文档） → 任务执行 → 案例沉淀（cases/）
      ↑                                  ↓
   更强的执行 ← skill 升格（SKILL.md 固化方法论） ← 重复模式识别
```

- 触发信号四类：失败重试后成功 / 同型任务重复 ≥3 次 / 执行前检索无果 / 技能停滞未用
- 升格两闸防膨胀：案例→候选（模式证据充分）→技能（eval 通过+晨报一键确认）
- **红线不变**：进化提案永不自批（hooks 强制）；效果跟踪 effects.jsonl 滚动验证，
  成功率跌破基线-0.15 自动出回滚建议任务卡（FR10b）
- 本层即"superpowers 285k★ 教训"的落地：方法论内容比纯工具传播快一个量级——
  所以技能包以 SKILL.md（方法论正文）为主体，脚本是附件

### 飞轮 B：群体生态自生长（市场，可选层）

```
作者上架技能 → 用户下载（花积分） → 作者得积分 → 积分换算力跑更多任务
     ↑                ↓                              ↓
  排行榜曝光 ← 下载计数公开 ← 新用户开箱即用（少走弯路）← 产能提升
```

- 个人不进市场也完整可用（飞轮 A 独立闭环）——本地永久免费是红线不是促销
- 市场是放大器：单机技能运行永久免费；云目录/跨设备同步/共享算力代跑收费
  （Home Assistant+Nabu Casa 同构切分，调研输入#5）

## 2. 技能资产层（格式=战略资产）

- **兼容 SKILL.md 事实标准**（anthropics/skills 176k★）：技能=文件夹
  （SKILL.md 方法论 + scripts/ + evals/ + meta.yaml）
- meta.yaml 本周字段（FR17 接口预留）：`author / version / license / price / requires`
  ——`requires` 为 capability 白名单（见 §4）
- 双向导入导出：能吃进别人生态的技能包，也能导出成 SKILL.md 兼容格式
  （做别人生态的避险层；Cal.com 闭源当天被分叉证明格式开放=信任本体）
- 技能库本体=git 仓库（ADR-10）：升格=commit+tag，回滚=checkout，
  用户自配 GitHub 远端备份（FR14），vault/凭据永不入同步

## 3. 市场机制（积分锚定真价值）

| 设计 | 裁决 | 案例依据 |
|---|---|---|
| 积分锚定物 | 锚定 token/算力消耗，可充值可变现 | OpenRouter credits、Civitai Buzz 成功组；Steemit/BAT 反面 |
| 赚取 | 技能被下载得积分；绑定真实使用（下载后实际运行才全额结算） | 防女巫：按行为发放的代币全灭 |
| 消耗 | 下载他人技能、云算力代跑、增值同步 | Civitai 下载-消耗闭环 |
| 防刷 | 早鸟奖励时间衰减+每日上限+新作者冷静期 | Civitai 衰减设计 |
| 透明 | 下载计数、排行榜、作者主页**第一天就有** | ClawHub/HF：供需信号透明是供给第一驱动 |
| 结算 | 预付制记账，平台抽成 ≤15% 常态公示 | Unity/Civitai 抽成惯例 |

## 4. 市场安全（生死线，ClawHub 恶意软件事件教训）

- **签名**：上架技能包强制签名，市场索引带签名校验
- **capability 白名单**：`meta.yaml.requires` 声明技能所需能力
  （fs.read/fs.write/net.exec/cloud.connector...），安装时明示用户，
  运行时按声明沙箱化——超出声明即熔断
- **双轨制**：认证作者（审核制，Raycast 式）与野生生态并存，
  认证标识+搜索加权，不搞全面审查拖死供给
- **举报下架流**：一键举报→自动隐藏→人工复核；恶意技能进公开黑名单
- 对应产品内红线：凭据目录黑名单、进化永不自批同样适用于市场技能

## 5. 收入三层（不押注单层）

| 层 | 内容 | 先例 |
|---|---|---|
| L1 市场抽成 | 交易额 ≤15% | Civitai/Unity |
| L2 订阅 | 云同步/认证作者/跨设备 | Nabu Casa、Zed |
| L3 算力/token 差价 | BYOK 返佣+官方网关按量 | OpenRouter/Cline |

- 本地核心永久免费（HA 同构）：单机感知/执行/技能运行不设墙
- 中国路线双参考：飞致云矩阵（互补技能簇互导流：采集→清洗→上架→结算成套）
  + DeepSeek/Dify（开源换信任+卖消耗；技能市场双语上架）

## 6. 治理宪法（第一天写死，永不横跳）

1. 核心仓库许可证一经选定不再变更（Redis/Elastic/Cal.com 四案：翻脸=信任永久折价）
2. 作者版权：技能包版权归作者，市场只获分发授权
3. 弃坑接管：技能 6 个月无维护+社区有接手者→可申请社区接管（OBS 传承式）
4. 逃生舱：平台倒闭/转向→格式开放+一键全量导出，市场索引数据随用户走
5. 生态健康指标（公开季度披露）：活跃技能数/下载中位数/作者收入分布/新作者留存

## 8. 自进化闭环的两条安全带（与红线调和）

- 全自动形成（扫描历史成果反推、任务中沉淀）+**上岗走晨报一键确认**
  （R15 进化提案永不自批保留——hooks 强制，不靠提示自觉）
- 每次技能升格后 effects.jsonl 持续跟踪，退化即回滚建议（FR10b）
  ——生态增速可以慢，信任不能塌
