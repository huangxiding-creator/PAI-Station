## 〇′、理念地层图（A 切片考古锚点：底层理念确实存在，而且很老）

```
L0 人的有限性（记忆衰减/注意力有限/生命有限）——一切个人 AI 的存在理由
L1 认知增强 vs 架空（Engelbart 1962「增强宪法」；Mann 1998：智能是人机回路的属性，不是机器的属性）
L2 心智外化与连续性（Bush 1945 Memex：全量采集+联想检索+外置记忆，81 年前说尽本愿景全部要素；
    Clark & Chalmers 1998 延展心智：工作站是用户心智的构成部分，隐私/删除权重定义）
L3 主权与伦理（Xanadu 1960：原文永不删改、来源永远可见——本项目「只增不删+留痕」红线的哲学祖先；
    Solid 2006+：数据舱归用户）
L4 产品综合（Memex→Engelbart→延展心智→Sovereign Dossier 的当代中文职场实现 = PAI-Station）
```

**试金石（Mann/Engelbart 判据）**：评价本项目每个功能的终极标准不是「功能多少」，而是「**人到底被增强还是被架空**」。本方案所有破界动作均过此石。

## 〇、一思维重问：现在的「一」是什么

**What**：一台 Windows 笔记本上的个人 AI 工作站软件。
**Why**：帮一个人把工作做得更好。
**How**：24/7 感知→记忆→确认→自主执行→自进化。

这个「一」的隐含语法：**站=中心，记忆=功能，价值=软件功能，用户=孤岛，AI=工具**。
五路调研的证据说：这五个词全部可以倒转——每倒转一个，就是一次破界。

## 一、隐含假设清单与逐条击破（调研证据链）

### 假设①「站=中心」 → 破界：「环境先于主机，无站胜有站」

- 证据：Weiser 1991「最深刻的技术是消失的技术」（C 切片，Scientific American 原文亲测）；感知器正在离开主机撒进环境——Omi 项链 13.5k★「Always Listening」、Home Assistant 90.6k★ 家庭 ambient OS、openpilot 63.7k★ 车载；Olares 5.3k★ 把 "Always-On Agents" 写进 OS 定位。
- **破界动作**：产品叙事从「工作站」升维为「**个人智能体运行时（Runtime）**」——笔记本是**首个宿主与首脑**，不是产品本体。M9 渠道栈（FR15 注册即接入）已经是「感受器群」的雏形：渠道=远端感受器，本地文件=体内感受器，可穿戴/家居=未来感受器。**不造硬件**（见死亡谷警示），只做「感知端点注册协议」的架构预留。

### 假设②「记忆=功能模块」 → 破界：「卷宗先于站，站只是访客」【单点破局尖点】

- 证据：EverOS 13k★ / memU 14.4k★ 2026 新星共识——记忆的竞争维度不是「记得准」而是「**归用户所有、跨 agent 便携、Markdown 人可读可改**」；Solid POD 理念（Inrupt 消费者路线失败恰因把数据舱做成了产品而非资产）；MIRIX 3.4k★ 全量录屏自动写记忆；第 02 路调研早已埋下 OKF 伏笔（记忆=markdown+YAML，git 可 diff，与 Anthropic /memories 殊途同归）。
- **破界动作**：把记忆层从「paistation 的内部 SQLite」升格为「**用户的人生卷宗（Sovereign Dossier）**」——OKF 目录形态、git 版本化、一条命令导出为人可读 Markdown 包带走。PAI-Station 对卷宗是「首席访客」：任何未来模型/agent 都可以来读卷宗，但卷宗是你的。**护城河从功能移到资产复利**——这是「模型越强我越强」的第一支柱。
- 现有基建完成度 ~80%：LayeredLoader/ObsidianMirror 双向镜像/SELF_PROFILE/local_index 36 万文件宇宙/渠道语料栈——只差「卷宗优先」这层窗户纸（当前是 SQLite 为主、镜像为辅；翻转为卷宗为主、索引为辅）。

### 假设③「价值=软件功能」 → 破界：「按成果计价，模型越强我越便宜」

- 证据：D 切片 + 第 01 路 D4 空白（全市场按积分/会员收费，无人按成果）；红杉「服务预算 6× 软件预算，下一个万亿公司是伪装成服务公司的软件公司」；token 成本年降 ~50× 而「一个人力小时」的价值不降；混沌「按省了多少人力成本定价，而非 token 加成」。
- **破界动作**：商业模式预留 per-outcome 计量层——08 成果库已是计量基础设施（每次交付自动落回执），加「成果→价值当量」账本即可。**不在本周做**（先把资产层立住），但架构不许堵死。

### 假设④「用户=孤岛」 → 破界：「站群网络，第二曲线」【分形创新】

- 证据：A2A 25.8k★ 黑盒任务卡交换、ANP 1.4k★「Agentic Web 时代的 HTTP」（did:wba 去中心身份+AP2 支付结算）、Agora 协议省 98% token——**agent 间被定价的不是劳动，是结构化意图**；第 10 路生态调研（Civitai Buzz 积分闭环样本）+ FR17 市场接口早已预留。
- **破界动作**：第二曲线试点=**总包圈社群站群**（天然试验田：同行、同业、同工具栈）——3~5 个站互联的最小闭环：技能包 swap（你 distilled 的 wwg-research-methods ↔ 我 distilled 的 EPC 检索），积分记账，ANP 身份预研。主航道（自己用）不减速，新曲线（群体用）从主航道分形长出。

### 假设⑤「AI=被使用的工具」 → 破界：「意图的物化，不是劳动的转移」

- 证据：D 切片四条证据链——倒在「劳动转移」侧全是墓碑（Rabbit LAM 转型遥控 OpenClaw、LaVague 停更、Copilot Workspace 被吸收）；活在「意图物化」侧全在收敛（智谱「把回答变成交付结果」、lotti 1.2k★「agents 提案—人批准」=全场与 PAI 最同构项目）。
- **破界动作**：把「任务卡」升格为一等公民资产——可积累（flywheel 样本库已有）、可审计（runs/ 断点已有）、可结算（P3 预留）。产品叙事从「替你干活」改为「**你的意图第一次有了可编译的表示与可结算的通道**」。感知→确认→执行三层恰在正确一侧，不动骨架，升维叙事。

## 二、反脆弱架构宪法（模型越强我越强）

**判定器**：下一代模型更强，会让我更值钱还是更没用？（每个器官过一遍）

| 器官 | 判定 | 依据 |
|---|---|---|
| 感知层（七路信号+渠道栈） | ✅ 更值钱 | 采集是 IO 不是智能；模型越强，喂进去的原料越值钱 |
| 记忆/卷宗层 | ✅✅ 最值钱 | 私有数据回路=模型永远没有的东西 |
| 画像层 | ✅ 更值钱 | 模型越强，同一份卷宗解读越深 |
| 意图层 L1 规则 | ⚠️ 会被吃 | 保持热插拔，不投资护城河 |
| 意图层 L2/执行层 | ✅ 网关已就位 | 模型=耗材，LlmGateway failover 自动传导升级 |
| ASR/OCR/VLM | ⚠️ 会被吃 | 档位制升级位（M8 形态），SenseVoice 只是当下最优解不是护城河 |
| 评测资产（金标准 100/219） | ✅✅ 永不贬值 | 模型升级→重跑金标准→再校准，评测资产随模型增值 |
| 技能库+效果跟踪 | ✅ 更值钱 | SKILL.md 事实上跨厂商标准（176k★），技能不绑定模型 |

**三条铁律**：
1. **智能全部外购**（模型是耗材，永不自研模型层能力当护城河）；
2. **资产全部自积**（卷宗/画像/评测/技能/渠道 know-how/意图卡流水——六类资产只进不出）；
3. **每次模型重大发布跑套壳三问**：换掉底层模型产品还在吗？有别人拿不到的私有数据回路吗？用户走要付多大转换成本？（纳入心跳自检项）

## 四、终局思维：模型无限强时，剩下什么

剩下的只有三样：**①你是谁的独家数据（卷宗）②信任（确认关/审批闸/审计留痕）③关系网络（站群）**。
终局定位=「**数字自我的托管人（Custodian）**」，不是「更强的助手」。托管人的护城河按年增厚，助手的护城河按版本稀释。
