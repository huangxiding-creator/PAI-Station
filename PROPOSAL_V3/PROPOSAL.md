## 0. 一页速览

**做什么**：一套 120-200MB 的 Windows 安装包，双击即把**任何人现有的笔记本**变成 24/7 运转的 AI 工作站——它持续感知（语音指令/环境声/屏幕/打字/文件变化），主动发现待办请你确认，确认后自主调研并执行，交付成果，从每次反馈中变强；硬盘即记忆（TB 级本地检索注入）；默认零模型成本。

**为什么现在**：零件刚凑齐（2026-09 时点）——CPU 中文实时 ASR（Fun-ASR GGUF 单二进制）、记忆文件标准化（Google OKF）、Agent 内核库化（Claude Agent SDK）、技能标准成熟（SKILL.md 176k★）、绿色分发链路打通（Inno+uv+Velopack，Ollama 实证零服务零 UAC）。六个月前这条缝合链不存在。

**凭什么是 100×**（33 项竞品矩阵实证，详见 GAP_REPORT）：
| 维度 | 全市场最强 | 我们 | 倍数 |
|---|---|---|---|
| 常驻感知 | 听会中音频/读当前网页 | 整机 24h 五通道 | ≈12× 时长 |
| 记忆容量 | WorkBuddy 旗舰 50GB 云 | 本地磁盘全量 TB 级 | 20-40× |
| 能力成长 | 33 项无一有进化机制 | 每任务固化技能，复利 | 0→∞ 质变 |
| 月成本 | ¥99/月 | ¥0（免费链+本地） | 付费→零 |

**生态位**：五线交点无人占位——感知（screenpipe 只卖水）× 中国 IM（飞书桥断供真空）× 中文职场技能（无人蒸馏）× 零成本模型（GLM 免费链）× 现有笔记本（无人做绿色便携）。巨头结构性看不见（云端脑=其商业模式），极客结构性不服务（要自架网关写 prompt）。

## 1. 问题

- 用户（任何知识工作者）每天大量调研/整理/撰写靠人工驱动；任务散落在会议、语音、聊天里无人捕获。
- 国产办公 AI（含假想敌腾讯 WorkBuddy ¥99/月）是**被动应答工具**：不感知环境、不主动发现任务、不自研方法、不持续进化；通用 Agent 不懂具体用户。
- 大模型上下文 ≤100 万 token，用户资料远超——现有产品无"硬盘即记忆"。

## 2. 产品定义

**是**：常驻笔记本的工作站服务，任务闭环为前门——感知 → 发现 → 确认 → 自主执行 → 交付 → 反馈 → 进化。
**不是**：聊天 App、云端 Agent、又一个桌面助手、需要新硬件的 OS。

**三大不可妥协**：
1. **极强普适性**（用户中途明令）：一套方式装到世界上任何人的笔记本——per-user 免管理员、自带运行时（Python 3.14 起 full installer 已官方废弃）、硬件三档自适应（8GB 起步）、首启 3 步向导。
2. **本地优先**：原始音频即采即弃（只留文本/事件）、数据不出机、opt-in 感知+一键暂停+证据可溯（Recall 争议教训+合规护城河）。
3. **多供应商生死架构**：GLM 免费链主 + 供应商热切换（OpenClaw 389k★ 被封杀实证）。

## 3. 架构（七器官缝合，详见 v3/RESEARCH_DIGEST.md）

① 感知（silero-vad→sherpa-onnx KWS→SenseVoice int8→CAM++，静默 CPU<5%）
② 任务发现（事件流→任务卡{责任人+动作+截止+证据指针}→时机/内容分离置信+打扰预算→notify/question/review 三模式→agent inbox）
③ 无限上下文（Everything+SQLite FTS5/sqlite-vec+bge-m3+L0/L1/L2 按需加载+OKF 记忆文件）
④ 用户建模（五层画像+双时间线+夜间整理+Obsidian 镜像人可编辑）
⑤ 执行（Claude Agent SDK 内核经 gateway 接 GLM 免费链；继承 V2 研究管线七步法/FDE/微信深读）
⑥ 进化（skill-forge 五段流水线：信号触发→案例两阶升格→SKILL.md+scripts+evals 三件套→eval-first 三闸→注册表版本管理；hooks 强制人审，**进化提案永不自批**）
⑦ 常驻+分发（全用户态四进程：daemon/托盘/感知worker/schtasks 看护器〔判活铁律 v3 复用〕；named pipe IPC；Inno+uv+pywebview+Velopack+winget）
