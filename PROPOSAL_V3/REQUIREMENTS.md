# REQUIREMENTS — PAI-Station V3（Phase 4 · 需求工程）

> 2026-09-13 ｜ 提案已批准，M1-M6 范围即需求边界 ｜ JTBD：交付"执行方法论的机器人"而非方法论

## 功能需求（FR）

| # | 需求 | 验收（可测） |
|---|---|---|
| FR1 | **语音感知**：麦克风+系统声双路采集→VAD 守门→流式 ASR→带说话人与时间戳的转写事件流 | 对麦克风说"帮我调研 X"→10 秒内转写落事件流；静默期 CPU<5% |
| FR2 | **唤醒词**：免训练自定义中文唤醒词（拼音词表），唤醒后进入指令监听 | 唤醒词触发率 ≥90%、误触 ≤0.5 次/时（三层防线：阈值+VAD 门控+确认） |
| FR3 | **环境声事件**：会议开始/结束、持续对话等场景事件（YAMNet/SenseVoice 自带标签） | 播放会议音频样本→事件流出现"会议中"状态切换 |
| FR4 | **任务发现**：事件流（语音/文件/截屏/cron）→ LLM 抽任务卡 `{任务,责任人,截止,证据指针,置信度}` | 模拟会议录音→晨报含正确待办且可点击回溯证据 |
| FR5 | **打扰预算**：时机/内容分离置信，每日即时通知上限 N（默认 5），超限并入晨报 | 连发 10 个候选任务→即时通知 ≤5 条，其余在晨报 |
| FR6 | **确认 UX**：notify/question/review 三模式；Windows 原生通知+托盘面板；默认晨报汇总 | 任务卡三模式各可达且一键 批准/否决/改期 |
| FR7 | **执行闭环**：批准→Agent 执行（调研/整理/撰写）→成果落 `08 成果/`→企微通知+回执 | 端到端：语音"调研 Z"→确认→交付报告文件+通知 |
| FR8 | **无限上下文**：Everything 文件名秒搜+SQLite(FTS5+sqlite-vec) 混合+ripgrep 兜底；L0/L1/L2 按需注入 | 问"我 X 月写的 Y"→注入层引用正确磁盘文件路径；单轮检索包 ≤32K token |
| FR9 | **用户建模**：五层画像（身份/风格/知识/流程/成果）+双时间线+夜间整理；Obsidian 镜像可编辑 | 画像条目带 confidence+evidence；用户改镜像文件→回写生效 |
| FR10 | **进化 skill-forge**：四类信号→案例库→两阶升格→SKILL.md+scripts+evals→三闸验证；分级人审 | 同类任务第 3 次→案例库出现候选技能；永不自批（hooks 强制） |
| FR10b | **进化效果跟踪+回滚**（用户 2026-09-13 指令）：批准≠终点——技能激活后持续记录每次使用效果（成功/失败/质量分 vs 基线），效果下降主动生成"回滚建议"任务卡反馈用户；一键回滚到任意历史版本（git 版本化） | 批准技能→模拟 3 次使用 2 败→出现回滚建议卡；点回滚→版本还原且效果统计重置基线 |
| FR11 | **常驻**：daemon+托盘+感知 worker+看护器四进程；Mutex 防双开；named pipe IPC | kill daemon→5 分钟内自愈；托盘崩溃不连坐 |
| FR12 | **普适安装**：Inno 单 exe（120-200MB）per-user 免管理员；uv 离线复原；硬件三档分级；首启 3 步向导 | 干净虚拟机双击→向导→M1-M4 跑通；卸载后仅剩用户数据目录（可选删） |
| FR13 | **多供应商 LLM**：GLM 免费链主+热切换；本地模型可选档 | 主供应商 429→自动切换下一家，任务不中断 |
| FR14 | **GitHub 备份同步**（用户 2026-09-13 指令）：用户可配置自己的 GitHub 仓库；本地进化产物（技能/案例/evals/画像镜像）自动 git 提交并同步到该仓库——云端永远有备份，换机可整体恢复。secrets/authkey/原始事件流永不入同步范围 | 配置仓库→技能升级→远端出现对应 commit；断网→本地提交积压、恢复后补推 |
| FR15 | **云端感知连接器框架**（用户 2026-09-13 指令）：感知不止本机——百度网盘/腾讯微云/飞书云文档/腾讯文档等云平台，用户给账号或扫码登录后**登录态永久保存**（DPAPI 加密落用户数据目录），后续持续感知用户在这些平台上的文件与工作，事件入统一事件流。"只要用户能提供，就没有感知不了的"——新源=注册即接入（connector 协议）；每连接器必配账号安全四件套（节流+冷却+日限额+熔断）+ opt-in 单独授权可撤 | 新增一个连接器（如飞书文档）→扫码授权→次日事件流出现 `cloud.doc.change` 事件且进记忆索引；撤销授权→该源立即静默 |
| FR16 | **成果反推 skill 库**（用户 2026-09-13 指令）：扫描用户历史成果（08 成果/+云端文档），LLM 反推"这份成果是怎么做出来的"→自动固化 SKILL.md+scripts 候选；与用户交互完成任务过程中自动沉淀案例→升格。**形成过程全自动零安排**；上岗激活走晨报一键确认（进化提案永不自批红线保留）+FR10b 效果跟踪回滚 | 首启扫 10 份历史成果→技能库出现 ≥3 个候选技能；任务完成→案例库自动新增条目 |
| FR17 | **skill 交易市场**（用户 2026-09-13 指令，本周仅接口预留）：用户技能可发布入市场；他人下载→作者得积分/token，下载他人技能→消耗积分/token——形成交易生态。计价/结算/防刷为 L3 阶段实现 | 本周验收=技能包格式带 author/version/license/price 元数据字段+可导出导入（市场闭环后置） |

## 非功能需求（NFR）

| # | 维度 | 指标 |
|---|---|---|
| NFR1 | 资源 | 静默期整机 CPU<5%、常驻内存<1GB（8GB 机可跑）；说话时 ≤25% |
| NFR2 | 隐私 | 原始音频即采即弃零落盘（只留转写+事件标签）；opt-in 分层授权（麦克风/屏幕/文件各自可撤）；一键全局暂停；凭据目录硬编码采集黑名单 |
| NFR3 | 可靠 | 崩溃自愈 RTO≤5 分钟（看护器）；更新=受控崩溃（换目录+看护拉新）；PAUSE 旗标人工熔断 |
| NFR4 | 安全 | 红线全程：项目外全盘只读、secrets 不入库、只增不删；进化提案永不自批 |
| NFR5 | 成本 | 默认 ¥0 模型成本（免费链+本地）；GEPA 类进化月度预算闸 |
| NFR6 | 质量 | 新模块单测覆盖 ≥80%；C12 金标验证；run-ledger 全程记录 |
