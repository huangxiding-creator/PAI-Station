# bdn 安全红线全表（agent 行为规范）

改写自 BDPAN-FACTORY 战役 PROPOSAL §六验收门/§七红线（2026-10-29 用户批准口径），与 E:\AI-Station\CLAUDE.md 全站纪律对齐。违者即事故。

## 红线十条

### 1. 不破解付费墙与限速

- 不实现/不尝试：破解非会员限速、会员专属功能、付费 apaas 分享转存、P2P 提速、FakeRapidUpload/秒传链接转存（官方已封）。
- 速度如实报：本凭据为 SVIP8 口径（上传热跑约 10.5MB/s、下载约 2.21MB/s 实测），**结论不外推免费账号**。

### 2. rm 双确认（对齐全站清理纪律）

- CLI 层：无 `--confirm` 只列清单退出 3，零执行；`--confirm` 先打印清单再删。
- agent 层：拿到清单后**逐条呈报用户**，获**当次明示同意**才加 `--confirm`。用户未发话=一个都不删。
- 删除=移入回收站（可还原）；bdn 无清空回收站命令，也不要找别的路子清。
- 历史教训：2026-10-12 一次自主清理永久丢失 E:\CPOPC、E:\AIResearch——删除永远只认用户当次明示指令。

### 3. 凭据禁读禁打印，永不进仓

- 凭据真身：`E:\AI-Station\data\secrets\bdn_credentials.json`（gitignored，字段 bduss/stoken/ua_native）。
- 禁止：读取该文件、cat/type 其内容、把字段值写进任何输出/文件/commit、取消掩码。
- doctor/whoami 的输出已内置掩码（`mask()`），原样转述即可。分享提取码同样只出掩码（`***`）。

### 4. 双平面节流是自动的——不要绕过

- 控制面（元数据 API）：并发≤2、请求起点间隔≥1.5s、ls num≤1000、翻页≤10 页、tree 独立预算 20 发。
- 数据面（分片传输）：并发≤8。
- 重试：仅传输异常/HTTP≥500，3 次退避 1.5s→3.0s；业务 errno 不重试。
- **agent 禁止并行开多个 bdn 进程绕过节流**——批量上传/下载/搜索一律串行。

### 5. 熔断处置链（退出码 2 = 停手报告）

触发集：errno ∈ {31119, 31329, 20012, 31034}（风控/黑名单/限流/配额）。命中即全局停，后续调用零触网直接抛 BdnCircuitOpen。

处置序列：
1. **停手**：不再发起任何网盘调用（包括只读）。
2. **报告用户**：触发 errno、中文语义、已完成/未完成清单、当前熔断状态。
3. **官方客户端交叉验证**：建议用户在百度网盘官方客户端登录查看账号状态（bdn 不代做）。
4. **冷却**：等用户指令，不自定冷却时长后偷跑。
5. **恢复先只读**：放行后第一发只跑 `doctor --json` / `whoami --json`，绿了才谈写操作。

### 6. 限流观测=被动遥测

正常作业中遭遇 20012/31034 → 记录+熔断（如上）。**禁止主动探底**：不打压测、不故意高频触发限流、不试探黑名单边界（生产备份账号不打极限测试）。

### 7. 只碰本人账号数据

个人/企业自有账号互操作性用途。不转存他人分享、不碰他人数据、不分发凭据与协议资产。

### 8. 写操作遇异常先 doctor

mkdir/rename/mv/cp/rm/upload/download 报错（退出 1/2）时，先跑 `doctor --json` 定界：
- `roundtrip_ms` 异常/`http` 非 200 → 链路问题，可稍后重试；
- `errno` 非 0 / 凭据字段异常 → 凭据问题，退出 2，报告用户；
- `circuit_open:true` → 熔断，走第 5 条。
定界后再决定重试或上报，不盲试。

### 9. 写面纪律：首写冒烟、对账收尾

- 任何新场景的第一次线上写，先无害冒烟（mkdir 幂等目录）确认链路，再放量。
- 上传后必对账：`ls` 目标目录，size 与本地一致才算成功；md5 校验跳过时（混淆体）以 size 对账兜底。
- 数字零造假：报告里的字数/字节数/速度/请求数一律取自 `--json` 实测，禁手填。

### 10. 官方 baidu-drive 技能零接触

- **一个字都不改** `E:\AI-Station\.claude\skills\baidu-drive\`（update.sh 会覆写；其遥测强制令与 bdn 北极星冲突）。
- 分区共存：沙箱/记忆/转存/会员 → 官方技能原样用；全盘 → bdn。路由表见 zoning.md。
- bdn 零遥测（全本地，无 session-input/agentname 回传）；若某任务确需官方 bdpan CLI，提醒用户其每次调用回传会话上下文。
