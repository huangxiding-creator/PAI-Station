# 安全与法务全表（用户侧表述）

## 法务四原则（PROPOSAL §七，入宪；对用户解释时用下述口径）

1. **法务隔离——只打公开分享面**：只做免登录公开分享索引 + 用户自有通道下载。
   不碰：限速破解、账号池、SVIP 代取、向下载收费（PanDownload 刑事案/常某收费案/盘多多民事案为界）。
   用户要「破解限速/代下付费件/买账号池」→ 一律拒绝并指引自有官方通道。
2. **双解耦**：源配方插件化 + 下载器抽象——单源死/单盘死不瘫引擎，热插拔换件即可（yt-dlp 纪律）。
3. **凭据零托管**：永不代收用户盘 Cookie/密码。黄盘交付=本地凭据插件（plugins/config.json enabled 默认空=全关）；
   凭据文件（如 `E:\AI-Station\data\secrets\bdn_credentials.json`）**禁读禁打印禁入仓**，只查存在性。
4. **无公开策展**：不建公开索引库、不转存再分发；**收割物只进内部调研语料，禁止直接进付费交付物**
   （付费层只收整编/原创）。每次 download 成功自动落 `analysis/download_audit.jsonl`
   （ts/url/盘/大小/sha1/purpose=research）——用途标签默认 research，这是商用防火墙审计位。

## 频控默认（在身，勿绕）

- 单源串行间隔≥2s 随机抖动；跨源并发≤4；代理仅失败单发重试（即用即弃）。
- 发现层总预算 150 发/进程（DiscoveryLedger 硬熔断，超发抛 BudgetExceeded）。
- 下载截断 cap 1.5GB；健康轮每轮≈9-12 发。
- **不要**并行多进程跑同一命令给源站加压；批量调研拆多轮串行。

## 红黄盘如实口径（对外表述红线）

- 黄盘只能说「可发现、可列清单、可探活」，**不得说「可下载」**。
- 绿?盘（115/光鸭/wss）不得冒充绿；要说明「链路就绪，分享者开启免登下载/有当活链即绿」。
- 红盘不承诺任何交付；奶牛已停服。
- 一切数字（活源数/成功率/门件 sha1/绿盘率）以 `analysis/` 台账实测为准，**禁手填禁估算**。

## 下载件处置纪律

- 落盘默认 `w1_downloads/`（或 `--out` 新目录）；该目录是证据链，**禁删禁覆盖**历史门件。
- 下载内容仅通道测试与调研语料用途；版权内容不入付费交付物、不二次分享。
