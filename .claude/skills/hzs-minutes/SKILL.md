# 黄藏寺会议纪要生成（哈佳主任零修改标准）

## 触发场景

用户给出黄藏寺项目的会议录音转写（.md/.docx）和/或 AI 摘要（Summary docx），要求生成专题会会议纪要初稿。目标：**哈主任一个字、一个标点都不用改**。

## 工作流（五步）

1. **读材料**：转写全文（识别说话人线索、ASR 错译）+ Summary + 本目录 `references/style-rules.md`。
2. **选条目**：按十二律之"选择律"筛选决定事项（什么不进纪要见规则 R12）；同主题合并；确定 8-15 条。
3. **写成文**：逐条按"主体+动作+节点"写；首条加战略定位句（材料中无依据时用 `[待确认：战略定位句]` 占位，禁止杜撰）；按 `references/style-rules.md` 的句式库与禁例清单写。
4. **生成 docx**：调用生成器（模板A原位改写，保留红头版式）：
   ```bash
   E:/AI-Station/.venv/Scripts/python.exe "e:/AI-Station/Com-Writer/build/gen_minutes_v2.py" <内容JSON路径> <输出docx路径>
   ```
   内容 JSON 格式见生成器头部注释。模板：`Com-Writer/02-2 黄藏寺EPC项目/总包部黑河黄藏寺水利枢纽工程专题会（模板A）.docx`。
   输出目录：`Com-Writer/02-1 总承包事业部/05 成果迭代优化/`，命名 `黑河黄藏寺水利枢纽工程专题会会议纪要（初稿）YYMMDD.docx`。
5. **交检**：跑检查单（见下），向用户报告"占位清单"（需人工确认的一把手增量项）。

## 哈主任十二律（速查；全文+证据见 references/style-rules.md）

1. **隐名**：正文零"哈佳强调/齐三红指出"；姓名只在主持人栏、参会栏、任务责任人（优先组织角色）。
2. **无金额**：零万元/元数字；费用只写"按公司相关程序上报"。
3. **合并**：核心条用"一、…一是…二是…三是…"总分收纳；全篇 **10-13 条**、1200-1800 字；超过 13 条=半熟事项没收干净（见 R16）。
4. **行动**：每条=责任主体+动作+节点（本周内/10月底前/每周五上午/明年汛前）；背景≤1句。导语三拍：听取了…汇报→认真梳理了今后一段时间工作重点和相关问题解决措施→对下一步工作进行了安排部署。形成纪要如下：
5. **主体精确**：工程管理部/现场项目部/施工单位/设代/安能一局/先河；部门牵头写"工程管理部组织起草"；部门级会议导语写部门不写人名。
6. **实体精确**：青海省电网（非国网）、委托书（非委托函）、座谈（非约谈）、安能一局、自钻式锚杆、细砂、锁脚锚杆、钢拱架、大开挖、天津电科院、黑河局。
7. **去口语去推测**："握在自己手里/窝在总包部"→删或转书面；"可能/或许"推测删。
8. **语气**：对抗软化（不得→尽量）；政治动员保留（政治任务/不折不扣）。
9. **战略定位**：首条必有一把手定位句（发电目标/领导关注重点/生产组织重心/关键时间），材料无依据则占位待确认。
10. **格式**：模板A；会议地点 211会议室（主任级专题会默认）；参会列全不写"等"；两字名空格对齐（贾 超、王 飞）；（线上）标注；末页发送栏独页标"（本页无正文）"。
11. **符号标点**：无符号缩写（1#→1号、<1mm→小于1mm）；总分用"："；标点精确。
12. **选择**：不进纪要：金额、内部监督细节（报量核查/成本对比）、另文办理事项（走联系单的）、监测布点细节、次要工作面、推测内容、**已闭环事项（欠薪已复工等）**、**半熟事项（试验才能定/参数未定/原因未查→并入相关条一句或删，见 R16）**。外部单位事实性短板可留（服务于行动理由时）。
16. **战略定位句完整范式**（R17）：候选句必须"时间节点成就+定位判断"两段齐全（如"今年的发电目标在9月底如期实现，左岸边坡处置是…"），成就事实在材料中须主动关联。
13. **台账取实**（R13）：参建单位与常任事实从台账取（安能一局/先河/水电十一局/天津电科院/青海省电网/设代；工程管理部每周五上午调度；锁脚锚杆等术语），取代泛称与占位。
14. **技术变更范式**（R14）：施工单位技术优化问题一律"试验→旁站验证→专题研究决策→按程序上报"定式，不写替代方案/费用/报领导决策。
15. **方位表述**（R15）：高程完成情况落到"构筑物+段别"（导流洞出口下游段已完成/上游段剩余），方位存疑标 `[待确认：方位]`。

## 一把手增量占位规约（零杜撰）

录音里没有、只有哈主任知道的内容，用显式占位并在交付时列清单；有默认映射的先按映射写、再列入待确认清单：
- `[待确认：战略定位句]`——同时生成候选句供替换（范式：**时间节点成就＋本工作成为各级领导关注重点/总包部生产组织重心**，如"今年的发电目标在9月底如期实现，左岸边坡处置是各级领导今后关注的重点，也是总包部生产组织的重心"）
- `[待确认：瓶颈工序判断]`（如"目前钻孔、注浆已成为制约边坡处置的关键工序"）
- 责任主体默认映射：现场管理类发函→工程管理部组织起草；支付类→商财资部；周调度→工程管理部（每周五上午）；其余→现场项目部
- 实体名优先查 R13 台账；台账无→`[待确认：实体名]`
