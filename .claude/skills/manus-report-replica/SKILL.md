# Manus 研报全链复刻（逆向实证版）

逆向来源：桌面端 asar 静态分析 + Live 事件流实测 + 870 会话语料统计
（全证据见 `逆向工程/manus-reverse/MANUS_FULLCHAIN_PLAYBOOK.md`）。
本 skill 把实证出的生成引擎机制转译为可执行工作流。

## 核心三条（引擎心法）

1. **报告是长出来的**：分解为 N 个独立章节单元并行研究+写作，每章独立完成
   搜→读→写→自检闭环，最后合并。绝不分段生成后硬拼。
2. **写作是绝对主体**：编辑操作占 76%，搜索只是弹药补给（4.5%）。
   小批搜→立即落稿→再搜→再写→终批长写。
3. **上下文即文件**：结构、章节、任务清单、发现全部落盘为独立文件，
   任何时刻中断都能从文件状态无损续跑。

## 执行模式选择

| 模式 | 何时用 | 引擎 |
|---|---|---|
| **A 自产复刻** | 默认。要在本地产线内产出、可控可审计 | Claude + Agent 并行章节子代理 |
| **B 军团代产** | 用户明示「派给 Manus / 用军团跑」 | Auto_Manus 基建下发+守护+收割 |

两模式共用同一套硬条款模板与质量契约（见 templates/）。

## Mode A：Claude 自产复刻工作流（七层）

### L1 指令接收与硬条款内化
把用户需求转译为**硬条款清单**（缺项主动补默认值）：
结构条款（报告结构文件+六配件）｜数量条款（≥N章/≥M字/段落≥150字/
每章≥6小节≥2表格）｜质量条款（来源可核验/交叉验证/标出处/禁待补充）｜
语言条款（专业严谨/表格优先/去AI味）｜流程条款（增量更新原文件/不建多版本/
自主决策授权）。逐条落 `报告结构.md`，后续所有动作对表核验。

### L2 计划树与并行编排
1. **先读规范**：本 skill references/ + 既有同类报告范本（有则读）。
2. **章节分解**：用专业域骨架生成 N 章（12章范式：概念制度边界→市场政策
   监管→全生命周期识别→分域展开×7→评价预警应急案例；详见
   references/cascade-orchestration.md）。每章 = {编号, 标题, focus 研究重点}。
3. **fan-out 判据**：≥5 个各自需独立研究的章节 → 并行子代理（Agent 工具，
   一波 3-6 个防过载）；<5 或参数型任务 → 顺序做。
4. 计划落 `todo.md`（文件制任务清单，跨会话耐久）。

### L3 子代理契约（每章独立闭环）
每章一个 Agent，prompt 用 templates/chapter-agent-prompt.md 骨架：
```
你是〈域〉研究专家。独立完成第N章《标题》。研究重点：〈focus〉
硬性要求：≥4500字/≥6小节/≥2表格/段落≥150字；≥8个可核验来源，
优先政府官方/部委/国标/统计公报/行业权威；关键事实交叉验证；
引用[n]+章末参考资料（不得编造URL）；只围绕本章，跨章内容仅接口说明；
写入 chapters/NN.md，首行「# 第N章 标题」；完成后返回
{chapter,title,path,summary,char_count,sources[],status} 结构化结果。
```
主会话**不等待期间闲着**：轮询收集、写六配件、盘已有素材。

### L4 搜索词工程（给子代理与主线的检索军规）
- 四维拼装：`地域 × 行业细分 × 主题 × 时间窗`；行业矩阵逐枚举扫描。
- 漏斗改写：泛查询 → 点名权威源（统计年鉴/住建/发改委/公共资源交易/
  白皮书）→ 直捣官方站。
- 词长中位 33 字、带年份、点名机构；先宽后精确。
- 打开原文读，不信摘要；发现即存档（notes/ 落盘防丢）。
- 全渠道纪律：zh-search-pro / WebSearch / std-samr-gb / mwr-law-radar /
  微信洞察等按课题启用（全渠道铁律）。

### L5 增量写作引擎
- 目录布局：`reports/<课题>/` 下 `报告结构.md` + `chapters/NN.md` +
  `notes/` + `终稿.md`。
- 章节分开写最后合并；同文件增量编辑不开新版本；多版本以字数多者为准。
- 搜×5→写×1 节奏；边写边回读；中间笔记永不直接交付，终稿重写为
  信息密集文档。

### L6 质量自检（六项✅ + 量化门）
逐项对表 L1 硬条款：
①结构完整（N章+六配件全）②字数达标（**实测统计**，禁自报）
③格式规范（标题层级/表格/引用格式）④内容去重（跨章查重）
⑤无待补充（禁 TODO/占位/虚构）⑥终稿生成（合并无损）。
字数用脚本实测（`python -c` 数 CJK 字符），数字零造假。

### L7 交付与续航
- 成品 = 核心章节 + 六配件（严正声明/内容摘要/研究方法/报告价值/
  推荐序/术语表）。
- 交付动作按产线常令链（PDF→企微推送→微盘归档，见 MEMORY 常令）。
- **断点续航**：状态落 `reports/<课题>/state.json`（已完成章/字数/缺口），
  新会话读文件即续跑；「继续」两字语义。

## Mode B：Manus 军团代产驱动

基建：`E:\AI-Station\Auto_Manus`（manus_lib/manus_api，端口 9333 专用）。
安全铁律内建（节流30s/连败冷却/封号熔断/单账号单发/日限额）。

标准链：
1. 选号：`Manus账号（全部）260922_干净版.txt` 取活号；token 落
   `data/tokens/`（永不进仓/永不打印）。
2. 下发：`lib.send_task(page, prompt)` — prompt 用 templates/task-prompt.md
   （硬条款模板，Manus 会内化为计划步骤并自动 Cascade 并行）。
3. 守护：轮询 `api.get_session_v2` 落盘快照；事件类型判据：
   积分不足(chat 含"积分")→ 换号或等刷新后「继续」按钮续跑
   （Cascade journal 重放，完成章不重烧）；cascadeJobDelivered 计数跟踪。
4. 收割：`api.get_files` → `lib.download_files` 拉成品。
5. 续跑：`live_resume.py` 模式（继续按钮优先，composer 兜底）。

信用经济：轻任务 ~55 积分；并行 12 章 ≈ 300 积分/13分钟。
积分刷新：各账号 08:00 北京（部分 00:00 UTC）。
