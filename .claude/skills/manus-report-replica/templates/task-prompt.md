# 硬条款下发 Prompt 模板（Manus 生产实证版）

> 用途: Mode B 军团代产下发（或任何需要"硬条款内化"的任务下发场景）。
> 实证: 该结构 prompt 驱动 Manus 内化为计划步骤并自动 Cascade 并行。
> 占位符 {{…}} 按课题填充; 量化条款按需缩放（12章×300积分≈全日额度, 量力）。

```markdown
请深入调研并撰写一份高水平研究报告：《{{报告全名}}》。

成果硬性要求：
1）报告结构单独存为"报告结构.md"文件，必须包含：严正声明、内容摘要、
   研究方法说明、报告价值说明、推荐序、不少于{{N}}章核心内容、术语表。
   章为一级标题，总章序号连续规范。
2）核心内容不少于{{N}}章，每章单独存储为一个Markdown文件，章节内容不可重复。
   总字数达到{{M}}万个汉字以上。
3）所有基础数据与事实必须真实、可靠、来源明确，关键信息通过多渠道交叉验证
   并标明出处；将详细的推理和思考过程写入相应内容，尽量采用表格呈现。
   穷尽方法无法获取的数据即删除并调整结构，不得留空、不得出现"待补充"字样。
4）语言风格专业、严谨、洞察、客观，符合{{行业}}术语规范；每个段落不少于
   150字。
5）各章节完成后按照"报告结构.md"整合为一份完整Markdown成果，并转制为
   docx格式交付。
6）最终交付前进行全面质量检查：对照上述要求逐项核验（结构完整/字数达标/
   格式规范/内容去重/无待补充），发现问题自动修正。
7）全流程自动化决策：故障自行修正；需确认事项自主采用最优方案，无需人工
   确认。遇到权限限制无法直接获取信息时，通过公开渠道间接查找。
```

## 提高轮（成果已存在但不达标时追加）

```markdown
经检查，你并没有严格按照我的要求交付高质量的成果，请基于当前成果继续提升，
严格交付最高质量的出版物级排版docx格式研究报告。请按如下要求逐条检查既有
成果并优化提升：
（1）报告结构：报告结构单独存为"报告结构.md"。必须包含：严正声明、
    ≥3000字内容摘要、研究方法、报告价值、≥5000字推荐序、≥N章核心内容、
    术语表。章为一级标题，禁止"部分"层级，总章序号连续规范。
（2）结构深度：各章深入到4级标题，章节末尾有小结。章节标题使用专业词汇
    并准确表达洞察性结论。
（3）语言风格：统一文风，彻底摒弃"AI味"，符合行业术语规范。
（4）核心内容：每个段落不少于200字，禁止关键词+一句话碎片段落。
（5）真实可靠性：所有数据事实来源明确，关键信息三重交叉验证并标明出处；
    观点结论经数据源/逻辑链/现实案例三重验证。
（6）完整性：需补充自行补充；无法补充直接删除，不留待补充说明。
（7）版本纪律：章节内容有更新时直接在原版本上修改，不另立新文件；
    重复章节取字数最多版本。
（8）最终成果：按"报告结构.md"无损合并，转制docx；总字数M万汉字以上。
（9）最终质检：全面对照最初要求，发现重复/遗漏/排版/字数不达标，自动修正，
    直接更新原文件。
（10）全流程自动化决策：故障自行修正；需确认事项自主最优，无需人工确认。
```

## 续跑词（积分刷新/中断后）

- 最简: `继续`
- 带契约: `继续。积分已补充，请按既定计划继续完成各章研究撰写、结构文件
  生成与最终合并交付；自主决策，无需人工确认。`
- 断流后上下文继承: Manus 自动 contextTransfer（旧会话上下文+文件全量继承）
