## 漏斗式改写（泛 → 点名权威源 → 直捣官方站）

```
江苏省EPC总承包市场规模 历史数据 来源
  → 江苏省EPC总承包市场规模 官方数据
    → 江苏省统计年鉴
```

失败改写三招（实测模式）：
1. **换来源类型**：统计年鉴不行 → 发改委公报 → 公共资源交易平台公告
2. **换粒度**：省级无 → 地市级 → 行业协会白皮书
3. **间接路径**：直接数据无 → 学术论文引用 → 上市公司年报披露

## 检索纪律（deep-research 八条军规 · 原文全录）

1. 深度研究请求 → **升级搜索与分析强度**
2. **假设零先验知识**，从定义和背景搜起
3. 先宽查询后精确查询
4. **MUST 打开并阅读多个来源 URL**（摘要常不完整，禁只看摘要）
5. 用新发现的事实生成后续搜索，滚动修正方向
6. **MUST 边发现边存文件**（防信息丢失）
7. **NEVER 把中间笔记当最终成果**；MUST 重写为信息密集可读文档
8. ≥5 个同类独立子项 → 并行处理（agent 工具）
