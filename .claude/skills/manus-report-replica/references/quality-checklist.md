## 字数实测脚本（数字零造假）

```python
# 统计目录下全部 md 的 CJK 字符数 (含每章与合计)
python -c "
import re,glob,sys
tot=0
for f in sorted(glob.glob('reports/<课题>/chapters/*.md'))+['reports/<课题>/终稿.md']:
    t=open(f,encoding='utf-8').read()
    n=len(re.findall(r'[一-鿿]',t))
    tot+=n; print(f'{n:>8,}  {f}')
print(f'{tot:>8,}  TOTAL(CJK)')"
```

## 最终质检行为（实证模式）

（不建新版本文件）→ 重新实测字数 → 全过才交付。
