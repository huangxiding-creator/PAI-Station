# 决策规则速查 — 万维钢调研方法论（14 源资料集蒸馏）

| 能力 | 一句话规则 |
|---|---|
| 调研式学习五步法 | 要在短时间掌握一个小领域并形成自己观点时走五步——读书→采访专家→到达前沿→形成观点→完成叙事，目的是找独特定位而非编百科全书。 |
| 输入端：五本书梯度×思维密集度 | 先用密集度=准备时间÷阅读时间给输入排序（书＞杂志＞网文），再按五本书梯度选书；入门档五本，写作档加 all-in 翻近三年新书。 |
| 强力研读法 | 值得的书读两遍且只读两遍——一遍陷进去通读，马上二遍跳出来逐章写笔记；四标准（脉络/亮点/心得/联系）自检，验收线=笔记能取代原书。 |
| 外部信息管线与想法立项 | 有价值即入库（搜索优先、少分类），可能成文的想法先立项占位、遇素材挂链接、攒够才动笔——识别归人/代理，提取归系统。 |
| 观点形成与检验 | 观点输出前过三检——反转检验（找最强反方，被动摇就反转再回访正方）、费曼检验（写给非专业读者）、专家审稿（外置红队）；无反转的调研是浅调研。 |
| 信源与论证方向评估 | 引用前先问三件事——结论先于证据吗？利弊量化了吗？说得出会改变观点的证据吗？答不出的信源降权并补对立面。 |
| 证据与研究权重评估 | 引用研究前判级五步——领域折扣、阶梯定位、效应量必查（P 低≠效应大）、单篇只是一块积木、对参数过分敏感即过拟合。 |
| 写作输出手艺与系统运行纪律 | 成文先定唯一说话对象（focus），结构性反复修改（polish，代理 3 轮为合成约定），wit 靠天赋不可规程化；长期靠定期写+研发平台测试，日常级完成>完美，出书级走唯一代言人标准。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
