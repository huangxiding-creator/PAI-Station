
# 调研式学习五步法（V1 · promoted）

## R — 原文 (Reading)

> 这是史蒂芬·科特勒总结出来的方法，我深有同感。以我之见，这个方法的核心是「主动调研」。……这里所说的调研，目的不是为了"全面了解"一个领域，不是为了给这个领域编写百科全书。我们的目的是发现其中最前卫、最活跃、最有意思的地方，以便给自己找一个独特的定位。

## I — 方法论骨架 (Interpretation)

这套方法把「学习一个领域」当作一次有截止、有交付物的调研项目来经营，而不是漫无目的的知识积累。
它分五步串联：先用读书搭底子，再拿问题去找专家，然后定位到这个领域还没有公认答案的地方，
在那里形成自己的判断，最后把判断讲成一个别人能听懂的故事。
跟普通自学的分界线在第③④步：普通学习到「读懂了」就停，这套方法要求你走到「别人还没有答案的地方」并拿自己的观点去撞。
两条前置声明决定所有分支的取舍——
一是目的：找「最前卫、最活跃、最有意思」的位置给自己定位，明确排除百科全书式的全面覆盖；读什么、问什么、停在哪，都用这把尺子量。
二是门槛：方法放大的是你已有的知识储备；研究生用它快速找到位置，零基础一年成不了理论物理学家。
每步都有明确产出：第①步产出技术基线（大图景＋术语＋问题清单），第②步解决检索解决不了的问题，
第③步产出正反方阵营地图，第④步产出一个经过反转检验的观点，第⑤步产出通过费曼检验与专家审稿的叙事。
最容易被跳过、也最不能跳过的是第③④步——跳过它们，输出就只是资料搬运，不是调研。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个能力？

1. 代理自动调研: 用户给出新课题要产出带观点的报告——市场进入可行性、技术路线对比、行业现状与前沿扫描（「帮我调研 X 并告诉我该不该进」）
2. 流程编排: 代理接到多轮调研任务时的主干流程——五步给统一口径，防在资料汇总层提前收工
3. 人类自查: 本人要进入新领域找位置（转型 / 新业务 / 开一家「垂直农场」式事业），用五步盘点自己走到哪一步、缺哪步
4. 调研质检: 发现已产出的「调研报告」只有汇总没有观点时，回五步定位缺口（通常是③④被跳过）

### 语言信号

- 「帮我调研 X」「了解一个新领域」「进入 XX 领域该怎么着手」「XX 市场可行吗」
- 「梳理一下 XX 的现状和前沿」「做个尽调」「给我一个判断 / 结论」
- "research X" / "get up to speed on X" / "do a deep dive on X" / "what's the state of the art in X" / "should we enter this market"

### 与相邻能力的区分

- 与 `viewpoint-testing`(V5): 本能力管调研全程五步；V5 是第④⑤步的单点深化质检（反转 / 费曼 / 审稿）。流程收口时本卡自动调用 V5 的检验规程；用户拿着现成观点只要求压力测试时，直接进 V5，不必从第①步走起
- 与 `input-selection-density`(V2): V2 是第①步的深化细则（五本书梯度怎么选、思维密集度怎么算输入排序）；本卡只用其结论组书单
- 与 `deep-reading`(V3): V3 是单本硬书的深读规程；调研第①步啃第④本「硬书」时借其笔记四标准

### 负例（什么情况不要触发）

- 从零基础攻克高门槛学科（原文前提：一年成不了理论物理学家——先补基础再用）
- 纯事实查询 / 单点检索（查数据、查定义、查价格，直接查，不开流程）
- 只需浅层概览、明确不需要观点的科普式了解（目的声明已排除百科全书式覆盖）
- 审查别人文章的信源与论证立场 → `source-audit`(V6)
- 只深读一本书 → `deep-reading`(V3)

## E — 可执行步骤 (Execution)

### 输入契约

- 必需: `topic`（string，调研主题——领域或课题名）；`depth_goal`（enum: 入门定位档 / 写作出书档。缺失时**询问，不猜值**——它决定读书档位与收口标准）
- 可选: `prior_knowledge`（string，已有储备自述——决定五本书从第几本进入）；`time_budget`；`output_form`（报告 / 文章 / 口头简报）
- 缺 `topic` 或 `depth_goal` 时先补问再动，不得自行假定

### 第 0 步 · 定目的与档位

1. 把调研要回答的核心问题写成一句话——必须是**无公认答案**的问题
2. 按 `depth_goal` 定档: 入门定位档＝五本书梯度；写作出书档＝近三年新书 all-in 过一遍（「绝对不能说有个特别酷的话题我不知道」）
- 完成标准: 核心问题一句话成文，且能指出「此问题目前没有定论」的依据

### 第 1 步 · 读书（深入见 V2 卡 input-selection-density）

- 操作要点: 五本书梯度组单（非书主题映射许可：行业报告/长综述充当第④档、论文集充当第⑤档）；主观地读、带着问题读；抓三个点——领域历史叙事（抓「主要矛盾」）/ 行话术语 / 让自己兴奋的东西；已有储备者直取第④⑤本；读书不为总结书，「没人会考你」
- **转译约定**: 「让自己兴奋的东西」是人类生理信号，代理换为可操作指标——登记「跨来源出现冲突或互补的命题」清单（每条注明出处对），兴奋点≈新知识增量的方向
- 完成标准: 产出技术基线三件套——①大图景叙事一段（含主要矛盾）②术语表（能跟内行对话）③待深挖问题清单 ≥3 条（供第②步用）

### 第 2 步 · 采访专家

- 操作要点: 先做家庭作业，只问「检索过而未果」的问题，把专业水平用到刀刃上；框架性大问题自己拿主意——「你的问题，你得负责」；专家最精通的是自己课题，别问左后卫「世界足球发展」
- 完成标准: 提问清单每条附「已检索路径与未果记录」；专家回答能挂回技术基线（更新术语表或问题清单）
- 判停点: 若全部问题都能被检索解决 → 如实记录「本步跳过」直接进第③步，不硬凑访谈

### 第 3 步 · 到达前沿

- 操作要点: 找无公认答案、教科书空白处；常在领域交叉点；输入切换到最新期刊 / 论文 / 专家博客与争论；「最有争议的地方，恰恰也是最活跃的地方」
- 完成标准: 列出 ≥2 个正反方阵营，各自最强论证有名字有出处（阵营地图）
- 判停点: 找不到任何争议（全部有定论）→ 选题不在前沿——回第①步换交叉点，或如实报告「该课题无独特定位空间」

### 第 4 步 · 形成观点（深入见 V5 卡 viewpoint-testing）

- 操作要点: 反复考虑各方意见、自己拿主意；观点允许几次反转；不人云亦云，彻底搞懂才判断
- 完成标准: 通过 V5 反转检验（至少一个 A→B→A 完整往返留痕）
- 判停点: 观点反复横跳无法稳定 → 回第③步补证据；仍不稳 → 输出「存疑＋证据缺口」

### 第 5 步 · 完成叙事（深入见 V5 卡）

- 操作要点: 把观点讲成故事、理顺因果关系、建立思维模型；费曼检验（讲给非专业读者）＋专家审稿
- **转译约定**: 原文「社交互动产生神经化学物质助记」属人类生理机制，代理无此通道，不作为完成依据，只保留三动作（叙事 / 费曼 / 审稿）为验收
- 完成标准: 费曼版说明自检通过＋至少一轮外部否定性审查（审稿 / 红队）留痕且无推翻性未决意见
- 判停点: 审稿推翻核心观点 → 回第④步并记录一次反转（这是正常机制，不是失败）

### 输出契约

- 交付: ①调研报告骨架 ②观点声明（一段可直接被引用的判断句）③五步完成清单（各步完成标准达成情况）④未决问题清单
- 全局判停: 预算耗尽时按当前步骤收口，如实标注「第 X 步未完成」，不伪造完成

## B — 边界 (Boundary) ★

### 反场景（何时不用）

- 从零基础的高门槛学科（原文自认其有效性依赖既有储备）
- 纯事实查询、单点检索——直接查，不开流程
- 只需概览、明确不需要观点的场合（目的声明排除百科全书式覆盖）
- 审查外部文章 / 信源 → V6；深读单本书 → V3

### 原书警告的失败模式

- **无反转＝浅调研**（ce13）: 「如果没有这样的反转，你的思维可能不够积极。但是你不能人云亦云，总要彻底搞懂了，才能做出高水平判断。」——观点从未动摇说明各方意见没被真正对撞过，输出只是搬运
- 跳步形态: 「读书→直接写综述」是普通学习路径；③④两步被跳过时调研退化为资料汇总

### 批判盲点（verified.md boundaries_from ＋ U12 反身性池）

- 量化验收缺: 读多少算够、采访几位专家，原文均无标准（本卡 E 段各完成标准为合成约定，须如此看待）
- 非写作型调研收口未展开: 源头是科特勒的记者式调研，万维钢自述用法是「写书前把三年新书全翻一遍」——对非写作型（工程 / 决策类）调研如何收口原文未展开
- U12 反身性（verified.md R5 全局池）: 方法拥有者不自动豁免——「现有 X 已能很好解释 Y，不需要 Z」式静态封闭句式会在圈外议题上自动接管；故第⑤步的外置审稿不可省略
- 出书级 vs 日常级（冲突#2 裁决）: 第④⑤步的「唯一代言人」标准属出书 / 署名级交付；日常系统运行应用「完成>完美」（V8 writing-craft 系统纪律），禁止跨级引用

### 相关能力

- 深化件: viewpoint-testing(V5 · 第④⑤步质检) / input-selection-density(V2 · 第①步细则) / source-audit(V6 · ③④步信源审查)
- 同门: deep-reading(V3 · 单本深读)
