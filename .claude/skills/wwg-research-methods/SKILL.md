# 万维钢调研方法论（14 源资料集蒸馏） — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 从零基础攻克高门槛学科（数学/物理等系统性学习，五步法适用于「小领域快速到达前沿」）
- 纯事实查询与百科式问答（无需观点即可回答）
- 37% 广度停止规则等 needs_review 项未收入（单源无推导，见 needs-review.md nr01）
- 决策框架组与学习科学组（R3/R4 reference，非代理调研场景核心）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 脑力工作统一论：读书、采访、调研、写作是同一套脑力工序，以新研究为本
2. 知识快速迭代：优先读活人写的新东西，不读死人的书
3. 思维密集度排序输入：准备时间÷阅读时间，高密集度材料优先
4. 调研走五步不跳步：读书建基线→采访专家→到达前沿→形成观点→完成叙事
5. 证据分层引用：单篇论文只是一块积木，P 值低≠效应大
6. 输出找独特定位：不为编百科全书；观点过三检再交付

## 边界与判停

- 用户只需概览无需独立观点时，走完五步①-③即可停，不强制④⑤
- 调研触发过度拟合信号（为边缘细节继续挖料边际收益趋零）即执行深度停止
- 源质量不足以支撑观点时如实报告缺口，不硬造结论
- 每步完成标准未达（如第②步说不出「这领域的人在争论什么」）不得跳步推进
