# 附录

## 附录一：工程总承包招投标相关法律法规汇编

### 1. 国家层面法律法规

**《中华人民共和国招标投标法》**

《中华人民共和国招标投标法》是我国招标投标活动的基本法律，于1999年8月30日第九届全国人民代表大会常务委员会第十一次会议通过，自2000年1月1日起施行。该法律对招标投标活动的基本原则、适用范围、招标、投标、开标、评标和中标等环节进行了全面规定，是工程总承包招投标活动的基本法律依据。

**《中华人民共和国招标投标法实施条例》**

《中华人民共和国招标投标法实施条例》是为了实施《中华人民共和国招标投标法》而制定的行政法规，于2011年12月20日国务院第186次常务会议通过，自2012年2月1日起施行。该条例对招标投标法的有关规定进行了细化和补充，进一步明确了招标范围和规模标准、招标程序和要求、投标人资格条件、评标委员会组成和职责、中标和合同签订等内容。

**《中华人民共和国建筑法》**

《中华人民共和国建筑法》是规范建筑活动的基本法律，于1997年11月1日第八届全国人民代表大会常务委员会第二十八次会议通过，自1998年3月1日起施行。该法律对建筑许可、建筑工程发包与承包、建筑工程监理、建筑安全生产管理、建筑工程质量管理等方面进行了规定，为工程总承包活动提供了法律基础。

**《中华人民共和国政府采购法》**

《中华人民共和国政府采购法》是规范政府采购活动的基本法律，于2002年6月29日第九届全国人民代表大会常务委员会第二十八次会议通过，自2003年1月1日起施行。该法律对政府采购的方式、程序、监督检查等方面进行了规定，对涉及政府采购的工程总承包项目具有重要指导意义。

**《中华人民共和国政府采购法实施条例》**

《中华人民共和国政府采购法实施条例》是为了实施《中华人民共和国政府采购法》而制定的行政法规，于2014年1月30日国务院第39次常务会议通过，自2015年3月1日起施行。该条例对政府采购法的有关规定进行了细化和补充，进一步明确了政府采购的范围、方式、程序和监督检查等内容。

**《中华人民共和国合同法》（已被《中华人民共和国民法典》替代）**

《中华人民共和国合同法》曾是规范合同关系的基本法律，于1999年3月15日第九届全国人民代表大会第二次会议通过，自1999年10月1日起施行。该法律对合同的订立、效力、履行、变更和转让、权利义务终止、违约责任等方面进行了规定，为工程总承包合同的签订和履行提供了法律依据。该法律已被《中华人民共和国民法典》替代。

**《中华人民共和国民法典》**

《中华人民共和国民法典》是我国的基本民事法律，于2020年5月28日第十三届全国人民代表大会第三次会议通过，自2021年1月1日起施行。该法典的合同编对各类合同关系进行了规定，包括建设工程合同，为工程总承包合同的签订和履行提供了法律依据。

**《必须招标的工程项目规定》**

《必须招标的工程项目规定》是由国家发展和改革委员会制定的部门规章，于2018年3月27日发布，自2018年6月1日起施行。该规定明确了必须进行招标的工程项目范围，包括大型基础设施、公用事业等关系社会公共利益、公众安全的项目和全部或者部分使用国有资金投资或者国家融资的项目。

**《房屋建筑和市政基础设施项目工程总承包管理办法》**

《房屋建筑和市政基础设施项目工程总承包管理办法》是由住房和城乡建设部、国家发展和改革委员会联合制定的部门规章，于2019年12月23日发布，自2020年3月1日起施行。该办法对房屋建筑和市政基础设施项目工程总承包的发包方式、发包条件、承包方式、合同管理等方面进行了规定，是工程总承包招投标活动的重要依据。

**《工程建设项目招标范围和规模标准规定》**

《工程建设项目招标范围和规模标准规定》是由国家发展计划委员会、国务院有关部门联合制定的部门规章，于2000年5月1日起施行。该规定明确了必须进行招标的工程建设项目的范围和规模标准，为工程总承包招标活动提供了依据。

**《评标委员会和评标方法暂行规定》**

《评标委员会和评标方法暂行规定》是由国家发展计划委员会等七部委联合制定的部门规章，于2001年7月5日发布，自2001年8月1日起施行。该规定对评标委员会的组成和职责、评标方法的选择和应用等方面进行了规定，为工程总承包项目的评标工作提供了指导。

**《工程建设项目施工招标投标办法》**

《工程建设项目施工招标投标办法》是由国家发展和改革委员会等七部委联合制定的部门规章，于2003年3月8日发布，自2003年5月1日起施行。该办法对工程建设项目施工招标投标活动的招标、投标、开标、评标和中标等环节进行了规定，为工程总承包施工部分的招投标活动提供了依据。

**《工程建设项目勘察设计招标投标办法》**

《工程建设项目勘察设计招标投标办法》是由国家发展和改革委员会等八部委联合制定的部门规章，于2003年6月12日发布，自2003年8月1日起施行。该办法对工程建设项目勘察设计招标投标活动的招标、投标、开标、评标和中标等环节进行了规定，为工程总承包设计部分的招投标活动提供了依据。

**《电子招标投标办法》**

《电子招标投标办法》是由国家发展和改革委员会等八部委联合制定的部门规章，于2013年2月4日发布，自2013年5月1日起施行。该办法对电子招标投标活动的基本规则、电子招标投标系统、电子招标投标活动的具体规定和监督管理等方面进行了规定，为工程总承包电子招投标活动提供了依据。

### 2. 地方层面法规政策

**《北京市工程建设项目招标投标条例》**

《北京市工程建设项目招标投标条例》是北京市为规范本市行政区域内工程建设项目招标投标活动而制定的地方性法规，于2002年3月29日北京市第十一届人民代表大会常务委员会第三十三次会议通过，自2002年7月1日起施行。该条例对招标范围和规模标准、招标程序、投标、开标、评标和中标等方面进行了规定，为北京市工程总承包招投标活动提供了地方性法律依据。

**《上海市建设工程招标投标管理办法》**

《上海市建设工程招标投标管理办法》是上海市人民政府制定的地方性规章，于2011年4月20日上海市人民政府令第48号公布，自2011年6月1日起施行。该办法对上海市行政区域内建设工程招标投标活动的招标范围、招标程序、投标、开标、评标和中标等方面进行了规定，为上海市工程总承包招投标活动提供了地方性法规依据。

**《广东省实施〈中华人民共和国招标投标法〉办法》**

《广东省实施〈中华人民共和国招标投标法〉办法》是广东省为贯彻实施《中华人民共和国招标投标法》而制定的地方性法规，于2002年5月31日广东省第九届人民代表大会常务委员会第三十一次会议通过，自2002年10月1日起施行。该办法对招标范围和规模标准、招标程序、投标、开标、评标和中标等方面进行了规定，为广东省工程总承包招投标活动提供了地方性法律依据。

**《浙江省招标投标条例》**

《浙江省招标投标条例》是浙江省为规范本省行政区域内招标投标活动而制定的地方性法规，于2002年6月28日浙江省第九届人民代表大会常务委员会第三十六次会议通过，自2002年10月1日起施行。该条例对招标范围和规模标准、招标程序、投标、开标、评标和中标等方面进行了规定，为浙江省工程总承包招投标活动提供了地方性法律依据。

**《江苏省工程建设项目招标投标管理办法》**

《江苏省工程建设项目招标投标管理办法》是江苏省人民政府制定的地方性规章，于2004年8月20日江苏省人民政府令第203号公布，自2004年10月1日起施行。该办法对江苏省行政区域内工程建设项目招标投标活动的招标范围、招标程序、投标、开标、评标和中标等方面进行了规定，为江苏省工程总承包招投标活动提供了地方性法规依据。

### 3. 行业规范和标准

**《建设工程工程量清单计价规范》（GB 50500）**

《建设工程工程量清单计价规范》是由住房和城乡建设部制定的国家标准，规定了建设工程工程量清单计价的基本规则和方法，为工程总承包项目的计价提供了技术依据。

**《建设工程施工合同（示范文本）》（GF-2017-0201）**

《建设工程施工合同（示范文本）》是由住房和城乡建设部、国家工商行政管理总局联合制定的合同示范文本，为建设工程施工合同的签订提供了参考模板，也为工程总承包合同的施工部分提供了参考。

**《建设项目工程总承包合同（示范文本）》（GF-2020-0216）**

《建设项目工程总承包合同（示范文本）》是由住房和城乡建设部、国家市场监督管理总局联合制定的合同示范文本，专门针对工程总承包项目，为工程总承包合同的签订提供了权威参考模板。

**《建设工程监理合同（示范文本）》（GF-2012-0202）**

《建设工程监理合同（示范文本）》是由住房和城乡建设部、国家工商行政管理总局联合制定的合同示范文本，为建设工程监理合同的签订提供了参考模板，也为工程总承包项目的监理工作提供了参考。

**《建设工程设计合同（示范文本）》（GF-2015-0209）**

《建设工程设计合同（示范文本）》是由住房和城乡建设部、国家工商行政管理总局联合制定的合同示范文本，为建设工程设计合同的签订提供了参考模板，也为工程总承包合同的设计部分提供了参考。

**《建设项目工程总承包管理规范》（GB/T 50358）**

《建设项目工程总承包管理规范》是由住房和城乡建设部制定的国家标准，规定了工程总承包项目管理的基本要求和方法，为工程总承包项目的实施提供了技术依据。

**《建设工程招标投标评标工作指南》**

《建设工程招标投标评标工作指南》是由住房和城乡建设部制定的行业指导文件，为建设工程招标投标评标工作提供了具体指导，包括评标委员会的组建、评标方法的应用、评标报告的编制等内容。

**《工程建设项目招标文件编制导则》**

《工程建设项目招标文件编制导则》是由国家发展和改革委员会等部门制定的行业指导文件，为工程建设项目招标文件的编制提供了具体指导，包括招标文件的结构、内容和格式等方面。

## 附录三：工程总承包招投标常见问题解答

### 1. 招标人常见问题解答

**问题1：什么情况下工程项目必须进行招标？**

答：根据《必须招标的工程项目规定》（国家发展改革委令第16号），以下工程项目必须进行招标：
1. 大型基础设施、公用事业等关系社会公共利益、公众安全的项目；
2. 全部或者部分使用国有资金投资或者国家融资的项目；
3. 使用国际组织或者外国政府贷款、援助资金的项目。
具体规模标准为：施工单项合同估算价在400万元人民币以上，重要设备、材料等货物的采购，单项合同估算价在200万元人民币以上，勘察、设计、监理等服务的采购，单项合同估算价在100万元人民币以上。

**问题2：工程总承包项目招标需要具备哪些条件？**

答：根据《房屋建筑和市政基础设施项目工程总承包管理办法》，工程总承包项目招标需要具备以下条件：
1. 初步设计已经完成并经相关部门审批；
2. 建设资金已经落实；
3. 建设用地、规划许可等建设条件已经具备；
4. 法律法规规定的其他条件。

**问题3：工程总承包招标文件应当包含哪些主要内容？**

答：工程总承包招标文件应当包含以下主要内容：
1. 招标公告或投标邀请书；
2. 投标人须知；
3. 评标办法；
4. 合同条款及格式；
5. 发包人要求；
6. 发包人提供的资料；
7. 投标文件格式。
其中，发包人要求是工程总承包招标文件的核心内容，应当明确项目的功能、规模、标准、规划设计条件、技术要求、工期要求、质量要求等。

**问题4：工程总承包项目如何确定合理的投标人资格条件？**

答：确定工程总承包项目投标人资格条件应当遵循以下原则：
1. 与项目规模、复杂程度和特殊要求相适应；
2. 不得以不合理条件限制、排斥潜在投标人；
3. 不得对投标人的注册资本、资产总额、营业收入、利润、纳税额等规模条件作为资格要求或者评审因素。
具体可以从资质要求、业绩要求、项目经理和项目总工资格要求等方面进行设置，但要确保这些要求是合理的、必要的，与项目实际需求相匹配。

**问题5：工程总承包项目如何选择合适的评标方法？**

答：工程总承包项目可以选择的评标方法主要有：
1. 综合评估法：对技术、商务等多个因素进行综合评分，推荐得分最高的投标人为中标候选人。适用于技术复杂、专业性强的项目。
2. 技术标评分最低标价法：在技术标评分达到一定分值的投标人中，推荐投标价格最低的投标人为中标候选人。适用于技术难度适中的项目。
3. 双信封评标法：先评审技术标，再开启商务标，综合考虑技术和价格因素确定中标候选人。适用于技术和价格均需重点考虑的项目。
选择评标方法应当根据项目特点和招标需求，选择最能体现项目价值的评标方法。

### 2. 投标人常见问题解答

**问题1：投标人参与工程总承包投标需要具备哪些资质条件？**

答：根据《房屋建筑和市政基础设施项目工程总承包管理办法》，投标人参与工程总承包投标需要具备以下资质条件：
1. 具有与工程规模和内容相适应的工程设计资质和施工资质，或者由具有相应资质的设计单位和施工单位组成联合体。
2. 工程总承包项目的施工单位应当具有相应的施工资质，且与其资质等级相符合的施工业绩。
3. 工程总承包项目的设计单位应当具有相应的设计资质，且与其资质等级相符合的设计业绩。
4. 联合体各方应当签订共同投标协议，明确各方权利义务。联合体中标的，联合体各方应当共同与招标人签订合同，就工程总承包项目承担连带责任。

**问题2：投标人如何编制有竞争力的工程总承包投标文件？**

答：编制有竞争力的工程总承包投标文件应当注意以下几点：
1. 深入研读招标文件，全面理解招标要求和评标标准，确保投标文件的针对性和响应性。
2. 精心设计技术方案，突出方案的先进性、可行性和针对性，提高技术评分。
3. 合理编制投标报价，既要具有竞争力，又要确保项目的盈利性，避免低价恶性竞争。
4. 突出企业优势和项目管理能力，包括企业业绩、项目经理和项目总工业绩、项目管理组织机构等。
5. 注重投标文件的规范性和完整性，确保文件格式正确、内容完整、签字盖章齐全。

**问题3：工程总承包投标报价应当如何编制？**

答：工程总承包投标报价编制应当注意以下几点：
1. 全面分析项目成本，包括设计成本、采购成本、施工成本、管理成本、税费等各项成本。
2. 充分考虑项目风险，包括设计变更风险、材料价格波动风险、工期延误风险等，合理计入风险费用。
3. 根据市场竞争情况和企业自身情况，确定合理的利润水平。
4. 采用科学的报价方法，如类比法、参数法、工程量清单法等，确保报价的准确性和合理性。
5. 注重报价的完整性和一致性，避免漏项、错项和前后矛盾。

**问题4：工程总承包联合体投标需要注意哪些问题？**

答：工程总承包联合体投标需要注意以下问题：
1. 联合体各方应当签订共同投标协议，明确各方权利义务、责任分工、收益分配等内容。
2. 联合体牵头人应当具有相应的资质和能力，能够有效协调联合体各方工作。
3. 联合体各方应当共同参与投标文件的编制，确保投标文件的一致性和完整性。
4. 联合体中标后，各方应当共同与招标人签订合同，就工程总承包项目承担连带责任。
5. 联合体各方不得再以自己名义单独或者参加其他联合体在同一项目中投标。

**问题5：工程总承包投标过程中如何应对招标文件的疑问和澄清？**

答：工程总承包投标过程中应对招标文件的疑问和澄清应当注意以下几点：
1. 仔细研读招标文件，及时发现招标文件中的疑问、矛盾或不明确之处。
2. 在招标文件规定的时间内，以书面形式向招标人提出疑问，要求澄清或解释。
3. 疑问应当具体、明确，指出招标文件的具体条款和内容，并提出建议或意见。
4. 关注招标人发布的澄清或修改文件，及时调整投标策略和投标文件。
5. 如果招标人的澄清或修改涉及投标文件的重要内容，应当及时组织相关人员研究讨论，确保投标文件的响应性。

### 3. 招标代理机构常见问题解答

**问题1：招标代理机构在工程总承包招标中的主要职责是什么？**

答：招标代理机构在工程总承包招标中的主要职责包括：
1. 协助招标人编制招标文件，包括招标公告、投标人须知、评标办法、合同条款等。
2. 组织发布招标公告或发出投标邀请书，接受投标人的资格预审申请文件或投标文件。
3. 组织开标、评标，协助评标委员会完成评标工作，编写评标报告。
4. 协助招标人发出中标通知书，协助招标人与中标人签订合同。
5. 协助招标人处理招标投标活动中的异议、投诉等事项。
6. 协助招标人完成招标投标活动的资料归档工作。

**问题2：招标代理机构如何协助招标人编制高质量的工程总承包招标文件？**

答：招标代理机构协助招标人编制高质量的工程总承包招标文件应当注意以下几点：
1. 深入了解项目背景和招标需求，全面掌握项目的功能定位、技术路线、质量标准、投资限额等关键要素。
2. 根据项目特点和市场情况，提供合理的资格条件建议，既要确保投标人具备相应的能力，又要避免不合理限制竞争。
3. 协助招标人设计科学合理的评标标准，明确各评分因素的权重和评分方法，减少主观判断的空间。
4. 协助招标人拟定公平合理的合同条款，合理分配项目风险，既要保护招标人的合法权益，又要考虑投标人的合理诉求。
5. 建立严格的招标文件质量把控机制，对招标文件进行多层次、多角度的审核，确保招标文件的质量和合规性。

**问题3：招标代理机构如何协助招标人规范组织评标工作？**

答：招标代理机构协助招标人规范组织评标工作应当注意以下几点：
1. 协助招标人依法组建评标委员会，确保评标委员会的组成符合法律法规要求和项目特点。
2. 为评标委员会提供必要的工作条件和技术支持，包括评标场所、评标工具、技术资料等。
3. 向评标委员会介绍项目情况和评标要求，但不得明示或暗示其倾向或者排斥特定投标人。
4. 协助评标委员会规范开展评标工作，包括初步评审、详细评审、澄清和说明等环节，确保评标过程的规范性和透明度。
5. 协助评标委员会编制规范的评标报告，如实记录评标过程和结果，包括评标基本情况、评标方法、评审过程、评审结果等内容。

**问题4：招标代理机构如何防范工程总承包招标过程中的法律风险？**

答：招标代理机构防范工程总承包招标过程中的法律风险应当注意以下几点：
1. 加强法律法规学习，熟悉招标投标相关法律法规和政策文件，确保招标活动的合法合规。
2. 建立健全内部控制制度，规范业务流程，明确岗位职责，加强风险管控。
3. 严格审核招标文件，确保招标文件的合法性、完整性和一致性，避免因招标文件问题引发争议。
4. 规范组织招标过程，确保招标公告发布、资格审查、开标、评标、定标等各环节的规范性和透明度。
5. 妥善保管招标投标资料，建立完善的档案管理制度，为可能的争议解决提供证据支持。
