一、权重表谁来定？"发包人提、承包人确认"才落地

权重表是指数法调价的基本条件。传统做法由投标人在投标函里提，发包人招标文件没写明，就形同虚设。

规范新增了一个反转程序——B.2表：发包人提出、承包人确认：

· 发包人在招标文件中直接提供权重表

· 投标人报价中考虑差异、提出变值权重

· 招投标确认后在合同里约定

你公司 EPC 招标，直接上B.2表（发包人提权重），别指望投标人自发提，才能真正落地过程结算。

算例：某建设项目，发包人在招标文件中提出本工程采用指数法调价，并给出价格指数权重表（见表1）；承包人在投标中响应，对人工费（0.20→0.22）、混凝土（0.15→0.16）权重提出更改，双方经计算确认。

承包人完成了某里程碑节点，该节点约定合同价款2150 万元，质量检验合格后进入进度款结算与支付，按约定本节点应扣回预付款80 万元。

代入指数法公式：

ΔP = P₀［A + ( B₁×Fₜ₁/F₀₁ + B₂×Fₜ₂/F₀₂ + B₃×Fₜ₃/F₀₃ + … + Bₙ×Fₜₙ/F₀ₙ ) − 1］

P₀ = 2150 − 80 =2070 万元

ΔP = 2070 ×［0.47 + ( 0.22×110%/110% + 0.13×107%/105% + 0.16×550/540 + 0.02×118%/110% ) − 1］

= 2070 × ( 0.47 + 0.22 + 0.132 + 0.163 + 0.021 − 1 )

= 2070 × 0.006

=12.42 万元

→ 该里程碑节点的合同价款应调增12.42 万元。

三、价格指数来源怎么约？"同源"是铁律

·政府投资项目：尽可能采用工程造价管理机构发布的人工、材料价格信息——已有 20 余省市和专业机构发布人工费调整指数

·常用建材：钢材网等专业网站发布的价格指数可选

·同源原则：基本价格指数选了某机构/网站，其现行价格指数也必须采用同一机构/网站，不能中途更换

你公司合同里"价格指数来源"条款要写死同一发布机构，防结算时双方各取有利来源扯皮。

四、没指数来源咋办？价格和指数可以互转

价格和价格指数可以互相转换——某一因子没有指数来源时，可用价格代替：

人工费示例

少数地区没发布人工费指数但发了人工单价 → 选最常用、占造价价值最大的人工单价作代表，把基准期单价列入基本价格指数栏，节点完工后将现行单价代入公式，照样算出调差。

商品混凝土示例

选用量最大的某强度等级混凝土价格作代表，完成某里程碑节点时确定该混凝土现行价格代入公式，同样算出调整金额。

遇到偏远地区、特殊材料无指数时，别卡住，用"代表单价替代指数"照样调差，过程结算不中断。

五、顺带：法律/税率变化归谁？

法律变化（含税率变化）引起的合同价格变化，风险由发包人承担（建市规12号第十五条）。

但注意"税金是否包干"可约定——增值税包干合法，税率涨跌一般不调价：

· 2018/2019 建筑业增值税从 11% 降到 9%，纳税人是承包人，依法纳税是法定义务，税率涨落后果由承包人承担

· 合同约定"税金包干不调"，不违反强制性规定，合法有效

· 发包人想拿"降税红利"？那是营业税思维——增值税下承包人进项也降（钢材 17%→13%），税负未必降，要求调含税价没有依据

六、一句话记住

权重表"发包人提、承包人确认"才落地；一张还是多张看工期和业态；指数来源认准同一机构，没有指数用"代表单价"也能调——法律税率变化归发包人。
