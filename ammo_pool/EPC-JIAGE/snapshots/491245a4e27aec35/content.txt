# 第八章 工程总承包招投标合规典型案例分析（续）

## 8.2 投标阶段典型案例

### 8.2.1 资质挂靠案例

**案例1：某水利工程EPC项目资质挂靠案例**

某水利工程EPC项目招标要求投标人具备水利水电工程施工总承包特级资质和水利行业设计甲级资质。A公司是一家实力较强的施工企业，具有水利水电工程施工总承包一级资质，但不具备特级资质和设计资质。为参与该项目投标，A公司采取了以下违规操作：

1. 与具有水利水电工程施工总承包特级资质的B公司签订"借用资质协议"，约定支付B公司50万元"资质使用费"，由A公司以B公司名义投标；
2. 与具有水利行业设计甲级资质的C设计院签订"挂靠协议"，约定支付C设计院合同金额2%的"管理费"，由C设计院出具资质证明文件并加盖公章。

A公司最终中标该项目，但在项目实施过程中，因A公司与B公司、C设计院之间的利益分配发生争议，B公司向招标人举报了资质挂靠行为。经调查，招标人认定A公司存在资质挂靠行为，违反了《招标投标法》和《建筑法》的相关规定，取消了A公司的中标资格，并将A公司列入不良行为记录名单，禁止其3年内参与该地区的水利工程投标。

**案例分析与启示：**

1. **资质挂靠的违法性**：资质挂靠是一种严重的违法行为，不仅违反了招标投标法律法规，也违反了建筑市场管理的相关规定。

2. **资质挂靠的法律风险**：资质挂靠行为一旦被发现，不仅会导致中标资格被取消，还可能面临行政处罚和市场禁入等严重后果。

3. **联合体投标的合规途径**：对于不具备全部资质条件的企业，可以通过组成联合体的方式参与投标，但必须遵循联合体投标的法定程序和要求。

4. **资质管理的重要性**：企业应当重视资质管理，通过合法途径提升自身资质水平，而不是通过挂靠等违法方式规避资质要求。

**案例2：某医院建设EPC项目"影子公司"挂靠案例**

某三甲医院建设项目采用EPC总承包模式，招标要求投标人具备建筑工程施工总承包特级资质和建筑行业甲级设计资质。D公司是一家大型建筑企业，具备建筑工程施工总承包特级资质，但其设计院只有建筑行业乙级设计资质。

为参与该项目投标，D公司采取了以下操作：

1. 成立了一家"影子公司"E公司，由D公司实际控制；
2. E公司与具有建筑行业甲级设计资质的F设计院签订了长期"设计资质挂靠协议"，约定E公司可以使用F设计院的资质参与投标；
3. D公司和E公司组成联合体参与投标，表面上符合资质要求。

D公司和E公司组成的联合体最终中标该项目。在项目实施过程中，由于E公司实际上没有设计能力，项目设计工作由D公司内部设计团队完成，导致设计质量不符合要求，多次返工，严重影响了项目进度。

医院方发现问题后，对E公司的背景进行了调查，发现了资质挂靠行为。医院方立即向当地建设主管部门和招投标监管部门投诉。经调查，监管部门认定D公司和E公司存在资质挂靠行为，违反了《招标投标法》和《建筑法》的相关规定，取消了联合体的中标资格，并对D公司、E公司和F设计院分别处以罚款，同时将三家企业列入不良行为记录名单。

**案例分析与启示：**

1. **"影子公司"挂靠的隐蔽性**：通过设立"影子公司"进行资质挂靠是一种更为隐蔽的违法行为，但同样会面临严重的法律风险。

2. **资质挂靠对项目质量的影响**：资质挂靠不仅是法律问题，更会导致实际施工或设计能力与资质要求不符，影响项目质量和进度。

3. **联合体投标的实质要求**：联合体投标必须是真实的合作关系，每个成员都应当具备相应的资质和能力，并在项目中发挥实际作用。

4. **资质挂靠的连带责任**：资质挂靠行为不仅会导致挂靠方受到处罚，被挂靠方也会面临连带责任，包括行政处罚和市场信用损失。

### 8.2.2 围标串标案例

**案例1：某能源EPC项目"抬价陪标"案例**

某省能源集团计划建设一座生物质发电厂，采用EPC总承包模式。G公司为了确保中标，采取了以下围标串标行为：

1. G公司与H公司、I公司达成协议，由H公司和I公司作为"陪标方"参与投标；
2. G公司向H公司和I公司分别支付50万元"陪标费"；
3. 三家公司共同商定投标报价，G公司报价最低，H公司和I公司的报价分别高出G公司5%和8%；
4. 三家公司的技术方案由G公司统一编制，H公司和I公司的方案故意设置一些缺陷，以确保G公司的方案评分最高。

在评标过程中，评标委员会发现三家公司的技术方案存在高度相似性，且部分内容完全相同，包括错误和标点符号。评标委员会向招标人报告了这一情况，招标人随即向当地招投标监管部门报告。

经调查，监管部门查获了三家公司之间的通信记录和资金往来证据，认定三家公司存在围标串标行为，违反了《招标投标法》第三十二条关于投标人不得相互串通投标的规定。最终，三家公司均被取消投标资格，并被处以投标保证金两倍的罚款，同时被列入不良行为记录名单，禁止其3年内参与该省的能源项目投标。

**案例分析与启示：**

1. **围标串标的违法性**：围标串标是一种严重的违法行为，不仅违反了招标投标法律法规，也扰乱了市场秩序。

2. **围标串标的识别特征**：投标文件的高度相似性、报价规律性异常、投标人之间存在资金往来等都是围标串标的典型特征。

3. **评标委员会的监督作用**：评标委员会应当对投标文件进行认真审查，发现可能存在的围标串标行为并及时报告。

4. **围标串标的法律后果**：围标串标行为一旦被发现，不仅会导致投标资格被取消，还将面临罚款、市场禁入等严重后果，甚至可能构成犯罪。

**案例2：某市政EPC项目"轮流中标"案例**

某市计划在3年内建设10个市政公园，采用EPC总承包模式，分批次进行招标。J公司、K公司和L公司是当地三家主要的园林绿化企业，为了避免恶性竞争，三家公司达成了以下串标协议：

1. 将10个项目按照3:3:4的比例分配给三家公司；
2. 在每次招标中，事先确定中标方，其他两家公司作为"陪标方"参与；
3. "陪标方"故意在资格条件、技术方案或报价方面设置缺陷，确保预定中标方能够中标；
4. 中标方向"陪标方"支付项目合同金额的1%作为"协调费"。

在第7个项目招标过程中，由于K公司的一名员工离职并举报了三家公司的串标行为，当地纪检监察部门和招投标监管部门联合展开调查。经查，三家公司的串标行为涉及前6个已完成招标的项目，违反了《招标投标法》和《反垄断法》的相关规定。

最终，三家公司被处以各自中标项目合同金额10%的罚款，相关责任人被移送司法机关处理。同时，已完成的项目被纳入重点监管范围，未完成招标的项目重新组织招标。

**案例分析与启示：**

1. **"轮流中标"的违法性**：通过事先分配项目、轮流中标的行为不仅违反了招标投标法律法规，还可能构成《反垄断法》禁止的垄断协议。

2. **长期串标的系统性风险**：长期、系统性的串标行为不仅扰乱市场秩序，还会导致项目质量下降、成本增加，损害公共利益。

3. **内部举报的重要性**：建立健全的内部举报机制和举报人保护制度，是发现和制止围标串标行为的重要途径。

4. **多部门联合监管**：招投标监管需要纪检监察、行业主管、市场监管等多部门联合执法，形成监管合力。

### 8.2.3 投标文件造假案例

**案例1：某工业EPC项目业绩造假案例**

某大型工业园区计划建设一座化工废水处理厂，采用EPC总承包模式。招标文件要求投标人具有类似项目业绩，并将业绩作为评分的重要因素。M公司为提高中标机会，在投标文件中提供了以下虚假材料：

1. 伪造了一份与某化工企业签订的EPC总承包合同，虚构了一个并不存在的项目；
2. 伪造了该虚构项目的竣工验收证明和业主评价；
3. 在业绩描述中夸大了公司在实际参与项目中的角色和贡献。

M公司凭借虚假业绩获得了高分，最终中标该项目。在合同签订后，招标人在进行背景调查时发现了业绩造假问题，立即向当地招投标监管部门报告。

经调查，监管部门认定M公司存在提供虚假材料谋取中标的行为，违反了《招标投标法》第三十三条的规定。最终，M公司的中标资格被取消，投标保证金被没收，并被列入不良行为记录名单，禁止其2年内参与该地区的工业项目投标。

**案例分析与启示：**

1. **业绩造假的违法性**：提供虚假的业绩材料谋取中标是一种严重的违法行为，一旦被发现将面临严重后果。

2. **业绩核查的重要性**：招标人应当对投标人提供的业绩材料进行认真核查，必要时进行实地考察或联系业主方确认。

3. **诚信投标的原则**：投标人应当遵循诚信原则，如实提供企业资质、业绩和能力等信息，不得提供虚假材料。

4. **信用评价机制的作用**：建立健全的信用评价机制和不良行为记录制度，是防范投标造假行为的重要手段。

**案例2：某交通EPC项目人员资质造假案例**

某高速公路隧道工程采用EPC总承包模式，招标文件要求投标人配备具有特定资质和经验的项目经理和技术负责人。N公司为满足要求，在投标文件中提供了以下虚假材料：

1. 伪造了项目经理的高级工程师职称证书；
2. 伪造了技术负责人参与类似项目的经历证明；
3. 在拟派人员简历中虚构了多个大型项目的管理经验。

N公司中标后，在项目实施过程中，业主方发现项目经理和技术负责人的实际能力与投标文件中描述的相差甚远，多次出现技术决策失误。业主方对N公司提供的人员资质进行了核查，发现了造假问题。

经调查，当地交通主管部门认定N公司存在提供虚假材料谋取中标的行为，违反了《招标投标法》和《公路工程建设项目招标投标管理办法》的相关规定。最终，N公司被责令更换项目经理和技术负责人，并被处以合同金额2%的罚款，同时被列入不良行为记录名单。

**案例分析与启示：**

1. **人员资质造假的危害**：人员资质造假不仅是法律问题，更会直接影响项目的质量和安全，带来重大风险。

2. **人员资质核查的方法**：招标人可以通过查询职称证书、联系原项目业主、面试考核等方式核查拟派人员的资质和能力。

3. **项目团队的真实性要求**：投标人应当确保拟派项目团队的真实性和稳定性，避免"挂名"或"借用"他人资质的行为。

4. **履约过程的监督管理**：业主方应当加强对项目团队的履约监督，确保实际参与项目的人员与投标文件中承诺的一致。
