## 🧩 核心功能

### 智能体编程

多轮对话式编码，Claude 自主推理、使用工具、生成代码并自我修正，支持跨文件操作。

### 深度思考（Extended Thinking）

为复杂任务提供深层推理能力，可通过 ⌥ + T 开关或 /effort 设置 5 级推理力度：

力度

low

极速回复，适合简单问答

medium

平衡速度与质量

high

默认模式

xhigh

深度推理

max

最大思考预算

### 多文件编辑

- **Read**：读取任意文件内容
- **Edit**：精确 diff 编辑
- **Write**：创建新文件
- **Glob**：模式匹配搜索文件
- **Grep**：正则表达式内容搜索

### Git 集成

内置完整 Git 工作流：分支管理、提交、PR 创建、代码审查、diff 查看。

### MCP 协议

Model Context Protocol 连接外部服务——数据库、Slack、GitHub、浏览器自动化等 100+ 服务。

### 子智能体（Subagents）

并行启动独立上下文的子智能体，处理复杂任务不互相干扰。支持 Agent 团队协作。

### 会话管理

- **恢复**：按 ID 或名称恢复历史会话
- **分支**：创建对话分支
- **检查点**：回退到任意历史状态
- **自动压缩**：上下文接近上限时智能总结

### 权限与安全

模式

default

默认模式，关键操作需确认

acceptEdits

自动接受文件编辑

plan

仅分析不执行

auto

分类器自动判断

dontAsk

全部自动执行

### Hooks 钩子

基于事件的自动化：SessionStart、PreToolUse、PostToolUse 等事件触发自定义脚本。

### IDE 集成

支持 VS Code、JetBrains 全系列（IntelliJ/PyCharm/WebStorm 等）、桌面端应用、Web 端。

### 1M 上下文窗口

百万 token 上下文，Opus 4.6 在 Max/Team/Enterprise 计划上默认开启。

## 🖥 CLI 常用参数

参数

示例

\-p "prompt"

非交互模式，打印后退出

claude -p "解释代码"

\-c

继续最近一次对话

claude -c

\-r <session>

恢复指定会话

claude -r "auth"

\-w <name>

隔离 worktree 启动

claude -w feat-auth

\--model <m>

指定模型

claude --model sonnet

\--effort <level>

推理力度

claude --effort max

\--remote

创建 Web 远程会话

claude --remote "Fix"

\--output-format json

JSON 输出

管道集成

\--max-turns N

限制交互轮数

claude -p "..." --max-turns 5

\--permission-mode

指定权限模式

claude --permission-mode auto
