# 关联法律法规体系

> 建设工程施工合同纠纷的裁判，以《民法典》建设工程合同章为上位法依据，以司法解释为操作规则，辅之以建筑法、招标投标法等行政管理性规定。本文档梳理与《建工解释二》适用密切相关的核心法律法规体系。

---

## 一、法律层面（全国人大及其常委会）

### （一）《中华人民共和国民法典》（2021年1月1日施行）

民法典是建工合同纠纷的最高法律依据，相关核心条文：

| 条文 | 内容要点 | 与解释二的关联 |
|:---:|---|---|
| 第153条 | 违反法律、行政法规强制性规定的民事法律行为无效（但该强制性规定不导致无效的除外） | 合同效力认定的根本依据（解释二第3—4条转包、违法分包、挂靠合同无效） |
| 第535条 | **代位权**：因债务人怠于行使其债权或者与该债权有关的从权利，影响债权人的到期债权实现的，债权人可以向人民法院请求以自己的名义代位行使债务人对相对人的债权 | **解释二第7条引入代位权的法律基础**（替代实际施工人突破合同相对性） |
| 第788条 | 建设工程合同是承包人进行工程建设，发包人支付价款的合同（包括勘察、设计、施工合同） | 建设工程合同的定义 |
| 第791条 | 总承包、分包、禁止转包、禁止违法分包的规定 | 转包、违法分包合同效力的法律基础（解释二第3条） |
| 第793条 | 建设工程施工合同无效，但建设工程经验收合格的，可以参照合同关于工程价款的约定折价补偿承包人 | **无效合同折价补偿的法律基础**（解释二第4、8条） |
| 第806条 | 建设工程合同解除的规定 | 合同解除的法律基础 |
| 第807条 | **建设工程价款优先受偿权**：发包人未按约定支付价款，承包人可催告；逾期不支付的，除不宜折价拍卖外，可协议折价或请求拍卖，工程价款享有优先受偿权 | **优先受偿权的法律基础**（解释二第15—21条） |
| 第808条 | 本章没有规定的，参照适用承揽合同的有关规定 | 建设工程合同参照承揽合同的依据 |

### （二）《中华人民共和国建筑法》（2019年修正）

| 制度 | 内容 | 与解释二的关联 |
|---|---|---|
| 施工许可 | 第7—11条，建筑工程施工许可制度 | 合同效力、违法施工的认定 |
| 承包资质 | 第12—13条，建筑施工企业资质等级制度 | 资质借用（挂靠）、超越资质的合同效力 |
| 禁止转包 | 第28条，禁止承包人转包工程 | 转包合同无效（解释二第3条） |
| 禁止违法分包 | 第29条，分包的合法性要件 | 违法分包合同无效 |
| 禁止挂靠 | 第26条，禁止以任何形式允许他人以本企业名义承揽工程 | 资质借用（挂靠）的法律基础 |

### （三）《中华人民共和国招标投标法》（2017年修正）及其实施条例

| 制度 | 内容 | 与解释二的关联 |
|---|---|---|
| 必须招标项目 | 第3条，关系社会公共利益、公共安全的大型基础设施等必须招标 | 解释二第1条"必须招标工程项目"的认定基础 |
| 中标合同 | 第46条，招标人和中标人应当自中标通知书发出之日起30日内订立书面合同，不得再行订立背离合同实质性内容的其他协议 | **解释二第2条"黑白合同"规则的法律基础** |
| 禁止串通投标、骗取中标 | 相关法律责任 | 影响合同效力 |

### （四）《中华人民共和国民法典》担保物权相关（优先权冲突）

| 条文 | 内容 | 与优先权的关联 |
|:---:|---|---|
| 第390条 | 担保物权物上代位：担保财产毁损、灭失或被征收，担保物权人对保险金、赔偿金、补偿金享有优先受偿 | 解释二第20条优先权物上代位的法理基础 |
| 第414条 | 同一财产上多个抵押权清偿顺序 | 优先权与抵押权冲突的处理参照 |

## 三、行政法规层面（国务院）

| 法规 | 核心内容 | 与解释二的关联 |
|---|---|---|
| 《建设工程质量管理条例》（2019修订） | 建设单位、勘察设计单位、施工单位、监理单位的质量责任；保修制度 | 工程质量争议、保修责任 |
| 《建设工程安全生产管理条例》 | 安全生产责任 | 安全事故的责任认定 |
| 《保障中小企业款项支付条例》 | 机关、事业单位、大型企业支付中小企业款项的期限和责任 | 工程款支付保障（相关参照） |
| 《保障农民工工资支付条例》（2020） | 农民工工资支付保障：专用账户、工资保证金、总包代发等 | **与实际施工人制度衔接**（农民工工资不依赖实际施工人诉权） |

> 特别注意：《保障农民工工资支付条例》的出台，为农民工工资提供了独立的保障机制（专用账户、工资保证金、总包代发、先行清偿等）。这也是2026年解释二敢于限缩实际施工人诉权的重要制度背景——农民工工资保护已不必依赖"实际施工人突破合同相对性"这一争议性制度。

## 五、规则适用层次总结

建工合同纠纷裁判的规则适用层次（从上位到下位）：

```
第一层：民法典（法律）
  ├─ 第153条（合同无效一般规则）
  ├─ 第535条（代位权）★解释二第7条基础
  ├─ 第788—808条（建设工程合同章）
  │   ├─ 第791条（转包、违法分包禁止）
  │   ├─ 第793条（无效合同折价补偿）★解释二第4、8条基础
  │   └─ 第807条（优先受偿权）★解释二第15—21条基础
  └─ 第390条（物上代位）★解释二第20条基础

第二层：建筑法、招标投标法（法律）
  ├─ 建筑法：资质、转包、挂靠禁止
  └─ 招投标法第46条：中标合同不得背离实质性内容 ★解释二第2条基础

第三层：司法解释
  ├─ 建工解释二（2026，23条）★最新优先
  └─ 建工解释一（2020，45条）基础性规定

第四层：行政法规
  ├─ 建设工程质量管理条例（质量、保修）
  └─ 保障农民工工资支付条例（工资保障）

第五层：部门规章、案例
  ├─ 住建部建市规〔2019〕1号（转包挂靠认定）
  └─ 最高法典型案例、公报案例、指导性案例
```
