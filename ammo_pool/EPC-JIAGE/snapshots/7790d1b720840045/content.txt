# 第八章 工程总承包招投标合规典型案例分析

## 8.1 招标阶段典型案例

### 8.1.1 招标条件与资格预审不当案例

**案例1：某市政工程EPC项目资格预审条件过高案例**

某市政府计划建设一座污水处理厂，采用EPC总承包模式。在招标过程中，招标人在资格预审文件中设置了严格的资格条件：要求投标人必须同时具备市政工程设计甲级资质、市政工程施工总承包特级资质，并在近5年内完成过至少3个类似规模的污水处理厂EPC项目。

这一资格预审条件发布后，引起了市场广泛质疑。经行业协会投诉并由当地建设主管部门调查后认定，全国范围内同时满足上述条件的企业不足5家，且均与招标人有密切业务往来。这种资格条件设置明显违反了《招标投标法》第二十条关于"招标人不得以不合理的条件限制或者排斥潜在投标人"的规定。

最终，当地建设主管部门责令招标人修改资格预审条件，将设计资质要求调整为市政行业设计乙级及以上资质，施工资质要求调整为市政工程施工总承包一级及以上资质，业绩要求调整为近8年内完成过至少1个类似规模的污水处理厂EPC项目或2个类似规模的污水处理厂设计或施工项目。修改后，符合条件的潜在投标人数量大幅增加，保证了充分的市场竞争。

**案例分析与启示：**

1. **资格条件设置的合理性原则**：资格预审条件应当与项目的规模、复杂程度和特殊要求相适应，不应设置歧视性、排他性条件。

2. **市场竞争的必要性**：招标人应当保证有足够数量的潜在投标人参与竞争，避免通过设置不合理条件形成变相的"定向招标"。

3. **监管部门的监督作用**：行业协会和监管部门应当加强对招标活动的监督，及时纠正不合理的招标行为。

4. **法律风险防范**：招标人在设置资格条件时应当进行市场调研，评估条件的合理性和可行性，避免因资格条件不当导致招标活动被投诉或者被责令重新招标。

**案例2：某化工项目EPC招标"量身定制"技术条件案例**

某大型化工企业计划建设一套特种化学品生产装置，采用EPC总承包模式进行招标。在招标文件中，招标人在技术规格书中详细描述了一种特定的生产工艺和设备参数，这些参数与市场上某特定企业的专有技术高度吻合。

多家潜在投标人在获取招标文件后发现，招标文件中的技术要求实际上是针对特定企业的专有技术"量身定制"的，其他企业即使具有类似的技术能力，也因为工艺路线不同而无法满足招标要求。

经投诉后，当地招投标监管部门介入调查，认定该招标文件违反了《招标投标法实施条例》第二十条关于"招标人不得以特定的专利、商标、品牌、原产地或者供应商来限定或者指定招标项目的技术、服务等要求"的规定。

最终，招标人被责令修改招标文件，将技术要求修改为基于性能和功能的描述，允许投标人提供不同的技术路线，只要能够满足最终产品的质量和产能要求即可。修改后，多家具有不同技术路线的企业参与了投标，促进了技术竞争和创新。

**案例分析与启示：**

1. **技术中立原则**：招标文件中的技术要求应当基于性能和功能进行描述，避免指向特定的专利、品牌或供应商。

2. **等效替代原则**：应当允许投标人提供满足同等功能和性能要求的替代方案，促进技术竞争和创新。

3. **公平竞争环境**：招标人应当创造公平的竞争环境，避免通过技术条件设置变相限制或排除潜在投标人。

4. **专业技术评审**：对于技术复杂的EPC项目，招标人应当组建专业的技术评审团队，客观评估不同技术路线的优劣，避免主观偏好导致的不公平评审。

### 8.1.2 招标文件编制不规范案例

**案例1：某电力工程EPC项目招标文件前后矛盾案例**

某省级电力公司计划建设一座燃气发电厂，采用EPC总承包模式。在招标文件编制过程中，由于时间紧迫，招标人将多个类似项目的招标文件进行拼凑，导致招标文件中出现了多处前后矛盾的内容：

1. 在资格条件部分，一处要求投标人具有电力行业设计甲级资质，另一处却要求具有火电专业设计甲级资质；
2. 在工期要求部分，一处规定总工期为24个月，另一处却规定为18个月；
3. 在付款条件部分，一处规定预付款比例为合同价的10%，另一处却规定为15%。

在投标人提出澄清申请后，招标人未能及时有效地澄清这些矛盾内容。多家投标人基于不同的理解编制了投标文件，导致评标过程中出现严重分歧。最终，该招标被多家投标人投诉，当地招投标监管部门责令招标人重新招标。

**案例分析与启示：**

1. **招标文件的一致性要求**：招标文件应当保持内部一致，避免前后矛盾的条款和要求。

2. **招标文件编制的专业性**：招标人应当组建专业的招标文件编制团队，避免简单拼凑或照搬其他项目的招标文件。

3. **澄清和修改的及时性**：对于投标人提出的疑问，招标人应当及时、明确地进行澄清和解释，必要时应当修改招标文件并相应延长投标截止时间。

4. **招标文件的审核机制**：招标人应当建立招标文件的内部审核机制，确保招标文件的质量和合规性。

**案例2：某市政EPC项目招标文件评标标准不明确案例**

某市计划建设一座大型体育场馆，采用EPC总承包模式。在招标文件中，评标标准部分存在以下问题：

1. 技术评分标准中多处使用"优秀"、"良好"、"一般"等主观描述，但未明确具体的评分标准；
2. 商务评分标准中对投标报价的评分方法描述不清，仅表述为"合理低价优先"；
3. 对投标人业绩的评分，未明确业绩的认定标准和评分方法。

在评标过程中，评标委员会成员对同一投标文件的评分出现巨大差异，导致评标结果存在明显的主观性和随意性。多家投标人对评标结果提出质疑，认为评标过程不公正、不透明。

经调查，当地招投标监管部门认定该招标文件的评标标准不符合《招标投标法实施条例》第三十三条关于"评标标准和方法应当清楚、明确"的规定，责令招标人修改招标文件并重新招标。

**案例分析与启示：**

1. **评标标准的客观性**：评标标准应当尽量采用客观、量化的指标，减少主观判断的空间。

2. **评标方法的明确性**：评标方法应当清楚、明确，便于评标委员会统一理解和执行。

3. **评分细则的详尽性**：应当制定详细的评分细则，明确各评分项的评分标准和方法。

4. **评标过程的公正性**：评标过程应当公正、透明，确保评标结果的客观性和公信力。

### 8.1.3 招标程序违规案例

**案例1：某环保EPC项目"先施工后招标"案例**

某县政府计划建设一座垃圾焚烧发电厂，采用EPC总承包模式。由于项目紧急，县政府在未完成招标程序的情况下，直接委托一家与县领导关系密切的企业开始了项目前期工作和部分施工准备。

在项目已经实质性启动的情况下，县政府才启动了公开招标程序。招标公告发布后，多家潜在投标人在现场踏勘时发现，项目已经有企业进场施工，部分基础工程已经完成。

这一情况被媒体曝光后，引起了上级主管部门的高度关注。经调查，该项目违反了《招标投标法》第三条关于依法必须进行招标的项目必须招标的规定，以及《招标投标法实施条例》第九条关于不得规避招标的规定。

最终，县政府被责令停止违规行为，对相关责任人进行了处分，项目重新启动招标程序。同时，已经完成的工程部分被纳入新的EPC总承包范围，由中标人负责质量检验和后续工作。

**案例分析与启示：**

1. **招标程序的法定性**：依法必须招标的项目必须严格按照法定程序进行招标，不得以任何理由规避招标。

2. **"先施工后招标"的违法性**：在招标程序完成前开始施工，属于严重违反招标投标法律法规的行为。

3. **政府采购的规范性**：政府及其所属部门作为招标人，应当带头遵守招标投标法律法规，规范招标行为。

4. **紧急项目的合规处理**：对于确实紧急的项目，应当按照法律法规规定的紧急程序处理，而不是简单地规避招标程序。

**案例2：某交通EPC项目评标委员会组成不合规案例**

某省交通厅计划建设一条高速公路，采用EPC总承包模式。在组建评标委员会时，招标人存在以下违规行为：

1. 评标委员会成员中，招标人代表超过了三分之一；
2. 部分评标专家不是从依法组建的专家库中随机抽取，而是招标人指定的；
3. 评标委员会中缺乏设计专业的专家，无法对投标文件中的设计方案进行专业评审。

在评标过程中，评标委员会对投标文件的评审明显偏向于某一投标人，最终推荐该投标人为中标候选人。其他投标人发现评标委员会组成不合规后，向当地招投标监管部门投诉。

经调查，监管部门认定该评标委员会的组成违反了《招标投标法》第三十七条关于评标委员会组成的规定，评标结果无效。招标人被责令重新组建评标委员会并重新评标。

**案例分析与启示：**

1. **评标委员会组成的法定要求**：评标委员会的组成必须符合法律法规的规定，包括人数、专业构成、产生方式等。

2. **专家抽取的随机性**：评标专家应当从依法组建的专家库中随机抽取，确保评标过程的公正性。

3. **专业构成的合理性**：评标委员会的专业构成应当与招标项目的特点相适应，确保能够对投标文件进行专业评审。

4. **评标过程的独立性**：评标委员会应当独立评审，招标人不得干预评标过程。
