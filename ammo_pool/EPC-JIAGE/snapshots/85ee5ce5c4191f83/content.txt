# 第九章 工程总承包招投标合规最佳实践（续）

## 9.2 投标人最佳实践

### 9.2.1 投标策略与决策最佳实践

在工程总承包招投标活动中，投标人的投标策略与决策直接关系到投标的成功率和后续项目实施的效益。科学合理的投标策略与决策是投标成功的关键。

**投标项目筛选与评估**

投标人应当建立科学的项目筛选与评估机制，选择适合自身能力和发展战略的项目参与投标。具体实践包括：

1. **项目信息收集**：建立多渠道的项目信息收集网络，包括招标公告平台、行业信息网站、客户关系网络等，及时获取潜在投标项目信息。投标人可以指定专人负责项目信息的日常收集和初步筛选，确保不错过重要的投标机会。

2. **项目初步筛选**：根据企业的资质条件、业务方向、技术能力等因素，对收集到的项目信息进行初步筛选，排除明显不适合的项目。例如，对于不具备相关资质或者技术能力的项目，应当果断放弃，避免浪费资源。

3. **项目深入评估**：对通过初步筛选的项目进行深入评估，包括项目的技术可行性、商业可行性、风险分析、竞争态势分析等。评估应当由技术、商务、法律等多方面专家组成的团队进行，确保评估的全面性和专业性。

4. **投标决策流程**：建立规范的投标决策流程，根据项目评估结果，由适当级别的管理层做出投标决策。对于重大项目，应当由企业高层管理团队集体决策；对于常规项目，可以由业务部门负责人决策。

投标人应当避免盲目投标，特别是对于以下类型的项目应当谨慎考虑：

- 资质条件勉强达到或需要借用资质的项目
- 技术要求超出企业能力范围的项目
- 招标条件明显不合理或存在明显倾向性的项目
- 预算明显不足或付款条件极为苛刻的项目
- 风险分配明显不公平的项目

**竞争态势分析与差异化策略**

投标人应当深入分析项目的竞争态势，制定差异化的投标策略，提高中标概率。具体实践包括：

1. **竞争对手识别**：通过市场调研、行业交流、历史投标数据分析等方式，识别可能参与投标的主要竞争对手。对于公开招标项目，可以通过参加现场踏勘、答疑会等活动，了解参与投标的其他单位情况。

2. **竞争优劣势分析**：客观分析自身与主要竞争对手在资质、业绩、技术能力、价格竞争力等方面的优劣势，找出差异化竞争的突破点。例如，如果在技术创新方面具有优势，可以重点突出技术方案的创新性；如果在项目管理方面具有优势，可以重点突出管理方案的科学性和可操作性。

3. **差异化策略制定**：根据竞争态势分析结果，制定差异化的投标策略，包括技术方案差异化、商务条件差异化、服务承诺差异化等。差异化策略应当基于企业的真实能力和项目的实际需求，避免盲目承诺或者虚假宣传。

4. **业主需求深度挖掘**：通过多种渠道深入了解业主的真实需求和关注点，有针对性地制定投标策略。例如，通过研究业主的历史项目、参加现场踏勘和答疑会、分析招标文件的重点和细节等方式，挖掘业主的隐性需求和关注点。

投标人应当避免简单模仿竞争对手或者采用千篇一律的投标策略。例如，某EPC项目中，多数投标人都采用常规的技术方案，而一家投标人通过深入研究业主需求，提出了创新的节能环保方案，虽然投资略高，但运营成本大幅降低，最终获得了业主的青睐。

**投标报价策略与成本控制**

投标报价是投标策略的核心要素，科学合理的报价策略有助于平衡中标概率和项目盈利能力。具体实践包括：

1. **项目成本精细测算**：组织专业团队对项目成本进行精细测算，包括设计成本、采购成本、施工成本、管理成本、财务成本等各项成本。成本测算应当基于详细的工作分解结构（WBS），确保测算的全面性和准确性。

2. **市场价格调研**：对主要设备、材料、劳务等资源的市场价格进行充分调研，了解价格趋势和波动规律，为报价提供可靠依据。价格调研应当考虑项目周期内的价格变化因素，必要时可以与主要供应商进行初步沟通，获取更准确的价格信息。

3. **风险因素量化**：识别项目可能面临的各类风险，并将风险因素量化为风险准备金，纳入报价考虑。风险准备金的计算可以采用定性分析与定量分析相结合的方法，根据风险发生的概率和影响程度确定合理的准备金额。

4. **多方案报价比选**：制定多个报价方案，通过比选分析各方案的优劣势和适用条件，选择最优方案。例如，可以制定激进方案、平衡方案和保守方案，分析各方案的中标概率和盈利能力，根据企业的风险偏好和项目特点选择合适的方案。

投标人应当避免以下报价误区：

- 盲目低价竞争，忽视项目实际成本和风险
- 简单套用历史项目的报价数据，忽视项目的特殊性
- 报价结构不合理，导致后期履约困难
- 对风险因素估计不足，导致项目亏损

例如，某EPC项目中，一家投标人为了获取项目，采用了极低的报价策略，中标后发现实际成本远高于预期，最终导致项目严重亏损，甚至影响了企业的正常运营。

**联合体投标策略**

对于资质或能力单独不足的投标人，联合体投标是一种有效的策略。科学合理的联合体投标策略有助于优势互补，提高中标概率。具体实践包括：

1. **合作伙伴选择**：选择资质互补、能力互补、文化相容的合作伙伴组成联合体。合作伙伴的选择应当考虑资质条件、技术能力、项目经验、企业信誉等多方面因素，确保联合体整体实力强大且协作顺畅。

2. **联合体协议制定**：制定详细的联合体协议，明确各方的权利、义务、责任分工、利益分配等事项。联合体协议应当包括但不限于以下内容：
   - 联合体各方的基本情况和资质条件
   - 联合体牵头人的确定和职责
   - 各方在投标和项目实施中的工作范围和责任分工
   - 联合体内部的协调机制和决策程序
   - 费用分担和利益分配方式
   - 保密义务和知识产权约定
   - 违约责任和争议解决机制

3. **联合体内部协调**：建立高效的联合体内部协调机制，确保投标过程中的信息共享和决策协同。可以设立联合体协调小组，由各方代表组成，负责投标过程中的重大事项协调和决策。

4. **联合体优势整合**：充分整合联合体各方的优势资源，形成强大的整体竞争力。例如，设计单位负责方案创新，施工单位负责施工组织优化，共同打造高质量的技术方案。

投标人应当避免以下联合体投标误区：

- 仅为满足资质要求而组建联合体，缺乏实质性合作
- 联合体协议过于简单，缺乏对权责利的明确约定
- 联合体内部沟通不畅，导致投标文件质量不高
- 联合体各方缺乏团队意识，各自为政

例如，某EPC项目中，一个由设计院和施工企业组成的联合体，由于前期沟通不充分，投标文件中的设计方案和施工方案存在明显矛盾，导致技术评分较低，最终未能中标。

### 9.2.2 投标文件编制最佳实践

投标文件是投标人向招标人展示自身实力和方案优势的重要载体，高质量的投标文件是中标的基础。投标人应当重视投标文件的编制工作，确保投标文件的专业性、针对性和竞争力。

**投标文件编制团队组建**

投标文件编制是一项复杂的系统工程，需要组建专业的编制团队。具体实践包括：

1. **团队结构设计**：根据项目特点和投标文件要求，设计合理的团队结构，一般包括总协调组、技术方案组、商务报价组、资格文件组等。对于大型复杂项目，可以进一步细分为设计方案组、采购方案组、施工方案组、试运行方案组等专业小组。

2. **人员配置优化**：选派具有丰富经验和专业能力的人员参与投标文件编制，确保各专业领域都有相应的专家支持。关键岗位如总协调人、技术负责人、商务负责人等应当由经验丰富的人员担任。

3. **职责分工明确**：明确团队各成员的职责分工和工作内容，建立责任制和考核机制。职责分工应当细化到具体的文件编制任务，确保每项工作都有明确的责任人。

4. **协作机制建立**：建立高效的团队协作机制，包括定期例会、信息共享平台、文件版本控制等，确保团队成员之间的有效沟通和协作。可以采用项目管理软件或协同办公平台，提高团队协作效率。

投标人应当避免以下团队组建误区：

- 临时拼凑团队，缺乏系统规划和专业配置
- 关键岗位人员经验不足或能力不匹配
- 团队成员兼职过多，无法专注投标工作
- 团队协作机制不健全，导致信息孤岛和工作脱节

**技术方案编制策略**

技术方案是投标文件的核心部分，直接关系到技术评分的高低。投标人应当精心编制技术方案，突出方案的先进性、可行性和针对性。具体实践包括：

1. **深入理解需求**：通过研读招标文件、参加现场踏勘、分析答疑文件等方式，深入理解业主的真实需求和项目特点。技术方案编制前，应当组织专家团队对招标文件进行详细解读，特别是对技术规格书、评标标准等关键部分进行深入分析。

2. **方案创新与优化**：在满足基本需求的基础上，注重方案的创新性和优化性，提供超越招标文件基本要求的价值。创新点可以包括技术路线创新、工艺流程优化、设备选型改进、施工方法创新等多个方面。

3. **重点难点突破**：针对项目的重点和难点问题，提出有针对性的解决方案，展示技术实力和问题解决能力。重点难点问题的识别可以通过分析招标文件、研究类似项目经验、参加现场踏勘等方式进行。

4. **方案论证与验证**：对技术方案进行充分的论证和验证，包括技术可行性、经济合理性、安全可靠性等方面，增强方案的说服力。论证可以采用理论分析、模型计算、案例参照等多种方法，必要时可以进行小型试验或模拟演示。

5. **图文并茂表达**：采用图文并茂的方式表达技术方案，提高方案的可读性和吸引力。可以使用流程图、示意图、三维模型、效果图等多种图形手段，直观展示方案的特点和优势。

投标人应当避免以下技术方案编制误区：

- 简单复制历史项目方案，缺乏针对性
- 过度承诺无法实现的技术指标或性能
- 方案描述过于笼统，缺乏具体的技术内容
- 忽视招标文件中的关键技术要求和评分点

**商务响应策略**

商务响应是投标文件的重要组成部分，直接关系到投标的合规性和商务评分。投标人应当认真编制商务响应文件，确保响应的全面性和合规性。具体实践包括：

1. **条款逐一响应**：对招标文件中的商务条款进行逐一响应，明确表示接受、部分接受或不接受，并对部分接受或不接受的条款提供合理的替代方案。响应表应当采用表格形式，清晰列出原条款内容、响应状态和响应内容。

2. **偏离合理化处理**：对于确需偏离的条款，应当提供充分的理由和替代方案，争取业主的理解和接受。偏离处理应当遵循"实质性条款不偏离，非实质性条款少偏离"的原则，避免过多的负偏离。

3. **商务优势突出**：在满足基本要求的基础上，适当提出对业主有利的商务条件，增强投标的竞争力。商务优势可以包括更优的付款条件、更短的工期承诺、更长的质保期、更全面的售后服务等。

4. **资质业绩展示**：充分展示企业的资质、业绩和实力，增强业主的信任和认可。资质业绩展示应当注重相关性和代表性，选择与投标项目类似的典型业绩进行重点展示。

投标人应当避免以下商务响应误区：

- 对实质性商务条款提出重大偏离，导致投标被否决
- 商务响应过于保守，缺乏竞争力
- 资质业绩材料不完整或不真实，影响评审结果
- 忽视招标文件中的商务评分点，导致商务得分不高

**投标文件质量控制**

投标文件的质量直接影响评标结果，投标人应当建立严格的质量控制机制，确保投标文件的高质量。具体实践包括：

1. **编制计划与进度控制**：制定详细的投标文件编制计划，明确各部分的完成时间和责任人，严格控制编制进度。计划应当预留充足的时间用于内部审核和修改完善。

2. **标准化模板应用**：建立标准化的投标文件模板库，提高编制效率和文件质量。模板库应当包括常用的技术方案模板、商务响应模板、资格文件模板等，便于快速调用和定制化修改。

3. **多级审核机制**：建立多级审核机制，包括专业审核、综合审核和最终审核，确保投标文件的准确性、完整性和一致性。审核应当关注以下方面：
   - 投标文件是否符合招标文件的格式和内容要求
   - 技术方案是否满足招标文件的技术要求
   - 商务响应是否符合招标文件的商务条件
   - 投标报价是否合理且符合招标文件的要求
   - 投标文件各部分是否存在矛盾或不一致
   - 投标文件是否存在错别字、格式错误等形式问题

4. **成果交叉检查**：组织不同专业组之间的交叉检查，确保投标文件各部分之间的协调一致。例如，技术方案与投标报价的一致性、设计方案与施工方案的协调性等。

5. **最终校对与完善**：在投标文件定稿前，组织专人进行最终校对和完善，确保投标文件的质量和完整性。最终校对应当重点检查投标文件的装订顺序、签字盖章、密封要求等形式要件。

投标人应当避免以下质量控制误区：

- 投标文件编制时间安排不合理，导致赶工应付
- 缺乏有效的审核机制，导致错误和遗漏
- 忽视投标文件的形式要件，导致形式不符被否决
- 投标文件各部分之间存在矛盾或不一致，影响评审结果

### 9.2.3 投标风险防控最佳实践

投标活动存在多种风险，有效的风险防控是投标成功的重要保障。投标人应当建立系统的风险防控机制，识别和应对投标过程中的各类风险。

**投标合规风险防控**

投标合规是投标的基本要求，合规风险防控是投标风险防控的首要任务。具体实践包括：

1. **合规审查机制**：建立投标合规审查机制，对投标过程和投标文件进行全面的合规性审查。合规审查应当覆盖以下方面：
   - 投标人资格条件是否符合招标文件要求
   - 投标文件格式和内容是否符合招标文件要求
   - 投标文件签字盖章是否符合要求
   - 投标保证金缴纳是否符合要求
   - 投标报价是否符合招标文件的限价要求
   - 技术方案是否满足招标文件的强制性要求
   - 商务条款响应是否符合招标文件的实质性要求

2. **法律法规培训**：定期组织投标团队进行招投标法律法规和政策培训，提高合规意识和能力。培训内容应当包括《招标投标法》及其实施条例、行业招投标规定、典型违法违规案例分析等。

3. **合规操作指引**：制定详细的投标合规操作指引，为投标团队提供明确的行为准则和操作规范。操作指引应当覆盖投标准备、投标文件编制、投标文件递交、开标评标等各个环节。

4. **合规风险预警**：建立合规风险预警机制，及时发现和处理投标过程中的合规风险。可以设立合规风险监测点，对关键环节和高风险事项进行重点监控。

投标人应当特别防范以下合规风险：

- 资质挂靠或借用，违反招标投标法律法规
- 围标串标行为，扰乱招标投标市场秩序
- 提供虚假材料，谋取不正当利益
- 商业贿赂行为，影响招标投标公平性

**技术风险防控**

技术风险是投标过程中的重要风险，有效的技术风险防控有助于提高投标质量和中标后的履约能力。具体实践包括：

1. **技术方案评审**：组织内部专家对技术方案进行严格评审，识别和解决方案中的技术风险。评审应当关注方案的可行性、先进性、经济性和安全性等方面。

2. **技术难点攻关**：针对项目的技术难点，组织专题研究和攻关，提前解决关键技术问题。可以借助企业内外部的技术资源，必要时可以与科研院所或专业机构合作。

3. **技术方案备选**：对于存在不确定性的技术方案，准备备选方案，增强应对变化的能力。备选方案应当与主方案保持一致的技术路线，但在具体实施方式上有所不同。

4. **技术承诺审慎**：对技术指标和性能承诺保持审慎态度，确保承诺的可实现性。技术承诺应当基于充分的论证和验证，避免过度承诺导致的履约风险。

投标人应当特别防范以下技术风险：

- 技术方案不成熟或存在重大缺陷
- 技术指标承诺过高，难以实现
- 忽视项目特殊条件对技术方案的影响
- 技术创新缺乏充分论证和验证

**商务风险防控**

商务风险直接关系到项目的经济效益和合同履行，有效的商务风险防控是投标成功的重要保障。具体实践包括：

1. **合同条款审查**：组织法律和商务专家对招标文件中的合同条款进行详细审查，识别潜在的商务风险。审查应当关注付款条件、工期要求、质量标准、验收条件、违约责任等关键条款。

2. **报价风险评估**：对投标报价进行全面的风险评估，识别可能的成本超支风险和价格波动风险。评估应当考虑材料价格波动、人工成本变化、政策变动等因素的影响。

3. **商务条件谈判策略**：针对不合理的商务条件，制定有效的谈判策略，争取更为平衡的权利义务关系。谈判策略应当基于对业主需求和关注点的深入理解，提出既能保护自身利益又能满足业主需求的替代方案。

4. **履约能力评估**：客观评估自身的履约能力，包括资金实力、技术能力、管理能力等，避免因能力不足导致的履约风险。评估应当基于企业的实际情况和项目的具体要求，确保两者的匹配性。

投标人应当特别防范以下商务风险：

- 合同条款严重不平衡，权利义务分配不合理
- 报价过低，无法覆盖成本和合理利润
- 付款条件苛刻，可能导致资金链紧张
- 工期要求过紧，难以按期完成

**投标过程风险防控**

投标过程中存在多种操作性风险，有效的过程风险防控有助于确保投标的顺利进行。具体实践包括：

1. **投标时间管理**：科学安排投标各环节的时间，确保投标文件按时完成和递交。时间安排应当预留充足的缓冲时间，应对可能的突发情况。

2. **投标文件递交保障**：制定详细的投标文件递交方案，包括人员安排、交通工具、备用方案等，确保投标文件安全、及时递交。对于重要项目，可以安排多人同行，采用多种交通工具，确保万无一失。

3. **开标现场应对预案**：制定开标现场可能出现问题的应对预案，包括投标文件形式问题、报价问题、质疑回应等。开标代表应当熟悉投标文件内容和相关法规，能够妥善处理开标现场的各种情况。

4. **投标保密措施**：采取严格的保密措施，防止投标信息泄露，特别是报价信息和技术创新点。保密措施应当包括人员保密教育、文件保密管理、信息系统安全防护等多个方面。

投标人应当特别防范以下过程风险：

- 投标文件准备时间不足，导致质量不高或无法按时递交
- 投标文件递交过程中出现意外，导致无法按时递交
- 开标现场出现异议或质疑，无法妥善应对
- 投标信息泄露，影响投标竞争力或引发合规风险
