# EPC发包范围内纳入运营资产费用的合规风险专项研究报告

原创 造价协作助手 2026-09-12 11:16 浙江

EPC总承包发包时，建设单位违规将本应作为运营资产的费用"打包"装入EPC总价合同，这属于基本建设财务制度违规 + 投资概算/预算执行违规 + 招标投标程序违规 + 国有资产管理违规的多重交叉问题。

问题定义：EPC总承包发包时，建设单位违规将本应作为运营资产的费用（如学校家具实验仪器、医院医疗设备、教学/医疗耗材、运营软件等）"打包"装入EPC总价合同，由此引发的合规风险与法律后果。          分析维度：法律定性、违规类型、风险后果、追责链条、案例警示、整改路径、防控建议

一、问题的法律定性与合规性质

1.1 违规行为的定性

违规发包的本质：将本属于"运营资产"（运营阶段采购、与工程交付无关的物资/服务）的支出，纳入"基本建设支出"（与工程建设直接相关的建安费、设备购置费、待摊投资等），通过EPC总价合同一并发包。

这属于基本建设财务制度违规 + 投资概算/预算执行违规 + 招标投标程序违规 + 国有资产管理违规的多重交叉问题。

二、违规发包行为的分类辨析

2.1 违规行为的类型学

违规将运营资产放入EPC，根据动机和形式可分以下类型：

类型一：规避招标型（最普遍）

将本应独立招标的运营资产（家具、设备、软件、耗材），伪装成"与工程配套"打包入EPC

目的：规避政府采购、简化流程

案例：学校课桌椅、医院病床本应公开招标，直接由总承包人在EPC内代采

类型二：预算消化型（最隐蔽）

基本建设投资有专项资金，而运营经费不足

建设单位为"消化"建安预算余额，将运营资产塞入EPC

目的：挪用基建资金、套取预算

案例：用基本建设项目资金购买医院医用耗材、教学耗材

类型三：扩大范围型（最主动）

将经营性质服务（如停车场运营、后勤物业、安保服务、医疗设备维保）打入EPC

目的：规避服务招标、绑定长期运营合同

案例：EPC合同内含5年设备维保、5年后勤服务

类型四：资产沉淀型（最有利可图）

将应费用化/消耗的运营资产通过EPC资本化，形成固定资产

目的：虚增固定资产投资额、做大业绩

案例：将一次性医疗耗材、试剂按"固定资产"通过EPC入账

类型五：关系输送型（最严重）

将运营资产交由总承包人"带资代采"，总承包人通过"指定品牌、虚高报价"输送利益

目的：利益输送、权钱交易

案例：EPC中医疗设备、教学设备由总承包人指定独家品牌且价格虚高

三、合规风险全景分析

3.1 合规风险地图

将运营资产违规纳入EPC，建设单位将同时触发六大类风险：

风险全景图

3.2 财政与审计风险（详细展开）

（1）违反基本建设财务制度

《基本建设财务规则》将建设成本界定为"建筑安装工程费、设备购置费、待摊投资、其他投资"四类

运营资产不属于建设成本，纳入后构成"建设成本虚增"

审计发现后，将认定"以基本建设投资名义列支运营费用"

（2）概算突破与预算执行违规

政府投资项目有严格的投资概算，运营资产纳入后：

若概算未含此部分 → 超概算，需重新报批，程序违规

若概算已含此部分 → 概算本身即违规（本不应列入）

突破概算需报原审批机关批准，未经批准的，构成擅自扩大建设规模、提高建设标准

（3）会计处理错误

运营资产通过EPC资本化 → 本应费用化的支出被资本化

资产账面价值虚增 → 折旧/摊销年限错误 → 财务报表失真

与"政府会计准则""企业会计准则"关于资产确认的条件不符

（4）审计整改后果

审计部门（政府投资审计、财政收支审计）发现后，可能：

出具《审计决定书》，责令追回资金

调整账务，冲减建设成本

对相关责任人提出移送处理建议

对单位处以罚款、通报批评

3.3 招标投标程序风险

（1）规避招标的认定

运营资产采购金额达到法定招标限额（施工400万、货物200万、服务100万，或依地方规定），但未单独招标，而是"打包"进入EPC由总承包人代采 → 构成规避招标

尤其学校家具、医院设备金额大（动辄数百万、上千万），规避招标性质明显

（2）程序违法的后果

依据《招标投标法》第五十五条及实施条例：

应招标而未招标的，合同无效

已签订合同的，应当重新招标

对单位处以罚款

对直接负责的主管人员和其他直接责任人员依法给予处分

（3）"捆绑销售"与限制竞争

将家具、设备指定由EPC总承包人代采，实质上限制了运营资产采购环节的公平竞争

涉嫌违反《反垄断法》《反不正当竞争法》

3.4 国有资产管理风险

（1）资产流失

运营资产经总承包人"代采"，往往存在虚高定价、以次充好、品牌垄断

学校家具市场价800元/套，EPC内报价可能1200-1500元/套

医院设备更是动辄虚增数倍

（2）产权不清

总承包人采购的运营资产，所有权归属不明（是建设单位还是总承包人垫资形成？）

未入固定资产台账 → 资产流失、账实不符

后续处置、报废程序无法执行

（3）账实不符

EPC总价中已含运营资产，但固定资产台账未单独登记

竣工决算时运营资产未单独列示 → 审计难以核实

3.5 合同法律风险

（1）合同效力存疑

若EPC合同范围包含依法必须招标而未招标的运营资产，该部分条款可能无效

整个EPC合同是否因此无效，需视是否可分、是否实质影响

依据《民法典》第一百五十三条、第五百零七条，违反法律、行政法规的强制性规定的民事法律行为无效

（2）变更与索赔风险

运营资产技术规格、品牌需求易变，纳入EPC后：

发包人变更需求 → 总承包人索赔、调价

总承包人"以次充好" → 发包人无法约束（已包干）

双方扯皮、停工 → 工程延期

（3）腐败与廉洁风险

运营资产定价权被总承包人垄断 → 形成利益输送通道

总承包人通过"代采"赚取差价 → 可能返利给发包人经办人员 → 受贿犯罪

3.6 行业监管与信用风险

住建部门：对政府投资EPC项目监管，发现违规发包可责令整改、处罚

财政/发改部门：将单位列入政府投资项目失信名单

卫生健康/教育部门：行业通报、问责

主要负责人：党纪政务处分（依据《中国共产党纪律处分条例》《公职人员政务处分法》）

七、审计与合规检查的关注重点

7.1 审计署《政府投资项目审计规定》关注点

政府投资审计、财政评审、竣工决算审计中，对EPC项目"打包运营资产"会重点检查：

检查点

具体方法

隐性债务审查

7.2 高频疑点信号

审计、巡察、纪检中发现以下"信号"即会重点关注：

EPC合同额异常高于常规建安费占比（如运营资产占EPC价30%以上）

EPC合同中含**"代采"、"总承包采购运营物资"**等条款

学校/医院项目EPC价明显偏离同类型项目

总承包人指定独家品牌的医疗/教学设备

EPC结算中家具、设备、软件费用占比畸高

项目中存在总承包人返利、好处费迹象

9.3 给建设单位的核心防控要点

1.守住"建安为主、运营不入"红线：EPC只做工程建设，运营资产全部剥离

2.严格区分"可暂列"与"不可入"：能暂列金额+发包人审批的才入合同，纯运营资产不入

3.大型设备/软件/危化品绝不打包：医院设备、HIS软件、危化品碰都不能碰

4."代采"需谨慎：确需代采的，以暂列金额+三方合同+发包人全程审批

5.全过程审计：引入财政评审、跟踪审计，实时把关

6.主动接受监督：事前报备、事中公开、事后报告

9.4 决策层的合规审示要点

给项目负责人/决策层的"五问"审示（立项前自问）：

1.这笔费用属于"工程建设"还是"运营"？

2.本应单独招标还是可打包入EPC？

3.有没有法规、政策依据？

4.总承包人代采会不会定价虚高？

任一问题无法明确回答，即不应将该项纳入EPC。

十、结论

10.1 核心结论

1.违规定性明确：将运营资产打包入EPC，是"运营费用资本化 + 规避招标 + 资产流失"的多重违规，而非程序瑕疵。

2.六大风险并存：财政审计、招标程序、国资管理、合同效力、廉洁刑事、行业监管六类风险交织，其中廉洁与刑事风险最严重、不可逆。

3.后果逐级加重：从责令整改、追回资金、罚款 → 党纪政务处分 → 滥用职权/受贿/贪污等刑事责任，后果随金额和情节加重。

4."代采"与"包干"是两大雷区：让总承包人"代采"运营资产并进入"总价包干"，等于把定价权和话语权交给可能逐利的对方，极易造成虚高与利益输送。

10.2 建设单位应建立的"黄金守则"

守则一：EPC只做"工程建设"，运营资产一律剥离单独采购；

守则二：大型设备、软件、危化品、长期服务绝不打包入EPC；

守则三：确需总承包人配合的，用"暂列金额+发包人审批+三方合同"，

绝不进入"总价包干"；

守则四：发包范围"说明书+负面清单"双公开，主动接受审计监督；

本报告基于现行法律法规（《政府投资条例》《招标投标法》《政府采购法》《基本建设财务规则》等）、部门规章、审计及纪检监察实务经验撰写，供政府投资EPC项目的建设单位、主管部门、审计与合规人员参考。具体个案的处理，应结合违规金额、情节、主观恶性、损失后果及当地政策综合判断，并建议咨询专业法律顾问与合规审计机构。
