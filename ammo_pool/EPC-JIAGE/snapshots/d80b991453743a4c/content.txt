# 第九章 工程总承包招投标合规最佳实践

## 9.1 招标人最佳实践

### 9.1.1 招标文件编制最佳实践

工程总承包招标文件是招标活动的核心文件，其质量直接影响招标的效果和后续合同履行的顺利程度。招标人在编制EPC总承包招标文件时，应当遵循以下最佳实践：

**明确项目目标和范围**

招标文件应当明确界定项目的目标和范围，包括但不限于：

1. **项目功能定位**：明确项目的功能要求和使用目的，为投标人提供清晰的设计导向。例如，一个污水处理厂项目应当明确处理规模、出水水质标准、运行要求等核心功能指标。

2. **工作范围界定**：清晰界定EPC总承包的工作范围，包括设计、采购、施工、试运行等各阶段的具体工作内容和边界。特别是与业主自行负责部分的界面关系，应当明确责任划分，避免后期争议。

3. **成果要求说明**：明确项目各阶段的成果要求，包括设计文件深度、设备材料标准、施工质量要求、验收标准等，为投标人提供明确的目标指引。

招标人应当避免项目范围界定不清或过于笼统的问题。例如，某市政道路EPC项目在招标文件中仅笼统要求"按照城市道路标准建设"，未明确具体的道路等级、设计车速、交通流量预测等关键参数，导致投标人理解不一，投标方案差异巨大，评标难度增加，后期还可能因理解不一致引发争议。

**合理设置资格条件**

资格条件是筛选合格投标人的重要工具，但不合理的资格条件设置可能导致限制竞争或无效招标。招标人应当遵循以下原则：

1. **与项目相适应**：资格条件应当与项目的规模、复杂程度和特殊要求相适应，不应过高或过低。例如，对于一个中等规模的市政道路项目，要求投标人具有特大型桥梁施工业绩就明显不合理。

2. **避免歧视性条件**：资格条件不得对潜在投标人设置不合理的限制或者排斥条件，不得以不合理条件限制或者排斥潜在投标人。例如，不得要求投标人必须是本地企业，或者必须使用特定品牌的设备。

3. **资质要求合理性**：对于EPC总承包项目，应当合理设置设计和施工资质要求，可以接受联合体投标，避免设置过高的资质门槛。例如，对于一般工业建筑项目，可以接受建筑工程设计乙级及以上资质和建筑工程施工总承包二级及以上资质。

4. **业绩要求适当性**：业绩要求应当与项目特点相关，数量要求适当，时间跨度合理。例如，可以要求近5-8年内完成过1-2个类似规模和类型的项目，而不应要求必须完成过3个及以上的完全相同项目。

招标人应当避免"量身定制"的资格条件。例如，某水厂EPC项目要求投标人必须在本省完成过处理规模完全相同的水厂项目，且必须采用特定工艺，这种条件明显具有排他性，可能导致只有特定企业符合条件。

**科学设计评标标准**

评标标准是评价投标文件优劣的重要依据，科学合理的评标标准有助于选择最适合的中标人。招标人应当遵循以下原则：

1. **评分因素的全面性**：评分因素应当全面考虑技术方案、项目管理、投标报价、企业实力、履约能力等多个方面，避免单一因素决定评标结果。

2. **评分标准的客观性**：评分标准应当尽量客观、量化，减少主观判断的空间。例如，对于技术方案的评分，可以设置具体的评分点和评分标准，而不是简单地用"优、良、中、差"来评价。

3. **权重分配的合理性**：各评分因素的权重分配应当合理，反映项目的特点和重点。例如，对于技术复杂的项目，可以适当提高技术方案的权重；对于工期紧张的项目，可以适当提高项目管理和工期承诺的权重。

4. **价格评审的科学性**：价格评审方法应当科学合理，既要防止恶性低价竞争，又要保证价格竞争的有效性。可以采用合理低价法、综合评分法等方法，并设置异常低价处理机制。

招标人应当避免评标标准过于笼统或主观。例如，某EPC项目的技术评分标准仅规定"方案合理性（30分）"，没有进一步细化评分标准，导致评标委员会成员评分差异巨大，评标结果缺乏公信力。

**完善合同条款设置**

招标文件中的合同条款是规范双方权利义务的重要依据，合理的合同条款有助于项目的顺利实施。招标人应当遵循以下原则：

1. **权责分配的公平性**：合同条款应当公平合理地分配双方的权利和义务，避免过度向一方倾斜。例如，不应当将所有风险都转嫁给承包商，或者过度限制承包商的权利。

2. **风险分担的合理性**：合同条款应当合理分配项目风险，遵循"风险由最有能力控制和承担的一方承担"的原则。例如，地质条件风险可以由业主承担，而施工组织不当导致的工期延误风险应由承包商承担。

3. **变更机制的灵活性**：合同条款应当设置灵活、可操作的变更机制，包括变更的认定、审批程序、费用确定方法等，以应对项目实施过程中的不确定性。

4. **争议解决的多元化**：合同条款应当设置多元化的争议解决机制，包括协商、调解、仲裁、诉讼等多种方式，以便及时有效地解决履约过程中的争议。

招标人应当避免合同条款的不公平或不合理。例如，某EPC项目合同条款规定"业主有权随时变更工作内容，承包商必须无条件执行，且不得要求增加费用或延长工期"，这种条款明显不公平，可能导致后期争议不断。

### 9.1.2 评标标准设置最佳实践

科学合理的评标标准是选择最适合的中标人的关键。在EPC总承包项目中，评标标准设置应当充分考虑项目的特点和要求，确保评标过程的公正性和有效性。

**技术评审标准优化**

技术评审是EPC总承包项目评标的核心环节，技术评审标准应当全面、客观、可操作。招标人可以采取以下措施优化技术评审标准：

1. **分层次设置评分项**：技术评审标准应当分为一级指标、二级指标和评分要点，形成层次分明的评分体系。例如，可以将技术方案分为总体方案、设计方案、采购方案、施工方案、试运行方案等一级指标，每个一级指标下设置若干二级指标，每个二级指标下设置具体的评分要点。

2. **明确各层次分值**：应当明确各层次指标的分值分配，确保评分的合理性和一致性。例如，在总分100分的技术评审中，可以将总体方案设为20分，设计方案30分，采购方案15分，施工方案25分，试运行方案10分。

3. **细化评分标准**：对于每个评分要点，应当制定详细的评分标准，明确不同得分档次的具体要求。例如，对于"设计方案的先进性和创新性"这一评分要点，可以规定：
   - 优秀（8-10分）：方案具有明显的创新点，采用了国际先进技术，能够显著提高项目性能或降低成本；
   - 良好（6-8分）：方案具有一定创新性，采用了成熟可靠的新技术，能够适度提高项目性能或降低成本；
   - 一般（4-6分）：方案基本采用常规技术，创新性不足，但能满足项目基本要求；
   - 较差（0-4分）：方案陈旧，缺乏创新，难以满足项目的优化要求。

4. **设置否决性条款**：对于关键的技术要求，可以设置否决性条款，明确不满足这些要求的投标文件将被否决。例如，可以规定"总体方案不符合项目功能定位"、"主要技术指标不满足招标文件要求"等情况将导致投标被否决。

**商务评审标准优化**

商务评审是评估投标人履约能力和条件的重要环节，商务评审标准应当客观、公正、有针对性。招标人可以采取以下措施优化商务评审标准：

1. **企业资质与实力评价**：对投标人的资质等级、财务状况、技术装备等基本实力进行评价，但应当避免过度强调资质等级，而应更注重实际能力。例如，可以将资质等级作为资格条件，而在评分中更注重企业的技术实力和项目管理能力。

2. **项目业绩评价**：对投标人的类似项目业绩进行评价，注重业绩的相关性和代表性，避免简单以数量取胜。例如，可以规定"每提供一个类似规模和类型的EPC项目业绩得3分，最高得9分"，同时明确"类似规模和类型"的具体标准。

3. **项目团队评价**：对投标人拟派项目团队的资质、经验和能力进行评价，注重团队的整体配置和关键岗位人员的能力。例如，可以对项目经理、设计负责人、采购负责人、施工负责人等关键岗位人员分别设置评分标准，考察其资质、经验和业绩。

4. **履约能力评价**：对投标人的同时在建项目情况、资源配置计划、质量管理体系、安全管理体系等履约能力因素进行评价。例如，可以要求投标人提供资源配置计划，并根据计划的合理性和可行性进行评分。

**价格评审方法优化**

价格评审是评标的重要环节，科学合理的价格评审方法有助于防范低价恶性竞争，确保项目的顺利实施。招标人可以采取以下措施优化价格评审方法：

1. **合理低价法**：采用合理低价法，而非简单的低价优先法，避免过度压价导致的履约风险。例如，可以采用以下公式计算价格得分：
   - 当投标报价≤评标基准价×（1-15%）时，价格得分 = 价格权重×评标基准价×（1-15%）/投标报价
   - 当评标基准价×（1-15%）<投标报价≤评标基准价时，价格得分 = 价格权重×[1-（评标基准价-投标报价）/评标基准价×100%]
   - 当投标报价>评标基准价时，价格得分 = 价格权重×评标基准价/投标报价

2. **评标基准价确定方法**：采用科学合理的方法确定评标基准价，可以考虑采用以下方法：
   - 去掉一个最高报价和一个最低报价后的算术平均值
   - 所有有效投标报价的算术平均值与招标控制价的加权平均值
   - 随机抽取系数法，即从预先设定的系数范围内随机抽取系数，与招标控制价相乘确定评标基准价

3. **异常低价处理机制**：设置异常低价处理机制，对明显低于成本的投标报价进行审查和处理。例如，可以规定"投标报价低于所有有效投标报价平均值的85%，或者低于招标控制价的75%时，评标委员会应当要求投标人作出书面说明并提供相关证明材料；无法证明其报价合理性的，评标委员会可以否决其投标"。

4. **价格权重合理设置**：根据项目特点合理设置价格评分的权重，避免价格因素过度主导评标结果。对于技术复杂、质量要求高的项目，可以适当降低价格权重；对于技术成熟、标准化程度高的项目，可以适当提高价格权重。

**综合评分权重优化**

综合评分是技术、商务和价格等多方面因素的加权综合，权重设置直接影响评标结果。招标人可以采取以下措施优化综合评分权重：

1. **项目特点导向**：根据项目的特点和重点确定各因素的权重。例如，对于技术复杂的创新项目，可以提高技术方案的权重；对于工期紧张的项目，可以提高项目管理和工期承诺的权重。

2. **平衡各方面因素**：在权重设置上应当平衡技术、商务和价格等各方面因素，避免单一因素过度主导评标结果。一般情况下，可以考虑以下权重范围：
   - 技术评分：40%-60%
   - 商务评分：20%-30%
   - 价格评分：20%-40%

3. **差异化评分策略**：对于不同类型的项目，可以采用差异化的评分策略。例如，对于标准化程度高的项目，可以采用"合格制+价格竞争"的方式，即只要技术和商务评分达到合格线，主要通过价格竞争确定中标人；对于创新性强的项目，可以采用"技术优先+合理低价"的方式，即主要通过技术方案的优劣确定中标人，同时确保价格的合理性。

4. **评分区间控制**：控制各评分因素的得分区间，避免得分过于集中或分散。例如，可以通过细化评分标准，确保技术评分在70-95分之间分布，避免所有投标人都得接近满分或者得分过低的情况。

### 9.1.3 招标过程管理最佳实践

招标过程管理是确保招标活动规范、有序、高效进行的关键。在EPC总承包项目中，招标过程管理应当贯穿招标活动的全过程，确保招标目标的实现。

**招标前期准备管理**

招标前期准备是招标活动的基础，充分的前期准备有助于提高招标质量和效率。招标人可以采取以下措施加强招标前期准备管理：

1. **项目可行性研究**：在招标前应当完成充分的可行性研究，明确项目的必要性、可行性和经济性，为招标活动提供坚实基础。可行性研究应当包括市场分析、技术方案比选、经济效益分析、风险评估等内容。

2. **招标方案策划**：根据项目特点和市场情况，科学策划招标方案，包括招标方式、资格预审方式、评标方法等。例如，对于技术复杂的项目，可以采用资格预审+综合评分法；对于标准化程度高的项目，可以采用资格后审+合理低价法。

3. **招标团队组建**：组建专业的招标团队，包括技术、商务、法律等方面的专家，确保招标文件的质量和招标过程的规范性。对于大型复杂项目，可以考虑聘请专业招标代理机构提供服务。

4. **招标计划制定**：制定详细的招标计划，包括招标各环节的时间节点、责任分工、质量控制措施等，确保招标活动有序进行。招标计划应当预留足够的时间用于招标文件编制、投标人准备投标文件、评标和定标等关键环节。

**招标公告与文件发布管理**

招标公告和招标文件的发布是招标活动的正式启动，其规范性和透明度直接影响招标的公正性和有效性。招标人可以采取以下措施加强招标公告与文件发布管理：

1. **招标公告内容完整性**：招标公告应当包含法律法规规定的必要内容，如项目概况、资格要求、获取招标文件的时间和方式、投标截止时间等，确保潜在投标人能够全面了解项目情况。

2. **发布渠道合规性**：招标公告应当在指定的媒体上发布，如国家或地方的招标投标公共服务平台、行业媒体等，确保信息发布的合法性和广泛性。

3. **招标文件获取便利性**：应当为潜在投标人提供便捷的招标文件获取渠道，如电子招标平台、现场领取等多种方式，并确保招标文件的完整性和一致性。

4. **招标文件售价合理性**：招标文件的售价应当合理，仅限于补偿印刷、邮寄等成本，不得以营利为目的，避免设置不合理的经济门槛。

**投标人疑问答复管理**

投标人疑问答复是澄清招标文件、统一理解的重要环节，科学规范的疑问答复管理有助于提高投标质量和评标效率。招标人可以采取以下措施加强投标人疑问答复管理：

1. **疑问收集规范化**：建立规范的疑问收集渠道和格式，如统一的疑问提交表格、电子邮件地址或招标平台功能，便于集中管理和及时响应。

2. **答复内容专业化**：组织专业团队对投标人疑问进行研究和答复，确保答复的准确性、专业性和一致性。对于技术性问题，应当由相关技术专家负责答复；对于商务和法律问题，应当由相关专业人员负责答复。

3. **答复过程透明化**：将所有投标人的疑问和答复内容以书面形式发送给所有获取招标文件的潜在投标人，确保信息的公开和透明。

4. **重大问题处理程序化**：对于可能影响投标的重大问题，应当建立程序化的处理机制，包括专家论证、集体决策、文件修改等步骤，确保处理的科学性和规范性。

**现场踏勘与答疑会管理**

现场踏勘和答疑会是投标人了解项目现场情况和招标要求的重要途径，科学组织现场踏勘和答疑会有助于提高投标质量。招标人可以采取以下措施加强现场踏勘与答疑会管理：

1. **踏勘计划科学性**：根据项目特点和现场情况，科学制定踏勘计划，包括踏勘路线、重点区域、安全措施等，确保踏勘的有效性和安全性。

2. **踏勘组织规范性**：规范组织现场踏勘，包括统一时间、集中引导、专人讲解等，确保所有投标人获得相同的现场信息。对于无法同时接待所有投标人的情况，可以分批组织，但应当确保各批次获得的信息一致。

3. **答疑会议专业性**：组织专业的答疑会，由项目技术、商务、法律等方面的专家参加，能够现场解答投标人的各类疑问。答疑会应当有完整的会议记录，并将会议纪要发送给所有获取招标文件的潜在投标人。

4. **信息公平性**：确保所有投标人获得相同的信息，避免个别投标人获得额外信息的情况。对于现场踏勘和答疑会中提出的重要问题和答复，应当以书面形式发送给所有获取招标文件的潜在投标人。

**招标文件澄清与修改管理**

招标文件的澄清与修改是完善招标文件、统一理解的重要手段，规范的澄清与修改管理有助于提高招标质量。招标人可以采取以下措施加强招标文件澄清与修改管理：

1. **澄清与修改的及时性**：对于投标人提出的疑问或者招标人自行发现的问题，应当及时进行澄清或修改，避免延误投标准备工作。

2. **澄清与修改的规范性**：澄清与修改应当采用书面形式，明确澄清或修改的具体内容、生效时间和适用范围，避免产生新的歧义或矛盾。

3. **澄清与修改的公平性**：澄清与修改内容应当同时发送给所有获取招标文件的潜在投标人，确保信息的公平性和透明度。

4. **实质性变更的处理**：对于招标文件的实质性变更，应当相应延长投标截止时间，确保投标人有充分的时间调整投标文件。一般情况下，延长的时间不应少于澄清或修改文件发出之日至投标截止之日的时间的50%。
