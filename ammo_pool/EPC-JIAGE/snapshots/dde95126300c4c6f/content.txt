# 第八章 工程总承包招投标合规典型案例分析（续）

## 8.3 评标与定标阶段典型案例

### 8.3.1 评标程序违规案例

**案例1：某电厂EPC项目评标信息泄露案例**

某火力发电厂扩建项目采用EPC总承包模式，共有5家投标人参与投标。在评标过程中，评标委员会成员P先生（某设计院专家）违反保密规定，将其他投标人的技术方案和报价信息泄露给了与其有私交的Q公司。Q公司利用这些信息，针对性地修改了自己的投标文件，并在评标现场答辩环节有针对性地强调自身方案的优势。

最终，Q公司以微弱优势中标。但在中标公示期间，另一投标人举报了P先生泄露评标信息的行为，并提供了相关证据。招标人立即向当地招投标监管部门报告，并暂停了中标程序。

经调查，监管部门查获了P先生与Q公司相关人员的通信记录，认定P先生存在泄露评标信息的违法行为，Q公司存在接受泄露信息并利用不正当手段谋取中标的违法行为。最终，评标结果被宣布无效，P先生被取消评标专家资格并被列入黑名单，Q公司被禁止3年内参与该地区的电力项目投标，招标人被责令重新组织评标。

**案例分析与启示：**

1. **评标保密的重要性**：评标信息的保密是保证评标公正性的基本要求，评标委员会成员必须严格遵守保密规定。

2. **评标专家的职业道德**：评标专家应当恪守职业道德，公正、独立地进行评审，不得利用评标信息谋取私利。

3. **评标过程的监督机制**：招标人应当建立健全评标过程的监督机制，防止评标信息泄露和不正当竞争行为。

4. **投标人的合规意识**：投标人应当遵循公平竞争原则，不得通过不正当手段获取评标信息或影响评标结果。

**案例2：某医疗设备EPC项目评标标准执行不一致案例**

某医院医疗设备采购及安装项目采用EPC总承包模式，招标文件规定采用综合评分法，其中技术分占70%，商务分占30%。在评标过程中，评标委员会成员对评标标准的理解和执行存在明显差异：

1. 部分评标委员会成员对技术方案的评分过于主观，缺乏统一标准；
2. 对投标人业绩的认定标准不一致，导致同样的业绩在不同评委处得到不同评分；
3. 对商务条款的响应程度评分标准不明确，各评委自行判断。

这种不一致的评标标准执行导致评分结果出现较大差异，最终计算的平均分难以真实反映投标文件的实际质量。在评标结果公示后，多家投标人对评标过程提出质疑，认为评标标准执行不一致，评分结果不公正。

经调查，当地招投标监管部门认定该项目评标过程存在标准执行不一致的问题，违反了《招标投标法实施条例》第五十五条关于"评标委员会应当按照招标文件确定的评标标准和方法，客观、公正地对投标文件进行评审和比较"的规定。最终，招标人被责令重新组织评标，并要求评标前对评标委员会成员进行统一培训，明确评标标准和方法。

**案例分析与启示：**

1. **评标标准执行的一致性**：评标委员会应当在评标前对评标标准和方法进行充分讨论和统一理解，确保评标过程的一致性。

2. **评分细则的明确性**：招标文件应当制定详细、明确的评分细则，减少主观判断的空间，便于评标委员会统一执行。

3. **评标培训的必要性**：在评标前对评标委员会成员进行培训，明确评标标准和方法，是保证评标质量的重要措施。

4. **评标过程的记录和说明**：评标委员会应当详细记录评标过程，对评分依据和理由进行充分说明，增强评标结果的可解释性和公信力。

### 8.3.2 评标标准执行不当案例

**案例1：某市政EPC项目低价中标异常案例**

某市政道路改造项目采用EPC总承包模式，招标文件规定采用综合评分法，其中价格分占40%，采用低价优先法计算。在开标后，评标委员会发现最低投标报价比次低报价低30%，比招标控制价低40%。

按照招标文件规定的评标标准，该最低报价自动获得满分，而其他投标人的报价分数则相对较低。尽管在技术评分中，最低报价投标人的得分较低，但由于价格分的优势，该投标人仍然获得了最高的综合得分，成为推荐的中标候选人。

评标委员会成员对此结果产生了质疑，认为最低报价明显不合理，可能导致后期履约风险。然而，招标文件中并未设置异常低价处理机制，评标委员会无法依据招标文件对最低报价进行否决或者调整评分。

最终，该投标人中标。但在项目实施过程中，由于资金不足，工程进度严重滞后，多次出现偷工减料和质量问题，最终导致合同解除，项目重新招标，造成了严重的时间和经济损失。

**案例分析与启示：**

1. **异常低价的风险防范**：招标文件应当设置异常低价处理机制，包括异常低价的认定标准和处理方法，防范低价恶性竞争。

2. **价格评分方法的合理性**：价格评分方法应当合理设置，避免单纯的低价优先，可以采用合理低价法或者综合评分法，平衡价格与质量的关系。

3. **投标报价的合理性分析**：评标委员会应当对投标报价进行合理性分析，对明显不合理的低价投标要求投标人作出说明并提供相关证明材料。

4. **履约能力的综合评估**：评标过程中应当综合评估投标人的履约能力，包括技术能力、资金实力、管理能力等，避免单纯依靠价格因素决定中标结果。

**案例2：某工业EPC项目技术标准偏离处理不当案例**

某化工厂技术改造项目采用EPC总承包模式，招标文件中规定了详细的技术标准和要求，并明确"投标方案必须满足技术标准的强制性要求，允许在非强制性要求上有所偏离"。

在评标过程中，评标委员会发现R公司的投标方案在某些技术参数上存在偏离，但评标委员会成员对这些偏离的处理存在分歧：

1. 部分评委认为所有偏离都应当视为不满足要求，对R公司的技术方案给予较低评分；
2. 部分评委认为只要不是强制性要求的偏离，都可以接受，对R公司的技术方案给予较高评分；
3. 还有部分评委根据偏离的具体情况和影响程度进行评分，态度较为中立。

由于评标委员会未能就技术偏离的处理达成一致意见，最终的评分结果差异较大，导致评标结果的公正性和可信度受到质疑。多家投标人对评标结果提出异议，认为评标标准执行不一致，评分结果不公正。

经调查，当地招投标监管部门认定该项目评标过程存在标准执行不一致的问题，责令招标人重新组织评标，并要求在评标前明确技术偏离的处理原则和评分方法。

**案例分析与启示：**

1. **技术偏离的明确界定**：招标文件应当明确界定技术偏离的类型、程度和处理原则，区分实质性偏离和非实质性偏离。

2. **评标标准的统一理解**：评标委员会应当在评标前对技术偏离的处理原则达成一致理解，确保评标标准执行的一致性。

3. **技术偏离的影响分析**：评标过程中应当对技术偏离的影响进行客观分析，考虑偏离对项目功能、性能、质量、安全等方面的实际影响。

4. **评标过程的沟通协调**：评标委员会主任应当加强对评标过程的组织协调，及时解决评标过程中出现的分歧和问题。

### 8.3.3 定标不公正案例

**案例1：某环保EPC项目"评定分离"异常案例**

某垃圾焚烧发电厂项目采用EPC总承包模式，招标文件规定采用"评定分离"方式，即由评标委员会按照综合评分法推荐3名中标候选人，再由招标人定标委员会确定中标人。

评标委员会经过评审，按照综合得分从高到低推荐了S公司、T公司和U公司为中标候选人，其中S公司的综合得分明显高于其他两家。然而，在定标阶段，招标人定标委员会却选择了排名第三的U公司作为中标人，理由是"U公司在类似项目上有更丰富的经验"。

S公司对此结果提出质疑，认为定标过程不公正，定标理由与招标文件规定的评标标准不一致。经调查，发现U公司与招标人存在利益关联关系，招标人定标委员会的决定存在明显的主观偏好。

当地招投标监管部门认定该项目定标过程违反了《招标投标法》第四十三条关于"评标委员会经评审，认为所有投标都不符合招标文件要求的，可以否决所有投标"的规定，以及《招标投标法实施条例》第五十五条关于"评标委员会应当按照招标文件确定的评标标准和方法，客观、公正地对投标文件进行评审和比较"的规定。最终，该定标结果被撤销，招标人被责令重新组织定标。

**案例分析与启示：**

1. **"评定分离"的规范实施**："评定分离"是一种新型的招标方式，但必须在法律法规允许的范围内规范实施，定标过程必须公正、透明。

2. **定标标准的一致性**：定标标准应当与招标文件规定的评标标准保持一致，不得随意改变评标结果的排序。

3. **定标过程的监督**：定标过程应当接受有效监督，定标委员会的组成和决策过程应当公开、透明。

4. **利益冲突的回避**：招标人和定标委员会成员应当主动回避与投标人存在的利益冲突，确保定标过程的公正性。

**案例2：某交通EPC项目评标报告篡改案例**

某高速公路服务区建设项目采用EPC总承包模式，招标文件规定采用综合评分法，由评标委员会推荐3名中标候选人。评标委员会经过评审，形成了评标报告，推荐了V公司、W公司和X公司为中标候选人，排名依次为V、W、X。

然而，在评标报告提交给招标人后，招标人的工作人员擅自修改了评标报告中的部分评分数据，导致最终排名变为X、V、W，使得原本排名第三的X公司成为第一中标候选人。

在中标公示期间，V公司发现了评分异常，向当地招投标监管部门投诉。经调查，监管部门通过比对评标委员会成员的原始评分表和最终的评标报告，发现了评标报告被篡改的事实。

最终，当地招投标监管部门认定该项目招标过程违反了《招标投标法》和《招标投标法实施条例》的相关规定，撤销了中标结果，对招标人的相关责任人进行了处分，并责令招标人重新组织招标。

**案例分析与启示：**

1. **评标报告的真实性**：评标报告是评标结果的重要载体，必须真实、准确地反映评标委员会的评审意见，不得篡改。

2. **评标资料的保存和管理**：评标过程中形成的原始评分表、评审记录等资料应当妥善保存，作为评标结果的依据和证明。

3. **招标人的法律责任**：招标人应当尊重评标委员会的专业判断，不得干预评标过程或篡改评标结果，否则将承担相应的法律责任。

4. **评标过程的公开透明**：评标过程应当公开透明，评标结果应当及时公示，接受社会监督，防止暗箱操作。
