# 工程造价审计基本操作流程+核心审核依据+常见问题

成控顾问 2026-03-21 23:41 河南

一、工程造价审计基本操作流程（全流程闭环）

审计准备：收集工程资料（合同、图纸、签证、结算书、招投标文件等），明确审计范围/计价口径，制定审计方案。

资料初审：核对资料完整性、规范性，排查签证/变更签字盖章不全、结算书与图纸不符等基础问题。

工程量审核：按图纸/计算规则复核工程量，现场踏勘核实实际施工与图纸、签证的一致性（如隐蔽工程、现场实测工程量）。

计价与组价审核：核对定额套用、主材价格、取费标准，确认是否符合合同及计价规范，核查价差调整、规费税金计取准确性。

签证与变更审核：核实签证/变更的真实性、合理性、合规性，剔除无效签证（无依据、重复计取、未施工签证）。

成本对比与分析：将审核结果与概算、中标价、市场造价对比，排查造价异常偏高/偏低项，分析偏差原因。

初稿编制与沟通：出具审计初稿，与施工、建设单位核对争议项，核实反馈意见并复核调整。

正式报告出具：确认无争议后，编制正式审计报告，明确审定造价、核增核减金额及依据，归档全部审计资料。

二、工程造价审计核心审核依据

1. 法定/规范依据

国家及地方造价计价规范（如《建设工程工程量清单计价规范》GB50500）、工程定额（土建、安装、市政等专业定额）；

建设工程质量、施工规范，工程量计算规则；

财税相关法规（规费、税金计取标准）。

2. 合同与招投标依据

工程施工合同（核心，含计价方式、结算条款、变更签证约定、奖罚条款）；

招投标文件、中标通知书（工程量清单、投标报价、招标答疑纪要）。

3. 工程现场与书面依据

施工图纸、设计变更、工程签证、工程联系单（需签字盖章齐全）；

竣工验收资料、隐蔽工程验收记录、现场踏勘实测数据；

材料设备采购合同、发票、认价单（甲方确认的主材价格）；

施工日志、监理日志、工程进度款支付凭证。

4. 其他补充依据

市场造价信息（当地造价站发布的材料价格、人工机械台班价格）；

类似工程造价案例（用于造价异常项对比参考）。

三、工程造价审计常见问题

1. 工程量类问题

重复计算工程量（如同一工序在图纸、签证中重复计取）；

虚增工程量（超出图纸范围、未施工部位计取工程量）；

工程量计算规则错误（未按规范/合同约定计算，如建筑面积、挖填方工程量计算偏差）。

2. 计价与组价类问题

高套定额（低标准工序套用高标准定额、普通工艺套用特殊工艺定额）；

定额重复套用（同一工作内容拆分后多次套取定额）；

主材价格偏高（未按合同认价、虚报材料价格，无正规采购凭证）；

取费错误（超高取费、违规计取未发生的费用，如夜间施工费、二次搬运费）。

3. 签证与变更类问题

无效签证（无建设/监理单位签字盖章、签证内容无事实依据、事后补签无佐证）；

签证内容模糊（无工程量、单价、施工部位，仅描述施工内容，无法核实）；

变更手续不全（设计变更无设计单位签字、变更后未按约定报审造价）；

重复计取变更费用（变更内容已含在原合同工程量中，仍单独计取）。

4. 合同与资料类问题

结算与合同约定不符（如固定总价合同擅自调整单价、未按约定扣减甲供材费用）；

资料缺失或矛盾（图纸与竣工图不一致、隐蔽工程无验收记录、签证与施工日志矛盾）；

甲供材管理混乱（甲供材数量虚报、未按实际领用扣减造价，甚至重复计取材料费用）。

5. 其他常见问题

规费、税金计取错误（如按非计税方法计取、违规减免规费）；

索赔费用不合理（无索赔依据、索赔工期/费用虚增，未按合同约定的索赔程序报审）；

现场施工与资料不符（如签证标注的施工工艺、材料规格与现场实际不一致，隐蔽工程偷工减料）。
