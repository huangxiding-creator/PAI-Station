3 条心法

20 条提示词，覆盖从合同到审计的全流程。每条都在项目里跑通过。

9 月底那篇《造价人用 AI 的 N 条提示词清单，直接抄走用》发了，私聊爆了。评论区最多的一句话是：

「10 条不够，能不能再给点？」

好，这篇是完整升级。我把从合同到审计的全流程走了一遍，按 5 大场景整理了 20 条。每一条都在项目里跑通过。

想收藏就先收藏，再挑你最烦的那一步开始试。

用之前，先说三件事

1
AI 不是万能的。 我踩过一个坑：让 AI 查实时信息价。它没广材网的会员账号，登不进去。它只能做你给它数据后的比对、找异常、算参考区间。信息价这块，还得你自己上广材网。

2
AI 不替你做判断。 一个 EPC 项目结算被砍 80 万。我拿 AI 反查了 5 条依据，最后回款 2.3 万。回款的不是 AI，是我拿着 AI 帮我整理好的条款，去跟甲方博弈。

3
提示词要带上下文。 别只发「帮我做一份清单」。给三样：你是干什么的、你在什么阶段、你要什么输出。

01

PART

合同阶段

CONTRACT · 5 Prompts

签合同那几天是最乱的：几十页文本，条款密密麻麻，甲方发个微信问「这条啥意思」，你可能半天答不上来。

这 5 条我按使用频次排的，从开工前到履约期，一路带下来。

PROMPT 01
合同交底

项目开工前给团队做交底。对齐你司用的交底表模板，能省一小时打字。

PROMPT

你是资深造价工程师，正在为一个[住宅/商业/公建/工业]项目做合同交底。

合同总价约 XXXX 万元，工期 XXX 天，采用[总价/单价/成本加酬金]合同。

关键条款如下：

[粘贴条款原文]

请输出一份合同交底记录表，包含：

1. 合同名称与编号

2. 工作界面划分（我方做什么、甲方做什么）

3. 核心条款 7 条（工期/付款/变更/索赔/违约/验收/争议解决）

4. 主要风险点（3-5 条）

5. 建议交底人、接受交底单位

输出格式：可直接填表的 Markdown 表格。

PROMPT 02
风险识别

甲方发合同草稿给你提意见。AI 不会替你说「改」，但会告诉你哪里在压你。

PROMPT

这是甲方发来的合同草案，我方作为[施工/设计/总包]方。

请从以下 5 个维度找出对我方不利的条款：

1. 支付条款（付款节点、比例、周期）

2. 变更索赔（签证时限、结算周期）

3. 违约条款（逾期、质量、解除）

4. 责任限制（上限、免责情形）

5. 争议解决（管辖地、仲裁/诉讼）

每条列出：条款原文 → 风险点 → 建议修改方向。

PROMPT 03
关键条款摘录

项目跑到一半，要快速查某个条款。3 分钟一份合同精华版，交接、复盘都好用。

PROMPT

请从这份合同中提取以下 5 类关键条款，每条只保留核心文字：

1. 付款条款

2. 变更与签证

3. 索赔与工期顺延

4. 违约金与赔偿

5. 争议解决

每条注明：条款编号 + 原文摘录 + 一句话解读。

PROMPT 04
违约条款梳理

甲方开始扣款/催办，你要知道扣得合不合理。谈判前必备——知道对方手里的牌，才知道怎么打。

PROMPT

这是合同违约相关的所有条款。请整理成一张表：

· 违约情形（甲方逾期付款 / 我方逾期完工 / 质量不合格等）

· 触发条件（时间、金额、次数）

· 处罚方式（违约金比例、解除权）

· 上限与免责

标出对我方最不利的 3 条，并给出应对思路。

PROMPT 05
履约节点提取

项目启动，给项目经理做一份时间线。一张时间线，让甲方、项目经理、财务都能对齐。

PROMPT

请从这份合同中提取所有时间节点要求，按时间轴排序：

· 合同生效日

· 开工/竣工节点

· 里程碑节点（每个付款节点对应什么）

· 报送节点（结算、变更、签证的时限）

· 验收节点

输出格式：甘特图风格的时间表，标注关键路径。

02

PART

清单编制

BILL OF QUANTITY · 3 Prompts

定额、材料、工程量、单价，四张表要互相咬合。一个数字错了，后面全乱。

PROMPT 06
材料编码核对

编码错了，套价全乱。10 分钟能省 1 小时。

PROMPT

请核对这份清单里的材料编码与名称：

1. 同一材料不同名称（比如 C30 混凝土 / C30 商品混凝土）

2. 编码与名称不匹配

3. 缺少编码但材料名称存在

输出一张材料对照表，标注需要修正的地方。

PROMPT 07
定额说明解释

甲方拿定额来卡你，你当场就答不上来——这是我见过最多的情况。尤其是碰到没做过的新工艺、新材料，救急。

PROMPT

定额编号：XXX

定额名称：XXX

请解释：

1. 这条定额的工作内容是什么

2. 适用范围（用于哪些部位、哪些做法）

3. 主要材料/机械消耗

4. 常见误用情形（什么情况下不该套这条）

5. 如果清单里套用错误，可能的修改方向

用造价人能看懂的语言，不要背条文。

PROMPT 08
清单遗漏检查

这条我最常用。 漏一次规费能少几十万，比套错定额还心疼。

PROMPT

这是一份清单。请按以下 6 类常见遗漏项检查：

1. 措施项目（脚手架、模板、垂直运输、超高、夜间施工）

2. 措施项目费（安全文明、二次搬运、冬雨季施工）

3. 规费与税金

4. 暂列金额、暂估价

5. 签证/变更预留

6. 竣工图、结算资料、保险

每类：列出该有哪些项 → 清单里有没有 → 漏了的话给出建议补充项。

03

PART

结算审查

SETTLEMENT · 3 Prompts

资料一堆、变更一堆、甲方一堆意见，光看就要看瞎。

PROMPT 09
资料完整性检查

甲方发结算资料过来，先判断齐不齐。资料不全，直接少钱。这张表 5 分钟出，省你一天翻资料。

PROMPT

这是甲方提交的结算资料目录：[粘贴目录]。

请从以下 8 项标准清单核对：

1. 结算汇总表

2. 工程量清单

3. 定额套用说明

4. 变更签证单

5. 材料调差依据

6. 索赔计算书

7. 图纸变更通知

8. 结算报告

列出：哪些齐了、哪些缺、缺的会不会被甲方反过来扣。

PROMPT 10
变更签证溯源

审计最爱砍的签证，就是这种「找不到源头」的。溯源之后，砍不动了。

PROMPT

这是变更签证单：[粘贴内容]。

请追溯：

1. 变更来源（图纸变更/现场指令/会议纪要）

2. 变更依据（合同哪一条）

3. 工程量增减是否与变更内容匹配

4. 是否超签证时限（合同规定 XX 天内）

输出一份溯源表，标出可能的问题点。

PROMPT 11
索赔条款反查

工期延误了，你要索赔工期和费用。索赔不是硬要，是先看合同允不允许。这张表能省你很多无用功。

PROMPT

请从合同里找出所有与索赔相关的条款：

1. 工期顺延情形（哪些情况可以顺延）

2. 费用索赔情形

3. 索赔时限（发生 XX 天内提出）

4. 索赔依据要求

5. 拒赔情形（哪些不能索赔）

针对本次延误原因：[描述原因]

给出索赔可行性判断 + 建议动作。

04

PART

签证单起草

SITE VISAS · 4 Prompts

一张签证写不清楚，后面扯皮 3 个月起。

AI 帮你写、帮你查、帮你改文字。工程量计算、签字盖章、送甲方盖章，这些线下动作还得你自己来。

PROMPT 12
签证理由起草

签证理由写得模糊，甲方一定卡你。

PROMPT

现场情况：[描述现场变更原因]。

变更依据：[图纸变更/甲方指令/会议纪要编号]。

请帮我起草一份签证理由，要求：

1. 客观陈述变更原因（不掺杂情绪）

2. 明确变更依据（引用编号）

3. 说明影响范围（部位、工程量）

4. 不涉及费用/工期主张（那部分单独写）

300 字以内，语言专业、简洁。

PROMPT 13
签证单正文生成

从零起草一份完整签证单。AI 帮你把骨架搭好，你填细节、盖章、送审。

PROMPT

项目：[项目名]

签证类型：[设计变更/现场变更/工程量调整]

变更依据：[图纸/指令/会议纪要编号]

涉及部位：[楼层/部位]

涉及工程量：[数量、单位]

请按标准签证单格式起草正文，包含：

1. 工程名称与签证编号

2. 变更原因与依据

3. 变更内容描述

4. 影响范围

5. 附件清单

用可提交给甲方的正式文本格式。

PROMPT 14
签证单要素检查

签字盖章前最后一关。漏一个要素，甲方就会卡。

PROMPT

这是一份签证单草稿：[粘贴]。

请从以下 8 项要素检查：

1. 签证编号是否规范

2. 变更原因是否清晰

3. 变更依据是否明确（编号/日期）

4. 变更内容是否具体（部位、工程量、做法）

5. 附件清单是否完整

6. 语言是否客观（无情绪词、无模糊表述）

7. 时间/地点是否明确

8. 签章栏是否预留

每项列出：有/无/模糊 → 建议补充。

PROMPT 15
签证单语言润色

手写草稿，甲方一看就觉得不正规。语言质感拉起来，别丢面子。

PROMPT

这是我手写的签证单草稿：[粘贴原文]

请润色为专业签证单文本，要求：

1. 用词专业（把口语改成书面语）

2. 结构清晰（一段一重点）

3. 客观陈述（去掉情绪词、主观判断）

4. 保留所有事实细节（不遗漏、不夸大）

5. 保持 300 字以内

输出润色版 + 修改对照说明。

05

PART

审计应答

AUDIT RESPONSE · 5 Prompts

审计来了，最怕的不是被砍，是不知道砍在哪、怎么回应。

PROMPT 16
审计问题拆解

审计 30 个问题，先分类再处理，比逐个应对省一半时间。

PROMPT

审计发来的问题清单：[粘贴]

请从以下角度拆解每个问题：

1. 审计依据（合同/定额/规范哪一条）

2. 问题的严重程度（必改/可辩/无据）

3. 我方应对策略（承认/反驳/补充依据）

4. 需要的支撑材料

输出应对策略表。

PROMPT 17
依据条款检索

甲方砍一个子目，你要有合同依据反驳。依据找不到，一切白搭。让 AI 帮你把「文件+条款号+原文」三层结构列出来。

PROMPT

审计质疑：[粘贴质疑点]。

请从以下 4 类里找出对应条款：

1. 合同条款

2. 定额说明

3. 图集规范

4. 招标文件/答疑纪要

每条注明：文件 + 条款号 + 关键原文。

PROMPT 18
反驳话术生成

谈判最怕没话讲。3 版话术，按场景切换。

PROMPT

审计砍点：[粘贴]

我方立场：[粘贴]

请生成 3 版反驳话术：

· 温和版（谈判初期）

· 中版本（僵持阶段）

· 强硬版（必要时用）

每版 100-150 字，专业、有据、不失礼。

PROMPT 19
材料索引整理

审计翻材料最怕「找不到」。这张表能让对方（也能让你自己）快速定位。

PROMPT

审计要的材料清单：[粘贴]

请按以下维度整理：

1. 材料名称

2. 来源（合同/变更单/发票/会议纪要）

3. 关键页码或编号

4. 存放位置

输出一张材料索引表，方便快速调取。

PROMPT 20
应答报告生成

审计的最后一关。这份报告是留档、也是复盘。

PROMPT

本次审计问答记录：[粘贴]

请生成一份审计应答报告，包含：

1. 审计问题清单

2. 我方应答要点

3. 依据条款索引

4. 最终结果（认可/调整/待协商）

5. 附：相关材料清单

输出格式：正式报告，可直接提交。
