# 养虾记 | 我用 OpenClaw 手搓了一个台账管理系统——初长成

原创 造价小龙虾 2026-05-28 08:28 广东

今天你养虾了吗？我用 OpenClaw 搭了一个全能台账系统。

5月11号那天，我跟 OpenClaw 说："帮我做一个造价咨询用的台账管理系统吧。" 它回了一个"好"，然后就开始写代码。十六天，从第一行 Java 到打包出 Setup 1.0.0.exe，从只能登录到现在的功能基本完整工作台——台账系统基本养成了。

睿唯造价助手，永久免费

现在这系统长什么样？

一句话说：它是一个可以自由设计、灵活录入、智能分析的项目台账工具。

核心三件套：

📋台账设计器
15种字段类型，想怎么搭就怎么搭。输入"合同金额"四个字，它自己就知道这是金额字段——250条词库帮你自动推断。

🗂️层级清单
多级展开收起，子行数据自动汇到父行。费用代码 + 公式联动，数量×单价=合价，改一个数全部跟着变。

🤖AI 助手
接 DeepSeek 或 MiniMax，用聊天的方式操作台账。"帮我把合同金额超过100万的行标红"——说句话就行。

📊项目仪表板
16种 Widget 随便拖，柱状图饼图看板甘特图，11个数据源即插即用。每个项目都能有自己的专属工作台。

还有 Excel 导出、台账关系图、任务管理、工作日志、文档版本管理、成本预算对比……功能列表跟超市货架似的，但我不想列了。

你只需要知道：一个造价咨询公司日常要用的台账场景，它基本都能兜住。

· · ·

手搓的体会

最大的感受是：OpenClaw 把"一个人做个系统"的门槛打到了地板上。

以前这种量级的项目，后端 Java + 前端 Vue + Electron 打包，没一个小团队搞不定。现在，我一个人，一个 AI 助手，十六天——从建表到生成安装包，全程没写一行代码。

但别误会，不是说不需要懂技术。你得知道什么时候该说"停，这个方案不对"，你得能看明白它写的 SQL 有没有性能坑，你得更清楚你想要什么——AI 是手，你的脑子才是舵。

我的角色：产品经理 + 架构师 + 测试。 OpenClaw 的角色：全栈开发。

它写的代码，差不多七成可以直接用，两成需要改，一成得推翻重写。但这就够了——那七成省下来的时间，比什么都值。

· · ·

初长成

虾不是一天养大的，系统也不是一天写完的。

现在这个版本，我叫它"初长成"——能用，好用，但还能更好。接下来要做的事还不少：审批流程、权限细化、多人协同……

但至少，从0到1的这段路，走完了。

下次再跟你聊，可能是一个月后的迭代，也可能是下一只新系统。
