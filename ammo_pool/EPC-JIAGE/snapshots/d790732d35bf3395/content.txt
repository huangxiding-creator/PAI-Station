# 六张网规划下的施工企业营销作战地图

原创 刘先胜 2026-09-03 06:30 江苏

当前六张网培训几乎全部拥挤在“政府/城投视角的项目谋划+资金申报”，施工企业“怎么接住政策红利、怎么营销突破”无人讲授，营销条线急需一门“自己人讲自己事”的课。

—— 把35万亿政策红利，变成你公司的真实订单（两天 · 模块化组合版）

课程背景

1. 万亿风口已来，但“看不懂、接不住”：2026年六张网投资超7万亿元、“十五五”总投资超35万亿元（发改委口径），水网、新型电网、算力网、城市地下管网、物流网、新一代通信网六大赛道同时开启。但施工企业普遍面临“7万亿不等于我能吃到”的结构性落差——机会高度结构化，而非普涨行情。

2. 甲方之变：三旧网（水网/地下管网/物流网）由各级政府财政主导，三新网（新型电网/算力网/通信网）由电网企业、运营商、云厂商等企业甲方主导。业主从“政府”变成“企业”，营销打法必须从政府公关切换为企业甲方营销。

3. 培训供给错位：当前六张网培训几乎全部拥挤在“政府/城投视角的项目谋划+资金申报”，施工企业“怎么接住政策红利、怎么营销突破”无人讲授，营销条线急需一门“自己人讲自己事”的课。

4. 一个真实的痛：某央企工程局在2025年某省新型电网配网市场，仍沿用多年的政府公关打法，但这一局业主换成了省网公司、招标改为评定分离；该企业既没进省网供应商库、定标前也没出现在前期策划会，最终眼睁睁看着订单被一家做“两建本地支点”的省建工联合体拿走——它丢的不是几个标，而是整片区域市场的长期入场券。这正是六张网时代“甲方变了、打法没变”的典型代价。

5. 本课定位：这不是又一门政策解读课，而是一场施工企业视角的“营销突围战”——讲清“机遇在哪、凭什么入场、每网怎么打、一线怎么拿项目”，把七万亿政策红利翻译成你能带回公司的作战地图。两天八模块，前半段看清行情与重点网，后半段沉到一线营销实战。

课程收益

1. 一张图看懂六张网：规模量级、省域高地、甲方之变、入场门槛，破除“普涨幻觉”。

2. 掌握三旧+三新差异化打法：财政资金网 vs 企业投资网，营销逻辑如何切换，避免“用政府公关打企业甲方”的代价。

3. 拿到物流网、水网两张重点网的深度作战地图，其他四张网可据需选配分网大纲灵活组合。

4. 学会一线拿项目实战打法：华为铁三角协同、大客户决策地图、从线索到回款（即商机到收款的全流程），把六张网项目真正变成合同。

课程对象及授课方式

课程对象

1. 施工企业市场营销/经营管理条线负责人及骨干；

2. 工程局/省建工集团区域公司、分公司经营负责人；

3. 项目经理（承担营销职能者）、战略规划与新兴业务拓展人员；

4. 适用对象涵盖央企工程局及二级单位、省级建工集团、专业施工与联合体单位。

课程大纲

模块一看懂六张网：为什么看了规划仍拿不到单？（约2小时）

【模块引言】你所在的工程局，今年有没有因看不懂六张网、慢了半拍而丢过单？这不是又一门政策科普课，而是一场"看懂行情、抢回订单"的营销突围战。这一节我先帮你把六张网的"共同地图"铺开，并回答三个问题：六张网到底是什么、钱到底砸在哪、凭什么轮到你。

1. 六张网的政策坐标与万亿量级：2026年4月28日中央政治局会议官方定义（水网、新型电网、算力网、城市地下管网、物流网、新一代通信网），“十五五”总规模超35万亿、2026年超7万亿的底层逻辑。

2. 三旧+三新结构：资金属性（财政 vs 企业）、甲方主体（政府 vs 电网/运营商/云厂商）、营销打法的本质分野——三旧网靠政府关系与资质，三新网靠企业甲方经营与能力入围。

3. 总规模与省域叠加高地：水网十五五超6万亿、新型电网超5万亿、城市地下管网77万公里超5万亿、算力网全产业链约6万亿、通信网上下游约7万亿、物流网152承载城市+229国家枢纽；山东、河南、四川、湖北、浙江、广东、河北、安徽为六网机会密度最高的布局地图。

4. 入场门槛分级与机会矩阵：高门槛（特高压/重大引调水/核电送出，封闭市场）→ 中门槛（配电网、地下管网改造、智算中心土建机电、物流枢纽场站）→ 低门槛（县域管网、农村供水、通信线路配套、小型水利）；六网×企业类型×切入角色的机会矩阵。

5. 三条共性铁律：资质提前布局（周期长、现在就要动）、区域跟着钱走、现金流是生死线。

6. 结构化机会 vs 普涨幻觉：机会按网、按省、按企业类型高度分化，“7万亿”不等于“我能吃到”。

【模块小结】你将带走“三旧三新框架+机会矩阵地图”，建立六张网共同语言，作为后续各模块讨论的统一底图。

模块二物流网：最友好的万亿赛道，怎么挤进去？（约2小时）★重点网

【模块引言】物流网是六张网里对你最友好的赛道——多数单位资质可承接、门槛中低、规模量大，但很多公司却在"最该拿的订单"上慢了半拍。这一节我不重复铺行情，直接给你一张"怎么挤进去"的作战地图，回答四个问题：决策链怎么摸、入围门槛怎么跨、差异价值怎么讲、攻单节奏怎么排。

1. 规模与省份锚点复现（约15分钟）：物流网建设实施方案2026年8月底落地、布局152个承载城市+229个国家物流枢纽，投资量级以千亿计、存量补短板空间大；枢纽集群集中于长三角、珠三角、成渝、中原及省域8高地（山东/河南/四川/湖北/浙江/广东/河北/安徽）。详细规模与省份清单见独立《物流网分网大纲》，本模块聚焦作战地图。

2. 作战地图之一·决策链与关键触点：发改/交通规划线（枢纽申报期）→ 城投/枢纽运营公司（业主）→ 总包定标方；内线必须落在规划线与运营公司前期，而非等招标公告。

3. 作战地图之二·入围条件：房建+市政混合资质、属地信用分（历年优质工程奖持续累积）、属地业绩门槛；在评定分离（评标与定标分离，信用分与价值主张权重上升、低价不再唯一中标依据）下，信用分权重高，是省建工守住属地订单的核心护城河。

4. 作战地图之三·差异价值主张：智能仓储工艺、低碳建造、交付时效、运营期配套能力；用“价值”而非“低价”在评定分离中胜出。

5. 作战地图之四·攻单节奏：申报期介入（规划线情报）→ 可研策划（场站方案）→ 评定分离价值营销（信用分+联合体分工）→ 运营期二次开发（枢纽延伸项目）。

6. 标杆打法（隐名不隐战果）：某省建工在评定分离下以历年优质工程奖持续堆高信用分、联合央企总包分工，守住属地物流枢纽场站订单、避开正面价格战——把枢纽集群当“一张图”连续经营，而非逐标攻。面对央企总包价格战，它以“属地信用+联合体”守住了本该流失的份额。

【模块小结】你将掌握物流网“决策链—入围—价值—节奏”四要素作战地图，能识别本公司可切入的子赛道与攻单路径。

模块三水网：6万亿里，你的位置卡在哪一段？（约2小时）★重点网

【模块引言】水网体量大、但专业壁垒差异也大——重大引调水高门槛，灌区与农村供水却很低，多数公司都能找到一个切口；难点是"在哪下嘴"。这一节我直接给作战地图，回答三个问题：决策链怎么摸、前期怎么介入设计院、价值怎么讲在定标前。

1. 规模与省份锚点复现（约15分钟）：十五五水利投资超6万亿，涵盖重大引调水、流域综合治理、大中型灌区、农村供水与智慧水利；水利大省四川、安徽、山东、广东、湖北、江苏、浙江、河南投资密集。详细清单见独立《水网分网大纲》。

2. 作战地图之一·决策链与关键触点：水利厅局/流域机构（规划线）→ 水利设计院（方案内线）→ 业主定标方；内线在水利设计院，前期介入方案即提前锁定定标。

3. 作战地图之二·入围条件：重大引调水高门槛（业绩为王，强手环伺）；中小项目看属地信用；电建系凭设计施工一体化领跑。

4. 作战地图之三·差异价值主张：低碳施工、智能建造、全生命周期成本、流域治理政绩；把价值讲在业主定标前。

5. 作战地图之四·攻单节奏：规划线情报 → 设计院前期介入（把价值讲在定标前）→ 评定分离价值营销 → 在建口碑撬动后续标段与流域连片项目。

6. 标杆打法（真实战报迁移）：某工程局在重大引调水项目上，用“前期介入设计院方案、把低碳与智能建造价值讲在定标前”的打法，从强手环伺中逆势入围，并转化为后续标段、形成流域连片经营——印证“业主定标前出现、而非招标后才投”能锁定大单，这套逻辑同样适用于地下管网、物流枢纽等需前期策划的赛道。

【模块小结】你将识别本公司可切入的水网子赛道（重大引调水/流域治理/灌区/农村供水/智慧水利），并形成“前期介入设计院”的阶段突破路径。

模块四甲方变了：老一套大客户策略还灵不灵？（约2小时）

【模块引言】光懂政策不够。你过去那套"大市场、大项目、大业主"打法，在六张网还灵不灵？这一节帮你判断：甲方变了之后，老策略该留还是该弃；你又该把自己摆成领导者、跟随者还是挑战者。

1. 大市场、大项目、大业主策略在六张网还有效吗：三新网甲方是企业（电网/运营商/云厂商），不再是单一政府业主，策略必须从“政府公关”切换为“企业甲方经营”。某央企工程局2025年某省配网市场仍用政府公关，业主已换省网公司+评定分离，份额被“两建本地支点”省建工联合体拿走——印证“甲方变了、打法没变”的代价。

2. 新基建、新质生产力下六张网的机会坐标：算力网与新型电网是增量主战场，水网与地下管网是存量升级，物流网是枢纽补短板——施工企业要分清“增量抢位”与“存量深耕”。

3. 存量市场下既不能守旧也不要盲目创新：在六张网里选赛道要讲定位——领导者（如两建在电网/水网）、跟随者（省建工做属地支点）、挑战者（专业公司找缝隙市场）。某建材类央企三年净利从赚6.45亿到亏7.30亿，根子在应收账款减值而非运营亏损——提醒“接不住项目”与“接了不赚钱”是两件事，营销要算现金流生死线。

4. 中国不缺施工队：六张网的真正壁垒是“懂甲方+懂技术+懂资金”，低价中标正在被评定分离、价值营销取代。

5. 把握宏观机会：从“经营项目”到“经营客户”——六张网业主（省网公司、三峡、云厂商、水利厅）是长期战略客户，要当大客户经营而非一个个项目投。

【模块小结】你将形成自身在六张网赛道中的定位判断（领导者/跟随者/挑战者），明确“增量抢位 vs 存量深耕”策略。

模块五领导者还是跟随者？先看清六张网业主图谱（约2小时）

【模块引言】六张网的业主，从"政府"变成了"电网、运营商、云厂商"——你有没有发现，用同一套话术打所有甲方，越来越吃力？这一节帮你看清每张网的业主长什么样、决策链通到哪、他们真正在意什么，让你"见人说人话"。

1. 六张网业主分类：政府（水网/管网/物流的财政部分）、电网企业、运营商、云厂商/IDC（互联网数据中心）、城投平台——每类业主的决策链与诉求完全不同。电网业主定标权在省网物资/建设部门+评定分离委员会；云厂商定标权在基建/采购+技术标准部门，两者触点与话术迥异。

2. 不同投资主体诉求分析：财政资金看合规与政绩；电网看并网安全与保供；运营商看覆盖与时效；云厂商看算力交付与PUE（电能使用效率，越低越省电、越受青睐）；诉求差异决定营销话术差异。

3. 知己知彼：系统分析自己（资质业绩短板）、对手（两建/央企/本地强企）、客户（隐性痛点），找到“我能赢的战场”。

4. 企业自身定位策略：领导者用标准与业绩卡位、跟随者做属地信用支点、挑战者以专业+价格切入低集中度赛道（如充换电、微电网、配网智能化）。

5. 工程营销不仅是投标：覆盖产品展示与技术支持、投标报价与商务谈判、合同签订、项目实施、交付维保五环节的全周期客户经营。

【模块小结】你将掌握各类业主的决策链与诉求差异，能针对不同业主准备差异化营销材料。

模块六从线索到回款：定标前如何提前半年卡位（约2小时）

【模块引言】前面讲"在哪打"，这一节讲"具体怎么打"。你最该问的是：怎么比对手早半年知道项目、首访怎么不被客客气气送走、投标怎么不再靠低价死磕？我逐一拆解从线索到回款的六个环节，每节都落到六张网真实卡点。

1. 项目线索三大来源（结合六张网）：政策线（规划与申报）、审批线（可研→初设→用地→招标四节点）、资金线（国债/专项债/企业投资计划）；建立“审批线情报”机制，在业主定标权形成前就进入。某单位对电网项目跟踪可研→初设→用地→招标四节点，在省网公司前期策划会出现并锁定定标，把“招标后才投”提前为“定标前已经营”。

2. 首次拜访客户印象管理与策划：针对六张网不同业主差异化准备——对水利厅讲流域治理政绩、对国网讲并网保障、对云厂商讲交付时效与PUE（电能使用效率，越低越省电）。

3. 企业展示与技术支持：用“局长的语言讲技术”，把专业能力翻译成业主关心的政绩、安全、ROI（投资回报）。

4. 投标报价与商务谈判：评定分离下做价值营销而非价格营销；原则式谈判借力联合体而非硬碰硬。物流网评定分离中，信用分+优质工程奖决定胜负，低价反而出局。

5. 项目实施中的分层定期交流与客户期望管理；让客户惊喜的交付仪式与维保快速反应，撬动二次开发。

【模块小结】你将把六张网项目纳入“审批线四节点跟踪”机制，建立从“招标后才投”到“定标前已经营”的提前量打法。

模块七别人怎么逆势拿单：3个真实作战样本（约2小时）

【模块引言】方法论讲再多，不如看别人怎么逆势拿单。这一节我用三个真实作战样本，把"逆势入围"拆开给你看——算力网怎么进云厂商库、电网怎么当两建本地支点、水网怎么前期介入设计院；最后再补一节"怎么比对手早半年知道项目"。

1. 算力网真实打法（某单位云厂商IDC切入）：以云厂商IDC土建机电总包切入，通过供应链入围与差异价值主张（低碳建造、交付时效）拿到智算中心订单，并把省网绿电直连逻辑平移到数据中心用能——证明“绑定云厂商生态+能力入围”能突破相对封闭的供应商库，是施工企业切入算力网的主路径。

2. 新型电网真实打法（省级建工做两建本地支点）：不与能建抢特高压设计，做其不愿做、国网系做不过来的配网与属地协调，成为两建进本省的总包支点；在评定分离下以属地信用分守住配网订单。

3. 水网真实打法（某工程局前期介入设计院）：在重大引调水前期介入设计院方案，把低碳施工与智能建造价值讲在业主定标前，从强手环伺中逆势入围并转化为后续标段——关键在于“定标前已经营”，而非等招标公告出来才投，这正是比对手早半年的核心。

4. 六张网线索获取的情报战（国内视角）：怎么比对手早半年知道项目——①设计院/规划院早期情报网（可研、初设阶段就拿项目清单）；②发改、财政申报窗口与规划发布跟踪（政策线情报）；③业主前期策划会与评标办法征求意见稿提前介入（审批线情报）；④行业协会、招标代理圈子关系情报；⑤竞争对手动态监控（对手在盯哪些网、哪些省）。区别于模块六“线索三大来源”的流程框架，本段聚焦“情报网怎么建、项目怎么早知道”。

5. 思维迁移示例：中建三局总承包“一园三标”——不押注单一行业、押注园区本身，同个工业园拿下印刷、家电、包装三个不同业态项目。可迁移到片区综合开发、城市更新、TOD枢纽等场景，把“押注园区/枢纽”延伸到“一张图规划多个相邻项目”，避免把每个项目当独立单元逐个攻。

【模块小结】你将从真实战报中识别可迁移打法（能力入围、本地支点、前期介入、情报网建设），并理解“一园三标”作为园区思维的迁移价值。

模块八AI+铁三角：画出你的六张网作战地图（约2小时）

【模块引言】AI不是噱头，它把情报工作从"人肉搜"升级成"智能研判"，是六张网营销的杠杆放大器。这一节我带你用 AI+华为铁三角，现场画出你公司的六张网作战地图，带走一份能落地的切入计划。

1. 用AI（DeepSeek）分析对手公司与标杆客户关系运作方法，把情报工作从“人肉搜”升级为“智能研判”。

2. 客户内部权力地图与主要诉求分析：识别真实决策者、影响者、使用者、把关者，发展内部教练（能在关键节点透底、影响决策的关键人），落到六张网各类业主的决策链（省网物资/建设部门、云厂商基建/采购、水利厅/流域机构）。

3. 华为铁三角在六张网营销落地：AR（客户负责人）/SR（方案负责人）/FR（交付负责人）协同，把省网公司、三峡、云厂商当“战略大客户”经营，而非“一个一个项目投”。

4. 从线索到回款（即商机到收款的全流程）：六张网项目三线跟踪（政策线/审批线/资金线）→ 关系深化 → 投标策略 → 二次开发与转介绍。

5. 行动工作坊：每组选定一张重点网，现场画出“本企业六张网营销作战地图”（决策链—内线—入围—差异价值—攻单节奏），产出可带走的“本企六张网切入计划”。

【模块小结】你将带走一份“本企业六张网营销作战地图”+30天行动清单，可直接落回本企业执行。

模块化组合与定制说明

1. 本课纲为两天主版本（八模块），物流网、水网已作深度模块；六张网均另有独立1.5小时分网大纲（城市地下管网、新型电网、算力网、新一代通信网、物流网、水网），可据客户行业与痛点灵活选配组合；如需单网深拆，可直接采用对应分网大纲。

2. 内训定制：课前进行课前调研，（公司经营/市场布局/营销痛点/重点赛道），讲师据以调整案例与演练；可深拆客户相关的1至3张网、带入真实在跟踪项目做作战地图工作坊。

3. 时长弹性：若客户要求六网全深拆或更多工作坊，可在模块二/三增配分网大纲、模块八增半天实战，扩展为两天半至三天，具体以课前沟通为准。
