# 国务院 24 号文｜60 日付现、商票锁 6 个月 ，施工企业该怎么用？

马楠讲造价 2026-09-18 10:51 北京

做工程的人，对回款难三个字都不陌生。

活干完了，验收拖着；验收过了，结算拖着；结算定了，付款还是拖着。好不容易等来一张商票，兑付日期又写在半年以后。一层压一层，最后压到分包、材料商和农民工头上。

9月10日，国务院办公厅发布《关于加强中小企业回款难问题治理有关工作的通知》（国办发〔2026〕24号）。9月14日，国新办举行政策例行吹风会，工信部、央行、国资委、市场监管总局、证监会五部门同台解读。

一份文件，四方面10条措施。它不是第一次提及时付款，但这一次，把该付多少、多久付、不付怎么办写进了可执行的机制里。

对工程领域的施工企业，尤其是做分包、专业承包的中小玩家，这份文件值得逐条读。本文不讲空话，只讲三件事：文件到底改了什么、施工企业能用到什么、哪些地方别高兴太早。

Part.01

这份文件的分量

从倡导到可执行

治理拖欠不是新话题。2025年修订后的《保障中小企业款项支付条例》施行，已经从法规层面立了规矩。24号文的意义在于，它没有重复应当及时支付这类倡导性表述，而是往机制和穿透监管上走了一步。文件围绕造成回款难的堵点，搭了四根柱子：

第一根

健全行业账款支付规则——分行业明确账期，把付款关键要素写进合同示范文本。

第二根

加强大型企业支付行为监管——约谈、执法、披露三管齐下。。

第三根

规范管理非现金支付工具——管住商票和电子凭证这两个拉长账期的核心手段。

第四根

强化资金传导效能和融资支持——让钱从业主到总包到分包真正流下去。

Part.02

最核心的一条

60日付现，到底是什么意思

文件第一条就提出了一个概念——付款四项关键要素：账期起算节点、账款支付方式及流程、货物和服务检验验收（或工程竣工结算）标准及期限、最长付款期限。这四个要素，恰好对应施工企业被拖欠的四个常见套路：

01

模糊起算节点

合同写验收合格后付款，但验收合格哪天算？业主迟迟不组织验收，账期就永远不起算。

02

支付方式模糊

合同写支付工程款，但没写现金还是商票，最后给你一张半年后到期的商票，你还没处说理。

03

拖延竣工结算

工程交付了，结算审计算个一年半载，付款自然跟着拖。

04

不设最长期限

工程交付了，结算审计算个一年半载，付款自然跟着拖。

24号文要求把这四项要素纳入合同示范文本，就是要堵这些漏洞。

落在数字上，是两个关键表述：

第一，引导大型企业将对中小企业最长付款期限限制在60日内。注意用词是引导，不是强制。但配合后面的约谈、执法、披露机制，这个引导有牙齿。

第二，推动龙头企业率先践行60日付现承诺，即自货物、工程、服务交付之日起60日内以现金方式支付。这是承诺制，龙头企业带头，行业跟进。

还有一条兜底条款，施工企业务必注意：对合同中未明确支付方式的，机关、事业单位、大型企业均使用现金支付中小企业账款，不得以商业汇票或电子凭证等替代支付。

这条的杀伤力在于，它把支付方式约定不明的后果直接落到了付款方头上——没写清楚，就必须给现金。过去很多合同在支付方式上故意留白，现在这条路被堵了。

工信部副部长柯吉欣在吹风会上说得直白：部分大型企业利用行业暂未出台专门结算支付规则的漏洞，通过模糊账期起算节点、拖延验收或结算、滥用商票和电子凭证故意拉长上下游中小企业账期。把付款四项关键要素纳入合同示范文本，正是要填补这个空白点。

Part.03

商票和电子凭证

被戴上了紧箍咒

0

1

期限卡死

电子凭证最长付款期限压减至6个月。电子凭证服务平台不得新开立付款期限超过6个月的电子凭证，商业银行、商业保理公司不得为超期电子凭证提供融资。

这意味着，过去那种开一张一年甚至更长期限的电子凭证、把账期无限滚下去的做法，从平台端和融资端都被堵死了。

0

2

规模压降

监测过度使用商业汇票和电子凭证的大型企业，督促压降业务规模。同时明确：大型企业不得强制或变相强制中小企业向其关联的商业保理公司进行应收账款融资。

最后一条尤其值得注意。实践中，不少总包方开了电子凭证后，又要求分包方去自己关联的保理公司贴现，两头收手续费。24号文直接禁止了这种操作。

0

3

数据穿透

电子凭证服务平台要把经营数据全量接入上海票据交易所，由票交所跨机构、全口径监测大型企业商票和电子凭证开立情况。付款逾期的，由票交所和平台分别披露，逾期企业停止提供新开立服务。

Part.04

监管怎么落地

约谈、执法、披露三把抓手

0

1

监测约谈

建立大型企业账款监测机制，重点关注应付账款规模大且现金类资产充裕的大型企业——说白了，就是有钱不还的企业。对故意拉长账期的，行业主管部门、央行、市场监管总局等联合约谈；拒不改正的，联合惩治；严重失信的，在信用中国网站公示并实施失信惩戒。

0

2

反不正当竞争执法

文件要求细化反不正当竞争法第十五条执法指引。对大型企业通过模糊账期起算节点、拖延验收或结算、使用商票或电子凭证变相延长付款期限等滥用优势地位故意拉长账期的行为，查实后依法处罚并公开曝光典型案例。

这一条的法律意义在于，它把故意拉长账期从商业道德问题上升到了不正当竞争行为的高度，有了明确的执法依据。

0

3

信息披露

应付账款达到一定规模的上市公司，要披露主要账款支付方式、平均账期、商票和电子凭证开立情况；发债企业也要加强披露。账期长、非现金支付占比高的，被引导逐步压减账期、提高现金支付比例。

从倡导到执法加曝光，威慑明显升了一级。

Part.05

工程链条被重点点名

央企、政府项目、分包一个不落

1

央企当表率

中央企业率先在合同中明确付款四项关键要素，对中小企业全部采用现金支付，对大型企业保持合理现金支付比例。违约拖欠发现一起、清偿一起，并严肃追责问责。

监管还用上了技术手段：运用司库系统对央企及各级子公司应付账款支付情况、商票和电子凭证开立情况实施穿透式监管。各地国资监管企业参照执行。

0

2

分包链条被单独拎出来

对大型企业承揽央企项目后分包实施的，央企应在合同中要求总承包单位向分包单位及时支付账款且保持同等现金支付比例。

这一条的逻辑很清楚：央企不能只保证自己给总包付了钱就完事，还要盯着总包把钱付到分包。同等现金支付比例意味着总包不能自己拿现金、给分包开商票。

0

3

政府投资项目单列

政府采购项目全额采用现金支付；政府投资项目业主单位优先采用现金支付，并推动项目总承包单位及时向分包单位支付不低于同等比例的现金。

已竣工但未结算支付的存量政府投资项目，要尽快完成竣工财务决算并支付工程款，推动总包尽快向分包支付，带动农民工工资支付。

Part.06

施工企业实操清单

五件事现在就可以做

0

1

合同审查，补上付款四项关键要素。

翻一翻正在签的合同和在手合同，账期起算节点写清楚了吗？支付方式写的是现金还是可以用商票？竣工结算期限有没有约定？最长付款期限是多少？这四个地方模糊的，尽快通过补充协议明确。示范文本出来后，尽量拿它当底稿。

0

2

收到商票或电子凭证，先核期限。

超过6个月的电子凭证，平台不能新开、银行不能融资，有兑付和融资双重风险。能争取现金就争取现金，实在要收，把期限和贴息成本算清楚。

0

3

在手的政府项目、央企项目欠款，该主张就主张。

24号文给了明确的清偿路径和监管抓手——全国违约拖欠中小企业款项投诉平台在运转，信用中国公示机制在运转。别碍于关系一直忍着，投诉和催告本身就是证据。

0

4

自身也要及时支付下游。

政策对全链条现金支付有要求，央企总包一定会向下传导。分包、材料商、农民工工资这一环拖不得，否则上游的合规压力会变成对你的违约追责。

0

5

保留好合同、验收、结算、催款证据。

维权有抓手，关键是企业自己得把材料攒齐。交付记录、验收申请、结算报送、催款函件，每一步都留痕。真到了投诉、仲裁或诉讼阶段，证据链比政策条文更管用。

Part.07

别高兴太早

三个边界要看清

0

1

60日是引导，不是一刀切的法律强制。

文件对大型企业用的是引导将最长付款期限限制在60日内推动龙头企业率先践行承诺，措辞是引导和推动，不是法律层面的强制性规定。真正有强制力的是机关、事业单位——《保障中小企业款项支付条例》对它们有明确的法定期限要求。对民营大型企业，更多靠约谈、执法、披露的组合压力来推动。

0

2

执行效果取决于后续细则。

24号文提到制定完善本行业领域结算支付管理规定制定《保障中小企业款项支付条例》配套规定细化反不正当竞争法第十五条执法指引。这些配套规则什么时候出、口径怎么定，直接决定文件的落地力度。住建领域的结算支付规定尤其值得关注。

0

3

中小企业身份有认定标准。

文件保护的是中小企业，不是所有施工企业。根据《中小企业划型标准规定》，建筑业中小企业有营业收入和资产总额的双重门槛。企业在主张权利时，需要确认自身是否符合中小企业划型标准，这是适用相关保护条款的前提。

建企及造价专业人士

近期面对的挑战及应对
