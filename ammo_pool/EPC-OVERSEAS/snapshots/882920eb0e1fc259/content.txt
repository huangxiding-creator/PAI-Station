# 7 家候选，4 家央企直接淘汰！河南本土建企中标三门峡2.5亿管廊EPC大项目

原创 建设汇 2026-10-03 20:08 河南

9月21日开标、9月29日15:30定标，三门峡陕州区先进制造业开发区基础设施及综合管廊项目设计施工总承包（项目编号 SGZ[2026]257-GC044）走出一条教科书级样本。项目总投资 2.5亿元，资金来源为自筹、地方政府专项债券与市场化融资三层拼盘，采用评定分离、核查随机法定标。最值得玩味的是：7家候选人经核查，4家央企及大型建企因非价格原因被直接淘汰，最终由河南本土企业河南锦路路桥建设有限公司（牵头）+ 大连市市政设计研究院以 10.122%审计优惠率中标。读懂这单，等于读懂河南当下"低资质门槛、高合规淘汰"的拿单逻辑。

一、最终定标结果：本土施工企业逆袭

中标人组合为河南锦路路桥建设有限公司（牵头人）与大连市市政设计研究院有限责任公司（成员），投标报价即审计金额优惠率 10.122%，计划工期300日历天（其中设计工期50天），项目经理杨斌（二级建造师，豫241212296252），设计负责人于弯（高级工程师），技术负责人李炫颉（工程师）。

资质门槛"低开"——施工只需市政公用工程总承包贰级及以上，设计需市政行业甲级（或综合甲级）。正是这道低门槛，让河南本土市政企业第一次和央企站在同一起跑线。资金拼盘为自筹 + 专项债 + 市场化融资，与9月30日农发行认领六张网主办行、推出含前期贷的四种融资工具形成呼应。

值得注意：最终赢家优惠率仅 10.122%，低于多家被淘汰者的报价区间。这意味着在本项目定标逻辑里，价格不是决胜项，"先过核查关"才是。低价者若倒在核查环节，连随机抽签的入场券都拿不到。

二、核查随机法淘汰了谁：7进3，4家全栽在合规

定标委员会对7家中标候选人逐一核查，结果4家不通过、3家进入定标程序。被淘汰的4家，没有一家因报价高，清一色倒在形式与合规红线：

1. 中铁十一局集团第五工程有限公司（牵头）+ 天津市政工程设计研究总院

成员单位的法人证明、身份证扫描件非本单位法定代表人（于立军）签署"属实"并签字或盖法人章；授权委托书中代理人"余玲玲"非成员单位员工。形式签署瑕疵，核查不通过。

2. 中铁二十五局集团有限公司（牵头）+ 中铁第五勘察设计院

技术标正文中多处出现"集团""院主管"等个性化文字，P336页出现"信阳市"字样，违反技术部分暗标规定；设计周期填90天，未响应招标文件要求的50天。暗标违规 + 工期未响应，核查不通过。

3. 宇杰集团股份有限公司（牵头）+ 长沙市市政工程有限责任公司

投标保证金未按招标文件要求附系统内下载的投标保函回执，不符合投标文件格式要求，核查不通过。

4. 三门峡市源泰市政工程有限公司（牵头）+ 郑州一建集团有限公司

工期填365天、设计工期90天，未响应300天（设计50天）要求；技术标P111页出现"日本、台湾省、欧美"等字样，违反暗标规定。核查不通过。

通过核查进入定标程序的3家全部为"河南本土施工企业 + 设计院"组合：河南讯迹建筑工程 + 河南省城乡规划设计研究总院、河南若航建筑工程 + 郑州市市政工程勘测设计研究院、河南锦路路桥建设 + 大连市市政设计研究院。最终从中产生中标人。

三、中标策略启示：核查随机法下，"零瑕疵"胜过"血价"

1. 形式零瑕疵是入场券。暗标规定（投标人须知9.10条）、工期响应（设计50天/总300天）、法人证明与授权委托的签署主体、投标保函回执——任何一项疏忽直接出局，且与价格无关。中铁等大型建企的翻车，全在标书生产流程的"最后一公里"。

2. 优惠率不是越低（让利越少）就一定输，但别盲目报高价。赢家10.122%的优惠率并不激进，却稳稳中标。核查随机法下，定标在"合格池"内择优或随机，先确保进池，再谈价格策略；把精力从"压价"转向"保合规"，性价比更高。

3. 暗标是央企翻车重灾区。技术标个性化文字、"信阳市"等地名泄漏、工期数字写错——大单位的标准化模板反而在多项目并行时易踩雷。建议投标前做暗标专项清洗：全篇去标识、统一工期口径、交叉复核页码。

4. 联合体"施工牵头 + 设计补位"是标配。本项目要求联合体≤2家、施工企业任牵头人。最终赢家即"河南本土施工 + 外地甲级设计院"组合，既满足资质又控成本，是中小施工企业借力拿大单的成熟路径。

5. 低门槛 ≠ 好拿单。市政贰级即可投，看似窗口大开，但核查淘汰机制让"能投"不等于"能中"。拼的是标书质量、合规精度与联合体组队，而非单纯资质或报价。

四、建筑企业投标前"核查清单"

1. 暗标合规：技术标全文去标识，无企业名、无地名、无个性化表述，页码与格式统一。

2. 工期响应：严格照抄招标文件数字（设计50天、总300天），不得自行换算。

3. 授权与签署：法人证明、授权委托书须由对应单位法定代表人签署"属实"，代理人须为本单位员工并附社保。

4. 保函回执：投标保证金须附系统内下载的投标保函回执原件扫描，不得用自制函件替代。

5. 联合体协议：牵头人为施工企业，各方资质分别满足，不得再单独或重复组团投标。

五、与六张网脉络呼应：城市地下管网赛道刚起步

本项目属六张网中的城市地下管网赛道，资金端"自筹 + 专项债 + 市场化融资"的组合，正与9月30日农发行河南省分行认领"六张网建设主办行"、推出含前期贷款的四种融资工具形成闭环。对建筑企业而言，帮平台公司做资金方案、把专项债与前期贷写进投标拼盘，是继"合规过关"之后的第二层加分项。
