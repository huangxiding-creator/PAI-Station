# 老客户第二次发来询价，为什么反而更难成交？

原创 云中浩 2026-09-17 07:00 山东

做工业外贸，很多人都觉得：

第一次订单最难。

陌生客户不认识你，不知道你的产品，也不知道中国供应商靠不靠谱。

所以好不容易做完第一单，大家都会觉得：

“以后就简单了。”

其实不一定。

有时候第二次询价，反而更难。

因为客户已经知道你的价格。

知道你的交期。

知道你的付款条件。

知道你上一次做出来的设备怎么样。

甚至手里还拿着你上一张PO。

这时候客户一句：

“Please quote the same unit as last time.”

看起来特别简单。

但真正麻烦的地方，恰恰在这个“same”。

真的还是同一台吗？

一、客户说“和上次一样”，千万别直接复制上一份报价

这个坑我觉得工业外贸人很容易踩。

客户：

Please quote the same heat exchanger as last time.

销售打开电脑。

找到上一份报价。

复制。

改一下日期。

发出去。

看起来效率很高。

但工业设备最怕这个。

因为客户说的“same”，可能只是：

设备类型一样。

并不代表所有参数都一样。

比如上一台板式换热器：

热侧流量50 m³/h。

冷侧流量60 m³/h。

设计温度120℃。

316L板片。

EPDM垫片。

这次客户可能只是说：

“Same type.”

但实际项目的流量可能已经变成70 m³/h。

介质也可能变了。

温度变了。

压力等级变了。

甚至安装空间都变了。

如果你直接按照上一台报价，最后很可能变成：

客户以为你已经确认了技术条件，你以为客户只是要一个价格。

这就麻烦了。

二、所以第二次询价，我通常会先确认一句

我不会马上报价。

我会先问：

“Is this for the same application and operating conditions as the previous order?”

如果客户回答：

Yes, same application.

那再继续确认几个关键参数。

不用重新问客户一百个问题。

就抓变化最大的几个：

Flow rate

Inlet / outlet temperature

Operating / design pressure

Fluid

Material requirement

如果这些都没变化，再考虑是不是可以直接沿用上一单的设计。

这样既专业，也不会让客户觉得你故意把简单事情搞复杂。

三、还有一种情况：客户其实是在“拿你上一单的价格做锚点”

这个就比较有意思了。

客户可能直接说：

“Last time you quoted USD 4,800. Can you give me the same price?”

这时候不要马上回答：

“Yes, same price.”

也不要马上说：

“Price increased.”

先看看为什么。

钢材价格有没有变化？

板片厚度有没有变化？

数量有没有变化？

运费有没有变化？

汇率有没有变化？

交期有没有变化？

付款条件有没有变化？

最关键的是：

这一次到底是不是同样的采购条件？

比如上一单只有一台。

这次客户要5台。

那其实是一个谈价格的机会。

你可以反过来问：

“Is the quantity five units for this project?”

如果确实是5台，就可以重新核算。

这时候你的谈判就不应该是：

“我能不能少100美元？”

而应该是：

“这次采购数量增加以后，我们能不能通过批量生产降低单台成本？”

这就完全不一样了。

四、第二次订单，我反而不建议一上来就谈价格

为什么？

因为客户已经买过你的东西。

你其实有一个优势：

你知道他的采购习惯。

比如上一单客户特别在意：

交期。

第三方检验。

木箱包装。

某个特殊材质。

某些文件。

那这次就应该主动把这些东西考虑进去。

甚至你可以告诉客户：

“We have kept the same material and inspection requirements as your previous order.”

这种话其实很有用。

客户会感觉：

你不是刚刚才认识我。

你记得上一单。

这就是老客户和新客户最大的区别。

五、我觉得第二次订单最值得做的一件事，是“找变化”

第一次订单，你是在搞清楚：

客户是谁。

第二次订单，你应该开始搞清楚：

客户发生了什么变化。

比如第一次：

采购1台。

第二次：

采购3台。

这可能意味着客户项目增加了。

第一次：

板式换热器。

第二次：

又问管壳式。

这可能意味着客户的应用范围扩大了。

第一次：

终端项目。

第二次：

让你直接给他们公司报价。

这可能意味着你开始进入他们的供应商体系。

所以不要只盯着这一张询价。

有时候客户采购行为的变化，本身就是信息。

六、还有一种情况，我特别建议注意：客户突然只问价格

比如以前客户会发：

Please quote according to the attached specification.

这次突然变成：

“How much for a 316L plate heat exchanger?”

就一句话。

这时候不要因为是老客户，就觉得：

“反正以前合作过，报个大概价格吧。”

最好还是问一句：

“Could you please share the duty and operating conditions so that we can offer the correct model?”

因为这次可能根本不是正式项目。

也可能客户正在做预算。

也可能在市场询价。

也可能只是想知道：

现在市场价格涨了多少。

这几种情况，跟进方式完全不同。

七、老客户询价，我会特别注意一个信号：他有没有给你项目背景

比如：

Project: Cooling System Expansion

Quantity: 4 units

Required delivery: December

End user: XXX

这种询价，我一般会比较认真。

因为信息比较完整。

说明客户大概率已经进入项目阶段。

但如果只是：

“Price for 1 unit?”

然后没有项目名称。

没有参数。

没有时间。

没有规格。

那就不能和正式RFQ用同样的精力。

这不是说不回复。

当然要回复。

但资源投入要区别对待。

八、第二次订单，还有一个好处：你终于可以问一些第一次不方便问的问题

第一次合作的时候，很多问题不太好直接问。

比如：

“How do you normally select suppliers?”

“Who approves the technical solution?”

“Do you normally compare three suppliers?”

“How many similar projects do you handle every year?”

刚认识的时候，问这些可能有点突兀。

但合作过一次以后，关系已经不一样了。

这时候就可以慢慢聊。

例如：

“For similar projects, do you normally purchase directly from manufacturers or through EPC contractors?”

这句话很有价值。

因为你可能突然发现：

客户背后还有一个很大的业务链。

他不是最终使用者。

他可能每年给几十个项目采购设备。

那么你真正应该开发的，就不是这一张PO。

而是：

成为他的长期供应商。

九、还有一个特别现实的问题：第二次报价以后，客户没下单怎么办？

这个时候千万不要因为“老客户”三个字，就连续追十封邮件。

比如：

Any update?

Any feedback?

Any news?

Please check.

这样很容易把关系搞得很机械。

我更喜欢根据项目阶段去问。

如果是正式项目：

“Has the project moved to the purchasing stage?”

如果是技术方案阶段：

“Has the technical specification been finalized?”

如果客户说还在比较供应商：

“If there is any technical point that needs clarification, please let us know.”

这样你得到的信息会更多。

有时候客户不是不要你。

只是项目还没到采购阶段。

这两个情况一定要分开。

十、做久了以后，我发现老客户其实最值得建立一个小档案

不用搞得特别复杂。

Excel就够了。

我自己会比较关注：

客户名称

上次采购时间

采购产品

设备参数

采购数量

成交价格

付款条件

主要联系人

技术联系人

项目类型

预计采购周期

上次订单有什么特殊要求

最后再加一栏：

下一次可能什么时候出现需求。

比如：

2026年3月：1台板式换热器

2026年8月：3台同类设备

2027年可能有工厂扩建项目

你慢慢积累几个月以后，就会发现：

客户开发不再完全靠“想起来了就联系”。

而是开始有一点规律。

写在第59天

以前我觉得：

老客户=好做。

现在我觉得更准确的说法是：

老客户更容易获得机会，但不代表每一次机会都容易成交。

第二次询价的时候，客户已经知道你的价格，也知道你的产品。

所以你真正需要做的，不是单纯比第一次报得更低。

而是把上一单的信息利用起来。

看看：

这次参数有没有变化。

采购数量有没有变化。

项目有没有变化。

客户的采购方式有没有变化。

客户内部有没有新的联系人。

甚至：

客户是不是正在从“一次采购”变成“重复采购”。

如果能看懂这些东西，你会发现：

客户第二次发来的，不只是一张RFQ。

它其实是在告诉你：

这个客户的采购行为，正在发生什么变化。

而这些变化，往往比这一张订单本身更值得关注。

第一张PO让客户认识你。

第二张PO，才开始决定你能不能真正成为他的供应商。
