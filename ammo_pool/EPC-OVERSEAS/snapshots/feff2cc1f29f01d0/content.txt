# 外贸干货｜沙特公司：商业登记号CR与增值税VAT号

2026-10-13 17:00 北京

很多对接沙特项目的外贸人，很容易混淆 CR商业登记号 和 VAT增值税号。合同、Fatoora电子发票、SABER、工程款结算，两个号码用途完全不同，填错直接导致发票驳回、回款受阻。

一、商业登记号 CR Number（رقم السجل التجاري）

发证机构：沙特商务部MoC

✅本质：沙特企业的工商营业执照编号，企业合法经营的基础身份。没有CR，公司不能在沙特开展商业活动、开设银行账户、办理VAT注册、申请Etimad投标资质。

- 格式：10位数字；2025年4月新商法实施后，新注册企业CR统一以7开头；旧号码继续保留，5年过渡期有效

- 在哪里看：商业登记证书（Commercial Registration Certificate）左上角

- 核验官网：沙特商务部 mc.gov.sa 可在线核验CR真伪、企业经营范围、法人信息

CR主要使用场景

1. 投标Etimad平台、签署项目合同、保函办理

2. 银行开户、劳工签证、社保GOSI注册

3. Fatoora电子发票上必填字段之一

4. 办理SABER认证、市政许可

一句话：CR=公司工商主体身份，所有沙特本地公司必有CR号。

二、增值税号 VAT Number（رقم التعريف الضريبي）

发证机构：ZATCA 天课税务海关总局

✅本质：增值税纳税人编号，只有完成VAT注册的企业才有。沙特标准增值税率15%。

- 格式：15位数字，固定以3开头

结构拆解：

第1位=3（沙特GCC国家代码）｜2‑9位=纳税人序列号｜第10位校验码｜11‑13位分支机构代码｜最后2位税种码

- 凭证：VAT注册证书（VAT Registration Certificate）

VAT号主要使用场景

1. Fatoora沙特电子发票核心必填，B2B工程发票缺少VAT号直接作废，无法抵扣进项税

2. 增值税月度/季度报税、进项税抵扣

3. 工程款结算、设备采购、材料交易开票

4. 海关进口清关、进口增值税申报

一句话：VAT号=税务身份，不是所有企业都自动拥有，需要单独向ZATCA申请注册。

三、工程外贸高频踩坑点

1. 千万不要把CR当成VAT号填进电子发票

Fatoora系统校验严格，两者位数不一样，混用直接报错、发票无效，客户无法抵扣，工程款结算卡住。

2. 沙特本地分包商、供应商，签合同前两个号码都要收集并核验

核验CR确认企业真实存续；核验VAT确认对方具备开票资质。

3. 分支机构会有独立VAT号，CR主体号不变

总部CR只有一个，不同分公司可以有多个15位VAT税号，项目以签约主体对应的VAT为准。

4. 出口中国企业本身没有沙特CR/VAT；向沙特本地业主开票的是沙特本地注册主体

国内出口商出具商业发票不需要沙特VAT；沙特本地公司之间工程结算，必须走ZATCA Fatoora电子发票，CR+VAT双号齐全。

5. 项目变更、签证、付款文件，保持CR、VAT号和营业执照、税务证书完全一致。

五、实操检查清单（对接沙特客户时）

✅ 获取客户CR号，商务部官网核验企业状态、经营范围

✅ 获取客户VAT号，确认VAT注册有效状态

✅ Fatoora电子发票：同时填写买卖双方CR、VAT

✅ 合同正文写明客户CR号，税务发票单独标注VAT号
