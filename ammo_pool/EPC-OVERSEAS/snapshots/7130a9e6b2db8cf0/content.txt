# 中国电建集团华东勘测设计研究院有限公司EPC业务信息

## EPC业务发展历程

1. **早期探索阶段（上世纪80年代）**：
   - 华东院早在上世纪80年代就涉足工程总承包领域
   - 承担了中国首个水电站工程总承包试点——浙江石塘水电站主体工程总承包
   - 该项目有效控制了投资，保证了质量，得到了原国家计委的肯定
   - 之后又相继承担了一批中小型水电站工程的总承包业务

2. **转型发展阶段（2008年起）**：
   - 2008年，随着转型战略的实施，总承包业务发展加快
   - 业务领域从单一的水电业务逐步拓宽，覆盖水利水电、工业与民用建筑、新能源、市政交通、水务、水环境治理工程、海水淡化等
   - 项目规模随着项目核心管理能力的逐步提升、PPP模式推广、市场需求逐步增长而增大

3. **试点示范阶段（2014年起）**：
   - 2014年12月，华东院成为浙江省工程总承包第一批试点企业
   - 大项目的经营取得了良好的成效，先后承担了国内首个百万千瓦级水电站工程总承包——四川杨房沟水电站、国内最大的水环境综合整治工程总承包——深圳茅洲河综合治理、国务院重大节水供水工程——鄂北引水总承包等数十个大型工程总承包项目

4. **快速发展阶段（近年来）**：
   - 工程总承包业务基本两年翻一番，业务水平、人才水平提升到了一个新的高度
   - 2008年华东院营收10亿元，到2017年，达到150亿元，九年翻了15倍
   - 连续多年新签合同与收款所占比例双超45%，转型发展初显成效
   - 从项目小而散的局面中走出来，项目规模不断增大

5. **海上风电EPC业务发展（2017年起）**：
   - 2017年起，华东院正式介入海上风电总承包领域
   - 2019年起开始承接海外海上风电项目
   - 目前以EPC总承包模式承接的大型海上风电项目已超过15个，总规模约500万千瓦

## EPC业务模式与特点

1. **以设计为龙头的EPC模式**：
   - 华东院在以设计为龙头的EPC领域具有特长与优势
   - 通过设计优化和管理集成降低工程造价
   - 掌控工程建设全局确保工程进度与质量
   - 华东院这种以设计为龙头的企业进军工程总承包，与以施工为龙头的企业从事工程总承包的最大区别，就是强调设计优势所在

2. **组织架构创新**：
   - 华东院下属分支机构按行业划分，比如交通院、建筑院、新能源院等，既做设计又做总承包业务，结合得也还不错
   - 随着项目规模扩大，这种模式逐渐难以适应
   - 为提高项目现场管控能力，华东院成立专门子公司，专业负责工程总承包
   - 成立五年来，目前已经担负全院工程总承包包分分之六十的份额
   - 同时院内部组织架构也逐步向工程公司靠拢，院总部、二级生产单位、专业中心都围绕项目高效运转

3. **数字化智慧管理**：
   - 华东院积极开发总承包项目现场综合管控云平台、BIM系统等
   - 2019年起，基于"O-Wind数字能源服务平台"，自主开发了一套应用于海上风电总承包管理的平台——项目标准化精细化信息平台
   - 从BIM、气象、质量、安全、进度、流程、成本等维度赋能管理
   - 通过管理标准化和流程化大幅提高效率，提升质量，降低成本

4. **全产业链服务能力**：
   - 华东院基本形成了以国内国际为两大目标市场，以水电与新能源、城市建设与环境发展、大坝与工程安全为三大主要领域，以勘测设计、工程总承包、投资为三项主要业务的全产业链发展模式
   - 从单一的勘测设计为主开始转型，工程总承包业务得到了长足发展

## EPC业务领域

1. **水电与新能源领域**：
   - 水电站工程总承包：浙江石塘水电站、四川杨房沟水电站等
   - 海上风电EPC：目前以EPC总承包模式承接的大型海上风电项目已超过15个，总规模约500万千瓦
   - 陆上风电EPC：国外首个大型风电EPC巴基斯坦项目群创造多个履约记录，树立了行业标杆
   - 光伏发电EPC：建德漂浮式光伏拥有自主知识产权

2. **水环境综合治理领域**：
   - 国内最大的水环境综合整治工程总承包——深圳茅洲河综合治理
   - 近几年，华东院抓住美丽中国建设的契机，主动出击，在深圳、福建、安徽、山东、云南等地，以"工程总承包"模式，参与地方政府的水环境综合整治工程，主攻河道整治、污水处理、景观提升、桥梁改造等
   - 水环境综合整治体量比较大，一个项目一般都是几十个亿，目前这块业务是华东院工程总承包的重要领域之一

3. **城市基础设施领域**：
   - 城市基础设施的建设是华东院的核心能力之一
   - 杭州大江东新区开发建设项目，华东院是其中某项目联营体合作方和EPC总承包方，整个基础设施建设包括9条道路，全长83公里，总标的超过100亿元

4. **教育与医疗领域**：
   - 华东院在杭州承接建设杭师大附属实验学校、拱墅区运河文化发布中心和大关单元学校、杭州市庆隆单元某地块24班配套中学，近日中标了良渚医院整体迁建工程EPC项目
   - 在宁波，承接建设浙江医药高等专科学校
   - 在湖北，承建监利县职业技术学校等

5. **农业领域**：
   - 衢州市衢江区富里农村综合改革试验区——万亩水田垦造及智慧生态农业培育EPC工程，通过高起点"六位一体"综合创新开发，打造出了"衢江模式"

## 重点EPC项目案例

1. **四川杨房沟水电站**：
   - 国内首个采用EPC模式百万千瓦级水电工程
   - 以联营体方式承担

2. **深圳茅洲河综合治理**：
   - 国内最大的水环境综合整治工程总承包项目

3. **鄂北引水工程**：
   - 国务院重大节水供水工程

4. **海上风电项目**：
   - 江苏竹根沙（H2#）300MW海上风电场EPC总承包项目
   - 国家电投江苏如东（H4#H7#）800MW海上风电场EPC总承包项目
   - 华能玉环2号海上风电项目EPC总承包标段包1，中标金额高达51.91亿元人民币

5. **东阳第二污水厂**：
   - 首个全面负责设计、投融资、建设管理、运行维护的项目
   - 顺利投产

6. **杭州大江东新区基础设施项目**：
   - 整个基础设施建设包括9条道路，全长83公里，总标的超过100亿元

7. **亚运场馆及北支江综合整治工程EPC项目**：
   - 2022年4月，该项目部被授予"2022年浙江省工人先锋号"称号

## EPC业务核心竞争力

1. **技术创新能力**：
   - 华东院以技术为核心创新发展
   - 技术是华东院的核心竞争力，是华东院立足市场、创造价值、实现可持续发展的有力武器
   - 持续不断的创新，是让这些武器不断丰富、升级换代、满足市场的有力方法

2. **人才队伍优势**：
   - 华东院每年有来自全国多所211或985高校的毕业生加入
   - 强大的设计团队，深厚的历史积淀，优秀的企业文化
   - 拥有一支既懂设计、又懂施工、也懂管理的综合性高级专业技术人才队伍

3. **海外工程经验**：
   - 曾在世界二十多个国家承担完成了数十项工程建设项目及业务合作
   - 具有很强的海外工程综合经营管理能力

4. **投融资能力**：
   - 投资开发过多个水电站工程建设项目
   - 具有较好的建设资金管理和投融资能力

5. **项目管理能力**：
   - 长期从事项目管理，建立了专业化项目管理队伍
   - 华东院工程总承包业务现在拓宽到许多领域，特别是学校与医院

## EPC业务发展战略

1. **国内市场战略**：
   - 抓住美丽中国建设的契机，主动出击，参与地方政府的水环境综合整治工程
   - 积极拓展城市基础设施、教育医疗等领域的EPC业务

2. **国际市场战略**：
   - 华东院依托产业链一体化优势和国际化发展势头，在"一带一路"倡议号召下，与巴基斯坦、越南、泰国、马来西亚、柬埔寨、缅甸、印尼、土耳其等近二十个"一带一路"沿线国家，在水电水利、风电、太阳能、通信、节能环保、市政建设、工程安全等领域开展广泛合作和全方位交流
   - 承接了数十项水电站EPC与设备成套，新能源EPC、光纤通信骨干网等工程

3. **业务架构战略**：
   - 正在逐步形成以国内、国际为两大目标市场，以水电水利与新能源、城市建设与环境发展、大坝与各类基础设施安全为主要领域，以勘测咨询、总承包与设备成套、投资为三大业务的国际型工程公司业务架构
