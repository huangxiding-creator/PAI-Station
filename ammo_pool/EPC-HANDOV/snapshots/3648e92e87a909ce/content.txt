# 第九章 工程总承包招投标合规最佳实践（续）

## 9.4 监督部门最佳实践

监督部门在工程总承包招投标活动中发挥着重要的监督管理作用，科学有效的监督管理有助于维护招投标市场秩序，保障招投标活动的公平公正。监督部门应当不断完善监督管理机制，提高监督管理效能。

### 9.4.1 监督管理机制优化

监督管理机制是监督部门履行职责的制度保障，科学合理的监督管理机制有助于提高监督管理的效能和权威性。监督部门应当不断优化监督管理机制，提升监督管理水平。

**监督管理制度建设**

监督部门应当建立健全招投标监督管理制度，为监督管理工作提供制度保障。具体实践包括：

1. **法规制度体系完善**：根据上位法和实际需要，制定和完善招投标监督管理的地方性法规、规章和规范性文件，形成层次分明、内容协调的法规制度体系。法规制度体系应当覆盖招投标活动的各个环节和各类主体，为监督管理提供全面的制度依据。

2. **监督管理职责明确**：明确各级监督部门的监督管理职责和权限，建立分工明确、协调配合的监督管理体制。职责划分应当遵循"谁审批、谁监管"和"谁主管、谁负责"的原则，避免监管真空或多头监管。

3. **监督管理程序规范**：规范监督管理的程序和方法，包括监督检查、投诉处理、行政处罚等程序，确保监督管理的规范性和透明度。程序规范应当明确各环节的时限要求、工作标准和责任主体，提高监督管理的效率和质量。

4. **监督管理标准统一**：统一监督管理的标准和尺度，避免因标准不一致导致的监管混乱和市场扰动。标准统一应当通过制定统一的监管指南、操作手册、检查表等方式实现，确保监管执法的一致性。

监督部门应当避免以下监督管理制度问题：

- 法规制度体系不完善，存在制度空白或冲突
- 监督管理职责不明确，导致推诿扯皮或多头监管
- 监督管理程序不规范，影响监管效率和公信力
- 监督管理标准不统一，导致执法尺度不一

**监督检查机制创新**

监督部门应当创新监督检查机制，提高监督检查的针对性和有效性。具体实践包括：

1. **风险导向监管**：建立风险导向的监管机制，根据招投标活动的风险程度和特点，确定监管重点和频次，实现监管资源的优化配置。风险导向监管可以通过建立风险评估模型，对不同行业、不同类型、不同规模的项目进行风险分级，实施差异化监管。

2. **"双随机、一公开"监管**：实施"双随机、一公开"监管，即随机抽取检查对象、随机选派执法检查人员，及时公开检查结果，提高监管的公正性和透明度。"双随机、一公开"监管应当与风险导向监管相结合，对高风险领域和环节加大抽查比例和频次。

3. **信用监管创新**：建立招投标信用监管机制，将市场主体的信用状况作为监管的重要依据，实施分类监管和联合惩戒。信用监管可以通过建立信用评价体系、信用档案、信用等级评定等方式实现，对不同信用等级的市场主体实施差异化监管措施。

4. **科技监管应用**：应用大数据、人工智能等现代科技手段，提高监管的智能化和精准化水平。科技监管可以通过建立招投标大数据平台，对招投标数据进行实时监测和分析，及时发现异常情况和违法违规线索。

监督部门应当避免以下监督检查机制问题：

- 监管方式单一，缺乏针对性和灵活性
- 监管资源配置不合理，无法覆盖重点领域和环节
- 信用监管流于形式，未能有效发挥激励约束作用
- 科技监管应用不足，未能充分利用现代科技手段

**投诉举报处理机制**

投诉举报是发现和纠正招投标违法违规行为的重要渠道，监督部门应当建立高效规范的投诉举报处理机制。具体实践包括：

1. **投诉举报渠道畅通**：建立多元化的投诉举报渠道，包括书面投诉、电话举报、网络举报、现场举报等，方便当事人和社会公众进行投诉举报。投诉举报渠道应当保持畅通，确保投诉举报信息能够及时传递到相关部门。

2. **投诉举报程序规范**：规范投诉举报的受理、调查、处理程序，明确各环节的时限要求和工作标准，提高投诉举报处理的效率和质量。程序规范应当包括投诉举报的形式要件、受理条件、调查方法、处理决定等内容。

3. **投诉举报保护机制**：建立投诉举报保护机制，保护投诉举报人的合法权益，鼓励社会各界积极参与招投标监督。保护机制应当包括信息保密、身份保护、反报复措施等内容，确保投诉举报人不因投诉举报行为而遭受不当对待。

4. **投诉举报结果反馈**：及时向投诉举报人反馈处理结果，接受投诉举报人的监督，提高投诉举报处理的透明度和公信力。结果反馈应当包括调查情况、处理决定、法律依据等内容，让投诉举报人了解处理过程和结果。

监督部门应当避免以下投诉举报处理机制问题：

- 投诉举报渠道不畅通，影响投诉举报的及时性和有效性
- 投诉举报程序不规范，导致处理效率低下或处理不当
- 投诉举报保护机制不健全，影响投诉举报积极性
- 投诉举报结果反馈不及时，降低投诉举报的公信力

**行政处罚与联动执法**

行政处罚是纠正违法违规行为、维护市场秩序的重要手段，监督部门应当规范行政处罚行为，加强联动执法。具体实践包括：

1. **处罚标准规范化**：制定统一、明确的处罚标准，规范行政处罚自由裁量权，确保同类违法行为得到同等处罚。处罚标准应当根据违法行为的性质、情节、危害后果等因素，设置不同的处罚档次和幅度。

2. **处罚程序法治化**：严格按照法定程序实施行政处罚，保障当事人的陈述申辩权、听证权等合法权益，提高行政处罚的合法性和公信力。程序法治化应当贯穿行政处罚的全过程，包括立案、调查取证、审查决定、送达执行等各个环节。

3. **部门联动执法**：建立招投标监管部门与纪检监察、公安、审计等部门的联动执法机制，形成监管合力，提高执法效能。联动执法可以通过建立信息共享平台、联合执法机制、案件移送制度等方式实现，确保各类违法违规行为得到及时有效查处。

4. **行业协同监管**：发挥行业协会、专业机构等社会力量的作用，形成政府监管与行业自律相结合的协同监管格局。行业协同监管可以通过制定行业自律规范、开展行业评价、实施行业惩戒等方式实现，扩大监管覆盖面和影响力。

监督部门应当避免以下行政处罚与联动执法问题：

- 处罚标准不明确，导致执法尺度不一和选择性执法
- 处罚程序不规范，影响行政处罚的合法性和有效性
- 部门联动不畅通，导致监管真空或监管重复
- 行业协同不充分，未能有效发挥社会力量的作用

### 9.4.2 重点环节监督管理

工程总承包招投标活动中存在一些重点环节和关键节点，这些环节往往是违法违规行为的高发区域，监督部门应当加强对这些重点环节的监督管理。

**招标条件和方式监管**

招标条件和方式是招标活动的起点，监督部门应当加强对招标条件和方式的监管，确保招标活动的合法合规。具体实践包括：

1. **招标条件审查**：加强对招标条件的审查，确保依法必须招标的项目履行招标程序，防止规避招标。审查应当重点关注项目性质、资金来源、投资规模等因素，判断项目是否符合依法必须招标的条件。

2. **招标方式监管**：监督招标人依法选择招标方式，防止滥用邀请招标、竞争性谈判等非公开招标方式。监管应当重点关注非公开招标方式的适用条件是否符合法律法规规定，是否存在违法规避公开招标的情况。

3. **招标程序监督**：监督招标人按照法定程序开展招标活动，包括招标公告发布、资格预审、招标文件发售、开标评标等环节，确保程序合法合规。程序监督应当贯穿招标活动的全过程，及时发现和纠正程序违法行为。

4. **招标信息公开**：监督招标人依法公开招标信息，包括招标公告、资格预审公告、中标候选人公示、中标结果公示等，确保信息公开的及时性、完整性和准确性。信息公开监督应当通过定期检查、随机抽查等方式进行，确保信息公开的有效性。

监督部门应当避免以下招标条件和方式监管问题：

- 招标条件审查不严格，导致应招标项目未招标
- 招标方式监管不到位，导致滥用非公开招标方式
- 招标程序监督不全面，未能及时发现和纠正程序违法行为
- 招标信息公开监督不力，影响招标活动的透明度和公信力

**资格条件和评标标准监管**

资格条件和评标标准直接关系到市场准入和竞争公平，监督部门应当加强对资格条件和评标标准的监管，防止不合理限制或者排斥潜在投标人。具体实践包括：

1. **资格条件合理性审查**：审查招标文件中的资格条件是否合理，是否与项目的规模、复杂程度和特殊要求相适应，防止设置歧视性条件。审查应当重点关注资质等级要求、业绩要求、财务要求等方面是否存在不合理限制。

2. **评标标准公平性监督**：监督评标标准的公平性和合理性，防止设置倾向性或者排他性条款，确保公平竞争。监督应当重点关注技术评分标准、商务评分标准、价格评审方法等是否存在不合理或者倾向性设置。

3. **违法设置条件查处**：及时查处违法设置资格条件和评标标准的行为，包括量身定制、明显不合理、违反强制性标准等情况，维护市场公平竞争秩序。查处应当依法依规进行，对违法行为给予相应的行政处罚。

4. **政策功能发挥监督**：监督招标人落实支持中小企业、促进创新、绿色发展等政策要求，在资格条件和评标标准中体现政策导向。监督应当关注招标文件是否落实了相关政策要求，如对中小企业的价格扣除、对创新产品的鼓励措施等。

监督部门应当避免以下资格条件和评标标准监管问题：

- 资格条件合理性审查不严格，未能发现和纠正不合理限制
- 评标标准公平性监督不到位，导致不公平竞争
- 违法设置条件查处不及时，影响市场公平竞争秩序
- 政策功能发挥监督不力，未能有效落实政策要求

**开标评标过程监管**

开标评标是招标活动的核心环节，监督部门应当加强对开标评标过程的监管，确保过程公正透明。具体实践包括：

1. **开标现场监督**：派员参加开标活动，监督开标过程的规范性和透明度，防止违规操作。现场监督应当关注开标程序是否符合法律法规和招标文件规定，是否存在泄露标底、串通投标等违法行为。

2. **评标专家监管**：加强对评标专家的监管，包括专家抽取、专家回避、专家评审行为等，防止专家不当行为影响评标公正性。专家监管应当通过完善专家库管理、规范专家抽取程序、加强专家培训等方式进行。

3. **评标过程监督**：监督评标过程的规范性和公正性，包括评标程序、评标方法、评标标准的执行情况，防止违规评标行为。过程监督应当注重程序监督，不得干预评标委员会的独立评审。

4. **评标结果复核**：对评标结果进行必要的复核，包括形式审查、资格审查、响应性审查、计算错误修正等环节，确保评标结果的准确性和可靠性。结果复核应当注重形式审查和计算准确性，不得改变评标委员会的实质性评审意见。

监督部门应当避免以下开标评标过程监管问题：

- 开标现场监督流于形式，未能有效防范违规行为
- 评标专家监管不到位，导致专家不当行为影响评标公正性
- 评标过程监督不规范，干预评标委员会的独立评审
- 评标结果复核不严格，未能发现和纠正评标错误

**合同签订与履行监管**

合同签订与履行是招标成果的转化和落实，监督部门应当加强对合同签订与履行的监管，防止招标成果落空。具体实践包括：

1. **合同签订监督**：监督招标人与中标人按照招标文件、投标文件和中标通知书的约定签订合同，防止擅自变更合同实质性内容。监督应当重点关注合同主要条款是否与招标文件、投标文件和中标通知书一致，是否存在实质性偏离。

2. **合同备案管理**：加强合同备案管理，及时掌握合同签订情况，为后续监管提供依据。备案管理应当建立电子化备案系统，简化备案程序，提高备案效率，同时加强备案信息的分析和利用。

3. **合同履行监督**：监督合同的履行情况，防止出现转包、违法分包、拖欠工程款等违法违规行为。履行监督可以通过定期检查、随机抽查、投诉举报调查等方式进行，及时发现和纠正违法违规行为。

4. **合同变更监管**：加强对合同变更的监管，防止通过不当变更规避招标或者损害国家利益、社会公共利益和他人合法权益。变更监管应当重点关注变更的必要性、合理性和合规性，防止借变更之名行规避招标之实。

监督部门应当避免以下合同签订与履行监管问题：

- 合同签订监督不到位，导致合同与招标文件、投标文件存在实质性偏离
- 合同备案管理流于形式，未能有效利用备案信息
- 合同履行监督不力，未能及时发现和纠正违法违规行为
- 合同变更监管缺失，导致通过变更规避招标或者损害相关利益

### 9.4.3 信用体系建设

信用体系建设是加强招投标监管的重要手段，科学完善的信用体系有助于发挥市场机制的作用，提高监管效能。监督部门应当加强招投标信用体系建设，推动形成守信激励、失信惩戒的市场环境。

**信用信息采集与管理**

信用信息是信用体系的基础，监督部门应当建立健全信用信息采集与管理机制，确保信用信息的全面性和准确性。具体实践包括：

1. **信息采集标准统一**：制定统一的信用信息采集标准，明确采集的内容、方式、频次等，确保信息采集的规范性和一致性。标准应当覆盖招标人、投标人、招标代理机构等市场主体的基本信息、资质信息、业绩信息、违法违规信息等。

2. **信息来源多元化**：拓展信用信息来源渠道，包括行政监管信息、司法裁判信息、行业协会信息、社会评价信息等，形成多元化的信息采集体系。多元化信息来源有助于全面反映市场主体的信用状况，提高信用评价的准确性。

3. **信息质量控制**：建立信用信息质量控制机制，对采集的信息进行审核、验证和更新，确保信息的真实性、准确性和时效性。质量控制应当包括信息录入审核、定期核查、信息更新机制等，防止信息失真或滞后。

4. **信息安全保障**：加强信用信息安全管理，保护商业秘密和个人隐私，防止信息泄露和滥用。安全保障应当通过技术手段和管理措施相结合的方式实现，确保信息采集、存储、使用、共享等环节的安全可控。

监督部门应当避免以下信用信息采集与管理问题：

- 信息采集标准不统一，导致信息不一致或不完整
- 信息来源单一，无法全面反映市场主体的信用状况
- 信息质量控制不严格，导致信息失真或滞后
- 信息安全保障不到位，导致信息泄露或滥用

**信用评价与分级**

信用评价是信用体系的核心，监督部门应当建立科学合理的信用评价与分级机制，客观反映市场主体的信用状况。具体实践包括：

1. **评价指标体系构建**：构建科学合理的信用评价指标体系，包括基础指标、行为指标、履约指标、违法违规指标等，全面反映市场主体的信用状况。指标体系应当具有科学性、可操作性和可比性，能够客观反映市场主体的信用水平。

2. **评价方法规范化**：采用规范化的评价方法，包括定量评价和定性评价相结合、静态评价和动态评价相结合的方法，提高评价的科学性和准确性。评价方法应当明确各指标的权重、计分方法、评价周期等，确保评价过程的透明性和可重复性。

3. **分级标准明确化**：制定明确的信用分级标准，将市场主体划分为不同的信用等级，为差异化监管和联合惩戒提供依据。分级标准应当根据行业特点和监管需要设定，既要有区分度，又要保持相对稳定性。

4. **评价结果公开透明**：及时公开信用评价结果，接受市场主体和社会公众的监督，提高评价的公信力和影响力。结果公开应当遵循合法、必要、适度的原则，既要保证公开的及时性和完整性，又要保护商业秘密和个人隐私。

监督部门应当避免以下信用评价与分级问题：

- 评价指标体系不科学，无法全面反映市场主体的信用状况
- 评价方法不规范，导致评价结果的主观性和随意性
- 分级标准不明确，难以有效区分不同信用水平的市场主体
- 评价结果公开不及时或不透明，影响评价的公信力和影响力

**守信激励与失信惩戒**

守信激励与失信惩戒是信用体系的重要功能，监督部门应当建立有效的激励惩戒机制，发挥信用约束作用。具体实践包括：

1. **守信激励措施**：制定守信激励措施，对信用良好的市场主体给予政策支持、简化程序、优先办理等激励，引导市场主体自觉守信。激励措施可以包括资格条件适当放宽、投标保证金减免、优先参与重点项目等多种形式。

2. **失信惩戒机制**：建立失信惩戒机制，对失信市场主体实施市场和行业禁入、限制招投标活动、从严监管等惩戒措施，增加失信成本。惩戒机制应当与失信行为的性质、情节、危害程度相匹配，做到惩戒适度、程序正当。

3. **联合奖惩机制**：建立跨部门、跨行业、跨地区的联合奖惩机制，形成守信联合激励和失信联合惩戒的合力。联合奖惩可以通过信用信息共享、联合惩戒备忘录、联合惩戒对象名单等方式实现，扩大奖惩的覆盖面和影响力。

4. **信用修复机制**：建立信用修复机制，为失信市场主体提供改过自新的机会，促进市场主体重塑信用。修复机制应当明确修复条件、修复程序、修复效果等内容，既要给予改正机会，又要防止随意修复导致惩戒失效。

监督部门应当避免以下守信激励与失信惩戒问题：

- 守信激励措施不具吸引力，无法有效激励市场主体守信
- 失信惩戒机制不健全，惩戒力度不足或程序不当
- 联合奖惩机制不畅通，未能形成奖惩合力
- 信用修复机制不完善，修复条件过严或过松

**信用信息共享与应用**

信用信息共享与应用是信用体系发挥作用的关键，监督部门应当推动信用信息共享与应用，提高信用体系的实用性和有效性。具体实践包括：

1. **信息共享平台建设**：建设统一的信用信息共享平台，实现招投标信用信息的集中管理和共享应用。平台建设应当遵循统一标准、互联互通、安全可控的原则，确保信息共享的高效性和安全性。

2. **部门间信息共享**：推动招投标监管部门与发改、住建、交通、水利等行业主管部门以及纪检监察、公安、法院等部门的信用信息共享，形成信息共享合力。部门间信息共享应当通过建立信息共享机制、签订信息共享协议等方式实现，明确共享内容、方式和责任。

3. **信用信息查询服务**：为市场主体和社会公众提供便捷的信用信息查询服务，提高信用信息的透明度和利用率。查询服务可以通过网站、APP、公共服务窗口等多种渠道提供，满足不同用户的查询需求。

4. **信用信息应用推广**：推动信用信息在招投标活动中的应用，将信用状况作为资格审查、评标、合同履行监管等环节的重要依据。应用推广可以通过制定应用指南、开展试点示范、加强宣传培训等方式实现，提高信用信息的应用水平。

监督部门应当避免以下信用信息共享与应用问题：

- 信息共享平台建设滞后，无法实现信息的集中管理和共享应用
- 部门间信息共享不畅通，形成信息孤岛
- 信用信息查询服务不便捷，影响信息的透明度和利用率
- 信用信息应用不充分，未能有效发挥信用约束作用
