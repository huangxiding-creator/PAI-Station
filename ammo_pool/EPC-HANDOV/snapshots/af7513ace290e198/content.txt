# 国际工程｜中国铁路设计院出海越南：从“设计输出”到“FEED+咨询+EPC+运营”的国际化转型

原创 无名高手 2026-08-21 12:12 北京

——广州地铁、深圳地铁、中铁设计、中铁六院与国际咨询公司的越南市场竞争

让我们先汇总一下最近一段时间中国设计咨询企业在越南这个单一市场的斩获：

摘要

越南铁路建设正在进入一个新的阶段。过去很长一段时间，越南铁路项目数量有限，项目推进速度也比较慢，设计咨询市场并没有形成持续的规模。近几年，情况开始发生变化。河内和胡志明市陆续推进新的城市轨道交通线路，隆城国际机场相关铁路项目进入前期准备，南北高速铁路也进入实质性推进阶段。铁路建设开始从一条线路、一个项目，逐渐转向国家铁路网络的整体建设。这给中国铁路设计咨询企业带来了新的机会。过去，中国工程企业进入海外市场，往往是施工企业先拿到EPC或工程承包项目，设计院跟随进入。设计更多是施工项目的一部分。现在，这种方式正在发生变化。越来越多中国设计咨询企业开始直接参与越南项目的规划、可行性研究、FEED、设计审查、项目管理和运营咨询。从目前的市场情况看，已经出现了几种不同的进入方式。广州地铁设计研究院更多采取设计咨询先行的方式，通过与越南本土设计企业以及国际咨询公司组成联合体，连续进入胡志明市城市轨道交通项目。深圳则依托深圳地铁集团的运营经验，把设计、设备、调试、培训和运营能力结合起来。中国铁路设计集团等传统铁路设计机构，则更多依托铁路、高铁和综合交通领域的技术积累进入越南市场。中铁六院参与守添—隆城铁路可研和FEED设计审查，则体现出另一种方向，即从设计服务进一步进入独立技术审查和技术咨询领域。这些变化说明，中国铁路设计企业出海正在发生一个比较明显的转变。过去是“把设计做出去”，现在越来越强调“参与项目定义”；过去主要提供设计服务，现在开始进入FEED、全过程咨询和Independent Engineering；未来则可能进一步延伸到EPCM、EPC、系统集成、运营以及TOD等业务。越南因此不只是中国设计院的一个海外市场，也可以看成观察中国设计院国际化转型的一个窗口。

一、越南为什么值得中国设计院关注

越南铁路市场的变化，首先来自投资规模的变化。目前越南铁路建设大体可以分成三个市场。一是河内、胡志明市的城市轨道交通。二是机场铁路、城际铁路和区域铁路。三是南北高速铁路等国家级铁路项目。这三个市场虽然项目类型不同，但在技术、人才和工程管理方面存在大量交叉。比如，一家设计企业如果能够做好城市轨道交通的可研和FEED，就能够积累越南的法规、标准、审批、地质、施工环境和本地合作伙伴经验。这些经验以后同样可以用于城际铁路和高速铁路。因此，对于刚刚进入越南的中国企业来说，城市轨道交通项目的意义可能并不完全在于合同金额。更重要的是，它能够帮助企业建立当地市场的第一批项目业绩和客户关系。

二、城市轨道交通正在从“单线建设”走向“网络建设”

河内和胡志明市过去的轨道交通建设相对缓慢。随着城市人口和交通压力增加，两座城市都在重新加快轨道交通规划。胡志明市尤其明显。随着既有线路逐步推进，以及新的地铁、跨城铁路和机场铁路项目进入前期阶段，市场开始出现连续性的咨询需求。过去，一家设计院可能花几年时间争取一个项目。现在，真正有价值的竞争开始变成：能不能进入一个城市，然后连续做下去。这也是广州地铁设计研究院在越南市场的一个明显特点。它并不是拿到一条线路之后就结束，而是在同一个市场继续争取新的线路和新的咨询业务。从商业角度看，这种方式比不断寻找新的国家和新的客户更加有效。因为第一个项目完成以后，企业已经熟悉了当地的标准、业主、合作伙伴和审批环境，第二个项目的市场开发成本会明显降低。

三、南北高速铁路是另一个完全不同的市场

如果说胡志明市和河内的城市轨道交通是中国设计企业进入越南的切入口，那么南北高速铁路可能是未来真正具有战略意义的项目。越南南北高速铁路线路长约1541公里，总投资规模约673亿美元，设计速度达到350公里/小时。这样的项目已经不是普通意义上的设计合同。它涉及铁路规划、线路工程、桥梁隧道、车站、轨道、供电、通信、信号、车辆、运营组织、投资估算、融资以及环境和社会影响等一整套问题。更重要的是，它具有明显的国家战略属性。因此，未来真正的竞争不会只是几家中国设计院之间的竞争，而会涉及不同国家铁路技术体系和咨询体系之间的竞争。中国、日本、法国、德国、西班牙、韩国等国家的企业都有可能参与。这对中国设计院提出了一个新的问题：中国企业的工程技术能力很强，但这种能力能不能转换成国际客户认可的咨询能力？这可能比单纯做好一套设计更加重要。

四、广州地铁：从“设计项目”进入越南市场

广州地铁设计研究院是目前比较值得研究的案例。它采取的不是传统的“跟着施工企业出海”方式，而是直接参与越南城市轨道交通前期咨询。在胡志明市市场，它先后参与相关线路的咨询工作，并通过与越南本土设计企业以及国际咨询机构组成联合体，进入新的项目。这种方式有一个很明显的特点：设计咨询本身就是市场开发的入口。比如，一个城市决定建设一条新的地铁线路，最早需要解决的不是施工，而是线路怎么走、车站怎么布置、采用什么系统、投资多少钱、客流能不能支撑以及项目采用什么建设模式。这些工作发生在EPC之前。谁能够进入这个阶段，谁就有机会更早了解项目，也更容易建立与业主的长期关系。

五、广州地铁真正输出的并不只是设计

广州地铁设计院的竞争力，很难简单归结为“设计能力”。因为它背后的广州地铁集团本身就是城市轨道交通建设和运营主体。这意味着广州地铁体系对地铁项目的理解并不止于设计。它知道一条线路如何规划，也知道一座车站建成以后如何运营。设计院能够从运营角度反过来看设计问题，这一点对海外客户有一定吸引力。因此，广州地铁的海外模式实际上更接近：运营经验 + 设计咨询 + 本地合作。这与传统设计院“业主给任务、设计院完成设计”的模式存在明显区别。

六、广州地铁最值得关注的，是“连续项目”能力

越南市场真正值得观察的并不是广州地铁拿到了多少个合同，而是它逐渐形成了连续进入同一市场的能力。一个项目完成以后，继续参与下一条线路。下一条线路完成以后，再进入网络规划、系统咨询或者运营相关业务。这种方式最后形成的是一个市场，而不是几个孤立的合同。可以把它理解成一个简单的过程：项目突破 → 客户关系 → 本地合作 → 项目复制 → 市场扩大。这也是国际咨询公司长期经营海外市场的基本方式。

七、深圳地铁走的是另一条路深圳地铁与广州地铁有相似之处，但商业模式并不完全相同。深圳的优势更加突出地体现在“运营商”身份上。深圳地铁不仅拥有设计和工程能力，还拥有长期的轨道交通投资、建设和运营经验。因此，它向海外市场提供的并不一定只是设计服务。还可以包括：

工程管理；

设备技术服务；

联调联试；

运营组织；

人员培训；

运营管理；

后续运维服务。这意味着深圳模式实际上是在把一套完整的地铁建设和运营经验输出到海外。

八、深圳模式的价值，在于设计和运营之间形成了反馈

传统设计院通常是：设计完成 → 项目交付。运营企业则是：设计 → 建设 → 调试 → 运营 → 维护 → 改造。两者最大的区别，是运营企业能够看到设计在实际运行中的结果。比如：一座车站的换乘距离是否合理？设备检修是否方便？车站高峰期会不会拥堵？机电系统的维护成本是不是过高？信号系统在长期运行中有没有问题？这些经验最终都可以反过来影响下一条线路的设计。所以，从长远看，运营经验本身就是一种设计能力。这也是纯设计咨询企业比较难复制的优势。

九、中国铁路设计集团代表另一条路线

中国铁路设计集团等传统铁路设计企业的优势，与广州、深圳有所不同。它们长期积累的是国家铁路、高速铁路、城际铁路和综合交通工程能力。从线路、桥梁、隧道、站场，到轨道、供电、通信信号，再到系统集成，这些企业具备比较完整的铁路工程技术体系。因此，它们更适合进入：

高速铁路；

国家铁路；

城际铁路；

大型铁路枢纽；

综合交通工程。这类项目规模大、专业复杂，对系统工程能力要求高，也更加符合传统铁路设计院的技术优势。

十、本地合作是传统设计院进入越南的重要方式

中国设计院进入越南，有一个问题很难绕开：不能只靠中国总部。越南的法律、审批、土地、规划、当地标准、政府关系和工程许可，都需要本地团队参与。因此，与越南设计咨询企业合作是一种现实而且有效的办法。中国设计院负责自己最擅长的工程技术部分，越南企业承担当地法规、审批、本地设计和客户沟通等工作。这种模式实际上与国际咨询公司的“Global Core + Local Platform”非常接近。总部提供技术和方法。当地平台负责市场和项目落地。

十一、中铁六院的案例更值得关注

中铁六院参与守添—隆城铁路项目的方式，与传统设计合同有一个明显区别。它承担的是：

可研报告审查；

FEED设计审查；

总投资审查；

勘察资料审查。换句话说，它不是简单地告诉业主“怎么设计”，而是在帮助业主判断：这个项目的技术方案是否合理？投资是否可信？前期工作是否完整？后续能不能进入实施阶段？这实际上已经接近国际工程咨询领域的Independent Technical Review。从中国设计院国际化的角度看，这条路很有价值。因为它不一定要求设计院承担整个项目的设计责任，却可以把工程技术能力转化成更高层面的咨询服务。

十二、为什么设计审查可能是一条值得重视的海外业务

在传统设计合同中，设计单位承担的是“设计责任”。而Independent Engineer或者Technical Advisor关注的是：项目能不能建；设计有没有明显缺陷；投资是否合理；工期是否可信；合同风险在哪里；项目是否具备融资条件。这类服务面对的客户也发生了变化。不再只是工程业主，还可能包括：

投资人；

银行；

基金；

政府；

PPP项目公司；

EPC承包商。因此，技术能力开始与投资决策联系起来。这就是从“设计”走向“工程咨询”的一个重要变化。

十三、越南市场已经出现几种不同的中国模式

把目前的企业放在一起看，可以看到几条比较清楚的路线。

这些模式并不存在绝对的高低之分。不同企业有不同的优势，也对应不同的客户。

十四、真正的竞争对手并不只是中国同行

中国企业进入越南以后，很容易产生一个误区：认为竞争主要来自其他中国设计院。实际上，未来更有竞争力的可能是这样的组合：中国工程技术 + 国际咨询能力 + 越南本地资源。比如：中国企业擅长大规模铁路工程和施工组织；欧洲咨询公司擅长国际标准、合同管理、融资机构要求和Independent Engineer服务；越南企业熟悉当地法规、审批和客户关系。三者结合以后，竞争力可能明显高于任何一方单独行动。
更应该弄清楚的是国际设计咨询公司为什么对越南市场非常谨慎。

十五、Arup、Systra、Ineco、SJ等国际咨询公司真正的优势在哪里

这里需要改变一个认识。国际咨询公司的优势，并不一定是某一项工程设计比中国企业做得好。它们更大的优势来自另外一套能力：

国际合同；

项目治理；

风险管理；

国际标准；

融资机构认可；

Independent Engineer；

ESG；

环境和社会管理；

索赔和争议管理；

全球客户网络。这些东西中国设计院过去在国内项目中接触得相对少。所以中国企业进入越南以后，真正需要补的未必是工程技术，而是国际咨询业务体系。

十六，为什么说FEED是一道门槛

目前很多企业把FEED理解为“初步设计”。这种理解在海外项目中是不够的。FEED实际上是在帮助业主确定整个项目的基本边界：线路；站点；系统；主要设备；工程量；投资；工期；建设方式；风险。因此，FEED完成以后，后面的EPC合同基本就有了一个技术基础。这也是为什么FEED合同金额可能并不大，但战略价值很高。一个几百万美元的FEED项目，背后可能对应几十亿美元的基础设施投资。

十七、越南标准是第一个真正的技术风险

中国设计院进入越南，不能简单地把中国规范翻译成英文。项目必须建立自己的Design Basis和Standards Matrix。实际项目中可能同时面对：

越南法规；

TCVN；

IEC；

EN；

UIC；

项目业主标准；

国际融资机构要求；

中国标准。不同标准之间如果没有提前处理，到了施工阶段再发现问题，代价会非常高。因此，海外设计真正需要解决的不是“会不会设计”，而是知道什么情况下应该采用什么标准，并且能够解释为什么。

十八、第二个风险是设计责任

国内设计人员有时容易把海外FEED理解成普通设计工作。但海外合同中，设计责任的边界通常需要写得非常清楚。例如：FEED阶段的工程量后来增加了，谁负责？地质条件变化，是勘察责任还是设计责任？系统接口出现问题，由哪个专业负责？EPC投标价格明显高于FEED估算，是否属于设计失误？性能测试无法通过，FEED顾问是否承担责任？这些问题不能等出了问题再讨论。必须在合同阶段就划清责任。

十九、投资估算同样是设计院必须补上的能力

海外FEED不能只提供图纸。还必须回答：项目到底要花多少钱？因此，需要建立完整的成本管理体系，包括：

工程量数据库；

当地价格数据库；

国际价格数据库；

CAPEX基准；

价格上涨因素；

预备费；

风险准备金；

工程量不确定性；

成本敏感性分析。特别是在PPP项目中，技术方案必须与财务模型相互验证。工程师认为合理的方案，不一定是投资人认为合理的方案。

二十、PPP会改变设计院的工作方式

PPP项目不能只看工程技术。比如，一座车站做得大一些，工程师可能认为能够提高服务水平。但是投资人会问：客流是否足够？运营方会问：运营成本是不是增加？银行会问：新增投资能不能带来相应现金流？因此，一个成熟的FEED团队不能只有工程师。至少需要逐步加入：工程 + 成本 + 客流 + 运营 + 财务。这也是工程设计向工程咨询转变的重要标志。

这种组织比简单地在越南设一个办公室更加重要。真正的本地化，核心是本地人才和本地项目管理能力。

二十二、中国设计院最大的变化，其实是从“交付项目”转向“经营市场”

国内设计院的典型工作方式是：业主有项目 → 设计院投标 → 中标 → 设计 → 交付。国际市场不是这样。国际市场更像：寻找客户 → 判断项目 → 建立关系 → 组成联合体 → 投标 → 谈合同 → 执行 → 获取业绩 → 再拿项目。这意味着海外业务不能只有设计人员。必须有：Business Development、Commercial、Contract、Risk、Legal和Project Management。否则技术能力再强，也很难持续获得项目。

二十三、广州模式最值得学习的是“市场飞轮”

广州地铁的价值不在于某一个项目，而在于能不能不断复制。比较理想的路径是：

第一条线路建立客户关系。↓

第二条线路扩大项目业绩。↓

第三条线路形成市场影响力。↓

网络规划进入更前端。↓

运营咨询进入更长期的服务。

最终，一个项目变成一个市场。这也是国际咨询公司经营海外业务的基本逻辑。

二十四、深圳模式则是另一种“产业链飞轮”

深圳地铁的模式可以概括成：

运营经验↓

设计↓

设备↓

工程管理↓

联调联试↓

运营培训↓

运营↓

运维↓

新的项目。

这种模式最大的优势是客户黏性强。因为客户买到的不只是设计文件，而是一整套地铁建设和运营经验。

二十五、中铁设计体系的机会在于高铁和国家铁路

对于中国铁路设计集团以及铁一院、铁二院、铁四院等大型铁路设计机构而言，没有必要完全复制广州、深圳的路线。它们真正的优势还是铁路系统工程。未来更值得关注的市场应该包括：

南北高速铁路；

城际铁路；

国家铁路改造；

大型铁路枢纽；

跨境铁路；

高速铁路系统集成。这些项目才是传统铁路设计院技术能力最容易形成优势的地方。

二十六、中铁六院提供了另一条值得尝试的道路

传统设计院出海，很容易陷入一个问题：必须承担完整设计责任，但海外项目规模又不足以覆盖全部经营成本。Independent Engineering可能提供了另外一种选择。也就是说：不一定自己做全部设计。而是帮助业主、投资人和银行判断：设计是否可靠、投资是否合理、风险是否可接受。进一步还可以发展到：

Technical Due Diligence；

Design Review；

Cost Review；

Construction Monitoring；

Completion Review；

Reliability Test Review；

Lender’s Technical Advisor。这类业务的价值并不完全取决于设计工作量，而与项目投资规模和融资结构有关。

二十七、未来中国设计院可能出现三种主要商业模式

第一种：专业咨询FS↓FEED↓Design↓Design Review

优点是风险相对低。缺点是收入规模有限，而且容易陷入价格竞争。

第二种：咨询+EPCMFS↓FEED↓EPCM↓Construction Management这种模式能够提高设计院对项目的控制力。但同时，项目管理和合同责任也会明显增加。

第三种：咨询+EPC+运营FS↓FEED↓EPC↓Commissioning↓O&M这是中国工程企业比较熟悉的模式。问题在于，一旦进入EPC和运营，风险也会随之扩大。因此，并不是所有设计院都适合走到这一步。

二十八、未来真正有价值的不是“设计量”，而是“项目定义权”

这是理解海外FEED价值的一个关键。如果一家设计院只是拿到EPC承包商确定以后的一部分施工图设计，它实际上处于产业链比较靠后的位置。但如果它参与：项目规划；可研；FEED；投资估算；技术路线；工程规模；建设方案；那么它实际上参与了项目定义。项目越大，这种价值越明显。所以，FEED合同看起来可能只是一个小合同，但它能够决定一个几十亿美元项目的技术边界。

二十九、南北高铁会成为中国设计院的一场真正考验

越南南北高铁吸引大量国内外咨询机构关注，这意味着竞争会非常充分。中国设计院需要证明的已经不只是：“我们设计过高铁。”而是：能不能做国际可研？能不能建立国际标准体系？能不能完成可靠的投资估算？能不能处理融资和PPP要求？能不能进行环境和社会影响评价？能不能接受国际合同？能不能承担相应的设计责任？能不能用英文管理一个大型国际项目？这些问题才是真正的门槛。

三十、中国设计院需要补的不是工程技术，而是“咨询业务系统”

如果把传统中国设计院与成熟国际咨询公司比较，会发现一个很有意思的现象。中国企业在工程技术、施工组织和成本控制方面并不弱，甚至在一些大型铁路项目上具有明显优势。真正的差距更多集中在：

因此，中国设计院真正需要补的，是一整套国际咨询公司的经营和管理体系。

三十二、未来五年，越南铁路咨询市场可能出现几个变化

第一，项目会从单线逐步走向网络规划。

第二，业主对FEED的要求会越来越高。

第三，EPCM和PMC的需求可能增加。

第四，城市轨道交通会逐步出现运营咨询需求。

第五，TOD会成为轨道交通项目的重要组成部分。因此，未来的轨道交通项目可能不再只是：Rail + Station而是：Rail + Station + TOD + Commercial Development这会把铁路设计企业与城市规划、房地产、金融和运营进一步连接起来。

三十四、中国设计院如果要长期经营越南，需要建立五个层级的能力

Level 1：Project Delivery先把项目做好。

Level 2：Local Delivery真正理解越南的法规、标准和市场。

Level 3：International Consulting掌握国际标准、合同、风险和项目治理。

Level 4：Business Development能够主动找到项目，而不是等待业主发项目。

Level 5：Infrastructure Development能够帮助客户完成：规划、可研、融资、FEED、EPC组织、建设管理和运营。

达到第五层以后，企业才真正摆脱了传统设计院的角色。
以上的前提是要挣到钱，笔者并没有从广州地铁院的公开财报里看到连续签约带来的经济效益，虽然成立了海外事业部，但海外的财报仍然归结在省外业务内。

真正需要改变的是设计院对“出海”的理解过去说设计院出海，通常想到的是：把国内设计人员派到国外。现在这种理解已经不够了。真正的国际化应该包括：市场开发能力本地人才国际合同风险管理国际标准成本和商务技术咨询项目融资接口EPCM运营咨询这些能力共同构成一家国际工程科技公司的基础。
越南市场的意义，不在于一年能拿多少设计合同如果只看合同额，很多海外设计项目并不算特别大。但如果从产业链看，一个可研项目可能影响后面的FEED。一个FEED项目可能影响后面的EPC。EPC又可能延伸到设备、系统集成、调试和运营。因此：前端咨询的价值不能只按照咨询合同金额衡量。它更重要的作用，是进入项目价值链的前端。
未来中国铁路设计企业会出现三条比较清晰的路线，第一条：广州路线专业设计咨询国际化核心业务：FS + FEED + Design + System主要面向：城市轨道交通。
第二条：深圳路线运营商+设计+产业链国际化核心业务：Design + Equipment + Commissioning + O&M主要面向：城市轨道交通网络。
第三条：中铁路线铁路技术+工程建设国际化核心业务：Railway + HSR + Engineering + EPC主要面向：高速铁路、国家铁路和城际铁路。
第四条：技术咨询路线Independent Engineering + LTA + Technical Advisory核心业务：TDD + Design Review + Cost Review + Construction Monitoring主要客户：业主、投资人、银行和项目公司。

最终竞争不是“中国企业和国际咨询公司谁赢”。未来真正有竞争力的，不一定是单独一家中国设计院，也不一定是单独一家欧洲咨询公司。更有可能出现的是：中国工程技术团队 + 国际咨询公司 + 越南本地企业形成长期合作。中国企业提供工程技术和施工经验；国际咨询公司负责国际标准、合同、风险和融资接口；越南企业负责本地法规、审批、客户关系和本地工程实施。三者结合以后，才可能真正适应越南这样一个正在快速建设基础设施、同时又高度重视本地化和国际规则的市场。

从这个角度看，越南更像是一场“组织能力考试”中国设计院过去证明了自己能够：把铁路设计出来。下一阶段需要证明的是：能不能把一个海外铁路项目经营起来。再往后，需要证明：能不能帮助客户把项目做成。最终则是：能不能长期经营一个国家的基础设施市场。这四个阶段对应的是四种完全不同的能力。设计能力   ↓工程咨询能力   ↓项目经营能力   ↓基础设施开发能力真正完成这一转变以后，企业才不再只是“海外设计院”。

结语：越南可能是中国铁路设计院国际化的一次转折越南铁路市场现在发生的事情，表面上是几家中国设计院拿到了几个项目。实际上，它反映的是中国工程咨询行业正在发生的一次变化。过去，设计院主要出售的是：设计成果。现在开始出售：工程知识和解决方案。再往后，可能出售：项目开发能力。最终则可能形成：Infrastructure Advisory + Engineering + EPCM + O&M的综合服务模式。广州地铁正在尝试从设计咨询切入；深圳地铁正在把运营经验带到海外；传统铁路设计院正在寻找高铁和国家铁路市场；中铁六院这样的企业则开始尝试从设计进入Independent Review和Technical Advisory。与此同时，Arup、Systra、Ineco等国际咨询公司仍然掌握着国际标准、合同管理、融资咨询和全球客户网络等优势。因此，未来的竞争不会简单地变成“中国设计院取代国际咨询公司”。更可能出现的是一种新的组合：中国工程技术能力 + 国际咨询能力 + 越南本地化能力。这才是越南市场真正值得关注的地方。对于中国铁路设计院而言，越南也许只是一个海外市场，但它提供了一个很重要的机会：让设计院第一次在一个相对完整的市场环境中，尝试把设计、FEED、咨询、项目管理、EPC、运营和本地化经营连接起来。如果这条路能够走通，那么中国设计院真正实现的就不只是“走出去”，而是完成一次更深层次的转变：从一家以设计生产为中心的设计院，变成一家以客户、项目和全生命周期价值为中心的国际工程科技公司。而这，可能比在越南多拿几个设计合同，更值得关注。
