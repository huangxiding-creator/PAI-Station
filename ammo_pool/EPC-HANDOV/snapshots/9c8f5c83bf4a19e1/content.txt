# 第八章 工程总承包招投标合规典型案例分析（续）

## 8.4 合同签订与履约阶段典型案例

### 8.4.1 合同签订违规案例

**案例1：某水务EPC项目合同实质性偏离案例**

某城市水厂扩建项目采用EPC总承包模式，Y公司通过公开招标中标。在招标文件中，明确规定了工程质量标准、工期要求、付款条件和违约责任等核心条款。然而，在合同签订阶段，招标人与Y公司私下协商，对合同条款进行了多处实质性修改：

1. 将原招标文件中规定的工期由18个月延长至24个月；
2. 将原招标文件中规定的预付款比例由合同价的15%降低至10%；
3. 将原招标文件中规定的质量保证金比例由5%提高至8%；
4. 大幅降低了Y公司的违约责任，同时提高了招标人的违约责任豁免条件。

这些修改使得合同条款与招标文件存在实质性偏离，损害了其他投标人的公平竞争权益。在合同签订后，有知情人向当地水务主管部门和招投标监管部门举报了这一情况。

经调查，监管部门认定该项目合同签订过程违反了《招标投标法》第四十六条关于"招标人和中标人不得再行订立背离合同实质性内容的其他协议"的规定。最终，招标人和Y公司被责令改正，恢复合同条款与招标文件的一致性，并分别被处以罚款。

**案例分析与启示：**

1. **合同条款的一致性要求**：中标后签订的合同必须与招标文件和中标人的投标文件保持一致，不得对实质性内容进行变更。

2. **实质性内容的界定**：工程质量标准、工期要求、付款条件、违约责任等核心条款属于合同的实质性内容，不得随意变更。

3. **合同签订的监督机制**：应当建立健全合同签订的监督机制，防止招标人与中标人私下达成不正当协议。

4. **合同变更的规范程序**：如确需对合同条款进行变更，应当按照规范程序进行，确保变更的合理性和公开性。

**案例2：某建筑EPC项目"阴阳合同"案例**

某商业综合体项目采用EPC总承包模式，Z公司通过公开招标中标，中标价为3.2亿元。在合同签订阶段，招标人与Z公司签订了两份内容不一致的合同：

1. 一份是提交给建设主管部门备案的"明合同"，合同价款为3.2亿元，与中标价一致；
2. 另一份是双方实际履行的"暗合同"，合同价款为2.8亿元，比中标价低0.4亿元。

同时，双方还签订了一份"补充协议"，约定Z公司向招标人支付0.4亿元的"管理费"，作为获取项目的"回扣"。

在项目实施过程中，由于实际合同价款较低，Z公司为了维持利润，大量使用不合格材料，导致工程质量问题频发。在一次质量安全检查中，当地建设主管部门发现了质量问题，并在调查过程中发现了"阴阳合同"的存在。

经调查，当地纪检监察部门和建设主管部门认定该项目存在"阴阳合同"和商业贿赂行为，违反了《招标投标法》、《建筑法》和《反不正当竞争法》的相关规定。最终，招标人的相关责任人被移送司法机关处理，Z公司被列入建筑市场黑名单，项目被责令停工整改。

**案例分析与启示：**

1. **"阴阳合同"的违法性**："阴阳合同"是一种严重的违法行为，不仅扰乱了建筑市场秩序，还可能导致工程质量和安全问题。

2. **合同备案的真实性要求**：提交给主管部门备案的合同必须是双方真实意思表示的合同，不得弄虚作假。

3. **商业贿赂的法律风险**：以"管理费"、"咨询费"等名义变相支付回扣，属于商业贿赂行为，可能构成犯罪。

4. **合同价款的合理性**：合同价款应当合理，过低的价格可能导致承包人通过降低质量标准来维持利润，带来质量和安全风险。

### 8.4.2 违法转包与分包案例

**案例1：某市政EPC项目整体转包案例**

某市政道路改造项目采用EPC总承包模式，AA公司通过公开招标中标。AA公司在中标后，并未组建项目团队开展实质性工作，而是将整个项目以"内部承包"的名义转包给了BB公司，约定BB公司支付AA公司合同价款的3%作为"管理费"。

BB公司接手项目后，又将设计工作分包给了CC设计院，将施工工作分包给了DD建筑公司。在项目实施过程中，由于多层分包导致责任不清、管理混乱，工程质量和进度均出现严重问题。

在一次例行检查中，当地建设主管部门发现了转包和违法分包问题，立即责令停工整改。经调查，监管部门认定AA公司存在将工程整体转包的违法行为，违反了《建筑法》第二十八条和《招标投标法》第四十八条的规定。

最终，AA公司被处以合同价款25%的罚款，并被列入建筑市场黑名单；BB公司因参与违法转包被处以罚款；项目被责令重新组织招标。

**案例分析与启示：**

1. **整体转包的违法性**：将中标项目整体转包给他人是一种严重的违法行为，中标人必须自行组织实施中标项目。

2. **"内部承包"的实质判断**：所谓的"内部承包"、"项目承包"等形式，如果实质上是将项目整体交由其他单位实施，仍属于违法转包。

3. **总承包单位的项目管理责任**：总承包单位必须对项目全过程负责，不得简单收取"管理费"而不履行实质性管理职责。

4. **违法转包的法律后果**：违法转包不仅会面临行政处罚和市场禁入，还可能导致合同无效，承担工程质量和安全责任。

**案例2：某工业EPC项目违法分包案例**

某化工厂技术改造项目采用EPC总承包模式，EE公司通过公开招标中标。EE公司具有化工石油工程施工总承包一级资质和化工石油行业设计甲级资质，符合招标文件的资质要求。

在项目实施过程中，EE公司将主体工程中的核心装置安装工程分包给了不具备相应资质的FF公司，并将关键的工艺设计分包给了不具备相应资质的GG设计工作室。这些分包未经业主批准，也未向建设主管部门备案。

在项目实施过程中，由于FF公司和GG设计工作室缺乏相应的技术能力和管理经验，多次出现设计错误和施工质量问题。在一次设备调试过程中发生了安全事故，导致多人受伤。

事故调查过程中，当地应急管理部门和建设主管部门发现了违法分包问题。经调查，监管部门认定EE公司存在将主体工程违法分包的行为，违反了《建筑法》第二十八条和《招标投标法》第四十八条的规定。

最终，EE公司被处以合同价款20%的罚款，并被责令整改；FF公司和GG设计工作室因参与违法分包被处以罚款；相关责任人因事故责任被追究刑事责任。

**案例分析与启示：**

1. **主体工程分包的违法性**：将主体工程或关键工作分包给不具备相应资质的单位是一种严重的违法行为。

2. **分包的审批和备案要求**：工程分包应当经过业主批准，并向建设主管部门备案，确保分包的合法性和可控性。

3. **分包单位的资质要求**：分包单位必须具备相应的资质和能力，确保工程质量和安全。

4. **总承包单位的管理责任**：总承包单位对分包工程的质量和安全负总责，必须加强对分包单位的管理和监督。

### 8.4.3 履约争议案例

**案例1：某能源EPC项目设计变更争议案例**

某光伏发电站项目采用EPC总承包模式，HH公司中标后与业主签订了固定总价合同。在项目实施过程中，由于当地电网接入政策变化，业主要求HH公司对电气系统设计进行重大调整，增加了多项设备和工程内容。

HH公司认为这属于业主原因导致的重大设计变更，应当相应增加合同价款。但业主认为，EPC总承包合同是固定总价合同，承包商应当承担政策变化的风险，拒绝增加合同价款。

双方争议无法协商解决，HH公司向当地仲裁委员会申请仲裁。仲裁庭经审理认为：

1. 电网接入政策变化属于业主风险范围，不属于承包商应当预见和承担的风险；
2. 业主要求的设计变更超出了原合同约定的工作范围，构成实质性变更；
3. 根据合同约定的变更程序，业主应当就变更部分与承包商协商确定增加的费用。

最终，仲裁庭裁决业主应当向HH公司支付因设计变更增加的合理费用，并相应延长工期。

**案例分析与启示：**

1. **EPC合同中的风险分配**：EPC总承包合同中应当明确风险分配原则，区分业主风险和承包商风险。

2. **设计变更的处理机制**：合同中应当明确设计变更的认定标准、审批程序和费用确定方法。

3. **政策变化风险的应对**：对于可能发生的政策变化风险，双方应当在合同中明确约定责任分担机制。

4. **争议解决机制的重要性**：建立健全的争议解决机制，包括协商、调解、仲裁等多种方式，是处理履约争议的重要保障。

**案例2：某建筑EPC项目工程款支付争议案例**

某办公楼项目采用EPC总承包模式，II公司中标后与业主签订了合同。合同约定按照工程进度分阶段支付工程款，其中设计完成后支付20%，主体结构完成后支付30%，竣工验收合格后支付45%，质保期满后支付5%。

在项目实施过程中，II公司按照合同要求完成了设计工作并获得了业主批准，但业主以资金紧张为由，仅支付了应付设计款的一半。II公司在多次催款无果的情况下，继续推进项目，完成了主体结构施工。然而，业主再次拖延支付工程款，导致II公司资金链紧张，无法正常支付材料款和劳务费。

最终，II公司被迫暂停了工程施工，并向当地法院提起诉讼，要求业主支付已完工程款及利息，并赔偿因拖延付款导致的损失。

法院经审理认为：

1. 业主未按合同约定支付工程款，构成违约；
2. II公司有权暂停施工，并要求业主承担违约责任；
3. 业主应当支付已完工程款及逾期利息，并赔偿因拖延付款导致的直接损失。

最终，法院判决业主向II公司支付已完工程款、逾期利息和相关损失赔偿，并在判决生效后30日内与II公司协商确定后续工程的继续实施方案。

**案例分析与启示：**

1. **工程款支付的合同保障**：合同中应当明确约定工程款支付的时间、金额和条件，确保承包商的合法权益。

2. **业主的付款义务**：业主应当按照合同约定及时支付工程款，不得以资金紧张等理由拖延付款。

3. **承包商的权利保障**：承包商在业主拖延付款的情况下，有权采取合理措施保护自身权益，包括暂停施工、要求支付逾期利息等。

4. **工程款争议的处理机制**：建立健全的工程款争议处理机制，包括协商、调解、仲裁、诉讼等多种方式，是解决工程款支付争议的重要保障。
