# 竣工结算流程全梳理：从收集资料到回款

2026-10-11 14:00 北京

适用于建筑、安装、市政、燃气等工程，完整闭环，可直接用于工作底稿、培训笔记。

一、结算前期：竣工资料收集与初审（结算启动阶段）

核心：资料不全不启动结算，避免后期反复补资料、扯皮

基础合同类资料

施工合同、补充协议、中标通知书、招投标文件、答疑纪要、询标纪要；甲供材约定、风险范围、调价条款、违约条款。

施工过程资料

施工图、竣工图、图纸会审、设计变更、技术核定单

现场签证、洽商记录、隐蔽工程验收记录

会议纪要、工作联系单（要有甲乙监理签字盖章，无签字的签证不能直接计入）

现场及验收资料

竣工验收报告、竣工移交证书；材料设备进场报验、合格证；甲供材领用单、扣料单；认价单（材料、设备、分包认价）。

其他资料

工期奖罚、索赔资料、停水停电、现场扰民补偿、罚款通知单；已付款台账、水电费扣款记录。

本阶段重点核查：签证手续是否完整、竣工图与现场是否一致、认价是否在有效期、甲供材数量是否核对清楚，缺失资料列出清单，限期补齐。

二、结算编制：施工单位端（承包人）

核对竣工图，对比施工图，梳理变更增减量，区分原合同内、变更增加、签证新增。

按合同计价规则算量：清单计价 / 定额计价，做好算量底稿。

计取变更、签证、材料调差、索赔、奖罚、甲供材扣减、水电费。

内部自审：工程量复核、子目套用、取费、税率、规费，避免低级错误。

形成完整结算书：结算封面、编制说明、汇总表、分部分项、变更签证附件、全套资料装订，正式报送建设单位 / 审计单位，做好报送签收记录。

编制说明必须写清：结算范围、合同依据、调差方式、未计入项目、甲供材扣款、争议项说明。

三、受理与初审：建设单位 / 审计接收结算

建设单位接收结算，检查资料完整性，资料不齐直接退回补资料，出具接收回执。

建设单位内部初审，可委托第三方造价咨询审计；签订审计委托协议，明确审计时限。

审计单位接收资料，建立结算台账，梳理：合同价、送审价、已支付工程款、甲供材。

初步筛查：送审结算是否超合同范围、签证有效性、认价是否合规，梳理初步疑问清单。

四、核对阶段：对量、对账、争议沟通（耗时最长环节）

量的核对：

图纸、竣工图、现场踏勘相结合，复核工程量，对量留对量记录底稿。

价的核对：

清单子目套用、定额换算、材料认价、信息价调差，核对甲供材扣减。

变更签证审核：

核实是否为合同外工作；重复计取剔除；手续不全签证，要求补签或予以扣减。

形成初审稿（初步审核结果），把核增核减明细全部列明，出具初审征求意见。

承包人对初审结果反馈：认同项、有异议争议项，书面反馈意见，附支撑依据。

组织多轮对账、现场勘查，针对争议项：依据合同、图纸、签证、定额规则谈判，留存会议纪要。

关键：所有核减要有依据，不能只给一个最终数；对账过程做好书面记录，口头沟通不作结算依据。

五、定案阶段：结算审定、出具结算报告

争议项达成一致，确认审定结算金额，三方（建设、施工、咨询）核对结算审定表。

签署《工程结算审定签署表》，各方盖章确认，这是结算最重要法律文件。

造价咨询单位出具正式《竣工结算审核报告》，包含审核说明、送审、审定、核减明细、附件。

建设单位内部审批：走内部流程，将结算报告、审定表归档，作为最终付款依据。

注意：审定签署表盖章后，原则上不再随意变更结算金额。

六、合同内尾款、质保金管理（付款与回款闭环）

依据审定结算总价，核对：已付工程款、甲供材扣款、水电费、违约金罚款，计算应付尾款。

应付尾款 = 审定结算价−已付进度款−各类扣款−预留质量保证金

施工单位按合同约定开具对应金额发票，提交付款申请。

建设单位内部付款审批，支付工程尾款。

质保期管理：

按合同约定质保期满，无质量问题，承包人提交质保金申请、维保完成证明。

建设单位现场核查，确认无缺陷，退还质量保证金。

全部款项结清，工程财务闭环，全套结算资料归档。

七、常见风险点（造价实操提醒）

签证无签字盖章，结算直接卡壳；过程一定要完善手续，不要全部堆到竣工再补。

送审不做签收，后期建设单位说没收到结算，造成逾期风险。

对账只口头沟通，没有书面记录，后期反复翻案。

忽略甲供材、水电费、工期罚款，审定后才发现漏扣。

质保金到期不主动申请，长期挂账回款滞后。

简化版流程速记

资料收集整理 → 承包人编制结算、报送签收 → 建设 / 审计受理初审 → 对量对账、争议协调 → 签署结算审定表、出具审核报告 → 内部审批、开票申请付款 → 支付尾款 → 质保期满退回质保金 → 资料归档，全部回款闭环。
