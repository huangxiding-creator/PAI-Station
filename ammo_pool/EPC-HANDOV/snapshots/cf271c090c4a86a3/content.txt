# 评标重大失误致导致实际无效合同履约后的结算实务研究

来源: 微信公众号·造价 AI 生成局 (RSS)

原创 造价协作助手 2026-09-30 21:06 江苏

项目属依法公开招标；定标过程存在重大失误；本应被否决却中标；该中标人履约完毕；履约中出现合同违约，未按合同及投标承诺的品牌供货；工程竣工验收已通过。争议焦点：合同是否无效、验收合格是否阻断品牌违约索赔、无效合同下如何结算、评标失误如何追责。

# 一、事实场景与争议焦点

本案例事实链条为：项目属依法公开招标；评标定标过程存在重大失误；投标仅三家，其中一家本应被否决（废标）却中标；该中标人履约完毕（履约结束）；履约中出现合同违约，典型为未按合同及投标承诺的品牌供货；目前工程竣工验收已通过。争议焦点集中在四层关系的叠加：合同是否无效、验收合格是否阻断品牌违约索赔、无效合同下价款如何结算、评标失误如何追责。

# 二、合同效力：中标无效导致施工合同无效

依法必须招标项目中，应废标者中标且已完工不可补救，落入《招标投标法实施条例》第82条："依法必须进行招标的项目的招标投标活动，违反本法和本条例的规定，对中标结果造成实质性影响，且不能采取补救措施予以纠正的，招标、投标、中标无效。"应废标者中标属评标定标重大失误，对中标结果具实质性影响，且工程已完工交付不可补救，故中标无效。依《施工合同司法解释（一）》法释〔2020〕25号第1条第3项"建设工程必须进行招标而未招标或者中标无效的"合同无效，并援引《民法典》第153条第1款，施工合同应认定无效。

需特别指出一个强化情节：三家投标中废掉一家只剩两家有效，本就达不到竞争性招标通常要求的至少三家有效投标人，招标程序本身存在重大瑕疵，进一步支持中标及合同无效认定。当然，该路径以项目确属"依法必须招标"为前提——若实际未达规模标准或为纯民营自有资金项目，则"应废标"可能只是内部管理瑕疵，合同反而有效，处理前须先核实强制招标属性。

# 三、竣工验收通过不阻断品牌违约索赔

五方验收（建设、勘察、设计、施工、监理）通过形成工程质量合格的推定，但该推定并非绝对。最高人民法院2025年"建设工程质量保护典型案例"明确"建设工程经竣工验收合格，并不意味着施工单位质量责任的终结"，其中隐蔽工程虽经验收但仍存缺陷的，判承包人承担修复费，纠正了"一旦验收合格、质量责任即转移"的错误观念。就品牌替换而言：若承包人隐瞒实际品牌、以次充好，甚至投标承诺品牌而实际供应不符（可能触发《招标投标法》第54条弄虚作假），发包人仍可追责；反之，若发包人验收时明知或应知品牌不符却未提异议，可能成立"受领瑕疵"、按与有过失减轻承包人责任（如新疆高院(2016)新民终450号、泉州中院(2020)闽05民终2312号所体现的处理口径）。因此，发包人能否成功索赔，关键在于证明品牌替换系隐瞒或实质不符，而非自身验收疏漏。

# 四、价款结算：折价补偿，但按实际品牌价值减价

合同无效不等于不付款。《民法典》第793条规定"建设工程施工合同无效，但是建设工程经验收合格的，可以参照合同关于工程价款的约定折价补偿承包人"；法释〔2020〕25号第24条进一步确认数份合同均无效但质量合格的，参照实际履行的合同折价补偿。付款以合格工程的实际价值为限，而非按原合同名义价照付。

落到品牌违约上，结算不能按合同承诺的溢价品牌全额计价，而应按实际供应品牌价值结算、扣除品牌差价。实务已有判例支持：福建龙岩中院(2021)闽08民终733号依鉴定认定品牌差价三十二万二千四百一十七元，在应付工程款中扣除。这是发包人最实在的结算抓手——在折价补偿的总框架下，对品牌不符部分据实减价。

# 五、品牌违约的实体救济

合同虽无效，质量瑕疵责任不因无效而免除（法释〔2020〕25号第12至14条精神；最高法案例明确无效合同下仍按合格工程折价、按过错担责）。结合《民法典》第157条无效行为损害赔偿、第582条瑕疵履行可请求修理重作更换减少价款、第617条质量瑕疵担保，发包人可主张：其一，按实际供应品牌价值结算（减价）；其二，在合理期限内请求修理、更换；其三，赔偿差价与可得利益损失。取证重点为材料进场验收记录、品牌不符的往来函件、监理或发包人签发的罚款单等。

# 六、投标承诺品牌与实际不符的定性

若投标人以承诺特定品牌谋取中标、实则明知无法供应或供应不符，可能构成《招标投标法》第54条"以其他方式弄虚作假，骗取中标"（《实施条例》第42条列举伪造证件、虚假业绩等"其他弄虚作假行为"）。一旦认定，将独立构成中标无效，并触发：处中标项目金额千分之五至千分之十罚款，没收违法所得；情节严重取消一至三年投标资格乃至吊销执照；给招标人造成损失的赔偿；情节严重可追刑责。发包人应向行政监督部门举报并同步索赔。

# 七、评标定标重大失误的追责

行政责任层面，评标委员会成员依《实施条例》第71条（"对依法应当否决的投标不提出否决意见""不按照招标文件规定的评标标准和方法评标""其他不客观、不公正履行职务"等）责令改正，情节严重禁止一定期限评标、特别严重取消资格；收受贿赂依第72条处罚。招标代理机构违规依《实施条例》第65条、第70条及《招标投标法》第50条规制，给他人造成损失的依法赔偿。

民事责任层面，评标委员会由招标人组建、二者为委托关系（依《民法典》第919条），评标错误的对外责任先由招标人承担（如相关判例判招标人先向受损方赔偿），招标人再向有故意或重大过失的专家追偿；招标代理机构因委托或过错向招标人担责。发包人可向行政监督部门投诉评标成员及代理机构，并就过错损失提起民事索赔。

# 八、审计对两笔扣减的区分（正面适用效力性/管理性区分）

本案恰是正确运用"效力性/管理性"区分的正面范例，而非审计滥用。结算中须区分两笔性质不同的扣减：其一为"效力性无效"项——中标、合同无效但验收合格，依法仍应折价付款，审计不能仅因效力瑕疵拒付或全额核减；其二为"质量违约减价"项——品牌不符是独立的质量违约，应按实际价值从价款中扣除。二者法律依据不同，审计须分别列项，既不能把"按合格工程付款"误作"全额认可"，也不能把"品牌减价"混同为"效力扣减"。

# 九、综合处理路径建议

第一，确认强制招标属性，凡属《招标投标法》第3条范围方适用本路径，否则按普通合同无效或有效处理。第二，认定中标无效、施工合同无效，依据《实施条例》第82条与法释〔2020〕25号第1条第3项。第三，竣工验收合格下参照合同折价补偿，但按合格工程实际价值结算，就品牌不符部分减价。第四，就品牌违约索赔，主张减价、修理更换、赔偿差价损失；同步向行政监督部门举报可能的第54条弄虚作假，请求行政处罚并索赔。第五，向评标委员会成员、招标代理机构追责，行政投诉加民事追偿。第六，审计分别列项，避免混淆效力性扣减与质量违约减价。

# 结论

该场景下，施工合同因中标无效而无效，但竣工验收合格使承包人仍有权折价补偿，付款以实际价值为限；承包人不按承诺品牌供货构成质量违约，发包人应按实际供应品牌价值减价结算并索赔，涉嫌弄虚作假的另予行政处罚乃至刑事追责；评标与代理的重大失误应行政投诉加民事追偿；审计须将效力性无效下的折价付款与质量违约的减价作为两笔不同性质的扣减分别处理。核心主线可概括为：合同无效不免除质量义务，验收合格不阻断违约索赔，结算减价依据实际价值，评标过失另行追责。
