# “六张网”项目怎么申报资金？

2026-09-16 14:31 河北

“六张网”进入项目落地期。（国家水网、新型电网、算力网、新一代通信网、城市地下管网、现代物流网）据测算，2026年“六张网”及相关重点领域投资规模超7万亿元，“十五五”累计规模望超20万亿。

但各地城投、产业国企扎堆申报，多数项目死在“包装碎片化、资金拼盘乱、手续不全、重复申报”。本文结合2026年最新审核口径，把“选什么资金—怎么包装—材料清单—流程节点—红线”一条线讲清。

一、先选对资金：六张网按“收益属性”分三类，选错渠道初审直接刷

2026年三大主力资金盘子：中央预算内投资7550亿（无偿不还要）、超长期特别国债1.3万亿（20–50年、中央财政还本付息）、地方专项债4.4万亿（项目收益自平衡还），外加8000亿级政策性金融工具补资本金。

1. 纯公益类（无稳定现金流）→ 国债+央投

适用：防洪水利、农村饮水、老旧燃气管网改造、城市内涝治理、乡村5G补盲。

中央预算内：东部补助10%–30%、中部15%–45%、西部最高60%，单项目上限1亿；

超长期特别国债：占总投30%–70%，可充资本金，2026年向地下管网/水利倾斜最大。

2. 准经营类（有水电气/运维收费）→ 专项债为主力

适用：城乡供水一体化、综合管廊、园区增量配网、污水处理、区域物流枢纽。

专项债覆盖总投60%，自身收益覆盖本息≥1.2倍（部分管网项目要求1.3倍）；

标准拼盘：专项债60% + 特别国债20% + 政策性贷款/自筹20%。

3. 市场化收益类（算力/风光储/冷链）→ 专项债+政银贷+产业基金

适用：智算中心、源网荷储、充电桩网络、产业物流园、工业互联网。

算力网民间投资为主力，国企牵头可叠专项债（限数据中心基建，不含纯GPU采购）+绿色信贷+引导基金；

严禁把“商业算力销售中心”包装成公益项目骗专项债。

一句话口诀：无收益走国债/央投，有租金水费走专项债，算电协同走混合拼盘，同一工程量绝不央投+国债双报。

二、申报前5道硬门槛，缺一道系统直接驳回

入库编码：录“国家重大建设项目库”+省级六张网专项储备库，并纳入本地十五五专项规划，无编码不能线上提交；

手续闭环：立项/备案、规划选址、用地预审、环评、节能、稳评、水保全部齐全；改造类管网/电网必须附设施老化检测+安全风险评估；

进度合规：仅支持新建/在建续建，已完工或投资完成＞80%一票否决，资金下达6个月内须形成实物量；

主体合规：城投/水务/能源/产业园区国企牵头，民企不能单独报，可组联合体由国企牵头；

自筹落实：自有资金承诺函+银行授信意向，高负债空壳城投会被压缩额度。

三、项目包装：同样修管子，名字起对多拿几千万

评审最烦“XX路雨水管道改造”这种碎片化小微项目。统一用片区/流域/园区系统打包：

❌ XX路雨水管道改造工程

✅ XX片区雨污分流与城市生命线管网综合提升工程（含老旧燃气管网更新+内涝点治理+智慧监测+附属管廊）

分赛道包装亮点（写进资金申请报告核心章）：

水网：防洪标准提升、灌区现代化、覆盖人口/灌溉面积量化；

新型电网：源网荷储、虚拟电厂、算电协同、零碳园区配套；

算力网：东数西算节点、绿色低碳算力调度平台（单项目总投≥8000万更易拿大额国债）；

地下管网：老旧管线安全隐患、漏损率降至10%以内+DMA分区计量、综合管廊智慧运维；

通信网：乡村5G补盲、工业互联网标识、园区千兆光网；

物流网：多式联运、城乡冷链、产地集配中心（库容≥2万m³、设备投资≥500万）。

必加三大效益：社会效益（覆盖人口/防灾）、经济效益（水费/机柜租赁/仓储现金流）、低碳效益（碳减排量/零碳绑定）——多网融合（电网+算力、管网+通信）额外加分。

四、资金拼盘三种主流模板（2026落地版）

模板A｜纯公益管网/水利（10亿）

超长期特别国债6亿（60%）+中央预算内2亿（20%）+国企自筹2亿（20%）

→ 老旧燃气/防洪/农村饮水，央投与国债二选一，不叠加同一工程量。

模板B｜准经营供水/管廊（10亿）

专项债6亿（60%）+特别国债2亿（20%）+国开行/农发行低息贷2亿（20%）

→ 收益覆盖倍数≥1.2，专项债做“一案两书”（实施方案+财评+法律意见书）。

模板C｜智算中心/冷链物流（10亿）

专项债4亿+银行绿色信贷4亿+国企自有资金2亿

→ 可引入社会资本组联合体，但国企牵头；算力项目须区分“基建（可债）”与“设备采购（市场化）”。

重复申报红线：同一建设内容不能同时拿央投+特别国债；中央补助叠加比例不超总投80%。

五、材料清单与流程节点

通用材料：

资金申请报告（政策符合性/建设方案/资金筹措/收益测算/绩效目标五章）、立项及前置批复全套、企业近三年审计+信用中国无失信、配套资金承诺函、绩效目标表、无隐性债务承诺。

分资金加件：

专项债：收益与现金流评估、法律意见书、收费机制方案；

特别国债：设施隐患评估、国家战略契合说明、年度实物工作量计划；

中央预算内：公益性论证、民生短板缺口分析。

5步流程：

提前3个月入库（发改+行业主管部门双线对接）；

锁定资金拼盘+银行授信；

编资金申请报告（一套材料不混报三类资金）；

国家重大库/省级债平台填报→区初审→市复审→省发改财政终审；

评审答疑→资金下达→6个月内开工→按月报进度。

2026关键窗口：

专项债提前批：上年9–10月报次年额度；

中央预算内：每年3–5月集中报；

超长期特别国债：3–4月主报，8月为补充申报黄金期（当前正当时）。

六、10条红线，踩中直接出局

已完工/投资＞80% → 否决；

含楼堂馆所/商业地产/纯景观 → 剔除；

手续缺失或建设内容与批复不一致 → 不予受理；

虚增现金流（如把财政补贴算作经营性收入） → 3年禁报；

同一工程量央投+国债双报 → 系统查重驳回；

民企单独报六网基建 → 无国企牵头不入库；

触碰永久基本农田/生态红线 → 一票否决；

高负债空壳城投无自筹证明 → 压缩或取消；

碎片化小微改造无片区统筹 → 优先级最低；

无数字化/低碳内容 → 同等条件下砍补助比例。

结语：2026年8–9月补充申报窗口，拼的是“前期成熟度”

六张网不是新瓶装旧酒，评审逻辑已经从“你建了多少公里”变成“你解决了哪张网的协同短板、钱怎么还、退出时资产归谁”。

国企能拿到钱的项目，共性只有四条：入规划库、手续闭环、片区打包、资金不重复。
