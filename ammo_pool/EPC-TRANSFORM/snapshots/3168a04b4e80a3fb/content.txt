# 10月15日 南京 西安 “新形势下国企投融资转型、项目谋划及存量资产盘活实操高级研修班”的通知

2026-09-17 14:31 河北

一、培训目标

1.划清合规红线：吃透 2026 财政、金融、国资改革及地方债务监管政策，规避隐性债务、融资违规、国有资产流失风险；

2.提升项目申报成功率：掌握专项债、超长期特别国债、中央预算内投资包装技巧，搭建标准化项目库，优化弱收益项目现金流；

3.打通信贷融资通道：区分国开行、农发行、各大商业银行差异化授信逻辑，破解抵押物不足、现金流薄弱、额度低、利率高等融资痛点；

4.批量盘活存量国有资产：土地、厂房、特许经营权、应收账款、数据资产一体化盘活，掌握 ABS/ABCP、公募 REITs、经营权出让等多元模式；

5.明确平台市场化转型路径：实现从单一融资平台向产业组织者、价值创造者转变，构建 “投、融、管、营” 一体化运营体系；

6.现场一对一解决企业难题：携带本单位存量项目、融资堵点、资产盘活难点现场会诊，同步领取全套融资申报模板、风险自查清单、项目收益测算工具。

二、培训内容

第一部分：2026 宏观政策全景解读与国企市场化转型顶层设计

（一）2026 国家财政、金融、国资及十五五投融资体制改革核心政策梳理

1.十五五投融资体制改革核心要点、对县域平台公司的全新要求；

2.国资国企改革深化提升行动政策要点，平台从 “融资主体” 转向 “产业组织者、价值创造者” 转型路径；

3.国办 35 号文地方政府债务监管新规核心要求，县域国企债务化解路径、合规融资清晰边界，隐性债务防控实操标准；

4.平台 “投、融、管、营” 一体化高质量发展框架，现金流平衡、资产流动、资本补充三位一体风险防控体系。

（二）国家各类政策性资金申报最新导向与县域适配赛道

1.超长期特别国债、中央预算内投资支持领域、申报主体、配套资金要求；

2.地方政府专项债投向、收益平衡硬性标准、县域可落地适配项目清单；

3.PPP 新机制、EOD 生态导向开发、特许经营新政实操落地约束与收益设计要点；

（三）国企市场化转型核心破局思路

1.从传统融资平台向 “实体经营 + 资本运作” 转型实操路径；

2.国企战略重组与专业业务整合，破解资产分散、业务同质化难题；

3.“负面清单 + 契约化” 市场化经营机制搭建，数字化赋能实现从 “管资产” 到 “管资本”；

4.“管委会 + 公司” 片区开发运营模式落地要点，政府主导、市场化双向协同机制。

第二部分：优质项目全周期谋划、储备与包装实操

（一）项目谋划底层逻辑与顶层设计

1.项目谋划三大核心逻辑：政策逻辑、区域规划逻辑、市场现金流财务逻辑；

2.从单点零散项目转向片区一体化联动开发，“政策研究 — 资源整合 — 需求分析 — 项目包装” 全链条工作机制；

3.政策文本对标清单法：从国家、省级政策中挖掘可申报项目。

（二）热门赛道项目包装实操要点

1.新型城镇化：城市更新、老旧小区改造、保障性住房、市政配套、智慧县域；

2.乡村振兴：和美乡村、高标准农田、农村基础设施、农文旅康养项目；

3.产业发展：园区提质升级、标准厂房、工业数字化、重大设备更新（两重两新）；

4.生态绿色：EOD、污水垃圾治理、流域生态修复、绿色低碳项目。

（三）项目手续、收益体系与组合融资包装标准

1.可研、立项、备案、规划、用地手续全流程规范，常见驳回问题整改方案；

2.无收益、弱公益性项目市场化包装方案，经营性现金流补足、增收渠道设计技巧；

3.多类型资金组合包装标准：专项债 + 配套银行贷款、国债资金 + 市场化信贷、存量盘活置换融资。

（四）标准化项目库长效管理机制

1.建立 “谋划一批、储备一批、申报一批、建成一批” 动态分级项目库，实现精准申报、滚动更新。

（五）案例复盘+ 现场实战演练

1.多地县市落地优质项目全流程拆解、申报失败项目核心问题复盘；

2.可现场提交本单位存量项目，讲师团队现场优化项目方案、搭建合规收益测算模型。

第三部分：国企银行信贷全流程实操、难点破解与多元创新融资

（一）县域主流融资工具差异化适配

1.国开行、农发行、国有大行、股份制银行、地方城商行 / 农商行信贷产品适配场景、准入门槛对比。

（二）政策性贷款专项申报全流程

1.基建、乡村振兴、生态环保、园区民生类政策性贷款申报条件、全套材料清单、审批流程、放款管控要点。

（三）银行授信底层审核逻辑

1.主体评级、资产负债结构、经营性现金流覆盖率、抵质押担保、隐性债务风控审核核心要点。

（四）标准化贷款申报材料编制规范

1.融资可研、财务报表、融资方案、资金用途、分期还款方案撰写模板与避坑要点。

（五）国企高频融资难题破解方案

1.授信额度不足、自有抵押物匮乏、经营性现金流薄弱、审批周期长、综合融资成本偏高落地解决路径。

（六）创新组合融资模式落地设计

1.专项债配套银行贷款、政策性贷款叠加市场化信贷、存量高息贷款置换降本实操；

2.政府融资担保、财政贴息撬动低成本信贷；产业基金、股权合作、混合改革引入社会资本；

3.政银企常态化对接平台搭建，直融优先、存量置换的低成本融资体系构建。

（七）融资合规长效风险防控

1.资金规范使用、杜绝新增隐性债务、贷款逾期预警、防范银行抽贷断贷实操举措；

第四部分：国有存量资产精细化盘点、批量盘活与资本化运营实战（含创新资本工具拓展）

（一）国有资产全面清查、确权与台账管理

1.土地、闲置厂房、低效园区、老旧房产、市政设施、供水环卫停车等特许经营权、应收账款、闲置资金分类盘点；

2.资产权属梳理、价值评估流程，建立可运营、可融资、可转让标准化资产台账，“一地一策、一企一策” 盘活策略。

（二）存量资产多元化盘活落地模式

1.传统模式升级：公开招租、长期租赁、先租后购、资产划转整合、提质改造、经营权出让；

2.合作开发模式：国企资产 + 民企运营、闲置资产联动产业招商、资产接收 + 以物抵债组合处置；

3.低效资产专项盘活：闲置园区、低效用地、老旧物业改造增收实操方案。

（三）公共资源特许经营权商业化运营

1.供水、环卫、城市停车、充电桩、文旅资源、园区运营、乡村资源长效收益运营方案。

（四）资产轻量化资本化运作专题（新增创新拓展内容）

1.收益权、应收账款、租赁债权打包融资：ABS、ABCP 设立、现金流测算、信用增级实操要点。

2.公募 REITs 政策要求、底层资产筛选标准，区县平台培育可发行 REITs 资产路径，实现 “投融管退” 闭环；

3.数据资产创新融资：数据资源确权入表、资产评估流程、数据质押授信实操案例。

（五）国有资产全流程合规管控

1.资产登记、评估、交易、处置合规流程，严防国有资产流失硬性要求。

（六）长效市场化运营体系搭建

1.市场化运营团队组建、绩效考核机制、资产动态数字化管控、项目收益反哺滚动开发机制。

（七）标杆落地案例分享

1.区县国企批量盘活存量资产实现增收典型案例；

2.“管委会 + 公司” 盘活低效用地、预招商盘活闲置厂房实战案例；

3.资产证券化、数据资产质押、林权 / 采砂权作价注入平台落地案例。

第五部分：现场答疑、企业专项问题会诊与一对一落地指导

1.现场自由提问，讲师针对债务化解、项目申报、授信融资、资产盘活共性问题集中解答；

2.参会单位可携带本企业真实项目、融资材料、闲置资产清单，开展分组专项会诊；

3.针对不同县域、不同资质平台定制转型、融资、盘活实操落地建议。

三、培训对象

各级政府发展改革、财政、环保、住建、交通运输、水利、农业农村、林草、文旅等部门有关人员；城投/ 交投 / 水投 / 农投 / 文旅投等国企有关人员；污水垃圾处理、城乡供水供气供热、仓储物流、新能源、环保及建筑施工等企业有关人员；银行、证券、基金、信托、保险等金融机构有关人员等。
