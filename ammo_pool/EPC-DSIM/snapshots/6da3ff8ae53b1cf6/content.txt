# 国际工程｜从一个沙特高铁项目研究中国设计咨询公司切入国际市场之路（五）

原创 无名高手 2026-10-01 09:42 北京

先把Egis的真实角色定位清楚

Q-Express目前公开的项目基础是：

一期约 84 km

5座车站

最高速度 250 km/h

Qiddiya目标旅行时间约 30分钟

PPP / EPCF两种采购路径推进

2026年进入正式招标阶段。

Egis于2023年被报道为项目Technical Adviser。

而Egis自己的项目资料明确将Q-Express工作描述为Feasibility Studies Review + Reference Design + Tender Documentation

另外Egis公开资料还显示其参与Q-Express相关的Financial Feasibility Assessment + Tariff Recommendation

所以，可以把Egis的实际价值链概括为：

前四个环节具有较强公开证据；后续实施阶段是基于Technical Adviser模式构建的完整WBS，不应误认为已经由公开资料确认属于Egis合同范围。

180项WBS总览

为方便理解项目，把完整工作划分为18个Work Packages × 10项 = 180项，每个Work Packages里面的内容基于篇幅原因，不再详列。

真正理解Egis，要从180项任务中看到它们之间的逻辑

这才是Egis的真正商业位置。

Egis需要什么样的人员？

这里要特别区分实际Egis Q-Express团队规模——公开资料没有披露。

因此下面是按照84 km、250 km/h、5座车站、业主侧TA、Reference Design + Tender Documentation这个工作量推算的合理Benchmark，而不是Egis实际人头数。一般会有三大团队组成：

一，核心项目管理团队

二、专业技术团队

三，专业顾问团队

因此合理的峰值组织规模大致是：如果把核心、专业和专家全部算进去，核心+专业团队约45–55人

如果把全球专家、阶段性Specialist、审查专家、短期顾问等全部算进去，整个咨询资源池可能达到60–80+人次，但不意味着全部Full-time。项目管理团队根据项目的执行计划，安排人员进入或退出。

这也是国际咨询公司与中国设计院的一个明显区别。中国设计院会安排大量Full-time专业设计人员。

Egis会按照Core Team + Global Expert Pool + Specialist Review来安排。也就是：

Egis本身强调其全球铁路业务拥有覆盖高速铁路、系统工程、运营、维护、资产管理等能力。

中国设计院对应能力Gap：

第一层——不是“不会设计”

这是最重要的判断。

如果仅比较Civil / Track / Station / Power / Signalling等专业团队，中国设计院并不存在根本性技术劣势，甚至经验丰富优于他们。真正的Gap主要在业主侧咨询能力。为说明问题，概括出20项内容作为比较。

真正最大的Gap其实是“身份”认同。这是最值得强调的。

中国设计院的默认自己身份是Engineer；Egis的客户看到的身份是Technical Adviser。这两种身份的工作逻辑不同。

工程师思维，一下子就会进入到具体的技术问题中去，例如工程师思维下典型问题会是：

这个桥怎么设计？

这个车站怎么布置？

这个信号系统怎么设计？

这个变电站容量是多少？

Technical Adviser思维会站在业主的角度为实现业主的商业目标从而用工程能力来做出判断。比如典型的问题会是：

为什么需要这个桥？

为什么选择这个方案？

这个方案对CAPEX有什么影响？

对OPEX有什么影响？

对运营可靠性有什么影响？

谁承担这个风险？

如果设计变更，谁承担？

银行是否接受？

PPP合同怎么规定？

这就是Engineering Judgment → Commercial Judgment。

如果要进入Egis这种类型的市场，不应该简单设置一个“海外设计部”就可以解决问题，而是应当补全

以下8个“产品”：

Product 1：Owner’s Technical Adviser

Product 2：Independent Engineer

Product 3：Lender’s Technical Adviser

Product 4：Technical Due Diligence

Product 5：PPP Technical Advisory

Product 6：System Assurance / RAMS

Product 7：Interface Management

Product 8：Testing & Performance Assurance

尤其值得注意是，LTA其实是中国设计院进入业主侧的“最佳跳板”。因为LTA天然要求：Independent Technical Judgment

而中国设计院已经具备Engineering Technical Depth

两者之间只需要补上：

Finance

Contract

Risk

Independent Review

International Liability

就可以形成新的产品。

把Egis与中国设计院的商业模式做一个直接对比

如果把Q-Express当成一场“能力考试”

那么中国设计院可能已经有80分以上的专业设计能力，但是国际咨询能力估计只能有40-60分。

尤其是PPP / LTA / IE / Technical Risk / Contract / Bankability这部分可能只有20–40分。

这不是说中国设计院能力弱，而是过去根本没有按照这个商业模式训练。Egis真正建立的“护城河”其实不是技术，Egis当然有技术，但更重要的是它把技术集成在咨询能力中作为基础

组合成了一个Advisory Product。这就是中国设计院最值得学习的地方。

一般的设计院一讲国际化，首先是成立一个海外事业部扛起责任，但实际运行很难实现依靠海外事业部来“接轨”，轨距不同，一个部门如何来接？

组织上不要简单成立“海外事业部”，而应该建立一个International Advisory Platform。

然后让原来的建筑 / 民航 / 机场 / 轨道 / 市政 / 工业 / BIM等专业院成为Technical Competence Centers，而不是继续让每一个专业院自己单独出海。

最重要的是建立“三级专家体系”

Level 1——Discipline Expert

例如：

Track

Civil

Power

Signalling

Architecture

Level 2——System Expert

例如：

Rail System

Airport Interface

Station System

RAMS

Systems Integration

Level 3——Adviser

能够回答：

这个项目是否值得建设？

技术风险在哪里？

谁应该承担风险？

银行是否应该融资？

合同应该如何写？

这三级是：

专业工程师

↓

系统工程师

↓

技术顾问

也是中国设计院最应该建立的人才金字塔。

咨询设计公司的能力结构是这样的：

中国设计院目前最强的是Level 1–3

Egis型国际咨询公司真正形成竞争壁垒的是Level 4–8

Q-Express案例给中国设计咨询行业最大的启示

不是“我们需要学习Egis怎么做高铁设计。”更不是鄙视egis的高铁业绩远不如我。

而是“需要学习Egis如何把工程技术能力包装成业主决策产品。”

Egis公开资料显示，其铁路业务本身已经从可研一直延伸到采购、系统工程、施工监督、测试调试、独立安全评估、BIM/Digital Twin、运营维护和资产管理。

这意味着它实际上形成了Idea → Feasibility → Reference Design → Procurement → Delivery → Testing → Operations → Asset Management

的完整价值链。

把中国设计院的能力升级成“Egis 2.0”

不二叔最近一直致力研究的中国设计咨询企业国际化，我认为最合理的路线不是照搬Egis，而是形成中国特色的“Engineering + Advisory + Finance + Risk”模式

这才是不二叔研究Q-Express案例希望带给中国设计院的东西。虽然说研究的案例是高铁项目，但希望能给到借鉴的远不是高铁而已。

对于中国设计院有一个非常现实的切入点：不需要一开始就和Egis争Owner’s Technical Adviser。完全可以从中国银行、保险公司、EPC联合体的Technical DD / LTA / Independent Design Review / Interface Review / RAMS / Performance Test做起，再逐步向Owner’s Engineer、Independent Engineer和Technical Adviser上移。

这条路径的最大优势是，中国设计院原有的专业技术优势可以直接转化，而需要补的恰恰是PPP、金融、合同、风险和独立性。

另外Egis目前在利雅得已经设有中东总部，这种本地组织 + 全球专家网络也是其能长期承担业主侧顾问工作的组织基础。
