EPC设计-采购-施工一体化管控管理要点（完整版、可落地）

EPC之三

EPC总承包工程相比施工总承包不知道要复杂多少，其工作理念，工作方式和相关工作内容等都是大相径庭。如果总承包单位没有一定的总承包经验，没有一定的管理水平，不懂调配相关资源，不懂各工种之间的衔接，没有整体架构思想，其组织、协调、配合及整体规划能力不强，总承包不可能会顺利交付工作成果。为此，为了能帮助现有总承包老板不再混淆相关工作性质，必须要明确，总承包要想一体化管控成功，最后能顺顺利利向业主交付总承包成果，所有的管理者都要知道总承包一体化管控管理要点。没有科学、合理的管理纲要，其管理效能一定会大打折扣。

前言部分

本要点适用于EPC总承包项目全周期管控，核心目标：打通设计、采购、施工界面割裂、前后脱节、互相甩锅、变更失控、工期超期、成本超支等行业通病。

核心管理理念：设计牵头、采购前置、施工预控、三方并行、全过程闭环、痕迹化管理、权责清晰、风险前置。

对外统一对业主、对内一体化协同，所有工作实行“前置评审、过程管控、闭环销项（指问题销项）、有据可查”。

第一部分 总体管控原则（通用底线，三方必须遵守）

1. 统一对外原则：设计、采购、施工不得单独对接业主下发、变更、指令，所有业主需求、变更、疑问统一由EPC项目部接收、转发、确认。

2. 书面留痕原则：所有技术要求、变更、异议、风险提示、会议决策必须书面留痕，口头指令一律无效。

3. 前置协同原则：采购、施工提前介入方案、初设、施工图阶段，禁止设计完成后再移交采购、施工。

4. 先定技术、后定采购、再排施工：图纸不稳定、技术参数未锁定，严禁盲目订货、盲目施工。

5. 先解决问题、后划分责任：现场问题优先保障项目推进，闭环完成后再复盘追责。

6. 限额设计、限额采购、节约施工：全链条受控，杜绝技术过剩、盲目无序采购、施工浪费。

第二部分 设计板块标准化管控要点（龙头管控）

一、设计核心定位

技术总负责、方案总把控、投资总源头；对图纸完整性、技术合理性、选型可行性、接口准确性、限额合规性负首要责任。

二、设计阶段关键管控动作（可操作）

1. 业主需求锁定管控

方案及初步设计阶段必须完成《业主要求确认书》，锁定功能参数、技术参数标准、验收标准、交付范围。业主口头要求一律不执行，不修改图纸，不调整方案。新增需求必须走书面变更及价款、工期确认。

2. 限额设计刚性管控

方案、初设、施工图三阶段动态造价测算，严格匹配EPC合同总价。一旦超限额，立即优化方案、简化选型、优化构造，严禁施工图完成后再调整。

3. 图纸输出完整性管控（核心）

完整输出必须包含：施工图纸+设计说明+计算书+设备技术规格书+选型表+接口条件表+预留预埋参数+荷载数据+供货范围说明。

实行图纸完整性检查表制度，缺项、缺参数、缺接口一律不予出图审批，不得下发采购及施工。

4. 三阶段三方联合评审

方案阶段：设计、采购、施工联合比选，兼顾技术、造价、供货、施工难度。

初设阶段：三方评审选型、标准、概算，问题闭环后方可进入施工图。

施工图阶段：施工开展可施工性审查、采购开展技术可采购性审查，未闭环不得出图。

5. 接口专项管控

土建-设备、土建-机电、机电设备各专业接口全部落图，形成《专业接口对照表》，杜绝无图纸、口头对接。

6. 变更管控

所有设计变更必须附带：变更图纸+变更说明+参数调整说明+对采购、施工影响分析。严禁只发通知单、无附图、无参数。

三、设计对内协同标准

1. 接收采购市场供货周期、主流设备参数、非标风险反馈，及时优化选型。

2. 接收施工现场工况、吊装条件、地质变化反馈，及时调整图纸及技术参数。

3. 对采购、施工提出的合理技术异议必须书面回复，不采纳需写明理由并书面留痕。

四、设计主要风险及应对

1. 选型小众、市场难采：前置采购评审，提前替换通用设备。

2. 图纸错漏碰缺、接口缺失：三级审图+三方会审+完整性检查表闭环。

3. 业主随意提高标准和扩能：书面锁定边界，超范围必须签证调价。

4. 超概算失控：全过程限额测算，动态优化。

第三部分 采购板块标准化管控要点（枢纽管控）

一、采购核心定位

技术落地转换器、进度保障枢纽、成本控制关键；承接设计技术标准、匹配施工进度计划、管控设备质量与供货风险。

二、采购阶段关键管控动作（可操作）

1. 技术文件会签制度

所有设备材料招标文件、技术规格书必须设计会签、采购复核双签字，无签字不招标、不定合同、不下单采购。采购严禁私自修改设计参数、降低技术标准。

2. 供货边界固化

采购文件、合同明确：设备本体、附件、接口件、备品备件、专用工具、技术资料、出厂试验资料范围，杜绝到货缺件、资料缺失。

3. 长周期设备前置管控

初设阶段提前介入，识别长周期设备，提前开展技术调研、市场调研，给设计选型提供周期约束。

4. 供货计划与施工进度双匹配

编制《设备材料到货计划表》，与施工总进度、月周进度一一对应，做到“到货即能用、用料即到货”，杜绝过早积压、滞后待料。

5. 设备接口资料前置传递

要求供应商提前提供设备基础、荷载、地脚螺栓、接管、电缆接口资料，及时转发设计复核、下发施工预埋，严禁设备到货后补基础。

6. 出厂验收、到货验收双管控

关键设备执行FAT出厂验收，不合格禁止发货；到货后采购牵头，施工、监理联合开箱验收，留存开箱记录、影像、资料清单。

三、采购对内协同标准

1. 对设计：实时反馈市场价格、供货周期、稀缺设备风险、非标制造难度，辅助限额设计及方案优化。

2. 对施工：同步到货计划、预警滞后风险、移交全套设备资料、配合现场验收及问题处置。

四、采购主要风险及应对

1. 供货延期：建立统一供货台账、节点预警、专人盯厂、预留缓冲工期。

2. 设备参数不符：技术双签、招标答疑、出厂验收把关。

3. 价格超概：前置比价、选型优化、严控非标及小众设备。

4. 资料缺失、接口不符：合同硬性约束资料交付时限及内容。

第四部分 施工板块标准化管控要点（落地管控）

一、施工核心定位

设计成果落地、采购物资实体安装、质量安全进度成本最终执行端；负责现场工况反馈、可施工性审查、实体落地闭环。

二、施工阶段关键管控动作（可操作）

1. 图纸可施工性前置审查

施工图下发前施工技术人员提前介入，核查节点、预埋、基础、吊装、安装空间、接口匹配性，书面反馈问题，未闭环不施工。

2. 图纸会审、技术交底全覆盖

所有分项工程先会审、先交底、后施工，疑问统一汇总设计答疑，严禁私自理解图纸、私自变通施工。

3. 现场工况实时反馈

现场地质、管线、场地、吊装条件与设计不符，必须立即书面反馈项目部及设计，严禁私自施工、私自改方案。

4. 进度计划双向匹配

施工月度、周度计划同步采购，明确用料、用设备时间，提前预警工作面、劳动力、机具需求，提前预警待料风险。

5. 材料设备使用管控

所有进场材料、设备必须参与开箱验收，参数不符、质量缺陷、资料不全严禁使用；材料代用必须经设计书面审批。

6. 隐蔽工程、危大工程专项管控

隐蔽工程先验收后覆盖；危大工程专项方案审批、交底、旁站、验收全流程闭环。

三、施工对内协同标准

1. 对设计：反馈现场施工难点、吊装限制、场地约束、工况变化，参与方案优化。

2. 对采购：准确提报用料计划、工作面时间、仓储吊装条件，提前预警到货冲突。

四、施工主要风险及应对

1. 图纸无法施工：前置审查+书面答疑+变更闭环。

2. 停工待料：进度联动采购、台账记录停窝工、提前预警。

3. 质量返工：交底到位、样板先行、隐蔽验收、问题停工反馈。

4. 界面漏项、错项：界面清单书面划分、三方核对。

第五部分 三方一体化协同机制（固定制度、强制执行）

1. 周协同例会制度：设计通报图纸进度、变更情况；采购通报供货状态、风险预警；施工通报现场进度、图纸及物资需求、存在问题，台账闭环。

2. 三阶段联合评审制度：方案、初设、施工图三方评审，无评审记录不得进入下一阶段。

3. 问题台账销项制度：所有图纸问题、供货问题、施工问题统一台账，明确责任人、完成时限、闭环标准。

4. 接口资料传递闭环制度：接口资料统一收集、复核、下发、签收，全程留痕。

5. 变更联动评估制度：任何设计变更，三方同步评估技术、工期、成本、供货影响，统一处置方案。

第六部分 三方风险划分与责任承担（内部标准、可考核）

1. 设计责任：图纸错漏、参数错误、选型不合理、接口缺失、超概算、未锁定业主需求导致变更损失；采购、施工已书面提示但设计未采纳的，全部责任归设计。

2. 采购责任：未按设计技术文件采购、私自改参数、供货滞后、供应商质量问题、资料未及时传递、到货缺件损坏导致损失。

3. 施工责任：未按图纸施工、未落实交底、未反馈现场工况、未履行图纸及开箱审查义务、私自代换材料、私自变更工艺造成损失。

4. 免责/共担原则：三方均无法预判的地质、规范、政策风险，项目整体共担；已书面提示风险、对方拒不整改的，由过错方全责承担。

第七部分 对外（发包方/业主）关系统一管控标准

1. 统一对外口径，禁止设计、采购、施工私自对接业主接受指令、修改图纸、承诺标准。

2. 业主口头需求一律转为书面确认，未确认不执行、不变更、不增项。

3. 业主提标、扩能、指定品牌，必须做价差表、工期测算，办理正式变更。

4. 图纸进度、技术疑问需业主确认的，书面发函列明清单，明确滞后责任。

5. 所有业主争议、矛盾，项目部统一收集证据、统一沟通、统一化解。

第八部分 内部矛盾标准化处置流程（终极解决方案）

第一步：现场暂停争议，优先保推进：出现选型冲突、图纸争议、供货冲突、责任扯皮，先确定临时施工/采购方案，不耽误工期。

第二步：项目经理组织三方协调会：各方只出示书面证据（评审纪要、会签单、台账、反馈记录），禁止口头甩锅。

第三步：形成会议纪要闭环：明确解决方案、工期成本影响、执行责任人、完成节点。

第四步：僵局升级裁决：三方无法统一，上报公司技术/工程委员会做最终裁决。

第五步：事后复盘追责：依据书面留痕资料界定责任，纳入考核、案例归档。

第九部分   一体化管控十条管理底线（红线制度）

1. 无业主书面确认，严禁私自变更功能、提高标准、扩大范围。

2. 无完整技术规格书、无设计会签，严禁采购订货。

3. 图纸未稳定、未完成三方审查，严禁大面积施工、关键设备订货。

4. 接口资料不全、参数不明，严禁开展设备基础、预埋施工。

5. 设备材料未验收、资料不全、参数不符，严禁投入使用。

6. 严禁施工私自改图、私自代材、私自变通工艺。

7. 所有变更必须技术、工期、成本三方联动评估。

8. 所有争议、风险、异议必须书面留痕，口头无效。

9. 供货计划、施工进度必须双向对齐、动态调整。

10. 最优设计=技术可行+采购可采+施工可落地+造价可控。
