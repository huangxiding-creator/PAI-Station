## 普查结论

1. **已验证**：深度调研 agent「计划→检索→综合→引用」管线成熟（deer-flow 82k/STORM 31k/gpt-researcher 29k）；STORM 多 persona 审讯式提问是「比董事长更懂」最可直接移植的机制
2. **已验证**：判断层学术链完整（MT-Bench→verbalized confidence→概率校准→预测市场聚合）——Jev 判断层直接对接
3. **已验证**：结构化企业 API（企查查/天眼查/D&B）+供应链穿透是商业付费验证过的能力，事实层接入即可不重造
4. **空白一**：无主流开源框架原生面向工程/EPC 尽调（最接近 company-research-agent 仅 2.3k star）——EPC 域是真空地带=我方护城河
5. **空白二**：超级预测×企业调研的「预测市场式多 agent 对赌收敛」几乎无人做——差异化候选
6. **空白三**：中文信源 OSINT「信源可靠性分级+自动交叉验证」无现成开源实现
7. **行动指向**：三层缝合=结构化 API 事实层 + STORM 式多视角提问层 + 校准化判断聚合层，每层有巨人可站
