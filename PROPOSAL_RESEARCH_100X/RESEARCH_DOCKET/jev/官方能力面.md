## 官方用例类别（与调研工厂直接相关者加粗）

| 类别 | 官方一句话 | 对调研工厂的意义 |
|------|-----------|----------------|
| **AI Map Reduce over Big Data** | "**100x cheaper** means you can process giant datasets. Search for relevant information over giant corpuses, classify giant agent traces, and extract features to make predictions." | **范围×100 的经济学根基**——官方口径亲口 100×：海量语料逐块语义筛变成付得起的操作 |
| **Universal Verification** | 检测 citation errors, hallucinations, mistakes "at a fraction of the cost for the actual LLM call" | **质量×100 的验证器根基**——E3 已实证真假分离 0.5 正切（真阳 0.58-0.97 / 假阳全 ≤0.48） |
| **Scientific discovery** | ①文献按纳入/排除标准筛选（系统综述）②访谈转写主题标注 ③**检查引文是否支持论断** ④标记方法论缺失 ⑤跨文献实体关系→研究知识图谱 | 调研五工序全命中：信源筛选→主题标注→引文验证→方法论审计→企业知识图谱 |
| **Search and retrieval** | 替代/补充 embedding 的语义评分排序；pairwise rerank；cross-encode 高精度 | 补嵌盲区（bge-m3 语义盲/假阳 17 题）+ 信源 rerank |
| **Model routing** | 难度/风险估计、贵模型升级阈值 | 已落地（l2 快路径 research 0.98 命中）；扩展到成稿路由 |
| **Feature extraction for predictive modeling** | 从自然语言提概率特征×结构化数据→训练预测模型（对 ground truth 验证） | **「比董事长更懂」的预测力来源**——把调研从「描述」升到「预测」 |
| Harness engineering | 模型路由/语义检索/错误检测 guardrail | 工厂自检层 |
| Real-time applications | 150ms 级语义判断 | 常驻工作站的实时意图层 |

## 经济学（官方+实测）

- 单次 $0.0002 / p50 1.3s（本仓实测）——比 LLM 引文判（月度额度）便宜 ~1000×，比人工快 ~10⁴×
- Map-Reduce 模式：4.5 亿 token 语料逐块筛（LLM 做一层粗筛要 ~$2000+，Jev ~$2-20 量级）
